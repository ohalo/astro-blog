## 一、结论先行

正态模型给收益分布只留了两个旋钮：均值和方差。真实收益有偏斜、有厚尾，还有一堆说不清的局部隆起。Normalizing Flow 的思路很直接：找一个**可逆且单调**的变换 $z=T(x)$，把复杂分布的数据映射成标准正态；密度由换元公式给出，雅可比的行列式因为单调性变成一个简单的正斜率乘积。网络不必直接输出密度，只需输出一个可逆的"橡皮筋"。

我在固定种子 `20261126` 的已知真值实验（82% 窄分布 + 18% 左侧宽尾的混合正态）上得到：

- 3000 条训练、1200 条测试。12 个内部结点的样条 Flow 样本外总对数似然 **-1739.13**，高斯 **-1835.22**，Student-t **-1787.40**，真密度 **-1737.09**——Flow 把高斯的 96 分差追回到距真值 2 分；
- 1% 左尾分位数：真值 **-3.792**，Flow **-3.833**（偏 0.041），Student-t **-3.326**，高斯 **-2.924**。1200 个测试日里低于真 1% 分位数的天数应是 11，Flow 报 **10 次**，Student-t **20 次**，高斯 **33 次**；
- 结点数不是越多越好：4 / 6 / 8 / 12 / 16 / 24 个内部结点对应测试似然 **-1750.08 / -1740.62 / -1739.47 / -1739.13 / -1740.04 / -1743.36**，12 个附近见顶；
- 外推是硬伤：把测试数据整体变换为 $2x-2$（真分布的两组分均值、尺度都同步移动），Flow 总似然 **-4080.64**，反而输给 Student-t 的 **-4054.27**，真分布是 **-2568.87**。样条两个端部是线性延拓，尾部形态不会自己跟着分布漂移。

## 二、单调样条 Flow：密度、雅可比与梯度

取 $K+1$ 个内部结点 $\tau_0<\dots<\tau_K$（用训练分位数固定，避免优化时结点交叉），每段给一个正斜率 $s_j=\mathrm{softplus}(r_j)+0.05$。变换是分段线性的：

$$
z=T(x)=b_j+s_j(x-\tau_{j-1}),\quad x\in(\tau_{j-1},\tau_j],
$$

两端用同样斜率线性延拓。$b_j$ 是累积位移，由一个可学习截距 $z_0=T(\tau_0)$ 递推。换元后

$$
\log p(x)=\log\varphi(z)+\log s_j
=-\tfrac12z^2-\tfrac12\log(2\pi)+\log s_j.
$$

单调性保证 $s_j>0$，所以**不需要算矩阵行列式**，一条 `np.log(s[idx])` 就是 logdet。解析梯度也很干净：对当前段斜率 $\partial z/\partial s_j=x-\tau_{j-1}$，对左侧所有段 $\partial z/\partial s_l=\tau_l-\tau_{l-1}$，对截距 $\partial z/\partial z_0=1$；再乘上 softplus 的导数即可喂给 L-BFGS-B。

```python
import numpy as np
from scipy.optimize import minimize
from scipy.stats import norm

class SplineFlow:
    def __init__(self, knots, raw):
        self.knots = np.asarray(knots)
        self.z0 = float(raw[0])                       # T(tau_0)
        self.slopes = 0.05 + np.logaddexp(0.0, raw[1:])
        nk = len(self.knots)
        self.prefix = np.zeros(nk + 1)                # prefix[j] = T(tau_{j-1})
        self.prefix[:2] = self.z0
        for j in range(1, nk):
            self.prefix[j+1] = (self.prefix[j]
                + self.slopes[j]*(self.knots[j]-self.knots[j-1]))

    @classmethod
    def fit(cls, x, n_knots=12):
        knots = np.quantile(x, np.linspace(0.04, 0.96, n_knots+1))
        raw0 = np.concatenate([[norm.ppf(0.04)], np.zeros(n_knots+2)])
        opt = minimize(lambda r: cls.nll_grad(x, knots, r)[0], raw0,
                       jac=lambda r: cls.nll_grad(x, knots, r)[1],
                       method="L-BFGS-B", options={"maxiter": 600})
        return cls(knots, opt.x)

    def logpdf(self, x):
        idx = np.searchsorted(self.knots, x, side="right")
        k = len(self.knots)
        left = np.where(idx == 0, self.knots[0],
                        np.where(idx == k, self.knots[k-1], self.knots[np.clip(idx-1, 0, k-1)]))
        z = self.prefix[idx] + self.slopes[idx]*(x - left)
        return -0.5*z**2 - 0.5*np.log(2*np.pi) + np.log(self.slopes[idx])
```

这里最容易踩的坑是**忘掉截距**：如果把第一个结点强行锚在 $z=0$，左侧 4% 的尾部会被映射到负半轴，其余 96% 却从 0 开始，极大似然会用一个塌缩的段斜率硬凑，样本外似然比高斯还差。我第一版就掉进去了：测试似然 -2392 对高斯 -1835。加上 $z_0$ 之后，隐变量的均值是 0、标准差是 1，段斜率才回到 0.46~1.24 的合理区间。

## 三、样本外密度：赢高斯，也赢厚尾的 t

![样本外密度拟合](/images/normalizing-flow-return-density/fig2_density.png)

真数据由 82% 的 $\mathcal N(0.15,0.75^2)$ 与 18% 的 $\mathcal N(-1.8,1.25^2)$ 组成，左侧有一条宽尾。高斯的样本外总似然 **-1835.22**，t 分布把它改善到 **-1787.40**，Flow 再到 **-1739.13**，距离真密度的 **-1737.09** 只差 2.04。t 分布虽然尾巴够厚，但对称的形状无法同时照顾主峰和左肩；Flow 的折线斜率在左肩明显变平，把那 18% 的质量摆到了正确的位置。

比较时用的是**同一批测试样本的完全似然**，不是分箱卡方，也不做事后平滑。Flow 的密度曲线在图上看有轻微折线感——这正是分段线性变换的真实样子，不是画图分辨率问题。

## 三之一、逆变换是免费的：分位数与情景生成

Flow 真正好用的地方不是画密度图，而是**反解分位数**。给定标准正态分位数 $z_p$，先看它落在哪个累积位移区间 $[b_j,b_{j+1})$，再直接解 $x=\tau_{j-1}+(z_p-b_j)/s_j$；两端用线性外推。整个过程是加减乘除，不需要求根、不需要 MCMC，也不需要排序全部历史样本。百万元级别的情景生成只要一次向量化计算。

这带来两个实务好处。第一，VaR、ES 与压力分位数可以共用同一套参数，不会像历史模拟那样被样本里最差那一天绑死；本文的 1% 分位数就是这样从 $z_{0.01}=-2.326$ 映回来的。第二，把 $u\sim U(0,1)$ 送进 $T^{-1}(\Phi^{-1}(u))$ 就得到同分布的模拟收益，可以用来给组合做非高斯蒙特卡洛，而不用先拟合一个跳扩散再写模拟器。代价是 $T^{-1}$ 的斜率由训练段斜率决定：段斜率跌到接近下界 0.05 时，那个区间的分位数会被拉得很长，必须给斜率下界并监控每段的样本占比。

分段线性保证 $T$ 在结点处连续，但斜率是跳变的，所以密度在结点处有折角。这不是 bug；如果强行要求密度一阶光滑，就得改用三次单调样条并额外约束二阶导，参数化和梯度都要重写。更现实的风险是**结点位置固定后不再更新**：数据漂移时，旧结点会把新增的极端尾部塞进最后一段线性区间，而那段斜率原本是按旧分布估的。滚动重估时建议同时重算结点分位数，而不是只优化斜率。

## 四、99% VaR：覆盖率比点估计更重要

风险岗位真正关心的是分位数。把标准正态的 1% 分位数 $z_{0.01}=-2.326$ 通过学到的逆变换 $T^{-1}$ 映回收益空间，得到 Flow 的 1% 分位 **-3.833**，真值由混合 CDF 数值求根得 **-3.792**，误差 0.041；高斯给 **-2.924**，浅了 0.868；t 给 **-3.326**，浅了 0.466。

把 1200 个测试日按顺序累计违约次数：真分位数下应该是 11 次，Flow 命中 **10 次**，t **20 次**，高斯 **33 次**。高斯不是"差一点"，是把 1% 的尾部事件当成 2.75% 来报，资本金口径直接错近三倍。注意这次 Flow 的违约次数略少于期望，属于正常抽样波动；不能用一次 1200 天的计数去断言模型校准完美。

## 五、基底选择：训练似然几乎不说话

结点数从 4 增到 24，训练期平均对数似然从 -1.4847 一路微升到 -1.4733，看着"越多越好"；但测试期平均似然在 12 个结点处见顶（-1.4493），24 个结点跌到 -1.4528。差距只有千分之几，换算成 1200 天总似然就是 4 分左右——真金白银的过拟合，但只靠训练集日志根本看不见。

结点位置用训练分位数固定，是为了避免优化器把结点挤到同一处造成斜率爆炸；代价是尾部结点永远落在样本的 4% 和 96% 分位上。**基底决定了模型能看到多远**：训练样本里最极端的那一天，就是样条最后一段开始线性外推的起点。

## 六、外推翻车：线性 tails 不是厚尾的替代品

![结点敏感性与分布漂移压力测试](/images/normalizing-flow-return-density/fig4_basis_stress.png)

把测试数据整体做 $x\mapsto 2x-2$：两个混合分量的均值分别移到 -1.7 和 -5.6，标准差放大到 1.5 和 2.5。真密度给出总似然 **-2568.87**，Flow **-4080.64**，Student-t **-4054.27**，高斯 **-5483.78**。Flow 比 t 差 **26.37**，尽管它在原位分布上曾经领先 t 48 分。

原因不神秘：Flow 的左端斜率固定为训练期估出的 0.55，意味着尾部被当成标准差约 1.8 的正态；真正的压力分布标准差是 2.5，而且整条尾向右平移。t 分布虽然中心拟合更差，但它的多项式尾部对外推更宽容。**原位分布上的高似然不等于压力场景下的稳健性**，这两件事必须分开测。

要缓解这个问题，实务里可以：把端点斜率单独加惩罚或下界约束，用广义 Pareto 显式接尾；定期滚动重估结点位置；或者干脆把 Flow 只用在主体分布，尾部交给极值理论。别指望一个 3000 点训练出来的可逆函数自动知道未来会漂移多远。

还有一层不确定性容易被忽略：12 结点的优势对 -1739.13 与 -1739.47（8 结点）这种差距，只有 0.34 的总似然，落在参数估计噪声的量级。本文没有做 bootstrap 置信区间，所以正确的读法是"8~12 个结点处在同一个平台"，而不是"12 精确最优"。如果换成真实数据，应该先做滚动起点的重复拟合，再看测试似然的平台在哪里，而不是拿单次样本的最高点当结论。

## 七、边界

这里的真值是合成混合分布，不是真实收益；样本是独立同分布的，没有波动聚集、隔夜跳空与交易成本。端到端的深度 Flow（RealNVP、Neural Spline Flow）能学更复杂的多变量依赖，但参数量、训练不稳定性和可解释性成本也同步上升，本文刻意选了单变量样条把机制讲清楚。所有数值固定种子 `20261126`，四张英文标签计算图与 `results.json`（含各结点数的训练/测试似然、VaR 分位与压力测试明细）保存在 `public/images/normalizing-flow-return-density/`，可直接复现。
