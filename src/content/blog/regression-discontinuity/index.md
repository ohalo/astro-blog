## 一、结论先行

指数调仓是量化里最干净的自然实验之一。市值排名刚过纳入线的股票，会迎来被动基金的强制买入；排名差一名、差 0.1% 市值的股票，什么都不会发生。两者在其他方面几乎一模一样——这就是断点回归（Regression Discontinuity Design，RDD）梦寐以求的场景。

 tempting 的做法是：拿线上股票的平均收益减去线下股票的平均收益，差额就是纳入效应。**这是个陷阱。** 因为市值本身就和收益有平滑的正向关系——大公司收益略高，这条趋势在门槛两侧是连续的，却被朴素均值差一起算进了「政策效应」。

真值已知的实验说话最响。我设定真实纳入效应是 2.5%，4000 只股票，市值分数在门槛两侧均匀分布，收益里埋了 0.012×市值分数 的平滑趋势。结果：

- 朴素均值差报出 **5.30%**，把效应夸大了 112%——多出来的 2.80% 全是平滑趋势的贡献。
- 带宽 0.6 的局部线性 RDD 估出 **2.54%**，标准误 0.41%，95% 置信区间 [1.75%, 3.34%] 稳稳覆盖真值，z=6.27。

关键区别在于：RDD 只在门槛附近的窄窗口里做局部线性拟合，把「平滑趋势」当作两侧共同的背景函数拟掉，只留下门槛处那一个跳跃。

## 二、为什么局部线性比全局均值靠谱

把问题写成公式，收益 Y 对市值分数 R 的关系是：

```
Y = f(R) + τ·1[R ≥ 0] + ε
```

其中 f(R) 是平滑的背景趋势（本文是真值 0.010+0.012R+0.004R²），τ 是我们想要的因果效应，门槛设在 R=0。

朴素均值差算的是 `E[Y|R≥0] − E[Y|R<0]`，它不仅包含 τ，还包含 f 在两侧均值之差——只要 f 随 R 变化，这部分就不为零。RDD 的核心洞见是：**在门槛的一个极小邻域内，f(R) 可以用左右两条直线分别局部近似**。在 R→0 处，两条直线的截距差就是 τ，平滑趋势被斜率项吸收掉了。

这就是局部线性回归：左侧只用 `[−h, 0]` 的样本，右侧只用 `[0, h]` 的样本，各自用三角核 `w=1−|R|/h` 加权拟合 `Y ≈ a + bR`，取两侧截距之差。带宽 h 是唯一的调节旋钮——太大则邻域不「局部」、线性近似失效；太小则样本太少、噪声大。

```python
import numpy as np

def local_linear(R, Y, cutoff, h, side):
    if side == 'left':
        m = (R <= cutoff) & (R >= cutoff - h)
    else:
        m = (R >= cutoff) & (R <= cutoff + h)
    x = R[m] - cutoff; y = Y[m]
    w = 1 - np.abs(x)/h                      # 三角核
    X = np.column_stack([np.ones(len(x)), x])
    W = np.diag(w)
    A = X.T @ W @ X
    b = np.linalg.solve(A, X.T @ W @ y)
    resid = y - X@b
    s2 = (w*resid**2).sum()/max((w>0).sum()-2, 1)
    se0 = np.sqrt(s2 * np.linalg.inv(A)[0,0])
    return b[0], se0                         # 门槛处截距及其标准误

def rdd_estimate(R, Y, cutoff=0, h=0.6):
    l, se_l = local_linear(R, Y, cutoff, h, 'left')
    r, se_r = local_linear(R, Y, cutoff, h, 'right')
    return r - l, np.sqrt(se_l**2 + se_r**2)
```

## 三、带宽敏感性

带宽 h 是 RDD 里最需要小心交代的选择。本文把 h 从 0.2 扫到 1.8：估计值在 0.2 时是 2.78%、0.6 时 2.54%、1.0 时 2.37%、1.4 时 2.31%、1.8 时 2.33%——全程贴着 2.5% 的真值小幅波动，没有系统性漂移。这是因为本文的背景函数 f 足够平滑，线性近似在较宽窗口里依然成立。

真实数据里 f 可能弯曲得更厉害，此时大带宽会把曲率误当成跳跃。规范做法是报告一个最优带宽（如 Imbens-Kalyanam 的 MSE 最优带宽），再附上不同带宽下的稳健性表格，让读者自己判断结论对 h 是否敏感。只报一个 h 的结果、不交代敏感性，是 RDD 论文最常被诟病的毛病。

## 四、三套有效性检验

RDD 的结论成立依赖一个前提：除了门槛处的处理，其他一切在门槛两侧都连续。有三套标准检验来验证它。

**协变量连续性。** 找一些「处理前就该确定」的变量——比如纳入之前的收益率、波动率、杠杆。它们不受指数纳入影响，如果在门槛处也跳变，说明样本选择有问题。本文的预处理协变量在门槛附近的局部均值左 0.473、右 0.504，局部差只有 0.031，过关。有意思的是，若用全局均值比较，左 0.394、右 0.597、差 0.203 看着像「跳变」——那其实还是平滑趋势，再次印证了「必须局部」的道理。

**密度检验（McCrary test）。** 如果公司能操纵市值把自己塞进指数，门槛附近的样本密度就会出现异常堆积，RDD 的「局部随机化」假设就破了。干净样本里，门槛两侧的对数密度跳变只有 0.0006——几乎完美连续。我人为制造了一个操纵样本：把门槛下方 45% 的公司向上挪过线，密度跳变立刻变成 0.590，窄窗内线上 214 家、线下 110 家，二项检验 p=7.9e-9，操纵无所遁形。

**安慰剂断点。** 在根本没有政策变化的假门槛（如 R=−1.2、R=1.5）上重复估计，应该得到接近零的「效应」。18 个安慰剂断点的估计均值 0.0001、标准差 0.0056、最大绝对值 0.0111——全都远小于真实断点处的 2.54%。如果安慰剂也频繁给出显著结果，说明你捕捉的根本不是政策效应，而是数据里别的结构。

## 五、为什么不用「匹配」或「双重差分」

面对「纳入指数有没有超额收益」这种问题，很多人第一反应是配对：给每只新纳入股票找一只市值、行业相近但没纳入的股票，比较两者收益。问题在于，市值相近不等于「刚好在门槛两侧」——你配对的对照股可能市值差 20%，那 20% 的收益趋势差异会直接污染结论。RDD 的精妙之处在于把比较对象锁定在「市值只差零点几个百分点」的邻居上，这些公司在所有维度上都几乎不可区分，唯一的差别就是过没过线。这种局部可比性是任何全局匹配都难以复制的。

双重差分（DID）也在做类似的事，但它依赖「平行趋势」假设——处理组和对照组在没有政策时，收益要沿平行轨迹演化。指数纳入场景里，刚过线和刚没过线的公司完全满足这个假设（它们本就是同一分布的连续切片），所以 RDD 本质上是把一个「局部的 DID」做到了极致：时间维度上的前后比较，被压缩成了门槛两侧的横截面比较，反而不再需要观测多期数据，识别更干净。换句话说，当你有一个明确门槛时，RDD 比 DID 少一个假设、少一层估计误差。

当然，RDD 也不是万能的。它需要门槛附近有足够的样本密度——如果没人恰好卡在门槛附近，局部拟合就成了无米之炊。它也只识别门槛那一点附近的效应，想评估「纳入指数对超大市值公司的长期影响」就鞭长莫及。理解这些边界，才能选对工具。

## 六、落地时的几点提醒

第一，RDD 识别的是**门槛附近的局部平均处理效应**（LATE），不是全市场效应。刚过线的公司受到的冲击，未必能外推到市值远超门槛的公司——写结论时务必说清适用范围。

第二，分清 Sharp 和 Fuzzy。本文是 Sharp RDD：过线必然被纳入。现实里常有「过线也可能不纳入、没过线也可能被特批」的 Fuzzy 情形，此时要用断点处的处理概率跳跃做工具变量（IV），估计出的是局部平均因果效应（LATE 的严格版本）。

第三， Running variable 要选「不能被策略性操纵」的。市值、排名可能被粉饰，此时密度检验必须做；像气温、生日这类天然外生的断点则干净得多。指数纳入场景里，用「调整后市值」而非可被短期拉抬的收盘价市值，能显著降低操纵风险。

第四，标准误要用稳健方法。本文用局部 OLS 的解析标准误做演示；严谨研究建议配合 bias-corrected 的稳健置信区间，在小样本下覆盖更准。把这套流程用在指数调仓、ST 摘帽、涨跌停规则变化这类「有明确门槛」的事件上，能帮你把真正的政策效应从平滑趋势里干净地剥离出来。
