## 一、结论先行

如果 payoff 是 `max(S1_T, S2_T)` 或者 `(S1_T - S2_T)^+`，很多人第一反应是写蒙特卡洛。但在两只资产都服从几何布朗运动、相关性恒定的世界里，这两个 payoff **都有闭式解**，而且闭式解不只是"省算力"——它是检验路径模拟对不对的标尺。

我取 $S_1=100,\ S_2=96,\ r=4\%,\ q_1=1\%,\ q_2=2\%,\ \sigma_1=25\%,\ \sigma_2=20\%,\ \rho=0.45,\ T=1$，把四条路径摆在一起：

- **Margrabe 交换期权**闭式价 **11.8725**；4 万条路径朴素 MC 得 **11.9021**，标准误 0.0826，偏离只有 0.36 个标准误；
- 用 $e^{-rT}(S_{1,T}-S_{2,T})$ 这个**期望已知的线性价差**做控制变量，价格变成 **11.8942**，标准误压到 **0.0358**，改善 **2.31 倍**；对偶变量在这组参数下几乎没有改善（0.0822）；
- 带执行价的 **best-of 看涨** $( \max(S_1,S_2)-K )^+$，$K=100$ 时二元正态尾概率公式给 **14.2110**，MC 给 **14.1542**，标准误 0.0920，差 **-0.62 个标准误**；20 组 $(K,\rho)$ 对拍里最大偏差也只有 2.05 个标准误；
- 相关性是这类期权的命门：$\rho$ 从 -0.8 升到 0.8，价差波动率从 0.4272 压到 0.1500，交换期权从 **18.8975** 跌到 **8.5528**，best-of 看涨从 **17.6028** 跌到 **12.5192**；
- 但闭式解的前提是你**知道真 $\rho$**。用 60 天日收益估相关，4000 次重复里 $\hat\rho$ 均值 0.4490、标准差 0.1050、95% 区间 [0.2333, 0.6355]，代入后报价均值 11.8445 竟只比真值低 0.0280——可平均绝对误差有 **0.6515**，**21.9%** 的报价偏离超过 1 元。均值无偏不等于报价可用。

## 二、为什么交换期权能闭式定价

设两只资产在风险中性测度下满足

$$
\frac{dS_i}{S_i}=(r-q_i)\,dt+\sigma_i\,dW_i,\qquad d\langle W_1,W_2\rangle_t=\rho\,dt.
$$

定义 $F_i=S_i e^{(r-q_i)T}$，组合波动

$$
\sigma=\sqrt{\sigma_1^2+\sigma_2^2-2\rho\sigma_1\sigma_2},
$$

则 Margrabe 公式是

$$
V_0=e^{-q_1T}S_1N(d_1)-e^{-q_2T}S_2N(d_2),\quad
d_1=\frac{\ln(F_1/F_2)+\tfrac12\sigma^2T}{\sigma\sqrt T},\ d_2=d_1-\sigma\sqrt T.
$$

直觉是把 $S_2$ 当计价单位：换股权利的本质是用第二只股票买第一只股票，于是问题退化成单一 Black-Scholes 看涨，标的是比值 $S_1/S_2$，分红率差是 $q_2-q_1$。注意 $r$ 在 $F_1/F_2$ 里抵消——**交换期权对无风险利率几乎不敏感**，只对相对分红敏感，这和单资产看涨很不一样。

本文参数下 $\sigma=0.2398$，$d_1=\bigl[\ln(1/0.96\cdot e^{0.01})+0.5(0.0575)\bigr]/0.2398$，算出 11.8725。这就是后面所有对拍的"真值"。

```python
import numpy as np
from scipy.stats import norm

S1, S2 = 100.0, 96.0
r, q1, q2 = 0.04, 0.01, 0.02
s1, s2, rho, T = 0.25, 0.20, 0.45, 1.0

def margrabe(rho):
    sig = np.sqrt(s1**2 + s2**2 - 2*rho*s1*s2)
    ratio = (S1*np.exp(-q1*T)) / (S2*np.exp(-q2*T))
    d1 = (np.log(ratio) + 0.5*sig**2*T) / (sig*np.sqrt(T))
    return (S1*np.exp(-q1*T)*norm.cdf(d1)
            - S2*np.exp(-q2*T)*norm.cdf(d1 - sig*np.sqrt(T)))
```

顺带一个便宜的副产品：收 $\max(S_{1,T},S_{2,T})$ 的合约价值是

$$
\mathbb E[e^{-rT}\max(S_{1,T},S_{2,T})]=S_2e^{-q_2T}+\mathrm{Margrabe},
$$

本文即 $94.0990+11.8725=\mathbf{105.9715}$。不需要任何积分。

## 二之一、换股测度到底换了什么

Margrabe 公式的推导值得展开，因为它解释了为什么 $r$ 会消失。令 $R_t=S_{1,t}/S_{2,t}$。由伊藤引理，

$$
\frac{dR}{R}=(q_2-q_1)dt+\sigma\,dW^R,\qquad
d\langle W^R,W_1\rangle_t=\frac{\sigma_1-\rho\sigma_2}{\sigma}dt.
$$

于是交换期权的 payoff 可以写成 $S_{2,T}(R_T-1)^+$。取 $S_2e^{q_2t}$ 为计价单位做测度变换，$R$ 在新测度下的漂移变成 $+\sigma^2$ 而不是 0，折现因子 $e^{-rT}$ 与计价单位的增长 $e^{rT}$ 正好抵消，留下 $S_2e^{-q_2T}\mathbb E^{S_2}[(R_T-1)^+]$，这就是标准的单资产看涨形式。换句话说，**交换期权是一个用第二只股票计价的普通看涨**，无风险利率被计价单位吸收掉了，真正驱动价格的是相对分红 $q_2-q_1$ 和相对波动 $\sigma$。

这也给出一个实用的 sanity check：若 $q_1>q_2$ 且 $\sigma\to0$，高价分红资产的比值单调下跌，期权应趋近 0；若 $\rho\to1$ 且 $\sigma_1=\sigma_2$，两只资产完全同步，交换期权也应趋近 0。本文 $\sigma_1\ne\sigma_2$，所以即便 $\rho=0.8$ 仍有残差波动 0.1500 和 8.5528 的价格，没有违反直觉。

## 三、控制变量：一个容易写错的期望

蒙特卡洛估交换期权时，最自然的控制变量是**线性价差本身**：$C=e^{-rT}(S_{1,T}-S_{2,T})$。它的期望不是 Margrabe 价格，而是

$$
\mathbb E[C]=S_1e^{-q_1T}-S_2e^{-q_2T}=99.0050-94.0990=4.9060.
$$

我第一版把控制变量均值误写成 Margrabe 价格，结果修正项 $C-\mathbb E[C]$ 整体平移，估价虚高到 16.23，标准误看起来还更小——**一个漂亮但完全错误的答案**。这类 bug 不会抛异常，只能靠"控制变量修正后的估计必须仍在真值附近"这条检查抓住。

修正后：$\beta=\widehat{\mathrm{Cov}}(P,C)/\widehat{\mathrm{Var}}(C)=0.6221$，控制变量估计 11.8942，标准误 0.0358。对偶变量之所以无效（0.0822），是因为 payoff 只取正部，配对后 $P(z)+P(-z)$ 并不近似常数，方差削减机制失效。

## 三之一、数值实验的三道闸门

这类"闭式解对蒙特卡洛"的实验很容易自我欺骗，我设了三道闸门。第一道是**解析恒等式**：$E[e^{-rT}(S_{1,T}-S_{2,T})]$ 必须等于 $S_1e^{-q_1T}-S_2e^{-q_2T}$，与是否取正部无关；控制变量的均值就靠这道闸门核对。第二道是**路径生成的相关性回读**：每条路径用 $Z_2=\rho Z_1+\sqrt{1-\rho^2}Z_3$ 构造，模拟 4 万条后样本相关必须回到 0.45 附近，否则 payoff 的相关性敏感性整个失真。第三道是**标准化残差**：所有 MC 对照都报告 $z=(\hat V-V_{\text{closed}})/\mathrm{SE}$，20 组 $(K,\rho)$ 的 $|z|$ 最大 2.05、平均 0.65，说明误差是抽样噪声而不是系统性偏移；如果 $|z|$ 随 $K$ 单调变大，那就该怀疑二元正态尾概率的阈值平移写错了。

调试中确实出过一次这种错误：best-of 公式第一版只换到股票测度、却漏减执行价现值，结果从 14.21 跳到 75 元。它不会抛异常，也不会让图形难看，只有和 MC 对拍才会暴露。**闭式解的真正价值不是更快，而是给你一个能抓 bug 的锚点。**

## 四、带执行价的 best-of 看涨：两段测度 + 二元正态

$K>0$ 时简单的"第二只股票 + 交换期权"分解就失效了。用不相交事件拆分：

$$
(\max(S_1,S_2)-K)^+=(S_1-K)^+\mathbf 1_{S_1\ge S_2}+(S_2-K)^+\mathbf 1_{S_2>S_1}.
$$

对每个事件换到相应股票测度（numeraire 是 $S_i e^{q_i t}$），把 $S_i>K$ 与 $S_i>S_j$ 两个条件写成标准正态向量 $\mathbf U=(U_1,U_2)$ 的联合尾概率，再用 `scipy.stats.multivariate_normal.cdf` 计算。记

$$
a=\frac{\ln(S_1/S_2)+(q_2-q_1+\tfrac12(\sigma_2^2-\sigma_1^2))T}{\sigma\sqrt T},
$$

则第一项在 $S_1$ 测度下的概率是 $\Phi_2\bigl(d_{1,1},\,a+\delta_1;\,\mathrm{Corr}_1\bigr)$，其中 $\delta_1=\sigma_1(\sigma_1-\rho\sigma_2)\sqrt T/\sigma$；第二项对称，阈值为 $-a+\delta_2$。最后必须减去执行价的现值乘上原测度下两个行权区域的概率，漏掉这一步会得到 75 元这种荒谬报价——这正是我调试时踩过的坑。

```python
from scipy.stats import multivariate_normal
import numpy as np

def best_of_call(rho, K, S1=100., S2=96., r=.04, q1=.01, q2=.02,
                 s1=.25, s2=.20, T=1.):
    sig = np.sqrt(s1**2 + s2**2 - 2*rho*s1*s2)
    Sig = np.array([[1., rho], [rho, 1.]])
    d11 = (np.log(S1/K) + (r-q1 + .5*s1**2)*T) / (s1*np.sqrt(T))
    d12 = (np.log(S2/K) + (r-q2 + .5*s2**2)*T) / (s2*np.sqrt(T))
    a = (np.log(S1/S2) + (q2-q1 + .5*(s2**2-s1**2))*T) / (sig*np.sqrt(T))
    d1 = s1*(s1-rho*s2)*np.sqrt(T)/sig
    d2 = s2*(s2-rho*s1)*np.sqrt(T)/sig
    A = np.array([[1., 0.], [s1/sig, -s2/sig]])
    B = np.array([[0., 1.], [-s1/sig, s2/sig]])
    p1 = multivariate_normal.cdf([d11, a+d1], cov=A@Sig@A.T)
    p2 = multivariate_normal.cdf([d12, -a+d2], cov=B@Sig@B.T)
    q1p = multivariate_normal.cdf([d11-s1*np.sqrt(T), a],
                                  cov=[[1, (s1-rho*s2)/sig], [(s1-rho*s2)/sig, 1]])
    q2p = multivariate_normal.cdf([d12-s2*np.sqrt(T), -a],
                                  cov=[[1, (s2-rho*s1)/sig], [(s2-rho*s1)/sig, 1]])
    return (S1*np.exp(-q1*T)*p1 + S2*np.exp(-q2*T)*p2
            - K*np.exp(-r*T)*(q1p+q2p))
```

对拍结果：$K=100$ 时闭式 14.2110 / MC 14.1542；把 $K$ 取 80/90/100/110/120、$\rho$ 取 -0.6/0/0.45/0.8 共 20 组，最大 $|z|=2.05$，平均 $|z|=0.65$，没有系统性偏移。

## 五、相关性：从 -0.8 到 0.8 的单调性，以及估计误差的反噬

价差波动率 $\sigma$ 随 $\rho$ 线性平方地收缩：ρ=-0.8 时 0.4272，ρ=0.45 时 0.2398，ρ=0.8 时只剩 0.1500。交换期权价格随之从 18.8975 单调跌到 8.5528，best-of 看涨从 17.6028 跌到 12.5192——**两只股票越不同步，"拿到更好的那只"就越值钱**，这是彩虹期权最核心的直觉。

![相关性敏感性](/images/margrabe-rainbow-option/fig3_rho_sensitivity.png)

麻烦在于 $\rho$ 要估。我用 60 个日收益估计真相关 0.45，重复 4000 次：$\hat\rho$ 标准差 0.1050，95% 区间宽到 0.23~0.64。把端点代进 Margrabe，报价从 10.2918 到 13.4298，跨了 3.14 元。报价均值只比真值低 0.0280（因为 $\rho\mapsto V$ 在这段近似线性），但平均绝对误差 0.6515，5%~95% 误差区间 [-1.37, 1.33]，**21.9% 的报价错超 1 元**。用"估计无偏"为定价精度背书，是典型的统计直觉误用：交易关心的是误差分布，不是期望。

## 五之一、别把两个单资产看涨相加

一个常见错误是把 best-of 看涨近似成两只股票看涨之和。本文参数下单资产 BS 看涨分别是 **11.2356** 和 **6.6253**，相加 **17.8609**，比真正的 best-of 价格 14.2110 高出 **3.6499（25.7%）**。原因是两个 payoff 在"两只都涨过 K"的区域被重复计了一次，而那一区域的概率恰恰随 $\rho$ 上升而增大：$\rho=0.8$ 时两只齐涨更常见，重复计价更严重；$\rho=-0.6$ 时两腿几乎互斥，相加反而接近正确。**相关性越高，简单的分腿加总越危险**——这和分散化直觉正好相反，值得在结构化产品设计时单独提醒。

## 六、边界与复现

公式依赖恒定相关、常数波动率和连续可交易假设。现实里微笑会让 $\sigma$ 随执行价变化，这时候 closed form 只能当"平值附近的局部近似"；跳跃风险下 $\rho$ 的概念本身就模糊，共同跳跃和扩散相关是两件不同的事。另外本文的 best-of 看涨没有考虑两只股票分红税差与借券成本，实盘报价要另加。对液态股票而言这些修正通常只有几个基点，但一旦换成低流动性的商品或信用名字，借券与分红的不确定性足以吞掉模型相对蒙特卡洛省下的那点算力优势。
