买保险的人愿意付比预期赔付更高的保费，因为保险公司承担了风险、要赚一笔补偿。期权市场里也有同样的事情：期权的隐含波动率（买方付的价格）长期、系统性地高于标的后来真正走出来的实现波动率。这道缝隙有个正式名字——**方差风险溢价**（Variance Risk Premium, VRP），它是波动率卖方（通常是机构）为承担"未来波动不确定"这个风险所索取的报酬。

它是波动率交易最核心、也被实证研究支持得最扎实的异象之一。CBOE 的 VIX 指数本质上就是它的温度计——这个被称为"恐慌指数"的数字，之所以长期在 20 上下而非 13 附近徘徊，很大程度就是溢价在托底。

为什么卖方愿意接受一个平均亏钱的价格？因为他们的效用函数不是线性的。对管理着巨额组合的机构而言，市场暴跌的那几天恰恰是其他资产一起亏损、保证金追缴最凶的时刻，波动率对冲的 pays off 价值连城。他们买的不是统计意义上的便宜货，而是一份在市场最缺钱时能兑现的保险。这份保险的精算溢价，就沉淀在隐含波动与实现波动的差里。理解这一点，你才会明白 VRP 为什么能长期存在而不被套利者抹平——它不是免费的午餐，而是用极端状态下的流动性换来的。

本文不在真实数据上讲故事（那样你永远不知道溢价"真值"是多少），而是反过来：用蒙特卡洛生成一段价格路径，人为埋进一个已知的溢价，然后把它挖出来，看看估计、显著性与交易策略各自会遇到什么坑。这种"已知真值再反解"的做法，是检验一个统计方法是否可靠最干净的方式。

## 一、把溢价定义清楚：两个测度，两个方差

VRP 的严格定义要区分两个概率测度：

- **风险中性测度 Q 下的隐含方差** E^Q[RV]：市场用期权价格"投票"出来的未来方差，包含了风险补偿，所以偏高。
- **真实测度 P 下的实现方差** E^P[RV]：标的真正走出来的收益平方和，不含补偿。

```
VRP = E^Q[RV] - E^P[RV]  > 0  (长期平均)
```

在本文的模拟里，我把这个差值设成真值：用 GARCH(1,1) 生成带有波动聚集和肥尾的日收益（这模拟真实 P 测度），然后把隐含波动率设成条件波动的 √1.30 倍——也就是隐含方差比真实条件方差高 30%，这个 30% 就是我埋进去的"溢价真值"。

```python
import numpy as np

rng = np.random.default_rng(2026)
n, omega, alpha, beta, nu = 6000, 5e-6, 0.08, 0.90, 5
z = rng.standard_t(nu, n)                 # 肥尾冲击
z = z / np.sqrt(nu / (nu - 2))            # 标准化到单位方差
sig2 = np.empty(n); r = np.empty(n)
sig2[0] = omega / (1 - alpha - beta)
r[0] = np.sqrt(sig2[0]) * z[0]
for t in range(1, n):
    sig2[t] = omega + alpha * r[t-1]**2 + beta * sig2[t-1]  # GARCH 波动聚集
    r[t] = np.sqrt(sig2[t]) * z[t]
r[3600:3605] = [-0.031, -0.044, -0.028, -0.052, -0.035]  # 人为注入崩盘周

ANN = 252
iv = np.sqrt(1.30 * sig2 * ANN)      # 隐含波动：埋入 30% 方差溢价
h = 21                                # 未来一个月
rv = np.sqrt(np.mean(r[t+1:t+1+h]**2) * ANN)  # 每个窗口的实现波动
vrp = iv - rv                         # 波动率点口径的溢价
```

注意我用标准差 t 分布而非正态——真实收益的肥尾是 VRP 存在的重要土壤，用正态会低估极端波动，把溢价算得过于温和。

## 二、挖出溢价：平均 4.13 个百分点，76% 的时间为正

跑完 5979 个重叠的 21 日窗口，结果和埋进去的真值对得上：年化隐含波动均值 **26.64%**，年化实现波动均值 **22.45%**，中间这道缝隙——VRP 的波动率点均值——是 **4.134 个百分点**，中位数 4.626，并且有 **75.98%** 的窗口里隐含波动确实高于实现波动。

![隐含波动率与实现波动率的时间序列](/images/variance-risk-premium-extraction/vrp-iv-vs-rv.png)

图上红线（隐含）几乎全程压在蓝线（实现）之上，两者之间的粉色带就是卖方赚到的补偿。只有少数时候蓝线反超——那通常发生在市场刚刚经历剧烈波动、实现波动短期冲高的时候，也是波动率卖方最难熬的时刻。

这个 4 个百分点的数量级不是我编的：大量实证文献在标普 500 上测得的 VRP 长期均值就在年化 3 到 5 个波动率点之间，和本文模拟设定同一量级。

## 三、第一个大坑：重叠窗口把 t 值吹大 3.6 倍

看起来证据确凿——均值 4.13、76% 的时间为正。但如果你直接算个 t 检验就宣布发现，会犯一个经典错误：21 日实现波动的窗口是**重叠**的，相邻两个窗口共享 20 天数据，样本之间高度自相关。普通标准误公式假设样本独立，会把有效样本量当成 5979，严重高估显著性。

我用 Newey-West 的 HAC（异方差自相关一致）标准误修正，滞后阶数取 20（对应重叠阶数）：

```python
def newey_west_se(x, lags):
    x = x[~np.isnan(x)]
    e = x - x.mean()
    m = len(e)
    se2 = np.dot(e, e) / m
    for l in range(1, lags + 1):
        w = 1 - l / (lags + 1)
        gamma = np.dot(e[l:], e[:-l]) / m
        se2 += 2 * w * gamma
    return np.sqrt(max(se2, 0) / m)
```

结果触目惊心：朴素标准误 0.1337，HAC 标准误 **0.4784**，放大 **3.58 倍**。相应的 t 值从虚高的 **30.92** 掉到 **8.64**。结论方向没变（依然显著为正），但"显著性"被砍掉了三分之二。任何拿重叠窗口数据、却不校正自相关的 VRP 研究，都在系统性夸大自己的发现——这是学术圈反复强调、实务里却常被忽略的一课。

## 四、第二个大坑：正期望的左尾，藏着爆仓

VRP 是"捡钢镚在压路机前"的典型。分布一算就明白：

![方差风险溢价的分布](/images/variance-risk-premium-extraction/vrp-distribution.png)

VRP 的偏度是 **−2.618**、超额峰度高达 **31.246**——远比正态肥的左尾。5% 分位达到 −9.326 个百分点，意思是大约二十分之一的月份里，实现波动会比隐含波动高出 9 个点以上。方差点口径的均值是 0.0185。正的均值、厚得吓人的左尾，这正是波动率卖家的收益画像：**大部分月份小赚，偶尔一个月亏掉几个月的利润**。

我在样本中段人为注入的那个崩盘周（连续五天 −3% 到 −5% 的暴跌）就制造了这样一根长左尾。真实市场里，2018 年 2 月的"Volmageddon"、2020 年 3 月的新冠崩盘，都是这个尾部形态的现实演绎——卖 VRP 的基金在那几天成片爆仓。

## 五、把溢价变成策略：年化 13.52%，回撤 22.33%

怎么把这个溢价变成可交易的收益？最直接的模型是做空波动：在每个月初按当时的隐含波动卖出一个月期波动（相当于卖一份方差互换），月末按实现波动结算。用固定杠杆把赚到的波动率价差折成月收益：

```python
leverage = 3.0
logrets = []
for t in range(0, n - h, h):              # 不重叠的月度窗口
    iv0 = np.sqrt(1.30 * sig2[t] * ANN)            # 月初隐含波动
    rv0 = np.sqrt(np.mean(r[t+1:t+1+h]**2) * ANN)  # 当月实现波动
    logrets.append(leverage * (iv0 - rv0) / 12.0)  # 收集价差
equity = np.exp(np.cumsum(logrets))       # 用对数收益保证净值恒正
```

这里有两个刻意的设计：一是用**不重叠**的月度窗口，避免第三节的重叠自相关污染净值；二是用对数收益累乘而非简单收益相加，保证净值为正、回撤定义清晰。杠杆只作用在波动率点上（而非方差除以波动这种会在低波动期爆炸的形式），这样净值行为可控、可解释。

![做空方差风险溢价策略的净值与回撤](/images/variance-risk-premium-extraction/vrp-short-vol-equity.png)

285 个不重叠月份的结果：年化收益 **13.52%**，月度胜率 **74.39%**，最大回撤 **−22.33%**（恰好发生在注入的崩盘月，单月 −22.32%）。这是一份诚实的风险收益画像——三分之二的年份里它稳稳跑赢，但你需要能扛住某个月两位数的净值回撤而不被强平。**活得久比赚得快更重要**，这句话在卖波动的生意里是字面意义上的生存法则。

## 小结

VRP 是市场为"未来波动的不确定"支付的保险费，长期稳定为正。本文在埋有真值的模拟数据上挖出 4.134 个百分点的均值，验证了它的存在；同时揭示了两个必须敬畏的坑：重叠窗口能把 t 值从 8.64 虚吹到 30.92，正期望的左尾能让一个年化 13.52% 的策略在某个月回撤 22.33%。理解 VRP 不只是学一个统计异象，更是理解一件事——**所有的风险补偿，都是用尾部风险换来的**。

**关键数值一览**：年化 IV 26.64% vs RV 22.45%；VRP 均值 4.134 个百分点、正值占比 75.98%；HAC 标准误放大 3.58 倍、t 值 30.92→8.64；偏度 −2.618、超额峰度 31.246；做空波动策略年化 13.52%、胜率 74.39%、最大回撤 −22.33%。
