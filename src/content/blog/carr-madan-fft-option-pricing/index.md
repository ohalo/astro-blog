## 一、结论先行

给期权定价，最直觉的做法是对每个执行价做一次积分或跑一次模拟。但要画一条完整的波动率微笑，你需要几十个执行价——蒙特卡洛要重跑几十次，数值积分要调用几十次求积程序，而卡尔·马丹（Carr-Madan）方法只要**一次快速傅里叶变换**，就把整条行权价轴上的价格一起算出来。

代价是公式看起来吓人：特征函数、阻尼因子、复平面上的平移。但拆开之后每一步都很朴素——把支付函数乘上一个衰减因子让它可积，做傅里叶变换，用特征函数把期望值写进频域，最后逆变换回来的同时除掉衰减因子。

本文用两个真值已知的模型把这套 machinery 钉死：

1. Black-Scholes 上，FFT 价格与解析公式最大误差 **1.43e-10**，由 FFT 反推的隐含波动率均值 **0.200000**（真值 20%）。这证明变换与离散化本身是对的。
2. Heston 随机波动率上，FFT 与独立自适应数值积分的最大价差 **5.86e-10**；与 12 万条全截断欧拉路径的对拍，隐含波动率最大差 **0.00194**（约 0.19 个波动率点）。平值看涨价 8.252849，执行价 70 的隐波 26.05%、执行价 130 的隐波 14.03%，负偏斜如期出现。
3. 阻尼参数 α 不是随便填的：α=0.05 时价格 12.724479（真值 8.252849），α=0.10 时 8.438081，α≥0.3 到 20 都稳定在 8.252849，α=25 则矩爆炸给出 **-39.79** 的荒谬负价。两端都会翻车。
4. 一个真实的工程坑：对数行权价网格步长 0.001917，直接取离 `ln K` 最近的网格点，价格会错到 0.03、相对误差 0.9%；用三次样条按 `ln K` 插值后误差降到 1e-10 量级。**这是实现 bug，不是方法误差**。

## 二、从支付函数到可计算的积分

设 `X_T = ln S_T`，执行价的对数 `k = ln K`。看涨价 `C(k) = e^{-rT} E[(e^{X_T} - e^k)^+]`。直接对 `k` 做傅里叶变换不收敛——`k → -∞` 时看涨价趋于 `S_0 e^{-qT}`，是常数。乘上阻尼因子 `e^{αk}`（`α > 0`）后，两端都衰减：

`f(k) = e^{αk} C(k)`

把期望与积分交换，对 `k` 积分的内层是初等积分，结果是

`F(u) = ∫ e^{iuk} f(k) dk = e^{-rT} · φ(u - i(α+1)) / [(α+iu)(α+1+iu)]`

其中 `φ(z) = E[e^{izX_T}]` 是风险中性测度下的特征函数。分母展开就是 `(α²+α-u²) + i(2α+1)u`。逆变换给出

`C(k) = e^{-αk} · (e^{-rT}/π) · ∫_0^∞ Re[ e^{-iuk} φ(u-i(α+1)) / ((α+iu)(α+1+iu)) ] du`

注意 `φ` 的自变量是**复数**：`u - i(α+1)`。这就是很多人实现失败的地方——你传进去的必须是复数参数，特征函数里的平方根分支、指数项都要按复数算。

离散化时用 `u_j = j·η`，`k_j = -b + j·Δk`，其中 `Δk = 2π/(Nη)`、`b = π/η`。把 `exp(i·b·u_j)` 的相位因子预先乘到被积函数上，逆变换就正好是 `numpy.fft.fft`。本文取 `N = 2^15`、`η = 0.1`，于是 `Δk = 0.001917`、`u_max = 3276.8`。梯形的首点权重取 0.5，其余取 1。

## 三、Heston 特征函数与验证策略

风险中性下的 Heston 模型写成 `dS = (r-q)S dt + √v S dW₁`，`dv = κ(θ-v)dt + σ√v dW₂`，`corr(W₁,W₂) = ρ`。取 `S_0=100`、`r=3%`、`q=1%`、`v_0=0.04`、`κ=2`、`θ=0.04`、`σ=0.5`、`ρ=-0.7`、`T=1`。特征函数用标准的 `C + D·v_0` 形式，其中

`d = √[(κ-ρσiz)² + σ²(z²+iz)]`，`g = (κ-ρσiz-d)/(κ-ρσiz+d)`

验证分三层，每层只负责证伪一件事：

- **第一层（变换 machinery）**：把 Heston 的特征函数换成 Black-Scholes 的解析特征函数，看 FFT 是否复现 BS 公式。结果最大误差 1.43e-10，隐波均值 0.200000——变换、相位因子、梯形权重全对。
- **第二层（FFT 离散化）**：同一个 Heston 特征函数，一个走 FFT，一个走 `scipy.integrate.quad` 逐执行价积分。最大价差 5.86e-10——网格分辨率与截断都够。
- **第三层（特征函数本身）**：12 万条路径、240 步全截断欧拉、对偶变量，独立模拟 `S_T`。FFT 与 MC 的价格最大差 0.022，隐波最大差 0.00194。这个量级就是采样噪声，不是模型错误。

![图2：Heston 隐含波动率微笑的三法对照](/images/carr-madan-fft-option-pricing/fig2_heston_smile.png)

为什么要三层而不是一层？因为一个错了的特征函数配上错了的 FFT 实现，有可能在某一层上"看起来对"。BS 层排除变换 bug，求积层排除离散 bug，MC 层排除模型公式（比如平方根分支、漂移符号）的 bug。

这里"独立"二字很关键。求积层虽然复用了同一个特征函数，却完全绕开 FFT：它直接在实数轴上对 `Re[e^{-iuk}ψ(u)]` 做自适应求积，所以能抓到网格间距、相位因子、截断位置这三类离散错误。而 MC 层连特征函数都不用，它只认随机微分方程——所以哪怕特征函数里的平方根分支选反了，前两层也发现不了，第三层一定会露馅。三层各自只承担一种证伪责任，比堆一个"看起来很全"的测试有用得多。

把 `N` 和 `η` 的选择说透：`η` 决定频域分辨率，`N·η` 决定积分截断上限；`Δk = 2π/(Nη)` 则同时受两者牵制。想让执行价网格更密，就得加大 `N` 或加大 `η`；但加大 `η` 会让高频段采样变粗。本文用 `N=32768`、`η=0.1`，频域上限 3276.8、行权价步距 0.0019，对一年期、20% 波动率足够。长到期或高波动率下变换衰减更慢，就得同步抬高 `N·η`，否则尾部积分被截掉的部分会变成价格上的系统偏差。

## 四、阻尼参数 α 的两头陷阱

α 控制 `e^{αk}` 的衰减速度。太小，高频尾部衰减不够，`u_max` 截断留下大误差；太大，`φ(u-i(α+1))` 要算更高阶矩，Heston 在有限期限内矩会爆炸。

实测平值执行价 100 的价格随 α 变化：

| α | 价格 | 与参考值 8.252849 的差 |
|---|------|----------------------|
| 0.05 | 12.724479 | +4.47 |
| 0.10 | 8.438081 | +0.185 |
| 0.15 | 8.260839 | +0.0080 |
| 0.20 | 8.253194 | +3.5e-4 |
| 0.30 | 8.252850 | +6.4e-7 |
| 0.5 – 20 | 8.252849 | < 1e-9 |
| 25 | -39.793144 | 矩爆炸，价格变负 |

安全区相当宽：0.3 到 20 都能给出正确价格，所以实践里取 α=1 或 1.5 就够了。但如果你做的是**长到期**、**高波动率**的 Heston，矩爆炸阈值会显著下降，必须实际扫一遍 α 看价格是否稳定——不能把一个参数从短期限照搬到十年期。

另一个细节：`α=0.05` 时的巨型误差来自 `e^{-αk}` 在很负的 `k` 上放大了尾部积分噪声。如果你的 FFT 网格覆盖 `k` 从 -31 到 +31，那 `exp(-0.05×(-31))` 就已经是 4.8 倍，截断误差被同步放大。实践里只保留你真正关心的执行价区间再做逆阻尼，别对整条 `k` 轴无脑计算。

## 五、无套利检查，以及一个真实的 bug

价格算出来之后要检查它是不是"像期权价格"。两个便宜的检验：

**蝶式组合非负**：等价格间距下 `C(K-h) - 2C(K) + C(K+h) ≥ 0` 是密度非负的离散版本。在 60 到 150 的执行价上取步长 1，88 个蝶式值全部为正，最小 0.000402。这里有个坑：如果你在**对数**价格上取等间距，条件不成立，会出现 33 个"负值"——那是检验写错了，不是价格错了。

**看跌看涨平价**：蒙特卡洛路径上逐条都有 `C - P = e^{-rT}(S_T - K)`，所以抽样误差直接体现在 `E[S_T]` 上。9 个执行价的平价残差最大 0.0192，与价格 8 到 32 的量级相比是合理的采样噪声。

最值得记录的 bug 是网格对齐。FFT 给的是 `k_j = -b + jΔk` 上的价格，`ln K` 几乎从不落在网格点上。初版用 `argmin(|kgrid - ln K|)` 取最近点，Black-Scholes 上价格最大误差 0.0413、相对误差 0.92%，隐含波动率均值 0.19916——看起来"差不多"，但足以让微笑曲线出现锯齿。原因很简单：最近的 `k` 可以差 `Δk/2=0.00096`，对应执行价差约 0.096 元，期权价格自然差几分钱。改成对 `ln K` 做三次样条插值后，误差立刻掉到 1e-10。**先插值，再逆阻尼。**

## 六、完整代码

核心实现，纯 numpy + scipy：

```python
import numpy as np
from scipy.interpolate import CubicSpline

S0, r, q = 100.0, 0.03, 0.01
v0, kappa, theta, sigma, rho = 0.04, 2.0, 0.04, 0.5, -0.7
T, N, ETA, ALPHA = 1.0, 2**15, 0.1, 1.0
DK, B = 2*np.pi/(N*ETA), np.pi/ETA

def heston_cf(z):
    z = np.asarray(z, dtype=complex)
    a = kappa - rho*sigma*1j*z
    d = np.sqrt(a**2 + sigma**2*(z**2 + 1j*z))
    g = (a - d)/(a + d)
    C = (kappa*theta/sigma**2)*(
        (a-d)*T - 2*np.log((1-g*np.exp(-d*T))/(1-g)))
    D = ((a-d)/sigma**2)*(1-np.exp(-d*T))/(1-g*np.exp(-d*T))
    return np.exp(1j*z*(np.log(S0)+(r-q)*T) + C + D*v0)

def call_prices(alpha=ALPHA):
    u = np.arange(N)*ETA
    w = np.ones(N); w[0] = 0.5
    z = u - 1j*(alpha+1)
    psi = heston_cf(z)/(alpha**2+alpha-u**2+1j*(2*alpha+1)*u)
    c = np.fft.fft(np.exp(1j*B*u)*psi*w).real*np.exp(-r*T)*ETA/np.pi
    k = -B + np.arange(N)*DK
    sel = (k >= 2.0) & (k <= 7.0)   # 只保留关心的执行价带
    k, c = k[sel], c[sel]
    return lambda K: CubicSpline(k, c)(np.log(K))*np.exp(-alpha*np.log(K))

price = call_prices()
print(price(100.0))   # 8.2528489825
```

把 `heston_cf` 换成 BS 的特征函数 `exp(1j*z*(ln S0+(r-q-0.5s²)T) - 0.5s²z²T)`，同样的 `call_prices` 就能复现 BS 解析价——这是最快的实现自检。

## 七、什么时候值得用

需要整条执行价或期限轴上的价格时（校准隐含波动率曲面、算方差互换、构造蝶式组合），一次 FFT 的效率优势是压倒性的。只需要两三个执行价时，直接用求积公式更简单，不必处理网格对齐和阻尼区间。

方法本身的边界也要说清楚：它依赖特征函数存在且可解析写出，Heston、VG、CIR、仿射跳跃扩散都满足；但 locals volatility 或者纯粹的随机波动率数值模型通常没有现成特征函数。另外逆变换给的是风险中性价格，它不告诉你对冲误差——Vega、Vanna 这些 Greeks 要么再推一个变换，要么乖乖用有限差分。

从价格到隐波还要再做一步数值反解。本文对每个执行价用 Brent 法在波动率 1% 到 150% 上求根，把 BS 价格匹配到 FFT 价格，容差 1e-12。这一步看着机械，却决定了你画出来的微笑是不是光滑：如果前一步的价格误差在 1e-3 量级，隐波上就会出现肉眼可见的毛刺。换句话说，FFT 的 1e-10 精度不是炫技，而是给后续反解留足余量。

最后，这套代码是定价引擎，不是交易系统。实盘报价里还要处理股息离散化、美式行权、买卖价差与模型风险，这些都不会因为 FFT 快就自动消失。校准时还要注意参数可辨识性：`κ`、`θ`、`σ`、`ρ` 四个参数在只给一条执行价切面的价格时经常互相补偿，换一组初值就可能收敛到完全不同的参数却给出相近的价格。这时候真正该做的是加期限维度、看参数在多次校准中的稳定性，而不是把 FFT 的精度再提高几位。
