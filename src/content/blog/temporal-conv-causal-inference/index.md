预测和因果推断问的是两个不同的问题。预测问「Y 明天是多少」——只要相关，什么特征都能用。因果推断问「X 这个月动了 1 个单位，Y 在接下来的第 0 天、第 1 天、第 5 天各动多少」——你要的是**滞后核**（distributed lag kernel），一条从冲击日延伸到未来的权重曲线。利率决议、财报公告、供应链冲击，关心的都是这条曲线。

计量经济学的标准答案是 Almon 多项式滞后模型和岭回归：把 Y 对 X 的 32 个滞后值回归，系数就是核。问题是，当核有**结构**——比如不是平滑的单峰，而是「主峰 + 远处一个孤立的长尾」——多项式平滑假设会把结构抹掉。深度学习的时序卷积网络（TCN）给出第三条路：把训练好的网络对输入的脉冲响应（IRF）当作核的估计。本文用 numpy 从零实现整条链路，在三个递进的实验里检验它到底能不能干因果推断的活。结论先放这：**线性世界里 TCN-IRF 赢不了岭回归；它的比较优势在状态依赖核；而无论哪条路，「推断」（标准误和置信区间）都比「点估计」难一个数量级。**

## 一、合成市场：滞后核是主角，不是预测精度

数据生成过程刻意简单——一条 AR(1) 驱动过程，一个已知形状的滞后核：

- X：AR(1)，ρ=0.5，标准化；
- 真实核 w：主峰 `3·(k/4)·exp(-k/4)`（lag 4 见顶，lag 12 后截断），加上 lag 20-28 一个孤立的高斯长尾（峰值 0.35），整体乘 0.15 使信号标准差约 0.44；
- Y = Σ w_k·X(t−k) + ε，ε 标准差 0.25。

输入窗口 48 天，TCN 感受野 43 步，完整覆盖核的支撑。三层因果膨胀卷积（d = 1/4/16，kernel 3，8 通道）+ ReLU + 1×1 卷积头读最后一个时间步，Adam（lr=3e-3）训 80 个 epoch——全部参数约 1650 个，8000 个训练窗口。这就是全部家当：

![DGP：驱动过程、真实滞后核与响应序列](/images/temporal-conv-causal-inference/lag_kernel_dgp.png)

「核」而不是「预测 R²」是本文的主角，所以所有比较都围绕**核恢复质量**（与真值的相关、RMSE）展开，预测 R² 只作陪衬。顺便说清楚为什么脉冲响应有资格被叫作「因果」量：在 X 外生的世界里，Y 对孤立脉冲的响应曲线就是结构参数的直接读出——把 X 的历史全部置零、只在 lag 处置一单位冲击，读到的 Y 变化剔除了其他滞后的串扰。岭回归的系数当然也是同一件事的估计，区别只在于「网络黑箱里的响应」对非线性交互是开放的，而系数表格是封闭的。这也决定了后文的叙事：不是谁取代谁，而是什么结构下谁更好用。

## 二、E1 线性核恢复：无聊的方法赢了

第一个实验没有任何花样：线性 DGP、独立同分布噪声。四种方法恢复同一条核：

| 方法 | 核 corr | 核 RMSE | 样本外 R² |
|---|---|---|---|
| Oracle support Ridge | 0.999 | 0.002 | 0.902 |
| Ridge 原始滞后（α=3.0，验证集选） | **0.998** | **0.002** | **0.902** |
| Almon 多项式滞后（3 次） | 0.762 | 0.022 | 0.755 |
| TCN-IRF | 0.747 | 0.032 | 0.830 |

结果有点伤深度学习的自尊：**8000 个样本、32 个滞后，岭回归几乎完美恢复核**（0.998），甚至不需要事先知道滞后支撑（Oracle 版 0.999，只多 0.001）。偏差-方差的语言说得很清楚：线性 DGP 下岭回归的偏差只有正则那一项（α=3.0 对 32 个滞后、8000 个样本几乎无害），方差被 L2 压住；TCN 的偏差同样趋零，但 ReLU 网络的 IRF 是「在零输入附近做有限差分」，激活 pattern 随脉冲位置跳变，方差天然大一截。训练曲线也印证了这点：测试 MSE 从 0.109 降到 0.105 就基本平了——噪声地板（ε²=0.0625）之上可学的东西有限，网络很快进入「背噪声」区间。TCN-IRF 把峰放对了地方（lag 4），长尾甚至略微超调（0.066 vs 真值 0.0525），但 lag 5-12 之间抖得厉害——形状对、精度差。最惨的是 Almon：它的多项式平滑假设把 lag 4 的峰挪到了 lag 2，并把 lag 20-28 的长尾压扁了 4 倍（0.0127 vs 0.0525）。**当核的形状假设是错的时候，平滑不是美德是失明。**

## 三、E2 状态依赖核：线性模型的死穴

第二个实验给 DGP 加一项非线性交互：`Y += γ·s(t−1)·X(t−8)`，其中 s 是波动状态（过去 20 日 |X| 滚动均值的中位数二值化，±1），γ=0.35。于是 lag-8 的系数不再是一个数：高波状态 +0.47，低波状态 −0.23——**同一个滞后，系数翻号**。注意输入里没有显式给出 s，网络必须从 48 天的 X 窗口里自己推断「最近波动大不大」——这件事滑动窗口里确实看得见。

- 线性 Ridge 只能输出**一个**核：合并估计 lag-8 系数 0.189，跟两个状态的真值都对不上；与低波状态真值的相关从高波的 0.853 掉到 0.480。
- TCN-IRF 分状态计算（把状态通道分别置 ±1 后打脉冲）：高波 0.672（真值 0.472）、低波 −0.182（真值 −0.228），相关 0.906 / 0.811；测试 R² 0.869 vs 线性的 0.807。

这就是 TCN 做因果推断的真正卖点：**核可以是状态的函数**。「降息在低波环境里 8 个月后见效、在高波环境里反而反号」这类问题，线性框架连表述的语法都没有。代价是估计方差更大——分状态 IRF 的峰比线性版更抖，这是维度换来的。

## 四、E3 AR(1) 噪声：点估计稳健，推断翻车

第三个实验把噪声换成 AR(1)（ρ=0.7），动的是「推断」而不是「估计」。三个发现：

1. **Almon 的点估计几乎没退化**：corr 0.765，与独立同分布噪声下的 0.762 持平。教科书里「自相关扰动毁掉分布式滞后估计」的故事，前提是回归量里有滞后因变量；X 外生时 OLS 依然一致。
2. **但朴素标准误全面失效**：四个多项式系数全部「极其显著」，max|t| = 49.2；换 Newey-West（HAC，截断 8 期）后 max|t| 降到 23.3——**朴素 SE 低估约 2.1 倍**。p 值从 1e-300 变成 1e-100，都是「显著」，但置信区间的宽度差了整整一半。
3. **TCN 的 block bootstrap 同样翻车**：6 个重抽样本（块长 40）重训网络，90% 置信区间对真核的覆盖率只有 **0.56**。原因不难想：滑动窗口彼此共享 47/48 的数据，bootstrap 重抽是伪重复——有效样本量远小于名义上的 8000，区间自然偏窄。

![状态依赖核与 AR 噪声下的推断](/images/temporal-conv-causal-inference/nonlinear_and_inference.png)

诚实的排序：**点估计上，外生 X + AR 噪声不难，OLS 一致；推断上，两类方法都没有开箱即用的答案**——经典路线要上 HAC，神经网络路线要先把重叠窗的相关性结构修掉（非重叠块、子采样、或按时间分层）。这里值得多说一句实践含义：如果只用 IRF 做点估计和形状判断（「冲击大概 4 天见顶、20 天后还有一波长尾」），E1-E2 的数字完全够用；一旦要拿核做假设检验（「lag-8 的系数在两个状态下真的反号吗」），就必须面对区间覆盖率的问题——而本文的 0.56 说明，直接把时间序列 bootstrap 套在重叠窗口上是不行的。

## 五、核心代码：六十行实现 TCN 与 IRF

因果膨胀卷积是整个建筑的地基——左填充 `(k−1)·d` 个零保证任何位置都看不到未来：

```python
import numpy as np

def causal_conv(X, W, b, dilation):
    """X:(B,Cin,T) W:(Co,Cin,k) b:(Co,) 左填充因果膨胀卷积"""
    B, Cin, T = X.shape
    Co, _, k = W.shape
    pad = (k - 1) * dilation
    Xp = np.zeros((B, Cin, T + pad))
    Xp[:, :, pad:] = X                      # 只在左侧补零 → 严格因果
    out = np.zeros((B, Co, T))
    for j in range(k):                      # 核的第 j 个抽头
        sl = Xp[:, :, pad - j * dilation: pad - j * dilation + T]
        out += np.einsum("bct,oc->bot", sl, W[:, :, j])
    return out + b[None, :, None]

class TinyTCN:
    """三层因果膨胀卷积(d=1/4/16)+ReLU+1x1头读末位"""
    def __init__(self, rng, C=8):
        self.dils = [1, 4, 16]
        self.W1 = rng.normal(0, .5, (C, 1, 3));  self.b1 = np.zeros(C)
        self.W2 = rng.normal(0, .5/np.sqrt(C), (C, C, 3)); self.b2 = np.zeros(C)
        self.W3 = rng.normal(0, .5/np.sqrt(C), (C, C, 3)); self.b3 = np.zeros(C)
        self.Wh = rng.normal(0, .5/np.sqrt(C), (1, C, 1)); self.bh = np.zeros(1)
```

训练就是标准的小批量 Adam（对 MSE 求导，反向传播用链式法则穿过三层卷积），这里不占篇幅。**因果推断发生的地方是 IRF 提取**——把零输入窗口的预测当基线，在 lag 位置放一个 1 标准分的脉冲，读预测差：

```python
def tcn_irf(net, L, lag_list):
    """脉冲响应：在窗口的第 L-1-lag 位（即 t-lag）置 1，读预测变化"""
    X0 = np.zeros((1, 1, L))
    f0 = net.forward(X0)[0]
    irf = np.zeros(len(lag_list))
    for i, lag in enumerate(lag_list):
        Xi = X0.copy()
        Xi[0, 0, L - 1 - lag] = 1.0
        irf[i] = net.forward(Xi)[0] - f0
    return irf
```

对照的 Almon 多项式滞后更短——把 32 个原始滞后用三次多项式参数化，岭回归则直接在原始滞后上加 L2：

```python
P = np.vander(np.arange(32), 4, increasing=True)   # (32,4) 滞后→多项式基
Za = Z @ P                                          # Z:(n,32) 原始滞后设计阵
beta, *_ = np.linalg.lstsq(Za, ya, rcond=None)      # Almon：4 个系数
w_almon = P @ beta                                  # 展开回 32 个滞后权重
b_ridge = np.linalg.solve(Z.T @ Z + 3.0 * np.eye(32), Z.T @ y)  # Ridge
```

## 六、诚实结论

- **线性 DLM 里，TCN-IRF 是个高方差估计量**：形状全对（峰在 lag 4、长尾在 20-28）、精度输给岭回归整整一个数量级（RMSE 0.032 vs 0.002）。8000 样本的线性问题，请用线性方法。
- **TCN 的比较优势是状态依赖核**：核可以随环境翻号，线性框架只能给一个平均核。如果你的问题长这样（「紧缩在低波环境 8 个月后生效、在高波环境反号」），膨胀卷积值得那点方差。
- **推断比点估计难一个数量级**：AR(1) 噪声下点估计稳健（corr 0.765），但朴素 SE 低估 2.1×，重叠窗 bootstrap 覆盖率只有 0.56。两条路都没有开箱即用的置信区间。
- **本文的「因果」有前提**：X 外生。X 内生（Y 反过来影响 X）时，滞后核的因果解释需要工具变量那一套 machinery，IRF 再漂亮也只是条件相关。
