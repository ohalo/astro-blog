组合优化里最容易被忽略的坑，是**协方差矩阵本身不可信**。当你有 200 只股票、却只有 1000 天历史，样本协方差矩阵是个 200×200 的大块头，里面装满了估计噪声。这些噪声不会安静地待着——它们会伪装成"看起来很稳定"的低风险方向，诱导最小方差组合重仓押上去，结果样本外一塌糊涂。

随机矩阵理论（Random Matrix Theory，RMT）提供了这件事的精确答案：如果数据纯粹是噪声，协方差矩阵的特征值会服从一个叫 **Marchenko-Pastur** 的分布，边界可以算出来。落在边界内的特征值，你没法把它和噪声区分开；远远超过边界的，才是真信号。把前者抹平、保留后者，就得到了一个干净得多的协方差矩阵。

## 样本协方差为什么在"高维"时坏掉

设收益矩阵 $X$ 是 $T \times N$（$T$ 天、$N$ 资产），样本协方差 $S = \frac{1}{T}X^\top X$（已中心化）。当 $N/T$ 这个比值——记为 $q$——不可忽略时，$S$ 的特征值会和真实协方差 $\Sigma$ 的特征值严重偏离。

经验法则很反直觉：即使真实协方差是单位阵（所有资产独立、等方差），样本协方差的特征值也不会集中在 1 附近，而是**铺满一个区间**：

$$
\lambda_{\pm} = \sigma^2 \left(1 \pm \sqrt{q}\right)^2
$$

这就是 Marchenko-Pastur 分布的支撑区间。$q$ 越大（资产越多、样本越短），区间越宽，噪声越张狂。当 $N = T$（$q=1$），噪声特征值能从 0 一路铺到 4——你以为的一个"低波动特征向量"，可能纯粹是噪声的杰作。

更糟的是对组合的伤害。最小方差组合权重 $w \propto \Sigma^{-1}\mathbf{1}$，对最小特征值极其敏感——求逆会把小特征值放大。而样本协方差的最小特征值被噪声压得比真值更小（因为 MP 分布的下界 $\lambda_- < \sigma^2$），于是组合把大量权重压到这些虚假的"低风险方向"上。这些方向在样本内确实波动小，但那只是噪声的偶然，样本外立刻打回原形。

这个现象还有个更工程化的说法：**协方差矩阵的条件数被噪声撑爆了**。真实 $\Sigma$ 的最大/最小特征值之比是 $26.34/1 \approx 26$，求逆很稳；而样本矩阵的最小特征值被压到 0.3 附近、最大被抬到 27，条件数翻了三倍多。任何依赖矩阵求逆或 Cholesky 分解的操作——最小方差、均值方差最优、风险平价的某些实现——都会在这个坏 conditioning 上放大误差。去噪的本质，就是把那些人为压低的最小特征值抬回噪声均值，让矩阵重新变得良态。这也解释了为什么改善不只在组合权重上，在数值稳定性上同样受益。

## 实验设计：真值已知的因子宇宙

我造了一个真值完全清楚的市场：$N=200$ 只资产，由 $K=8$ 个因子驱动，加上单位方差的特异性噪声。真实协方差：

$$
\Sigma = L L^\top + I_N
$$

其中 $L$ 是 $200\times 8$ 的因子载荷矩阵。真实协方差有 8 个远大于 1 的特征值（信号），其余 192 个恰好等于 1（纯噪声）。

生成 $T=1000$ 天的收益样本后算样本协方差，再取 $T_2=400$ 天独立数据做样本外验证。这样每个方法的好坏都能拿真实 $\Sigma$ 和独立样本来评判，不含前视。

## MP 噪声带：把信号和噪声一刀切开

$q = N/T = 0.2$，噪声级 $\sigma^2 = 1$，代入公式：

$$
\lambda_{\pm} = (1 \pm \sqrt{0.2})^2 = [0.306,\ 2.094]
$$

这个公式的直觉值得停一下。$\sqrt{q}$ 是噪声偏离的"相对尺度"：样本越短、资产越多，$q$ 越大，随机矩阵的特征值就越散。当 $q \to 0$（样本远多于资产），$\lambda_\pm \to 1$，噪声收敛到真实值，样本协方差是可信的；当 $q \to 1$，噪声带撑满 $[0,4]$，你几乎分不清任何东西。它像一把标尺，告诉你"以你现在的样本量，多大的特征值才有资格被当作信号"。低于这把尺子的，无论看起来多显著，都可能是随机的产物。这套理论在上世纪六十年代由 Marchenko 和 Pastur 提出，最初用于物理里的随机 Hamiltonian，后来被金融界（尤其是 Bouchaud 学派）引入组合管理，成为高维协方差估计的标配工具。

所有小于等于 2.094 的样本特征值，都无法和噪声区分。看一下样本谱长什么样。

!![样本特征值谱与MP噪声带](/images/random-matrix-covariance-denoising/fig1_spectrum_mp.png)

图1一目了然：192 个噪声特征值全部挤在橙色 MP 带内（0.31~2.09），而 8 个真信号特征值远远甩在右边（13~27）。红虚线 $\lambda_+=2.094$ 是一条干净的分界线——线内是噪声，线外是信号。RMT 去噪做的事情很简单：**把线内所有特征值替换成它们的均值**（这里约 0.988），线外的信号特征值原样保留。

结果是 96% 的特征值被判定为噪声、抹平成同一个数。重建的协方差矩阵有效秩从 200 降到 8——正好是真因子数。

!![排序特征值对比：样本/真实/去噪](/images/random-matrix-covariance-denoising/fig2_eigen_compare.png)

图2用对数刻度看排序特征值。蓝色样本特征值在两个地方偏离真值：信号端被**系统性高估**（最大 27.46 vs 真值 26.34，因为样本噪声在信号方向上也贡献了正向偏差），噪声端则**散开成一片**（绿色真值全在 1，蓝色却从 0.3 铺到 2）。红色去噪后，噪声端被压成一条平线、信号端保留——重建后的谱形状和真实谱高度吻合。

## 去噪能不能真的改善组合

这才是关键。用四种协方差各配一个最小方差组合，在**真实 $\Sigma$** 下算理论波动，再用独立的 400 天数据算样本外实现波动。

!![最小方差组合样本外波动对比](/images/random-matrix-covariance-denoising/fig3_oos_vol.png)

结果（日内波动 × √252 年化口径下的组合波动）：

| 方法 | 真实Σ下波动 | 样本外实现波动 |
|---|---|---|
| 理论最优（上帝视角） | 0.0723 | 1.2018 |
| 样本协方差 | 0.0802 | 1.3283 |
| Ledoit-Wolf 收缩 | 0.0801 | 1.3278 |
| **RMT 去噪** | **0.0728** | **1.2046** |

样本协方差比理论最优高出约 11%（0.0802 vs 0.0723）——这就是噪声的代价。RMT 去噪几乎完全追平了理论下限（0.0728 vs 0.0723，差距不到 1%），把噪声造成的 10% 波动膨胀基本消除干净。样本外也印证了这一点：RMT 1.2046 对样本协方差 1.3283，改善 9.3%。

Ledoit-Wolf 收缩在这里几乎失效（0.0801，和样本协方差无差别）。原因是收缩强度 $\delta \approx 0.001$——因为 $q=0.2$ 不算大，LW 的自适应规则判断"不需要怎么收缩"。这不是 LW 不好，而是它针对的是另一种失效模式（整体估计误差），而 RMT 精准打击的是**谱结构里的噪声**。两者可以互补。

## 什么时候去噪最有用：q 扫描

既然噪声边界由 $q$ 决定，那 $q$ 越大、去噪收益应该越明显。固定 $N=200$，扫描样本长度 $T$。

!![q扫描：不同样本长度下的去噪效果](/images/random-matrix-covariance-denoising/fig4_q_scan.png)

图4里，样本长度越短（$q$ 越大），红线（样本协方差）离绿色理论线越远，而蓝线（RMT 去噪）始终贴着理论线走。当 $T$ 只有 100 天（$q=2$，比资产数还少），样本协方差的组合波动远超理论值，去噪的价值最大。这给出一个实用指引：**历史越长、资产越少，去噪越不重要；一旦 $N/T$ 超过 0.1，就该认真考虑谱去噪了。**

## 完整代码

核心实现（需 numpy、matplotlib）：

```python
import numpy as np

rng = np.random.default_rng(20261119)
N, K, T = 200, 8, 1000
q = N / T

# 1) 真值已知的因子协方差
s = 0.30
L = rng.normal(0, s, (N, K))
D = np.ones(N)
Sigma_true = L @ L.T + np.diag(D)

# 2) 收益样本
F = rng.normal(0, 1, (T, K))
noise = rng.normal(0, 1, (T, N)) * np.sqrt(D)
R = F @ L.T + noise

# 3) 样本协方差与特征分解
Xc = R - R.mean(axis=0)
S = Xc.T @ Xc / (len(R) - 1)
eig, U = np.linalg.eigh(S)
eig, U = eig[::-1], U[:, ::-1]

# 4) Marchenko-Pastur 噪声带（sigma2=1）
sigma2 = 1.0
lam_plus = sigma2 * (1 + np.sqrt(q)) ** 2

# 5) RMT 去噪：带内特征值 -> 均值，带外信号保留
eig_dn = eig.copy()
inside = eig <= lam_plus
eig_dn[inside] = eig[inside].mean()
Sigma_rmt = U @ np.diag(eig_dn) @ U.T

# 6) 最小方差组合
def minvar_weights(Sig):
    inv1 = np.linalg.solve(Sig, np.ones(N))
    return inv1 / (np.ones(N) @ inv1)

w_sample = minvar_weights(S + 1e-6 * np.eye(N))
w_rmt = minvar_weights(Sigma_rmt + 1e-6 * np.eye(N))

def port_vol(w, Sig):
    return np.sqrt(w @ Sig @ w)

print("sample vol", port_vol(w_sample, Sigma_true))  # 0.0802
print("rmt    vol", port_vol(w_rmt, Sigma_true))     # 0.0728
```

实盘用时有两点要留神。第一，$\sigma^2$ 这里取了真值 1；真实数据里要从噪声带的特征值估计它（比如用带内特征值的中位数反推），估错 $\sigma^2$ 会让整条边界平移。第二，因子收益往往厚尾、有波动聚集，MP 分布的正态假设会被破坏，噪声带边界需要留出余量——实证里常用 $\lambda_+ \times 1.1$ 之类的保守阈值。

## 小结

样本协方差在高维下的失效不是小毛病，而是会实打实吃掉组合 10% 波动的结构性问题。随机矩阵理论给了把手术刀：Marchenko-Pastur 分布精确圈出噪声特征值的地盘，把带内的抹平、带外的留下，就能把一个满是噪声的 200×200 矩阵还原成 8 个真实因子撑起的干净结构。在这个真值已知的实验里，去噪让最小方差组合的波动从 0.0802 压回 0.0728、逼近理论下限 0.0723，样本外也稳稳改善 9.3%。

它和 Ledoit-Wolf 不是替代关系——后者管整体收缩、前者管谱结构，在 $q$ 大的场景里 RMT 才是那个对症的工具。记住那个阈值：$N/T$ 一旦过 0.1，你手里的协方差矩阵就有一半是假的，该拿随机矩阵的尺子量一量了。
