做量化的人几乎都干过一件事：给价格或收益序列"平滑一下"。最常用的工具是移动平均，它简单、直觉、人人会用。但它有一个看不见的代价——**它在压掉噪声的同时，也把信号里真正的突变抹平了**。而市场里最值钱的信息，往往恰恰藏在突变里：一次政策转向、一次流动性枯竭、一次波动状态切换。

小波分析给出的答案不一样。它不假设信号是光滑的，而是允许信号由"缓慢的趋势 + 局部的突变 + 各尺度的波动"叠加而成，然后按尺度分层处理。噪声散落在最细的尺度上，趋势沉淀在最粗的尺度上，突变则表现为少数几个**幅值很大的细节系数**。阈值一卡，噪声被去掉，突变却因为系数够大而保留下来。

本文从 Haar 小波的两条平均/差分公式出发，把一个已知真值的合成信号彻底拆开、去噪、还原，用真实数字回答三个问题：噪声强度怎么从数据里估出来？阈值该取多大？小波凭什么在保突变上赢过移动平均？

## 一、Haar 小波：两条公式就是全部

Haar 小波是最简单的正交小波，简单到分解只需要"两两平均"和"两两作差"。

给定一串信号 $x$，把它相邻的两个点 $x_{2k}$、$x_{2k+1}$ 拿出来：

```
近似系数 a_k = (x_{2k} + x_{2k+1}) / sqrt(2)   # 平均：保留低频趋势
细节系数 d_k = (x_{2k} - x_{2k+1}) / sqrt(2)   # 差分：捕捉高频变化
```

`sqrt(2)` 是归一化因子，保证变换正交、能量守恒。`a_k` 是把两个相邻点合并成一个"更粗的平均值"，`d_k` 则记录这两个点之间有多大差异——差异就是局部的突变或噪声。

对 `a_k` 重复这个过程，就得到多分辨率分析（MRA）：第 1 层把 2048 点变成 1024 个近似 + 1024 个细节，第 2 层再把 1024 个近似变成 512 + 512……9 层下来，得到 1 个最粗近似系数 $cA_9$ 和 9 组细节系数 $cD_1 \dots cD_9$。

关键性质是**完美重构**：把 $cA_9$ 和所有 $cD_j$ 用逆公式逐层拼回去，能精确还原原始信号。我在代码里做了硬校验，最大重构误差 `4.4e-15`——纯粹的浮点舍入，等于机器精度。这不是近似算法，是无损的坐标系变换。

![合成信号与多尺度分解](/images/wavelet-multiresolution-denoising/fig1_decomposition.png)

图 1 上半部分是含噪观测（灰）叠加真值（深蓝），往下依次是第 9 层近似系数、第 5 层细节系数、第 1 层细节系数。可以直观看到：最细层 $cD_1$ 几乎全是密密麻麻的噪声点，几乎没有结构；而粗尺度 $cD_5$ 已经能看出信号的平台切换；$cA_9$ 则是缓慢起伏的趋势骨架。**去噪的本质，就是按尺度决定保留多少细节系数。**

## 二、噪声强度不用猜：最细层的 MAD 估计

阈值去噪要定一个门槛 $\lambda$：细节系数的绝对值小于它的当作噪声砍掉，大于它的当作信号保留。门槛多大合适？经典答案是 Donoho 的**通用阈值**：

```
lambda = sigma * sqrt(2 * ln(N))
```

$N$ 是样本数，这里 2048，$\sqrt{2\ln 2048} \approx 3.90$。唯一要估的是噪声标准差 $\sigma$。

很多人会错误地用整段信号的标准差——那里面混着信号本身的波动，会严重高估噪声。正确的做法是用**最细层细节系数** $cD_1$ 来估：因为信号在 finest 尺度上几乎是平滑的，$cD_1$ 里几乎只剩噪声。用中位数绝对偏差（MAD）这个稳健估计量：

```
sigma_hat = median(|cD1|) / 0.6745
```

0.6745 是标准正态分布的 MAD 与标准差的换算常数。实测 $\hat\sigma = 0.5159$，真值 0.55，误差 6.2%——**从数据本身估出来的噪声强度，相当准**。由此得到 $\lambda = 0.5159 \times 3.90 = 2.0147$。

## 三、软阈值与硬阈值：一个会缩小突变，一个不会

有了阈值，两种处理方式：

```
硬阈值: d' = d           若 |d| >= lambda，否则 0     # 一刀切
软阈值: d' = sign(d)*(|d| - lambda)  若 |d| >= lambda，否则 0  # 向 0 收缩
```

差别在突变处特别关键。信号里的跳变产生**幅值很大**的细节系数，硬阈值原样保留它，跳变被完整还原；软阈值把每个保留的系数都往 0 拉了 $\lambda$，突变会被系统性缩小。

数值结果印证了这一点。原始含噪信号对真值的 MSE 是 0.3037：

| 方法 | MSE | 信噪比 (dB) |
|---|---|---|
| 原始含噪 | 0.3037 | 6.83 |
| Haar 软阈值 | 0.0868 | 12.27 |
| 移动平均（窗 15，最优） | 0.0434 | 15.28 |
| **Haar 硬阈值** | **0.0206** | **18.52** |

硬阈值把 MSE 从 0.3037 砍到 0.0206，降幅 93%，信噪比提升 11.69 dB；表现最好的移动平均（在窗长 5/15/31/63/127 里搜出来的）MSE 是 0.0434，硬阈值比它还低 53%。

不过先别急着下结论说"软阈值没用"。软阈值的收缩是一把双刃剑：它牺牲了突变幅度，换来的是重构曲线更平滑、没有硬阈值在阈值附近可能产生的抖动。下面这个跳变实验会把两者的取舍摆得更清楚。

## 四、跳变保真度：小波赢在哪

最能说明问题的不是整体 MSE，而是突变处的还原能力。我在 $t=1300$ 处埋了一个幅度 2.4 的台阶（模拟一次波动状态切换），用台阶两侧紧邻的窗口均值差来估计台阶幅度：

- 真值：**2.40**
- 含噪观测：2.38（噪声碰巧抵消得不错）
- **Haar 硬阈值：2.55**（ closest，甚至略高估）
- 移动平均（窗 15）：**1.72**（抹掉了约 28%）
- Haar 软阈值：1.35（收缩效应把台阶压小了约 44%）

移动平均为什么吃亏？窗长 15 意味着台阶附近的 15 个点被平均，台阶两侧的值互相"串味"，陡峭的跳变被摊成一段斜坡。而小波的细节系数在跳变位置是一个孤立的大值，硬阈值完整保留它，重构出来的台阶干干净净。

这就是小波的真正价值：**它不是假设信号光滑再滤噪，而是允许信号有突变，并且把突变当作信号的一部分保护起来**。

图 2 上半部分看整体去噪效果，下半部分放大 $t=1300$ 的台阶：移动平均（绿）在台阶处是一段缓慢爬升的斜坡，硬阈值（红）几乎垂直跳上去，紧贴真值（深蓝）。

## 五、两个诊断：尺度能量基底与阈值 U 形

要真正理解阈值为什么有效，看两张诊断图。

第一张看**各尺度的能量**。白噪声是尺度无关的：经过正交小波变换后，噪声在每个尺度上的期望方差都是 $\sigma^2$，形成一条平坦的"噪声基底"（图中红虚线，$\hat\sigma^2 = 0.266$）。而信号的能量集中在少数几个粗尺度上——那些方差远超基底的层（第 6～9 层）就是信号所在，存活系数占比从最细层的 0% 一路升到最粗层的 100%。阈值做的事，就是在细尺度上把趴在基底附近的系数清零，在粗尺度上几乎不动。

第二张看**阈值扫描的 U 形曲线**。把阈值从 0 扫到 $2.5\lambda$，MSE 先降后升：阈值太小噪声留着，太大信号被抹掉。有意思的是，MSE 的最优点在 $0.47\lambda$（MSE=0.0369），比通用阈值 $1.0\lambda$（MSE=0.0885）更小——**通用阈值是偏保守的**，它保证"以很高概率去掉所有噪声"，代价是可能误伤一些中等幅值的信号系数。

这给实践提了个醒：$\sqrt{2\ln N}$ 是个安全起点，不是最优点。如果你的信号信噪比高、突变多，可以更激进地把阈值往下调；如果噪声很重、宁可平滑也别乱动，就守住通用阈值。

## 六、完整可运行代码

下面是生成全部结果的 numpy 实现，可直接运行：

```python
import numpy as np

rng = np.random.RandomState(20261119)
N = 2048
t = np.arange(N)

# 真值信号：分段常数状态 + 慢漂移
cp = [0, 200, 420, 700, 1000, 1300, 1600, 1850, N]
levels = [0.0, 1.8, -0.6, 1.2, -1.5, 0.9, 2.4, -0.3]
signal = np.zeros(N)
for i in range(len(levels)):
    signal[cp[i]:cp[i+1]] = levels[i]
signal += 0.25 * np.sin(2 * np.pi * t / 1024.0)
noisy = signal + rng.normal(0, 0.55, N)

# Haar 分解：两两平均得近似，两两作差得细节
def HaarDecomp(x, J):
    a = x.astype(float).copy()
    details = []
    for j in range(J):
        even, odd = a[0::2], a[1::2]
        details.append((even - odd) / np.sqrt(2))   # 细节
        a = (even + odd) / np.sqrt(2)               # 近似
    return a, details

# 逆变换：逐层交织还原
def HaarReconstruct(cA, details, N):
    a = cA.copy()
    for d in reversed(details):
        L = len(d)
        even = (a[:L] + d) / np.sqrt(2)
        odd  = (a[:L] - d) / np.sqrt(2)
        a = np.empty(2 * L)
        a[0::2], a[1::2] = even, odd
    return a[:N]

J = 9
cA, details = HaarDecomp(noisy, J)
assert np.max(np.abs(HaarReconstruct(cA, details, N) - noisy)) < 1e-9

# 最细层 MAD 估噪声 + 通用阈值
sigma_hat = np.median(np.abs(details[0])) / 0.6745
lam = sigma_hat * np.sqrt(2 * np.log(N))   # ≈ 2.0147

def denoise(cA, details, lam, kind="hard"):
    out = []
    for d in details:
        if kind == "soft":
            out.append(np.sign(d) * np.maximum(np.abs(d) - lam, 0))
        else:
            out.append(d * (np.abs(d) >= lam))
    return HaarReconstruct(cA, out, N)

mse = lambda a, b: np.mean((a - b) ** 2)
print("sigma_hat", sigma_hat, "lambda", lam)
print("raw   MSE", mse(noisy, signal))
print("soft  MSE", mse(denoise(cA, details, lam, "soft"), signal))
print("hard  MSE", mse(denoise(cA, details, lam, "hard"), signal))
```

## 七、边界与诚实提醒

小波去噪不是万能药，有三条边界必须说清。

**第一，Haar 只适合阶跃型信号。** 它的小波函数是方波，对光滑的振荡信号（比如一段正弦价格路径）会产生"阶梯化"伪影。这时该换更平滑的小波基——Daubechies db4、Symlet 或双正交小波。本文选 Haar 是为了把原理讲到最透，代码可以逐行看懂；实战请按信号形态选基。

**第二，阈值是全局的，但信号往往不是。** 通用阈值假设噪声在所有尺度均匀，对真实金融序列（波动聚集、厚尾）未必成立。更高级的做法是按层自适应阈值（level-dependent thresholding）或用小块阈值（block thresholding），本文不展开。

**第三，去噪不是预测。** 本文全程用的是一个已知真值的合成信号，检验的是"还原能力"。把去噪后的序列拿去做交易信号是另一回事——平滑会让信号滞后，突变保护不等于方向正确。别把"重构 MSE 低"直接等同于"策略能赚钱"。

真正该带走的结论是这个：移动平均是一把锤子，把所有频率一视同仁地压平；小波是一套手术刀，能按尺度区分什么是噪声、什么是突变。当你关心的数据里藏着阶跃、断点、状态切换时，这个区别就是真金白银。
