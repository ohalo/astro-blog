CAPM 教我们把 $\beta$ 当成一只股票的「固有属性」：跑一次全样本回归，得到一个常数。但只要你盯过几轮牛熊就知道，$\beta$ 会动——杠杆率变化、业务结构转型、波动率 regime 切换，都会让一只股票对市场的敏感度系统性漂移。用一个常数 $\beta$ 去算风险敞口、做对冲比率，本质上是拿「昨天的平均」赌「明天的瞬时」。

更稳妥的框架是**状态空间模型**：把 $\beta$ 看作一条会缓慢演化的隐状态 $\beta_t$，观测到的只是它被市场收益和噪声「染色」后的影子。而估计这条隐状态轨迹的标准工具，就是**卡尔曼滤波**。

## 一、把 β 写成状态空间

对第 $t$ 天，设资产收益 $r_{ast,t}$、市场收益 $r_{mkt,t}$，建模为

$$
\begin{aligned}
\text{观测方程：}&\quad r_{ast,t}= \alpha + \beta_t\, r_{mkt,t} + v_t,\qquad v_t\sim\mathcal N(0,R)\\
\text{状态方程：}&\quad \beta_t = \beta_{t-1} + w_t,\qquad w_t\sim\mathcal N(0,Q)
\end{aligned}
$$

$\beta_t$ 是个一维随机游走（局部水平模型），$Q$ 是状态噪声方差、$R$ 是观测噪声方差。卡尔曼滤波就是在这个模型下，用截至第 $t$ 天的所有观测，给出 $\beta_t$ 的**最优线性无偏估计**。

## 二、卡尔曼递推（标量版）

记预测步的估计为 $\hat\beta_{t|t-1}$、误差方差 $P_{t|t-1}$，观测增益 $H=r_{mkt,t}$，则

$$
\begin{aligned}
P_{t|t-1} &= P_{t-1|t-1}+Q\\
S_t &= H^2 P_{t|t-1}+R\\
K_t &= P_{t|t-1}H/S_t\\
e_t &= r_{ast,t}-(\alpha+\hat\beta_{t|t-1}H)\quad\text{（新息 / 残差）}\\
\hat\beta_{t|t} &= \hat\beta_{t|t-1}+K_t e_t\\
P_{t|t} &= (1-K_t H)P_{t|t-1}
\end{aligned}
$$

增益 $K_t$ 自动在「相信模型预测」和「相信新观测」之间权衡：当观测噪声 $R$ 大时 $K_t$ 小（更平滑），当状态抖动 $Q$ 大时 $K_t$ 大（更紧跟）。下面用一条合成数据演示——真实 $\beta_t$ 在前 300 天约为 1.0，之后结构性抬升到 1.6，全程叠加随机游走抖动。

```python
import numpy as np

def kalman_filter(r_ast, r_mkt, alpha=0.0003, Q=1e-4, R=8e-5):
    T = len(r_ast)
    beta_filt = np.zeros(T); P = np.zeros(T)
    innov = np.zeros(T); innov_var = np.zeros(T)
    beta_est, P_est = 0.0, 1.0
    for t in range(T):
        P_pred = P_est + Q                 # 预测
        H = r_mkt[t]
        S = H * P_pred * H + R             # 新息方差
        K = P_pred * H / S                 # 卡尔曼增益
        innov[t] = r_ast[t] - (alpha + beta_est * H)
        innov_var[t] = S
        beta_filt[t] = beta_est + K * innov[t]
        P[t] = (1 - K * H) * P_pred
        beta_est, P_est = beta_filt[t], P[t]
    return beta_filt, P, innov, innov_var

# RTS 固定区间平滑：用全部数据向前回溯，进一步降噪
def rts_smooth(beta_filt, P, Q):
    T = len(beta_filt); out = np.zeros(T)
    out[-1] = beta_filt[-1]
    for t in range(T - 2, -1, -1):
        C = P[t] / (P[t] + Q)
        out[t] = beta_filt[t] + C * (out[t + 1] - beta_filt[t])
    return out
```

## 三、三种基线 vs 卡尔曼

我们把卡尔曼滤波（因果、只用历史）和三种朴素基线摆在一起：全样本 OLS（一个常数 $\beta$）、滚动 60 日窗口 OLS、以及卡尔曼平滑（用全部数据回溯）。对真实 $\beta_t$ 的 RMSE 如下：

| 估计器 | β 估计 RMSE |
|---|---|
| 卡尔曼平滑（用全部数据） | **0.0686** |
| 卡尔曼滤波（因果） | 0.1619 |
| 全样本 OLS（常数） | 0.2003 |
| 滚动 60 日 OLS | 0.3975 |

最反直觉也最值得记住的是最后一行：**滚动 60 日 OLS 的 RMSE 竟然最高**。单只股票相对市场的日度噪声回归，斜率估计方差极大；一旦某 60 天里市场波动特别低，分母 $\sum r_{mkt}^2$ 几乎为零，斜率就爆炸。卡尔曼滤波凭「状态先验」给回归做了正则化，直接掐掉了这种爆炸。下图把真实 $\beta_t$（黑）和四条估计画在一起——滚动窗口（蓝虚线）上下乱窜，卡尔曼（红）稳稳贴着真实轨迹，平滑（绿）更干净。

![四种估计器 RMSE 对比](/images/kalman-timevarying-beta/fig4_rmse.png)

需要诚实补一刀：上面的全样本 RMSE 是卡尔曼（0.162）完胜滚动（0.398），但**分段看并非处处领先**。在 $t\ge300$ 的纯结构性抬升段，滚动 60 日 OLS 的 RMSE 反而只有 **0.163**，略低于卡尔曼的 **0.198**——因为单调抬升对滚动窗口是「局部无偏」的，它看得见近期，而 $Q=10^{-4}$ 的卡尔曼偏平滑、跟不上斜坡。卡尔曼真正的赢面在**稳健性**：全样本里滚动窗口一旦遇到市场低波动日（分母 $\sum r_{mkt}^2$ 趋零）斜率就爆炸，把全样本 RMSE 拉到 0.398；卡尔曼靠状态先验把这些爆炸摁住，全样本才以 0.162 反超。**结论：卡尔曼不是「每一段都更准」，而是「几乎不翻车」。** 下图把四条估计画在一起——滚动窗口（蓝虚线）上下乱窜，卡尔曼（红）稳稳贴着真实轨迹，平滑（绿）更干净。

![真实 β_t vs 卡尔曼/滚动/静态估计](/images/kalman-timevarying-beta/fig1_beta_track.png)

全样本 OLS 给出 $\hat\beta=1.1448$，而真实均值恰为 $1.1500$——它「平均上没错」，却完全丢掉了时变结构；这正是常数 $\beta$ 模型的根本缺陷。

## 四、拟合质量与新息

卡尔曼滤波顺带产出「一步预测」：用截至 $t-1$ 的状态预测第 $t$ 天的资产收益。下图对比资产实际收益与滤波预测，二者走势贴合，说明模型抓住了主要的系统性联动。

![资产收益 vs 卡尔曼一步预测](/images/kalman-timevarying-beta/fig2_fit.png)

更重要的是**新息序列** $e_t=r_{ast,t}-(\alpha+\hat\beta_{t|t-1}r_{mkt,t})$。在模型正确设定下，新息应近似白噪声、落在 $\pm2\sigma_t$ 带内。本例 98.2% 的点落在带内——一旦某个交易日冲出带外，就是「市场联动结构可能变了」的预警信号，可直接拿去做异常检测。

![卡尔曼新息与 ±2σ 控制带](/images/kalman-timevarying-beta/fig5_innovation.png)

## 五、超参 Q：激进还是平滑

卡尔曼滤波唯一的「调音钮」是状态噪声 $Q$。$Q$ 大→相信状态在剧烈漂移→紧跟；$Q$ 小→相信状态稳定→平滑。我们扫了三档：

![状态噪声 Q 决定跟踪激进度](/images/kalman-timevarying-beta/fig3_Q_effect.png)

实务中 $Q$ 不该拍脑袋：可以用 **EM 算法**对 $Q,R$ 做极大似然估计，或用样本外预测误差（新息对数似然）做交叉验证选。本文取 $Q=10^{-4}$ 时，滤波末端 $\hat\beta_{600}=1.474$，与真实 $1.508$ 仅差 0.03。

## 六、用 EM 自动定 Q、R

实务里 $Q$ 不该拍脑袋。卡尔曼滤波的新息 $e_t$ 在高斯设定下服从已知方差 $S_t$ 的正态分布，其对数似然只依赖状态参数 $(Q,R)$（以及截距 $\alpha$）。最大期望（EM）算法可以迭代地：E 步用卡尔曼平滑算隐状态的充分统计量，M 步闭式更新 $Q,R$，直到似然收敛。一个轻量近似是**交叉验证**：在验证集上扫一组 $Q$，挑新息对数似然（或一步预测误差）最高的那档。本文取 $Q=10^{-4}$ 时，滤波末端 $\hat\beta_{600}=1.474$，与真实 $1.508$ 仅差 0.034；若把 $Q$ 自动挑到最优，对斜坡段的滞后还会再小一点——毕竟当前 $Q=10^{-4}$ 在 $t\ge300$ 的抬升段略偏平滑，这正是「平滑 vs 紧跟」权衡的代价。补充一句：若你手上是真实日收益而非合成数据，建议先用滚动窗口 OLS 估计一条「参考 β 轨迹」作为 sanity check——卡尔曼滤波若与参考轨迹在方向上长期背离，多半是 $Q,R$ 没标定好，而非市场真的变了；这种对照能帮你尽早发现参数病态。

## 七、诚实的边界

- **滞后 vs 过灵敏都是错**。Q 太小会追不上真实的结构性抬升（β 在 t=300 后的漂移），Q 太大又把噪声当信号。这是所有在线估计算子的通病。
- **线性高斯假设**。真实收益有厚尾、波动聚类，严苛讲应上学生-t 扰动或 GARCH 观测方差；但线性高斯卡尔曼作为基线，性价比极高。
- **和市场收益质量强耦合**。若市场收益自身被噪声淹没（低波动窗口），观测增益会变小、滤波变钝——这与滚动回归的爆炸是同一枚硬币的两面，只是方向相反。
- **多资产可直接推广**。把标量 $\beta$ 换成向量（单只资产对多因子），观测方程变成 $\mathbf r_{ast,t}=\boldsymbol\alpha+\boldsymbol\beta_t^\top\mathbf f_t+v_t$，递推完全同构，只是矩阵维度上升——这正是时变因子暴露模型的起点。
- **对冲比率即用 $\hat\beta_t$**。用卡尔曼时变 $\beta$ 做市场中性对冲，比常数 $\beta$ 在 regime 切换日少留敞口；本文滤波末端 $\hat\beta=1.474$ 比常数 1.145 更接近真实 1.508，提示在抬升段用常数对冲会系统性欠对冲。

一句话：估计时变 $\beta$，与其在滚动窗口里和噪声搏斗，不如把 $\beta$ 当成一条隐状态，交给卡尔曼滤波用状态先验把它**正则化**出来。

## 八、把时变 β 真正用进组合

估计出来不是为了好看，是为了用。三个最直接的落地点：

1. **动态对冲比率**。做市场中性时，用 $\hat\beta_t$ 当对冲系数而非常数；regime 切换日 $\hat\beta$ 跳变，常数对冲会系统性留敞口，本文末段 $\hat\beta=1.474$ 比常数 1.145 更接近真实 1.508，正是这种欠对冲的现场证据。
2. **风险预算再平衡**。把 $\hat\beta_t$ 当时变风险暴露喂给风险平价 / 风险预算优化，避免用陈旧常数低估当前杠杆，尤其在波动率 regime 切换前后。
3. **异常预警**。新息 $e_t$ 持续冲出 $\pm2\sigma_t$ 带（本例 98.2% 落在带内），是「β 结构可能变了」的早期信号，可触发模型重估或暂停策略，比等回撤出来了再补救便宜得多。

一句话：β 是会呼吸的，你的风控和头寸也该跟着呼吸——卡尔曼滤波给的正是那条平滑而不过敏的呼吸曲线。
