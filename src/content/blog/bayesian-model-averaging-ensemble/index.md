"把回测第一名的模型拿上实盘"——这大概是量化里最自然的习惯，也最容易翻车。集成学习的答案是别只信一个：加权平均。可权重从哪来？等权平均对所有候选一视同仁，等于承认"我不知道谁好"；而贝叶斯模型平均（BMA）说：我知道，后验概率就是权重。本文把这套东西放上手术台——8 个候选因子、256 个子模型、g-prior 闭式后验、60 个随机种子的样本外对决——并且故意在因子池里塞了两对孪生复制品和三枚纯噪声，看 BMA 在"真模型根本不在冠军位置"的世界里怎么活。

结论先行（全部来自本文现场计算，seed=20261027）：

**① 冠军不是你以为的那个模型。** 固定演示种子上，256 个子模型的后验冠军是「动量＋波动孪生＋噪声2」，拿走 0.213；真模型「动量＋价值＋波动孪生」只分到 **0.021**，连前十都费劲。95% 的后验质量要靠 **59 个模型**才凑得齐，有效模型数 exp(H)=**31.4**——"模型的点估计"是幻觉，你手里始终握着一整个模型部落。

**② 后验最诚实的地方：它敢把噪声写进冠军。** 冠军模型里赫然有噪声2。这不是 bug：价值因子的信号方差只占 y 总方差的 3.1%（β=0.22，σ_ε=1.15），砍掉价值的代价太小，似然罚不动它——"漏掉价值因子"的三因子族合计拿走近 **37.1%** 的后验质量。数据说了多少，后验就信多少，一毫不多信。

**③ t 检验在孪生前掷硬币，PIP 不掷。** 相关 0.90 的动量孪生对，全模型 OLS 里恰好一个显著的种子占 **68.3%**（0.80 相关的波动孪生对是 80.0%），两个都显著的只占 3.3%——裁判把票扔给复制品中的随机一个。但逐因子包含概率（PIP）给出稳得多的大盘：动量 0.794 + 孪生 0.271 = 族质量 **1.065**（超过 1 说明孪生经常同入一票），波动族同理 1.039；三枚噪声全部 ≤0.14。**"必须有动量"这件事，模型平均知道，显著性检验不知道。**

**④ 选错模型的代价：0.3%。** 60 种子样本外对决里，样本内 R² 冠军 **88.3%** 的时间选错模型、5 折 CV 也有 70% 失手，可冠军的中位 MSE 1.3893 只比 BMA（1.3852）贵 0.3%。因为池子里全是孪生近亲，"错误的模型"大多和真模型几乎同构。等权 Top-64 中位 1.3821、oracle 真模型 1.3829——五种方法在 0.5% 内打平。**同质池里选择是免费的；BMA 真正买的是异质池、厚尾情形下的那份保险**（见文末冷水）。

**⑤ g 是第二个"模型数"旋钮。** g-prior 从 g=0.1 扫到 g→∞：有效模型数从 **236.1** 单调拧到 **2.7**；真模型平均后验在 g=n=300 附近爬到峰值 0.225；OOS MSE 呈 U 型，g=5 最优 1.3740，g→∞ 恶化到 1.5076（**+9.7%**）。"默认 g 就行"经不起逐点对照——对照表就画在图五。

## 一、考场：8 因子、两对孪生、三枚噪声

数据生成过程：8 个"因子"里，`动量`、`价值`、`波动孪生` 是真信号（β=0.35/0.22/0.28）；`动量孪生 = 0.90·动量 + √(1−0.81)·ε` 是动量加了 19% 新息的复制品；`波动 = 0.80·波动孪生 + 噪声` 是波动孪生的复制品；再加三枚独立纯噪声。y 由三个真因子线性驱动，残差 σ_ε=1.15。样本 n=300，前 240 天训练、后 60 天样本外。注意信号方差 0.35²+0.22²+0.28²≈0.249，只有噪声方差 1.32 的 19%——理论 R²≈0.16，这是个"信噪比正常偏低"的现实市场。

![合成市场与 256 子模型后验](/images/bayesian-model-averaging-ensemble/fig1_model_landscape.png)

候选模型空间 = 8 因子的全部非空子集，共 2⁸−1=255 个，外加空模型。真模型 `(动量, 价值, 波动孪生)` 只是其中之一。

## 二、闭式后验：g-prior 让 256 个模型全部可算

BMA 的要件是每个子模型的**边际似然** p(D|M)。对线性高斯模型， Zellner g-prior 给先验 β|σ² ~ N(0, gσ²(X'X)⁻¹)、σ² ∝ Jeffreys，边际似然有闭式：

```
log p(D|M) = −(k/2)·ln(1+g) − (n/2)·ln( SST − (g/(1+g))·ESS )
```

其中 ESS 是该子模型的回归平方和。先验只留一个标量 g，后验权重就是归一化指数：

```python
import numpy as np

def bma_weights(rss, y, g, k):
    """g-prior + Jeffreys 闭式边际似然 → 后验模型权重
    rss: 每个子模型的残差平方和, k: 各子模型参数数(不含截距)"""
    n, SST = len(y), ((y - y.mean()) ** 2).sum()
    ess = SST - rss
    lml = -0.5 * k * np.log1p(g) \
          - 0.5 * n * np.log(SST - (g / (1 + g)) * ess)
    w = np.exp(lml - lml.max())
    return w / w.sum()

# 预测 = 模型加权平均：w @ P  其中 P[i] = 模型 i 的样本外预测向量
pred_bma = w @ P          # 一次矩阵乘法，256 个模型全部参与
```

全程只用 `np.linalg.lstsq` 逐子模型跑 OLS 加这一行归一化，无 MCMC、无外部库。图二(a) 是按后验降序的累计质量曲线——95% 线切在 59/256；(b) 把模型按"家庭"归堆：真模型一家 0.021、它的三个孪生变体凑 0.007、孪生父子同入的冗余族 0.085、欠规格（≤2 因子）0.229、**漏掉价值因子 0.371**、其余 0.288。逐模型比较看的是柱子，归堆看的是潮水。

## 三、PIP：把"因子投票"从掷硬币变成大盘

每个因子的 PIP（posterior inclusion probability）= 所有包含它的模型后验之和。60 个独立种子重跑：

| 因子 | PIP 均值 | 95% CI 半宽 | | 因子 | PIP 均值 | 95% CI 半宽 |
|---|---|---|---|---|---|---|
| 动量 | **0.794** | ±0.063 | | 波动孪生 | **0.800** | ±0.068 |
| 动量孪生 | 0.271 | ±0.060 | | 噪声1 | 0.106 | ±0.029 |
| 价值 | **0.791** | ±0.071 | | 噪声2 | 0.089 | ±0.014 |
| 波动 | 0.238 | ±0.063 | | 噪声3 | 0.136 | ±0.040 |

三个真因子 0.79/0.79/0.80，噪声全部压在 0.14 以下——BMA 的"投票"把真信号和垃圾分得很开。孪生对的 individually 数字（0.79 vs 0.27）恰好说明裁判在两票之间摇摆，但**族质量 1.065/1.039 ≥ 1** 意味着几乎每个后验大头模型都至少派了一个孪生代表入场——超过 1 的部分来自孪生同入一个模型的冗余配置。对照右边：全模型 OLS 的 |t|（10% 临界 1.65），60 种子里孪生对"恰好一进一出"占 68.3%/80.0%——你换一个种子，系数显著性就换人当选中者，这种裁判怎么用来做因子筛选？

![PIP 与 OLS t 检验对拍](/images/bayesian-model-averaging-ensemble/fig3_pip_vs_ols.png)

## 四、样本外对决：冠军、CV、BMA、等权、oracle

60 个种子，每个都重新生成数据，五种方法同台：样本内调整 R² 冠军、5 折时序 CV 选模、BMA(g=n)、剔除冠军后的等权 Top-64、oracle（直接用真模型 OLS）。中位 MSE：

| 方法 | 中位 | P90 | 备注 |
|---|---|---|---|
| 单模型冠军 | 1.3893 | 1.6922 | 88.3% 的时间选错模型 |
| 5折CV选模 | 1.3853 | 1.6746 | 70% 时间选错 |
| BMA (g=n) | 1.3852 | 1.6922 | 从不"选"模型 |
| 等权 Top-64 | 1.3821 | 1.6878 | 剔除冠军后 64 个等权 |
| oracle 真模型 | 1.3829 | 1.6675 | 天花板 |

这组数字有两个诚实的刺：**其一**，88.3% 选错率只换来 0.3% 的 MSE 代价——同质近亲池里"错模型"≈"对模型"，选择根本不值钱；BMA 的保险费在这种池子里收不回本钱。**其二**，等权 Top-64 的中位比 BMA 还低 0.003，BMA 的 P90 也没有优势。那 BMA 赢哪？看冠军的分布右尾：错得离谱的冠军（选了"欠规格＋漏关键因子"的复合残次）把 P90 顶到 1.692，比 oracle 贵 1.5%；种子越接近"某真因子恰好被噪声复制品完全顶替"，冠军的独注越疼。BMA 的价值随池子异质度增长——把孪生系数从 0.90/0.80 降到 0.5 重跑，冠军/BMA 差距立即拉开。本池的设计就是让它俩打平，然后诚实报账。

![60 种子样本外对决](/images/bayesian-model-averaging-ensemble/fig4_oos_showdown.png)

## 五、g 先验：一根从"全都要"到"全不要"的旋钮

g 控制先验对系数的信任强度：g→0 系数先验收缩到 0（边际似然只罚参数个数，近似全部 256 个模型平分秋色）；g→∞ 逼近平无信息（似然差被指数放大，后验塌到极少数模型）。40 种子均值：

| g | 有效模型数 | 真模型平均后验 | OOS MSE |
|---|---|---|---|
| 0.1 | 236.1 | 0.006 | 1.3947 |
| 5 | 68.2 | 0.056 | **1.3740** |
| 300 (g=n) | 17.1 | 0.225 | 1.3832 |
| 12000 | 6.8 | 0.149 | 1.4138 |
| 2²⁶ | 2.7 | 0.003 | 1.5076 |

OOS 是 U 型：中段 g（5～150）最优，两端各亏 1.5%/9.7%。常用默认 g=n 离最优只差 0.7%，可以接受但不是免费；g→∞ 时真模型后验反而崩回 0.003——过度信任似然会在孪生混战里锁死一个错误代表。另外试了尺寸先验（对每个子模型乘 1/C(8,k)，奖励简约）：演示种子的有效模型数从 31.4 缩到 25.8，但 40 种子均值 MSE 1.3945，比 g=n 均匀先验的 1.3832 **贵 0.8%**——孪生池里连先验技巧都翻不出浪花，这个负面结果如实上报。

![g 先验敏感性与尺寸先验](/images/bayesian-model-averaging-ensemble/fig5_g_prior_sensitivity.png)

## 六、把 BMA 装进自己的工具箱

三条实战守则：**a)** 别拿"PIP>0.5"当因子录用线——真因子的 PIP 在低信噪比市场常常只有 0.4~0.6，先对照族质量与 OLS 显著性稳定性再下结论；**b)** BMA 预测是加权平均，对**峰度敏感**：如果池子里混进一个样本内极好、样本外灾难的模型（过拟合冠军），它后验不高但预测方差大，BMA 会被拖累——先做预测截断或淘汰 P90 异常者；**c)** g 至少扫三档（n/10、n、10n），把 OOS 对 g 的响应曲线画出来再定，本文图五(b) 就是模板。计算上的好消息：256 个子模型 ×300 观测的全流程（OLS+闭式后验+加权预测）在本机 numpy 下 40 种子共约十几秒，BMA 从来不是算力问题，是观念问题。

## 结语

BMA 的卖点从来不是"选出冠军"，而是**在选不出冠军的时候不交智商税**：它承认 59 个模型共同解释数据，把预测做在后验期望上；t 检验在孪生间掷硬币时，它的族 PIP 已经数清了"必须有动量"的共识。代价同样诚实——在孪生遍地的同质池里，它与 CV、等权、甚至那个 88.3% 时间选错的冠军打成一片，差异小到可以忽略。先问你的模型池是部落还是克隆大队，再决定为谁付这份保险费。
