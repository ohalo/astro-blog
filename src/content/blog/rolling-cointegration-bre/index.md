配对交易的教科书第一步是 Engle-Granger：回归、取残差、ADF 检验，通过就开干。这套流程藏着三个很少被明说的假设——**对冲比恒定、全样本估计可信、断裂会被平均掉**。本文用一个 3000 个交易日的合成协整对，把这三个假设一次拆到底，并顺带回答两个实操问题：协整断裂多久能被发现？发现之后该换什么方法？

## 一、合成市场：一条在 t=1500 断掉的协整关系

3000 个日频观测。资产 A 是随机游走（日漂移 0.04%、日波动 1.1%）；资产 B 的对数价格 = β_t·log(A) + 价差，价差是 OU 过程（κ=0.22，半衰期约 3.2 天，稳态标准差 0.6%，接近 ETF 与一篮子成分股之间的套利型协整）。断点设在 t=1500：β 从 0.80 用 20 天渐进升到 1.30——不是瞬时跳变，而是像指数调样、成分股重组那样的渐进重定价。

注意这个设计的一个后果：β 断掉的那一刻，B 的价格相对旧关系出现约 25% 的水平移（0.5×logA 的量级）。这不是瑕疵而是特征——真实世界的协整断裂从来都是价格水平移，不是温柔的回转。

还有一个必须先交代的设计约束：**价差的均值回复速度直接决定滚动 ADF 有没有功效**。ADF 的功效大致取决于回复速度 φ 与窗口长度 n 的乘积 φ·√n——要稳定拒绝单位根，需要 φ·√n 明显小于 -2.86。如果按"现实感"把价差半衰期设为 14 天（κ=0.05），250 日窗口的 φ·√n 只有 -0.76，t 值中位 -1.2 上下，连协整成立的世界都拒绝不了单位根，检测器成了摆设。本例因此把半衰期压到 3.2 天（κ=0.22），让断点前中位 t=-5.64。这不是作弊，是把检测器的功效区间对准要检测的现象；代价是这个价差短得像套利关系，读者应把它读成"高协整强度"的特例，而不是普遍设定。

## 二、全样本 Engle-Granger：协整"平均而言成立"

对全样本 3000 天跑 Engle-Granger：β̂=1.190（真值前半段 0.80、后半段 1.30，全样本估计落在中间，毫无意义），残差 ADF t=-4.24，深度拒绝单位根。**协整检验通过了——在一个关系已经断掉一半的世界上。** 这就是全样本检验的结构性盲点：它回答"这两条序列有没有长期关系"，不回答"这个关系有没有变过"。断点后残差里混进了 0.5×logA 的随机游走成分，但 1500 个平稳观测足以把它平均掉。

## 三、滚动 ADF：断裂检测，零误报

检测的正确姿势是盯着**旧关系**：用样本内（前 1000 日）估出的冻结 β=0.800 构造残差，每 250 日窗口跑一次 ADF。断点前 250 个窗口的中位 t=-5.64，全部拒绝单位根、**零误报**；断点后中位 -1.47，稳定升破临界值 -2.86——协整消失在断点后 10 天被确认。

10 天的滞后不是普遍规律，它便宜是因为本例的断裂是猛烈水平移；换平缓断裂，滞后会拉长到窗口量级。更重要的是对照实验：在**没有断点**的平行世界里，同一套滚动 ADF 跑完 3000 天从未误报一次（中位 -5.35）。检测器在没事的时候闭嘴、在有事的时报信——这两点合起来才叫可用，单点"事后检测到了"一文不值。

这里藏着一个反直觉的设计，值得单独说：**检测残差必须用冻结的旧 β，不能用滚动重估的 β。** 如果用滚动 β，断点后的新关系会被窗口逐步吸收，残差永远平稳、ADF 永远拒绝单位根——滚动估计是优秀的适应器，同时也是失明的检测器。检测与适应必须使用两套 β，这是本文最实用的结论：想早一点知道关系断了，就别让估计器替你粉饰残差。

## 四、对冲比跟踪与 DCC：谁在适应，谁在叙事

检测是事后确认，交易要的是事前适应。滚动 120 日 OLS 每 120 日重估一次 β：全样本 RMSE 0.179、断点后 0.243；静态冻结分别是 0.352 和 0.498——断点后静态对冲比永久偏离真值约 0.5，价差被污染成趋势。窗口拉长到 250 日，RMSE 降到 0.149/0.200：估计更准但适应更慢。本例中断点后的估计噪声比滞后更贵，长窗反而占优；但若断点发生在窗口初期，结论会反转——窗口长短是检测滞后与估计噪声的权衡，没有免费窗口。

那 DCC 呢？实现上，两条腿各拟合一个方差目标化的 GARCH(1,1)（σ²ₜ = (1−a−b)·v + a·ε²ₜ₋₁ + b·σ²ₜ₋₁，QMLE 优化），取标准化残差后跑 DCC：Qₜ = (1−a−b)·Q̄ + a·zₜ₋₁zₜ₋₁′ + b·Qₜ₋₁，相关矩阵由 Qₜ 归一化得到。资产 A 估出 a=0.000——它的收益是指定 iid 正态、没有波动聚集，估计器如实回答"没有"；B 也接近常数波动（a=0.013）。**两腿都没有波动聚集，DCC 的动态全部来自 β 断点造成的相关水平移**——这恰好把"相关结构断点"这一个现象从波动聚集里隔离出来，是本文选这个 DGP 的用意。

再报告数字：DCC 条件相关从断点前 0.905 移到断点后 0.950，与直接计算的 0.901→0.960 吻合。但注意两件事：其一，这是**被动、滞后、幅度有限**的水平移，相关矩阵从来不是断裂的领先指标，领先信号在残差漂移里；其二，一个流行的偷懒写法——滚动相关直接用 mean(xy)/(σx·σy)、不减窗口均值乘积——在本例把断点后相关从 0.959 高估到 0.984，极端窗口算出 **1.119** 的"相关系数"。窗口日均收益只有 -0.46%/-0.59% 就够穿帮了：mean(xy) 里混进了 mean(x)·mean(y)，窗口均值一大，假相关就浮出来。DCC 用去均值的标准化残差，没有这个病。

## 五、回测：静态断点后流血，滚动续命，无断点对照泼冷水

配对回测规则：价差 60 日 z-score，|z|>2 开仓、|z|<0.5 平仓，单边 5bps 成本，信号当日收盘计算、次日生效，无前视。记账上，日 PnL = 持仓×(rB − β̂·rA) − 5bps×|Δ持仓|×(1+β̂)。第二项是成本，第一项里藏着本文的主角——对冲比误差 e = β̂−β 会把 PnL 污染成 e·rA 的噪声项：断点后 e≈0.24，日噪声约 0.26%，与信号同量级。Oracle 与滚动之间断点后约 10 个百分点的收益差距，主要就是这项噪声随时间的积分。

| 策略 | 全样本收益 | Sharpe | 最大回撤 | 断点后收益 | 断点后 Sharpe |
|---|---|---|---|---|---|
| 静态冻结 β | +16.96% | 0.25 | -23.87% | **-18.05%** | -0.36 |
| 滚动 120 日 β | +119.19% | 1.46 | -11.82% | +51.69% | 1.30 |

| buy&hold 等权 | +22.63% | — | — | +5.88% | — |

断点世界里，静态策略断点后 1500 天亏掉 18.05%，滚动策略不仅止血还赚 +51.69%——逼近 Oracle 的 +61.38%。但泼冷水的对照来了：**在无断点世界里，静态 +120.90%/SR 2.15/DD -1.49%，与 Oracle（SR 2.13）几乎重合，滚动反而只有 +75.73%/SR 1.36/DD -4.61%。** 没有断点要防的时候，滚动估计的噪声是净负担。滚动协整卖的是保险，保险费是常态收益，理赔只发生在断裂真的发生时。

## 六、诚实结论

- 全样本协整检验对断裂结构性失明——它检验"有没有关系"，不检验"关系变没变"。显著性是通过考试的最低标准，不是免检牌照。
- 检测要靠旧关系的残差：滚动 ADF 在本例断点后 10 天确认，断点前 250 窗与无断点对照均零误报；平缓断裂的滞后约等于窗口量级，这是学费不是缺陷。
- 适应要靠重估 β：断点后 RMSE 0.243 vs 静态 0.498，回测 -18.05% vs +51.69%。但 Oracle 与滚动之间约 10 个百分点的断点后差距说明：估计误差本身就是 PnL 的噪声源（e·rA），窗口长短是滞后与噪声的权衡。
- DCC 与滚动相关是衍生信号：水平移 0.905→0.950 真实但被动，用相关系数做断裂预警等于用后视镜开车；真要监控，监控残差的 CUSUM 和冻结关系的 z-score。
- 合成世界的断裂是植入的，真实世界的断裂密度未知——上实盘前，先回答"你的组合里有多少对子、历史上断过几次、断的时候你用什么速度知道"。
- 落地清单：检测用冻结 β 的滚动 ADF（或残差 CUSUM），适应用滚动 OLS 的重估 β，两套 β 分开跑；窗口长度按"滞后预算 vs 噪声预算"定，别抄默认值；监控指标首选冻结关系的 z-score 偏离持续时间，次选 DCC 水平移，别把相关系数当警报器。

```python
import numpy as np

def synth_pair(seed, T=3000, break_at=1500, ramp=20, kappa=0.22):
    """合成协整对：B = beta_t*A + OU 价差；beta 在 break_at 起渐进断裂"""
    rng = np.random.default_rng(seed)
    rA = rng.normal(0.0004, 0.011, T)
    logA = np.cumsum(rA)
    spread = np.zeros(T)
    for t in range(1, T):
        spread[t] = spread[t-1] + kappa*(0 - spread[t-1]) + rng.normal(0, 0.004)
    beta = np.full(T, 0.80)
    if break_at:
        k = np.arange(ramp)
        beta[break_at:break_at+ramp] = 0.80 + 0.50*(k+1)/ramp
        beta[break_at+ramp:] = 1.30
    return logA, beta*logA + spread, beta

def adf(x, maxlag=8):
    """ADF t 统计量（BIC 选滞后阶）"""
    d, n0 = np.diff(x), len(x)-1
    best = (np.inf, 0.0)
    for lag in range(maxlag+1):
        n = n0-lag
        cols = [np.ones(n), x[lag:n0]] + [d[lag-i:n0-i] for i in range(1, lag+1)]
        X = np.column_stack(cols)
        XtXi = np.linalg.pinv(X.T @ X)
        b = XtXi @ (X.T @ d[lag:])
        e = d[lag:] - X @ b
        s2 = e @ e/(n-X.shape[1])
        bic = n*np.log(s2) + X.shape[1]*np.log(n)
        t = b[1]/np.sqrt(s2*XtXi[1, 1])
        if bic < best[0]:
            best = (bic, t)
    return best[1]

logA, logB, beta_true = synth_pair(42)

# 1) 检测：冻结旧 beta，滚动 ADF 盯残差（t 升破 -2.86 = 协整消失）
beta_frz = np.linalg.lstsq(np.c_[np.ones(1000), logA[:1000]], logB[:1000], rcond=None)[0][1]
resid = logB - beta_frz*logA
adf_t = [adf(resid[e-250:e]) for e in range(250, len(logA), 5)]

# 2) 适应：滚动 OLS 重估对冲比
beta_hat = np.array([np.linalg.lstsq(np.c_[np.ones(120), logA[t-120:t]], logB[t-120:t],
                                     rcond=None)[0][1] for t in range(120, len(logA))])

# 3) 交易：价差 z-score 开平仓，单边 5bps 成本
z = (logB - beta_hat*logA)
mu = np.convolve(z, np.ones(60)/60, 'valid')      # 示意：滚动均值/标准差
sd = np.sqrt(np.convolve(z**2, np.ones(60)/60, 'valid') - mu**2)
```
