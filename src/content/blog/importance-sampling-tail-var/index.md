## 一、结论先行

风险部门要一个数：99.9% 分位的单日亏损是多少。朴素做法很简单——生成几十万条收益路径，取损失的第 99.9 百分位。问题是这个分位数只由最极端的 0.1% 样本决定：20 万条路径里只有 200 个落入尾部，标准误天然就大。想要小数点后两位稳，得生成上千万条路径，计算成本让人望而却步。

重要性采样（Importance Sampling, IS）换了一个思路：**与其在原始分布里苦等罕见事件，不如主动把采样分布挪到罕见事件上去，再用似然比权重把结果搬回来**。对正态收益，最优挪动由指数倾斜给出，倾斜强度 $\theta^*$ 有闭式解。我用一个 5 资产、日波动率 0.9% 到 2.0% 的多头组合把它算了一遍：

- 真实尾部概率 $P(L>{\rm VaR}_{99.9\%})=0.001$。20 万条朴素样本估计的标准误 **7.07e-05**（相对误差 7.1%）；同本量下 IS 的标准误 **4.18e-06**（相对 0.4%），改善 **16.9 倍**。200 次重复的 RMSE 比值 **16.6 倍**。
- 单样本量 2 万、重复 150 次：VaR 的 RMSE 从 **6.37e-4** 降到 **3.65e-5**（**17.5 倍**）；ES 从 **8.47e-4** 降到 **2.75e-5**（**30.8 倍**）。尾部均值比尾部分位数更受益，因为 ES 的估计完全依赖尾部样本的加权平均。
- 倾斜强度不是越大越好。$\theta/\theta^*$ 从 0 升到 1，估计量相对标准差从 0.0716 单调降到 0.00418；继续升到 1.5 反而回到 0.00736，升到 2.0 冲到 0.0417——**比不倾斜还差**。尾部加权样本的有效样本占比（ESS）在 $\theta=\theta^*$ 时还有 0.446，到 2 倍倾斜只剩 0.003。
- 厚尾是另一道坎。把损失换成自由度 5 的 t 分布，99.9% VaR 从正态的 3.042% 抬到 **4.509%**（高 48.2%）。若把正态倾斜的权重硬套到 t 样本上，尾部概率估成 **2.11e-08**，相对真值偏低 **99.998%**——数值上等于零。改用 t 分布的位置平移加精确密度比，估计回到 0.000985，标准误 1.20e-05。

**一句话：指数倾斜把「等 1000 次才发生一次」变成「每次都在发生，然后乘一个权重」，代价是权重本身有方差——倾斜强度选对，方差降一个数量级；选错，比不做还糟。**

## 二、指数倾斜的数学与实现

设组合损失 $L=-w^\top R$，收益 $R\sim N(\mu,\Sigma)$，则 $L\sim N(\mu_L,\sigma_L^2)$，其中 $\mu_L=-w^\top\mu$、$\sigma_L^2=w^\top\Sigma w$。要估计 $p=P(L>V)$，其中 $V$ 是 99.9% 分位。

指数倾斜把采样均值移向 $V$。令倾斜后的收益均值变为 $\mu-\theta\Sigma w$，则损失均值变成 $\mu_L+\theta\sigma_L^2$，希望它等于 $V$，于是

$$
\theta^*=\frac{V-\mu_L}{\sigma_L^2}
$$

这个例子的 $\mu_L=-0.000315$、$\sigma_L=0.009946$、$V=0.030421$，所以 $\theta^*=310.70$。对应的似然比权重为

$$
W_\theta(L)=\exp\big(-\theta L+\theta\mu_L+\tfrac12\theta^2\sigma_L^2\big)
$$

于是 $p=E_Q[W_\theta(L)\mathbf 1\{L>V\}]$，其中 $Q$ 是倾斜后的采样分布。注意权重是**指数形式**，这是方差的来源：当 $\theta$ 过大，少数样本的权重会吃掉大部分总权重，ESS 崩溃。

实现只有几行，关键在于倾斜要沿 $\Sigma w$ 方向而不是标量地加在某个坐标上：

```python
import numpy as np
from scipy.stats import norm

# mu, Sigma, w 为 5 资产的参数; L_chol = cholesky(Sigma)
muL = -w @ mu
sigL = np.sqrt(w @ Sigma @ w)
V    = muL + sigL*norm.ppf(0.999)
theta_star = (V - muL)/sigL**2

def sim_loss(n, theta=0.0, rng=None):
    """theta=0 为原始分布; 否则均值沿 -theta*Sigma@w 平移"""
    z = rng.standard_normal((n, len(w))) @ L_chol.T
    R = z + mu - theta*(Sigma @ w)
    return -R @ w

def weights(loss, theta):
    psi = theta*muL + 0.5*theta**2*sigL**2
    return np.exp(-theta*loss + psi)

# 尾部概率估计
l = sim_loss(200_000, theta_star, rng)
p_hat = (weights(l, theta_star)*(l > V)).mean()
se = (weights(l, theta_star)*(l > V)).std()/np.sqrt(len(l))
```

这里踩过一个实现坑：一开始把倾斜写成 `mu + Sigma@theta`（把标量 $\theta$ 当成向量），方向完全错了，估计量给出荒谬值。**正确的平移向量是 $-\theta\Sigma w$**，它让组合损失的均值朝正方向移动 $\theta\sigma_L^2$。

图1 画出了倾斜前（蓝）与倾斜后（橙）的损失密度。原本 3.04% 的尾部几乎贴着横轴，倾斜后密度中心被搬到 3.04% 附近，尾部事件从「千载难逢」变成「家常便饭」；权重则精确地把它们压回原来的概率质量。

## 三、精度收益：概率、VaR 与 ES

图2 给出收敛速度。横轴是对数样本量，纵轴是尾部概率的相对误差：朴素 MC 大致按 $1/\sqrt n$ 慢慢下降，20 万条时还有 7% 的波动；IS 在同一样本量下已经收敛到 0.4%。两条曲线的垂直间距在同一本量下稳定在约 17 倍——这不是某一次运气好，而是 200 次独立重复的 RMSE 比值 16.6 倍所证实的系统性改善。

![朴素 MC 与重要性采样的收敛对比](/images/importance-sampling-tail-var/fig2_convergence.png)

VaR 和 ES 的估计要稍微多一步。IS 下不能直接取加权样本的分位数（权重会破坏顺序统计量的性质），而是解一个方程：在网格上找 $v$ 使 $\sum_i W_i\mathbf 1\{L_i>v\}/n=0.001$，再用线性插值细化。ES 则用尾部加权平均 $\sum W_iL_i\mathbf 1\{L_i>\hat v\}/\sum W_i\mathbf 1\{L_i>\hat v\}$。

150 次重复、每次 2 万样本的结果：朴素法 VaR 平均低估 0.0000932，IS 平均高估 0.0000132；RMSE 从 6.37e-4 降到 3.65e-5。ES 更夸张：RMSE 从 8.47e-4 降到 2.75e-5，30.8 倍。原因直观——朴素法的 ES 只用到尾部那十几个样本，IS 则让大部分样本都携带尾部信息。

## 四、倾斜过猛：方差不降反升

图3 是这篇文章最该记住的一张图。左半边是估计量相对标准差随 $\theta/\theta^*$ 的变化：从 0 到 1 单调下降，在 $\theta^*$ 处触底 0.00418，之后掉头向上，到 2 倍时 0.0417——已经比不倾斜的 0.0716 好不了多少。右半边给出诊断：尾部加权样本的有效样本占比在 $\theta^*$ 时 0.446，1.25 倍时 0.238，1.5 倍时 0.090，2 倍时只剩 0.003。

![倾斜强度敏感性与有效样本量](/images/importance-sampling-tail-var/fig3_theta_sensitivity.png)

为什么会反噬？倾斜的目标是把采样中心恰好放到阈值 $V$ 上。倾斜不足，尾部事件仍然罕见，权重方差小但指示函数几乎恒为 0；倾斜过度，采样中心跑到 $V$ 右边很远，指示函数几乎恒为 1，但此时权重 $W=e^{-\theta L+\psi}$ 中的 $-\theta L$ 项开始剧烈震荡，少数落在阈值附近的样本拿到巨权重，ESS 崩塌。**最优倾斜是这两种失效之间的平衡点**，它恰好使采样分布的中心落在被积函数「贡献最大的区域」——对指示函数 $\mathbf 1\{L>V\}$ 而言，这个区域就在 $V$ 附近。

实操建议：不要凭感觉设 $\theta$，用累积量和目标分位数算出 $\theta^*$，然后小幅上下扫描（0.8/1.0/1.2 倍），用 ESS 或权重变异系数做诊断。如果 ESS 低于样本量的 5%，就是倾斜过猛的信号。

## 五、厚尾下的失效：正态权重套到 t 分布

风险管理里最危险的假设是「损失服从正态」。我把损失换成自由度 5 的标准化 t 分布（保持相同波动率）：99.9% VaR 从 3.042% 抬到 **4.509%**，高了 48.2%。图4 画出了两条密度曲线和两条 VaR 竖线，尾部差异一目了然。

![厚尾下的正态倾斜失效](/images/importance-sampling-tail-var/fig4_heavy_tail.png)

这时如果照搬正态的倾斜权重，结果是灾难性的：尾部概率估计值只有 **2.11e-08**，相对真值 0.001 偏低 99.998%。原因在于 t 分布的尾部是多项式衰减而非指数衰减，正态指数倾斜的权重函数在远端要么过冲要么欠冲，完全失去了似然比的解释。这不是「精度略差」，是量级错误。

正确的做法是承认厚尾结构：用 t 分布的位置平移作为提议分布，权重取两个 t 密度之比 $f_0(L)/f_1(L)$。这样权重在远端按相同的多项式阶衰减，方差有界。实测尾部概率 0.000985、标准误 1.20e-05，与朴素法的 0.000995 一致但方差低得多。代价是 ESS/n 只有 0.017——厚尾下尾部事件本身就「更重」，能分到有效权重的样本比例天然更低。

## 六、什么时候值得上 IS

判断标准很简单：**目标概率越小、朴素法的尾部样本越少，IS 的收益越大**。99% 分位（尾部 1%）时 20 万样本还有 2000 个尾部点，朴素法已经够用；99.9% 时只剩 200 个，IS 带来十几倍改善；到 99.99% 时朴素法的尾部样本不足 20 个，IS 几乎是唯一可行的蒙特卡洛方案。反过来说，如果要估计的是整个分布（不止尾部），IS 只优化了一个点，其他区域的精度反而可能下降，这时该用分层采样或多重要性采样。

### 与方差缩减家族的对比

重要性采样不是唯一的方差缩减工具。对偶变量法用 $\varepsilon$ 与 $-\varepsilon$ 配对，实现几乎零成本，但对本次实验的指示函数 $\mathbf 1\{L>V\}$ 效果有限——两个对偶样本通常一个在阈值内一个在阈值外，方向相反反而增加方差。控制变量法需要一个与损失高度相关、且期望已知的辅助量；尾部概率问题里这样的辅助量很难找。分层采样把样本按概率质量切块，对单维问题有效，但组合损失是多维投影，分层的维度会随资产数爆炸。IS 的优势恰恰在于：它直接针对「关心的那个点」设计采样分布，不需要辅助变量，也不随维度指数增长——只要能写出倾斜后的分布和似然比。

### 与历史模拟法的对话

许多风控系统用的是历史模拟：把过去 250 天的收益重新抽样。这个方法的尾部只有 250 个样本，99.9% 分位本质上是从这 250 个点里外推，统计上极不可靠。IS 无法直接救历史模拟，因为经验分布没有解析的累积母函数可做倾斜。但可以先用一个拟合的分布（正态或 t）做 IS 得到参数化的尾部估计，再用历史分位数做交叉校验——两者差异大说明模型假设有问题，而不是简单取更保守的那个。

另一个边界是模型可解性。指数倾斜的闭式解依赖损失的正态性（或至少已知的累积母函数）；对一般的非线性组合（含期权、路径依赖）没有闭式 $\theta^*$，需要用自适应 IS 或交叉熵法迭代估计倾斜参数——那是另一篇文章的话题。本文的数值实验全部基于可写出特征函数的正态与 t 分布，结论不要外推到未知分布的黑箱模型。
