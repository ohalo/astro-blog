## 一、结论先行

真实收益面板从来不是整齐的矩阵。新股上市晚、停牌、退市、数据源漏字段，动辄三成以上的格子是空的。最常见的处理是拿列均值一填了事，然后在残缺数据上跑 PCA、估协方差、做组合优化。本文用一个真值已知的面板把这件事的代价量化出来。

在 240 只股票、500 天、4 个真因子、10% 独立留出格子的实验里：

- 列均值填充的留出 RMSE 在 10%~70% 缺失率下几乎不动，稳定在 **0.01454~0.01458**——它根本没有利用任何横截面结构；
- EM-PCA 在秩正确（k=4）时做到 **0.00831**，SoftImpute 是 **0.00857**，都把误差砍掉四成以上；
- 但秩猜错时剧情反转：k=2 时 EM-PCA 误差 **0.01176**，k=40 时 **0.01375**，而 SoftImpute 不需要指定秩，全程 **0.00857**；
- 整块连续缺失（全市场连续 20~160 天没有数据）时，三种方法的块内 RMSE 全部落在 **0.0143~0.0153**，和低基线几乎没差别。

一句话：**低秩补全值不值得做，取决于缺失是不是随机散开的、以及你能否可信地定出秩。** 两条都不满足时，它不会比填均值更强。

## 二、实验设计与数据生成

我把因子收益设成 $4$ 个独立标准正态向量 $F$，载荷 $B$ 也是标准正态，低秩信号 $L=0.006\,FB^\top$；再叠加 $0.008$ 的独立噪声 $E$。每只股票的日收益标准差大约 1.4%，接近真实个股量级。测试格点是随机抽出的 10% 观测值，补全算法完全看不到它们。

```python
import numpy as np
rng = np.random.default_rng(20261124)
N, T, K = 240, 500, 4
F = rng.standard_normal((T, K))
B = rng.standard_normal((N, K))
LOW = 0.006 * (F @ B.T)          # 真低秩信号
R = LOW + 0.008 * rng.standard_normal((T, N))
test_mask = rng.random((T, N)) < 0.10   # 留出，永不参与拟合
```

三种基线各自代表一种常见思路：列均值填充（最简单）、EM-PCA（反复用当前低秩估计填补缺口，再做 k 阶 SVD）、SoftImpute（求解带核范数惩罚的矩阵补全问题，用奇异值软阈值迭代）。

SoftImpute 的更新只比 SVD 多一步软阈值，代码短得惊人：

```python
def softimpute(Z, mask, lam, max_iter=120, tol=1e-6):
    X = np.tile((Z*mask).sum(0)/np.maximum(mask.sum(0), 1), (Z.shape[0], 1))
    M = np.where(mask, Z, 0.0)
    for _ in range(max_iter):
        Y = M + X * (~mask)                 # 观测值 + 当前填补值
        U, s, Vt = np.linalg.svd(Y, full_matrices=False)
        Xn = (U * np.maximum(s - lam, 0)) @ Vt   # 核范数近端算子
        if np.linalg.norm(Xn-X)/np.linalg.norm(X) < tol:
            break
        X = Xn
    return X
```

$\lambda$ 不是拍出来的：我在训练观测里再切出 20% 做验证集，从 0.05 到 0.8 扫描后取验证误差最小者，10%/30%/50%/70% 缺失下分别选中 0.20/0.15/0.15/0.10。

## 三、误差如何随缺失率变化

上图里红线（列均值）几乎是一条水平线：缺失再少，它也只能把每只股票填成自己的均值，把横截面的共同运动完全丢掉。蓝线（EM-PCA）和绿线（SoftImpute）随缺失率上升缓慢劣化，70% 缺失时分别是 **0.00866** 与 **0.00918**，仍比列均值低 37% 左右。

值得注意的是，SoftImpute 在所有随机缺失档位上都没有赢过秩已知的 EM-PCA。原因不复杂：真秩就是 4，直接告诉算法答案当然占优；核范数惩罚在收缩噪声奇异值的同时，也把 4 个真奇异值各压掉了 $\lambda$，属于用一点偏差换「不必知道秩」的自由。

![补全后矩阵的奇异值谱](/images/matrix-completion-factor-model/fig2_spectrum.png)

奇异值谱把这件事看得更清楚。真信号的 4 个奇异值是 2.251、2.123、2.054、1.956，后面全是 0。EM-PCA 硬截到 4 阶，前四个是 2.283、2.145、2.079、1.971，第 5 个 0.178 是吃进来的噪声。SoftImpute 前四个降到 1.92~1.61，剩下的是 0.07~0.11 的噪声尾巴。最糟的是列均值填充：**0.311 的单一尖峰加一长串零**——每只股票每行都被填成同一个常数向量，补全结果人为变成 rank-1，后续任何基于协方差的推断都建立在假结构上。

![真实、观测与补全的热力图对比](/images/matrix-completion-factor-model/fig3_heatmap.png)

## 四、秩猜错时，软阈值才显出价值

真实研究里没人能拍着胸脯说因子个数就是 4。把 EM-PCA 的秩从 2 扫到 40，答案就变得有意思了：

![秩误设定下的表现](/images/matrix-completion-factor-model/fig5_rank_sweep.png)

k=2 欠拟合，误差 **0.01176**；k=4 最优 **0.00831**；k=6 略升到 **0.00854**；k=10 是 **0.00911**；k=20 **0.01043**；k=40 直接恶化到 **0.01375**，比列均值还好不了多少。SoftImpute 不动声色地停在 **0.00857**，比 k=4 的 EM-PCA 只差 3%，却比任何错误秩都稳。

这是核范数惩罚真正的卖点：它不是把噪声切掉，而是让数据自己决定有效秩。如果你有可靠的因子个数先验（比如 Barra 的十大风格因子），EM-PCA 更准；如果因子个数本身是研究对象，软阈值更抗犯错。

## 五、协方差与组合：补全到底赚在哪

补全的终点往往不是「把空格填满」，而是估一个能用的协方差。我用前 400 天估协方差，在独立生成的后 300 天上检验长仓最小方差组合：

![整块缺失与组合波动](/images/matrix-completion-factor-model/fig4_block_and_portfolio.png)

等权组合与列均值填充得到的组合波动都是 **0.000810**——列均值把矩阵压成 rank-1，优化问题退化成等权。EM-PCA 和 SoftImpute 都是 **0.000526**。更有意思的是用**完整真实收益**算出的协方差得到 **0.000627**，反而比补全版高 19%。

这不是代码错了。样本协方差把每只股票的特质噪声也当成「可分散的结构」估进权重，而未来 300 天的特质噪声与样本内那一批毫无关系；低秩截断恰好把这些不可预测的成分扔掉了。换句话说，这里赢的不是补全，而是**去噪**。当然，这是单次模拟、长仓约束下的结果，不该当成「补全一定跑赢完整数据」的普遍规律。

图的左半部分是反面证据：把某一段连续 20~160 天的全市场数据整块挖掉，块内 RMSE 对三种方法几乎一样（0.0143~0.0153），SoftImpute 对真信号的相对误差从 28.5% 单调涨到 59.8%。矩阵补全依赖「缺口周围有同一批横截面观测」这个前提；当整个时间片都空了，低秩结构无从对齐，算法只能给出时间上的平滑插值。真实市场里如果遇到长时间停牌或数据源整体中断，这个边界必须提前认清。

## 六、为什么随机散缺能补，整块缺失就不行

矩阵补全的可用信息不是「格子数量」，而是「同一时刻横截面上还有多少只股票在说话」。随机缺失 70% 时，每只股票平均还剩约 150 个观测日，而每天仍有约 72 只股票有报价；4 个因子的载荷可以从这些交叉观测里被反复约束住，所以误差只从 0.0083 缓慢升到 0.0092。整块缺失则把某一时间片的横截面整段拿走：那几天没有任何股票提供同时刻信息，低秩结构失去锚点，算法只能沿着时间方向做平滑外推。

这里的因子被设成逐日独立，是最不利于块缺失的设定；真实收益存在序列相关与动量，时间插值能救回一部分。但即便如此，块内估计的信噪比也和随机缺失完全不是一回事。诊断缺失 mask 的结构，比挑 $\lambda$ 更早一步决定方法能不能用。

还有一类常见误区是把「补全」等同于「提高预测精度」。补全恢复的是低秩共同成分，也就是本例中的 $FB^\top$；特质收益 $E$ 按定义不可从其他股票的收益里推出来，它恰好是补全误差的地板。留出 RMSE 在 0.008 附近不再下降，原因就是噪声本身的标准差正好是 0.008。任何声称把这类误差压到地板以下的回测，先查有没有信息泄漏。

## 七、和协方差清洗工具怎么分工

如果目标只是协方差估计而非补全面板，Ledoit-Wolf 收缩与随机矩阵去噪是更直接的对手：它们对样本协方差做结构化的收缩，不需要逐格填数。低秩补全的优势在于你**最终还需要一个完整矩阵**——比如要给停牌股估 beta、要把缺口喂给只接受完整输入的模型、或者要基于完整面板做主成分归因。三者不互斥：先补全，再做收缩，是常见流水线的两个不同环节。

组合层面的代价也不能忽略。补全与低秩截断都会让估计出的协方差更「干净」，从而给出更极端的权重；本文的最小方差组合加了长仓约束，样本外波动依旧低于用完整样本协方差算的版本。若换成允许做空的全局最小方差，低秩估计更容易因为遗漏尾部共动而给出隐藏的杠杆。风控上应把补全后的协方差当作「共同风险的描述」，而不是「全部风险的真相」。

## 八、怎么用在自己的面板上

实践里我会按这个顺序做：先按缺失的分布诊断——随机散缺可以补全，整块缺失只能靠时间维度信息或外部因子；再用验证集挑 $\lambda$，不要拿留出测试集反复调参；最后检查补全后矩阵的奇异值谱，如果前几个奇异值没有与后面的噪声带拉开断层，就别硬套低秩模型。对载荷矩阵有行业或风格先验时，把先验写进 EM-PCA 的秩选择通常比调正则强度更有效。

本文所有数字来自固定种子 20261124 的单次真值已知实验，代码用 numpy 实现，SVD 用 `np.linalg.svd` 全分解——240×500 的矩阵足够快，更大面板可换随机 SVD。
