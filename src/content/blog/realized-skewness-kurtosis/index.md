日度收益率的一阶矩和二阶矩是策略语言的全部词汇：收益、波动、Sharpe。但收益分布的三阶矩（偏度）和四阶矩（峰度）里藏着日度数据看不到的信息——Amaya、Bøhler、Ødegaard 和 Söderlind（2015）发现，用日内高频收益算出的**已实现偏度（RSK）能负向预测未来一周收益，已实现峰度（RTK）能正向预测未来波动**，且两者都不是已实现波动的代理。前者对应「彩票偏好」：近期经历过大幅单边上涨（高正偏）的股票被投机资金买高，随后回落；后者对应「不确定性」：日内出现极端波动的日子之后，波动率倾向于维持在更高水平。本文在合成市场里把这两条机制**植入进去**，然后检验估计量能不能把它们测出来。

## 一、合成市场：高频世界与两条植入机制

一只股票、1250 个交易日、每日 390 根 1 分钟 K 线。波动过程是 log 波动的 AR(1)（φ=0.98、日创新 0.09，日波动基准约 1.2%），日内叠一个 U 型季节因子（开盘收盘各有一个高斯峰，模仿真实的日内波动曲线）。跳跃强度 2%/日，跳跃日后聚集到 8%，跳跃幅度恒为负（−(0.003 + 0.002·|N|)，崩盘型）、与 1.2% 日波动同尺度。

两条机制是**植入**的，不是发现的：

- **RSK → 未来收益**：当日 RSK 每高 1 单位，未来 5 个交易日总收益被压 −0.4%（每日 −0.08% 分摊）。这是彩票需求通道；
- **RTK → 未来波动**：当日 RTK 相对经验基准（4.38，见下）每高 1 单位，log 波动获得 +0.025 的即时冲击，冲击按 AR(ρ=0.88) 衰减（半衰期约 5 日，正好覆盖 5 日预测窗）。

**先跑一个无机制对照世界**（同一条随机路径、两条机制强度设 0）：corr(RSK, 未来 5 日收益) = −0.0275，corr(RTK, 未来 5 日 RV) = −0.0432——纯噪声。这是本文的基准线：后面测到的任何相关性都必须显著超过它，否则就是运气。

![日度 RSK 与 RTK 序列](/images/realized-skewness-kurtosis/rsk_rtk_daily.png)

估计量本身（日内 n 根 bar）：

```
RSK = sqrt(n) · Σ r_i³ / RV^{3/2}      RV = Σ r_i²
RTK = n · Σ r_i⁴ / RV²
```

两个技术细节值得先说清楚。第一，**RTK 的无条件均值不是 3**：日内 U 型波动让各 bar 方差异质，E[n·Σr⁴/RV²] 被机械抬到 4.38（异质波动下 Jensen 不等式直接推出 >3）。用「3」当基准去解读 RTK 会系统性地高估「异常」——这是真实数据里也存在的陷阱。第二，RSK 与 RV 几乎正交（corr +0.013）：高阶矩测的是分布的**形状**，不是分布的**尺度**，这正是它能提供增量信息的前提。

## 二、RSK 预测收益：单调，但一年只有 60bp

把当日 RSK 分十档，看未来 5 日平均收益：D1（最低偏度）+1.00%，单调降到 D10（最高偏度）−0.25%，斜率 −8.2bp/十分位，整体相关 −0.062（t=−2.20）。控制住当日 RV 后回归，RSK 系数 −63.8bp/单位（t=−2.3）——高偏度周之后确实被系统性压回。

![RSK/RTK 十分位预测](/images/realized-skewness-kurtosis/predictive_bins.png)

幅度必须说实话：五分位 Q1 +0.495% vs Q5 −0.171%，周度价差 0.666%，年化约 35bp 的毛 edge。这个量级和真实文献一致（Amaya 等人的周度价差也在几十 bp），单股票上 RSK 是一个**真实但很小**的信号。深谷全部来自跳跃日：25 个跳跃日的 RSK 均值 −0.84，非跳跃日 0.00——偏度信号本质上是「崩盘探测器」，崩盘后的过度反应才是可交易部分。同一张图的右半是 RTK 五分位的未来一周收益：+0.19%/+0.22%/+0.28%/−0.16%/+0.29%，既无单调 pattern 也无稳定价差——峰度不带收益方向的信息，它带的是波动信息，这正是下一节的主题。

![RSK/RTK 五分位未来收益](/images/realized-skewness-kurtosis/quintile_spread.png)

机制上值得多想一步：为什么高 RSK 周之后会被压回？植入的版本里没有任何「交易者」，压回是外生的。真实市场里至少有两个候选解释——其一，近期大涨（高正偏）制造了彩票型回报，吸引投机性买盘把价格推离基本面，随后均值回复；其二，高偏度周的「赢家」吸引了事件驱动型资金（追涨、跟单），这些资金的持仓周期正好是一两周，退出时形成抛压。两个解释都预言同一个方向（负相关），但预言不同的持有期结构：如果是追涨资金退出，压回应该集中在第 3–10 个交易日；如果是彩票偏好消退，压回应该更平缓。把漂移按滞后天数拆开（每日 −0.08% 只是本文的简化植入），是真实数据上区分两者的标准做法。

本文做的是一只股票的时序版本。真实用法是截面版：对全市场每只股票算 RSK，做多低 RSK 组、做空高 RSK 组，每周调仓。截面版的优势是把市场共同波动消掉（RSK 与市场 beta 无关，组间差异更纯），代价是引入了横截面分散度的估计噪声——500 只股票各自的 RSK 标准误比单股票时序版本大得多，两边的信噪比权衡没有免费答案。

## 三、RTK 预测波动：原始相关会骗人，控制 RV 后才见真章

RTK 十分位 vs 未来一周已实现波动，原始相关只有 +0.072——因为**未来波动的 89% 由当前 RV 决定**（corr(RV, 未来 5 日 RV) = 0.894），RTK 那点增量信息被 RV 的巨大影子盖住了。把「当前 RV 可预测的部分」从未来波动里剔除后再看十分位：D10 的残差最高（+21e-6）、corr(RTK, 残差) = 0.21，回归里 RTK 的增量 t 值 **+7.7**——控制 RV 后，峰度是显著的波动率前瞻指标。

这个对比是本节最重要的结论：**判断高阶矩有没有用，不能看原始相关，必须看控制二阶矩后的增量**。原始相关小的原因恰恰是二阶矩太大，而不是信号不存在。真实数据里做 RTK 选股，如果忘记控制 RV，会得出「峰度无用」的错误结论。

## 四、抽样频率：信号衰减与噪声上升的拔河

高频矩的估计质量取决于抽样频率。从 1 分钟聚合到 5/15/30/60 分钟重算 RSK：与 1 分钟「真信号」的相关从 1.00 衰减到 0.65/0.58/0.55/0.41——粗抽样把日内路径磨平了，跳跃被摊薄；同时 mean|RSK|（噪声尺度）从 0.26 单调升到 0.97。预测力（corr with 未来收益）随之从 −0.062 衰减到 −0.038/−0.040/−0.015/−0.033——30 分钟处有一次明显跳水。另一端，1 分钟以下更密的抽样则会引入买卖价差弹跳之类的微观结构噪声，同样污染三阶矩。**5–15 分钟是这个市场的甜点区**，和真实文献的选择一致。

![抽样频率分析](/images/realized-skewness-kurtosis/sampling_frequency.png)

另一个反直觉发现：RSK 的 lag-1 自相关只有 −0.028——它近似白噪声。这意味着「高偏度」不会持续，每周重新排序是必要的，代价就是换手。

## 五、周频多空：毛收益可观，成本吃掉三成

按「本周平均 RSK 排序 → 下周持仓」做多空：做多偏度最低的 20% 周、做空最高的 20% 周（阈值用滚动 104 周分位数，无前视）。毛 CAGR +16.0%、SR 0.89，周均换手 30%。成本是生死线：单边 10bp/次降到 +12.5%/SR 0.73，30bp 只剩 +5.7%/0.39——高换手（白噪声信号的必然代价）把毛 edge 的约三分之二交给了交易成本。

还有一个执行细节：阈值用滚动分位数而非全样本分位数，是为了避免「用未来分布定今天阈值」的前视；前 26 周信号不足时空仓，这部分时间不贡献收益也不贡献成本。真实产品里这两件事经常被忽略——回测里美若天神的 RSK 因子，换成全样本分位数可能立刻缩水一半。

## 六、诚实声明与完整代码

两条机制（彩票需求反转、RTK→波动）全部植入，本文测的是**估计量能否恢复植入的机制**：单调性、控制二阶矩后的增量、抽样频率下的信噪比、成本后的残余。真实数据的 RSK/RTK 还要面对隔夜跳空、拆股分红、财报日聚集，以及最关键的——机制强度本身在不同股票、不同年份并不稳定。代码用 numpy 从零实现日内 bar 模拟与全部统计量：

```python
import numpy as np

n_days, bars = 1250, 390                       # 1250 日 × 390 根 1min bar
t = np.linspace(0, 1, bars)
seasonal = 1 + 0.9 * (np.exp(-((t - .02) / .06) ** 2) + np.exp(-((t - .98) / .06) ** 2)) - .15
seasonal /= seasonal.mean()                     # 日内 U 型

phi, sd_eta = 0.98, 0.09                        # log 波动 AR(1)
lv, sig = np.log(0.0006), 0.0
rsk = np.zeros(n_days); rtk = np.zeros(n_days); daily_ret = np.zeros(n_days)
drift_future = np.zeros(n_days)                 # RSK 播种的未来收益漂移
LAM_RSK, LAM_RTK, RHO_S = -0.004, 0.025, 0.88

for d in range(n_days):
    lv = np.log(0.0006) + phi * (lv - np.log(0.0006)) + np.random.normal(0, sd_eta)
    br = np.exp(lv + sig) * seasonal * np.random.standard_normal(bars)
    if np.random.random() < 0.02:               # 跳跃：恒负、聚集由简化处理
        br[np.random.integers(0, bars)] -= 0.003 + 0.002 * abs(np.random.standard_normal())
    rv = (br ** 2).sum()
    rsk[d] = np.sqrt(bars) * (br ** 3).sum() / rv ** 1.5
    rtk[d] = bars * (br ** 4).sum() / rv ** 2
    daily_ret[d] = br.sum() + drift_future[d]
    for k in range(1, 6):                       # 播种未来 5 日
        if d + k < n_days:
            drift_future[d + k] += LAM_RSK * rsk[d] / 5
    sig = RHO_S * sig + LAM_RTK * (rtk[d] - 4.38)   # RTK→波动信号，AR 衰减
```

复现要点：① RTK 的基准必须用经验均值（4.38）而非理论值 3，否则机制中心系统性偏移；② 波动信号要用 AR 衰减而非乘数复合——后者会让波动随机游走爆炸；③ 策略的「本周信号→下周持仓」结构差一天就是前视，周度对齐必须逐日核对。
