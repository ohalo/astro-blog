评价一个因子模型，标准动作是把资产收益对因子做时间序列回归，看截距项 alpha 显不显著。这条路有个绕不开的麻烦：alpha 的估计噪声很大，而且你对"用什么资产做检验"这件事的选择会直接改变结论。

Hansen 与 Jagannathan（1991）给了一条不需要任何均衡假设的路。他们问的是：**一个能把所有资产都定价的随机贴现因子（SDF）$m$，它必须"波动"到什么程度？**答案是一个不等式，违反它就是数学上不可能，跟模型流不流行无关。

## 一、SDF 与那条"不可能"的界

若资产超额收益向量为 $R^e$，$m$ 能定价它们的条件是 $\mathbb E[m R_i^e]=0,\ \forall i$。由柯西-施瓦茨不等式可以推出：对任意这样的 $m$，

$$\frac{\sigma(m)}{\mathbb E[m]}\ \ge\ \max_{w}\frac{\mathbb E[w'R^e]}{\sigma(w'R^e)}\ =\ \sqrt{\mu'\Sigma^{-1}\mu}$$

右边就是切线组合的最大夏普比率。含义极其直白：**SDF 必须至少和"你能造出的最好组合"一样波动**。如果某个候选 SDF 的比率低于这条界，它就不可能给这批资产定出价——不用跑任何回归，判定已完成。

三个细节值得说清：

- 候选 SDF 怎么造。给因子 $f$（超额收益形式），取 $m=1-b'f$，令 $b=\mathbb E[ff']^{-1}\mathbb E[f]$，就有 $\mathbb E[mf]=0$，因子自身的溢价被精确定价。
- **落在界以上不等于通过**。界是必要条件不是充分条件：比率够高只说明"没被数学排除"，定价误差可能依然很大。
- 本实验中 CAPM 的 SDF 比率在总体里等于市场夏普 0.1340，而总体界是 0.1969——CAPM 的 SDF 太"平滑"了，它不可能给这批资产定价。

顺带一条**可自查的恒等式**：对 $m=1-b'f$，总体里有 $\sigma(m)/\mathbb E[m]=S_f$，其中 $S_f$ 是因子切线组合的夏普比率。本实验 CAPM 的比率 0.1340 与市场夏普 0.1340 完全相等（不是凑巧，是恒等式）；三因子比率 0.2134 也等于三因子世界的因子切线夏普。所以"加因子能提高 SDF 比率"的另一面是"加因子提高了可达夏普"——两者是同一件事，别当成两个独立证据。

无约束最小方差 SDF $m^\ast=1-(\Sigma^{-1}\mu)'R^e$ 也有一条可以对拍的恒等式：它的比率应等于 $\sqrt{\mu'\Sigma^{-1}\mu}/(1-\mu'\Sigma^{-1}\mu)$。本样本 $0.2507/0.9372=0.2675$，实测 0.2676，$\delta$ 只剩 0.0149 的数值残差。写完代码先对这两条恒等式，比对着课本推公式快得多。

## 二、样本界会上偏：一个必须知道的陷阱

用 600 个月的样本去估 $\mu$ 和 $\Sigma$，再算 $\sqrt{\hat\mu'\hat\Sigma^{-1}\hat\mu}$，得到的不是 0.1969 而是 **0.2507，高出 27.3%**。原因和"样本内最大夏普被高估"完全同源：切线权重是朝着样本噪声优化出来的，$N/T$ 越大偏得越多。

后果很尴尬：**正确的三因子 SDF 比率在本样本里是 0.2040，低于样本界 0.2507，按"界以下即拒绝"它也会被判死**。所以样本界只能当描述性诊断，不能当检验——要检验就必须把它放回模拟分布里校准。

## 三、HJ 距离 δ：量"离可定价有多远"

给定候选 $m$，定价误差 $\alpha=\mathbb E[mR^e]$，HJ 距离定义为把这个误差补掉所需的最小修正幅度：

$$\delta=\sqrt{\alpha'\,G^{-1}\,\alpha},\qquad G=\mathbb E[R^eR^{e\prime}]$$

总体值（用 20 万个月的大样本近似）分层非常干净：CAPM **0.1467**、市场+规模 **0.0619**、三因子 **0.0080**、四因子 0.0080、五因子 0.0079——三因子之后加因子不再有任何改善，因为第四、第五个因子本来就是与资产无关的纯噪声。

可到了 T=600 的样本里，五个数全挤在 0.15 附近：CAPM 0.1961、两因子 0.1481、三因子 **0.1547**、四因子 0.1557、五因子 0.1542。原因是 δ 的噪声地板约为 $\sqrt{N/T}=\sqrt{12/600}=0.1414$，和 CAPM 真实误差 0.1467 同量级——你想测的东西和噪声一样大。

## 四、功效：δ 检验到底需要多少数据

正确的做法是：在"CAPM 成立"的世界里（把规模、价值溢价设为零）模拟 400 次得到 δ̂ 的零分布，再在真实三因子世界里模拟 400 次得到备选分布，看重叠多少。

结果是 T=600 时零分布 95% 分位 0.1827，真实世界里只有 **58.3%** 的样本能越过去——**用一个错误模型，你有四成机会检测不出来**。本样本的观测值 0.1961 恰好落在右尾（$p=0.020$），属于运气不错。作为对照，"界违反"检验（gap = 界 − SDF 比率）在同一批数据上功效 47.5%，观测 gap=0.1177（$p=0.028$）。

把样本长度拉长，功效立刻上来：T=1200 → δ 检验 90.0%、界违反 81.0%；T=2400 → 双双 100%。结论可以量化成一句话：**用 HJ 距离淘汰模型，50 年月度数据只有六成功力，100 年才够用，200 年才满格。**

把 T=600 放回现实语境：这大约就是 CRSP 1960 年代至今的月度样本长度，也是绝大多数因子实证论文的样本量。也就是说，文献里大量"δ 不显著、模型没被拒绝"的结论，很可能只是功效不足的另一种写法；反过来，本样本里 CAPM 的 $p=0.020$ 能拒绝，一半功劳在数据碰巧站在右尾。如果你的资产池更大（N 更大）或者只能拿到十年数据，那 δ 检验基本就是摆设——这时候更应该看的是 SDF 比率与界的**相对位置**（它对样本长度的依赖小得多），以及因子载荷本身的经济含义。

## 五、δ 随 N 膨胀：不能跨设定比大小

即使模型完全正确（就用三因子），样本内 δ 也随检验资产个数线性膨胀：N=4 时 0.0575、N=12 时 0.1235、N=30 时 0.2020、N=80 时 **0.3472**，几乎贴着理论地板 $\sqrt{N/T}$（0.0816 / 0.1414 / 0.2236 / 0.3651）。

这条曲线有个直接推论：**N=80 时，光是噪声地板（0.3472）就已经超过 CAPM 的真实定价误差（0.1467），检验彻底失效**。所以文献里不同论文的 δ 数值不能横向比较——N 和 T 不一样，数字就不是同一个东西。

## 六、长样本下：三因子见底，冗余因子不被惩罚

换到 T=4800 的长样本（噪声地板降到 0.05），δ 终于能读出结构了：CAPM 样本内 0.1422 / 样本外（后半段定 b）0.1345；两因子 0.0796 / 0.0746；三因子 0.0385 / 0.0372；四因子 0.0380 / 0.0382；五因子 0.0374 / 0.0355。到三因子就见底，之后既没改善也没恶化。

注意最后两个数：**加两个纯噪声因子，样本外 δ 不但没变差，还略好（0.0355 vs 0.0372）**。这是 HJ 距离的盲点——它只量定价误差，不惩罚"多估了一堆无用的因子暴露"。想抓这类过拟合，得去看样本外组合表现或因子载荷的显著性，δ 帮不了你。

![长样本下样本内/样本外 δ](/images/sdf-hansen-jagannathan/delta-in-out.png)

定价误差的来源也能直接验证：CAPM 的 α 对规模载荷 $B_{i,2}$ 回归，斜率 **0.00576**，几乎等于规模因子真实溢价 0.0050；CAPM 的 α 月度 RMS 是 0.465%，三因子降到 0.221%（后者基本就是纯估计噪声，$\mathrm{se}(\hat\alpha_i)\approx\mathrm{sd}(mR_i)/\sqrt T\approx0.2\%$）。所谓"异象"，很多时候只是遗漏因子的载荷在横截面上的投影。

这个分解对实盘的含义很直接：当有人拿"某组合有显著 alpha"当卖点时，先算一下它相对于你现有因子集的载荷是多少。本实验里 CAPM 的 alpha 几乎 100% 是规模与价值载荷的线性映射——**它不是超额收益，是没被对冲掉的因子暴露**。HJ 框架的好处就在这里：它把"alpha 是否真的存在"这个问题，翻译成"你的 SDF 有没有把这些载荷定价"，而后者可以用界和距离量化，不用靠显著性星星。

## 七、代码实现

```python
import numpy as np

def sdf_from_factors(R, F):
    """R: (T,N) 资产超额收益; F: (T,K) 因子（超额收益形式）
       构造 m = 1 - b'f（b 由 E[mf]=0 决定），返回定价误差、HJ 距离、SDF 比率"""
    T = len(R)
    Gff = F.T @ F / T
    b = np.linalg.solve(Gff, F.mean(0))       # 令 E[m f] = 0
    m = 1.0 - F @ b
    alpha = R.T @ m / T                       # E[m R^e]，N 维定价误差
    G = R.T @ R / T
    delta = float(np.sqrt(alpha @ np.linalg.solve(G, alpha)))   # HJ 距离
    ratio = float(m.std(ddof=1) / m.mean())   # σ(m)/E(m)，与 HJ 界比较
    return m, alpha, delta, ratio

def hj_bound(R):
    """HJ 界 = 切线组合最大夏普比率"""
    mu = R.mean(0)
    return float(np.sqrt(mu @ np.linalg.solve(np.cov(R.T), mu)))

# 最小方差 SDF（达到界的那一个）：m* = 1 - (Σ^{-1}μ)' R^e
lam = np.linalg.solve(np.cov(R.T), R.mean(0))
m_star = 1.0 - R @ lam
# 本实验：m* 的比率 0.2676，δ 0.0149（数值残差，理论应为 0）
```

## 八、落地清单与诚实边界

1. **界是必要非充分**。比率高于界 ≠ 模型可用，只是没被数学排除；要定量还得看 δ。
2. **永远别用样本界直接下结论**。本样本 +27.3% 的上偏足以把正确模型判死，必须做模拟校准。
3. **δ 必须在同 N、同 T 下比较**。它随 $\sqrt{N/T}$ 膨胀，跨论文比数字毫无意义。
4. **功效要先算**。50 年月度数据下 δ 检验只有 58% 功效，"没拒绝"不等于"模型对"。
5. **δ 不惩罚冗余因子**。想抓过拟合请配合样本外组合表现一起看。
6. **α 的绝对值没意义**。0.221% 的月度 RMS 在三因子下就是纯噪声水平，别把它当异象。
7. **本文所有数字都来自合成数据**。三因子结构是我植入的，所以"三因子最好"这一结论是同义反复；这些实验能验证的是**估计量的行为**（界的上偏幅度、δ 的噪声地板、功效曲线），不能验证任何真实市场里因子是否存在。
