## 一、结论先行

外汇期权看起来只是 Black-Scholes 把无风险利率换成两个：本币利率 $r_d$ 贴现，外币利率 $r_f$ 进漂移。真正让人栽跟头的不是公式，而是**你到底站在哪个测度上记账**。我把同一个 EUR/USD 欧式看涨期权（$S_0=1.10$，$T=1$，$r_d=4.5\%$，$r_f=2.0\%$，$\sigma=12\%$）用四条独立路径算了一遍：

- Garman-Kohlhagen 解析公式；
- 本币风险中性测度下的 40 万条蒙特卡洛；
- 外币测度下模拟倒数汇率 $X=1/S$ 的看跌期权，再用对称性换回本币看涨价；
- 对数价格空间上的 Crank-Nicolson 有限差分。

结果：7 个执行价（0.95 到 1.25）上，PDE 与解析解的最大偏差只有 **8.08e-07**（平值 0.065361 对 0.065361）；两条蒙特卡洛路径与解析解的最大偏离分别只有 **1.14** 和 **1.93 个标准误**。Put-Call 平价的解析误差是 **1.11e-16**，纯浮点舍入级别。

但同一个模型，只要把漂移里的利差写错——用 $r_d$ 代替 $r_d-r_f$——平值看涨价就从 0.06536 变成 0.07917，**虚高 21.1%**。这不是精度问题，是测度错误；回测里这种错误会伪装成「波动率估错了」。

## 二、模型：两个利率，两条测度

记 $S$ 为 1 欧元折合多少美元。在本币风险中性测度 $\mathbb{Q}_d$ 下，美元货币市场账户是 numéraire：

$$
\frac{dS}{S}=(r_d-r_f)\,dt+\sigma\,dW_d,
\qquad
C= e^{-r_dT}E^{\mathbb{Q}_d}[(S_T-K)^+].
$$

代入对数正态积分即得 Garman-Kohlhagen 公式：

$$
C=S_0e^{-r_fT}N(d_1)-Ke^{-r_dT}N(d_2),\quad
d_1=\frac{\ln(S_0/K)+(r_d-r_f+\sigma^2/2)T}{\sigma\sqrt{T}},\; d_2=d_1-\sigma\sqrt{T}.
$$

换到外币测度 $\mathbb{Q}_f$，以欧元账户为 numéraire，$X=1/S$（美元折欧元）的漂移变成 $r_f-r_d$。Radon-Nikodym 导数是

$$
\frac{d\mathbb{Q}_d}{d\mathbb{Q}_f}=\frac{S_0}{S_T}e^{(r_d-r_f)T}.
$$

把看涨 payoff 用 $X$ 改写并做测度变换，会得到一个干净的对称式：

$$
C(S_0,K;r_d,r_f,\sigma)=S_0K\,P^{\mathbb{Q}_f}\!\left(\tfrac{1}{S_0},\tfrac{1}{K};r_f,r_d,\sigma\right).
$$

这条式子不只是理论装饰：它给出一条**完全独立的数值路径**——模拟 $X_T=X_0\exp[(r_f-r_d-\sigma^2/2)T+\sigma\sqrt{T}Z]$，算外币看跌，再乘 $S_0K$。如果本币路径的随机数生成、贴现或漂移有任何一处写错，两条路径不会同时错成一样。

## 三、三路对拍与 PDE 的边界条件

对数价格 $x=\ln S$ 上的 backward PDE 是

$$
\partial_tV+(r_d-r_f-\sigma^2/2)V_x+\tfrac12\sigma^2V_{xx}-r_dV=0.
$$

Crank-Nicolson 把三对角系统写成 $(I-A)V^{n+1}=(I+A)V^n$，其中 $A=\tfrac12\Delta t\,L$。我在 $x\in[\ln0.55,\ln2]$ 上取 900 个空间步、1200 个时间步，两端用 GK 解析价做 Dirichlet 边界。这里有个容易忽略的实现坑：`solve_banded` 的上对角线偏移一格，第 $j$ 个内部点对上邻居的系数取 $c_{j+2}$ 而不是 $c_{j+1}$；我第一版写错一格，整个价格曲线被压低约 2 美分，而且**不报错**。诊断方法很简单：拿常数系数矩阵与显式 `np.linalg.solve` 对拍一次，差应为零。

两端之所以敢用解析 Dirichlet 边界，是因为 $\ln0.55$ 和 $\ln2$ 离执行价足够远：边界附近的期权要么几乎必然行权、要么几乎必然作废，用 GK 价格钉住它们不会把内部解往错误方向拉。若把区间缩到 $[\ln0.9,\ln1.2]$，边界刚好落在 payoff 的拐点附近，解析边界会把「外部区域的价值」硬塞进内部，误差反而随网格加密不收敛。这是有限差分里典型的「边界比格式更关键」：Crank-Nicolson 本身无条件稳定，但稳定不等于一致。

## 四、对偶变量省下的钱没你想的多

外汇期权 payoff 是凸的，教科书说对偶变量（antithetic variates）能降方差。实测：5 万、20 万、80 万条路径三档，朴素 MC 的标准误分别是 0.0004008、0.0002011、0.0001003；用 $Z$ 与 $-Z$ 成对、按**对均值**估计后是 0.0002745、0.0001384、0.0000690，稳定改善约 **1.45 倍**，而不是一些教程暗示的一个数量级。

这里也藏着一个统计坑：如果把 $[Z,-Z]$ 拼成一个长度 $n$ 的数组，再直接用 `std(p)/sqrt(n)` 算标准误，会得到和朴素 MC 几乎一样的数（比值 1.001），因为样本内标准差没有反映成对相关性。正确做法是先对每对取均值 $q=(P(Z)+P(-Z))/2$，再算 $q$ 的标准误除以 $\sqrt{n/2}$。成对收益的相关系数只有 −0.52，不是 −1，所以改善倍数天然有限。

## 五、利差先动远期，再动价格

固定 $r_f=2\%$，把 $r_d-r_f$ 从 −4% 扫到 +8%：远期 $F=S_0e^{(r_d-r_f)T}$ 从 1.0569 移到 1.1916，平值看涨价从 **0.03353** 升到 **0.10166**，接近三倍。所以外汇期权的「隐含波动率报价」必须同时说明远期——同一波动率、不同利率差下的 ATM 价格完全不同，直接拿本币股票期权的直觉去套会系统性错位。

把漂移误写成 $r_d$（漏掉 $r_f$）时，40 万条路径给出 0.07917，比正确价高 21.1%。Put-Call 平价 $C-P=S_0e^{-r_fT}-Ke^{-r_dT}$ 在这种错误下依然**在你的错误测度内部成立**，所以平价检查抓不到漂移错误；只有两条测度路径对拍或解析对拍才能抓到。

## 六、波动率微笑的蝶式陷阱

允许 $\sigma$ 随执行价变化后，静态无套利要求看涨价对执行价二阶导非负。我用两条微笑曲线各取 321 个执行价：平缓曲线 $\sigma(u)=0.12+0.10u+0.10u^2$（$u=K/S-1$），蝶式差最小值为 $5.51\times10^{-9}$，**没有**负节点；陡峭曲线 $\sigma(u)=0.12-0.08\tanh(u/0.05)+0.03u^2$，虽然波动率始终在 4.1%–20.5% 的合理区间，却有 **38 个节点**蝶式为负，最负 −0.0206。

换句话说，波动率数值看起来人畜无害，不代表报价能拼成合法密度。做外汇期权做市或校准时，先把蝶式检查写在插值之后、定价之前，比事后解释负概率便宜得多。

## 六点五、柜台说的 ATM 不是你以为的那个 ATM

外汇期权市场说「平值」时，通常指**远期平值**：$K=F=S_0e^{(r_d-r_f)T}$，而不是 $K=S_0$。本例 $F=1.1278466$，对应看涨价格 0.0515867、Delta 0.5135；如果按即期 $K=S_0=1.10$ 算，价格是 0.0653608、Delta 0.5938。同一个「平值波动率」挂在不同的执行价定义上，价格能差 0.0138，比本文整条微笑曲线造成的差别还大。

这也解释了外汇市场的 Delta 报价惯例：25Delta 看涨的执行价是 $K=1.22943$（价格 0.01868），并非某个漂亮整数；做市商用 Delta 而非执行价来定位报价，就是为了把不同利差的远期平移自动吸收掉。把股票期权「按行权价读波动率」的习惯搬过来，第一步就会错在 ATM 锚点上。

## 六点七、平价检查为什么抓不到漂移错误

Put-Call 平价的推导只需要 $C-P=e^{-r_dT}E^{\mathbb{Q}_d}[S_T-K]$，再要求 $E^{\mathbb{Q}_d}[S_T]=S_0e^{(r_d-r_f)T}$。如果你把漂移误写成 $r_d$，只要你在同一个错误模型里同时算看涨和看跌，平价依然成立——它检验的是**同模型内部的一致性**，而不是模型与市场的对应关系。这类检查的价值在于抓实现 bug（比如看涨和看跌用了不同的贴现因子），不在抓设定错误。

真正能抓测度错误的是外部锚：解析解、第二条测度路径，或者市场上可观测的远期点。实务里最省事的一条是拿银行给出的远期点反推 $r_d-r_f$，再把它代入漂移；本文两条蒙特卡洛路径之所以能互相验证，靠的也是它们对同一个利差给出了方向相反的敏感性。记住这条分工：**平价查 bug，双测度查设定，远期点查输入**。

## 七、可运行代码骨架

```python
import numpy as np
from scipy.stats import norm

S0, K, T, rd, rf, sig = 1.10, 1.10, 1.0, 0.045, 0.020, 0.12

def gk_call(S0, K, T, rd, rf, sig):
    d1 = (np.log(S0/K) + (rd-rf+0.5*sig**2)*T) / (sig*np.sqrt(T))
    d2 = d1 - sig*np.sqrt(T)
    return S0*np.exp(-rf*T)*norm.cdf(d1) - K*np.exp(-rd*T)*norm.cdf(d2)

# 本币测度：漂移必须是 rd-rf
z = np.random.default_rng(2026).standard_normal(400_000)
ST = S0*np.exp((rd-rf-0.5*sig**2)*T + sig*np.sqrt(T)*z)
mc_dom = np.exp(-rd*T)*np.maximum(ST-K, 0).mean()

# 外币测度：X=1/S 的漂移是 rf-rd，看跌乘 S0*K 换回本币看涨
XT = (1/S0)*np.exp((rf-rd-0.5*sig**2)*T + sig*np.sqrt(T)*z)
mc_for = S0*K*np.exp(-rf*T)*np.maximum(1/K-XT, 0).mean()

# Put-Call 平价（解析）
parity = S0*np.exp(-rf*T) - K*np.exp(-rd*T)
```

完整实验（含 Crank-Nicolson 三对角求解、对偶变量标准误、微笑蝶式扫描与全部图表）已随本文数值结果落盘。

## 八、边界与小结

三路一致只说明**实现**一致，不说明模型正确：GK 假设常数波动率与连续路径，真实外汇市场有微笑、跳空与流动性分层。本文的微笑实验正是提醒：可交易的报价先过静态无套利检查，再谈动态模型。

实用清单：（1）漂移里永远写 $r_d-r_f$，写完用两条测度对拍；（2）PDE 的带状矩阵索引用显式矩阵验一次；（3）对偶变量的标准误必须按对均值算；（4）报价插值后立刻查蝶式。做到这四条，外汇期权定价里最常见的四类静默错误就都能在上线前被抓住。最后提醒一句：本文所有数值都来自合成参数，真实市场的买卖价差、交割日的假期调整与掉期点报价规则会引入另一层误差，模型对拍再漂亮也只是把「实现错误」这一项排除掉，不能替代对市场数据的校验。
