做金融研究的人有个永远的痛：**没法对市场做实验**。想知道没有做市商的市场会怎样？不能真的把做市商全撤了。想知道提高一跳 tick size 的影响？不能拿真实的 A 股试。基于智能体的仿真（Agent-Based Model，ABM）就是干这个的——在代码里搭一个市场，放进去几种行为的交易者，让价格从他们的交互里「长」出来，然后拆开看每个零件的作用。这是量化风洞：撞坏了一辆，再撞下一辆。

本文用 numpy 从零实现一个事件驱动的限价订单簿（LOB）仿真：3000 步、一个标的、tick=0.01，四类 Agent——做市商、噪声交易者、知情交易者、动量交易者。我们问三个问题：价格发现是怎么发生的？经典的市场「风格化事实」能复现吗？最后是谁在赚谁的钱？

结论先放这：

**① 价格发现完全由知情者驱动**：完整模型里中间价与基本面价值的 RMSE 只有 **0.093**（约 9 个 tick），拿掉知情者后飙到 **69.26**——放大 **748 倍**，价格 essentially 与基本面脱钩；价差同时从 13.7 tick 涨到 31.6 tick。知情交易者不仅定价信息，还在顺带改善流动性。
**② 三大风格化事实全部复现**：收益厚尾（20 步聚合峰度 **2.63**，无知情者是 -1.64）、波动率聚集（|r| 滞后 1 阶自相关 **0.43**）、量价联动（20 步窗口 corr(已实现波动, 成交量)=**0.85**）。厚尾不是噪声本身——是跳变被知情者连续扫单 impound 的过程。
**③ 盈亏分解回到经典三段论**：按最终中间价平仓，做市商每股赚 **0.054**、知情者赚 **0.044**、噪声亏 **0.070**、动量亏 **0.051**，四方加总为零。做市商靠价差薄利多销，知情者赚信息租，噪声和动量是输血方。

## 一、市场设置：四类 Agent 与一个限价簿

限价簿用字典实现：`book[price] = [[agent, qty, side], ...]`，同价位 FIFO 队列。市价单从最优价位开始吃单，被动方（挂单方）同步记账——这一步是盈亏分解能对上的关键。

基本面价值 v 遵循**两状态波动 regime 的随机游走**（低波 σ=0.015 / 高波 σ=0.05，持续概率 0.99），外加 0.8% 概率的跳变（幅度 8 倍 regime 波动）。v 只有知情者看得见。

四类 Agent 每步依次行动：

| Agent | 行为 | 关键参数 |
|---|---|---|
| 做市商 | 撤掉旧报价，围绕 mid 挂双边（每侧 2 档、每档 10 股） | 半价差 = 1.5 + 2·波动率比 + 0.1·|库存| tick；库存偏移 0.1·库存 tick；库存超 ±150 抽掉被攻击的一侧 |
| 噪声交易者 | 8 个，泊松式市价单，方向随机 | 下单概率 0.30 + 0.45·波动率比，量 1–5 股 |
| 知情交易者 | 看得见 v 和盘口，只在覆盖价差后仍有赚头时下单 | v 超最优卖价 1 tick 以上才买，量 = min(25, 4·优势/tick) |
| 动量交易者 | 追 20 步中间价变动 | 变动超 6 tick 下单 5 股，冷却 10 步 |

做市商的三个细节值得说道：**价差随波动率走**（高波 regime 报宽价差，这是做市商的自我保护）；**库存偏移**（囤多了就压价出货、缺了就抬价收货，且偏移不超过半价差，避免白送）；**库存上限**（超限后抽掉会加重库存的那侧报价——流动性真空是真实的做市商行为）。

## 二、核心仿真循环

```python
book = {}                      # price -> [[agent, qty, side], ...]  FIFO
mid, v = 100.0, 100.0

for t in range(N_STEPS):
    # 1) 基本面：regime 切换随机游走 + 罕见跳变（仅知情者可见 v）
    if rng.random() > 0.99:
        vol_state = 1 - vol_state
    sig = [0.015, 0.05][vol_state]
    v += (8 * sig * rng.normal() if rng.random() < 0.008 else sig * rng.normal())

    # 2) 做市商撤单重报：围绕 mid 挂双边，价差随波动与库存走
    for p in [p for p, q in book.items() if q and q[0][0] == "mm"]:
        book[p] = [o for o in book[p] if o[0] != "mm"]
    inv = pos["mm"]
    half = 1.5 + 2 * sig / 0.02 + 0.1 * abs(inv)          # 单位：tick
    skew = min(max(0.1 * inv, -(half - 1)), half - 1)      # 库存偏移，不超半价差
    if abs(inv) < 150:                                     # 库存上限：超限抽单
        for lvl in range(2):
            book.setdefault(round((mid + (half + 2*lvl) * 0.01 - skew*0.01)/0.01)*0.01,
                            []).append(["mm", 10, "ask"])
            book.setdefault(round((mid - (half + 2*lvl) * 0.01 - skew*0.01)/0.01)*0.01,
                            []).append(["mm", 10, "bid"])

    # 3) 噪声交易者：泊松市价单，高波动时更活跃
    for i in range(8):
        if rng.random() < min(1.0, 0.30 + 0.45 * sig / 0.02):
            market_order("noise", "buy" if rng.random() < 0.5 else "sell",
                         int(rng.integers(1, 6)))

    # 4) 知情交易者：v 超过最优卖价 1 tick 才动手
    ba, bb = best_ask(), best_bid()
    if v - ba > 0.01:
        market_order("informed", "buy", min(25, max(1, int(4 * (v - ba) / 0.01))))
    elif bb - v > 0.01:
        market_order("informed", "sell", min(25, max(1, int(4 * (bb - v) / 0.01))))

    # 5) 动量交易者：追 20 步变动，带冷却
    if len(mid_hist) >= 20 and t - last_mom >= 10:
        if mid - mid_hist[-20] > 0.06:
            market_order("momentum", "buy", 5); last_mom = t
```

`market_order` 从最优价位逐档吃单，**同时更新攻击方与被动方的 cash 和持仓**——被动方记账是大多数自制 LOB 会漏掉的一步，漏了它做市商的盈亏永远算不对。

## 三、价格发现：一次跳变的慢动作

图 1 是仿真里最大的一次跳变（t=2591，Δv = -0.61，约 61 tick）。跳变前 mid 贴着 v 走；跳变发生的瞬间，mid 还在原地——**只有知情者知道世界变了**。接下来大约二三十步里，mid 以每步几个 tick 的速度向下追赶，直到重新咬住 v。这段追赶就是价格发现：信息没有「瞬间」进入价格，它是被知情者的订单一单一单砸进去的。

量化它：完整模型的 RMSE(mid−v) = **0.0926**（约 9 tick，与半价差同量级——这是做市商报价宽度的自然下限）；无知情者变体 **69.26**（价格 essentially 是绕原地的随机游走，与 v 完全脱钩）；浅簿变体（做市商深度 10→5）**15.29**（薄簿放大滑点，间接拖慢发现）。注意无知情者时价差反而更宽（31.6 vs 13.7 tick）——**知情者的存在本身就在收窄价差**：价格信息效率越高，做市商越不需要用宽价差自保。

## 四、风格化事实：厚尾、聚集、量价联动

ABM 的试金石是能否复现真实市场的「风格化事实」。三个都复现了：

**厚尾**：完整模型单步收益峰度 **1.15**（正态为 0），20 步聚合 **2.63**。来源不是噪声——噪声本身近似对称薄尾，无知情者变体的 20 步峰度是 **-1.64**。厚尾是**信息冲击的印记**：跳变发生后，知情者连续大单扫单（最多 25 股/步），把一次 61 tick 的跳变拆成十几个 4–6 tick 的大步——单步大变动在时间上聚集，统计上就是厚尾。没有知情者，跳变永远不会进入价格，自然也没有胖尾。
**波动率聚集**：|r| 滞后 1 阶自相关 **0.43**、5 阶 **0.27**。来源是 regime 切换（平均持续 100 步的平静段与爆发段交替）叠加跳变聚集。
**量价联动**：低波 regime 每步成交 19.4 股、高波 26.8 股；20 步窗口 corr(已实现波动, 成交量) = **0.85**。价差同步联动：低波段 10.3 tick、高波段 19.6 tick。

## 五、消融与盈亏：谁在赚谁的钱

图 5 左边是消融：拿掉知情者，价格发现误差放大 748 倍；拿掉动量，误差反而略降（0.076 vs 0.093）——**动量交易者对价格发现只有轻微的干扰**，它的主要戏份在盈亏表上。右边是盈亏分解（按最终中间价平仓，四方加总严格为零）：

- **做市商 +0.054 元/股**（合计 +3581）：价差 capture 扣除被知情者逆向选择的成本后仍为正，靠 6.7 万股的大成交量薄利多销；
- **知情者 +0.044 元/股**（合计 +411）：信息租，只交了 9303 股的「学费」就赚走 411 元；
- **噪声 -0.070 元/股**（合计 -3909）：为流动性支付过路费，教科书式的 spread-crossing 成本；
- **动量 -0.051 元/股**（合计 -82）：追涨杀跌，在高波 regime 里被两头打。

做市商的库存始终有界（最大 |库存| 77 股、均值 16.5），说明「价差放大 + 库存偏移 + 超限抽单」三件套足以控住库存——这也是真实做市商的风控骨架。

## 六、诚实结论：这个风洞的边界

**这个模型没有的**：Agent 不学习（没有根据盈亏调整策略）、没有订单分割与算法单、没有跨资产、没有信息扩散的动态过程、单一标的没有基本面盈余。**所以它证明的不是「市场就是这样」，而是「这些机制足以产生这些现象」**——价格发现不需要任何中央计划者，只需要一类知道更多的人和一类提供流动性的人；厚尾不需要「市场恐慌」这种宏大叙事，跳变加上快速套利就够。

**参数是敏感的**：调参过程中我们见过做市商库存死亡螺旋（价差爆炸到 621 tick）和动量正反馈（价格单向熔断），都是把库存控制调弱的结果——ABM 的结论永远绑定在参数邻域里，换组参数要重跑。这正是 ABM 该有的样子：它不是解析解的替代品，而是「如果机制是这样，那么现象会是那样」的可执行思想实验。
