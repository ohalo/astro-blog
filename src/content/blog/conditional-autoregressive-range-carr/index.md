## 一、结论先行

每天的 K 线里藏着一个比收盘价信息量更大的数字：最高价减最低价。它记录了当天多空双方实际推到的边界，而不是只记录了最终停在哪里。本文用真值已知的合成数据把这件事的收益和边界都算出来。

先说收益：从 96 个日内价格快照构造的 Parkinson 波动估计，标准差是收盘到收盘收益绝对值法的 **0.473 倍**，方差只有 **0.224 倍**。同样一天的波动，用极差估要稳得多。

再说模型：把极差写成 CARR(1,1)，用指数分布拟极大似然（QMLE）拟合。真值 $\alpha=0.12$、$\beta=0.83$ 时，120 次重复的平均估计是 $\hat\alpha=0.1197$、$\hat\beta=0.7865$，看起来不错；但截距 $\omega$ 平均估到 **0.2207**（真值 0.1445），标准差 **0.2317**，和 $\beta$ 严重此消彼长。

最后说风险：样本外次日极差预测的 QLIKE，CARR 是 **1.2777**，收益上的 GARCH(1,1) 是 **1.2801**，滚动 20 日均值 **1.3114**。CARR 确实最好，但差值只有约 **1.1 个 bootstrap 标准差**，远谈不上压倒性。更关键的是隔夜跳空：当 5% 的交易日埋进 5% 幅度的跳空，只看日内极差的 CARR 把 99% VaR 违约率放到 **2.6%**，而看收盘收益的 GARCH 是 **1.37%**，目标都是 1%。

**极差适合「现在有多波动」，不适合单独承担「明天会亏多少」。**

## 二、CARR 到底在建模什么

经典 GARCH 写的是收益平方的条件方差；CARR（Chou, 2005）写的是**极差本身的条件均值**：

$$R_t = \sqrt{\psi_t}\,\varepsilon_t,\qquad \psi_t=\omega+\alpha R_{t-1}+\beta\psi_{t-1},\qquad \varepsilon_t\sim\mathrm{Exp}(1)$$

指数分布均值为 1，所以 $E[R_t\mid\mathcal F_{t-1}]=\sqrt{\psi_t}$，而条件方差正好是 $\psi_t$。$\alpha+\beta$ 决定冲击衰减速度，本文设成 0.95。

一个极易踩的坑是**量纲**。如果把极差写成 0.017 这样的小数，$\beta\psi$ 的量级是 $10^{-4}$，而 $\alpha R$ 是 $10^{-3}$，两个系数根本不在同一尺度上，优化器会跑到边界并给出荒谬的 $\alpha\approx0.02$、$\omega$ 顶到上界。本文把极差统一用**百分数**（1.7 而不是 0.017），$\omega=0.1445$、$\alpha=0.12$、$\beta=0.83$，似然才正常收敛。

![模拟的极差路径](/images/conditional-autoregressive-range-carr/fig1_range_paths.png)

模拟里有个细节值得单独说：必须让**同一个**新息既生成当期极差，又进入下一期状态递推。我第一版用了两个独立的指数随机数，结果filter还原不出真状态（平均绝对偏差 0.60），参数估计系统性跑偏。修好反馈后，filter 与真状态的平均偏差降到 0.004。

```python
def sim_carr(n, omega=0.1445, alpha=0.12, beta=0.83, burn=200):
    psi = np.empty(n); R = np.empty(n)
    h = omega / (1 - alpha - beta)
    for t in range(n + burn):
        rt = np.sqrt(h) * rng.exponential()      # 当期极差（百分数）
        if t >= burn:
            psi[t-burn], R[t-burn] = h, rt
        h = omega + alpha * rt + beta * h        # 同一个 rt 反馈进状态
    return R, psi

def qmle_carr(R):
    def nll(th):
        w, a, b = th
        if w <= 0 or a < 0 or b < 0 or a + b >= 0.995:
            return 1e8
        psi = np.empty(len(R)); h = w / (1 - a - b)
        for t in range(len(R)):
            if t > 0:
                h = w + a * R[t-1] + b * h
            psi[t] = h
        return np.mean(0.5*np.log(psi) + R/np.sqrt(psi))
    return minimize(nll, [0.15, 0.12, 0.80], method="L-BFGS-B",
                    bounds=[(0.001, 10), (0.001, 0.45), (0.05, 0.98)]).x
```

## 三、参数能不能估准

![参数恢复与样本外预测损失](/images/conditional-autoregressive-range-carr/fig2_recovery_qlike.png)

左图是 120 次重复（每次 T=2000）的 $\hat\alpha$ 与 $\hat\beta$ 分布。$\alpha$ 的中枢贴着 0.12，但四分位区间约 0.09~0.14，标准差 **0.0493**；$\beta$ 均值 **0.7865**、标准差 **0.1462**，箱线图里有一串 0.4~0.6 的低估离群点。$\omega$ 的问题更严重：均值 **0.2207**、标准差 **0.2317**。

原因是近单位持续性下的「截距—持续性」交换：把 $\beta$ 调低一点、$\omega$ 调高一点，条件均值路径在有限样本里几乎不变。所以别把 CARR 的 $\omega$ 当成有经济含义的结构参数，真正稳定的是 $\alpha+\beta$ 和长期平均极差。

QLIKE 的选择也有讲究。这里比较的是条件均值预测，指数分布的对数损失 $\log m+R/m$ 在 $m=E[R]$ 处取最小值，因此低 QLIKE 直接对应「均值估得准」；如果换成平方损失，结果会被极差分布的右偏尾巴主导，排名可能完全不同。做模型比较前先确认损失函数与预测目标配套，否则赢了也不知道赢在哪。

右图是样本外结果：前 2000 天拟合、后 1000 天评估，三种预测都是「次日极差的条件均值」，损失用指数分布的 QLIKE（越小越好）。CARR **1.2777**、GARCH 经样本内尺度校准后 **1.2801**、无条件均值 **1.2802**、滚动 20 日均值 **1.3114**。CARR 对 GARCH 的平均差是 **−0.00233**，bootstrap 标准差 **0.00213**——方向对，但统计上只是弱证据。滚动均值明显最差，说明极差序列的持续性值得建模，但别指望换掉 GARCH 就能获得数量级提升。

## 四、区间为什么更有效，以及它什么时候失效

![Parkinson 与收盘收益的效率对比](/images/conditional-autoregressive-range-carr/fig3_efficiency_noise.png)

用 96 步布朗运动模拟 3000 天，每天同时算两个波动估计：Parkinson 的 $(H-L)/(2\sqrt{\ln 2})$ 和收盘收益绝对值。两者都有离散化偏差——Parkinson **−11.6%**，收盘法 **−19.8%**——但 Parkinson 的标准差是 **0.00342**，收盘法是 **0.00724**，比值 **0.473**。这就是「同样长度的历史，区间估计更稳」的量化版本：极差用了当天路径的极值，收盘法只用了两个点。

图中右半部分是它的软肋。给每个日内价格加扰动噪声，噪声从 0 升到 20bp 时，Parkinson 的相对偏差从 −11.6% 翻到 **+9.4%**——因为噪声会被当成新的极值记进 $H$ 和 $L$。低流动性股票、报价稀疏的品种，区间法反而可能比收盘法更脏。

![隔夜跳空下的 VaR 违约率](/images/conditional-autoregressive-range-carr/fig4_gap_var.png)

更根本的问题在隔夜。第四张图里，5% 的交易日有幅度约 5% 的隔夜跳空，但它发生在开盘之前，**当天的日内 $H-L$ 完全看不见**。用 CARR 的条件极差换算成波动再算 99% VaR，违约率是 **2.6%**；把跳空算进收益的 GARCH 是 **1.37%**；名义目标是 1%。CARR 违约更多不是因为模型拟合差，而是它的输入变量从定义上就不覆盖那部分风险。

## 五、为什么这是 QMLE，而不是严格极大似然

指数分布下的似然只用到条件均值 $\sqrt{\psi_t}$ 正确这一点。只要 $E[R_t\mid\mathcal F_{t-1}]=\sqrt{\psi_t}$ 设定无误，即使真实的极差分布不是指数（现实里它往往更接近 Weibull 或带阈值的伽马分布），拟极大似然估计量仍是一致的，只是不再是有效的。代价是常规优化器返回的 Hessian 标准误会偏，本文对样本外损失差异用的是 1000 次 iid bootstrap，不依赖似然曲率。

这也解释了为什么参数恢复里 $\alpha$ 的中枢对了、离散程度却不小：QMLE 放弃了分布形状里的信息，而极差序列的持续性又是有限样本里最难分辨的部分。如果愿意假设 Weibull 形状参数并联合估计，效率会提高，但对分布误设也更敏感——这是一个明确的权衡，不是「更贵的似然一定更好」。

## 六、离散化偏差怎么读

96 个日内快照构造的 Parkinson 估计有 −11.6% 的偏差，其中一部分来自极差不包括开盘前跳空，一部分来自离散采样没有覆盖两次快照之间的极值。采样越密，后者越小，但市场微观结构噪声越大——本文第四节里 20bp 噪声就足以把偏差从负翻成正，说明**提高采样频率不是无脑更优**。实务中的折中通常是 5~30 分钟频率，并用子采样或 pre-averaging 类方法压掉噪声；拿到不同频率的估计后，先在同一段历史上对拍它们的偏差方向，再决定用哪个做风控输入。

## 七、实操建议

如果把 CARR 用在实盘，我会这样分工：用极差做**日内或次日波动的 nowcast**，因为它在短周期上信息更足；用包含隔夜收益的收盘序列做**风险预算与 VaR**，或者至少在 CARR 的 VaR 上叠加一个跳空缓冲区。对于有夜盘、跳空常见的品种（个股财报、地缘事件驱动的商品），单独设一条隔夜风险线比调 $\alpha$、$\beta$ 有效得多。

还有一条容易被忽略的口径问题：极差要用对数价格的高减低差，而不是绝对价格差。低价股与高价股的绝对价差没有可比性；对数口径下 Parkinson 的 $2\sqrt{\ln 2}$ 常数才成立。本文用百分数表述 $\psi$，本质就是对数极差乘 100，换回小数时所有系数要同步换尺度——第一节提到的量纲坑正是从这里来的。

本文所有数值来自固定种子 20261124 的模拟：3000 天样本，2000/1000 训练测试切分，120 次重复的参数恢复，1000 次 iid bootstrap 配对损失。代码用 numpy 与 scipy 实现，没有调用任何 GARCH/CARR 现成包，便于核对每一步。

**方法没有免费午餐。** 极差用更多价格信息换了更低的估计方差，代价是对 microstructure noise 和隔夜跳空失去抵抗。知道它看不见什么，比知道它看得见什么更重要。
