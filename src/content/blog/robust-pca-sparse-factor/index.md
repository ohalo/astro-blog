## 一、结论先行

收益面板里最讨厌的不是「噪声大」，而是**少数条目特别大**：一次财报暴雷、一次指数调仓、一个错标的价格，会把整块协方差矩阵往后拽。普通 PCA 把这些孤立大值当成真实方差，于是所有股票的主成分载荷一起被污染。

我构造了一个 240 只股票 × 300 天的面板：真实结构是秩 4 的低秩因子收益 $L_0=A F^\top$，再往 1.2% 的条目（864 个格子）塞进幅度约 ±0.09 的稀疏跳变 $S_0$。观测 $X=L_0+S_0$。结果：

- 秩 4 普通 PCA 的低秩相对 Frobenius 误差 **0.2642**；
- 主成分追踪（Principal Component Pursuit, PCP）把误差压到 **1.16e-07**，稀疏项的检出精确率、召回率、F1 全部 **1.000**，864 个异常一个不多一个不少；
- PCP 只用 11 次增广拉格朗日迭代，约束残差 **6.10e-08**。

代价同样清楚：把 $\lambda$ 从理论值放大 8 倍，低秩误差反而升到 **1.2709**、F1 掉到 0.5331；再给面板叠加大幅密集噪声（日标准差 1%），PCP 误差 **0.8021**，反而输给 PCA 的 **0.3906**。PCP 不是「更稳健的 PCA」，它是**对不同噪声模型的另一种假设**。

## 二、为什么几个大格子能污染整个主成分

普通 PCA 求的是 $\min_{L:\operatorname{rank}(L)\le r}\|X-L\|_F^2$。平方损失对大残差极度敏感：一个 ±0.09 的跳变，相对典型因子贡献 0.01 的量级是 9 倍，它在 Frobenius 目标里的权重是普通条目的 81 倍。为了「照顾」这 864 个格子，前几个奇异向量会主动向它们倾斜。

数据说话：真实 $L_0$ 的前四个奇异值是 1.325/0.919/0.690/0.445，第五个起严格为零；观测 $X$ 的前四个被抬到 **1.342/0.949/0.739/0.497**，而且第五到第八个变成 0.360/0.356/0.346/0.336——本来不存在的「因子」凭空冒出来了。PCP 恢复出的 $L$ 奇异值则与真值逐位吻合，第五个起重新归零。

![奇异值](/images/robust-pca-sparse-factor/fig2_singular_values.png)

一个反直觉的观察：如果只想知道**哪些格子坏了**，直接对 $X-\hat L_{\text{PCA}}$ 取绝对值阈值，F1 也有 0.9948——864 个真异常全抓到，只多报 9 个假阳性。但这不代表 PCA 没问题：坏格子的位置抓到了，$\hat L$ 本身仍然歪了 26%，用它算出来的因子载荷和协方差照样不能用。「检出异常」与「恢复低秩结构」是两件事。

## 三、PCP：把问题写成凸优化

Candès 等人的主成分追踪把目标换成

$$
\min_{L,S}\ \|L\|_*+\lambda\|S\|_1\quad \text{s.t.}\quad L+S=X,
$$

其中 $\|L\|_*$ 是核范数（奇异值之和，低秩的凸松弛），$\|S\|_1$ 是元素绝对值和（稀疏的凸松弛）。它们对 $L$ 和 $S$ 的作用，相当于 Lasso 对稀疏系数的作用；理论保证在「低秩不强、稀疏不密」的条件下可以精确恢复，典型阈值是 $\lambda=1/\sqrt{\max(N,T)}$。本例 $N=240,T=300$，$\lambda=0.057735$。

实现用增广拉格朗日（inexact ALM），每轮两步 proximal 更新：

$$
L_{k+1}=\mathcal{D}_{1/\mu}\!\left(X-S_k+Y_k/\mu\right),\qquad
S_{k+1}=\mathcal{T}_{\lambda/\mu}\!\left(X-L_{k+1}+Y_k/\mu\right),
$$

$\mathcal{D}_\tau$ 是奇异值软阈值，$\mathcal{T}_\tau$ 是元素软阈值；随后 $Y\leftarrow Y+\mu(X-L-S)$，$\mu\leftarrow 1.6\mu$。本例 11 轮收敛，最终约束违例 6.10e-08。代码不到 30 行，唯一需要注意的是：奇异值阈值与 L1 阈值共用同一个 $\mu$，量纲必须先把 $X$ 的谱范数正常化到 1 附近，否则 $\mu$ 初值会把收敛拖到几百轮。

## 三点五、核范数为什么能代替秩

直接约束 $\operatorname{rank}(L)\le r$ 是非凸组合优化，想求出全局最优基本没戏。核范数 $\|L\|_*$ 是秩函数在谱范数单位球上的凸包：把目标换成它以后，问题变成标准凸优化，任意初值都收敛到同一个全局解。直观上，软阈值 $\mathcal{D}_{1/\mu}$ 把小奇异值直接抹掉、对大奇异值只做等量收缩，等价于「先猜秩、再平滑地惩罚猜错的那些方向」。

这也是 PCP 与迭代重加权 PCA 的根本差别：后者的权重是手工设定的启发式函数，靠残差大小猜哪里该降权；前者由优化问题本身决定哪些奇异值该留下、哪些格子该进稀疏项。代价是每次迭代都要做一次完整 SVD，240×300 的面板 11 轮在本机不到一秒，但放到上千只股票、十年日频的面板上就要考虑随机化 SVD 或分块策略。

## 四、污染比例扫描与一个失败基线

把跳变比例从 0 扫到 8%：PCA 的误差从 0 单调升到 0.1688 / 0.2811 / 0.4468 / **0.8196**（对应 0.5%/1.2%/3%/8%），PCP 在每一档都把误差压到机器精度附近，稀疏 F1 保持 1.000。这说明 PCP 的优势不是「调参调出来的」，而是异常稀疏散布时的结构性优势。

![恢复误差与污染敏感性](/images/robust-pca-sparse-factor/fig3_recovery_sensitivity.png)

我也试了更便宜的做法：迭代重加权 PCA——先用 PCA 取秩 4，再用残差的 Huber 权重把大残差降权、重新做加权 SVD。结果误差 **0.5237**，比普通 PCA 的 0.2642 还差一倍。原因很实际：这类权重是按**元素**给的，而主成分是整行整列的低秩结构；把坏元素连同它所在股票/日期一起降权，等于把真实因子信息也扔了。这个负面结果我保留在文章里：**不是所有「稳健版 PCA」都稳健**，低成本替代未必便宜。

## 五、λ 的两头都是坑

$\lambda$ 决定「多大的残差算异常」。太小，稀疏项会把低秩部分啃掉；太大，异常被留在低秩里。扫描 $c=\lambda\sqrt{\max(N,T)}$：

| c | 低秩误差 | 稀疏 F1 | 稀疏非零数 |
|---|---|---|---|
| 0.25 | 0.1113 | 0.9801 | 27409 |
| 0.5–4 | ≈0 | 1.000 | 864 |
| 8 | 1.2709 | 0.5331 | 455 |
| 16 | 1.4839 | 0.0069 | 4 |

$c=0.25$ 时非零数飙到 27409——算法把普通因子波动也当异常，抢走了 $L$ 的成分；$c=16$ 时只剩 4 个非零，真异常几乎全被吞进低秩部分。好消息是中间有相当宽的平台（0.5 到 4 都完美），这比很多需要精调的方法宽容；坏消息是平台宽度依赖稀疏幅度，实盘里跳变幅度小到与因子波动同量级时，平台会迅速收窄。

## 六、诚实边界：密集噪声下 PCP 会输

PCP 的标准模型假设**没有密集小噪声**：每一格要么属于低秩，要么属于稀疏。真实日收益显然不是这样。我给面板叠加独立高斯噪声（日标准差 0、0.1%、0.3%、1%），结果：

| 噪声标准差 | PCA 误差 | PCP 误差 |
|---|---|---|
| 0 | 0.2618 | ≈0 |
| 0.1% | 0.2889 | 0.0828 |
| 0.3% | 0.2982 | 0.2455 |
| 1% | 0.3906 | **0.8021** |

噪声到 1% 时 PCP 反过来明显劣于 PCA。原因是 PCP 被迫把密集噪声分给 $L$（增加秩、扭曲载荷）或 $S$（稀疏预算被海量小值耗尽），两头都不划算。真要用在实盘面板上，需要先做去噪/聚合（比如把日内收益聚合成周频、或对极小条目做硬阈值），再喂给 PCP；或者改用带噪声项的稳健矩阵分解变体。**「异常稀疏、常态小噪声」这两个假设必须同时成立**，只满足前者就上 PCP 是危险的。

## 六点五、稀疏项不一定是「坏数据」

我一直把 $S$ 叫异常，但在因子研究里它往往是有信息量的那一半：个股财报公布日的巨大跳空、指数纳入当天的被动买盘、停牌复牌的补涨，都是真实事件而非数据错误。把它们从 $L$ 里剥出来以后，可以单独做事件研究——本例恢复出的 $S$ 恰好就是 864 个注入点，没有一个把正常波动误判成事件。

更实用的顺序是：先看 $S$ 的时间分布是否集中在财报季、调仓日，再看这些点的横截面是否聚在同一行业。若 $S$ 均匀分布、幅度分布连续，那更可能是坏数据或模型失配；若 $S$ 成簇出现且对应公开事件，那它本身就是一个事件驱动策略的样本池。要注意的是，PCP 的稀疏项**没有统计显著性**——它只回答「哪些格子无法被低秩结构解释」，不回答「这些格子是不是可交易信号」，后续仍需事件研究的显著性检验与成本扣除。

## 七、可运行代码骨架

```python
import numpy as np

def pcp(X, lam=None, max_iter=500, tol=1e-7):
    if lam is None:
        lam = 1.0 / np.sqrt(max(X.shape))
    L = np.zeros_like(X); S = np.zeros_like(X); Y = np.zeros_like(X)
    mu = 1.25 / np.linalg.norm(X, 2)
    for _ in range(max_iter):
        M = X - S + Y / mu
        U, sv, Vt = np.linalg.svd(M, full_matrices=False)
        L = (U * np.maximum(sv - 1.0 / mu, 0.0)) @ Vt
        R = X - L + Y / mu
        S = np.sign(R) * np.maximum(np.abs(R) - lam / mu, 0.0)
        E = X - L - S
        if np.linalg.norm(E, 'fro') / np.linalg.norm(X, 'fro') < tol:
            break
        Y += mu * E
        mu = min(mu * 1.6, 1e8)
    return L, S

# 与普通 PCA 对比
U, sv, Vt = np.linalg.svd(X, full_matrices=False)
L_pca = (U[:, :4] * sv[:4]) @ Vt[:4]
```

## 八、小结

给量化面板做因子分析前，先问一句：异常是稀疏的还是密布的？稀疏（暴雷、错价、调仓）就用核范数 + L1 把 $L$ 和 $S$ 分开；密布（高频微观噪声、连续两只股票同涨同跌）先用去噪或协方差收缩，再谈低秩。本文给出的操作清单：（1）看奇异值谱，第五个起不该有值却冒出来，是污染信号；（2）$\lambda$ 从理论值 $1/\sqrt{\max(N,T)}$ 上下扫一档，别只跑一个值；（3）同时报告低秩误差和异常 F1，这两件事不能互相替代；（4）密集噪声超过千分之几时，老老实实退回 PCA 或改用带噪声项的变体。
