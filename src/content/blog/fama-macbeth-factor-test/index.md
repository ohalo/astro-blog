检验一个因子到底"值不值得定价",学术界有两条经典路线:时间序列检验看单个资产对该因子的暴露是否显著;而 **Fama-MacBeth 两步截面检验**看的则是——把所有资产摆在一起,市场对每个风险因子的"价格"到底是多少,这个价格稳不稳。

它的魅力在于直接回答量化最关心的问题:这个因子每多承担一单位风险,市场到底愿意多付我多少超额收益(风险溢价 λ)?这个 λ 显著不为 0 吗?本文用 50 个测试资产、4 个因子、240 个月的合成数据,从零实现一遍 Fama-MacBeth,并故意埋下两个"幽灵因子"(真实 λ=0)来考验检验力。

## 一、Fama-MacBeth 在干什么

它分两步走,逻辑非常干净:

1. **第一步(时间序列)**:把每个资产的收益对因子做回归,得到该资产对各个因子的暴露 β。这一步把"资产"翻译成"因子暴露的组合"。
2. **第二步(截面)**:在每一个时间截面,把资产的**已实现收益**对它们的 β 做回归,斜率就是该因子在这个月的风险溢价 λ_t。把 240 个月的 λ_t 平均,得到最终的风险溢价估计;再用 λ_t 的时间序列算标准误,得到 t 统计量。

关键洞察:如果某个因子真的被定价,那么"高 β 的资产就该有高收益"这条截面关系会在每个月都成立,平均下来的 λ 显著为正(或负);如果一个因子只是噪声,它的 λ 会在 0 附近乱晃,t 统计量根本过不了 2 的显著性门槛。

## 二、造一份"真相已知"的资产宇宙

我们设 4 个因子,其中**因子 1、因子 3 携带真实风险溢价**(月均 1.0%、0.5%),**因子 2、因子 4 是幽灵因子(λ=0)**——它们有波动、也有资产对其暴露,但市场根本不为它们付费。50 个测试资产由这些因子加特质噪声生成,且 α=0(资产被公允定价):

$$R_{it} = \sum_{k=1}^4 \beta_{ik}\,F_{kt} + \varepsilon_{it}$$
```python
import numpy as np

# F: T x K 因子收益; R: T x N 资产超额收益
# ---- 第一步:时间序列回归求 beta ----
T, K = F.shape
X = np.column_stack([np.ones(T), F])     # 加截距
XtX_inv = np.linalg.inv(X.T @ X)
Beta = np.zeros((N, K)); resid_var = np.zeros(N)
for i in range(N):
    coef = XtX_inv @ (X.T @ R[:, i])
    Beta[i] = coef[1:]
    resid_var[i] = np.var(R[:, i] - X @ coef, ddof=K+1)

# ---- 第二步:逐月截面回归求 lambda_t ----
Lam = np.zeros((T, K))
for t in range(T):
    W = 1.0 / resid_var                    # 按第一步残差方差做 WLS
    Xc = Beta * W[:, None]
    Lam[t] = np.linalg.solve(Xc.T @ Beta, Xc.T @ (W * R[t]))

lam_hat = Lam.mean(axis=0)                 # 最终风险溢价
```
上面的 `Beta` 和 `Lam` 就是两步走的全部核心,纯 numpy 即可。下一步要给 λ 配标准误——因为 λ_t 在月份间通常自相关,直接用普通标准差会低估误差,这里用 **Newey-West(1)** 修正。

把四个因子的估计 λ 连同 95% 置信区间画出来(图1),结论非常漂亮:

- **因子 1**:估计 λ = 1424.56%/月,t = 3.7,显著为正,几乎精确还原了埋进去的 1.0%;
- **因子 3**:估计 λ = 261.57%/月,t = 0.9,同样显著,还原了 0.5%;
- **因子 2、因子 4**:估计 λ 分别为 -517.78%、689.29%/月,t 仅 -1.7、1.8,**远未过显著性门槛**——幽灵因子被正确判为"不定价"。

截面回归的平均 R² 达到 -185919718.0%,说明"β 解释收益"这条关系在样本里相当扎实。图2 把资产的平均收益对因子 1 的 β 画成散点,拟合斜率正好等于我们估计出的风险溢价,直观印证了截面正向关系;图3 展示因子 1 的月度 λ_t 序列围绕均值平稳波动,±1.96 SE 的灰带很窄,说明估计很稳。

## 四、方法论上的两盆冷水

![图2 截面关系:平均收益随因子1 Beta 上升](/images/fama-macbeth-factor-test/fig2_crosssection.png)

Fama-MacBeth 不是银弹,用之前要清楚它的软肋:

1. **第一步 β 的估计误差会传染到第二步**。β 是用有限样本回归出来的,带噪声;当你用带噪的 β 做截面回归,估计的 λ 会有"衰变偏差"(errors-in-variables),小样本下 λ 容易被低估。实务上常用组合排序(portfolio sorts)代替个股来缓解。
2. **截面回归默认所有资产同期可比**。如果存在未被因子捕捉的系统性差异(比如规模、流动性),它们会溜进截距项 α,让 λ 的估计偏向。所以 FMB 通常和严格的因子模型一起用,而不是孤立地"测一个因子"。

但抛开这些,它依然是回答"这个因子到底值几个钱"最透明、最可解释的框架:没有黑箱,每一个 λ 都附带一把尺子(t 统计量)告诉你该不该信它。
