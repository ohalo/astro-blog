资产配置的第一性问题不是"买什么"，而是"这些资产到底是不是同一回事"。你以为分散买了 20 只股票，结果全是同一个板块，涨一起涨跌一起跌——名义上的分散，风险上根本没分散。要解决它，得先把资产按相关性**聚类**，再从每个簇里各挑代表。

常见做法是 K-means 或层次聚类，但它们各有毛病：K-means 要你先拍脑袋定 K，还对异常点敏感；相关矩阵热力图在资产一多时就糊成一块。最小生成树（Minimum Spanning Tree, MST）提供了一条更干净的路：把相关矩阵变成一张带权距离图，**只保留把所有人连起来所必需的最短边**，形成一棵树。树的结构本身就暴露了资产的亲缘关系——抱得紧的自然聚在一起，跨板块的连接只能靠少数几条长边。切断这几条长边，簇就自动浮出来了。

本文用纯 Python + numpy 完整走一遍：从相关距离的定义、Kruskal 算法从零建树，到用经典多维缩放（MDS）把树画出来，再到用簇结构做一个真正分散的组合。所有数值都是脚本实跑的。

## 一、从相关系数到距离图

聚类的第一步是把"相关性"翻译成"距离"。相关系数 $\rho$ 越大表示越像，但聚类算法吃的是距离——越像距离越小。标准转换是：

$$
d_{ij} = \sqrt{2(1-\rho_{ij})}
$$

这个式子有几何意义：如果把每只资产看成单位向量，相关就是夹角余弦，$d$ 正是它们在高维空间里的欧氏距离。完全相关 $\rho=1$ 时 $d=0$，完全无关 $\rho=0$ 时 $d=\sqrt{2}$，负相关更远。

我造了一个 known-truth 的市场：4 个板块、每板块 8 只、共 32 只资产，板块内相关 $\rho_{in}=0.70$、板块间 $\rho_{out}=0.10$，用 Cholesky 分解生成 1200 天收益。前 800 天训练、后 400 天测试。真实标签就是板块编号——这样我们能客观检验 MST 有没有把板块重建出来。

![训练期相关矩阵与相关距离](/images/minimum-spanning-tree-clustering/01_correlation.png)

上图按板块排序后，相关矩阵呈现清晰的 4 个红色方块（块内 0.70），块间只有 0.10 的浅色；距离矩阵则相反，块内距离小（深紫）、块间距离大。这就是 MST 要处理的输入：一张"块内紧密、块间疏远"的图。

## 二、Kruskal 从零建树

最小生成树是一棵连接所有 $n$ 个节点、却没有回路、且总边权最小的树，恰好 $n-1$ 条边。我用 Kruskal 算法从零实现，不依赖 networkx：

```python
all_edges = sorted([(i, j, D[i,j]) for i in range(N) for j in range(i+1,N)],
                   key=lambda e: e[2])
parent = list(range(N))          # 并查集
def find(x):
    while parent[x] != x:
        parent[x] = parent[parent[x]]
        x = parent[x]
    return x
mst = []
for i, j, w in all_edges:        # 从小到大取边
    if find(i) != find(j):       # 不成环才加入
        parent[find(j)] = find(i)
        mst.append((i, j, w))
```

核心就一句：**按边权从小到大贪心取边，用并查集跳过会形成环的边**。32 个节点得到 31 条边。

关键观察来了。这 31 条边里，**90.3% 连接的是同板块资产**；板块内边的平均权重是 0.742，而跨板块边高达 1.287——差了近一倍。换句话说，MST 几乎不浪费边去跨板块，只有实在没法时才用长边把不同板块接起来。这些长边正是天然的簇边界：把最长的 $K-1=3$ 条边切断（权重 1.278 / 1.286 / 1.299），树就裂成 4 个连通分量，恰好对应 4 个板块。

这个性质非常实用：层次聚类要你指定切在哪里，MST 的"最长边"自己告诉你切点在哪——**簇的数量和边界是从数据里读出来的，不是拍出来的**。

不过也要讲清 MST 的软肋，否则容易误用。第一，它本质上只保留每个节点的"最近邻"关系，对**链状结构**特别敏感：如果两簇之间恰好有几个"桥梁资产"把距离一点点拉近，MST 会用一串短边把它们连成一条链，此时按最长边切分就可能切错地方——这种情况下 average-linkage 层次聚类反而更稳。第二，MST 对距离度量的选择很敏感，用 $d=\sqrt{2(1-\rho)}$ 和用 $d=1-\rho$ 得到的树可能不同，实务中要结合领域知识定度量。第三，树强制每个节点只有"一棵生长方向"，无法表达一个资产同时属于多个板块的软归属——真要考虑这种交叉暴露，得用允许重叠的聚类或因子模型。认识到这些边界，才知道什么时候该用 MST、什么时候该换工具。

![最小生成树网络与切断的桥边](/images/minimum-spanning-tree-clustering/02_mst_network.png)

图里灰线是保留的边、橙色虚线是被切断的 3 条跨板块桥，节点颜色是真实板块归属。可以看到同色节点抱团、异色之间只靠几条橙线相连。图的坐标用经典 MDS 从距离矩阵算出——它让距离近的资产在平面上靠近，于是树的拓扑结构肉眼可读。

## 三、聚类质量与板块枢纽

切出来的 4 个簇和真实板块对照：Purity 和 Adjusted Rand Index 都是 **1.000**，完美重建。作为对照，层次聚类的 average-linkage 与 ward 方法在这份干净数据上同样是 1.000。这个结果要诚实解读：**当板块结构本身清晰时，三种方法都能恢复**，MST 的价值不在于"比别人准"，而在于它额外给了两样东西——**显式的簇边界**（最长边）和**网络拓扑**。

拓扑里最有用的是节点的**度**（连了几条边）。度数高的节点是板块的"枢纽"——它和板块内很多资产都保持了最短连接，最能代表这个板块的共同风险。本例四个板块的枢纽分别是 A2、A11、A19、A28（度数 4/4/3/3）。在实盘里，这类枢纽股往往是板块的领涨核心，也是板块风险传导的关键节点：它一动，整个板块跟着动。

![切断边阈值与板块枢纽](/images/minimum-spanning-tree-clustering/03_cluster_quality.png)

左图是 31 条边权的分布，红色虚线标出切断阈值 1.278——阈值右侧正好只有 3 条边，干净地分离出来。右图按板块排序画出每个节点的度数，能看到每个板块内部都有一个明显突出的高度数枢纽。

## 四、用簇结构做真正的分散

聚类本身不是目的，配置才是。我做一个朴素的实验：每个簇挑一只"离簇内其他资产平均距离最近"的代表股（medoid），4 只等权；对照组是随机选 4 只（重复 500 次取平均）和故意集中在同一板块选 4 只。三者都用训练期数据选股、测试期 400 天评估。

```python
def medoid_of_cluster(labels, D, k):
    idx = np.where(labels == k)[0]
    sub = D[np.ix_(idx, idx)]
    return idx[np.argmin(sub.sum(axis=1))]   # 到其他人距离和最小
reps = [medoid_of_cluster(labels_mst, Dtr, k) for k in range(K)]
```

结果验证了分散的价值：

| 组合 | 样本外年化波动 | Sharpe |
|------|------|------|
| MST 每簇代表（4 只） | **10.24%** | **0.98** |
| 随机选 4 只（500 次均值） | 12.01% | 0.66 |
| 集中同板块 4 只 | 16.85% | 0.25 |

MST 代表组合的波动比随机选股低 **14.7%**，比同板块集中组合低近四成；Sharpe 也从 0.66 / 0.25 提升到 0.98。逻辑很直白：随机选 4 只可能撞上同板块（相关性 0.70）而白白承担集中风险，而 MST 聚类强制你从 4 个低相关板块各取一只，把 $\rho_{out}=0.10$ 的分散红利吃满。

![样本外组合分散化效果](/images/minimum-spanning-tree-clustering/04_diversification.png)

要强调的是，这里的代表股是用**训练期**相关矩阵选的、收益在**测试期**评估，没有前视偏差；但合成数据里板块结构极其稳定，实盘中相关性会漂移、危机时还会集体趋近 1（"分散化在最需要时失效"）。所以别把 10.24% 当成实盘承诺——它证明的是"按簇分散确实比随机/集中更有效"这个方向，而非具体数字。

要在实盘用这套方法，还有几个工程细节。一是**滚动重建**：相关矩阵应该用滚动窗口定期更新，MST 的结构随窗口滑动而变化，簇边界的迁移本身就是有价值的信号——某个板块的枢纽股换了人，往往意味着板块内部的领导权在转移。二是**边权的稳定性**：可以对自己做 bootstrap 重采样，统计每条边在多少比例的样本树里出现，只保留高置信度的连接，避免被估计噪声带偏。三是**与因子模型配合**：MST 告诉你哪些资产"像"、可以互相替代，因子模型告诉你它们为什么像；把两者结合，既能在簇内做替代套利，又能控制住风格因子的暴露。这些都不改变本文的核心结论，只是把一个干净的实验室结果，逐步推向 messy 的真实市场。

## 结语

最小生成树把一团乱麻的相关矩阵，压缩成一棵只有 $n-1$ 条边的树：90.3% 的边留在板块内、最长三条边（约 1.28）自动标出跨板块边界，切断即得 4 个簇，Purity 与 ARI 都是 1.000。它不只是在做聚类——高度数节点告诉你谁是板块枢纽，树的拓扑告诉你风险如何传导。落到配置上，从每个簇挑一只代表股，样本外波动 10.24%，比随机选股低 14.7%、比集中持股低近四成。当板块结构清晰时 MST 不比层次聚类更准，但它给出的簇边界和拓扑信息，是后两者给不了的。这才是它在资产配置里真正的立足之地。
