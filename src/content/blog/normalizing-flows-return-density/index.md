量化研究里，我们对收益分布的建模长期在两难中摇摆。高斯模型干净、似然好算，但收益的尖峰肥尾、偏斜、以及「市场越慌波动越大」的异方差，它一个都抓不住。 Student-t 加个自由度能兜住肥尾，GARCH 能刻画时变波动，但都要你事先拍定结构——分布的形状是你假设出来的，不是数据学出来的。

**归一化流（normalizing flow）**提供了第三条路：不假设分布形状，而是学一个可逆映射 $f$，把一个简单的高斯噪声 $z\sim N(0,I)$ 精确变成复杂的真实数据 $x=f(z)$。因为映射可逆且雅可比行列式好算，你既能精确评估任意点的密度 $\log p(x)=\log p(z)+\log|\det J|$，又能从噪声一步采样出新样本。生成能力和密度评估兼得，这在深度学习模型里相当罕见。本文用纯 numpy 把 RealNVP 耦合层从零搭出来，看看它能不能把高斯噪声「揉」成有肥尾、会随市场压力变形的收益密度。

## 一、可逆映射与雅可比：归一化流的核心账本

归一化流的全部魔法压在一句话上——**变量替换公式**。若 $x=f(z)$ 是可逆光滑映射，$z\sim p_Z$，则

$$p_X(x)=p_Z(z)\left|\det\frac{\partial f}{\partial z}\right|,\qquad z=f^{-1}(x)$$

取对数：$\log p_X(x)=\log p_Z(f^{-1}(x))+\log\left|\det\frac{\partial f^{-1}}{\partial x}\right|$。**训练**时把数据 $x$ 沿逆映射推到 latent $z$（data → latent），最大化这个对数似然；**采样**时反过来从 $z$ 推回 $x$（latent → data）。

难点在行列式：一般神经网络的雅可比行列式计算是 $O(n^3)$，对高维数据不可承受。RealNVP 的巧思是设计一种**耦合层（coupling layer）**，让它的雅可比是三角矩阵，行列式退化成对对角元求和，复杂度瞬间降到 $O(n)$。

具体做法：把输入的高维向量劈成两半 $x=(x_1,x_2)$，只变换其中一半，且变换的参数只依赖另一半：

$$y_1=x_1,\qquad y_2=x_2\odot\exp\big(s(x_1)\big)+t(x_1)$$

因为 $y_1$ 原封不动、$y_2$ 的依赖里 $x_1$ 是「常数」，雅可比是分块下三角：

$$\frac{\partial y}{\partial x}=\begin{pmatrix} I & 0 \\ * & \mathrm{diag}(\exp(s(x_1))) \end{pmatrix},\qquad \log|\det J|=\sum_i s(x_1)_i$$

把多层这样的耦合堆起来、每层交换哪一半被变换（checkerboard 模式），就是 RealNVP。每层只改一半，但层层交替后每一维都被反复变换过，表达力足够拟合复杂分布。

## 二、数据：一个「压力越大越肥尾」的已知世界

为了让结果可验证，我们造一个真值已知的世界。市场压力指标 $x$ 在 $[-2,2]$ 均匀；收益 $r$ 以压力为条件：基准波动随 $x$ 线性放大（压力高时波动从 0.7% 升到 1.3%），另有 12% 概率的跳变成分（波动放大 2.6 倍并带偏斜）。这样 $r|x$ 同时具备**异方差、肥尾、偏斜**三个真实收益的典型特征。8000 条训练、2000 条测试。

![合成数据：条件于压力的异方差肥尾收益](/images/normalizing-flows-return-density/01_data.png)

真实收益的峰度是 **4.10**（高斯为 0，Fat tail 明显），99% 分位数 -3.59%、99.5% 分位数 -4.49%。任务就是让流从这堆样本里把这套结构自己学出来。

## 三、搭建 RealNVP：有界耦合，稳定可逆

数据先做二维标准化。我们的耦合层用 4 层 checkerboard，待变换维由 partner 维的 $\tanh$ 多项式驱动：

```python
def phi(p):
    h = np.tanh(p)
    return np.stack([h, h**2, h**3, np.ones_like(p)], axis=-1)

def forward_logp(D, params):      # data -> latent
    z, logdet = D.copy(), 0
    for l in range(NL):
        d, part = l % 2, 1 - (l % 2)     # 交替变换第 0/1 维
        P = phi(z[:, part])
        s = 2.0*np.tanh(P @ params[l, 0])
        t = 3.0*np.tanh(P @ params[l, 1])
        z[:, d] = (z[:, d] - t)*np.exp(-s)
        logdet += -s
    logp = -0.5*(z**2).sum(1) - np.log(2*np.pi) + logdet
    return logp, z
```

**一个关键的稳定性教训**：初版用 $s,t$ 直接线性依赖于 partner 的原始 polynomial（$p,p^2,p^3$），训练时数据有界还算正常，但从高斯 latent 采样时偶尔抽到大的 $z$，三次项立刻爆炸——采出的收益标准差 0.026 对真值 0.013、峰度飙到 6 万，彻底失真。改成对 partner 先取 $\tanh$（有界）、再对 $s,t$ 输出也套 $\tanh$ 后，变换处处有界，采样分布立刻回到正轨。这提醒我们：**可逆流训练时只看数据分布，采样时却要面对 latent 的全部尾部**，映射必须在数据_SUPPORT 之外也表现良好。

## 四、结果：似然、肥尾、可逆性三重验证

训练用 L-BFGS（中心差分梯度，400 次迭代）。三个维度交叉验证：

**其一，可逆性。** 把 2000 条测试数据推到 latent 再拉回来，最大重构误差 **3.9e-15**——机器精度级别，确认映射双向精确。这是「归一化」名副其实的前提。

**其二，样本外联合对数似然。** 在标准化空间，流的测试似然 **-2.5932**，Student-t（网格搜索自由度，最终 df=30）-2.7693，高斯 -2.7791。流比最好的参数化基线高出约 0.18 nat/样本，说明它学到的异方差与肥尾结构确实带来了实打实的密度改进，而非过拟合噪声。

**其三，采样还原分布。** 从流里采 8 万条收益：标准差 1.39%（真值 1.34%），峰度 **3.84**（真值 4.10，高斯 0），99% VaR **-3.44%**（真值 -3.59%），99.5% VaR -4.03%（真值 -4.49%）。肥尾被大体还原——注意峰度和极端分位数仍略偏低，这是流模型在尾部样本稀疏处的常见保守倾向，诚实披露比强行调参更重要。

![流 vs 基线的样本外对数似然](/images/normalizing-flows-return-density/03_fit_compare.png)

训练过程本身也值得盯一眼。L-BFGS 的负对数似然从初始的约 2.8 一路降到 2.61 附近，前 150 次迭代下降最快、之后逐渐趋缓——这是流模型典型的收敛形态：先把主体的方差和均值结构学对，再花剩下的迭代慢慢雕琢尾部细节。一个实用的诊断是检查 latent $z=f^{-1}(x)$ 是否真的接近标准正态：如果各维均值明显偏离 0 或方差偏离 1，说明变换还没把数据「压平」，继续训练或加层通常还有收益；如果 latent 出现系统性的偏斜或多重模态，则可能是耦合层数不够、结构不足以拆解数据的复杂性。这个「把数据变换成高斯」的目标，正是归一化流名字的由来——训练完成的标志，就是 latent 看起来像一堆无结构的标准正态噪声。

## 五、真正的杀手锏：直接吐出条件密度

前面这些，GARCH + Student-t 努努力也能做到八九成。归一化流真正的独门武器是**条件密度**：因为我们联合建模了 $p(r,x)$，固定任意一个 $x$ 再对 $r$ 归一化，就得到 $p(r|x)$，全程不用手写一行波动率方程。

把压力固定在 $x=-1.5$（平静）与 $x=+1.5$（高压），条件密度自动变形：平静时又窄又瘦、尾部轻；高压时明显变宽、尾部变厚。这个「波动随压力放大」的结构是模型从数据里自己发现的，不是我们告诉它的。对比之下，如果硬套一个只允许多元高斯的模型，无论 $x$ 怎么变，条件分布永远是一个高斯、只能靠手动加一个 $\sigma(x)$ 的函数来模拟异方差——而那个函数形式又得你来拍。

![流采样的收益边际与高斯对比](/images/normalizing-flows-return-density/04_marginal.png)

这一能力在量化里用途广泛：给期权定价用的是风险中性条件密度 $p(S_T|\mathcal{F}_t)$；给组合做场景生成要的是多资产的条件联合分布； taile risk 管理关心 $p(r|\text{压力})$ 的左尾形状。归一化流把这三个问题统一成「训练一个可逆映射，然后查条件密度」。

## 六、诚实的边界与工程取舍

归一化流不是银弹。首先，**可逆性约束是代价**：每一维都得被变换、雅可比得三角化，这限制了网络结构，表达力不如同等参数量的普通生成模型。其次，**高维密度估计本质上难**：维度越高，数据越稀疏，流需要更多层和更多数据才能学好尾部——本文 2D 是教学规模，几十维的真实资产组合要谨慎评估。第三，**训练要看住尾部行为**：如第二节的坑所示，必须在整个 latent 空间（而不只是训练数据覆盖的区域）保持映射有界，否则采样失真。

和竞品比一比定位：GAN 能生成高质量样本但**没有似然**、训练不稳；VAE 有似然但是**变分下界**、采样质量一般；归一化流**精确似然 + 精确可逆**，代价是结构受限、训练更挑。对量化而言，「能精确算密度」这一点权重极高——因为定价、风险度量、似然推断全都要密度值，而不只是样本。这是归一化流在金融场景里比在图像生成里更对味的原因。

## 七、完整代码骨架

```python
import numpy as np
from scipy.optimize import minimize

NL, NF = 4, 4
def phi(p):
    h = np.tanh(p)
    return np.stack([h, h**2, h**3, np.ones_like(p)], axis=-1)

def forward_logp(D, params):
    z, logdet = D.copy(), np.zeros(len(D))
    for l in range(NL):
        d, part = l % 2, 1 - (l % 2)
        P = phi(z[:, part])
        s = 2.0*np.tanh(P @ params[l, 0])
        t = 3.0*np.tanh(P @ params[l, 1])
        z[:, d] = (z[:, d] - t)*np.exp(-s)
        logdet += -s
    return -0.5*(z**2).sum(1) - np.log(2*np.pi) + logdet

def obj(flat, D):
    return -forward_logp(D, flat.reshape(NL, 2, NF)).mean()

res = minimize(obj, p0.ravel(), args=(Dtrain,), method='L-BFGS-B',
               jac='2-point', options={'maxiter': 400})
```

把 `Dtrain` 换成你自己的多资产收益面板、把维度从 2 扩到 N（checkerboard 掩码相应改成多维棋盘），就是一套完整的可学习收益联合分布。从高斯噪声出发，流经训练，最终吐出贴合数据的肥尾条件密度——这就是归一化流给量化研究者的礼物：**让数据的形状自己说话**。
