配对交易的标准动作是：找到一对协整资产 X 和 Y，用 OLS 估出对冲比例 β，然后交易价差 `Y - βX` 的均值回复。整套方法建立在一个默不作声的前提上——**β 是常数**。可真实市场里，两只票的联动关系会随流动性、成分股、行业景气度缓慢漂移。你三年前估的 β，今天可能已经差了 20%。用错误的 β 算价差，等于往价差里注入一条趋势，而"交易趋势的均值回复"是标准的亏钱姿势。

问题很清晰：**能不能在线追踪 βₜ，而不是一次性估一个常数？** 这正是 Kalman 滤波器的主场。本文把配对关系写成状态空间模型，从零实现滤波器，并回答三个问题：β 追踪能准到什么程度？估准了的价差真的能赚钱？OLS 类方法到底差在哪？

结论先放这：

**① OLS 类被"伪回归"污染，Kalman 把误差压掉两个数量级**：在 β 从 0.85 漂到 1.22 的合成协整对上，静态 OLS 估出 **β=-0.096**（RMSE 1.128，符号都是反的）、120 日滚动 OLS RMSE 0.486；Kalman 滤波器 RMSE **0.015**——分别小 76 倍和 33 倍。
**② 价差还原度是分水岭**：Kalman 滤波 spread 与真实 spread 相关性 **0.93**；OLS 类估出的"价差"与真实价差相关性只有 **0.08 / 0.10**，基本是噪声——信号在进入策略前就已经失真。
**③ 回测里 Kalman 几乎摸到 Oracle 上界**：z-score 回测（日波动目标 0.5%、5bps 换仓成本），Kalman 夏普 **2.92**、最大回撤 **-5.9%**，对比 Oracle（真实 β + 真实 spread）的 3.24 / -3.2%；滚动 OLS 夏普 **-0.07**，静态 OLS 只有 1.72 且在 30 条路径上离散度远大（2.13±0.34）。同期买入持有 X 的夏普只有 0.20。

## 一、把「β 会变」写进状态空间模型

教科书模型是 `yₜ = βxₜ + sₜ`，β 一个常数。我们把它升级成：

- **观测方程**：`yₜ = βₜ·xₜ + sₜ + εₜ`——当天的对数价格里，X 的贡献由当期 βₜ 决定，外加一个均值回复的价差 sₜ；
- **状态方程 1**：`βₜ = βₜ₋₁ + ηₜ`，ηₜ~N(0, q²)——对冲比例是随机游走，会漂移；
- **状态方程 2**：`sₜ = φ·sₜ₋₁ + νₜ`，νₜ~N(0, ν²)——价差是 AR(1)，φ=0.80 对应约 3.1 天半衰期。

这里有个**新手必踩的坑**：如果把 sₜ 当普通 iid 观测噪声（很多教程那么写），滤波器会把价差本身"滤掉"——我们实测过，那种设定下滤波 spread 的 AR(1) 半衰期只有 1.9 天，而真实半衰期是 3.1 天，且与真实 spread 的相关性仅 0.03：滤波器把慢变的价差成分统统倒进了 β 状态，残差变成白噪声，根本不存在可交易的均值回复。必须把价差的持续性（AR(1)）显式建模进状态，滤波器才知道"哪些偏离是暂时的（归 sₜ）、哪些是永久的（归 βₜ）"——**两种状态靠持续性差异被识别，这是整个方法成立的关键**。

换个角度说卡尔曼增益每天在做的判断：观测到 yₜ 后，新息 vₜ 有多大比例该记在"β 变了"账上、多大比例记在"价差波动"账上，取决于两个状态各自的预测不确定性。价差半衰期 3 天、β 以月为单位漂移，时间尺度差一个数量级，滤波器就能把两者分开。这也是为什么 β 越平稳、价差越持续，分离越难——本 DGP 特意把价差调得又宽（日冲击 5%）又快（3 天半衰期），让识别尽可能干净。

那 OLS 为什么不行？因为 xₜ 是单位根（随机游走），β 的漂移路径与 x 的路径相关，`Cov(x, β)≠0`，而 OLS 斜率 = `β + x̄·Cov(x,β)/Var(x)`——第二项就是伪回归偏差，量级可以到 O(1)。这不是"样本不够"，是估计量本身不一致。放到本例：静态 OLS 训练段（前 900 天）的平均 β 约 0.96，却估出了 -0.096；滚动 OLS 每一窗口内部同样中毒，120 天窗口的斜率标准差高达 0.5——你以为在跟踪 β，其实在跟踪噪声。

## 二、Kalman 滤波器：十行核心代码

状态 θ=[β, s]，观测矩阵 H=[xₜ, 1]。滤波器每个交易日做一次预测（状态按 F 演化、协方差加过程噪声 Q）和一次更新（按新息 v 和增益 K 修正）：

```python
import numpy as np

def kalman_pair(x, y, phi=0.80, nu=0.05, q_beta=1e-3, sig_eps2=1e-10):
    """y_t = beta_t*x_t + s_t;  beta 随机游走, s 为 AR(1) 价差"""
    T = len(x)
    th = np.array([1.0, 0.0])               # 状态初值 [beta, s]
    P = np.diag([0.05, 0.05])               # 协方差初值
    F = np.array([[1.0, 0.0], [0.0, phi]])  # 状态转移矩阵
    Q = np.diag([q_beta**2, nu**2])         # 过程噪声
    beta_hat = np.empty(T); s_hat = np.empty(T)
    for t in range(T):
        th = F @ th                          # ---- 预测 ----
        P = F @ P @ F.T + Q
        H = np.array([x[t], 1.0])            # 观测矩阵
        v = y[t] - H @ th                    # 新息
        S = H @ P @ H + sig_eps2             # 新息协方差
        K = (P @ H) / S                      # 卡尔曼增益
        th = th + K * v                      # ---- 更新 ----
        P = (np.eye(2) - np.outer(K, H)) @ P
        beta_hat[t], s_hat[t] = th
    return beta_hat, s_hat
```

全程只用当日及以前的数据，是在线因果估计。合成数据：1500 个交易日，X 日波动 1.5%，β 以每日 0.00025 的漂移加 0.0008 的噪声从 0.85 走到 1.22，价差 AR(1)（φ=0.80，日冲击 5%，半衰期 3.1 天）。

实现上有两个细节值得点出。其一，过程噪声 Q 里 ν² 用真实价差创新方差（可从残差 ACF 估计），q_β 则是唯一需要标定的超参，第五节专门讨论。其二，观测噪声 R 取 1e-10 近似为零——因为模型里所有"噪声"都已被 sₜ 状态吸收，这是设定正确的应有之义；若强行给 R 一个较大值，等于告诉滤波器"别信观测"，β 会变迟钝。

## 三、估计结果：Kalman  vs. OLS 家族

![对冲比例追踪：Kalman 紧跟漂移，OLS 类被伪回归污染](/images/kalman-pairs-cointegration-fusion/beta_tracking.png)

数字比图更有说服力：

| 估计量 | β RMSE | 价差与真实价差相关性 |
|---|---|---|
| 静态 OLS（前 60% 训练段） | 1.128（β=-0.096） | 0.10 |
| 120 日滚动 OLS | 0.486 | 0.08 |
| **Kalman 滤波器** | **0.0147** | **0.93** |

滚动 OLS 并非不用心——120 天窗口、只用过去数据——但伪回归偏差与窗口长度无关（x̄·σ_β/σ_x 不随 T 收缩），估计曲线像醉酒一样绕著真值抖。Kalman 则利用了两个状态不同的动态结构：漂移是持久的、价差是衰减的，靠持续性差异把两者分开。

代价也说清楚：Kalman 的 β 估计并非零误差——每天约 5% 的价差创新会被误吸进 β 状态（这是 MMSE 意义上的最优分摊，无法归零），累积成 RMSE 0.015 的高频抖动。但这不要命：价差污染量是 `(βₜ-β̂ₜ)·xₜ ≈ 0.015×4.7 ≈ 0.07`，只有价差本身波动的八成；而滚动 OLS 的同款污染是 `0.486×4.7 ≈ 2.3`，是价差波动的 26 倍。**对冲比例误差会被价格水平放大后灌进价差——这就是为什么 β 估得准不准，直接决定价差信号是不是噪声。**

## 四、价差回测：信号失真如何变成亏损

交易规则对所有方法一视同仁：EWMA z-score，±1.5σ 入场、回到 ±0.5σ 内离场，双边 5bps 成本，仓位按日波动 0.5% 目标缩放。

![Kalman spread 与真实 spread 相关性 0.93](/images/kalman-pairs-cointegration-fusion/spread_signals.png)

![配对交易净值：Kalman 几乎摸到 Oracle 上界](/images/kalman-pairs-cointegration-fusion/equity_curves.png)

| 策略 | 总收益 | 夏普 | 最大回撤 | 交易次数 |
|---|---|---|---|---|
| Oracle（真实 β + 真实 spread） | +393% | 3.24 | -3.2% | 188 |
| **Kalman 动态对冲** | **+319%** | **2.92** | **-5.9%** | 192 |
| 静态 OLS | +155% | 1.72 | -7.2% | 107 |
| 滚动 OLS | -5.7% | -0.07 | -15.3% | 30 |
| 买入持有 X | +7.6% | 0.20 | -23.0% | — |

三个值得细看的点：

- **Kalman 拿到 Oracle 的 90%**（2.92 vs 3.24），回撤只厚了一倍多。动态追踪的损耗主要来自滤波 spread 里混的 β 估计误差×xₜ，在 q_β 调好后只占价差方差的一成多。
- **滚动 OLS 几乎不交易**（30 次 vs Kalman 192 次）：它的价差被 β 估计噪声主导，σ 被抬高、z-score 很少触带——信号不是变差，是直接消失。
- **静态 OLS 为什么还赚钱？** 它的价差与真实价差相关性只有 0.10，本质是"1.1 倍的 X 加一条趋势"，盈利来自价差信号被极度稀释后漏进仓位的那一丝残香，外加本路径上 X 的均值回复运气——下一节的稳健性检验会证明这不可依赖。
- **成本结构对小刀锯大树不友好**：Kalman 年换手约 190 次全进全出，5bps 双边成本合计约 19bps/年，相对 319% 的收益是零头；但若价差收紧到真实市场的 1/10、单笔利润同步收缩，成本占比会涨一个数量级——**这个方法对执行成本敏感，价差越窄越要精算**。

## 五、调参：q_β 是估计精度与价差还原的权衡

滤波器唯一需要标定的超参是 β 的过程噪声 q_β。太小，β 跟不上漂移（滞后误差）；太大，价差创新被误吸进 β（价差还原度崩塌）。敏感性曲线把这个权衡画得很清楚：

![q_β 敏感性：估计精度与价差还原的权衡](/images/kalman-pairs-cointegration-fusion/rmse_sensitivity.png)

q_β=0.001（与真实过程噪声同量级）附近是甜点：β RMSE 0.0147、价差相关性 0.926。实战中可用训练段的多步预测误差标定——本 DGP 下该准则同样落在 0.001-0.002 区间，且 8 倍范围内结论稳健。

Kalman 夏普 **2.97±0.29**，Oracle 3.34±0.30——两条分布几乎重叠；滚动 OLS **-0.02±0.31**，中心就在零轴；静态 OLS 均值 2.13 但标准差 0.34，且最小值跌到 1.5 附近——它的"赚钱"高度依赖路径，换条路径就可能变成亏钱。**Kalman 的优势不是某一组参数下的运气，而是结构性的。**

## 诚实结论

- 这是**合成数据**：价差很宽（日波动 8.7%）、关系漂移是设定好的、没有借券成本与冲击成本。真实市场价差更紧、β 漂移更慢，Kalman 的优势会缩小——但"OLS 类被伪回归污染、状态空间模型不受影响"这个排序不变。
- 滤波器假设线性高斯、spread 为 AR(1)。真实价差常有厚尾和结构断裂，上马前请先用新息的自相关检验模型设定。
- 怎么发现"该换 β 了"？实战中可以监控滤波新息 vₜ 的 CUSUM 统计量：新息持续单边，往往意味着关系发生结构断裂（例如一方停牌复牌、成分股调整），此时应重置滤波器或加大 q_β。
- q_β 需要按数据标定，本文给出的 0.001 是本 DGP 的量级，不是普适常数。
- 回测含 5bps 换仓成本，但未含借券、融券、市场冲击与容量约束；十分之一多空以外的执行细节都会吃掉一部分夏普。
