波动率微笑可以拆成三件套：整体水平（level）、偏斜（skew）、中段凸性（curvature）。前两件的交易已经卷成红海，curvature 这块还留着一点「免费午餐」的传说：两翼比中间贵的时候卖凸性，便宜的时候买凸性，等它回归。蝴蝶价差（买 1 份低行权价 call、卖 2 份 ATM call、买 1 份高行权价 call）就是曲面上最干净的凸性表达。本文用 numpy 从零搭一个 Heston + 风格化微笑的合成市场，把「凸性均值回归」这笔买卖拆开验货：信号是真的，edge 也是真的，但小到会被成本生吃。

结论先放这：

**① 裸蝶不是凸性仓，是波动率仓。** 蝴蝶溢价与 σ_atm 的相关系数 −0.947（裸蝶 vega −11.14 美元/每 1 vol 点）——你以为在做凸性回归，其实绝大部分 PnL 方差来自波动率方向。同一信号下的裸蝶策略赚 +3.752%（IR 0.19），但最大回撤 −3.697%，赚的是 vol 均值回归送的。
**② 凸性状态本身确实均值回归。** 把曲率缺口除以 σ_atm 得到「相对凸性」（= 0.01×凸性状态 c），AR(1) 系数 0.968、半衰期 21.4 天；按十分位分组，最贵的 10% 状态后 5 日平均回落 0.0090、最便宜的 10% 后 5 日平均回升 0.0073——方向完全正确。
**③ 但对冲隔离之后，edge 几乎归零。** 用每日再平衡的 ATM 跨式对冲掉 vega 后，29 笔交易总 PnL 只有 +0.043%（IR 0.01），最大回撤 −1.603%。归因显示：单笔凸性贡献 +0.0253%，被对冲泄漏（−0.0125%）、gamma 噪声（现货贡献的绝对值 0.2426%，是凸性的 4 倍）和约 8bp/笔的成本吃光。

## 一、合成市场：Heston 标的状态 + 风格化微笑

标的状态用 Heston：dS/S = r·dt + √v·dW₁，dv = κ(θ−v)·dt + ξ·√v·dW₂，相关系数 ρ=−0.7（参数 κ=2、θ=4%、ξ=0.4），500 个交易日。ρ=−0.7 不是摆设：它让「跌」和「波动上升」绑定，这也是后文对冲总是慢半拍、gamma 噪声压不住的根源。微笑叠在上面：σ(k) = σ_atm·(1 + sk·k + c·k²)，k 是 log-moneyness；skew 状态 sk 走 OU（均值 −0.60、φ=0.97），凸性状态 c 走 OU（均值 14、φ=0.96）外加每天 0.8% 概率的 ±3 机制跳变（样本内跳了 3 次）。所有期权 30DTE，蝴蝶的行权价取 S·e^(−0.10)、S、S·e^(0.10)。

直觉上先在曲面上认出这三件套：偏斜让微笑整体歪向一侧（市场更怕跌，看跌一侧更贵），凸性让中间凹下去一块（ATM 比两翼连线便宜）。蝴蝶「多两翼、空中间」的结构，恰好只吃中间那块凹凸——买它等于赌凹得不够深会弹回来，卖它等于赌凹得过分会摊平。这就是「纯凸性」的含义：level 和 skew 在构造里被抵掉了。

跑一遍市场诊断，确认这个世界「有生意可做」：500 天里 σ_atm 在 0.081-0.356 之间游走（均值 0.225，覆盖了平静到恐慌的完整区间）；凸性状态 c 均值 13.56、标准差 3.38、极值 4.93-20.85，三次机制跳变都完整发生；曲率缺口（vol 点）均值 0.0309、最大 0.0532——也就是说两翼平均比 ATM 贵 3-5 个 vol 点，这是蝴蝶策略的全部利润空间来源。蝴蝶溢价平均占标的价格的 4.541%，裸蝶 vega 均值 −11.14，这两个数决定了后文对冲比率和成本量级。

```python
def surface_sig(v_t, c_t, sk_t, k):
    """风格化微笑：水平 × (1 + 偏斜 + 凸性)"""
    return np.sqrt(max(v_t, 1e-6)) * (1 + sk_t * k + c_t * k * k)

def fly_legs(S_t, v_t, c_t, sk_t):
    DK = 0.10                       # 行权价间距（log-moneyness）
    K1, K2, K3 = S_t * np.exp(-DK), S_t, S_t * np.exp(DK)
    return ((K1, surface_sig(v_t, c_t, sk_t, -DK)),
            (K2, surface_sig(v_t, c_t, sk_t, 0.0)),
            (K3, surface_sig(v_t, c_t, sk_t, DK)))

def fly_premium(S_t, v_t, c_t, sk_t):
    """蝶式溢价 = call(K1) - 2*call(K2) + call(K3)"""
    (K1, s1), (K2, s2), (K3, s3) = fly_legs(S_t, v_t, c_t, sk_t)
    return (bs_call(S_t, K1, TAU, R, s1) - 2 * bs_call(S_t, K2, TAU, R, s2)
            + bs_call(S_t, K3, TAU, R, s3))

def curvature_gap(v_t, c_t, sk_t, k=0.10):
    """中段凸性缺口：两翼平均高出 ATM 的部分（vol 点）"""
    return (0.5 * (surface_sig(v_t, c_t, sk_t, -k) + surface_sig(v_t, c_t, sk_t, k))
            - surface_sig(v_t, c_t, sk_t, 0.0))
```

## 二、蝴蝶解剖：先认清你的对手是 vega

对曲率缺口做个恒等式推导：0.5·(σ(−k)+σ(k)) − σ(0) = 0.01·c·σ_atm（skew 项在双翼平均里精确抵消）。也就是说，**曲率缺口以 vol 点计会随 σ_atm 一起缩放**，除以 σ_atm 之后的「相对凸性」= 0.01·c 才是可跨时间比较的纯净状态——它与 c 的相关系数 1.000，而原始曲率缺口与 c 只有 0.829（被 σ_atm 污染）。

但致命的问题在定价：样本内蝴蝶溢价与 √v 的相关系数 **−0.947**，与 S 的相关 0.214，与相对凸性的相关只有 −0.093。裸蝶 vega 均值 −11.14（每股每 1 vol 点）——**不先对冲波动率，你做的就不是凸性交易，是波动率方向交易**。溢价与相对凸性相关只有 −0.093 也不难理解：c 和 v 在本模拟里同向而行（曲率缺口与 √v 相关 0.739），凸性偏贵常常踩着高波，而 vega 的 (−) 号把两者的贡献大部抵消，剩下的才是凸性的正向推力。这就是后文归因那张图标题的由来。

## 三、策略：z-score 信号 + 每日 vega 对冲

信号用相对凸性的 40 日滚动 z-score：z>1.5（凸性偏贵）卖蝶，z<−1.5（偏便宜）买蝶，|z|<0.5 或持仓满 12 天离场。窗口取 40 天是为了罩住凸性状态的半衰期（21.4 天）的两倍，z-score 阈值 ±1.5 是经典的经验值，出场线 ±0.5 保证「吃到回归的主鱼身」。12 天的持仓上限对应半衰期过半，超期还没回归的信号大概率是机制跳变而非暂时偏离，及时认错。头寸永远带一个每日再平衡的 ATM 跨式对冲腿，对冲比率 n = −V_fly / vega_straddle，把组合的 ATM vega 钉在 0。成本按实战口径：蝴蝶单边 2bp，对冲腿每日再平衡 0.5bp。

## 四、结果：对冲前 vs 对冲后

500 天、29 笔交易（买 14 / 卖 15），平均持仓 8.1 天。两条曲线放一起看（图 4）：

- **裸蝶**：总 PnL **+3.752%**，IR 0.19，胜率 59%，但最大回撤 **−3.697%**。回忆 corr(曲率缺口, √v)=0.739——凸性偏贵常常和高波同行，卖贵凸性顺带做空了波动率，Heston 的均值回归把这笔方向利润也发了。这不是 edge，是搭便车。
- **对冲后**：总 PnL **+0.043%**，IR 0.01，最大回撤 **−1.603%**，对冲成本合计 1.175%。剥掉 vol 方向后，凸性回归的真实剩余就这么多——500 天 +4.3 个基点。

这个对照把「波动率曲面策略」的水分挤得干干净净：同一组信号、同一个出场规则，只差一条对冲腿，收益差 87 倍、回撤差 2.3 倍。很多「凸性回归策略」回测里的漂亮曲线，拆开来看多半是裸蝶的 vol 方向暴露在悄悄赚钱——曲线归因的时候，这笔账必须算在波动率头上，不能算在凸性头上。图 3 的右panel 是对冲后的单笔盈亏分布：均值贴着零轴，胜率 48%，左右基本对称——赚不到钱，但也没被市场惩罚，这就是一个「信号真实、edge 太薄」的策略该有的样子。

## 五、归因：edge 死在哪

把每笔 PnL 按「凸性变动 / ATM 波动 / 标的价格 / 残差」拆开（图 5，单边平均）：

| 成分 | 平均贡献 | 平均绝对值 |
|---|---|---|
| 凸性变动（目标暴露） | +0.0253% | 0.0615% |
| ATM 波动（对冲后残余） | −0.0125% | 0.0916% |
| 标的价格（gamma） | +0.0715% | **0.2426%** |
| 残差 | −0.0828% | 0.0977% |

目标腿（凸性）平均只赚 2.5bp/边，而标的价格 leg 的波动是它的 4 倍——**对冲掉 vega 之后，gamma 成了新的噪声之王**。蝴蝶是二阶导头寸，对 spot 的二阶敏感（gamma）本来就是它的本性；vega 对冲只解决一阶波动率暴露，二阶的 gamma 敞口原封不动地留着，而 Heston 的 ρ=−0.7 意味着每次 spot 大跌都裹着 vol 跳升，静态日度对冲比率永远在追着变化跑。再加上成本：单边 2bp × 2 + 每日 0.5bp × 8.1 天 ≈ 8bp/笔，比凸性 edge 本身还大。残差 −0.0828% 就是对冲比率漂移与微笑高阶项（k³ 以上）的总账。

## 六、诚实结论

这笔账算下来：**凸性均值回归在状态层是真的（AR(1) 0.968、十分位条件均值符号全对），在 PnL 层被三道闸吃干抹净**——vega 对冲的再平衡泄漏、gamma 噪声、以及比 edge 还大的成本。裸蝶那 +3.75% 是波动率均值回归发的红包，别当成凸性的功劳。500 天 +4.3 个基点的对冲后收益不是策略失败，而是把幻想挤掉之后剩下的真实骨架——很多经典「异象」的骨架，其实就这么细。

要把这个策略从论文搬进组合，得逐条拆闸：对冲从「只对冲 vega」升级到动态 delta/gamma 联合对冲，压住那只占绝对值 0.2426% 的 gamma 噪声；信号从单序列 z-score 换成曲面横截面（同一时刻所有到期日的凸性一起打分，用横截面分位替代时间序列分位）；成本按真实报价带（不是 2bp 假设）重算。还有一个更根本的问题：本文的凸性状态由外生 OU 过程给定，而真实市场的凸性是无数交易员博弈出来的——当足够多的人做同一笔均值回归，edge 本身就会被压缩。波动率风险溢价的传说养活了多少论文，就被多少回测里的三道闸打回原形——这就是本文最想留下的印象。
