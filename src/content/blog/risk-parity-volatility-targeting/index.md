投资组合的第一直觉往往是"平均分":把资金等分成几份买进去。但在风险的世界里,**等权根本不等于等风险**。一只年化波动 40% 的资产和一只年化波动 8% 的资产各占 50%,前者贡献的风险可能是后者的十几倍——你以为分散了,其实把赌注悄悄压在了波动最大的那一个上面。

风险平价(Risk Parity)想解决的正是最初这个错觉:它不按金额等分,而是让**每个资产对组合总风险的边际贡献相等**。再叠一层波动率目标化(Volatility Targeting),给组合装上一个"减震器"——市场躁动时自动降杠杆,风平浪静时再加回来。本文用一份 8 年、6 类资产的合成日收益(含一段人为制造的波动率崩盘),把这两件事算个底朝天,并给出可运行的 numpy 实现。

## 一、为什么等权是"伪分散"

风险贡献(Risk Contribution)的定义很干净:资产 i 的贡献

$$RC_i = w_i \,(Σw)_i \;/\; (w^\top Σ w)$$

也就是它在组合总方差里占的那一份。把它除以组合总风险,就得到"第 i 个资产吃掉了百分之多少的风险预算"。对 6 个资产来说,理想的风险平价状态是**每个资产都恰好吃掉 16.7%**。

我们造一份因子模型数据:6 类资产(股票、信用债、商品、REITs、成长股、黄金)由 2 个共同因子加特质噪声驱动,再用 8 年日收益算出年化协方差 Σ。结果触目惊心——

- 等权下,风险贡献从 4.9% 到 29.1% 大幅倾斜,波动最大的资产一个人吃掉了近三成风险预算;
- 风险平价下,6 个资产的风险贡献被压到 16.7%–16.7% 的窄带里,几乎完美相等。

这就是"等权 ≠ 等风险"的量化证据:你不控制风险贡献,市场就替你控制——而且通常替你集中。

## 二、风险平价权重怎么求
![图1 等权 vs 风险平价的风险贡献](/images/risk-parity-volatility-targeting/fig1_risk_contrib.png)

一般协方差下不存在风险平价的解析闭式,但有一个漂亮的**逐坐标下降**迭代可以收敛到精确解。固定其他资产权重,只调第 i 个:令 $v$ 为把 $w_i$ 置 0 的向量,则组合方差对 $w_i$ 是一个二次函数。把"$RC_i$ 必须等于 $1/N$"这个条件代入,会落到一个一元二次方程

$$a(N-1)\,w_i^2 + c(N-2)\,w_i - d_0 = 0$$

取正根更新 $w_i$,在所有资产间循环几百轮即可。下面给出完整实现——它不依赖任何优化器,纯 numpy 就能跑。
```python
import numpy as np

def risk_parity_weights(Sigma, iters=500):
    """逐坐标下降求风险平价(ERC)权重,纯 numpy 实现。"""
    N = Sigma.shape[0]
    w = (1.0 / np.sqrt(np.diag(Sigma)))      # 逆波动初始化
    w /= w.sum()
    for _ in range(iters):
        for i in range(N):
            v = w.copy(); v[i] = 0.0         # 固定其他资产
            a = Sigma[i, i]
            c = (Sigma @ v)[i]
            d0 = float(v @ (Sigma @ v))
            A = a * (N - 1); Bc = c * (N - 2)
            disc = Bc * Bc + 4 * A * d0
            w[i] = (-Bc + np.sqrt(disc)) / (2 * A)
        w /= w.sum()
    return w

def risk_contrib(w, Sigma):
    Sw = Sigma @ w
    return w * Sw / (w @ Sw)

# Sigma 为年化协方差矩阵
w_rp = risk_parity_weights(Sigma)
rc   = risk_contrib(w_rp, Sigma)
print("风险平价权重:", np.round(w_rp, 3))
print("风险贡献占比:", np.round(rc * 100, 2))
```
跑出来你会发现,风险平价天然**低配高波动资产、高配低波动资产**:黄金、债券这类"安静"的资产反而拿到更大权重,而股票、成长股被自动压低。这不是拍脑袋,而是"让每份风险都花在刀刃上"的数学必然。

## 三、波动率目标化:给组合装减震器

风险平价解决了"风险怎么分",但没解决"整体风险多大"。如果市场整体进入高波动状态,再怎么平分,组合的绝对波动也会跟着飙。波动目标化干的就是这件事:设定一个目标年化波动(这里取 12%),用**滚动 60 日已实现波动**估计当前风险,反推该用几倍杠杆:

$$L_t = \frac{\sigma_{\text{target}}}{\hat\sigma_t^{\text{roll}}}, \quad \text{并截断在 }[0.25,\,3.0]$$

也就是说,波动变大就降杠杆,波动变小就加杠杆,把组合的整体波动**钉在目标线附近**。我们用一段人为制造的崩盘(中间 45 天因子波动放大 3.4 倍)来考验它。

## 四、四种策略同台对比
![图2 四种策略累计净值](/images/risk-parity-volatility-targeting/fig2_cumret.png)

把"等权 / 风险平价"与"是否叠加波动目标"两两组合,得到 4 条净值曲线。关键指标如下:

| 策略 | 年化波动 | 夏普 | 最大回撤 |
|------|---------|------|---------|
| 等权 1x | 13.1% | 0.74 | -16.8% |
| 风险平价 1x | 10.2% | 0.82 | -12.0% |
| 等权 + 波动目标 | 12.5% | 0.84 | -14.2% |
| 风险平价 + 波动目标 | 12.4% | 0.91 | -11.8% |

三个结论很清楚:

1. **风险平价先降集中风险**:1x 下它把最大回撤从等权的 -16.8% 压到 -12.0%,因为不再让高波动资产独自扛雷。
2. **波动目标再砍尾部**:叠加之后,组合波动被钉在 12% 目标附近,崩盘那段被自动去杠杆,最大回撤进一步降到 -11.8%。
3. **两者叠加夏普最优**:风险平价+波动目标的夏普 0.91,高于单纯等权的 0.74——它买的不是更高收益,而是更稳、更可预期的回撤路径。

需要泼的冷水是:波动目标是**滞后**的,用过去 60 天估现在,遇到"瞬间闪崩"来不及反应;而且它默认波动可预测、杠杆可无限细调,实盘还要叠加交易成本与融资约束。但它作为组合层的"风险 thermostat",性价比极高。

## 五、小结
![图3 波动目标化把组合波动钉在目标附近](/images/risk-parity-volatility-targeting/fig3_rolling_vol.png)

等权是偷懒,风险平价是让风险预算均等分配,波动目标化是在此之上再给组合套一个自适应减震器。三者一脉相承:**先问"风险从哪来",再问"风险有多大",最后问"我能不能把它调到我想要的大小"**。下一份数据、下一个资产池,你都可以把上面的 `risk_parity_weights` 和 `vol_target` 直接搬过去用。
