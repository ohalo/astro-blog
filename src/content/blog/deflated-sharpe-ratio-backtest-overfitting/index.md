你花了两周，回测了上千个策略参数组合，终于找到一个 Sharpe 1.30 的「圣杯」。兴奋之余，一个声音该在脑中响起：**这 1.30 里，有多少是真本事，有多少是你从一千次尝试里挑出来的运气？**

这就是量化研究最隐蔽的陷阱——**选择偏差（selection bias）**。你不是在做一次假设检验，你是在做上千次，然后报告最好的那个。传统 Sharpe 的 t 检验假设「策略是事先指定的」，一旦你挑过，它给出的置信度就全是幻觉。Bailey 与 López de Prado 在 2014 年提出的**缩减夏普比率（Deflated Sharpe Ratio，DSR）**，就是专门给这类「挑出来的策略」验明正身的工具。本文用纯 numpy 把它的每一块积木都搭出来，所有数字都是脚本实跑所得。

## 一、为什么「最好的」必然虚高：纯噪声也能挑出高 Sharpe

先做一个让人清醒的实验。假设市场上所有策略都没有任何预测能力，日收益就是均值为 0 的高斯噪声。我们生成大量这样的「垃圾策略」，每个用 5 年日频数据（T=1260 天），计算各自的年化 Sharpe，然后**只看最好的那个**。

Key insight：N 个独立的标准正态随机变量，其最大值的期望随试验次数对数增长。对 Sharpe 估计量（其标准误约为 1/√(T-1)，年化后乘 √252），N 次试验后的期望最大 Sharpe 近似为：

$$
E[\max SR_N] \approx \sigma_{SR}\left[(1-\gamma)\Phi^{-1}\!\left(1-\tfrac{1}{N}\right) + \gamma\Phi^{-1}\!\left(1-\tfrac{1}{Ne}\right)\right]
$$

其中 γ≈0.5772 是欧拉-马歇罗尼常数，σ_SR=√(252/(T-1)) 是年化 Sharpe 的标准误，Φ⁻¹ 是标准正态分位数函数。这个式子叫**期望最大 Sharpe**，它是 DSR 里的「零技能门槛」。

![N 个噪声策略的最大 Sharpe：试验越多，挑出来的越高](/images/deflated-sharpe-ratio-backtest-overfitting/01_max_sharpe_vs_trials.png)

实测结果触目惊心（T=1260，蒙特卡洛 3000 次）：

| 试验次数 N | 蒙特卡洛期望最大 Sharpe | 欧拉修正理论值 |
|---|---|---|
| 1 | -0.001 | 0.00 |
| 10 | 0.687 | 0.705 |
| 100 | 1.105 | 1.132 |
| 1000 | 1.437 | 1.456 |
| 10000 | 1.735 | 1.727 |

看到没有？**什么都不懂的研究员，只要回测 1000 次，就能「发现」一个年化 Sharpe 1.44 的策略；回测 1 万次，能「发现」1.73 的。** 图中那条 √(2lnN) 的粗略近似在 N 小时偏高（因为它忽略了欧拉修正项），但欧拉修正理论曲线与蒙特卡洛几乎完美贴合，验证了公式的正确性。这就是为什么「我筛了几百个因子，最好的 IC 0.08」这种话不能信——筛选本身就是偏差来源。

## 二、DSR 公式：把门槛从「0」抬到「你挑过之后的恰好水平」

普通 Sharpe 检验的问题是拿观测 Sharpe 和 0 比。DSR 的洞见是：**你挑过 N 次，那你的对手就不是 0，而是「零技能下挑 N 次能达到的期望最大 Sharpe」SR₀。** 而且策略收益往往有偏度、有厚尾，会放大 Sharpe 的抽样波动，这也要算进去。

Sharpe 估计量的方差（含高阶矩修正）：

$$
\hat{\sigma}_{SR}^2 = \frac{1 - \gamma_3 SR + \frac{\gamma_4 - 1}{4}SR^2}{T - 1}
$$

其中 γ₃ 是偏度、γ₄ 是峰度（正态为 3）。零技能下的期望最大 Sharpe 就是 SR₀ = σ_SR·[(1-γ)Φ⁻¹(1-1/N)+γΦ⁻¹(1-1/(Ne))]。最后，DSR 定义为：

$$
DSR = \Phi\!\left(\frac{SR_{obs} - SR_0}{\hat{\sigma}_{SR}}\right)
$$

它读作：「观测 Sharpe 超过『挑 N 次的零技能门槛』的概率」。DSR>0.95 才有 95% 把握说这策略不是挑出来的运气。

注意一个微妙之处：方差公式里也含 N（通过 σ_SR），且 SR₀ 与观测 Sharpe 共用同一份高阶矩信息——这正是 DSR 比朴素 t 检验更严的地方。下面的实现把这些细节都保留了。

```python
import math
import numpy as np
from scipy.stats import norm

GAMMA = 0.5772156649015329  # 欧拉-马歇罗尼常数
P = 252                      # 年化因子

def expected_max_sr(n, sigma_sr):
    """零技能下挑 n 次的期望最大 Sharpe（per-period）"""
    if n <= 1:
        return 0.0
    z1 = norm.ppf(1 - 1 / n)
    z2 = norm.ppf(1 - 1 / (n * math.e))
    return sigma_sr * ((1 - GAMMA) * z1 + GAMMA * z2)

def deflated_sharpe(sr_ann, n, T, skew, kurt):
    s = sr_ann / math.sqrt(P)                       # 年化转 per-period
    vnum = 1 - skew * s + (kurt - 1) / 4 * s**2    # 高阶矩修正的方差分子
    sigma = math.sqrt(vnum / (T - 1))              # Sharpe 标准误
    sr0 = expected_max_sr(n, sigma)                # 零技能门槛
    z = (s - sr0) / sigma
    return norm.cdf(z), sr0 * math.sqrt(P)         # 返回 DSR 和年化 SR0

# 观测 Sharpe=1.30，偏度 -0.5、峰度 4，样本 5 年
for n in [1, 10, 100, 1000, 10000]:
    dsr, sr0 = deflated_sharpe(1.30, n, 1260, -0.5, 4)
    print(f"N={n:>5}: SR0={sr0:.2f}, DSR={dsr:.3f}")
```

## 三、同一个 Sharpe，试的次数不同，结论天差地别

现在回答开头的问题。一个观测 Sharpe=1.30 的策略（偏度 -0.5、峰度 4、5 年样本），它的真实性与「你试了多少次」强相关：

![同一个 Sharpe=1.30：试验次数越多，DSR 越塌](/images/deflated-sharpe-ratio-backtest-overfitting/03_dsr_sensitivity.png)

| 试验次数 N | 零技能门槛 SR₀ | DSR | 解读 |
|---|---|---|---|
| 1（事先注册） | 0.00 | 0.998 | 几乎确定为真 |
| 10 | — | 0.897 | 尚可 |
| 100 | — | 0.622 | coin flip |
| 1000 | 1.49 | 0.339 | 大概率是挑出来的 |
| 10000 | — | 0.154 | 几乎肯定是运气 |

这就是全文最重要的结论：**Sharpe 1.30 本身不含信息，含信息的是「你为得到它付了多少次尝试的代价」。** 事先注册一个策略、回测一次得到 1.30，DSR 0.998，你可以很有信心；事后从一千个参数组合里挑出 1.30，DSR 只有 0.339——你该怀疑它是不是噪声。右图进一步显示：要让试过 1000 次的策略达到 95% 置信，观测 Sharpe 得接近 2.0；试过 1 万次则要 2.4 以上。

![1000 次噪声回测下最大 Sharpe 的分布](/images/deflated-sharpe-ratio-backtest-overfitting/02_selection_distribution.png)

分布图把这件事看得很直观：零技能下试 1000 次，最高 Sharpe 的均值 1.44、中位数 1.40、90 分位 1.70、99 分位 1.84。你的「圣杯」1.30 甚至没到中位数——它在这个分布里毫不起眼，大概率就是噪声池里冒出来的一个普通分子。

## 四、高阶矩：负偏与厚尾让门槛进一步抬高

真实策略收益很少是正态的：亏钱时尾部更肥（负偏）、极端行情更多（高峰度）。这两个都会放大 Sharpe 的抽样波动 σ_SR，从而抬高零技能门槛 SR₀、压低 DSR。

![偏度与峰度对 Sharpe 标准误和 DSR 的影响](/images/deflated-sharpe-ratio-backtest-overfitting/04_moments_effect.png)

数值实验：在 SR=1.30、N=1000 下，正态假设（γ₃=-0.5、γ₄=3）时 DSR=0.3403；把峰度抬到 γ₄=12，DSR 降到 0.3329。Sharpe 年化标准误从正态的 0.447 升到（γ₃=-1、γ₄=12 时）0.469。幅度看着不大，但方向一致且系统——**厚尾策略需要更高的观测 Sharpe 才能证明自己**，这正是 DSR 把 γ₃、γ₄ 显式写进公式的意义。要注意高阶矩本身也是估出来的、噪声很大，实盘中常用稳健的预先指定值。

## 五、诚实地说清楚 DSR 的边界

DSR 不是万能护身符，用之前得明白它假设了什么：

- **独立试验假设**：公式假设 N 次回测相互独立。现实中参数网格高度相关（把均线从 20 调到 21 不算一次真正独立的新试验），有效试验数可能远小于名义次数，DSR 会偏保守。反过来，如果你偷偷试了几百个数据集版本，实际 N 又远大于你申报的，DSR 会偏乐观。诚实地记录你到底试了多少次，是前提。
- **它只回答「是否非零技能」，不回答「能否赚钱」**：DSR 高只说明 Sharpe 大概率不是挑出来的，不代表扣掉成本、容量、滑点后还有超额。
- **样本期单一**：5 年数据只覆盖一段市场状态，DSR 修正的是「挑策略」偏差，不是「 regimes 会变」的风险。
- **高阶矩估计误差**：γ₃、γ₄ 在小样本上抖动剧烈，建议用长历史或行业先验，别用回测期里那点样本现估现用。

实务中的配套纪律：把研究日志当成实验记录本（每次试验都登记，事后才知道真实 N）；对通过 DSR 的策略再叠加样本外滚动验证与 paper trading；或者干脆采用 Bailey 等人建议的 **PBO（回测过拟合概率）** 与最小回测长度（minimum backtest length）联合判断。DSR 是这套防御体系里最锋利的一把刀，但它需要你诚实——而诚实，恰恰是量化研究里最难落到纸面的东西。

这里多说一句**最小回测长度**，它和 DSR 是一对孪生工具。DSR 问「这份 Sharpe 是不是挑出来的」，最小回测长度问「给定我想验证的目标 Sharpe 和已经试过的次数，至少要多长的历史才够」。直觉上，目标 Sharpe 越高、试验次数越多，你反而需要**更长**的样本——因为高 Sharpe 更容易被少数几个幸运的极端收益撑起来，试得越多越容易撞上这种幸运。把 DSR 公式反解、令其等于 0.95，就能得到所需的最小 T。它揭穿了一个常见错觉：很多人以为「策略好就不需要长历史」，事实恰恰相反，越是漂亮的结果越需要长时间来证伪。这也是为什么专业机构对三年以内的回测普遍保持怀疑——不是数据不够用，而是不足以把运气和技能分开。

另一个配套指标 PBO 换了个角度：它把历史切成训练段与测试段，看「在训练段表现最好的策略，在测试段是否依然最好」，用组合式交叉验证统计这种排名翻转的频率。如果 PBO 接近 0.5，说明你的「最优策略」和随机挑一个没区别。DSR 从单次选择的统计门槛切入，PBO 从样本内外的稳健性切入，两者结论一致时才有说服力；若一个说好一个说坏，多半是试验次数没记准，该回到研究日志上去核对。

## 小结

选最好的策略没错，错在把「选出来的 Sharpe」当成「事先假设的 Sharpe」来做统计推断。DSR 把多重检验的账算清楚：5 年日频、零技能下挑 1000 次，期望最高 Sharpe 就有 1.44；观测 1.30 经 DSR 修正后只剩 0.339 的置信度。记住这条铁律——**报告 Sharpe 时必须同时报告你试了多少次**，否则那个漂亮数字，很可能只是大数定律给你开的空头支票。
