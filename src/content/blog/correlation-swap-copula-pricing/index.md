## 一、结论先行

相关性互换是最容易被"看起来一样"骗过去的合约。我构造了两个 8 资产的联合分布：高斯 Copula 与自由度 5 的 t Copula，二者的线性相关系数都精确等于 **0.40**，边缘都标准化为均值 0、方差 1。每个世界模拟 24000 条路径，用 60 天窗口估计平均两两样本相关 $\hat\rho$，再给互换和期权定价：

- **线性互换**在 $K=0.40$ 的报价（以相关性点为单位）分别是 **-0.00305** 与 **-0.00529**，差 0.0022 个点，几乎同一个数；
- **相关性看涨期权** $K=0.50$ 的报价是 **0.000569** 与 **0.003525**，t(5) 是高斯的 **6.2 倍**；$K=0.55$ 是 **1.73e-05** 与 **9.70e-04**，差距放大到 **56 倍**；
- 把估计窗口拉到 250 天，$K=0.50$ 的看涨从 **3.65e-07** 跌到 **3.09e-04**，相差约 **846 倍**。

一句话：**线性产品只看均值，均值由线性相关决定；凸性产品看整个分布，分布由尾部依赖决定。**两个模型在均值上几乎无差别，在尾部上差了一个数量级，线性互换把差别抹平，期权把它放大。用同一个校准过的互换波动率去给相关性期权定价，是这类产品最常见的定价事故。

## 二、合约到底在赌什么

设组合有 $N$ 个资产，观察窗 $M$ 天。先把每个资产的收益标准化，算两两样本相关 $R_{ij}$，再取所有 $\binom{N}{2}$ 对的等权平均：

$$
\hat\rho=\frac{2}{N(N-1)}\sum_{i<j}R_{ij}.
$$

相关性互换的 payoff 是 $\Phi(\hat\rho-K)$，相关性看涨是 $\Phi\max(\hat\rho-K,0)$，其中 $\Phi$ 是名义本金。与利率互换不同，这里**没有贴现现金流**——所有不确定性都在估计量 $\hat\rho$ 的分布里。

这个定义有三个直接后果。第一，$\hat\rho$ 的估计口径本身就是合约条款的一部分：用 60 天还是 250 天、用收益还是残差、是否先扣市场因子，都会改变 payoff。第二，$\hat\rho$ 天然有**小样本下偏**：$M=60$ 时两个世界的期望分别是 0.3969 和 0.3947，都低于真实 0.40；$M=20$ 时进一步降到 0.3916 和 0.3869。所以公平互换行权价不是 0.40，而应在 0.397 / 0.395 附近（图 2）。第三，$M$ 越短，$\hat\rho$ 的标准差越大：$M=60$ 时高斯 0.0563、t(5) 0.0769；$M=250$ 时降到 0.0273 / 0.0411。

## 三、同一相关系数，两种尾部

高斯世界直接生成 $z\sim N(0,\Sigma)$，$\Sigma$ 是等相关阵，$(1-\rho)I+\rho\mathbf 1\mathbf 1^\top$。t 世界生成 $w\sim N(0,\Sigma)$，再除以逐日抽出的 $\sqrt{g/\nu}$，$g\sim\chi^2_\nu$，最后乘 $\sqrt{(\nu-2)/\nu}$ 把边缘方差归一到 1。这样两个世界的线性相关都是 0.40，差异只在共同除数的厚尾上。

尾部依赖的理论差别很大。t Copula 的上尾依赖系数是

$$
\lambda=2\,t_{\nu+1}\!\left(-\sqrt{\frac{(\nu+1)(1-\rho)}{1+\rho}}\right),
$$

代入 $\nu=5,\rho=0.4$ 得 **0.1599**；高斯的 $\lambda=0$。但在**有限分位**上，这个差别并没有直觉中那么夸张：各自 95% 分位以上的联合概率是 **0.00948** 对 **0.0133**（解析高斯值 0.00943，模拟对得上）；99% 分位是 **0.00101** 对 **0.00210**；99.9% 分位是 **3.5e-05** 对 **1.7e-04**，约为 4.9 倍。尾部依赖是极限概念，只有往足够深的分位走才接近 0.16；而期权 payoff 的成本，恰恰集中在这些稀薄区域。

t 世界单资产的样本峰度约 7.2，理论值是 $3+6/(\nu-4)=9$；样本低于理论是有限样本常见的，说明这类估计本身也不稳定。为了不让峰度噪声主导结论，下面的定价只对 $\hat\rho$ 的分布做蒙特卡洛，不用峰度反推价格。

## 三点五、估计偏差是条款，不是 bug

$\hat\rho$ 的下偏不是代码写错，而是样本相关估计量在小样本里的系统性行为：分母用的是样本标准差，波动的估计误差与分子相关项耦合，向 0 收缩。$M=60$ 时高斯世界偏差 -0.0031、t 世界 -0.0053；$M=20$ 时扩大到 -0.0084 / -0.0131。厚尾世界偏得更厉害，因为一次极端行情同时抬高某几个资产的波动，分母变大而相关项没有同步变大。

实务上这带来两条纪律。第一，**互换的公平行权价是 $E[\hat\rho]$ 而不是模型参数 $\rho$**：在 $M=60$、高斯世界报价应选 0.3969 附近，而不是 0.40；否则卖方每笔白送 0.0031 个相关性点。第二，别把单对相关的教科书标准误套到平均估计量上。单对的 Fisher-z 标准误是 $1/\sqrt{M-3}=0.130$（$M=60$），而本次实验中 28 对平均后的 $\hat\rho$ 标准差只有 0.0563；用它构造 95% 区间，24000 条路径里覆盖率高到 100%（t 世界也有 99.1%），说明这个区间过度保守。28 对相关共享同一个市场因子，有效样本量远不是 $28\times M$，正确的标准误要从联合结构或重抽样里拿。

这也解释了互换定价为什么对 Copula 不敏感：两个世界的 $E[\hat\rho]$ 只差 0.0022，而这个差本身还不到 60 天窗口下估计标准误的 4%。**对线性产品，你几乎看不出自己在哪个世界里；对凸性产品，你每一档行权价都在为那个世界的尾部付费。**

## 四、为什么互换不敏感，期权敏感

互换价格是 $E[\hat\rho]-K$，**只依赖均值**。两个世界的均值差 0.0022 个点；按 1 亿名义本金折算只差约 22 万元，常常被交易成本与估计误差淹没。所以"用哪个 Copula"对线性互换几乎无所谓。

期权价格是 $E[(\hat\rho-K)^+]$，**依赖整条右尾**。$K=0.50$ 时，高斯的 $z$ 值约 $(0.397-0.50)/0.056=-1.83$，落在极稀薄右尾；t 世界的标准差更大 37%，同一执行价瞬间从"几乎不可能"变成"偶尔发生"。价格比从 6.2 倍一路升到 $K=0.55$ 的 56 倍（图 3）。

这也解释了为什么实务里用 Bachelier 正态公式给相关性期权报价会出事。用各自的样本均值与标准差代入正态看涨公式 $C=(m-K)\Phi(d)+\sigma\phi(d)$，$d=(m-K)/\sigma$：

- 高斯世界 $K=0.50$：正态近似 0.000743，蒙特卡洛 0.000569，近似**高估 30.5%**；
- t(5) 世界 $K=0.50$：正态近似 0.003013，蒙特卡洛 0.003525，近似**低估 14.5%**；
- t(5) 世界 $K=0.55$：0.000618 对 0.000970，低估 **36.3%**。

同一条正态公式，在两个世界里朝相反方向错，而且错幅随行权价上升。原因是 $\hat\rho$ 的分布并不正态：它受限于 $[-1,1]$，在高斯世界里略左偏，在 t 世界里右尾更厚（图 4 左）。

## 五、窗口长度：把凸性慢慢磨掉

$M$ 是合约最锋利的参数。$K=0.50$ 的看涨价格在高斯世界从 $M=20$ 的 0.00633，掉到 60 天的 0.000569、120 天的 4.41e-05、250 天的 3.65e-07；t(5) 世界对应为 0.01222、0.003525、0.001116、0.000309。两条曲线都近似指数衰减，但 t 世界衰减慢得多：250 天时仍比高斯高约 846 倍。

对交易员的含义是：**估值窗口不只是数据选择，而是合约的"凸性额度"**。短窗口卖方收高溢价但承担巨大的估计噪声；长窗口把噪声压平，也因此把 t 尾部的期权价值几乎磨没。如果你的交易簿上同时挂着不同窗口的相关性期权，不能简单地用同一条波动率曲面插值——那条曲面的第三个维度是 $M$。

## 六、核心实现

```python
import numpy as np
from scipy.stats import norm

N, M, rho, nu, n_paths = 8, 60, 0.40, 5.0, 24000
rng = np.random.default_rng(20261126)
Sigma = (1-rho)*np.eye(N) + rho*np.ones((N, N))
chol = np.linalg.cholesky(Sigma)
i, j = np.triu_indices(N, 1)

def realized_corr(x):                 # x: (paths, M, N)
    x = x - x.mean(axis=1, keepdims=True)
    cov = np.einsum("pmi,pmj->pij", x, x) / (M - 1)
    sd = np.sqrt(np.diagonal(cov, axis1=1, axis2=2))
    R = cov / (sd[:, :, None] * sd[:, None, :])
    return R[:, i, j].mean(axis=1)

def draw(model, n):
    w = rng.normal(size=(n, M, N)) @ chol.T
    if model == "t":                  # 逐日 chi-square 混合 -> t Copula
        g = rng.chisquare(nu, size=(n, M)) / nu
        w = w / np.sqrt(g)[:, :, None] * np.sqrt((nu-2)/nu)
    return w

rho_hat = {}
for model in ("gaussian", "t"):
    vals = []
    for _ in range(n_paths // 2000): # 分批控制内存
        vals.append(realized_corr(draw(model, 2000)))
    rho_hat[model] = np.concatenate(vals)

for model in ("gaussian", "t"):
    r = rho_hat[model]
    print(model, "swap", r.mean()-0.40, "call K=0.50", np.maximum(r-0.50, 0).mean())
```

注意 t 混合的 $\chi^2$ 必须**逐日**抽取，且同一天所有资产共享同一个除数；若按路径共用一个 $g$，相关性估计量的分布会被完全改写，尾部定价失真。

## 七、别把模拟价当市场价

第一，本文是**风险中性分布已知**的定价实验，实盘的风险中性 Copula 要从期权报价反推，历史相关和历史尾部不能直接代入。第二，相关性互换的 payoff 依赖具体估计口径，本文用样本均值相关；用市场加权、因子中性化或中位数相关的合约，数值不可互换。第三，24000 条路径对 1.73e-05 级别的价格只有个位数的有效尾部样本，那种深度虚值报价的蒙特卡洛误差已经和价格本身同量级，文中引用它只为展示数量级差异，不宜作为可成交报价。第四，t Copula 只有单一尾部参数，真实市场在股灾中的非对称尾部更强，vine 或混合 Copula 会给出不同答案。第五，样本相关估计量在 $M$ 很小时的下偏并非缺陷，而是合约条款；把它"修正"成无偏估计会改变 payoff 定义，必须与交易对手写进确认书。

**线性相关相同的两个世界，可以给出相差两个数量级的相关性期权价。**做互换时你赌的是均值，做期权时你赌的是尾部；把这两个赌注混在一起定价，就是在替对手方免费送凸性。
