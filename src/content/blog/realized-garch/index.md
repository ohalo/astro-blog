做波动率模型的人心里都有一笔账：GARCH 每天只用到一个数字——收盘收益 r_t。可 r_t 只是当天方差的一次抽样，r_t² 估计方差的效率低到尘埃里（方差是均值的两倍）。而日内已实现波动 x_t（5 分钟平方收益和）是同一个 h_t 的精确测量，噪声只有 r² 的几十分之一。Realized GARCH（Hansen-Huang-Shek，2012）的想法一句话能说完：**别把 x_t 扔掉，把它写成 GARCH 的第二个方程**。收益方程管形状，测量方程管尺度，联合估计。本文用 2500 个交易日的合成市场，从零实现这套联合 QMLE，并 deliberately 安排两个对照实验，回答两个更实际的问题：RV 到底把钱花在哪？什么时候不花？

结论先放这：

**① 联合估计把参数误差压掉约 5 倍。** 20 条独立路径上，(a, b) 的 RMSE 从纯收益 QMLE 的 0.0148 / 0.0151 降到联合 QMLE 的 0.0029 / 0.0036；测量方程自己的两个参数 δ（杠杆）和 s_u（测量噪声）分别恢复为 −0.1485 ± 0.0068（真值 −0.15）和 0.0047 的 RMSE（真值 0.30）——这两个数字，纯收益模型根本估不出来。

**② 模型正确设定时，一步预测的误差就是参数误差。** 在这个 DGP 里 h_{t+1} 由 F_t 完全决定，所以 QLIKE 差距纯粹反映参数质量：GARCH 0.00054，Realized GARCH 0.00001——**58 倍**。参数效率直接兑换成预测精度，中间没有折扣。

**③ 但把递推里的 r² 换成 x_t（RV-GARCH）是净亏损，而且惨败 14-45 倍。** 这是全文最反直觉的结果：离散 GARCH 里 r_t² 是 h_t 的充分统计量，递推换掉它等于往滤波器里灌噪声。RV 递推只属于连续时间世界——那里日收益才是当天方差的一次抽样。

**④ 对 x_{t+1} 本身的预测，三家打平**（GARCH 代理 0.0623 / Realized GARCH 0.0618 / HAR 0.0800）：x_{t+1} 的测量噪声 s_u=0.3 主导了损失，模型差异被噪声淹没。联合模型的钱要花在参数上，不是花在 RV 点预测上。

**⑤ 噪声扫描：优势随噪声衰减但始终占优。** s_u 从 0.1 到 0.8，Realized GARCH / GARCH 的 QLIKE 比值从 0.009 单调升到 0.389——RV 越脏，联合估计越薄，但只要测度还有信息就仍然赢；同区间 RV-GARCH 的比值从 14 倍烂到 45 倍烂。

## 模型：两个方程，一个 latent h

Realized GARCH 的全部结构就三行。收益方程还是那个 GARCH：

```python
# 收益方程: r_t = sqrt(h_t) * z_t,  h_t = w + a*r_{t-1}^2 + b*h_{t-1}
h = w + a * r[t-1]**2 + b * h[t-1]
r[t] = np.sqrt(h) * z[t]          # z ~ N(0,1)
```

测量方程把 RV 接上来——x_t 是 h_t 乘一个均值 1 的乘性噪声，噪声里还藏着杠杆通道 δ：

```python
# 测量方程: x_t = h_t * u_t,  u_t = exp(delta*z_t + s_u*eta_t - (delta^2+s_u^2)/2)
u = np.exp(delta * z[t] + s_u * eta[t] - 0.5 * (delta**2 + s_u**2))
x[t] = h * u                      # E[x_t | F_{t-1}] = h_t
```

δ < 0 就是杠杆效应：坏消息日（z<0）当天已实现波动系统性偏高。E[u]=1 是对数正态的均值修正，保证 x_t 是 h_t 的无偏测量。联合 QMLE 的对数似然就是两项相加——收益的标准正态似然，加测量的对数正态似然（条件在 z_t 上，而 z_t = r_t/√h_t 是可观测的）：

```python
# 联合负对数似然（核心循环, t = 1..n-1）
h = w + a * r[t-1]**2 + b * h[t-1]
z = r[t] / np.sqrt(h)
# 收益项
nll += 0.5 * (np.log(2*np.pi) + np.log(h) + r[t]**2 / h)
# 测量项: log x_t ~ N(log h_t + delta*z_t - (delta^2+s_u^2)/2, s_u^2)
resid = (np.log(x[t]) - np.log(h) - delta*z + 0.5*(delta**2 + s_u**2)) / s_u
nll += np.log(x[t]) + np.log(s_u) + 0.5*np.log(2*np.pi) + 0.5*resid**2
```

注意一个实现细节：**δ 和 s_u 在似然里总是以 δz_t + s_u·η_t 的组合出现**，单看一天的 x_t 分不清「杠杆」和「噪声」；是收益方程提供的 z_t 把两者拆开的。这也是为什么联合估计不只是「多加一个方程」，而是两个方程互为识别。

先说 x_t 本身怎么来。实务中的已实现波动就是日内平方收益和：A 股一天 240 分钟，按 5 分钟切 48 段，x_t = Σ r_{t,j}²。若当天方差恒定，48 个平方收益的样本方差是 h_t·χ²₄₈/48，标准差只有 h_t·√(2/48)≈0.2·h_t——这就是 s_u 的理论地板，和日收益 r_t² 的 √2≈1.41 差了 7 倍。真实数据里还要叠加买卖价差跳动、开盘噪声、跳跃，把 s_u 推到 0.3-0.6；本文取 0.30 是这个区间的中位数。另一个常见变体是对数 RV 或双幂变差（抗跳跃），测量方程的结构不变，只是 u_t 的分布换一个——模型框架对测度的构造方式是开放的，这正是它比「GARCH 套一个 RV 外生变量」更通用的地方。

![合成市场：日收益、已实现波动与真实条件方差](/images/realized-garch/sim_panel.png)

本文全部实验跑在一个 DGP 上：n=2500 个交易日，真值 w=0.02, a=0.08, b=0.90（持续性 0.98），δ=−0.15, s_u=0.30。训练集 2000 天，样本外 500 天。三家估计量：**GARCH**（只用收益的标准 QMLE）、**RV-GARCH**（递推用 x_t 替换 r_t²，在 x 上做 QMLE）、**Realized GARCH**（联合 QMLE，五参数）。

## 实验一：参数恢复——RV 是免费的精度

先看参数。20 条独立路径，RMSE 摆在一起：

| 参数 | GARCH（只用收益） | Realized GARCH（联合） | 压缩倍数 |
|---|---|---|---|
| ω | 0.00408 | 0.00119 | 3.4× |
| a | 0.01477 | 0.00293 | **5.0×** |
| b | 0.01507 | 0.00361 | **4.2×** |
| δ | 估不出来 | 0.00693 | — |
| s_u | 估不出来 | 0.00466 | — |

![参数恢复：联合 QMLE 把 (a,b) 误差压掉 5 倍](/images/realized-garch/param_recovery.png)

直觉：x_t 是 h_t 的直接测量（噪声 s_u=0.3），而 r_t² 是 h_t·z²（噪声 √2≈1.41）。每天多一个精度高 4.7 倍的观测，2000 天累积下来，(a, b) 的估计误差减半再减半。δ 的恢复尤其漂亮：20 条路径均值 −0.1485，标准差 0.0068——**杠杆效应被测量方程稳稳抓住**，而这个数字在纯收益模型里根本不存在（收益方程的 QMLE 对 δ 零信息）。

## 实验二：测量方程长什么样

把 z_t 对 log(x_t/h_t) 画个散点，斜率就是 δ。用联合估计的 (a, b) 过滤出 h_t 后：

![测量方程：坏消息日的已实现波动系统性偏高](/images/realized-garch/measurement_eq.png)

OLS 斜率 −0.1486，真值 −0.15。这张图就是「已实现波动包含收益之外的方差信息」的肉眼证据：同一天里，r_t 告诉你抽了哪个 z，x_t 告诉你这次抽样之外方差本身的状态。 Engle-Russell 当年的过度分散检验、HHS 的测量方程，说的都是同一件事。

## 实验三：一步预测——以及 RV-GARCH 的惨败

样本外 500 天，预测真实的 h_{t+1}，QLIKE 说话：

| 模型 | QLIKE | MSE |
|---|---|---|
| GARCH | 0.00054 | 1.243×10⁻³ |
| RV-GARCH（递推用 x_t） | 0.01793 | 3.160×10⁻² |
| Realized GARCH | **0.00001** | **2.147×10⁻⁵** |

![波动率预测评估](/images/realized-garch/forecast_eval.png)

两个读法。第一，**Realized GARCH 赢 GARCH 58 倍，且赢得「理所当然」**：这个 DGP 里 h_{t+1} = w + a·r_t² + b·h_t 是恒等式，一步预测没有 irreducible error，QLIKE 差异 100% 来自参数误差——58 倍正好兑现实验一的 5 倍参数压缩在预测上的复利。第二，**RV-GARCH 输得最难堪，而且这不是 bug 是统计**：离散 GARCH 世界里 r_t² 是 h_t 的充分统计量，递推 h_{t+1} = w + a·x_t + b·h_t 等于用带噪测量替换精确充分统计量，滤波器方差凭空多出 a²h_t²(e^{s²}−1)。想靠「RV 更精确所以递引换 RV」占便宜，你的世界必须是连续时间的——那里日收益只是当天方差的一次抽样，r² 和 RV 都是它的估计量，而后者噪声小得多（HAR-RV 那条线就是这个世界的居民）。

那 Realized GARCH 对 x_{t+1} 本身的预测呢？三家加一个 HAR 基准：GARCH 代理 0.0623、Realized GARCH 0.0618、HAR 0.0800。**基本打平**——x_{t+1} 的损失被测量噪声 s_u 主导，模型差异淹没在噪声里。诚实结论：联合模型的钱在参数效率，不在 RV 点预测。

## 实验四：噪声扫描——RV 越脏，两种用法差距越大

把 s_u 从 0.1 扫到 0.8（每档 6 个种子），看两种用法相对纯 GARCH 的 QLIKE 比值：

![噪声扫描：递推换入始终惨败，联合估计始终占优](/images/realized-garch/noise_scan.png)

橙线（RV-GARCH）从 14 倍烂到 45 倍烂——s_u 越大，灌进递推的噪声越多，且 GARCH 完全不受影响（它看不见 x，QLIKE 恒定 0.00083）。红线（Realized GARCH）从 0.009 升到 0.389——测量方程的信息量随噪声衰减，但联合似然的信息量恒不小于边际似然，所以它**在任何噪声水平下都不该输**，实测也确实没输。实务含义：5 分钟 RV 的 s_u 通常在 0.2-0.4，正是联合模型优势最大（比值 0.02-0.08）的区间；1 分钟 RV 掺入微观结构噪声后 s_u 可达 0.6-0.8，优势缩到十分之四，但方向不变。

## 实务清单

把上面的结果翻译成可执行的动作。**第一，有日内数据就别只喂日收益**：联合 QMLE 的实现只比标准 GARCH 多约 30 行代码（一个测量似然 + 两个参数），换来 (a, b) 五倍的参数精度和 δ、s_u 两个新可观测量。**第二，别手动把递推里的 r² 换成 RV**，至少在跳跃/连续时间结构没有先验证据时不要——本实验显示这是往滤波器里灌噪声；要让 RV 进递推，请连同测量方程一起估（HEAVY、Realized GARCH 的递归变体），让似然去决定权重。**第三，把 δ 当成监控指标**：它估计得很稳（±0.007），实时跟踪 δ 的漂移比跟踪 a、b 更能揭示「收益-波动反馈结构」的变化——杠杆通道收窄往往先于波动率 regime 切换。**第四，预测评估分两个靶子**：赌 latent 波动（对冲、风控）看 QLIKE(h)，赌已实现波动本身（波动率交易）看 QLIKE(x)，两者的赢家不完全一样，别混用。

## 适用边界与遗留问题

三个诚实的备注。**一**，本 DGP 是离散 GARCH，r² 充分统计量的设定「帮」纯 GARCH 拿走了递推权；连续时间 + 跳跃的世界里结论会翻转（RV-GARCH/HEAVY 类模型的主场），本文测的是「联合估计 vs 收益估计」这一条通道，没有假装测全部。**二**，联合 QMLE 的五维优化比三维娇气得多，本文用多组初值 + Nelder-Mead 才稳住；初值离真值太远时（尤其 s_u 大的情形）容易落局部最优——信息量恒优是渐近结论，不是有限样本保证。**三**，没有碰创新分布：收益用正态、测量用对数正态都是便利假设，尾部更厚的世界需要换似然（学生 t 或半参数），那是另一篇文章。
