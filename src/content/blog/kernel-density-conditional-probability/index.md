做 regime 研究的人都干过这种事：把动量因子切成 10 个桶，数一数每个桶里"恐慌日"占多少，画一张"动量越高、恐慌概率越大"的柱状图。这张图看起来人畜无害，实际上它建立在直方图这块流沙上——**换一组 bin 起点，图就变一副样子**。

核密度估计（KDE）把直方图的"方块"换成"每个样本点放一个小高斯山包，全部叠加再除以 n"，只留一个超参数：带宽 $h$。本文用四组实验说明：为什么 regime 概率映射该用 KDE 而不是直方图，怎么用留一似然把带宽这个唯一旋钮调到点上，以及 KDE 在什么时候会骗你。

结论先放这里（全部来自现场计算）：

**① 直方图的位置敏感性是量化的，不是修辞。** 同一份 1500 点双峰样本，bin 数量固定 30，只把起点平移 0/0.25/0.5/0.75 个 bin 宽，$\mathrm{KL}(\text{真}\|\text{直方图})$ 从 0.0137 一路摆到 0.0422——**误差翻了 3.1 倍**。同一份数据的 KDE 恒定 0.0041，没有"位置"这个自由度。

**② 带宽可以用留一似然免费调优，Silverman 法则几乎白送答案。** 800 点样本上扫 60 档带宽，LOO 对数似然最优点 $\hat h = 0.277$（−1281.5）；Silverman 法则给 0.271，似然 −1281.5，**与最优持平**；Scott 法则给 0.489，−1288.4，白白亏掉 6.9 nats。

**③ regime 后验曲线是 KDE 的主场。** 把平静态 1698 点和恐慌态 702 点各做一个 KDE，贝叶斯一拼：动量 $x=0$ 时 $P(\text{恐慌})=0.09$，$x=3$ 时 $0.999$。在 1000 个未见过的测试点上，KDE 概率的校准误差 ECE = 0.023，优于等频分箱的 0.029。

**④ 冷水：小样本的尾部，KDE 会把噪声画成信号。** 只给 120 个样本，bootstrap 重采样 200 次，尾部带内的密度中位相对误差 30.9%，最右侧 5 个网格点高达 98.5%。

## 一、直方图为什么是流沙

直方图估计器 $\hat p(x) = \frac{\#\{x_i \in \text{bin}(x)\}}{n \cdot w}$ 有两个隐藏旋钮：箱宽 $w$ 和箱的**起点**。箱宽好理解，箱起点几乎没人管——但它要命：一个样本点落在哪个箱，完全取决于起点在哪。真密度取双峰混合 $0.7\,\mathcal N(-0.3, 0.8^2) + 0.3\,\mathcal N(1.9, 1.4^2)$（平静态 + 恐慌态的动量分布长这样），n=1500：

![直方图 bin 平移实验 vs KDE](/images/kernel-density-conditional-probability/fig1_hist_vs_kde.png)

左图四个半透明直方图是**同一份数据**，只平移了起点；右图 KDE（$h=0.266$）与真密度几乎重合。量化结论：$\mathrm{KL}(\text{真}\|\text{hist}) = 0.0137 / 0.0177 / 0.0256 / 0.0422$（四次全不同），$\mathrm{KL}(\text{真}\|\text{KDE}) = 0.0041$。

KDE 的公式：

$$\hat p_h(x) = \frac{1}{nh}\sum_{i=1}^n K\!\left(\frac{x - x_i}{h}\right), \qquad K = \text{标准高斯}$$

```python
import numpy as np

def kde(x, grid, h):
    # 每个样本点放一个小高斯，全部叠加
    z = (grid[:, None] - x[None, :]) / h
    return np.exp(-0.5 * z**2).sum(1) / (len(x) * h * np.sqrt(2*np.pi))

def silverman(x):
    s = np.std(x, ddof=1)
    iqr = np.subtract(*np.percentile(x, [75, 25]))
    return 0.9 * min(s, iqr/1.349) * len(x)**(-0.2)
```

## 二、带宽是唯一的旋钮，留一似然替你拧

KDE 只有一个超参数 $h$，而它恰好有一个**免费的调优目标**：留一（leave-one-out）对数似然。把第 $i$ 个点从估计里挖掉，看密度在它头顶给出多少概率——自己夸自己不有效，挖掉自己再夸才算数：

```python
def loo_ll(x, h):
    n = len(x)
    d = np.abs((x[:, None] - x[None, :]) / h)
    k = np.exp(-0.5*d**2) / (h*np.sqrt(2*np.pi))
    np.fill_diagonal(k, 0.0)            # 关键：挖掉对角线=该点自己
    f = k.sum(1) / (n - 1)
    return np.log(np.maximum(f, 1e-300)).sum()
```

![带宽扫描：LOO 似然 vs h](/images/kernel-density-conditional-probability/fig2_bandwidth_loo.png)

800 点样本、60 档带宽的对决：LOO 峰值在 $h=0.277$（−1281.5），Silverman 0.271 几乎踩中正中心，Scott 0.489 偏胖、似然 −1288.4。左边的"过拟合悬崖"（$h\to0$ 时 LOO 断崖式塌陷，因为模型在记忆训练点）在图上清晰可见。**实务建议：无脑用 Silverman 起步，再用 LOO 扫一遍确认，成本是几行代码。**

## 三、regime 后验：两个条件 KDE + 一次贝叶斯

regime 概率映射想要的东西是 $P(\text{恐慌} \mid \text{动量} = x)$。拿到过历史 regime 标签（事后标注的也行），它就是两个条件密度的比值：

$$P(\text{恐慌} \mid x) = \frac{\pi_b\, p_b(x)}{\pi_a\, p_a(x) + \pi_b\, p_b(x)}, \qquad p_a = \text{KDE}(\text{平静态}),\ p_b = \text{KDE}(\text{恐慌态})$$

![regime 条件密度与后验曲线](/images/kernel-density-conditional-probability/fig3_regime_posterior.png)

2400 点样本切成平静态 1698 / 恐慌态 702，后验曲线单调爬升：$x=-2$ 处 0.054，$x=0$ 处 **0.092**（远低于 0.3 的先验），$x=3$ 处 **0.999**。这条连续的 S 形曲线替代了"桶 1 恐慌率 2%、桶 2 恐慌率 7%……"的阶梯表——桶边界处该信哪个数的问题不复存在。

## 四、校准对质：KDE vs 等频分箱， unseen 数据上见真章

概率模型不能只看不准，得上校准曲线。训练集 1000 点，测试集 1000 点全部未见。选手 A 是 KDE 后验；选手 B 是最常用的土办法——动量按训练集十分位切 10 个等频桶，每桶数恐慌频率当概率。测试点按各自预测概率再分十档，比较"预测概率 vs 实际频率"：

![校准曲线对比](/images/kernel-density-conditional-probability/fig4_calibration.png)

两个选手都贴着对角线（相关系数 0.9971 vs 0.9961），但期望校准误差 ECE：**KDE 0.023，分箱 0.029**。分箱输在桶内"一刀切"——桶边界两侧各 0.01 的点被迫共享同一个概率，而 KDE 给它们不同的数。优势不大，但方向正确，且在桶数少（比如只有 5 桶）时差距会拉得更开。

## 五、泼冷水：小样本的尾部是 KDE 的坟场

KDE 的温柔（处处可导、无双峰失真）有个代价：**尾部没有数据撑着的时候，它会若无其事地瞎画**。取 n=120（约半个月的极端样本），bootstrap 重采样 200 次，看 $x\in[3,6]$ 右尾上中位密度曲线离真密度有多远：

![小样本尾部 bootstrap 不确定带](/images/kernel-density-conditional-probability/fig5_small_sample_tails.png)

带内中位相对误差 **30.9%**，最右侧 5 个网格点 **98.5%**——差不多是重新编了一个数。更阴险的是 KDE 看起来"挺平滑"：图上的曲线毫无破绽，直到你去核真值。**纪律：尾部概率要配 bootstrap 带一起看；带宽由主体数据的 Silverman 决定，天然照顾不到尾部分辨率（尾部需要局部带宽或极端值理论）。** 用 KDE 输出 0.3% 的"崩盘概率"之前，先问一句：撑这条尾巴的样本有几个？

## 六、把零件装起来：regime 概率映射四步法

1. **备标签**：先有一个（哪怕是事后视角的）regime 划分——阈值法、波动率分位、或者下一篇要讲的 GMM；
2. **各成一族**：每个 regime 的条件特征单独做 KDE（Silverman 起步，LOO 似然确认带宽）；
3. **贝叶斯合体**：混合先验得后验曲线，输出连续概率而不是桶表；
4. **校准 + 不确定带**：E 个 decile 的校准图上对质 ECE；样本少的一律附 bootstrap 带，尾部没有 30 个以上样本的概率不出门。

四步跑完，你手里的"动量 → 恐慌概率"就不再是十根柱子的阶梯，而是一条校准过、带置信带的函数。下一篇我们用高斯混合模型（EM 算法）把"标签从哪来"这个问题也自动掉——不用先分 regime，让模型自己发现市场有几个态。
