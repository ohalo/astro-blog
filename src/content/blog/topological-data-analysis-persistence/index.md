Kac 那句"你不知道你在说什么，直到你会把它画出来"在量化里有个更刻薄的版本：**你不知道你的统计量在测什么，直到它在随机游走上跑一遍**。今天的主角是拓扑数据分析（TDA）：不测均值、不测方差，测数据"绕不绕圈"。听起来玄，但它在金融里的卖点很具体——一个在 (收益, 波动) 平面上打转的系统，和一个在原地布朗抖动的系统，均值方差可以全部一样，**但一个有洞，一个没有**。

先说结论，免得"拓扑"两个字替你原谅含糊（全部为本文现场计算，seed=20261027，手写 Rips 持续同调，未用 gudhi/Ripser）：

**① 洞是真的能数出来的。** n=110 的带噪圆周（σ=0.07）在 Rips 过滤下恰好生成 1 条长寿 β1 持续对：出生 0.323，死亡 1.552，长度 **1.229**，比它的噪声底（下一条 β1 只有 0.043）高 28 倍。同样规模的标准高斯云最长 β1 是 **0.476**，且没有一条在尺度上离群。

**② 做成检测器能打。** 对 900 天合成序列（周期 p=24 的均值回归震荡 vs 随机游走），延迟嵌入 e=10、PCA 到 2 维、抽 80 点，统计量取"死亡 ≤1.8（σ 单位）的最长有限 β1 条长度"。60 个随机游走校准出 5% 阈值 **0.1915**（零假设均值仅 0.0244）：噪声/振幅比从 0.2 到 1.5，检出率 **0.917~1.0**；噪声堆到振幅 3 倍，掉到 **0.5**。

**③ 但嵌入维是反直觉的。** 固定噪声比 1.0，e=6 在全部 5 个周期（10~60 天）上检出率 **1.0**；e=20 只有 **0.50~0.75**。教科书说"嵌入维取半周期"，实测说"嵌入越深，PCA 抓到的噪声越多"。

**④ 跟传统方法对轰：输得很干脆。** 方差比 VR(12)（滞后=半周期，把周期先验诚实地喂给对手）、同样 5% 校准，在全部噪声比上检出率 **1.0**。单变量均值回归不是 TDA 的战场——VR 用的是同一条信息（序列沿周期的自相关）且不需要抽样、嵌维、PCA 这三层任意性。TDA 的合法卖点只在 VR 无法定义的地方：多资产、平面闭合轨道、跨尺度结构。

## 一、五分钟把持续同调说到可计算

Rips 复形：给定规模 ε，点距 ≤ε 就连边，三边全在就填三角形，四维全在就填四面体——ε 从 0 长到 ∞，复形一路膨胀。0 阶同调 β0 数连通块，1 阶 β1 数"洞"（闭合环且内部没被三角形填死）。每个块/洞有出生、死亡两个坐标，画在平面上就是**持续图**：越靠对角线越是噪声，离对角线越远越是结构。

β0 用 union-find 一行流：边按权排序，连两个分量的边就"杀死"晚出生的块（出生=该分量合并时刻，死亡=边权）。β1 的朴素做法要在天文数字的环里做线性代数，Ripser 的关键化简本文照抄：**生成森林直接商掉**。按边权顺序建森林，"成环边"（约 n−1 条到全连通为止）构成 H1 生成元的基，每个三角形的边界在商空间里就是基向量的一个 Z2 子集——用一个 Python 整数的 bit 位表示，列约化就是异或：

```python
def rips_persistence(P, max_r):
    D = squareform(pdist(P))                      # 欧氏距离阵
    E = sorted((i, j, D[i, j]) for i, j in zip(*np.triu_indices(len(P), 1)))
    parent = list(range(len(P)))                  # union-find 见正文
    co_tree, edge_bit = [], {}
    b0 = []
    for a, b, v in E:
        if v > max_r: break
        ra, rb = find(a), find(b)
        if ra != rb:                              # 森林边：杀死较晚出生的块
            b0.append((max(birth[ra], birth[rb]), v))   # 点生于 0，实则全是 (0, v)
            union(ra, rb)
        else:                                     # 余树边 = H1 基向量
            edge_bit[(a, b)] = len(co_tree); co_tree.append((a, b, v))
    tri = []                                      # 三角形 → 余树边集的 bitmask
    for (a, b, c) in all_triangles_within(E, max_r):
        bits = 0
        for (u, w) in ((a, b), (a, c), (b, c)):   # 森林边在商空间中为 0
            if ekey(u, w) in edge_bit: bits ^= 1 << edge_bit[ekey(u, w)]
        tri.append((max(D[a,b], D[a,c], D[b,c]), bits))
    pivots, b1 = {}, []
    for vtri, col in sorted(tri):                 # 按杀死尺度排序
        c = col
        while c:
            p = c.bit_length() - 1
            if p in pivots: c ^= pivots[p]
            else:
                pivots[p] = c
                b1.append((co_tree[p][2], vtri))  # 边 p 的洞在 vtri 处被填
                break                             # c==0：三角形约化为闭链
    return b0, b1
```

三个单元对照实验验证实现：正六边形顶点 → 恰 1 条长条 (1.00→1.732)，其余 9 条 β1 全为零长；10 点圆周 → 最长条 1.284，其余为 0；实心 6×6 网格 → 最长仅 0.166。手算对得上再往下走。

## 三、做成检测器：随机游走校准的功效曲线

金融数据没有"真洞"给你对答案，所以自造：AR(2) 生成周期 24 天的平稳震荡，用最优一步预测 f_t 拆出可预测分量、残差 d_t 拆出噪声，各自标准化后按噪声/振幅比 snr 合成——snr 就是这条序列"可预测性"的标尺。零假设用 60 条随机游走。

统计量：延迟嵌入 e=10 → 整体 std 归一 → PCA 前 2 维 → 抽 80 点 → Rips 到 1.8（σ 单位）→ 最长有限 β1 条。固定 1.8 这个截断是设计选择：调 2.2/2.6 也可用（功效 0.96），但 1.8 下零假设分布最紧。

![功效曲线](/images/topological-data-analysis-persistence/fig3_power_vs_noise.png)

(a) 左：随机游走的统计量几乎全堆在 0（60 个样本均值只有 0.0244，阈值 0.1915 取其 95 分位——这是"分布自由"校准，不需要任何渐近理论）；OU 震荡的分布整体右移。(b) 右：snr 0.2（振幅是噪声 5 倍）到 1.5（噪声 1.5 倍振幅）全区间检出率 ≥0.917；snr=3.0 时半数漏检——洞在噪声里被提前填死了（OU 统计量中位数从 0.54 一路阴跌到 0.193）。

## 四、嵌入维的反直觉：越深越瞎

TDA 教程总强调 Takens 定理：嵌入维至少 2×流形维数+1。金融信噪比下这条经验反着来：

![周期敏感性](/images/topological-data-analysis-persistence/fig4_period_sensitivity.png)

snr=1.0，横轴信号周期，四条线不同嵌入维。e=6 全部周期 1.0 检出；e 每加一档，功效掉一截，e=20 最差 0.50。原因不玄：e 维延迟向量的噪声各维独立，e 越大，"纯噪声方向"上的点数散布越接近各向同性高斯——PCA 抽 2 维时恰好把真圆环从噪声雾里捞出来的概率越低，而信号方向只有 1 维，e=6 早已够 PCA 锁定它。金融时序的 TDA，**先当作特征工程调，再当作拓扑学信**。

## 五、跟方差比对轰，输掉才诚实

拓扑能测"绕圈"，那把传统武器摆上来：Lo–MacKinlay 式方差比 VR(k)——随机游走时 VR→1，均值回归时 VR<1。用本文同一套随机游走校准 5% 阈值（95 分位 = 1.3745），k 取半个信号周期 12（等于把周期先验双手奉上）。

![对照方差比](/images/topological-data-analysis-persistence/fig5_vs_vr.png)

VR 在全部 7 档噪声比上检出率 1.0，包括 TDA 掉到 0.5 的 snr=3.0。没有悬念：**"周期性均值回归"就是自相关结构**，VR 直接在相关函数上动手，不需要把序列折叠成点云再数洞——三层有损压缩（抽样、嵌维、PCA）之后信息只会少不会多。

那 TDA 什么时候上桌？两个条件同时成立：(a) 特征是**几何闭合**而非单变量自相关——比如 (β 敞口, 残差动量, 波动) 三资产轨道绕一圈回到原点，任何单变量统计量对闭合免疫；(b) 噪声结构是**各向异性**的，VR 假设的"高斯鞅差"不成立而"绕圈"仍成立。本文的合成设计故意选了 TDA 的最差场景——单变量、高斯噪声——因为用对轰输出来的边界，比用演示赢出来的信仰值钱。

## 六、实现与复现

完整脚本 `scripts/gen_tda_persistence.py`（seed=20261027，系统 Python，依赖 numpy/scipy/matplotlib，无 sklearn/gudhi），全流程 ~14 秒：

```python
# 检测统计量：Rips(≤1.8σ) 内最长有限 β1 条
E, CAPT = 10, 1.8
def stat(y, m=80):
    X = delay_embed(y, E); X = X[rng.choice(len(X), m, replace=False)]
    P = pca2(X); P /= P.std()
    _, b1, *_ = rips_persistence(P, CAPT)
    return max([d - a for a, d in b1] + [0.0])

null = [stat(gen_rw(900)) for _ in range(60)]        # 零假设校准
thr = np.quantile(null, 0.95)                         # = 0.1915
# 对任意新序列：stat(y) > thr → 在 5% 水平上拒绝"无闭合结构"
```

坑笔记：① 100 点的 bitmask 整数约化在小 ε 下三角形爆炸，`max_r` 截断（本文 1.8）既是统计选择也是防爆措施；② 未杀条（essential）在固定截断下会被截成长假条，统计量里**只用"死在窗口内"的有限条**，否则随机游走因抽样不连通会伪造长条——这是调试本文实验时真金白银踩出来的；③ PCA 前必须按整体 std 归一，否则 1.8 这个固定阈值随序列波动率漂移，功效曲线就成了波动率检测器。

**一句话收束**：持续同调把"有没有洞"变成一个可校准、可证伪的统计量，这是它比 PPT 上的 TDA 美图诚实的地方；而它在一个自相关任务上被 VR 打满全场，也是它比美图更值得信的地方——**你知道它的边界，才算知道它的价值**。
