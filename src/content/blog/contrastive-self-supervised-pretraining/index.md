标注数据贵、噪声大、还容易过拟合——这是做量化因子的人最熟的痛点。监督学习（给每条 K 线贴个涨跌标签）把模型绑死在标签上，换个标的换段时间就垮。自监督对比学习走另一条路：**不给你标签，只告诉你「这俩片段是同一段的不同增广视角，应当靠近；跟别的段应当远离」**。模型为了完成这个 pretext task，被迫把数据的「语义」——比如一段正弦的频率、一段成交的节律——挤进一个向量。等表征学好了，下游随便接一个逻辑回归或 KNN 就能干活。

SimCLR（Chen et al., 2020）是对比学习里最干净的一招，分四步：

1. 对同一样本做**两次随机增广**，得到两个视角 $x_i, x_j$；
2. 编码器 $f_\theta$ 把每段映射到表示 $h$；
3. 投影头 $g_\phi$ 再映射到一个低维空间并 L2 归一化，得 $z$；
4. **NT-Xent** 损失：同一对的 $z_i,z_j$ 互为正样本，batch 内其余 $2N-2$ 个全为负样本，温度 $\tau$ 控制对困难负样本的惩罚力度。

本文在一段**合成的时序分类**上把这套跑通，并量化它到底比「直接用原始信号」强在哪。结论先放这里（全部数字来自本次运行，seed=20261028）：

**① 自监督表征让下游线性模型满分，原始信号只有一半。** 数据：4 类不同频率的正弦（$\omega\in\{0.10,0.18,0.28,0.40\}$），每类 250 条、长度 64、加 $\sigma=0.12$ 噪声，700 训练 / 300 测试。冻结编码器后做线性探测（在表征上训一个逻辑回归），SimCLR 表征准确率 **100%**；而**直接在原始 64 维信号**上训同样的逻辑回归只有 **50.3%**；随机基线 25%。**关键洞察**：原始正弦信号其实是**非线性可分但线性不可分**的——KNN 在原始空间也能拿 **100%**，说明近邻能靠形状认出频率，但一个线性平面划不开；SimCLR 的价值正是把「频率语义」压进一个**线性可分**的向量。

**② 类内/类间分离比，表征空间是原始空间的 2000 倍。** 用朴素的距离比（类间均值距离 / 类内方差）度量：表征空间 **40.02**，原始 64 维空间 **0.02**。也就是说，原始空间里同类样本（不同相位、振幅、噪声）彼此散得很开，类别边界糊成一团；编码器把相位/振幅这些「风格」剥离，只留下频率这个「内容」。

**③ 对比损失确实在降，但幅度温和。** NT-Xent 从首轮 **5.4483** 降到末轮 **4.2674**，降幅 **21.7%**（温度 $\tau=0.5$）。这不是监督学习那种断崖式下降，而是对比学习特有的「慢慢把相似对拉近」——但下游探测准确率在第一轮就已经摸到天花板。

**④ 收敛曲线：这个 4 频率任务对 SimCLR 来说太简单，首轮就到位。** 线性探测准确率在第 1 epoch 就 **0.9933**，第 21 epoch 起稳定 **100%**。曲线本身没什么「形状」可言，但它说明一件事：只要存在清晰、可区分的底层语义（这里是频率），SimCLR 几乎瞬间就能抓到——真正难的、需要长训练的，是语义被噪声和无关维度层层包裹的真实金融序列。

五个实验逐一展开，代码全部可运行（依赖 `torch`）。

## 一、增广：SimCLR 要学到「变的是噪声，不变的是语义」

增广是 SimCLR 的灵魂。对一段时序 $x$，我们随机施加四样扰动：加抖动（高斯噪声）、缩放（乘一个 $0.7\sim1.3$ 的因子）、随机遮罩（把一段置零）、随机符号翻转。两个视角 $x_i,x_j$ 用**独立**的随机增广。模型必须学会：无论怎么抖、怎么遮、怎么缩，这段的频率「身份」不变——于是「频率」被强制写进表征，而「噪声/相位/振幅」作为与任务无关的样式被平均掉。

![同一段时序的两个增广视角](/images/contrastive-self-supervised-pretraining/fig1_augmentations.png)

左图是原始样本，中右两图是同一段的两个增广：形态各异，但底层频率一致。这正是 SimCLR 想让编码器「看穿」的东西。

## 二、NT-Xent：让正样本对靠近、负样本远离

![](/images/contrastive-self-supervised-pretraining/fig2_loss.png)

损失曲线从 5.45 平缓降到 4.27。注意 NT-Xent 的量级：因为相似度是「点积除以温度」后再做 softmax，值在几个 nat 的量级，不像 MSE 那样趋近于 0。判定对比学习有没有在学，不看损失绝对值，看**下游探测准确率**——那才是真金。

## 三、表征空间里的聚类：原始空间糊成一团，编码后清清楚楚

把测试集表征做 PCA 降到二维、按真实频率着色：

![](/images/contrastive-self-supervised-pretraining/fig3_embedding_pca.png)

四个频率各成一簇，几乎没有交叠。对比右图（若画原始信号的 PCA，四个频率的点会互相穿插——因为相位/振幅的方差远大于频率差异，把簇冲散了）。分离比 40.0 vs 0.02 就是这个视觉差异的定量版。

## 四、线性探测 / KNN：SimCLR 的真正价值是「线性可分」

![](/images/contrastive-self-supervised-pretraining/fig4_probe.png)

这张图是本篇最核心的一张。横轴三个基线：SimCLR 表征、原始信号、随机。**线性探测**那组（红+灰）才是重点——SimCLR **100%**、原始信号 **50.3%**、随机 25%。而 **KNN**（绿+蓝）两侧都是 **100%**：原始信号虽然线性划不开，但近邻能靠形状认出频率。

这就把「自监督表征到底有什么用」讲透了：它不创造新信息，而是**把本来非线性可分的信息，重排成一个线性可分的空间**，让你的下游模型可以是一个便宜的线性层、一个透明的逻辑回归，而不是一个黑盒深网。对量化尤其重要——因子可解释性、可审计性，往往就卡在「线性」这两个字上。

## 五、收敛：清晰语义下，SimCLR 首轮即到位

![](/images/contrastive-self-supervised-pretraining/fig5_probe_curve.png)

线性探测准确率在 epoch 1 就 0.9933、epoch 21 起满 100%。曲线本身没有戏剧性，但它传递一个诚实的信号：当底层语义（频率）清晰、与其他维度解耦良好时，SimCLR 收敛极快；真实金融序列的语义被微观结构噪声、 regime 切换、幸存者偏差层层包裹，那时才需要更长的训练、更讲究的增广（比如保留趋势/翻转不变性、丢弃绝对价位），以及更大的 batch 和更多负样本。

核心代码（编码器 + NT-Xent，完整实现见仓库 `scripts/gen_simclr_ts.py`）：

```python
import torch, torch.nn as nn, torch.nn.functional as F

class Encoder(nn.Module):
    def __init__(self, rep_dim=64):
        super().__init__()
        self.c1 = nn.Conv1d(1, 16, 5, padding=2)
        self.c2 = nn.Conv1d(16, 32, 5, padding=2)
        self.fc = nn.Linear(32, rep_dim)
    def forward(self, x):                      # x: (B,1,L)
        h = F.relu(self.c1(x)); h = F.max_pool1d(h, 2)
        h = F.relu(self.c2(h))
        return self.fc(F.adaptive_avg_pool1d(h, 1).squeeze(-1))

class Projector(nn.Module):
    def __init__(self, rep_dim=64, proj_dim=32):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(rep_dim, rep_dim), nn.ReLU(),
                                 nn.Linear(rep_dim, proj_dim))
    def forward(self, z):
        return F.normalize(self.net(z), dim=1)  # L2 归一化

def nt_xent(z1, z2, temp=0.5):
    z = torch.cat([z1, z2], 0)                 # 2N
    sim = z @ z.t() / temp
    N = z1.shape[0]
    mask = torch.eye(2*N, dtype=torch.bool)
    sim.masked_fill_(mask, -9e15)
    pos = torch.cat([(z1*z2).sum(1, keepdim=True)/temp,
                     (z2*z1).sum(1, keepdim=True)/temp], 0)
    return -torch.mean(pos - torch.logsumexp(sim, 1, keepdim=True))
```

注意 `nt_xent` 里把正样本对（第 $i$ 个与第 $i+N$ 个）从 $2N$ 个点里挑出来当 numerator，其余 $2N-2$ 个全当 denominator 里的负样本——这就是 SimCLR「靠大 batch 凑负样本」的本质。batch 越大、负样本越多，表征质量越好；小 batch 下这条损失很容易塌成退化解（所有 $z$ 都挤到一点）。

## 结论

SimCLR 用「无标签对比」把时序的语义压进一个线性可分的表征：本文合成实验里，它把 4 频率分类的线性探测从 50.3% 拉到 100%，类内/类间分离比提升 2000 倍。落到量化，最有价值的不是「精度更高」，而是「下游可以用一个透明的线性模型」——因子可解释性、可审计性、低延迟推理全受益。但要清醒：合成数据语义干净、收敛极快，真实行情需要更狠的增广、更大的 batch、以及对「哪些变换该保持不变」的先验。把 SimCLR 当因子预训练的起点，而不是终点。
