## 一、结论先行

量化研究员每天面对上千个因子的 IC、t 值、分组收益差。最常见的两个做法是：要么直接用每个因子的点估计排序（谁大选谁），要么逐个做 t 检验、只留住显著的。前者被噪声灌水，后者在多重检验下手软。经验贝叶斯给出第三条路：让因子之间**互相借力**，用全体因子的分布去约束每一个因子。

本文用真值已知的合成实验把收益和边界算清楚。500 个因子，15% 埋了真 alpha，观测是 $x_i=\theta_i+\varepsilon_i$，$\varepsilon_i\sim N(0,1)$。

先说收益。直接用 $x_i$ 估 $\theta_i$，均方误差 **1.075**；James-Stein 正部收缩把它压到 **0.278**，降 74%；非参数经验贝叶斯（对先验做复合分布 EM）再降到 **0.222**，降 79%。这不是调参的功劳——收缩强度是从数据里估出来的，不依赖任何手工阈值。

再说为什么"高维"反而是帮手。维度实验里 p=3 时原始 MSE 只有 0.121（只有 1 个因子带真信号、种子下真效应弱），到 p=5000 时原始 MSE 涨到 **1.005**，而 JS 收缩估计始终稳定在 0.02–0.29 之间。原始误差随 p 增长八倍，收缩估计几乎纹丝不动——**要收缩的均值越多，越能把分布在全体上估准，每个因子的估计就越沾光**。这正是 Stein 悖论的实质——三个以上的不相关正态均值，联合估计严格优于逐个估计。

最后说边界。所有收缩方法都假设各因子的估计误差**相互独立**。我构造了带共同因子的相关误差（等相关 $\rho$ 从 0 到 0.9）：ρ=0.6 时独立假设的 EB 收缩 MSE 还有 0.290，和剥离共同因子的 oracle 打平；ρ=0.9 时前者恶化到 **0.733**，后者仍保持 **0.206**。当误差高度相关，全体因子不再提供 500 份独立信息——它们可能只是同一个宏观冲击的 500 个投影，借力变成了共谋。

**一句话：因子越多、越独立，收缩越值；因子估计被共同因子绑在一起时，先剥离相关结构，再谈收缩。**

## 二、James-Stein 悖论：为什么"明显更准"违反直觉

设你估了 p 个因子的真实均值 $\theta_1,\dots,\theta_p$，各有一个观测 $x_i\sim N(\theta_i,1)$。逐个看，$x_i$ 是 $\theta_i$ 的无偏估计，似乎无可挑剔。Stein 在 1956 年证明了一件事：当 $p\ge 3$，把**所有** $x_i$ 一起朝 0 收缩的估计量

$$\hat\theta^{\mathrm{JS}} = \left(1 - \frac{p-2}{\sum_i x_i^2}\right) x$$

在总均方误差上**严格小于**原始估计，不管真实 $\theta$ 是多少。直觉上这很荒谬——如果某个因子的真 alpha 是 2.0，把它往 0 拉怎么可能更准？答案在于：你不知道哪个是真 2.0、哪个是噪声冒出来的 2.0。收缩用整体均方作为"总信号强度"的代理：全体 $x_i$ 的平方和若只比 p 大一点，说明大概率大部分是噪声，那就集体狠缩；平方和远大于 p，说明有真信号，收缩自动变轻。

我在实现里加了一个细节——**正部修正**（positive-part Stein）：

```python
def js_shrink(x):
    p = len(x)
    c = 1.0 - (p - 2) / np.sum(x**2)
    return np.maximum(0.0, c) * x
```

当 $\sum x_i^2 < p-2$ 时，括号会变成负数，把每个 $x_i$ 符号翻转——这显然不合理（收缩不该把方向调头）。取正部后，收缩系数最低为 0，即全部归零。Baranchik 在 1970 年代证明了正部修正还**严格优于**原始 JS。这是个容易漏掉的工程细节，却直接影响尾部情形的合理性。

## 三、Efron-Morris：把收缩强度也交给数据

James-Stein 假设噪声方差已知为 1，且默认先验是"以 0 为中心、方差无穷大"的 diffuse 先验。Efron 和 Morris 在 1970 年代把它推进了一步：假设 $\theta_i\sim N(0,\tau^2)$，那么边际分布 $x_i\sim N(0,\sigma^2+\tau^2)$，于是

$$\hat\theta_i = \frac{\tau^2}{\tau^2+\sigma^2}\,x_i$$

收缩系数 $\tau^2/(\tau^2+\sigma^2)$ 可以直接从全体 $x$ 的样本二阶矩估出来：

```python
def eb_normal(x, sigma2=1.0):
    tau2 = max(np.mean(x**2) - sigma2, 1e-8)
    shrink = tau2 / (tau2 + sigma2)
    return shrink * x, tau2, shrink
```

本实验中真值 $\mathrm{Var}(\theta)=0.368$，估出 $\hat\tau^2=0.451$（因为噪声方差也被算进了边际二阶矩，估计略偏高），收缩系数 0.311。注意这里只有一个超参数 $\sigma^2$ 需要外部给定——它是因子 IC 估计的标准误，实践中可以从 Newey-West 标准误、或因子分组收益差的 t 统计量反推。

更进一步，先验未必是正态。金融因子的 alpha 分布往往尖峰厚尾——大量因子真效应接近 0，少数几个特别大。我用 Efron 的 g-modeling 思路做了一个简化的**非参数 EB**：在 $[-4,4]$ 上放 61 个支撑点，用 EM 估先验在各点的质量 $\pi_k$，再算每个 $x_i$ 的后验均值：

```python
def eb_nonparam(x, sigma2=1.0):
    grid = np.linspace(-4, 4, 61)
    pi = np.ones(len(grid)) / len(grid)
    for _ in range(500):
        ll = -(x[:, None] - grid[None, :])**2 / (2*sigma2)
        resp = np.exp(ll - ll.max(axis=1, keepdims=True)) * pi[None, :]
        resp /= resp.sum(axis=1, keepdims=True)
        pi_new = resp.mean(axis=0)
        pi_new = np.maximum(pi_new, 1e-12) / np.sum(np.maximum(pi_new, 1e-12))
        if np.max(np.abs(pi_new - pi)) < 1e-7:
            pi = pi_new
            break
        pi = pi_new
    ll = -(x[:, None] - grid[None, :])**2 / (2*sigma2)
    rw = np.exp(ll - ll.max(axis=1, keepdims=True)) * pi[None, :]
    rw /= rw.sum(axis=1, keepdims=True)
    return rw @ grid
```

结果是 $1.075\to0.278\to0.222$——非参数先验比正态先验又多挤出了 20% 的误差。代价是计算量：EM 迭代 500 轮，每轮一个 500×61 的矩阵，但相对因子筛选的规模这点开销可以忽略。

## 四、稀疏度与维度：什么时候收缩最值

收缩的收益不是固定的，它取决于真效应有多稀疏、以及你同时估了多少个因子。

稀疏度实验固定 p=500，改变有真 alpha 的因子比例 ρ：ρ=0.02 时几乎全是噪声，非参数 EB 的 MSE 只有 **0.066**（收缩几乎把一切都归零，而真值也几乎全 0，所以非常准）；ρ=0.80 时大部分因子都有真信号，非参数 EB 的 MSE 升到 **0.636**，原始估计约 1.0——收缩仍然赢，但优势从 94% 缩到 36%。

![MSE 随稀疏度变化](/images/empirical-bayes-factor-shrinkage/fig2_mse_vs_sparsity.png)

这个规律有实践含义：如果你研究的是"因子动物园"式的大规模筛选（几千个因子里少数几个有真信号），收缩的收益最大；如果你确信手上 20 个因子全是精挑细选的真信号，收缩帮不了太多，甚至可能过度压制——James-Stein 的理论保证是"总 MSE"，不保证每个因子都变准。

维度实验更戏剧化。p=3 时原始 MSE **0.121**、JS **0.019**，两者都低——因为只有 1 个因子带真信号、且这个种子下真效应抽得很弱，估计哪都不难。p=10 时原始冲到 0.902，JS 只有 0.295；p=5000 时原始 **1.005**，JS **0.191**。把 p 从 3 拉到 5000，原始估计的误差翻了八倍，收缩估计几乎纹丝不动——**维数越多，收缩从噪声里省下的绝对误差越大**（p=3 时省 0.10，p=5000 时省 0.81）。这是 Stein 悖论最实用的形态：与其挑出 10 个因子一个个精估，不如把 1000 个一起收缩。

## 五、相关误差：500 个因子可能只是 1 个因子的 500 个影子

所有上述方法共享一个假设：各 $x_i$ 的估计误差独立。真实市场中这个假设经常崩——一批"价值因子"可能都在押注同一个宏观预期，一批"动量因子"可能共享同样的拥挤度冲击。

我用一个共同因子 $F$ 生成相关误差：$e_i=\sqrt{\rho}F+\sqrt{1-\rho}\varepsilon_i$，这样误差的等相关系数正好是 $\rho$。对照组是"oracle：已知共同因子并剥离"——它代表你能识别出宏观冲击、在残差上做收缩的理想情形。

![相关误差下的失效](/images/empirical-bayes-factor-shrinkage/fig4_correlation.png)

结果：ρ=0 时原始 MSE 1.04、JS 0.122、oracle 0.120，收缩大胜且与 oracle 打平；ρ=0.3 时三者都降到 0.19 附近（共同因子恰好带走了部分真信号的方差，是个巧合，不要过度解读）；ρ=0.6 时独立假设的 EB 0.290、oracle 0.290，仍打平；ρ=0.9 时独立 EB **0.733**、JS **0.737**，而 oracle 只有 **0.206**——差了 3.5 倍。

原因很直白：ρ=0.9 时，500 个因子的误差里 90% 的方差来自同一个 $F$。独立假设的收缩把这当成"500 份信息"来做统计，实际上只有"1 份共享冲击 + 500 份弱独立残差"。shrinkage 系数被共同因子撑大，结果把噪声当信号留了下来。oracle 先把 $F$ 剥离（实践中可以通过对因子收益矩阵做 PCA、取第一主成分当作宏观因子来近似），再在残差上收缩，就回到了独立情形的收益。

这里有个诚实的提醒：图 4 的 ρ=0.3 那一行三者数字接近纯属随机种子下的巧合，不是"相关性反而帮忙"的证据。看趋势就好——相关性越高，独立假设越危险。

## 六、落地到因子研究：三个建议

第一，**收缩前先去相关**。对因子收益或 IC 序列做 PCA，如果第一主成分解释力异常高（比如超过 30%），先把它当共同宏观因子剥离，再对残差做 EB 收缩。本文的 oracle 就是这个流程的理想版。

第二，**别把收缩当显著性检验**。James-Stein 和 EB 给的是点估计的改进，不直接给 p 值。它们回答的是"给定我认为这组因子来自同一个分布，每个因子的真效应最可能是多少"，不是"这个因子是否显著非零"。两者可以配合：先收缩排序，再对入选者做严格的多重检验校正。

第三，**报告 MSE 而不是命中率**。收缩的价值在期望意义的风险下降，单次回测里它可能让某个真因子看起来"被削弱了"。评估要用样本外均方误差、或组合层面的风险指标，而不是"我选中的因子这个月涨了多少"。

## 七、结论

经验贝叶斯把"上千个因子一起估"从一个统计难题变成了一个借力游戏。真值已知实验里，原始 z 值 MSE 1.075，James-Stein 0.278，非参数 EB 0.222；因子从 3 个涨到 5000 个，收缩的收益从微不足道涨到 81%。但这个杠杆的支点是独立性：误差相关 $\rho=0.9$ 时，独立假设下的收缩 MSE 0.733，先剥离共同因子的 oracle 0.206。**收缩不是免费的午餐，它是拿"因子们共享一个分布"这个假设换来的；当这个假设被共同因子悄悄架空，先修假设，再修估计量。**

## 附：完整可运行代码

```python
import numpy as np

def js_shrink(x):
    p = len(x)
    c = 1.0 - (p - 2) / np.sum(x**2)
    return np.maximum(0.0, c) * x           # 正部修正

def eb_normal(x, sigma2=1.0):
    tau2 = max(np.mean(x**2) - sigma2, 1e-8)
    shrink = tau2 / (tau2 + sigma2)
    return shrink * x, tau2, shrink

# 真值: 500 因子, 15% 有真 alpha
rng = np.random.default_rng(20261125)
p = 500
theta = np.zeros(p)
idx = rng.choice(p, int(p*0.15), replace=False)
theta[idx] = rng.normal(0, 1.5, len(idx))
x = theta + rng.standard_normal(p)

mse = lambda est: float(np.mean((est - theta)**2))
print("raw  MSE:", round(mse(x), 4))          # ~1.07
print("JS   MSE:", round(mse(js_shrink(x)), 4))  # ~0.28
eb, tau2, s = eb_normal(x)
print("EB   MSE:", round(mse(eb), 4), " shrink:", round(s, 3))  # ~0.28, ~0.31
```
