市值加权指数有一个反直觉的性质：涨得越多的股票权重越大。Smart Beta 的思路是把权重规则从「市值」换成「因子」——按股息率、波动率、盈利稳定性这些可测特征重新分配权重，让组合系统性地偏向被认为有超额收益的特征。红利 + 低波是 A 股最流行的 Smart Beta 组合（中证红利低波 100 一类指数的构造逻辑），学术上对应 Frazzini-Pedersen 的 BAB（低波异象）与 Novy-Marx 的盈利溢价。本文用 500 只合成股票把这三条通道**分别植入、分别测量**，回答三个问题：综合分真的单调吗、组合超额能被拆回三条通道吗、牛熊市里这份超额怎么分布。

## 一、合成市场：三条通道，人为植入

500 只股票、2500 个交易日（约 10 年）。市场因子分五个制度块：500 日牛市（漂移 0.06%/日）、400 日熊市（−0.04%、波动 1.6%）、500 日复苏、500 日深度熊市（波动 1.8%）、600 日牛市。分块的意义是让「分块谁赢」成为有信息量的比较——混在 iid 市场里，低波溢价的牛熊不对称会被平均掉。个股 β~U(0.6, 1.7)，特质波动基础值 0.3% 起步随时间缓慢演化（AR 过程），市值对数正态。

**关键一步：alpha 是植入的，不是发现的。**三条通道全部用 z 分数写成日频 alpha：

- **低波通道**：alpha_lv = 0.0002 − coef_lv × vol_z。coef_lv 随制度变化——熊市块 0.000352、牛市块 0.000154（杠杆约束在危机时绑得更紧，这是 Frazzini-Pedersen 的核心机制）；
- **彩票需求**（只存在于牛市块）：alpha_lot = +0.0001 × vol_z——牛市里高波动股票被投机资金买高，抵消一部分低波优势；
- **红利通道**：alpha_dy = 0.0001 + 0.00012 × dy_z（高分红公司更成熟稳定）；
- **质量通道**：alpha_q = 0.00008 + 0.00010 × q_z（盈利稳定性溢价）。

可观测特征是带噪声的时变代理：特质波动用 beta×市场回归残差的 63 日已实现波动，DY 和质量是月度慢随机游走加测量噪声。这个世界的「Smart Beta 异象」是设计出来的，所以本文测的是**机制的可分解性与策略的可执行性**——异象在真实数据里存不存在，请去看红利低波指数的长期实证。

## 二、截面证据：三条通道都单调，综合分更单调

先看单因子。按静态真实特征分五组（组内等权、预热期后）：

| 通道 | Q1 年化 | Q2 | Q3 | Q4 | Q5 年化 | Q5−Q1 |
|---|---|---|---|---|---|---|
| 股息率 DY | +4.7% | +6.3% | +9.8% | +12.0% | +14.8% | +10.1pp |
| 特质波动（低者优） | +2.5% | +7.7% | +10.3% | +12.3% | +14.8% | +12.3pp |
| 质量分 | +5.5% | +8.6% | +9.8% | +11.1% | +12.4% | +6.9pp |

三条通道单独都单调，低波腿的截面斜率最陡（+12.3pp），质量腿最平（+6.9pp）——这与真实数据的排序大致吻合：低波异象的截面幅度通常大于质量异象。

![单因子截面单调性](/images/smart-beta-dividend-lowvol/component_spreads.png)

综合分 = 三个分位数的均值（红利分位 + 低波分位 + 质量分位），月度调仓。五组年化收益从 Q1 +2.57% 单调爬到 Q5 +16.75%（Q2 +7.09%、Q3 +9.07%、Q4 +12.32%），Sharpe 0.23→0.77，最大回撤从 −67.8% 收窄到 −40.3%。单调性比任何单因子都干净——三条通道的信号叠加把各自的截面噪声平均掉了，这是多因子打分相对单因子的第一个好处。

## 三、组合构建：Smart Beta 跑赢基准多少

每月末按综合分取前 100 名（前 20%），权重按分数本身加权（分数越高权重越大），与两个基准对比：等权 500 只、市值加权 500 只。前 63 日为预热期（滚动波动窗口未满）。

- **红利低波 Smart Beta**：CAGR +16.91%、波动 23.59%、Sharpe 0.78、最大回撤 −40.2%
- **等权基准**：CAGR +9.47%、SR 0.49、DD −52.1%
- **市值加权基准**：CAGR +9.43%、SR 0.49、DD −52.2%

Smart Beta 相对市值基准年化多赚 7.5pp，Sharpe 高 0.29，回撤小 12pp。注意分数加权只比组内等权多一层倾斜，没有引入额外杠杆或做空——这是一个纯多头、可执行的指数化方案。

分数加权（权重 ∝ 综合分）相对组内等权的差别值得单独说一句：等权版本把 Q5 里「刚好蹭线」和「三项全优」的股票一视同仁，分数加权则把仓位集中到信号最强的个股上。在这个合成世界里分数加权略优（16.91% vs 16.75% 的组内等权 Q5），但差别不大——三条通道的信噪比都不高时，加权方式的边际贡献远小于选股本身的贡献。真实指数产品更多用等权或市值封顶，原因也在这里：加权方式的锐度必须和信号的锐度匹配，过度加权等于把估计误差一起放大。

## 四、归因：超额能拆回三条通道吗

构造三个因子价差序列（每组用静态真实特征的头部 20% 减尾部 20%）：低波价差、红利价差、质量价差。把 Smart Beta 相对市值基准的日超额回归到这三条价差上：

- **低波价差**：+1.67bp/日，贡献 **66%** 的超额
- **红利价差**：+0.49bp/日，贡献 **19%**
- **质量价差**：+0.28bp/日，贡献 **11%**
- 残差：+0.09bp/日（3%），回归 R²=0.49

归因结构和我们植入的通道强度完全同构（coef_lv 的熊市放大是最大单一通道）。一半出头的方差被三条价差解释，剩下的来自特征测量噪声与分数加权与五分位构造的差异。这条归因在真实产品上的对应物就是「Smart Beta 指数的收益分解报告」——发行人需要向投资者证明超额来自声称的因子，而不是来自某个没声明的暴露（比如不知不觉押注了小市值）。

## 五、成本与分块：它主要是一份保险

月度调仓的**单边换手 14.5%**——特征慢变，这个换手低得像指数基金。成本敏感性：单边 10bps 年化从 16.91% 降到 16.70%，30bps 到 16.31%，即使 50bps 也还有 15.90%。换手是 Smart Beta 相对高频因子的结构性优势：一年约 1.7 次完整换仓，交易成本几乎不构成决策变量。

更有信息量的是分块。把超额按五个制度块拆开：

| 块 | 1 牛 | 2 熊 | 3 复苏牛 | 4 深熊 | 5 牛 |
|---|---|---|---|---|---|
| SB−市值基准 | +4.73pp | **+11.60pp** | +4.31pp | **+11.68pp** | +4.74pp |

熊市块的超额大约是牛市块的 2.5 倍——熊市占 36% 的交易时间，贡献了超过一半的总超额。机制上这是设计好的：coef_lv 在熊市放大 2.3 倍（杠杆约束绑紧），而牛市的彩票需求通道把高波股票买高、抵消掉一部分低波优势。**这份超额的主要形态是下跌保护，不是上涨增强**——买它的人应该在熊市里感谢自己，在牛市里忍受相对收益的平淡。任何把 Smart Beta 当「收益引擎」的预期管理都是错的。

这个不对称对资金属性有直接含义。有负债端压力、熊市里可能被迫减仓的资金（比如带止损线的产品），Smart Beta 的价值恰好在它最脆弱的时候兑现；而能全程持有的长线资金，拿到的是全样本 7.5pp 的年化超额，其中牛熊贡献大致对半。用哪个数字做预期管理，取决于你的资金能不能活到熊市结束——这比因子研究本身更接近组合管理的真实问题。

## 六、诚实声明与完整代码

三条溢价通道、彩票需求、特征测量噪声全部由我植入，本文测的是**可分解性与可执行性**：单调性存在吗、归因回到声称的因子了吗、成本下还剩多少、牛熊怎么分布。真实数据的红利低波指数还要面对分红税、指数规则变更、成分调整的时滞，执行损耗只会更高。另外别忘了本文的世界里三条通道互不相关，而真实数据的股息率、低波、质量彼此纠缠（高分红的公司往往本身就是低波成熟的），正交化该怎么做本身就是另一篇文章的题目。代码用 numpy 从零实现全部环节（含 AR 特质波动、噪声特征代理、时序归因）：

```python
import numpy as np

rng = np.random.default_rng(20261025)
n_stocks, n_days = 500, 2500
blocks = [(500, 0.0006, 0.010), (400, -0.0004, 0.016), (500, 0.0004, 0.012),
          (500, -0.0005, 0.018), (600, 0.0007, 0.011)]
mkt = np.concatenate([rng.normal(mu, sig, n) for n, mu, sig in blocks])
is_bear = np.concatenate([np.full(n, i % 2 == 1) for i, (n, _, _) in enumerate(blocks)])

beta = rng.uniform(0.6, 1.7, n_stocks)
base_vol = np.clip(0.003 + 0.002 * np.abs(rng.normal(0, 1, n_stocks)), 0.0015, 0.012)
base_dy = np.clip(rng.normal(0.025, 0.02, n_stocks), 0.0, 0.08)
base_q = rng.normal(0, 1, n_stocks)

# 三条植入通道（z 分数）+ 制度依赖
vol_z = (base_vol - base_vol.mean()) / base_vol.std()
dy_z = (base_dy - base_dy.mean()) / base_dy.std()
q_z = base_q / base_q.std()
coef_lv = np.where(is_bear, 0.000352, 0.000154)        # 杠杆约束熊市更紧
lottery = np.where(is_bear, 0.0, 0.00010)              # 牛市彩票需求
alpha = (0.00020 - coef_lv[:, None] * vol_z[None, :]
         + lottery[:, None] * vol_z[None, :]
         + 0.00010 + 0.00012 * dy_z + 0.00008 + 0.00010 * q_z)
R = alpha + beta[None, :] * mkt[:, None] + rng.normal(0, 1, (n_days, n_stocks)) * base_vol[None, :]

# 综合分（三个分位数的均值）→ 前 20% 分数加权
def pct_rank(x):
    return np.argsort(np.argsort(x)) / (len(x) - 1)
score = (pct_rank(base_dy) + pct_rank(-base_vol) + pct_rank(base_q)) / 3.0
mask = score >= np.quantile(score, 0.8)
w = score[mask] / score[mask].sum()
sb = R[:, mask] @ w                    # 红利低波 Smart Beta
cap = R @ (np.exp(rng.normal(0, 1.2, n_stocks)) / np.exp(rng.normal(0, 1.2, n_stocks)).sum())
```

复现要点：① 特质波动的 AR 过程和噪声特征代理是「可观测信号 ≠ 真实驱动」的来源，也是换手的来源；② 归因回归要用**静态真实特征**构造价差（干净），而组合构建必须用**时变噪声特征**（现实）；③ 分块超额必须用同一调仓规则分别计算，不能事后挑块。
