## 一、结论先行

量化里最常见的区间是"预测值 ± 1.96 倍历史残差标准差"。这个做法偷偷塞了两个假设：残差服从正态，而且未来和校准期同样波动。收益序列两条都不太成立——尖峰肥尾、波动聚集，偶尔还直接换一个波动率状态。

保序预测（Conformal Prediction）走的是另一条路：不做分布假设，只要求**校准样本与未来样本可交换**（比独立同分布还弱一点），就能给出"边际覆盖率至少 1-α"的有限样本保证。它不要求模型正确，不要求残差正态，甚至允许你用一个黑箱模型——只要你能算残差。

本文用真值已知的收益数据把六种区间摆在一起比：

1. 平稳测试上，90% 名义的 split conformal 覆盖 **89.88%**，平均宽度 5.5581；名义覆盖率从 80% 扫到 98%，实测从 77.25% 单调爬到 96.25%，整体贴着对角线走。
2. 用**训练残差**算分位数的"省事做法"只有 **83.75%** 覆盖，平均宽度反而更宽（4.6671）——因为区间错位，宽也没用。400 次重复实验里这个方法 **100% 低于 90%**，平均 82.81%。
3. 高斯区间覆盖 **83.00%**：训练期的残差标准差 1.3823 低估了测试期实际波动，正态假设又在尾部进一步失信。
4. 条件覆盖才见真章：split conformal 在低波动代理组覆盖 93.92%、高波动组只有 85.60%；按代理变量分两组各自校准的 Mondrian 版本给出 88.81% / 89.72%，边际覆盖几乎没变但组间公平多了。
5. **可交换性是最贵的假设**。把测试期波动率直接乘 2.4 倍后，固定校准的覆盖率从 89.88% 掉到 **59.50%**，高斯 52.06%，Mondrian 59.13%；用最近 100 个已实现残差每天重校准，覆盖率回到 **89.19%**，但平均区间宽度从 5.56 涨到 11.21——不确定性变大了，区间就该变宽，这是诚实的代价。

## 二、保序预测到底保了什么

Split conformal 的构造只有三步：

1. 把历史切成训练集与校准集。在训练集上拟合任意点预测模型 `f̂`。
2. 在校准集上算 conformity score，这里取绝对残差 `s_i = |y_i - f̂(x_i)|`。
3. 取 `q̂` 为 `s_i` 的第 `⌈(m+1)(1-α)⌉` 个顺序统计量（m 是校准样本数），新样本的区间就是 `[f̂(x_new) - q̂, f̂(x_new) + q̂]`。

保证的形式是 `P(Y_new ∈ Ĉ(X_new)) ≥ 1-α`，概率是对校准样本和新样本的联合随机性取的。注意三个限定：**边际**而非条件；覆盖的是随机抽取的新点，不是某个特定交易日；前提是训练模型固定后校准点与新点可交换。它不保证"每 10 天恰好有 1 天越界"，也不保证"高波动那几天也覆盖 90%"。

本文取 `m=400`、`α=0.10`，于是 `⌈401×0.9⌉ = 361`，取排序后第 361 个分数——分位点相当于 90.25% 而不是恰好 90%，这是有限样本保守性的来源。样本越小，这个保守间隙越大。

一个常见的自欺是把训练残差当校准残差：模型在训练数据上拟合过，残差天然偏小。本文的点是预测模型有 153 个特征，其中 150 个是纯噪声，训练样本只有 800 条——过拟合让训练残差分位数 2.3336，而诚实的校准分位数 2.7790，比值 0.84。覆盖差的 6 个百分点，全部来自这一步偷懒。

## 三、实验设计

生成 3600 天日收益。信号部分是 `0.35·x₁ + 0.20·x₂`，`x₁`、`x₂` 是标准正态因子，另外 150 个特征全是噪声。噪声项服从 `σ_t·z`，其中 `log σ_t` 是 AR(1) 随机游走（系数 0.9、新息 0.12），再乘上 `1 + 0.5|x₃|` 的异方差因子；从第 2000 天起把基础波动率乘 2.4，制造一次永久性的状态切换。

切分是 800 天训练、400 天校准、800 天平稳测试、1600 天突变测试。测试期完全不参与模型拟合与初始校准，所以平稳段的可交换性成立，突变段则是**故意打破**它。

六种区间：标准 split conformal、训练残差版（错误示范）、高斯版（±1.645σ_train）、归一化 conformal（用训练残差拟合尺度模型）、Mondrian 分组版（按 `|x₃|` 中位数分两组各自校准）、滚动 conformal（最近 100 个已实现残差，每天重算分位数）。

为什么要加入归一化版？因为它看起来能解决异方差——把残差除以特征驱动的尺度估计再校准。但尺度模型的基线是在平稳期估的，波动率整体抬升 2.4 倍后它同样失效：突变段覆盖 58.31%。这正好说明**相对波动的形状**和**绝对波动的水平**是两件事，前者建模得再漂亮也救不了后者漂移。

## 四、条件覆盖：边际合格不等于每个状态都合格

把平稳测试按 `|x₃|` 分成高低两组，标准 split conformal 的覆盖率是 93.92% 和 85.60%——边际 89.88% 是两者平均出来的，低波动组超赔、高波动组欠赔。如果你做的是波动率目标策略，欠赔的恰好是你最需要区间的那些天。

Mondrian conformal 的做法很朴素：在校准集上按协变量分桶，每个桶单独算分位数。这里只分两组，分位数分别是 2.2862 和 3.1406，实测覆盖 88.81% 和 89.72%。边际覆盖 89.25% 与标准版几乎一样，但组内公平性改善明显。

高斯版的分组结果更极端：88.56% 和 77.12%。均值±常数倍标准差的区间在高波动子样本上系统性偏窄——这是同方差假设最直接的反噬。

![图3：按波动率代理变量分组的条件覆盖](/images/conformal-prediction-returns/fig3_conditional_coverage.png)

要强调 Mondrian 的边界：分组本身会消耗校准样本，每组 200 条时分位数估计的噪声明显变大；而且它只保证组内边际覆盖，不保证在组内进一步细分（比如再按星期几）后仍成立。分组变量也必须事先选好，不能看着测试结果挑——否则你做的就是另一种形式的多重检验。

## 五、状态切换：保证失效时怎么办

从第 2000 天起波动率乘 2.4，固定校准的区间宽度停在 5.5581，而实际残差分布被拉宽，覆盖率一路掉到 59.50%。这不是方法 bug——保序预测的前提被明确破坏了：校准样本和新样本不再可交换。

滚动重校准是最直接的补丁：每天用最近 100 个已实现残差重新取分位数。突变段覆盖率 **89.19%**，接近名义 90%，平均宽度 **11.2096**，大约是固定版本的两倍。宽度上升与真实波动放大 2.4 倍方向一致，说明区间在诚实地追踪不确定性。

代价要说清楚：滚动版需要每天拿到真实收益，所以它是**事后可复盘的监控工具**，不能直接当作事前预测区间的无偏估计。真要做事前，得用预测波动模型给出尺度，再做归一化 conformal，并接受尺度模型本身会错。另外窗口长度是新的超参数——太短分位数抖，太长跟不上状态切换，本文的 100 天只是这个合成设定下的选择。

## 六、重复实验：保证是期望，不是每次都达标

跑 400 次独立重复（每次重新造数据、重新拟合、重新校准），标准 split conformal 在平稳测试上的平均覆盖率 **89.76%**，标准差 2.42%，最小 80.90%、最大 95.50%，其中 **49%** 的重复达到或超过 90%。

这个结果经常被误读。"覆盖率至少 90%"是对校准集和新样本联合分布说的期望不等式，不是"每次实验都至少 90%"。单次 800 天测试的标准误约 1.1 个百分点，所以 49% 的达标率与期望 90% 完全相容——如果每次都稳稳超过 90%，反而说明实现里塞了过多保守性。

错误版本的对照更刺眼：训练残差版的 400 次重复里，**400 次全部低于 90%**，平均只有 82.81%。这是一个稳定的偏差，不是运气差。看到"覆盖率系统性低于名义水平"，第一件事就该检查校准残差是不是用了样本内残差。

## 七、完整代码

核心实现，纯 numpy：

```python
import numpy as np

def quantile_threshold(scores, alpha=0.10):
    m = len(scores)
    k = int(np.ceil((m+1)*(1-alpha))) - 1     # 有限样本保守修正
    return float(np.sort(scores)[min(max(k, 0), m-1)])

# X_tr/y_tr 训练, X_ca/y_ca 校准, X_te/y_te 测试
A = np.column_stack([np.ones(len(y_tr)), X_tr])
beta = np.linalg.lstsq(A, y_tr, rcond=None)[0]
predict = lambda X: beta[0] + X @ beta[1:]

scores = np.abs(y_ca - predict(X_ca))
q = quantile_threshold(scores, alpha=0.10)
p = predict(X_te)
lower, upper = p - q, p + q
coverage = np.mean((y_te >= lower) & (y_te <= upper))
```

滚动版只需把 `scores` 换成最近 100 个已实现残差并每天重算 `q`；Mondrian 版只需在 `scores` 上按协变量分组、每组各算一个 `q`。归一化版把分数改成 `|残差| / s(x)`，区间改成 `p ± q·s(x_new)`——但请记住实验里它在波动率水平漂移时同样失效。

## 八、实务里的三条建议

第一，**先画覆盖率随时间的变化，再看平均值**。本文突变段整体覆盖 59.50%，平均值已经很难看；但很多真实数据里的状态切换只占 10% 的时间，整体覆盖率还能停在 88%，把问题藏起来。按 100 天窗口分段看，异常立刻显形。

第二，**别拿保序区间当风险预算**。它保证的是覆盖率，不是损失大小。一个覆盖 90% 但宽度是实际风险两倍的区间，统计上合格、资金效率上糟糕；反过来，宽度合格但条件覆盖失衡的区间，在压力期会连续击穿。这两个维度要分开评估。

第三，**可交换性假设要显式写在模型文档里**。什么时候重校准、用什么窗口、协变量漂移了怎么办——这些不是实现细节，而是模型保证成立的边界条件。本文的滚动版能恢复到 89.19%，是因为我们明确知道波动率什么时候跳；实盘里你不知道，只能靠持续监控和保守的窗口设计。
