CAPM 的直觉是高风险高收益，横截面上却被反复打脸：低波动组合长期跑赢高波动组合，风险调整后差距更大。Frazzini-Pedersen 的 BAB 因子把这件事写成可交易策略，主流解释有两条——**杠杆约束**（想加杠杆的资金被迫买高 β 股票，把高 β 的 alpha 竞价压平；低 β 的 alpha 因为要加杠杆才买得起而无人竞争）和**彩票偏好**（散户为高特质波动的"中奖感"支付溢价，把高 idio 股票的后续收益买下去）。本文用 500 只合成股票把两条通道分别植入、再分别拆开测量。

## 一、合成市场：两条通道，人为植入

500 只股票、2500 个交易日（约 10 年）。市场因子分五个制度块：500 日牛市（漂移 0.06%/日）、400 日熊市（−0.04%、波动放大到 1.6%）、500 日复苏、500 日深度熊市（波动 1.8%）、600 日牛市。分块的意义在于让"分年谁赢"成为有信息量的比较——同一个低波因子，在熊市块和牛市块里的表现截然不同，混在一个 iid 市场里是看不出这种不对称的。个股 β~U(0.6, 1.7)，特质波动 = 0.3% + |N(0.6%, 0.25%)|（日频）。**关键一步：alpha 是植入的，不是发现的**——杠杆约束通道 alpha = 0.018% − 0.022%×(β−1.15)（日频，β 每高 1，年化 alpha 低约 5.5%）；彩票偏好通道 alpha = −1.2%×(idio−0.9%)（日频，特质波动每高 1 个百分点，年化 alpha 低约 3%）。收益 = alpha + β×市场 + 特质噪声。这个世界的"异象"是设计出来的，所以本文测的是**机制的可分解性与策略的可执行性**，不是异象的存在性——存在性请去看 Ang-Hodrick-Xing-Zhang 那类真实数据论文。

## 二、截面证据：波动-收益的负斜率

全样本按已实现波动分五组（每组 100 只）：年化收益从 Q1 低波的 +5.00% 单调降到 Q5 高波的 −4.26%，波动从 14.77% 升到 30.92%，Sharpe 从 0.34 掉到 −0.14，最大回撤从 −39.60% 恶化到 −82.54%。散点图拟合斜率 −0.557：每多 1 单位年化波动，年化收益低 0.56 个单位。这个 10 年样本的市场因子恰好是负收益（−1.51%/年），放大了低波的相对表现，第五节分年数据会把这一点摊开。

月度调仓版（排序用过去 250 日已实现波动、持有 21 日、无前视）结论不变：Q1 +6.26%/SR 0.37 vs Q5 −0.68%/−0.02，中间组单调排列（+4.39%/+2.82%/+0.16%）。Q1 组合月均名单更替只有 3.1%——波动是慢变量，这个策略的换手低得不像话，第五节看成本时会感谢这一点。

![月度调仓波动五分位累计净值](/images/low-volatility-anomaly-cn/quintile_cumulative.png)

五条净值曲线的分离度就是异象的强度：低波组（蓝）全程压着高波组（红），而且不是靠某一段行情——曲线在 120 个月里几乎单调地张开。顺带交代静态与月度两个口径的差：静态分组（全样本排序一次）的 Q1−Q5 差是 9.26 个百分点，月度调仓版收窄到 6.94 个百分点。差距来自排序噪声——月度版每次用过去 250 日的数据重新猜"谁低波"，猜错的部分把组间差抹平了一截。两个数字都真实，区别只在于你问的是"这个截面事实"还是"这个可执行策略"。

## 三、机制分解：beta 通道是主因，idio 通道是配角

把每只股票的时间序列 alpha 对真实 β 和特质波动回归：alpha = 0.061% − 0.024%×β − 1.71%×idio（日频口径，折年约 −6.1%/单位 β、−4.3%/1% idio），R²=0.155。拆解 Q5−Q1 的 −9.26% 年化收益差：**beta 通道贡献 −4.96%（占 54%），idio 通道只贡献 −0.97%（占 10%）**，其余 −3.33% 是分组噪声与交互。

为什么彩票通道这么小？因为按**总波动**分组时，组间波动差异大部分由 β 贡献（市场波动 ×β 是主项），特质波动在组间只从 0.76% 差到 0.99%。这提醒一个常见误用：把"低波动异象"整个归因于彩票偏好之前，先看你的分组变量里 β 和 idio 各占多少——按总波动分组，你测的主要是 beta 异象；要单独测彩票偏好，得先剥掉市场暴露（比如用特质波动直接分组）。

在 A 股，彩票偏好有更具体的面孔：次新股、高换手的题材股、财报季的期权式押注。这些股票的共同点是特质波动高、beta 不一定高——所以用 beta 排序的 BAB 抓不全它们，用特质波动分组的 MAX 因子（买彩票的人为最高特质波动支付溢价）才是对症下药。本文的 idio 通道就是 MAX 因子的合成版本，只是植入强度只有 beta 通道的一半不到，所以它在总分组的归因表里只能当配角。如果换个问法——直接用特质波动分组、再看组间 alpha 差——它会站到舞台中央，这个留作习题。

## 四、BAB 与 A 股可执行版

标准 BAB：按 β 分低/高两组，低组加杠杆到 β=1、高组降杠杆到 β=1，做多做空。写成公式是 r_BAB = (r_L − r_f)/β̄_L − (r_H − r_f)/β̄_H——注意两腿的市场敞口被各自的杠杆倍数精确抵消（β̄_L·m/β̄_L − β̄_H·m/β̄_H = 0），剩下的只有 alpha 差与特质噪声。这就是它 Sharpe 3.26 而长仓版只有 0.31 的全部秘密：不是低波聪明，是中性化把 beta 这个最大的收益源（本例中是负贡献）切掉了。本例月度调仓（低波组均 β=0.70、高波组 β=1.60）：年化 +6.65%、波动 2.04%、Sharpe 3.26、最大回撤仅 −0.84%——β 中性化之后，剩下的几乎全是纯 alpha。

但 A 股没有便利的个股融资做空，更现实的版本是**长仓低波倾斜**：权重 ∝ max(1/β − 中位数, 0)，只超配低 β、不碰高 β。年化 +5.40%/SR 0.31/DD −39.04%，跑赢等权基准（+2.59%/SR 0.10/DD −58.96%）——但注意它的回撤仍有 −39%：低波倾斜降波动不消回撤，想要 BAB 的回撤形状，得真有对冲工具。

## 五、成本与分年：熊市保险，牛市租金

Q1 组合月换手 3.1%，单边成本从 0 加到 50bps 只吃掉 0.19 个百分点的年化（+6.26%→+6.07%）——低波策略的敌人从来不是成本，是信号在牛市里缺席。换手低有结构性原因：波动排序拼的是持续性，一只股票这个月在低波组，下个月大概率还在（特质波动和 beta 都是慢变量）；相比之下动量类因子月换手动辄 50%+，成本敏感度完全不是一个量级。A 股现实的成本结构（佣金加卖出印花税）对 3% 的月换手几乎无感——换手是因子策略最常见的死法，低波恰好是换手最低的那一档。分年看：10 年里 Q1 赢 6 年，但赢得极不对称——三个熊市年（Y1/Y3/Y7）低波分别少亏 22.9/32.6/20.8 个百分点，四个强势年（Y5/Y8/Y9/Y10）少赚 0.3-8.5 个百分点。**这是一份保险：保费是牛市里持续的小额漏损，理赔是熊市里的一次性大额少亏。** 用夏普比率考核它会在牛市里被骂，用回撤和存活考核它才公平。

## 六、诚实结论

- 合成世界里两条机制都按设计工作，beta 通道贡献了过半的组间差，彩票偏好通道在总波动分组下几乎看不见——误把低波异象全记在"散户彩票需求"账上，通常是分组变量没拆干净。- BAB 的 SR 3.26 是 β 中性化的功劳；长仓版把 SR 打到 0.31 不是策略变差了，是你把对冲工具扔了，beta 敞口回来了。
- 真实 A 股的异象比合成世界弱得多（成本更高、因子更拥挤、散户结构独特），本文只证明机制方向没错，不证明存在免费午餐。
- 可执行性清单：月度调仓、3% 换手、无做空依赖——低波是少数"约束下也能做"的因子，这也是它在 A 股受欢迎的原因；但要接受它在牛市里持续跑输的租金结构。
- 最后一条给自己：合成世界的 R² 只有 0.155——alpha 的大头是噪声，两条植入通道只解释了截面 alpha 变异的一成半。真实世界不会更干净，所以任何"因子逻辑完美所以要重仓"的叙事，先在散点图的残差里醒醒神。
- 还有一点别忽略：本例市场因子十年负收益（−1.51%）且最大回撤 −61.85%，低波策略全部跑赢基准的对比都发生在一个下行的市场里。换个牛市样本，Q1 相对等权的超额会薄得多——但 BAB 是市场中性的，它的 +6.65% 对市场方向不敏感，这也是它比"直接买低波"更值得理解的原因。

```python
import numpy as np

rng = np.random.default_rng(7)
N, T = 500, 2500
blocks = [(0, 500, .0006, .009), (500, 900, -.0004, .016), (900, 1400, .0007, .008),
          (1400, 1900, -.0003, .018), (1900, 2500, .0005, .010)]
mkt = np.concatenate([rng.normal(mu, sd, b-a) for a, b, mu, sd in blocks])
beta = rng.uniform(0.6, 1.7, N)
idio = 0.003 + np.abs(rng.normal(0.006, 0.0025, N))
# 两条植入通道：杠杆约束（随 beta 衰减）+ 彩票偏好（随特质波动衰减）
alpha = (0.00018 - 0.00022*(beta-1.15)) + (-0.012*(idio-0.009))
R = alpha + np.outer(mkt, beta) + rng.normal(0, 1, (T, N))*idio

# 月度调仓五分位：过去 250 日已实现波动排序，持有 21 日，无前视
port = []
for m in range(250, T, 21):
    vol = R[m-250:m].std(0)*np.sqrt(252)
    q = np.array_split(np.argsort(vol), 5)
    port.append([R[m:m+21][:, idx].mean(1).sum() for idx in q])
port = np.array(port)                      # 行=月，列=分位
sr = port.mean(0)/port.std(0)*np.sqrt(12)  # 各分位夏普

# 机制分解：时间序列 alpha ~ beta + idio
beta_r = np.array([np.cov(R[:, i], mkt)[0, 1]/np.var(mkt) for i in range(N)])
alpha_r = R.mean(0) - beta_r*mkt.mean()
X = np.c_[np.ones(N), beta, idio]
coef = np.linalg.pinv(X.T @ X) @ (X.T @ alpha_r)
```
