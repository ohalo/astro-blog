做日频的人习惯把「一天」当成一个均匀的时钟：24 小时一切四段，各算一段收益。可打开逐笔成交数据，这个时钟是歪的——开盘十分钟能成交两百笔，午后半小时可能只有三十笔；而且「快」和「慢」会抱团：一连串短间隔之后往往还是一串短间隔，一笔长间隔会把之后十几笔的期望一起拉长。 Engle 和 Russell（1998）把这件事写成了模型：成交持续期（两笔成交的时间间隔）本身就是一个 GARCH。本文用 20 个交易日、35,180 笔合成成交，从零实现 ACD 的 QMLE 估计，并 deliberately 埋了两个陷阱——日内 U 型节律和创新分布误设——看估计器会不会上当。

结论先放这：

**① 持续期强烈拒绝「指数 + 独立」的双原假设。** 过度分散检验 var/mean² = 1.46（指数分布下应为 1），T = 51291，p ≈ 0；原始持续期的 Ljung-Box(20) Q = 22694，p ≈ 0。泊松到达过程在这个市场里活不过第一节课。

**② 去季节化不是可选项，是指南针。** 不去掉日内 U 型节律直接估，β 从 0.842 虚抬到 0.876、持续性从 0.943 虚抬到 0.977——开盘收盘的规律性稀疏冒充了持久性。本节用非参数分箱估计季节乘数（开盘 0.61× / 中庸 1.48× / 收盘 0.62×，真值 0.40/1.00/0.40），形状完整恢复。

**③ 指数 ACD 干净恢复全部结构参数。** 去季节化后 QMLE 给出 α = 0.1015、β = 0.8415（真值 0.10 / 0.85）；Weibull ACD 估出 ν = 0.999——正确识别出创新分布就是指数；标准化残差均值 1.000、标准差 1.002，Ljung-Box p = 0.707，堂堂正正掉进白噪声带。

**④ 冲击半衰期约 12 笔。** 一笔 5 倍于期望的长持续期，会把之后十几笔的期望持续期整体抬高，再按 (α+β) = 0.943 缓慢衰减回无条件水平。对排单的含义直接：「下一笔可能很慢」是一个可量化的状态，不是噪声。

**⑤ 创新分布误设时，参数鲁棒但诊断会出卖你。** 把创新分布换成 Weibull(1.3) 重新生成数据、仍用指数 ACD 拟合：(α, β) 照样估到 0.098 / 0.841（QMLE 的伪似然鲁棒性），但残差峰度从 8.9 掉到 5.3（指数参考值 9）——峰度指纹留在残差里。

## 模型：持续期的 GARCH

ACD 的结构和 GARCH 一一对应，只是把「方差」换成「期望持续期」：

```python
# ACD(1,1): x_i = psi_i * eps_i,  eps_i ~ Exp(1)
# psi_i = w + alpha * x_tilde[i-1] + beta * psi[i-1]
psi[i] = w + alpha * x_tilde[i-1] + beta * psi[i-1]
```

x_i 是第 i 笔与第 i−1 笔之间的秒数，ψ_i 是给定历史后的条件期望持续期，ε_i 是创新。和 GARCH 一样，QMLE 的对数似然就是把 ε_i 的密度乘起来（指数创新：−log ψ_i − x̃_i/ψ_i），ψ_i 递推出来。三个组件缺一不可：**日内季节性**（U 型强度）、**持续期聚类**（α + β）、**创新分布**（指数 / Weibull / Burr）。

季节性的处理方式值得说一句：模型假设 E[x_i | F_{i-1}] = ψ_i·s(τ_i)，s(τ) 是期望持续期乘数（开盘收盘短、中庸长）。实务中用非参数分箱估 s——把每天切成 39 个 15 分钟箱，算每箱平均持续期，平滑后归一化，然后 x̃_i = x_i / s(τ_i) 得到「去季节化持续期」，再对 x̃ 跑 ACD。这个顺序反了（先估 ACD 再找季节）会把 U 型节律整个吞进 α。

![日内 U 型强度与成交持续期](/images/acd-duration/intraday_pattern.png)

本文的合成市场按真实 A 股的节奏搭：6.5 小时交易日，日内强度 m(τ) = 1 + 1.5·(2τ−1)²（开盘/收盘成交密度是中庸的 2.5 倍），持续期 x_i = ψ_i·ε_i/m(τ_i)，真值 ω = 1.0、α = 0.10、β = 0.85。20 天跑出 35,180 笔成交，日均 1,759 笔，平均持续期 13.3 秒、中位 8.1 秒——量级和真实的市场中盘股一致。

## 实验一：两个检验，原假设尸骨无存

先不动模型，只问两个 yes/no 问题。**持续期是指数的吗？** Engle-Russell 过度分散检验：指数分布下 Var = mean²，所以 (n−1)·s²/x̄² ~ χ²(n−1)。实测 var/mean² = 1.46，T = 51291——35,180 个自由度的卡方，均值 35,179、标准差 265，T 超出均值 60 个标准差。**持续期是独立的吗？** Ljung-Box(20) Q = 22694，p ≈ 0；原始 ACF(1) = 0.242，一阶自相关就把「独立」打死。

两个检验打的是不同的原假设：过度分散说的是边际分布（右尾比指数厚），LB 说的是时间结构（间隔会抱团）。ACD 的存在意义就是把后者（以及由它引起的部分前者）吸收进条件项。

![持续期分布与残差诊断](/images/acd-duration/duration_dist.png)

去季节化之后过度分散比从 1.46 降到 1.24——U 型节律贡献了约 0.2 的边际方差，剩下的 1.24 全部是持续期聚类（ACD 的 α + β = 0.95 自己造出来的）。仍然以 p ≈ 0 拒绝指数原假设，但此时拒绝的理由「归因清楚」了：不是日历，是聚类。

## 实验二：估计、季节与残差

按正确顺序走一遍完整流水线：估季节 → 去季节化 → 估 ACD → 看残差。

```python
# 指数 ACD 的 QMLE 负对数似然（递推 + 指数密度）
def nll(p):
    w, a, b = np.exp(p[0]), expit(p[1]), expit(p[2])
    psi[0] = w / (1 - a - b)
    for i in range(1, n):
        psi[i] = w + a * x_tilde[i-1] + b * psi[i-1]
    return np.sum(np.log(psi) + x_tilde / psi)   # -log Exp(1) 密度
```

结果：ω = 0.753、α = 0.1015、β = 0.8415（真值 1.0 / 0.10 / 0.85），持续性 α+β = 0.943。Weibull 版本估出 ν = 0.999——创新分布确实是指数，估计器没有把不存在的信息编出来。残差 x̃_i/ψ_i：均值 1.000、标准差 1.002（指数创新下都应为 1），LB(20) Q = 16、p = 0.707。从原始持续期（Q = 22694）到标准化残差（Q = 16），ACD 把可预测性整袋收走。

![ACD 滤波：长持续期冲击与均值回复](/images/acd-duration/acd_filter.png)

看一眼滤波的动态：窗口里最长的一笔持续期是期望的 4 倍以上，ψ_i 应声跳高，随后按 (α+β) = 0.943 逐笔衰减，半衰期 ln0.5/ln0.943 ≈ 11.8 笔（真值 13.5 笔）。注意一个小样本现象：估计出的持续性 0.943 略低于真值 0.95，但文献里更常见的是反向——有限样本把 α+β 往 1 推，本文的低估是运气；实务中看到持续性贴着 0.99 要默认打折。

## 实验三：ACF 对比——可预测性去哪了

![原始持续期 vs ACD 标准化残差的自相关](/images/acd-duration/acf_compare.png)

左灰右红，同一个 20 阶窗口：原始持续期的 ACF 一阶 0.242、前 20 阶全在 95% 白噪声带（±1.96/√35180 ≈ ±0.0105）之外；标准化残差一阶 −0.004，整整齐齐收回带内。LB 从 22694 塌到 16。这就是 ACD 的销售话术的诚实版本：**它不创造对成交时点的预测，它把已经存在的持续性重新分配给条件项**，让你能回答「给定刚才那笔很长，下一笔的期望是多少」这种条件问题。

## 实验四：两个陷阱

**陷阱一：跳过季节化。** 直接对原始持续期估 ACD：α = 0.1007（几乎不动，α 主要吃 lag-1）、但 β 从 0.842 虚抬到 0.876、持续性从 0.943 虚抬到 0.977。机制：U 型节律让「相邻时间段的持续期天然相似」，这份相似性在滞后一阶以上持续存在，被 β 全盘接收。持续性虚高 3.4 个点，半衰期从 12 笔膨胀到 30 笔——排单模型会系统性地高估「慢状态的黏性」。

![冲击预测与季节化对照](/images/acd-duration/forecast_seasonal.png)

**陷阱二：创新分布误设。** 用 Weibull(1.3) 创新重新生成一个市场（条件形状一样，只是条件分布比指数更集中），仍用指数 ACD 拟合：(α, β) = (0.098, 0.841)，和真值 (0.10, 0.85) 只差一丝——QMLE 对创新分布误设是鲁棒的（伪似然性质，只要条件均值设定对）。但残差峰度从指数 DGP 的 8.88 掉到 5.29，而指数参考值是 9：**峰度指纹留在残差里**。实务顺序因此很清楚：先估指数 ACD 拿稳健的 (α, β)，再用残差诊断（峰度、LB on 平方残差）决定要不要升级 Weibull/Burr。

## 应用与边界

ACD 最直接的用武之地是执行。把「还要成交 V 股」写成持续期积分：E[T_V] = Σ ψ_{i+k}·s(τ)·E[ε]，冲击后的 ψ 剖面（左图）直接给出「这笔大单后面市场会变慢」的时间表；把 ψ_i 的倒数当瞬时成交强度，可以给 TWAP/VWAP 排单加一个状态维度——不是按均匀时钟切片，而是按条件强度加权。另一个用法是风险：持续期拉长往往伴随信息缺乏，把 ψ_i 作为「市场活跃度」协变量丢进波动率或流动性模型。

三个边界。**一**，ACD 只对「时间」建模，不对「方向或价格」建模——持续期长不代表要跌，只代表要等。**二**，本文的 U 型节律是确定性的，真实市场的季节性本身会漂移（财报季、假期），需要滚动重估 s(τ)；分箱估计本身也有噪声，箱越细噪声越大，39 箱 + 3 箱平滑是偏差-方差的折中，开盘首箱和尾箱还要单独处理（样本少且行为最异常）。**三**，ACD 和成交量时钟（volume clock）是两种不同的「换表」思路：一个用等待时间，一个用成交量；哪个更公允取决于你的执行约束，本文只证明前者值得单独建模。 Engle-Russell 当年在 IBM 逐笔数据上估出的 α ≈ 0.05、β ≈ 0.85 与本文恢复的结构同构——四分之一个世纪过去，持续期聚类的形状没变，变的是我们能多快地把它估出来。
