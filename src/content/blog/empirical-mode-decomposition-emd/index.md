价格序列从来不是一个频率在跳。它有慢牛的趋势、有几个月的周期、有几天的摆动，还叠着一堆噪声。想把它拆开，传统工具各有各的别扭：**傅里叶变换**假设频率不随时间变，对非平稳的价格天然错位；**小波分析**要你事先选好基函数和分解层数，选错了就事倍功半。

**经验模态分解（EMD）** 走了第三条路：不预设任何基函数，让数据自己决定该拆成几个分量、每个分量什么尺度。它把信号自适应地分解成一系列**本征模态函数（IMF）**——每个 IMF 满足两个条件：极值点数和过零点数相差不超过一，且上下包络的均值为零。本文从零实现筛选（sifting）过程，在已知真值的数据上验证它到底准不准，也诚实展示它的软肋。

## 一、IMF 是什么：两个条件定义一个「振荡」

一个合格的 IMF 必须同时满足：

1. **极值数与过零点数相等或最多差 1**——保证它是一个干净的振荡，没有叠加多个尺度；
2. **任意时刻上下包络的均值为 0**——保证它是局部对称的，没有趋势成分。

任何一个复杂信号都可以被表示为若干 IMF 加一个残差（趋势或常数）。EMD 的目标就是把这个分解**自适应地**求出来，不需要你指定「我要 5 层」或「用 db4 小波」。

## 二、筛选过程：一遍遍剥掉均值包络

EMD 的核心是**筛选（sifting）**。对信号 $x(t)$：

1. 找出所有局部极大值和极小值；
2. 用三次样条分别插值极大值（上包络）和极小值（下包络）；
3. 算上下包络的均值 $m(t)$；
4. 令 $h(t)=x(t)-m(t)$；
5. 检查 $h$ 是否满足 IMF 的两个条件——不满足就把它当作新的 $x$，回到第 1 步反复筛，直到收敛。

剥出一个 IMF 后，从原信号里减去它，对残差重复整个过程，直到残差单调或极值点不足。下面是关键实现：

```python
import numpy as np
from scipy.interpolate import CubicSpline

def local_extrema(x):
    d = np.diff(x)
    max_idx = np.where((d[:-1] > 0) & (d[1:] <= 0))[0] + 1
    min_idx = np.where((d[:-1] < 0) & (d[1:] >= 0))[0] + 1
    return max_idx, min_idx

def envelope(t, x, ext_idx):
    idx = np.sort(ext_idx)
    if idx[0] != 0:  idx = np.concatenate([[0], idx])
    if idx[-1] != len(x)-1: idx = np.concatenate([idx, [len(x)-1]])
    keep = np.concatenate([[True], np.diff(t[idx]) > 0])  # 去重横坐标
    return CubicSpline(t[idx][keep], x[idx][keep])(t)

def sift(t, x, max_iter=50):
    h = x.copy()
    for it in range(1, max_iter + 1):
        mx, mn = local_extrema(h)
        if len(mx) < 2 or len(mn) < 2: break
        mean = (envelope(t, h, mx) + envelope(t, h, mn)) / 2
        h_new = h - mean
        mx2, mn2 = local_extrema(h_new)
        n_zero = np.sum(np.diff(np.sign(h_new)) != 0)
        balanced = abs(len(mx2)+len(mn2) - n_zero) <= 1
        amp = np.max(envelope(t, h, mx)) - np.min(envelope(t, h, mn))
        if balanced and np.mean(mean**2)/amp**2 < 0.05 and np.max(np.abs(mean))/amp < 0.05:
            return h_new, it
        h = h_new
    return h, max_iter   # 达到最大迭代仍不收敛，诚实返回
```

填充端点、去重横坐标这两个细节是工程上的坑：不补端点，样条在序列两端会剧烈摆动；不去重，CubicSpline 遇到相同横坐标直接报错。

## 三、场景一：三个已知周期能不能还原

造一个真值完全已知的信号：周期 16、64、256 的三个余弦，加上线性趋势和噪声，共 2048 点。EMD 拆出 5 个 IMF，筛选迭代次数依次是 15/6/5/3/4（第一个 IMF 最细碎，筛得最久）。

用 Hilbert 瞬时频率估每个 IMF 的主周期：IMF1≈3（这就是噪声）、IMF2≈15.6、IMF3≈65.1、IMF4≈301、IMF5≈633。三个真周期 16/64/256 分别落到 IMF2/3/4 上，与对应真分量的相关系数是 **0.971 / 0.912 / 0.707**。周期 16 和 64 还原得很干净；周期 256 的相关只有 0.707，因为它和线性趋势的尺度靠得太近，出现了**模态混叠**——这是 EMD 的固有短板，后面还会聊。

两个质量指标值得单独看：**完美重构误差 1.78e-15**，五个 IMF 加残差能把原信号还原到机器精度，这是 EMD 分解完备性的直接证据；**正交性指数 -0.022**，越接近零说明各 IMF 之间越独立，这个量级相当不错。

## 四、场景二：非平稳信号的杀手锏

EMD 真正甩开傅里叶的地方，是频率随时间变化的信号。造一个两段式信号：前 1024 点周期 24（快振荡），后 1024 点周期 96（慢振荡）。

EMD 干了件漂亮事——**它自动把两个时段分到了不同的 IMF**：快段的主振荡落在 IMF2（估计周期 24.3，真值 24），慢段落在 IMF3（估计周期 102.2，真值 96）。对每段各自的主导 IMF 做 Hilbert 变换，提取瞬时频率，与真实的分段频率对比：**RMSE 0.00199，相关系数 0.993**。

作为对照，全局傅里叶变换只能给出两个静态的频谱峰，告诉你「有快有慢」，却完全说不清「什么时候快、什么时候慢」。EMD 配 Hilbert 谱则把这份时频定位交还给你——这正是它在非平稳金融序列上的价值。

## 五、Hilbert 谱：从 IMF 到时频能量分布

拆出 IMF 之后，EMD 的故事只讲了一半。另一半是**Hilbert 谱**——把每个 IMF 做 Hilbert 变换，得到随时间的瞬时频率与瞬时振幅，再把所有 IMF 的时频能量叠在一起，就得到信号完整的时频分布。

对第 $i$ 个 IMF 做 Hilbert 变换 $\hat{c}_i(t)$，可以写成解析信号形式：

$$c_i(t)=\mathrm{Re}\big[a_i(t)e^{j\theta_i(t)}\big],\qquad \omega_i(t)=\frac{d\theta_i(t)}{dt}$$

其中 $a_i(t)$ 是瞬时振幅，$\omega_i(t)$ 是瞬时角频率。把振幅的平方（代表能量）画在时间—频率平面上，就是 Hilbert 振幅谱 $H(\omega,t)$；对时间积分得到边际谱，对频率积分得到类似能量的量。和小波谱相比，Hilbert 谱没有窗函数的分辨率权衡——它的频率分辨率来自 IMF 本身的自适应分离，而不是固定的时频格子。这正是它能看清「周期从 24 跳到 96」这类突变的原因。

代码上只需几行：对 IMF 取 `hilbert`，用 `np.unwrap(np.angle(...))` 解相位，`np.diff` 除以 $2\pi$ 得瞬时频率，再用 `np.abs` 取振幅。要小心的是过零点附近相位噪声会放大，所以本文在估计前先按振幅做了阈值筛选，并用中值滤波压掉边界尖峰。

## 六、诚实的局限：别把 EMD 当银弹

三个软肋必须写清楚，否则容易误用：

**模态混叠（mode mixing）**。场景一里周期 256 与线性趋势挤在同一个 IMF，相关系数掉到 0.707；当信号里两个尺度太接近，或存在间歇性成分时，一个 IMF 会混进多个尺度。改进方案是集合经验模态分解（EEMD/CEEMDAN）——往信号里反复加白噪声、多次分解取平均，利用噪声的统计特性把尺度分离开。

**端点效应**。三次样条在序列两端没有极值约束，包络容易飞出去，误差会从两端向内传播。工程缓解办法是给信号两头做镜像延拓或极值延拓再分解。本文图里蓝色估计曲线在切换点附近出现的几个尖峰，就是 Hilbert 变换在边界和突变处的伪影，用中值滤波压掉了大部分。

**Hilbert 的物理意义边界**。瞬时频率只在 IMF 满足窄带条件时才有清晰解释；对噪声主导的 IMF（如场景一的 IMF1）谈瞬时频率意义不大。此外 EMD 缺乏严格的数学基础，筛选的收敛性和分解的唯一性至今仍在研究中——它是强大的经验工具，不是有完备定理保证的算子。

## 七、在量化研究里怎么用

理论归理论，落到实盘 EMD 有几个靠谱的用法。最经典的是**多尺度去噪**：把价格拆成若干 IMF 后，高频 IMF 通常是市场微观噪声，低频 IMF 是趋势，中间尺度才是有效的周期成分；丢掉两端、重构中间，能得到比简单移动平均更干净的序列，用于均线类策略或趋势识别。

第二个用法是**周期性挖掘**。对长周期的商品价格或宏观序列做 EMD，某个 IMF 的周期如果稳定落在比如 40 个月附近，就值得进一步查它是否对应库存周期或产能周期。这里 Hilbert 边际谱能告诉你哪个尺度在每个时间段占据主导能量。第三个用法是**多尺度相关性**：先把两个资产各自分解，再看它们在相同尺度 IMF 上的相关性——往往能发现原始序列相关性被不同尺度的信号互相抵消掉的隐藏联动。

但要克制住一个诱惑：**别直接拿 IMF 当预测信号**。EMD 是分解工具，不是预测模型；它用的是全样本信息（尤其是端点处的样条插值有前视味道），在因果的回测里必须只用历史窗口内的分解结果，否则会引入难以察觉的未来函数。这正是上文反复强调端点效应的实际含义——它不只是数值精度问题，更是回测严谨性问题。

## 结语

EMD 用「让数据自己拆解自己」的思路，绕开了傅里叶的固定基和小波的人工选择。本文从零实现的筛选过程在三周期合成信号上把 16/64/256 还原到相关系数 0.971/0.912/0.707，重构误差压到 1.78e-15；在两段式非平稳信号上自动分离快慢振荡，Hilbert 瞬时频率相关 0.993。这些数字证明了它在自适应时频分解上的威力，而模态混叠、端点效应与 Hilbert 边界伪影则划清了它的适用边界。把它当作探索价格多尺度结构的显微镜，而不是预测未来的水晶球——用对了地方，EMD 能让你看见趋势与摆动之间那些 Fourier 永远看不清的细节。
