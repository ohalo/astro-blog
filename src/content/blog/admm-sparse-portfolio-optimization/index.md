## 一、结论先行

稀疏组合优化是量化里最常见的一类凸问题：均值-方差目标加 L1 稀疏惩罚、再加对上一期仓位的换手惩罚。它没有闭式解，但 ADMM（交替方向乘子法）能把复合目标拆成两块**各自有闭式解**的子问题——这正是它在组合优化里经久不衰的原因。本文把这套流程在真值已知的合成市场上做完整，结论有四条：

1. **拆分后每一步都是闭式。** w 步是带净敞口约束的二次规划，KKT 方程组的系数矩阵在整个求解过程中不变，一次 Cholesky 预分解后每步只做两次三角回代加一次标量校正；两个 z 步是逐元素软阈值。与 CVXPY/CLARABEL 内点法对拍：目标值相对误差 7.5e-12，最大权重差 4.2e-7。
2. **rho 必须匹配 gamma·Sigma 的特征尺度。** rho 从 1e-4 扫到 1e-1，收敛到 1e-9 精度所需迭代数是一条教科书级的 U 形曲线：1e-3 处 66 次最少，两端 675 次和 1828 次。rho=1（网上示例代码的常见默认值）在本问题里比最优值慢 28 倍——**不是 ADMM 慢，是 rho 选错了**。
3. **稀疏是否划算，由换手成本口径一票决定。** L1 惩罚把非零权重从 60 个压到 15 个、总杠杆从 10.7 降到 1.0，但毛 Sharpe 单调下降（3.58 到 2.28）；净 Sharpe 的最优 lambda 随单位换手成本从 0 单调移到 4e-4。成本口径取错了，稀疏就从风控工具变成纯粹的收益损耗。
4. **自适应 rho 与热启动是一对真实的工程权衡。** 残差平衡的自适应 rho 从 3e-4 出发要 315 次迭代，比调好的固定 rho 慢 4.8 倍——它省的是调参人力，不是计算时间。而 scaled 形式下的对偶变量 u=y/rho 只有在 rho 不变时才能跨期传递：固定 rho 时热启动省 15.8% 迭代，自适应 rho 下热启动反而拖慢两倍以上。

## 二、问题与拆分

要解的问题是带两个 L1 惩罚的均值-方差组合，允许做空、净敞口为一：

$$\min_{w}\ \frac{1}{2}\gamma\, w^\top\Sigma w-\mu^\top w+\lambda\|w\|_1+\eta\|w-w_{\mathrm{prev}}\|_1\quad \mathrm{s.t.}\ \mathbf 1^\top w=1$$

lambda 是稀疏惩罚（把小权重精确压到零），eta 是换手惩罚（压制对上期仓位的调仓幅度）。直接对 w 做投影梯度会被两个不可微点卡住，内点法则每改一次 lambda 都要重跑。ADMM 的做法是引入两个拆分变量把不可微部分隔离开：

$$z_1=w\ \text{(承载稀疏)},\qquad z_2=w-w_{\mathrm{prev}}\ \text{(承载换手)}$$

增广拉格朗日的 scaled 形式下，三步更新全部闭式。w 步是带等式约束的二次规划，KKT 条件给出线性方程组：

$$A\,w=\mu+\rho(z_1-u_1)+\rho(w_{\mathrm{prev}}+z_2-u_2)-\nu\mathbf 1,\qquad A=\gamma\Sigma+2\rho I$$

其中 nu 由净敞口约束定出：先解无约束解 w_free，再减去 nu·A⁻¹1 修正。A 在整个求解中不变，Cholesky 分解一次即可复用。两个 z 步都是逐元素软阈值，u 是 scaled 对偶变量累加器：

```python
import numpy as np

def soft(x, t):
    return np.sign(x) * np.maximum(np.abs(x) - t, 0.0)

def admm_sparse(Sigma, mu, w_prev, lam, eta, rho=1e-3, maxit=6000, tol=1e-9):
    """带 L1 稀疏 + 换手惩罚的均值-方差组合，sum(w)=1，允许做空"""
    N = len(mu)
    A = GAMMA * Sigma + 2 * rho * np.eye(N)
    L = np.linalg.cholesky(A)                      # 预分解，整个求解只做一次

    def Ainv(b):
        y = np.linalg.solve(L, b)
        return np.linalg.solve(L.T, y)

    ones_inv, denom = Ainv(np.ones(N)), None
    denom = np.ones(N) @ ones_inv
    w = np.zeros(N); z1 = w.copy(); z2 = w.copy()
    u1 = np.zeros(N); u2 = np.zeros(N)
    for it in range(maxit):
        b = mu + rho * (z1 - u1) + rho * (w_prev + z2 - u2)
        w_free = Ainv(b)
        nu = (np.ones(N) @ w_free - 1.0) / denom   # 净敞口约束的拉格朗日乘子
        w = w_free - nu * ones_inv                 # w 步：闭式
        z1 = soft(w + u1, lam / rho)               # z1 步：稀疏软阈值
        z2 = soft(w - w_prev + u2, eta / rho)      # z2 步：换手软阈值
        u1 += w - z1                               # 对偶累加
        u2 += w - w_prev - z2
        if np.linalg.norm(w - z1) < tol and np.linalg.norm(w - w_prev - z2) < tol:
            break
    return w
```

合成市场用三因子结构：N=60 只资产、日频因子载荷、特异波动 0.8%–1.2%，真实预期收益由三个因子 alpha（0.08/−0.06/0.05）加特异噪声构成；训练段 600 天估出 Sigma_hat 与 mu_hat，全部优化在这套估计上做，评估用真实矩。风险厌恶 gamma=30、基准 lambda=1.2e-4、eta=6e-5，上一期仓位取等权。

## 三、与内点法对拍：1e-12 级别的吻合

对拍的参照物是 CVXPY 建模、CLARABEL 内点法求解（tol_gap 压到 1e-12）的同一个问题。ADMM（自适应 rho、tol=1e-9）返回的目标值与内点法只差相对 7.5e-12，60 个权重分量的最大绝对差 4.2e-7——图 2 的两根柱子肉眼完全重合。

![图2：ADMM 与内点法的最优权重逐资产对比](/images/admm-sparse-portfolio-optimization/fig2_weight_match.png)

值得强调的是代价结构：ADMM 的每步成本是一次三角回代（O(N²)），预分解只在开始做一次；内点法每步要分解一个随约束增长的 KKT 系统。本例 N=60 两者都快，但 ADMM 的结构在两处占优——lambda/eta 扫描时可以热启动复用分解，且约束可以任意加（多空限额、行业上限都只改 w 步的投影）而不破坏闭式性。收敛轨迹（图 1 左）显示三种固定 rho 的原始残差（实线）与对偶残差（虚线）同步下探，右图把目标值与内点法最优值的相对差距画进同一坐标系，三条曲线最终都跌破 1e-10——**ADMM 不是近似算法，收敛判据给足精度它就是精确解**。

## 四、rho 必须匹配 gamma·Sigma 的尺度

这是全文最想传出去的工程教训。ADMM 的收敛速度由增广项 rho 与目标函数曲率（本例即 gamma·Sigma 的特征值，量级 3e-3）的相对大小决定：rho 远小于曲率，w 步对 z 的约束太软，primal 残差下得慢；rho 远大于曲率，w 步几乎只看增广项，对偶残差下得慢。U 形的最低点就在两者匹配的量级。

rho 扫描实测（收敛到原始与对偶残差同时低于 1e-9）：

| rho | 1e-4 | 3e-4 | 1e-3 | 3e-3 | 1e-2 | 3e-2 | 1e-1 |
|---|---|---|---|---|---|---|---|
| 迭代数 | 675 | 229 | **66** | 75 | 195 | 553 | 1828 |

最优 rho=1e-3 与 gamma·Sigma 的特征尺度 3e-3 同量级，完全符合预期。rho=1e-1（很多示例代码的默认值）比最优慢 28 倍，rho=1e-4 慢 10 倍。**换一个 gamma 或换一组 Sigma，U 形最低点会整体平移**——rho 没有普适默认值，只有「与问题曲率同量级」这一条原则。图 4 左图把这七个点连成完整曲线，红虚线标出自适应 rho 从 3e-4 出发的成绩（315 次）。

## 五、稀疏前沿：L1 同时压住持仓数与杠杆

lambda 从 0 扫到 6e-3，解的结构发生三段式变化（图 3 左）：非零权重从 60 个降到 47、29、21、最后稳在 15 个；总杠杆（绝对权重之和）从 10.7 一路压到 1.0——lambda 足够大后解收敛到「15 只多头、零做空、杠杆恰为 1」的纯多头组合，继续加惩罚不再改变解。换手从 10.5 降到 1.5，这是同一枚硬币的另一面：杠杆下来了，对等权仓位的调仓幅度自然小了。

![图3：稀疏前沿与换手成本敏感性](/images/admm-sparse-portfolio-optimization/fig3_sparsity_frontier.png)

毛 Sharpe（用真实矩评估、不计成本）则单调下降：3.58、3.52、3.30、2.93、最后 2.28。这个方向性很清楚——**稀疏惩罚是在用分散化换简洁**，L1 每压掉一个权重，丢掉的是那部分资产的真实分散化贡献。它不是免费的样本外增强。

## 六、稀疏是否划算，由成本口径一票决定

既然稀疏降换手、升毛收益成本，那净 Sharpe（扣掉换手成本）的最优 lambda 就取决于单位换手成本。把同一组前沿解在六个成本口径下重新计分（图 3 右）：

| 单位换手成本 | 0 | 2e-5 | 5e-5 | 1e-4 | 2e-4 | 5e-4 |
|---|---|---|---|---|---|---|
| 最优 lambda | 0 | 0 | 1e-4 | 2e-4 | 2e-4 | 4e-4 |
| 最优净 Sharpe | 3.58 | 3.39 | 3.11 | 2.70 | 1.88 | −0.53 |

成本为零或 0.2bp 时最优解就是不稀疏（lambda=0）；成本升到 0.5bp，最优 lambda 移到 1e-4；到 2bp 时移到 2e-4；到 5bp（年化口径的现实量级）时移到 4e-4，且**所有日频调仓方案净 Sharpe 全部转负**——这个量级的成本下，10 倍换手本身就是策略亏损的第一原因，稀疏惩罚只是把亏损从更糟收窄到 −0.53 而已。

这张表是本文最想被记住的诚实结论：**lambda 的正确值不在优化器里，在你的交易成本假设里。** 实务里常见的「拍脑袋取 lambda=0.01 再看权重好不好看」恰恰把因果搞反了——先定成本口径（含滑点与市场冲击），再反推 lambda，稀疏惩罚才是在为成本服务而不是为美感服务。

## 七、热启动要奏效，得先固定 rho

滚动调仓是 ADMM 的天然主场：相邻两期的 mu、Sigma 高度相似，上期解是本期极好的起点。但实验里有个反直觉的发现（图 4 右）：让预期收益按 AR(1) 缓慢漂移、逐期重解 20 次，**自适应 rho 下热启动平均 872 次迭代，比冷启动的 391 次还慢一倍多**——scaled 形式的对偶变量 u=y/rho 会随自适应 rho 改变尺度，跨期沿用旧 u 与本期新 rho 失配，算法要花大量迭代重新校平。

![图4：rho 扫描的 U 形与固定 rho 下的热启动收益](/images/admm-sparse-portfolio-optimization/fig4_rho_warmstart.png)

切换到固定最优 rho=1e-3 后，同一套漂移序列下热启动平均 318.9 次对冷启动 378.6 次，省 15.8%。**自适应 rho 与热启动在这里是互斥的**：前者免掉调参人力，后者要求 rho 稳定以传递对偶状态。实务的取舍很直接——逐日滚动的生产环境固定一个校准过的 rho 并热启动；研究环境频繁改 gamma、lambda、约束，用自适应 rho 免调参、放弃热启动。另一条诚实披露是图 4 左的红虚线：自适应 rho 从 3e-4 出发要 315 次，比调好的固定 rho 慢 4.8 倍——自适应的价值是鲁棒性不是速度，别指望它比手调更快。

## 八、实操建议

1. **rho 从 gamma·Sigma 的特征尺度起步。** 算一下目标函数 Hessian 的中位特征值（本例 3e-3），rho 取它的 0.3–3 倍做网格，再用 rho 扫描确认 U 形最低点，而不是照抄示例的 rho=1。
2. **扫描时预分解、热启动。** A 只依赖 rho，lambda/eta 的整条前沿可以共用一次 Cholesky；相邻点的解做起点，扫描速度能再提一个量级。
3. **lambda 由成本口径反推。** 把「单位换手总成本（佣金+滑点+冲击）」写进参数表，按第六节的敏感性表定 lambda；成本口径一变，lambda 跟着重标定。
4. **收敛建议用相对判据。** 绝对 tol=1e-9 在权重量级 0.01 的本例是严格的；量级更大的问题记得按 ‖w‖ 缩放 tol，否则会在尾部精度上白白多跑几百次。
5. **不要拿 L1 当样本外增强。** 本文真实矩评估显示毛 Sharpe 随 lambda 单调下降；L1 的收益只存在于成本端与容量端（杠杆 10.7 到 1.0 的差别在实盘约束下是生死问题），把它当 alpha 来源是对工具的误解。

全部数值来自 N=60、三因子、gamma=30 的合成市场，优化与对拍代码即第二节函数加一个 CVXPY 版本，可整段复制运行。ADMM 本身二十行，真正决定成败的是 rho 的量级与成本口径这两件优化器外面的事。
