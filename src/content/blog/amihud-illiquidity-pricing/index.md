## 一、结论先行

流动性溢价是资产定价里最难「干净」检验的命题之一：流动性差的股票往往也是小盘股、高波动股，你以为自己买的是流动性补偿，很可能只是买了个规模因子。Amihud（2002）给出的 ILLIQ 提供了一个直接把价格冲击塞进收益横截面的办法。

在 500 只股票、132 个月的合成面板里，我给 ILLIQ 埋了一个真实的月度溢价 **0.15%**（每上升一个横截面标准差）。结果分三层：

- 按 ILLIQ 排序的最高五分位减最低五分位，每月价差 **0.577%**，年化 **6.93%**，Newey-West t=11.09；
- 朴素 Fama-MacBeth 斜率 **0.002188**，比真值高 **46%**——多出来的部分来自小盘效应；
- 加入市值控制后斜率 **0.001503**，t=5.38，几乎正好回到埋进去的真值。

换句话说，ILLIQ 排序确实抓到了溢价，但如果不处理规模混淆，你会把规模溢价错记到流动性账上，据此设计的产品很可能在小盘因子反转时一起亏钱。

## 二、ILLIQ 到底在量什么

对股票 i 在第 t 个月，Amihud 非流动性的定义是：

```
ILLIQ_i,t = (1 / D_t) · Σ_d |r_i,t,d| / DollarVolume_i,t,d
```

直观含义是「一美元成交额推动多少价格变动」。分子取绝对收益而非 signed return，是为了避免买卖方向抵消；分母用成交额而非成交量，才能跨价格、跨股票比较。数值越大，说明同样的成交金额造成的价格位移越大，流动性越差。

![Illiquidity vs size](/images/amihud-illiquidity-pricing/fig1_illiq_size.png)

我在模拟里让市值决定日常成交额，再让潜在流动性影响成交额与日内波动。第 60 个月横截面上，log ILLIQ 与市值 z-score 的相关系数达到 **-0.873**：小盘股几乎必然出现在高 ILLIQ 一端。这不是模拟的偶然，而是现实市场里最麻烦的混淆源。

## 三、真值已知的合成面板

实验设定：500 只股票、132 个月，每月 21 个交易日。每只股票的对数市值从 N(22, 0.9²) 起步，潜在流动性 q 服从 AR(1) 并叠加市场共同流动性冲击。月度收益由下式生成：

```
r_i,t+1 = 0.005 + 0.0015·z(ILLIQ_i,t) - 0.0006·z(Size_i,t)
          + 0.00035·Momentum_i,t + 0.85·r_market,t + ε_i,t
```

这里 0.0015 就是唯一的真溢价。注意收益依赖的是**滞后一期**的 ILLIQ，避免把当月冲击成本与当月收益混在一起。先用每月日收益算出 ILLIQ，再拿它预测下个月收益，整个时间顺序保持干净。

构造因子的核心代码只有几行：

```python
def amihud_illiq(daily_ret, daily_dollar_vol, scale=1e8):
    # daily_ret: (days,) 日收益；daily_dollar_vol: (days,) 成交金额
    return np.mean(np.abs(daily_ret) / daily_dollar_vol) * scale

illiq = np.array([
    amihud_illiq(daily_ret[i, m], dollar_vol[i, m])
    for i in range(N) for m in range(T)
]).reshape(N, T)
illiq_z = zscore(np.log(illiq[:, m]))   # 每月横截面标准化
```

尺度因子本身不影响横截面排序，但必须在所有月份、所有股票上保持一致。若有的月份用 10^6、有的用 10^8，时间序列上的因子暴露会凭空跳变。

## 四、Fama-MacBeth 与组合排序

月度 Fama-MacBeth 分两步：每个月把下月收益对当期标准化因子做横截面回归，再把 119 个月的系数序列平均，用 Newey-West 处理序列相关。

```python
def nw_t(x, lag=3):
    m, n = x.mean(), len(x)
    e = x - m
    v = np.mean(e*e)
    for L in range(1, lag+1):
        v += 2*(1-L/(lag+1))*np.mean(e[L:]*e[:-L])
    return m / np.sqrt(max(v, 1e-20)/n)

for t in range(13, T):
    y = ret[:, t]
    x_raw = np.column_stack([np.ones(N), illiq_z[:, t-1]])
    x_ctl = np.column_stack([np.ones(N), illiq_z[:, t-1], size_z[:, t-1]])
    fm_raw.append(np.linalg.lstsq(x_raw, y, rcond=None)[0])
    fm_ctl.append(np.linalg.lstsq(x_ctl, y, rcond=None)[0])
```

![Fama-MacBeth slope](/images/amihud-illiquidity-pricing/fig2_fama_macbeth.png)

灰色水平线是零。朴素斜率序列整体位于控制市值版本之上，两者相差接近 0.0007/月，年化就是 8% 以上的「虚假溢价」。控制市值后市值系数本身为 -0.000788、t=-2.59，方向也符合埋进去的小盘效应。

组合排序给出更可交易视角。每月按滞后 ILLIQ 把股票分成五组，等权持有到下个月：

![ILLIQ quintiles](/images/amihud-illiquidity-pricing/fig3_quintile.png)

最高组（红色）累计收益明显跑赢最低组（蓝色），多空价差曲线稳定向上。119 个月里月均价差 **0.577%**，t=11.09，年化 **6.93%**。样本内结果漂亮，但请记住：这是合成数据，且等权重没有扣交易成本——高 ILLIQ 组合的冲击成本本来就该从毛收益里扣掉。

## 五、规模控制后还剩多少

五分位排序的「全样本价差」包含了规模暴露。为了拆开，我先用市值三分位分组，再在每个市值组内部按 ILLIQ 分五组：

![Size controlled spread](/images/amihud-illiquidity-pricing/fig4_size_control.png)

三组内部价差分别是 **0.372% / 0.203% / 0.514%** 每月，全部为正，但都低于全样本排序的 0.577%，而且组间噪声不小。这与 Fama-MacBeth 的结论一致：流动性溢价真实存在，但全样本排序把它与规模效应混在了一起。大市值组内部价差反而最高，说明这里的异质性还包含估计误差，不能过度解读排序。

## 六、和其他流动性代理有什么区别

Roll 价差只用收盘价的自协方差反推有效价差，优点是只需要价格序列；Corwin-Schultz 用两日高低价，优点是日频数据就能估；Pastor-Stambaugh 则把流动性冲击本身当成一个可定价的系统性因子。Amihud ILLIQ 站在这三者中间：它直接度量「成交额对价格的推动」，经济含义最贴近交易成本，但依赖高质量的成交额与日频收益。

因此这些方法不是互相替代，而是互相校验。如果 ILLIQ 排序出的高溢价在 Roll 价差与 Corwin-Schultz 上也存在，可信度会明显提高；如果只有 ILLIQ 能排序出收益，就要怀疑它其实在代理别的风险——比如波动率、关注度或信息不确定性。本文的合成数据只埋了流动性溢价，所以四个口径理论上应该一致；真实数据里出现分歧时，分歧本身往往比任何一个单独指标更有信息量。

还有一个方法论细节：ILLIQ 的横截面分布极度右偏，直接拿原始值做线性回归会被少数极端股票主宰。我选择先取对数再做每月 z-score，这让系数解释变成「流动性对数标准差上升一单位对应的月收益变化」。若改用分位数排序或 winsorize，结论方向通常不变，但系数大小会变；发文或写报告时必须把口径写清楚，否则不同研究之间的数值根本不可比。

## 七、三个高频坑

**第一，成交额量纲必须换算成货币。** 如果用「股数」而非「成交额」，高价股会被系统性判成更流动。A 股研究常用元为单位，美股用美元；跨市场比较时还要处理汇率与复权。

**第二，零收益日怎么处理。** 若一天收益恰为 0，分子为 0 会把 ILLIQ 拉低。部分文献剔除零收益日，部分保留。两种口径对不同股票的影响并不相同，必须在全样本统一，并做敏感性测试。

**第三，排序口径决定你赚的是谁的溢价。** 全样本五分位里高 ILLIQ 端挤满小盘股；市值中性组合才是真正的流动性暴露。若你的组合已经有个股上限或市值约束，回测里的 0.577% 大多拿不到。

换手成本是另一个容易被忽略的扣减项。ILLIQ 高的股票不仅买卖价差大，冲击也随交易规模非线性增长；等权组合每月全仓换到新的一组高 ILLIQ 股票，实际成本可能吞掉月均价差的相当一部分。更接近实盘的做法是按参与率约束下单，用平方根冲击模型估算每笔交易的滑点，再把净收益重新排序一次。你会发现毛收益上的漂亮单调性，在净收益里可能被成本最大的那几只股票打断——这恰恰说明因子研究里「可交易」三个字有多重。

还有一个容易被忽略的点：ILLIQ 是**已实现**冲击的代理，不是事前挂单簿深度。危机中成交额骤降、波动飙升，ILLIQ 会跳升，但它同时反映价格变化与交易萎缩，因果方向并不干净。把它当预测因子可以用，把它当「流动性成本」直接扣进 PnL 则会重复计算。

## 八、小结

Amihud ILLIQ 的价值，在于把抽象的交易摩擦压缩成一个可横截面比较的数字。但这个数字与规模高度纠缠：本实验中简单排序的月均价差 0.577% 里，只有约 0.15% 是埋进去的真实流动性溢价。Fama-MacBeth 加市值控制把斜率从 0.002188 修回 0.001503，几乎是教科书级的演示。

做流动性因子，先问自己一个问题：你到底想交易「难交易」本身，还是想交易「小」？这两件事在历史数据里长得几乎一样，在风格切换时却会彻底分道扬镳。
