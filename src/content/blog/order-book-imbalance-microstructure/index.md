看 K 线，你看到的是**成交之后**的世界：一根阳线已经把买方 victory 写进了历史。但真正决定下一笔往哪走的，是此刻挂在买卖盘上的那些**还没成交**的限价单。订单簿（limit order book）就是这张即时供需地图，而订单簿失衡（Order Book Imbalance, OBI）是读这张地图最直接的一把尺子。

本文做三件事：第一，从挂单量构造 OBI，验证它能不能预测下一笔是主动买还是主动卖；第二，用 Kyle 价格冲击模型把失衡翻译成价格漂移，并亲手演示一个经典的计量陷阱——遗漏变量偏误；第三，把 OBI 做成方向策略，同时诚实说明为什么模拟里的漂亮 Sharpe 在实盘里会大幅缩水。全程用 numpy 从零模拟一个 20000 笔的订单簿，所有数字都是脚本实跑出来的。

## 一、订单簿失衡：把供需压成一个数

在限价簿里，买方把买单挂在最优买价（bid）及之下，卖方把卖单挂在最优卖价（ask）及之上。最浅的两档之间就是价差。我们只取各档挂单量的总和，定义：

$$
\text{OBI}_t = \frac{V_t^{bid} - V_t^{ask}}{V_t^{bid} + V_t^{ask}}
$$

其中 $V^{bid}$、$V^{ask}$ 分别是买卖盘若干档的挂单总量。OBI 取值在 -1 到 +1：接近 +1 表示买盘队列远厚于卖盘，接近 -1 反之。它的直觉是：挂单是"等待成交的意愿"，买方堆得越多，说明越多人愿意在这个价位接货，价格越可能被买上去。

为了验证这个直觉，先造一个已知真相的市场。我让一个潜在的"买卖压力" $s_t$ 服从 AR(1) 过程（$\phi=0.95$，持久度很高），它同时驱动三件事：买盘深度 $V^{bid}\sim\text{Poisson}(e^{2.4+1.3s_t})$、卖盘深度 $V^{ask}\sim\text{Poisson}(e^{2.4-1.3s_t})$，以及下一笔主动买入概率 $p_{buy}=\text{sigmoid}(1.6s_t)$。这样 OBI 里天然含有关于成交方向的信息——这正是真实市场里发生的事：大资金一边在买盘悄悄挂单，一边接连主动扫货。

![订单簿模拟：潜在压力、挂单深度与 OBI](/images/order-book-imbalance-microstructure/01_obi_signal.png)

图里能清楚看到，潜在压力 $s$（第一行）抬升时，红色买盘深度同步变厚、绿色卖盘变薄（第二行），紫色 OBI（第三行）随之冲高。三者被同一个 $s$ 串起来，这是后面所有验证的基础。

## 二、OBI 真能预测方向吗

有了数据，第一个问题很直接：OBI 越高，下一笔越可能是主动买吗？我用两种办法检验。

第一种是**分箱统计**：把 OBI 从小到大切成十档，看每档里主动买入的实际比例。结果是一条漂亮的单调递增曲线——最低档只有 1.15% 是主动买，最高档高达 97.35%，中间从第 4 档的 25.44% 一路爬到第 8 档的 84.27%。这不是噪声能解释的斜率，失衡和方向之间存在强单调关系。

第二种是 **AUC 与 logistic 回归**。我自己实现了带并列秩次的 AUC（避免引入 sklearn），得到 AUC = **0.8999**。用梯度下降拟合 $P(\text{主动买})=\text{sigmoid}(w_0+w_1\cdot\text{OBI})$，得到 $w_0=-0.0044$、$w_1=2.2319$——截距几乎为零（OBI 为 0 时买卖各半，符合对称预期），斜率 2.23 说明 OBI 每抬升 0.1，主动买概率的对数几率就上升约 0.22。用 0.5 作阈值分类，准确率 **81.87%**，而"永远猜多数类"的基线只有 51.26%（本例买卖几乎均衡）。

```python
# OBI 对成交方向的预测力
X = np.column_stack([np.ones(N), OBI])   # 设计矩阵
w = np.zeros(2)
for _ in range(4000):
    p = 1 / (1 + np.exp(-np.clip(X @ w, -30, 30)))
    w -= 0.5 * X.T @ (p - direction) / N   # 梯度下降
acc = ((X @ w > 0).astype(int) == direction).mean()  # 0.8187
```

![OBI 的预测力：分箱曲线与 ROC](/images/order-book-imbalance-microstructure/02_predictive_power.png)

要注意 AUC 0.90 是**模拟世界的理想值**。真实订单簿里，你看到的是快照，而驱动成交的是别人脑中的私有信息；挂单还能被随时撤掉（"幌骗单"），OBI 的预测力通常只有 0.55 到 0.65 这个量级。这里的价值在于方法，而非这个具体数字。

这里还要分清两个常被混用的概念。OBI 衡量的是某一时刻**存量**挂单的不对称，是一张静态快照；而订单流不平衡（Order Flow Imbalance, OFI）衡量的是一段时间里挂单量**变化**的累积，是动态过程。前者回答"此刻供需哪边厚"，后者回答"这一段时间里谁在持续进攻"。真实研究中两者互补：OBI 对瞬时方向更敏感，OFI 对持续价格漂移的解释力更强。此外，本文只用了最优几档的总量，实务中还会按档位距离加权——越靠近最优价的单子，越可能马上成交，权重越高；把远档的单子与近档等量齐观，会稀释信号。这些改进都不改变核心逻辑，只是把"供需地图"读得更精细。

## 三、价格冲击：一次遗漏变量偏误的现场教学

OBI 能预测方向，那能不能预测**价格会动多少**？Kyle 的价格冲击模型给出一个线性近似：

$$
\Delta m_t = \lambda \cdot Q_t + \varepsilon_t
$$

其中 $Q_t=2\cdot\text{dir}_t-1$ 是净订单流（主动买为 +1、主动卖为 -1），$\lambda$ 是价格冲击系数——每单位净买压推动价格变动多少。我埋下的真值是 $\lambda=0.0012$，同时让价格里还有一项 $0.0004s_t$ 的漂移（压力本身也会推动中间价）和标准差 0.0009 的噪声。

先用最简单的单变量 OLS 回归 $\Delta m$ 对 $Q$，估出 $\hat\lambda=0.001658$——比真值高了约 38%。这个偏差不是运气差，而是**遗漏变量偏误**：潜在压力 $s$ 既影响净订单流 $Q$（压力高则更可能主动买），又直接影响价格（那一项 $0.0004s$）。它被挤进了 $\lambda$ 的估计里，把冲击系数顶高了。

修正方法很简单：把遗漏的 $s$ 加回回归。

```python
# 有偏：遗漏潜在压力 s
beta  = np.linalg.lstsq(np.column_stack([np.ones(N), netflow]), dmid, rcond=None)[0]
# 修正：把 s 纳入多元回归
beta2 = np.linalg.lstsq(np.column_stack([np.ones(N), netflow, s]), dmid, rcond=None)[0]
```

结果 $\hat\lambda$ 从 0.001658 回落到 **0.001192**，几乎分毫不差地命中真值 0.0012；压力系数估出 **0.000403**，也对准了真值 0.0004。这一课在实盘研究里极其重要：当你发现某个因子的"影响"大得离谱时，第一反应不该是庆祝，而是问**是不是漏掉了一个同时驱动因子和结果的共同变量**。价格冲击估计里漏掉流动性潮汐、市场情绪，是研究员最常踩的坑。

## 四、把 OBI 做成策略

预测力和价格冲击都验证完，最后把它变成交易信号：OBI 为正就做多、为负就做空，持仓收益等于持仓方向乘以下一期价格变化，再扣掉单边 4bp 的成本（半个价差加冲击）。

```python
pos = np.sign(OBI)
ret = pos * np.roll(dmid, -1) - np.abs(pos) * spread_cost
sharpe = ret.mean() / ret.std() * np.sqrt(252)
```

实跑结果：OBI 方向策略 Sharpe **8.46**、最大回撤 **-2.45%**、方向命中率 **78.61%**；对照的随机方向策略 Sharpe -3.26（被成本拖垮），买入持有 Sharpe -0.63。策略完胜的根源正是前面验证过的方向预测力——当命中率接近 79% 且盈亏幅度对称时，期望收益自然是正的。

![OBI 方向策略与基准的净值对比](/images/order-book-imbalance-microstructure/04_strategy.png)

但我必须把这个漂亮结果的**水分**讲清楚，否则就是误导。这个 8.46 建立在一个残酷简化的假设上：**你能以看到的 OBI 立刻成交**。真实世界里：

- **排队位置**：你挂在买一的价格未必成交，前面有成千上万手排队；主动扫货则要付价差和冲击，成本远高于 4bp。
- **信息衰减**：从快照到成交之间，别人也在更新订单，OBI 的预测力随延迟快速衰减；高频领域拼的就是微秒级的延迟军备竞赛。
- **容量限制**：订单簿顶部那点深度，撑不起大资金；你自己的单子一进去就改变了 OBI，这是典型的 self-impact。

把这些加回来，Sharpe 从 8.46 掉到 1 附近甚至以下是完全正常的。这个实验真正的产出，是那套"构造失衡 → 验证预测力 → 估计冲击 → 做策略"的完整流程，以及第三节那记警钟。

还有一个容易被忽略的现实约束是信号的**拥挤度**。OBI 这类公开可见的指标，一旦被市场广泛使用，其超额收益就会被套利者迅速吃掉——真正能赚钱的不是指标本身，而是你比别人更快地计算它、更准地识别假单、更低地付出冲击成本。这也是为什么微观结构策略的研究重心，往往从"找信号"转向"拼执行"：谁来提供流动性、谁在消耗流动性、你的订单在队列里排第几位。把这些问题想清楚，比再拟合出一个更高的回测 Sharpe 有意义得多。

## 结语

订单簿失衡把一堆静态挂单压缩成一个可读的方向信号：分箱曲线从 1.15% 单调爬到 97.35%、AUC 0.900、方向准确率 81.87%，证明供需信息确实藏在队列里。价格冲击实验则演示了 Kyle 模型的用法，更演示了遗漏变量偏误如何让 $\lambda$ 虚高 38%——把共同驱动项补回后估计立刻归位。至于 Sharpe 8.46，请把它当成"方法有效性的上限证明"，而不是"可以拿来实盘的收益预期"。微观结构的钱，最终是在延迟、排队和容量的缝隙里挣出来的，不是在理想模拟里。
