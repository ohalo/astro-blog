做量化的人迟早会撞上同一个问题：**这个指标到底领不领先收益？** 大多数人的第一反应是 Granger 因果检验——把 Y 对自身滞后回归，再加进 X 的滞后，看 F 检验显著不显著。这套工具在线性世界里好使，可市场真正值钱的领先关系往往是非线性的：情绪到收益的传导、波动的溢出、成交量的突变效应，都不是一条直线能刻画的。

**传递熵（Transfer Entropy）** 换了个问法。它不问「X 的滞后项在回归里显不显著」，而是问一个更本质的问题：**知道 X 的过去，能让 Y 的未来少掉多少不确定性？** 这个定义建立在信息论的条件互信息上，不对依赖形式做任何线性假设，因此能抓住任意非线性传导。本文用纯 numpy 从零实现分箱传递熵，在四个已知真值的场景里把它和 Granger 正面对比。

## 一、从条件熵到传递熵

传递熵的定义是条件互信息：

$$T_{X\to Y}=I(Y_{t+1};\,X_t\mid Y_t)=H(Y_{t+1}\mid Y_t)-H(Y_{t+1}\mid Y_t,X_t)$$

拆开看非常直觉。第一项 $H(Y_{t+1}\mid Y_t)$ 是「只知道 Y 自己过去」时，预测 Y 未来还剩多少不确定性；第二项 $H(Y_{t+1}\mid Y_t,X_t)$ 是「额外知道 X 过去」后剩下的不确定性。两者一减，就是 X 的过去为预测 Y 未来**额外贡献的信息量**。如果 X 对 Y 毫无影响，两项相等，传递熵为零；如果 X 确实领先 Y，这个差值显著为正。

它和 Granger 因果的关系很微妙：对高斯线性过程，两者渐近等价；但传递熵是分布层面的量，不挑模型，这才是它的杀手锏。方向性也天然具备——$T_{X\to Y}$ 和 $T_{Y\to X}$ 可以完全不同的数值。

## 二、分箱估计：把积分变成数格子

连续变量的传递熵要估概率密度，麻烦。最朴素的做法是**分箱（binning）**：把每个变量的取值按分位数切成 $b$ 个箱子，用频数 approximates 概率。核心估计器只需几十行：

```python
import numpy as np

def bin_series(x, n_bins=4):
    """分位数分箱，返回 0..n_bins-1 的离散标签"""
    edges = np.quantile(x, np.linspace(0, 1, n_bins + 1))
    return np.digitize(x, edges[1:-1])

def te_bits(src, dst, lag=1, n_bins=4):
    """从 src 到 dst 的传递熵（bits），三点联合分布估计"""
    y_next = bin_series(dst[lag:], n_bins)   # t+1
    y_now  = bin_series(dst[:-lag], n_bins)  # t
    x_past = bin_series(src[:-lag], n_bins)  # src 的过去
    n = len(y_next)

    idx3 = y_next * n_bins**2 + y_now * n_bins + x_past
    c3   = np.bincount(idx3, minlength=n_bins**3).reshape(n_bins, n_bins, n_bins) / n
    c_yx = np.bincount(y_now*n_bins + x_past, minlength=n_bins**2).reshape(n_bins,n_bins) / n
    c_yy = np.bincount(y_now*n_bins + y_next, minlength=n_bins**2).reshape(n_bins,n_bins) / n
    c_y  = np.bincount(y_now, minlength=n_bins) / n

    te = 0.0
    for a in range(n_bins):          # y_{t+1}
        for b in range(n_bins):      # y_t
            for c in range(n_bins):  # x_t
                p = c3[a,b,c]
                if p <= 1e-12: continue
                p_y_given_yx = p / c_yx[b,c] if c_yx[b,c] > 0 else 0
                p_y_given_y  = c_yy[b,a] / c_y[b] if c_y[b] > 0 else 0
                if p_y_given_yx > 0 and p_y_given_y > 0:
                    te += p * np.log2(p_y_given_yx / p_y_given_y)
    return te
```

分箱数是唯一的超参数：太少会低估（信息被粗化），太多会因样本稀疏而高估（每个格子没几个点）。本文固定 4 箱、样本量数千，够用。生产环境更稳健的做法是 Kraskov 的 k 近邻估计器，但分箱版本胜在透明——你能清楚看到每一项概率是怎么数出来的。

光有数值还不够，得知道它是否**显著**。做法是**置换检验**：把 src 的时间顺序彻底打乱（破坏时序依赖，但保留边际分布），重复几百次得到传递熵的零分布，再看真实值站在分布的什么位置。

## 三、场景一：线性驱动，方向性有多强

先造一个真值明确的线性系统：$X_t\sim N(0,1)$，$Y_{t+1}=0.6X_t+0.3\epsilon_t$。X 领先 Y 一步，反向不该有任何因果。

结果干净利落：$T_{X\to Y}=0.7675$ bits，而 $T_{Y\to X}=0.0111$ bits，**正向是反向的 69 倍**。置换检验里，打乱 X 后的传递熵均值只有 0.0087、95% 分位 0.0125，真实值高出 353 个标准差。同期 Granger 检验也确认了这个方向：X→Y 的 F 统计量 3001.27（p≈0），而 Y→X 只有 2.33（p=0.054，不显著）。

![传递熵方向性与置换检验](/images/transfer-entropy-market-causality/te-direction-significance.png)

滞后扫描更能说明问题。沿着 k=1 到 k=8 扫一遍，$T_{X\to Y}$ 在 k=1 处飙到 0.7675，其余滞后全部趴在 0.008 附近——传递熵精确定位了「领先一步」这个真值，没有把自相关误认成因果。

## 四、场景二：非线性，Granger 翻车的地方

真正的重头戏在这里。改成 $Y_{t+1}=X_t^2+0.5\epsilon_t$：Y 完全由 X 的平方驱动。这是最典型的非线性传导——X 和 Y 的**线性相关系数几乎为零**，因为 X 取正负时 Y 都变大。

Granger 检验在这里彻底失灵：X→Y 的 p 值高达 0.9549，宣告「无因果」。可传递熵给了 $T_{X\to Y}=0.4385$ bits，反向仅 0.0086——它毫不犹豫地抓住了这条平方关系。这不是传递熵比 Granger «更高级»，而是两者的**问题域不同**：Granger 问的是线性预测力的增量，传递熵问的是任意形式的信息贡献。当传导天然非线性时，前者结构上就看不见。

![非线性场景：传递熵抓住而 Granger 漏判](/images/transfer-entropy-market-causality/te-nonlinear.png)

## 五、场景三与四：市场语境与零基线

再看一个更贴近实盘的场景：舆情冲击 news 领先收益 ret 一步（系数 0.35），同时收益以更弱的力度（0.15）反馈创造新闻——一个双向系统。传递熵给出 $T_{\text{news}\to\text{ret}}=0.2099$，反向 0.0086，置换检验 z=133.6。它正确识别了「舆情→收益」主导、「收益→舆情」微弱的不对称结构。

最后的控制组：两列独立正态随机数，$T_{A\to B}=0.0140$ bits，接近零但不完全是零——这是有限样本下方格估计的系统性偏差。这个数字很重要，它提醒我们：**传递熵没有天然的零，显著性必须靠置换检验校准**，不能看到 0.01 就当成因果。

## 六、条件传递熵：把混淆变量挡在门外

前面反复强调传递熵测的是信息流而非严格因果，最大的漏洞就是**混淆变量**。设想第三个变量 Z 同时驱动 X 和 Y（比如宏观流动性同时推高舆情热度和股价），那么即便 X 对 Y 毫无直接影响，$T_{X\to Y}$ 也会因为两者共享 Z 的信息而显著为正。这叫虚假传递（spurious transfer）。

解法是引入条件变量，把定义扩展成**条件传递熵**：

$$T_{X\to Y\mid Z}=I(Y_{t+1};\,X_t\mid Y_t,Z_t)$$

含义是：在已知 Z 的信息之后，X 的过去还能为预测 Y 的未来**额外**贡献多少。如果 X 与 Y 的联系完全由 Z 解释，这一项会塌回零。实现上只需把分箱从三维升到四维，对 $(Y_{t+1},Y_t,X_t,Z_t)$ 的联合分布做同样的条件互信息求和——代码结构和 te_bits 几乎一样，只是多套一层循环。代价是格子数从 $4^3=64$ 膨胀到 $4^4=256$，对样本量的要求陡增。所以在小样本场景，与其硬上高维条件传递熵，不如先对 Z 做回归残差化，把 Z 的线性影响从 X 和 Y 里剔掉再算。

这个思路在实盘里很实用。检验「北向资金是否领先大盘」时，市场整体的风险偏好就是天然的混淆变量；检验「某舆情指数是否领先个股收益」时，行业板块的共同涨跌也扮演同样角色。不做条件化，你测到的可能只是「两者都跟着大盘走」。

## 七、用之前必须知道的坑

除了混淆变量，还有几个工程层面的限制要记牢。**样本量是硬约束**：4 箱的三元联合有 64 个格子，样本少于几千时估计方差极大，很多格子只有一两个点，概率估计几乎全是噪声——这也是为什么本文每个场景都用数千个点。**分箱数要敏感分析**：不妨把 b 从 3 扫到 6，看方向性结论是否稳定；只有稳健的排序才值得相信，别把单个 b 下的数值当圣旨。**平稳性假设**：分箱依赖边际分布稳定，市场结构突变（牛熊切换、监管变化）时边际分布漂移，要用滚动窗口重估，窗口长度本身就是个需要仔细调的参数。

还有一点容易被忽略：**高频数据里的微观结构噪声**。分时或逐笔数据充满买卖价差的 bouncing、成交的离散性，这些会在极短滞后上制造虚假的信息流。做日内领先滞后分析时，通常要先对数据做重采样或去噪，把传递熵作用在合理的尺度上。

但这些局限不掩盖它的核心价值。在因子研究里，传递熵能帮你回答那些 Granger 看不见的问题：某个另类数据的突变是否在领先股价？某板块的波动是否在做跨市场传导？两个高频序列之间究竟谁先谁后？它给出的不是一条回归系数，而是一个方向明确、模型无关的信息流数值——这恰恰是探索性研究里最稀缺的东西：一个不依赖你先猜对函数形式，就能告诉你「这里可能有故事」的信号。

## 结语

传递熵把「领先滞后」从线性回归的框架里解放出来，用条件互信息重新定义因果的强弱。四个场景的实测给出了清晰的证据链：线性场景它和 Granger 结论一致（69 倍方向比），非线性场景它完胜（0.4385 vs p=0.9549），市场模拟里它识别出不对称双向结构（z=133.6），独立场景它诚实归零（0.0140）。配图与全部代码已附，拿去跑你自己的数据——也许会发现某个你一直当作噪声的信号，其实一直在悄悄领先价格。
