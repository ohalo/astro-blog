## 一、结论先行

协方差矩阵在教科书里往往是常数，在行情里却是**会呼吸的东西**。我用矩阵 OU 因子造出一个 5 资产、2520 天（10 年）的随机协方差路径：资产 1 与资产 2 的相关系数在 **-0.052 到 0.561** 之间游走，5% 与 95% 分位分别是 **0.082 / 0.451**，围绕 0.30 的均值大幅摆动（图 1）。在这条真值已知的路径上，把 1260 天当训练期、后 1260 天当样本外，比较四种协方差口径：

- **常数协方差**：训练期样本协方差，之后固定不动；
- **EWMA**：RiskMetrics 式递归，λ=0.94；
- **五因子投影**：EWMA 协方差减去已知特质方差后取前 5 个特征对，再投影回"因子 + 对角特质"结构；
- **oracle**：每天直接读取模拟真值 $C_t$，只作上界参照，不可交易。

每天用各口径估出的矩阵做长仓最小方差组合与 99% 正态 VaR。结果：样本外全部日子里，违约率是 **2.14% / 1.67% / 1.51% / 1.11%**；在真实相关系数最高的 25% 日子里（315 天），是 **2.54% / 2.22% / 1.90% / 1.59%**。换成组合波动，四种口径是 **14.82% / 14.63% / 14.47% / 13.95%**；而日均权重换手是 **0 / 0.1098 / 0.0957 / 0.0590**。

这三个数字放一起才是完整结论：动态协方差确实降低违约率和波动，但幅度有限；`oracle` 也不能把违约率压到 1%，因为正态 VaR 面对的是混合分布；按 5bp 成本算，因子投影每天 0.0957 的换手一年要吃掉约 **1.21%** 收益，比它省下的 0.35 个百分点波动更贵。**协方差会呼吸是真的，但"跟着呼吸调仓"未必划算。**

## 二、矩阵 OU：怎样造一个 Wishart 型的协方差过程

构造思路是把协方差写成随机因子载荷的外积。设 $Y_t$ 是 $n\times k$ 矩阵，每个元素独立服从 OU 过程：

$$
dY_{ij}=-\kappa Y_{ij}\,dt+\sigma_f\,dB_{ij},\qquad X_t=M+Y_t,\qquad C_t=X_tX_t^\top+D.
$$

$D$ 是已知的特质协方差对角阵。若 $Y$ 的平稳方差为 $\sigma_f^2/(2\kappa)$，则由 Wishart 分布的一阶矩：

$$
E[C_t]=MM^\top+k\frac{\sigma_f^2}{2\kappa}I_n+D.
$$

这个恒等式是整篇实验的**校验闸门**：模拟完要先检查样本均值是否回到理论值。本文取 $n=k=5$，$\kappa=2$（相关系数半衰期 $\ln 2/2\approx0.35$ 年），资产目标年化波动 20%、基线相关 0.30，于是 $M$ 的第一列填 $\sqrt{0.3}\times0.2$，特质方差 $D_{ii}=0.7\times0.04$，随机载荷平稳方差取 0.002。理论 $E[C]_{ii}=0.0500$、$E[C]_{ij}=0.0120$，训练期样本估计是 **0.0517 / 0.0103**，量级和方向都对得上（图 2 左）。如果这一关不过，后面的回测再漂亮也是数值事故。

收益用 $r_t=\mathrm{chol}(C_{t-1})z_t\sqrt{dt}$ 生成，日内新息与协方差路径独立。这里有一个容易被忽略的建模选择：OU 是**连续、均值回复**的，所以相关性不会突然跳到 1 再跳回来。真实市场在危机中的相关性上跳往往快得多，本文的结论只适用于这种"慢性呼吸"式协方差。

## 三、四条口径与最小方差权重

常数口径用训练期 1260 天收益估一次就不再更新；EWMA 每天按 $S_t=0.94S_{t-1}+0.06r_{t-1}r_{t-1}^\top$ 递归；因子投影把 $S_t/dt-D$ 做特征分解，只保留最大的 $k=5$ 个非负特征值：

$$
\hat C_t=V_k\Lambda_kV_k^\top+D.
$$

这一步的直觉是：EWMA 的样本噪声主要藏在小特征值里，把小方向砍掉，权重就不容易被噪声牵着走。oracle 口径每天读取 $C_t$ 真值。

权重用长仓、和为 1 的最小方差解，目标函数加一条 $\lambda=0.01$ 的相对对角正则，用 SLSQP 求解。不加正则时 5 资产的最小方差权重经常把 90% 以上押在单一资产上，权重换手会被放大到失去可比性。所有口径用**完全相同的目标函数和约束**，差别只在输入的协方差矩阵。

这里必须强调时序纪律：第 $t$ 天只使用 $t-1$ 及以前的数据估矩阵，oracle 用的是生成第 $t$ 天收益的那一个 $C_t$——是同一时刻的真值，不是未来窗口。所以 oracle 是理论上限，不是可复制策略；它的意义是告诉我们"若协方差完全已知，还剩多少误差是无法消除的"。

## 三点五、为什么不用 EWMA 就够

EWMA 本质上是一个**滤波器**：它对过去的收益外积做指数加权，给出一个平滑的协方差估计，但并没有说明协方差本身服从什么随机过程。矩阵 OU 多出来的不是"另一组权重"，而是三样 EWMA 给不了的东西。第一是**平稳分布**：$Y$ 的平稳方差是 $\sigma_f^2/(2\kappa)$，因此 $C_t$ 的一阶矩可以解析写出，模拟结果有可校验的锚点。第二是**记忆尺度**：相关系数半衰期 $\ln2/\kappa$ 直接对应"高相关状态能持续多久"，这决定了样本外 VaR 应该在多长的窗口里保持警戒；EWMA 的 $\lambda$ 只是一个衰减系数，要换算成半衰期还得自己算 $\ln0.5/\ln0.94\approx11.2$ 天，而且它刻画的是收益率平方的记忆，不是相关性的记忆。第三是**情景生成**：知道生成机制后，可以把 $\kappa$、$k$、$D$ 扰动，直接压测组合，而不必重新找一段历史行情。

因子投影是两者之间的折中：它借 EWMA 做在线更新，再用 $k$ 把估计结果压回低秩加对角的结构。图 2 右画了 1000 个交易日的特征值分布——最大特征值随共同因子强弱明显鼓动，小特征值则贴着特质方差的下沿。砍掉小方向在直觉上很合理，但注意这一步**只降噪，不建模均值回复**：它不会像矩阵 OU 那样告诉你高相关还能持续几天。换句话说，投影改善的是输入矩阵的信噪比，不是你对协方差动态的理解。

## 四、VaR 回测：常数口径在高相关日失守

99% 正态 VaR 写成 $\mathrm{VaR}_t=z_{0.99}\sqrt{w_t^\top\hat C_t w_t\,dt}$，$z_{0.99}=2.3263$。全样本外 1260 天的违约率前面已经给出：常数 2.14%，是目标 1% 的 2.14 倍；oracle 1.11%，已经很接近 1%。两者相差 1.03 个百分点，以 $n=1260$、$p=1\%$ 的二项标准差 **0.28 个百分点**计，约 3.7 个标准差，不是噪声。

更关键的是条件行为。把样本外按真实相关系数排序，取最高的 25%（315 天，平均相关 0.440，低组 0.234），常数口径 VaR 在这组日子里**完全不变**（均值 1.898%），违约率升到 2.54%；oracle 的平均 VaR 升到 2.052%，违约率 1.59%。常数口径的问题不是"估得不准"，而是它根本没有条件化的能力——不管世界怎么变，它给出同一个数（图 3）。

诚实地说，oracle 在高相关组仍有 1.59% 违约率，超过 1% 目标；该组样本只有 315 天，二项标准差约 0.56 个百分点，单次实验无法排除抽样运气。而且这里的收益新息是正态的，组合收益却因为随机协方差成为**正态混合分布**，其尾部天然比正态厚。所以即使用对协方差，正态 VaR 公式依然会低估极端损失——这是另一层模型风险，不是协方差估计能修好的。

## 五、组合层：省下的波动被换手吃掉了吗

把样本外日收益按各口径权重累乘，年化波动从常数的 14.82% 降到 EWMA 14.63%、因子投影 14.47%、oracle 13.95%；最大回撤分别是 -49.98%、-50.05%、-49.86%、-49.90%。**注意最大回撤几乎没改善**——波动下降主要来自平时，真正造成回撤的那几天，动态权重也没能躲开。

换手是另一面账本。日均 $\sum_i|w_{t,i}-w_{t-1,i}|$：常数 0，EWMA 0.1098，因子投影 0.0957，oracle 0.0590。因子投影比 EWMA 少换手 12.8%，说明砍掉小特征值确实让权重更稳；但仍相当于每月约 2 倍组合金额的累计换手。按单边 5bp 的保守成本，因子投影一年摩擦约 $0.0957\times0.0005\times252=1.21\%$，超过它相对常数口径省下的 0.35 个百分点波动。只有当你的成本结构远低于 5bp、或你的目标函数真正惩罚尾部而不只是波动时，这套动态权重才值得上（图 4）。

## 六、核心实现

```python
import numpy as np
from scipy.optimize import minimize
from scipy.stats import norm

n, k, kappa, dt = 5, 5, 2.0, 1/252
rng = np.random.default_rng(20261125)
phi = np.exp(-kappa * dt)
noise = np.sqrt(0.002 * (1 - phi**2))
M0 = np.zeros((n, k)); M0[:, 0] = np.sqrt(0.3) * 0.2
D = 0.7 * 0.2**2 * np.eye(n)

# 矩阵 OU -> Wishart 型随机协方差
Y = rng.normal(size=(n, k)) * np.sqrt(0.002)
Cs, r = [], []
for t in range(2520):
    Y = phi * Y + noise * rng.normal(size=(n, k))
    C = (M0 + Y) @ (M0 + Y).T + D
    Cs.append(C)
    r.append(np.linalg.cholesky(C) @ rng.normal(size=n) * np.sqrt(dt))
r = np.asarray(r); Cs = np.asarray(Cs)

def project(C):                      # EWMA -> k 因子 + 已知特质
    val, vec = np.linalg.eigh(C - D)
    idx = np.argsort(val)[::-1][:k]
    return vec[:, idx] @ np.diag(np.clip(val[idx], 0, None)) @ vec[:, idx].T + D

def minvar(C):                       # 长仓 + 相对对角正则
    Cr = C + 0.01 * np.trace(C) / n * np.eye(n)
    res = minimize(lambda w: w @ Cr @ w, np.ones(n)/n,
                   bounds=[(0, 1)]*n,
                   constraints=[{"type": "eq", "fun": lambda w: w.sum()-1}],
                   method="SLSQP")
    return res.x

S = r[:1260].T @ r[:1260] / 1260     # 训练期样本协方差（日频）
for t in range(1260, len(r)):
    S = 0.94 * S + 0.06 * np.outer(r[t-1], r[t-1])
    C_hat = project(S / dt)           # 因子投影口径
    w = minvar(C_hat)
    var99 = norm.ppf(0.99) * np.sqrt(w @ C_hat @ w * dt)
    breach = r[t] @ w < -var99        # oracle 口径把 C_hat 换成 Cs[t]
```

## 七、边界与误用提醒

第一，本文的真值路径是模拟出来的，参数 $\kappa$、$k$ 和 $D$ 都已知；实盘里这三个量本身要估，"因子投影"的优势会被估计误差再削一层。第二，$k$ 选小了会漏掉真实的共同运动，选大了又回到 EWMA 的噪声状态，本文没有做 $k$ 的敏感性扫描，读者不应把 5 当作普适答案。第三，正态 VaR 与混合分布的组合在极端分位上必然偏乐观，若要真正控制尾部，应换 ES 或直接对协方差路径做蒙特卡洛。第四，本文用日频收益、固定 5 资产，无法回答周度或月度的调仓频率问题；换手成本随频率线性放大，结论不会更好。

**把协方差当成随机变量，而不是一个待估的常数，是观念上的一步；但从中赚到钱，需要动态带来的风险下降大于它制造的摩擦。**在这个可控实验里，前者是 3.7 个标准差的统计事实，后者是一个还没回本的账单。
