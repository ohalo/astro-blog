## 一、结论先行

基金跑赢了基准，基金经理会说"我选股准"，也会说"我择时强"——这两种能力带来的收益在流水上看是一样的，但价值完全不同：选股能力可以稳定复制，择时能力往往依赖于不可持续的预测。怎么把它们分开？

Treynor-Mazuy（1966）和 Henriksson-Merton（1981）给出了两个经典检验，思路都是**看基金收益对市场收益的响应曲线形状**：

1. **TM 二次回归**：`r_p = a + b·r_m + g·r_m² + ε`。如果 `g > 0` 且显著，说明收益曲线向上凸——牛市放大收益、熊市减小亏损，这就是择时。
2. **HM 分段回归**：`r_p = a + b₁·min(r_m,0) + b₂·max(r_m,0) + ε`。熊市斜率 `b₁`、牛市斜率 `b₂`，若 `b₂ − b₁ > 0` 且显著，说明经理在牛市调高 beta、熊市调低 beta。

本文用真值已知的模拟数据把两种方法正面拆解，四条结论：

- **各自的主场都精确**：TM 世界里真 `g=6`，估出 6.0014；HM 世界里真 `b₂−b₁=0.7`，估出 0.6986。
- **原假设下不乱报**：无择时的基金，两种检验的误报率只有 3.75% 和 3.25%，接近 5% 的名义水平。
- **弱择时下功效随样本增长**：牛熊 beta 只差 0.18 的弱择时，60 个月样本检测功效只有 0.28，到 360 个月爬到 0.89——"没测出来"很多时候只是样本太短。
- **最关键的警告**：一个只会持有跨式期权、完全不预测方向的经理，两种检验都 100% 把他判成择时高手（平均 t 值 7.10 和 6.55）。**它们测的是收益曲线的形状，不是预测能力本身。**

## 二、两种检验的数学直觉

先把基金对市场的响应想成一条曲线。如果基金只有选股能力、没有择时，那么它的 beta 是常数，收益对市场是**一条直线**：`r_p = a + b·r_m + ε`，截距 `a` 就是选股 alpha。

择时会让这条直线变形。TM 的假设是"平滑变形"：经理根据对市场的判断连续调整仓位， beta 大致随市场收益线性变化，于是响应曲线变成**抛物线**，`g·r_m²` 这一项捕捉凸性——`g>0` 意味着行情越好、基金涨得越猛，行情越差、基金跌得越少。

HM 的假设是"开关式变形"：经理只判断牛熊两种状态，牛市把 beta 调到 `b₂`、熊市调到 `b₁`，于是响应曲线是**在零点折弯的两条直线**。用 `min(r_m,0)` 和 `max(r_m,0)` 两个回归元就能分别估出熊市和牛市的斜率，`b₂ − b₁` 就是择时能力的大小。

一个用二次项、一个用折点——这就是TM 与 HM 的核心分歧。TM 在择时"连续渐变"时更贴合，HM 在择时"非此即彼"时更贴合。

## 三、实验设计：三种真值已知的世界

本文设定市场月超额收益服从 `N(0.6%, 4%)`，构造三种数据生成过程（DGP），每种重复 400 次、每次 360 个月（30 年）：

- **A：TM 世界**——基金收益真包含二次凸性 `6·r_m²`（`g_true=6`），检验 TM 能否 recovery。
- **B：HM 世界**——牛市 beta=1.3、熊市 beta=0.6（`b₂−b₁=0.7`），检验 HM 能否 recovery。
- **C：无择时世界**——常数 beta=1.0、alpha=0.2%，检验两种检验会不会"无中生有"。

每种 DGP 上同时跑 TM 和 HM 两套回归，用普通最小二乘估计，t 统计量来自回归残差的标准误。

## 四、主场精确，客场也"通过"

表1 汇总了 400 次重复的估计均值与显著性比例：

| 数据世界 | TM 的 g（真值） | TM 显著率 | HM 的 b₂−b₁（真值） | HM 显著率 |
|---|---|---|---|---|
| A：TM 世界 | 6.0014（6） | 100% | 1.0546（无对应） | 100% |
| B：HM 世界 | 3.495（无对应） | 100% | 0.6986（0.7） | 100% |
| C：无择时 | −0.0017（0） | 3.75% | 0.0012（0） | 3.25% |

三个要点。第一，**主场精确**：TM 估 g=6.0014，误差不到万分之三；HM 估 `b₂−b₁=0.6986`，误差不到千分之二。两种方法在各自适配的数据结构下都是无偏的。第二，**原假设守规矩**：无择时世界里两个估计都贴着零（−0.0017 和 0.0012），错误拒绝率 3.75% 和 3.25%，甚至比 5% 名义水平还保守一点。第三，**客场也报"有择时"**：把 TM 用在 HM 世界，虽然 g=3.495 没有"真值"可比，但它依然高度显著；反过来 HM 用在 TM 世界也一样。**两种检验只要看到凸性就会亮绿灯，并不挑剔凸性来自哪种机制。**

图2 是一个 HM 世界的真实样本：绿色 HM 折线在零点明显折弯，红色 TM 抛物线也拟合得不错——两条线在数据中间段几乎重合，尾部才分道扬镳。这就是为什么单看一个样本，很难说谁对谁错。

## 五、样本长度决定"测不测得出来"

很多基金评价的争议其实是样本量问题。本文实验 3 构造了一个**弱择时**基金：牛市 beta=1.0、熊市 beta=0.82，只差 0.18，噪声调大到月残差 1.2%。每种样本长度重复 500 次，统计检测功效（正确拒绝无择时的比例）和 size（原假设下错误拒绝的比例）。

结果显示：60 个月（5 年）时 TM 功效只有 **0.276**、HM 为 0.30——也就是说一个真有弱择时能力的经理，5 年数据下有七成概率被判"无择时"；到 120 个月功效升到 0.42/0.48，240 个月 0.70/0.79，360 个月（30 年）达到 **0.886/0.92**。与此同时，size 在所有样本长度上都稳定在 5% 附近（0.044~0.06），没有因为样本变化而失真。

![图3：检验功效与 size 随样本长度的变化](/images/market-timing-treynor-mazuy/fig3_power_size.png)

这个结果对实务的启示很直接：**用三五年数据做择时检验，基本等于没测**。基金经理的择时能力如果不是很强，你需要十几二十年的数据才有把握识别出来——而这期间市场结构早已变了，这本身就是择时检验的实用困境。HM 的功效在每个样本长度上都略高于 TM，因为它对"开关式"择时（本实验的 DGP）更贴合，但差距不大。

## 六、凸性陷阱：两种检验都会被骗

这是本文最想强调的一点。构造一个**完全没有预测能力**的经理：他不做任何市场判断，只是长期持有一个跨式期权组合，其收益对市场呈现对称的凸性 `2·r_m²`。他的 alpha 是零，他对牛熊没有任何判断——但收益曲线是凸的。

结果（400 次重复）：TM 估出平均 `g=1.999`（真凸性系数就是 2.0），平均 t 值 **7.10**，**100%** 被判为有择时能力；HM 估出平均 `b₂−b₁=0.3503`，平均 t 值 **6.55**，同样 **100%** 误判。

![图4：凸性陷阱下两种检验的 t 统计量分布](/images/market-timing-treynor-mazuy/fig4_convexity_trap.png)

原因很清楚：TM 的 `g·r_m²` 项、HM 的牛熊斜率差，本质上都是在度量**收益曲线的凸性**。一个持有期权、或其他非线性 payoff（可转债、结构化产品、趋势跟踪的非线性仓位）的基金，即使预测能力为零，也会天然表现出凸性。两种检验都无法区分"因为你预测准所以牛市加仓"和"因为你买了期权所以牛市涨得多"——它们看到的是同一个信号。

这不是说检验没用，而是说**必须结合持仓信息解读**。如果已知基金不持有任何期权类资产，那么凸性大概率来自真实的择时调仓；如果基金大量使用衍生品，凸性检验就失去了归因能力。这是纯收益数据做业绩归因的固有局限。

## 七、完整代码

```python
import numpy as np

MU_M, SIG_M = 0.006, 0.04          # 市场月超额收益参数
rng = np.random.default_rng(20261122)

def gen_market(n):
    return rng.normal(MU_M, SIG_M, n)

def fit_tm(rp, rm):
    # TM: r_p = a + b*r_m + g*r_m^2
    X = np.column_stack([np.ones(len(rm)), rm, rm**2])
    beta, *_ = np.linalg.lstsq(X, rp, rcond=None)
    resid = rp - X @ beta
    n, k = len(rm), X.shape[1]
    cov = (resid @ resid / (n - k)) * np.linalg.inv(X.T @ X)
    se = np.sqrt(np.diag(cov))
    return beta, beta[2] / se[2]     # g 及其 t 值

def fit_hm(rp, rm):
    # HM: r_p = a + b1*min(r_m,0) + b2*max(r_m,0)
    X = np.column_stack([np.ones(len(rm)), np.minimum(rm, 0), np.maximum(rm, 0)])
    beta, *_ = np.linalg.lstsq(X, rp, rcond=None)
    resid = rp - X @ beta
    n, k = len(rm), X.shape[1]
    cov = (resid @ resid / (n - k)) * np.linalg.inv(X.T @ X)
    diff = beta[2] - beta[1]         # b2 - b1
    var_diff = cov[2,2] + cov[1,1] - 2*cov[1,2]
    return beta, diff, diff / np.sqrt(var_diff)

# HM 世界：牛 beta=1.3、熊 beta=0.6
rm = gen_market(360)
rp = 0.002 + np.where(rm >= 0, 1.3, 0.6)*rm + rng.normal(0, 0.01, 360)
btm, t_tm = fit_tm(rp, rm)
bhm, diff, t_hm = fit_hm(rp, rm)
print(f"TM: g={btm[2]:.3f}, t={t_tm:.1f}")
print(f"HM: b_bear={bhm[1]:.3f}, b_bull={bhm[2]:.3f}, diff={diff:.3f}, t={t_hm:.1f}")
```

## 八、局限与实践建议

第一，**两种检验测的是同一件事的两面**，不要把它们当成互相独立的证据。它们都基于市场模型的残差结构，对市场收益的分布假设、对 beta 稳定性的假设是一致的。同时显著不代表"双重确认"，只代表凸性很强。

第二，**必须审查持仓**。如第六节所示，衍生品、可转债、结构化产品都会制造假凸性。实务中应先做持仓穿透，把期权类资产的 Delta 单独剥离，再对剩余现货仓位做择时检验，否则归因结论不可信。

第三，**样本长度是硬约束**。五年数据的弱择时检验功效不到三成，这意味着"检验不显著"绝不等于"经理没有择时能力"。报告结果时应同时给出功效分析，明确在当前样本量下能检测到的最小效应是多少，而不是简单接受原假设。

第四，**滚动态度比全样本更有信息**。真实的择时能力会随时间变化，用滚动窗口反复检验，观察 `g` 或 `b₂−b₁` 的时间序列，比一个全样本数字更能反映经理能力的稳定性——当然，这又回到了多重检验和样本窥探的老问题，需要配合相应的统计校正。
