向量自回归（VAR）是宏观金融里最顺手的框架之一：每个变量都由自己和其他变量的过去解释，脉冲响应、方差分解、格兰杰检验一应俱全。但它有个代价——参数随变量数和滞后阶数平方增长。四个变量、四阶滞后，每个方程就要估 1 个常数加 16 个系数，四个方程合计 68 个参数。如果你手上只有 100 个观测，平均每个参数分不到两个数据点。这种情况下最小二乘不是「估计精度差一点」，而是会把噪声当成结构，估出一堆看似显著、实则毫无意义的系数，再顺着 Companion 矩阵传播成离谱的脉冲响应。

**贝叶斯向量自回归（BVAR）**的解法不是删变量、也不是拍脑袋缩阶数，而是把领域知识写成先验分布：经济序列大致接近随机游走，自己的一阶滞后最重要，高阶滞后和跨变量影响应该很小。明尼苏达先验（Minnesota prior）把这套直觉量化成一张标准差表，并且妙在它可以完全等价地改写为几行**虚拟观测**，于是后验均值用普通最小二乘就能算出来。本文从零实现这套机制，用真值已知的模拟系统做 200 次重复实验，看看它到底能救回多少东西。

## 一、参数爆炸到底有多严重

先数清楚账。设变量数 $K=4$，滞后阶数 $p=4$，每个方程的回归元是常数加上 $K\times p=16$ 个滞后项，共 17 个系数；四个方程就是 68 个待估参数。样本量 $T=100$ 时，观测/参数比只有 1.47。统计上这不是「小样本」，这是**病态问题**：设计矩阵接近秩亏，系数估计的方差被放大到无法解释的程度。

一个自然的反应是把滞后阶数降到 1 或 2。但这等于用硬约束替代了软约束：如果真实系统里确实存在微弱的二阶效应，砍掉就引入了偏差。明尼苏达先验的思路是——**不删，只是给每个系数一个「我本来就该接近某个值」的倾向**，数据足够强时可以推翻它，数据不足时由它兜底。这就是 shrinkage 与硬约束的本质区别。

## 二、把先验写成虚拟观测

对第 $i$ 个方程的第 $(j,l)$ 个系数 $a_{ijl}$（变量 $j$ 的第 $l$ 阶滞后对变量 $i$ 的影响），明尼苏达先验设定：

$$a_{ijl}\sim N\big(m_{ijl},\,s_{ijl}^2\big),\qquad m_{ijl}=\begin{cases}1,& i=j,\ l=1\\ 0,&\text{otherwise}\end{cases}$$

也就是说先验均值把系统锚定在随机游走上：变量只受自己的上一期影响，系数恰好为 1。标准差则按三条经验规则递减：

$$s_{ijl}=\frac{\lambda}{l}\times\begin{cases}1,& i=j\\ \theta\,\sigma_i/\sigma_j,& i\neq j\end{cases}$$

其中 $\lambda$ 是全局紧度（tightness），控制先验整体有多强；$l$ 在分母上表示滞后越远、越应该接近零；$\theta<1$ 表示跨变量影响比自身滞后更可疑；$\sigma_i/\sigma_j$ 则让不同量纲的变量可比——波动大的变量的系数先验更松。常数项的先验通常是均值 0、标准差很大（本文取 8，变量先除以样本标准差），相当于近乎无信息。

关键技巧来了。假设某个系数 $a$ 的先验是 $N(m,s^2)$，我们往设计矩阵里加一行：只有 $a$ 对应的那一列为 $1/s$，其余为 0；相应地在被解释向量里加一个值 $m/s$。这一行的残差平方是 $(m/s\cdot 1 - a/s)^2=(a-m)^2/s^2$，恰好就是高斯先验负对数似然的二次项。于是**最小化「数据残差平方和 + 先验惩罚」等价于在这批虚拟观测上直接跑 OLS**。每个方程加自己的 17 行虚拟观测，实现只需一个循环。

## 三、真值已知的赛马场

为了让结论可验证，我们造一个真值完全已知的世界。四个变量可以想成增长、通胀、政策利率和信用利差，真实数据由二阶 VAR 生成：一阶自回归系数在 0.55 到 0.72 之间，交叉影响很小（绝对值多在 0.02 至 0.08），二阶系数约 0.08 至 0.11，三阶和四阶**真实系数恒为零**。创新项带轻微相关，标准差约 1%。每个重复样本生成 200 期，前 100 期训练，后 100 期评估，共做 200 次重复，以抹平单次抽样的运气。

三个选手同场竞技： unrestricted OLS（17 个系数全估）、BVAR（$\lambda=0.20,\ \theta=0.5$）、以及最偷懒的随机游走基准（只把一阶自身系数设为 1，其余全零）。评价用一步预测误差和四步迭代预测误差，都在样本外计算。

## 四、预测精度：BVAR 全面胜出

![样本外预测误差对比](/images/bayesian-var-minnesota-prior/02_rmse.png)

200 次重复的平均结果很清晰。一步预测 RMSE：OLS 0.1138，BVAR 0.1024，改善 10.0%；随机游走 0.1966，差了将近一倍。四步预测：OLS 0.1589，BVAR 0.1457，改善 8.3%；随机游走 0.2112。不止均值，BVAR 的重复间标准差也更小（一步 0.0041 对 OLS 的 0.0070，四步 0.0107 对 0.0147）——意味着它不仅平均更准，而且**每次都更稳**，这对实盘比平均值更重要。

随机游走输得难看并不意外：真实序列有明显均值回归（自回归系数 0.72 而非 1），硬套随机游走等于系统性误设。但这个基准的存在很有价值——它提醒我们，一个复杂模型如果连「什么都不学」都打不过，那它的复杂度就是纯负担。BVAR 的先验均值恰好也是随机游走，可它并不把先验当结论：**数据会把 0.72 从 1 拉回来**，这正是贝叶斯收缩区别于硬约束的地方。

## 五、紧度 λ 的 U 形曲线

先验该多强？把 $\lambda$ 从 0.02 扫到 4.00，答案是一条漂亮的 U 形曲线。

![先验紧度扫描](/images/bayesian-var-minnesota-prior/03_lambda.png)

$\lambda=0.02$ 时 RMSE 0.1076，先验太紧，系数几乎被钉死在随机游走上，严重的偏差让 0.72 拉不回来；$\lambda=0.05$ 降到 0.1053，$\lambda=0.10$ 到 0.1027，$\lambda=0.20$ 触及最低点 0.1024；再放松就开始过拟合，$\lambda=0.4$ 回升到 0.1043，$\lambda=4.0$ 升到 0.1126，几乎退回 OLS 的水平。这个 U 形就是教科书式的偏差—方差权衡：**先验既是正则化，也是偏见的来源**，最佳紧度取决于真实的信噪比，不存在放之四海皆准的数值。实务里应该用滚动样本外预测来选 $\lambda$，而不是凭感觉拍一个。

## 六、真正要命的是脉冲响应

预测误差改善 10% 听起来不算惊天动地，但系数和脉冲响应的差距是数量级的。

![脉冲响应对比](/images/bayesian-var-minnesota-prior/04_irf.png)

先看三、四阶系数：这些项的真值全是零。OLS 估出来的系数平方均值是 0.0160，BVAR 只有 0.000023，相差约 690 倍——先验把本来该为零的东西直接按住了。

再看增长冲击对信用利差的脉冲响应。真值在第 4 期是 -0.00549，OLS 的重复均值 -0.00518 看着很准，可重复间标准差高达 0.01521，是信号本身的三倍；BVAR 均值 -0.00366 明显被收缩压扁了，但标准差只有 0.00472，窄了三倍多。统计上这叫偏差—方差交换：**BVAR 用一点可预期的偏差，换来了不稳定的彻底消失**。按第 4 期响应的符号是否正确统计，OLS 在 200 次里有 78 次估反方向（39%），BVAR 只有 43 次（21.5%）。如果你拿脉冲响应做风险归因或政策判断，符号估反的代价远比幅度偏小惨烈。

## 七、完整实现

下面是核心代码。虚拟观测构造函数是整个方法的灵魂：

```python
import numpy as np

K, P = 4, 4                      # 变量数、滞后阶数
T_TRAIN, T_EVAL, NREP = 100, 100, 200

def build_X(y):
    T = len(y)
    return np.hstack([np.ones((T - P, 1))] +
                     [y[P - l:T - l] for l in range(1, P + 1)])

def minnesota_prior(lam, theta=0.5, int_sd=8.0):
    """返回 (先验均值, 先验标准差)，形状 (K, 1 + K*P)。"""
    mean = np.zeros((K, 1 + K * P))
    sd = np.full((K, 1 + K * P), np.inf)
    sd[:, 0] = int_sd                    # 常数项：近乎无信息
    for i in range(K):
        for l in range(1, P + 1):
            for j in range(K):
                col = 1 + (l - 1) * K + j
                own = (i == j and l == 1)
                mean[i, col] = 1.0 if own else 0.0
                s = lam / l
                if not own:
                    s *= theta            # 变量先标准化后 sigma_i/sigma_j = 1
                sd[i, col] = s
    return mean, sd

def ols_with_prior(X, Y, sd=None, mean=None):
    """逐方程 OLS；把每个系数的先验编码成一行虚拟观测。"""
    B = np.zeros((X.shape[1], Y.shape[1]))
    for i in range(Y.shape[1]):
        Xa, ya = X.copy(), Y[:, i].copy()
        if sd is not None:
            for j in range(X.shape[1]):
                if np.isfinite(sd[i, j]):
                    row = np.zeros(X.shape[1])
                    row[j] = 1.0 / sd[i, j]
                    Xa = np.vstack([Xa, row])
                    ya = np.append(ya, mean[i, j] / sd[i, j])
        B[:, i] = np.linalg.lstsq(Xa, ya, rcond=None)[0]
    return B.T

# 训练：变量先除以样本标准差，预测后再乘回去
sc = train.std(axis=0)
Xtr = build_X(train); Xtr[:, 1:] /= np.tile(sc, P)
Ytr = train[P:] / sc
pri_m, pri_s = minnesota_prior(lam=0.20)
B_s = ols_with_prior(Xtr, Ytr, pri_s, pri_m)   # OLS：ols_with_prior(Xtr, Ytr)
B = np.zeros_like(B_s)
for i in range(K):
    B[i, 0] = B_s[i, 0] * sc[i]
    for l in range(P):
        for j in range(K):
            c = 1 + l * K + j
            B[i, c] = B_s[i, c] * sc[i] / sc[j]

def one_step(y, t):
    x = np.r_[1.0, y[t-1], y[t-2], y[t-3], y[t-4]]
    return B @ x
```

脉冲响应只需把系数矩阵装进 Companion 矩阵 $C$，给第一个变量一个 Cholesky 冲击，然后反复乘 $C$ 取前 $K$ 行；代码里注意 $C$ 的左上角块是转置后的 $A_1$，移位块是单位阵。

## 八、先验不是免费午餐

必须把几条边界讲清楚。第一，先验均值锚定随机游走适合大多数宏观经济与价格序列，**但对强均值回归或平稳性很高的变量会引入偏差**——$\lambda$ 扫描里太紧的那一端就是证据。第二，$\theta$ 和 $\lambda$ 都是超参数，本文的 0.20/0.5 只在这个合成系统里最优，换资产、换频率必须重选。第三，虚拟观测给的是后验**均值**；如果要做置信区间或概率预测，还得推导残差协方差与系数后验分布的抽样，不是把点预测画个带子就行。第四，BVAR 依然假设线性、时不变和残差同方差，遇到结构性断裂照样会失效。

所以 BVAR 的定位很明确：它不是让 VAR 变得「正确」，而是让一个本来就无法可靠估计的模型，在数据稀缺时给出**方差可控、符号可信**的答案。当你的观测数和数据维度处在同一量级时，与其假装OLS 的结果精确，不如坦白地把先验写进模型——这正是贝叶斯方法在量化研究里最实用的价值。
