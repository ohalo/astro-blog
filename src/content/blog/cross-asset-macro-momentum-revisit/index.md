一年多前我们展示过跨资产宏观动量的 sunny case：股、债、商品、外汇四条腿各自打 12-1 月时序动量、各自做腿级波动目标化，再等风险聚合成一个组合——不同资产的趋势彼此错开，某条腿被震荡打脸时另几条腿还在赚趋势的钱，Sharpe 2.41、最大回撤 -9.6%。那篇文章留了两个没回答的问题：**如果趋势不是无处不在呢？如果成本不是 0 呢？** 本文用 20 年、7500 个交易日、8 个 regime 的合成面板，把这两个问题一次问到底。结论先放这：**在这个世界里，宏观动量是保险不是引擎——Sharpe 与 buy&hold 打平，但回撤减半、危机区间全部少亏；而它成立的前提「四条腿都有趋势」根本不成立，等风险聚合把唯一的真边缘稀释掉了。**

## 一、合成市场：8 个 regime，含危机 V 型和震荡衰减期

7500 个日频观测、四条资产（股票 σ=1.0%/日、债券 0.35%、商品 1.1%、外汇 0.6%），按时间切成 8 个 regime，每个 regime 有各自的漂移向量、波动倍数和相关性结构：2003-2007 大缓和牛市（四资产齐涨，股票漂移 0.085%/日）、2008 次贷危机、2009-2012 复苏、2013-2015 震荡衰减（漂移归零，专治趋势策略）、2016-2019 平稳趋势、2020 新冠 V 型、2021-2022 通胀与趋势反转（股债跌、商品外汇涨）、2023-2026 AI 行情。危机 regime（2008、2020）不只是跌——股商相关性拉到 0.86、股债转为 -0.55，波动放大 2.4-3.0 倍；新冠 regime 还是「40 天崩盘 + 40 天 V 型 + 100 天复苏」的三段式。非危机 regime 注入 0.20 的日收益自相关（趋势持续性），危机 regime 不加。这个面板的残酷之处在于：8 个 regime 意味着 7 次切换点，而 12-1 信号的消化期是 229 天——7500 天里超过五分之一的时间，信号盯着的是上一个世界。

## 二、构造：12-1 TSMOM + 腿级波动目标 + 等风险聚合

信号用经典时序动量（TSMOM）构造：每腿的 12-1 月动量（250 日回看、跳过最近 21 日）除以自己的 60 日年化波动，再除以窗口尺度因子（两种信号速度比较时归一化到同尺度）；仓位 = clip(0.2×信号, ±0.75)。三条纪律：**信号在 t 日收盘后用 t+1 日收益结算（无前视）；成本按单边 5bps 对换手收取；等风险聚合（每腿半个风险单位）。** 这就是上一篇文章的同一个策略，只是换了个更严苛的世界。

|---|---|---|---|---|

## 五、信号速度：√n 的信噪比，n 的陈旧，1/n 的成本

提速到 3-1 月（63 日回看）听起来顺理成章——适应更快。实测 turnover 从年化 13.2 涨到 29.4（2.2 倍），但毛 Sharpe 反而从 +0.13 掉到 -0.13。三种力量的权衡解释了这一切：**信噪比 ∝ √n**（漂移在窗口里累积，噪声只按 √n 增长——慢信号的信噪比是快信号的 2.3 倍）、**切换点陈旧期 ∝ n**（快信号的适应优势）、**成本 ∝ 换手**（快信号的代价）。子区间上看得很清楚：快信号只在 2021-2022 翻了身（-0.24 vs -1.27），在牛市、复苏、震荡、新冠四个区间全输——2020 新冠被打到 -1.68，V 型把快信号来回抽耳光。把这个权衡写成一句话：**慢信号用 2.3 倍的信噪比和一半的换手，换 229 天的切换盲区；快信号用 63 天的切换盲区，换更低的信噪比和双倍的成本。** 在 regime 长、趋势缓的世界里（本次的 2003-2007、2016-2019），前者完胜；在 regime 短、反转急的世界里（2021-2022），后者才有翻身之日。**在这个世界里，信噪比的力量压过了适应性的力量；信号速度是用成本换适应性，而净额上慢信号赢了。**

## 六、最重的修正：聚合的隐含假设不成立

上一篇文章的 2.41 有个从未言明的假设：四条腿都有可用的趋势边缘。本次检验把单腿拉出来单独跑——股票 Sharpe 0.256（最大回撤仅 -21.2%）、商品 0.053、债券 -0.221、外汇 -0.324。**只有股票腿有真边缘**：债券和外汇的 regime 漂移相对自身波动太小（信噪比不足 0.35），它们的「趋势」大半是噪声，等风险聚合把股票腿的边缘和两条噪声腿拌在一起，合成 Sharpe 只剩 0.035——**聚合把 0.256 稀释成了 0.035**。名义上的四腿多元化，实际是「一条真腿 + 三条噪声腿」。这里要替聚合说句公道话：把 0.256 稀释成 0.035 的同时，聚合也把单腿 -21.2% 的回撤分散成了组合层面的结构（虽然组合回撤 -43.3% 仍高于股票单腿，但年化波动从各腿的 2-5% 汇总成了组合的 6.9%，且四条腿不会同时进入陈旧期）——聚合交易的是「浓度的稀释」换「错峰的平滑」，在真边缘只有一条腿时这笔交易是亏的，在多数腿都有边缘时（上一篇文章的世界）才是赚的。危机相关性抱团让情况更糟：平稳期四腿平均 |相关| 0.16，危机期 0.56（股商 0.86）——**危及时刻「四条腿」实际上是一条半，多元化的名义远远大于实际。**

## 七、两个变体都救不了场

趋势强度过滤（|信号|<0.75 的腿清零）把 Sharpe 做到 0.018，回撤只多收 3pp——过滤掉的是噪声也是信号。1 月反转叠加（信号减半个 1 月动量）直接做到 -0.447：在趋势持续的世界里，反转叠加是毒药，它系统性地和趋势信号对着干。**当一个策略的核心假设（趋势存在）只部分成立时，缝缝补补的变体救不了它。**

## 八、诚实结论与三条对策

- **宏观动量在这个世界里是保险不是引擎**：Sharpe 打平、回撤减 18pp、危机区间全部少亏、牛市区间全部跑输。要 beta 收益的人不该买它；要活过危机的人应该懂它。
- **成本是生死线**：毛 Sharpe 0.13，5bps 后 0.04，20bps 转负（-0.25）。任何成本超过 20bps 的执行渠道，这个策略不存在。
- **信号速度不是免费午餐**：√n 信噪比、n 陈旧期、1/n 成本的三角权衡里，本次慢信号赢；但切换更频繁的世界里结论可能反转——这是世界参数，不是普适定律。
- **对策一：按边缘浓度加配，不要等风险。** 只给有信噪比的腿（本例只有股票）实质性权重，噪声腿缩到最低或剔出。
- **对策二：把危机相关性抱团写进风险预算。** 用条件相关（危机期 0.56）而不是全样本相关（0.16）算组合风险，否则危机里的真实暴露会被低估三倍以上。
- **对策三：成本意识下的信号减速。** 在成本可承受范围内选最慢的可执行信号——慢不只是稳健性，它本身就在积累信噪比。

## 九、核心代码：信号、回测、成本

```python
import numpy as np

def make_signal(R, cum, sig, look=250, skip=21):
    """12-1 月 TSMOM 信号：动量 /(年化波动 × 窗口尺度)，无漂移时 sd=1"""
    n_days = look - skip
    norm = np.sqrt(n_days * 1.5 / 252.0)      # AR(0.2) 下窗口标准差（年化单位）
    mom = np.zeros_like(R)
    for t in range(look, len(R)):
        mom[t] = cum[t - skip] - cum[t - look]
    return np.where(sig > 1e-9, mom / (np.where(sig > 1e-9, sig, 1.0) * norm), 0.0)

def backtest(R, sig_full, cost_bps=5.0, k=0.2, cap=0.75):
    """无前视回测：t 日信号赚 t+1 日收益，成本按换手单边收取"""
    T = len(R)
    pos = np.clip(sig_full * k, -cap, cap)     # 腿仓位
    pret = np.zeros(T)
    pret[1:] = (pos[:-1] * R[1:]).sum(axis=1)  # 昨日仓位 × 今日收益
    turn = np.abs(np.diff(pos, axis=0)).sum(axis=1)
    pret[1:] -= turn * cost_bps / 1e4          # 换手成本
    return pret, pos
```
