## 一、结论先行

一个因子在牛市有效、熊市失效，甚至反向——这类"状态依赖"在量化研究里随处可见。常见做法是拍一个波动率阈值把样本切成两半分别回归，但阈值本身是数据决定的，拍脑袋切会产生三重问题：切点选错、显著性被夸大、置信区间无从谈起。

Hansen（1999）门槛回归把阈值也当参数来估，并用 bootstrap 解决"阈值在原假设下不可识别"的难题。本文用一组真值完全已知的合成月度数据把方法跑通：

1. 真实阈值是 20%，模型估出 **19.957%**，95% 置信区间 **[19.263, 20.531]** 稳稳覆盖真值。
2. 线性回归把两段斜率钝化成 **0.265**；门槛模型恢复出低波动段 **0.451**、高波动段 **-0.226**，与真值 0.45 / -0.20 基本一致。
3. 似然比统计量 **32.54**，400 次 wild bootstrap 的 5% 临界值 **11.91**，p 值 **0.0025**；换成无关噪声当门槛变量，p 值 **0.681**，正确地什么也没发现。
4. 样本外年化 Sharpe：买入持有 **0.171**、线性动量 **0.428**、阈值拍在 18 的分割 **0.795**、门槛模型 **1.056**、知道真值的上界 **1.211**。

## 二、模型：让回归系数在阈值两侧跳变

单阈值门槛模型写起来很朴素：

`y_t = β₀ + β₁ x_t + δ x_t · I(q_t > γ) + ε_t`

其中 `x_t` 是因子信号，`y_t` 是下一期收益，`q_t` 是门槛变量（本文用年化波动率），`γ` 是待估阈值。低波动区斜率是 `β₁`，高波动区是 `β₁ + δ`。给定 `γ`，这就是一个普通最小二乘；困难在于 `γ` 未知，而且它在"不存在门槛"的原假设下**没有定义**——这会导致标准的卡方分布失效。

估计流程因此分成三步：先对每个候选 `γ` 算残差平方和（SSR），取 SSR 最小的那个作为 `γ̂`；再用 wild bootstrap 生成原假设下的伪样本，每次重新搜索阈值、构造似然比统计量；最后用伪统计量的经验分位数做检验和置信区间。wild bootstrap（残差乘以随机正负号）比普通残差重抽样更稳，因为它不要求误差同方差。

本文样本：480 个月训练、240 个月独立测试。`q_t` 由均值 18%、自回归系数 0.7 的 AR(1) 过程生成，`x_t` 为标准正态动量信号，误差标准差 1.2%。真值设定为：波动率不超过 20% 时动量斜率 0.45，超过时反而变成 -0.20。候选阈值在 `q` 的 10%~90% 分位数之间取 200 个网格点，两端各修剪 10%，避免某一区制只有几个观测时把 SSR 压到接近零。

## 三、阈值估得准，检验也不能少

网格搜索的 SSR 曲线在真值附近有明显谷底：全样本线性模型 SSR 是 **766.13**，门槛模型降到 **717.49**。但 SSR 下降多少才算显著？由于我们是在 200 个候选里挑最优，下降本来就会有运气成分。

![图2：阈值网格上的 SSR 曲线与置信区间](/images/hansen-threshold-regression/fig2_ssr_profile.png)

统计量为 `LR = n·(SSR₀ / SSR₁ - 1)`，观测值 **32.54**。在"没有门槛"的原假设下，用拟合的线性模型加符号翻转残差生成 400 个伪样本，每个都重新跑一遍完整的 200 点搜索，得到 LR 的 5% 临界值 **11.91**——观测值远在其上，p 值 0.0025（即 400 次里没有一次伪统计量超过观测值，按 1/(B+1) 计）。

置信区间用同样的 bootstrap 分布做反演：把"距离峰值的 LR 下降量"超过临界值的网格点排除，剩下 **[19.263, 20.531]**，宽度约 1.27 个百分点。这个区间告诉你阈值估计本身也有不确定性，别把 19.96 当成刻在石头上的数。

这里有个容易被跳过的细节：bootstrap 伪样本必须复用**同一个网格**，而且每个伪样本都要重新完整搜索一次阈值。如果只固定在你原先估出的 `γ̂` 上算伪统计量，等于把搜索过程的好处偷偷留给了真实样本而没有留给原假设，临界值会偏小、p 值虚低。这也是很多人自己实现 Hansen 检验时最容易犯的错——看起来只差一行循环，结论却可能从"不显著"变成"高度显著"。

## 四、两段斜率，以及"拍脑袋切点"的代价

在估计阈值划分的两个区制里分别回归，低波动组 355 个观测，斜率 **0.4513**；高波动组 125 个观测，斜率 **-0.2257**。用门槛模型自身的系数读也是一回事：截距 0.1031、动量斜率 0.4512、交互项 -0.6764，高波动区斜率就是 0.4512 - 0.6764 = **-0.2252**，与分组回归吻合。

![图3：阈值两侧的回归拟合，斜率符号相反](/images/hansen-threshold-regression/fig3_regime_fits.png)

对照组更能说明问题：如果凭经验把阈值拍在 18，交互模型给出低波动段 0.4152、高波动段 **+0.1154**——真值明明是负的，却估成正的，SSR 也有 754.17，明显差于自动搜索的 717.49。原因不难理解：18 到 20 之间的观测其实属于低波动区，把它们错误归入高波动组，正的动量效应把负效应稀释掉了。**切点不是细节，它直接决定你看到的因子符号。**

我还做了一个安慰剂检验：用一串独立随机噪声当门槛变量重跑全部流程。最优"阈值"落在 14.39，LR 只有 **3.27**，p 值 **0.681**——方法没有凭空造出门槛。这个对照值得写进每一篇门槛回归报告里，因为它直接回答"你的检验会不会随便什么变量都显著"。

## 五、样本外：门槛值多少钱

在 240 个月的独立测试样本上，用训练期估出的系数构造仓位（仓位正比于该区制的预测斜率乘以信号），月度损益折算成年化 Sharpe：

- 买入持有：**0.171**；
- 全样本线性斜率交易：**0.428**；
- 固定 18 切点：**0.795**；
- 门槛模型：**1.056**；
- 事先知道真阈值的上界：**1.211**。

![图4：样本外五种策略的累计损益曲线](/images/hansen-threshold-regression/fig4_oos_equity.png)

门槛模型拿走了"可发现收益"的大部分，固定切点虽然方向对了但被错误分组拖累。必须诚实说明：这是只有一个真实断点、且误差独立同分布的合成世界，所以门槛模型的优势近乎"开卷考试"。真实市场里阈值可能随时间漂移、可能有多个断点、候选门槛变量往往有几十个，届时 bootstrap 显著性还要叠加重重检验校正。这里的 Sharpe 不应被当作实盘预期。

## 六、完整可运行代码

```python
import numpy as np
rng = np.random.default_rng(20261120)

def simulate(n):
    q = np.empty(n); q[0] = 18.
    for t in range(1, n):
        q[t] = 18 + .7*(q[t-1]-18) + rng.normal(0, 2.8)
    x = rng.normal(0, 1, n)
    y = .08 + .45*x*(q<=20) - .20*x*(q>20) + rng.normal(0, 1.2, n)
    return x, q, y

def ols(X, y):
    b, *_ = np.linalg.lstsq(X, y, rcond=None)
    return b, np.sum((y - X@b)**2)

def fit(x, q, y, grid):
    ssr = []
    for g in grid:
        X = np.column_stack([np.ones(len(x)), x, x*(q > g)])
        ssr.append(ols(X, y)[1])
    return grid[int(np.argmin(ssr))], np.array(ssr)

x, q, y = simulate(480)
X0 = np.column_stack([np.ones(len(x)), x])
b0, ssr0 = ols(X0, y)
grid = np.quantile(q, np.linspace(.10, .90, 200))
ghat, ssr = fit(x, q, y, grid)
ssr1 = ssr.min()
LR = len(y)*(ssr0/ssr1 - 1)

resid = y - X0@b0
LRb = []
for _ in range(400):                       # wild bootstrap under H0
    ys = X0@b0 + resid*rng.choice([-1., 1.], len(y))
    _, s0 = ols(X0, ys)
    _, sp = fit(x, q, ys, grid)
    LRb.append(len(y)*(s0/sp.min() - 1))
print(f'gamma={ghat:.3f}  LR={LR:.2f}  crit95={np.quantile(np.array(LRb), .95):.2f}'
      f'  p={(1+np.sum(np.array(LRb)>=LR))/401:.4f}')
```

## 七、几个真实的坑

第一，**不要在原假设下用普通卡方分布**。阈值未识别会让 LR 的分布偏离标准卡方，必须 bootstrap。第二，**两端要修剪**，否则极端阈值把一两个观测单独切成一组，SSR 人为接近零。第三，**门槛变量要事先想清楚经济含义**：本文用波动率有"动量崩溃"的故事支撑；如果把几百个宏观变量挨个试一遍，总有一个能给出显著结果。第四，**斜率跳变是简化**：真实状态切换往往是渐变的，平滑过渡模型（STR）可能更贴合数据，门槛模型的价值在于给出可解释的断点与检验框架。第五，**区制持续性会压缩有效样本**：AR(1) 系数越高，高低波动的连续段落越少，独立信息量远小于名义样本量。第六，**两个区制的样本量要平衡的看待**：本文低波动组 355 个、高波动组 125 个，斜率标准误相差近一倍，报告时应该同时给出分组样本量，否则读者无法判断高波动区那个负号有多稳。第七，**阈值附近要留缓冲带**：估值落在阈值上下 0.2 个百分点的观测，实际状态归属本身就模糊，实盘里可以用软权重过渡代替硬切换。

## 八、小结

门槛回归做的事情并不神秘：把"什么时候这个因子有效"变成一个可估计、可检验的参数。本文实验里，它把阈值估到 19.96、把两段相反斜率还原出来、把样本外 Sharpe 从 0.428 提到 1.056，同时用安慰剂检验证明自己不会乱报显著。真正需要带走的不是某个数字，而是那个方法论态度——**先让数据告诉你切在哪里，再用 bootstrap 问这个切点是不是真的**。只有当阈值经得起检验、两段系数符号站得住、样本外还能兑现时，状态依赖才从故事变成可用的交易规则。
