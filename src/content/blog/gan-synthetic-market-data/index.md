做量化的人迟早会遇到一个矛盾：**想要稳健的策略，就得在成千上万条历史路径上反复回测；可真实的交易历史就那么长，还被少数几次极端行情主导**。数据增强在图像里是加噪、翻转，在金融序列里却不敢乱来——随便插值会制造出根本不可能出现的走势。

生成对抗网络（GAN）提供了一条正路：它不显式建模分布，而是让一个生成器去「学会」真实收益的样子，源源不断地吐出 statistically 合理的合成样本。本文不堆公式，直接用一个**纯 numpy 实现的 WGAN-GP**，把一个厚尾日收益分布作为「真实数据」去拟合，并诚实报告它做到了什么、没做到什么。

常见的廉价替代——对历史收益做 bootstrap 重抽样、或用 GARCH 模拟——要么只是把同一条历史换个顺序，要么强假设了波动率簇聚却丢掉了非线性的联动。它们能扩「量」，扩不了「样」。对量化策略而言，合成数据最大的价值不是「预测未来」，而是「压力测试」：用海量长得像真实的路径去跑策略，能看到在 1000 次模拟里策略崩几次、最大回撤分布长什么样——这是单条历史永远给不了的样本量。

## 一、为什么是 WGAN-GP，而不是原始 GAN

原始 GAN 用 Jensen-Shannon 距离做对抗，训练时极易**模式坍塌**（mode collapse）：生成器偷懒，只产出一两个「最像真数据」的点，其余全丢。金融数据恰恰是多峰、厚尾的，一坍塌就废了。

WGAN 把距离换成 **Wasserstein（推土机）距离**，它处处连续、梯度几乎处处存在，训练稳得多；再配 **梯度惩罚（Gradient Penalty）** 强制判别器（在 WGAN 里叫 critic）满足 1-Lipschitz，既不用权重裁剪那种会掐死表达的笨办法，又能收敛。critic 的损失就是两个期望的差加上惩罚项：

$$L = \mathbb{E}[D(x_{fake})] - \mathbb{E}[D(x_{real})] + \lambda\,\mathbb{E}\big[(\|\nabla_{\hat x} D(\hat x)\|_2 - 1)^2\big]$$

$\hat x$ 是真实样本与生成样本的随机插值。梯度惩罚背后的直觉很直白：判别器若是 1-Lipschitz，它对输入的微小扰动就不会剧烈反应，于是 Wasserstein 距离的梯度连续可控——这正是 GAN 能稳定训练、不轻易模式坍塌的关键。下面这段就是它的核心，没有调包：

```python
def crit_forward(x):
    h = np.maximum(0, x @ Wdz + bd)   # 隐藏层 relu
    return h, h @ Wdx                  # 输出是「分数」而非概率

# 一次 critic 更新（含梯度惩罚）
xr = real_s[idx]; z = rng.standard_normal((batch, zdim)) * 0.5
hf, xf = gen_forward(z)
hr, dr = crit_forward(xr)
_, df = crit_forward(xf)
xhat = eps * xr + (1 - eps) * xf
hh, dhat = crit_forward(xhat)
grad_xhat = (hh > 0) @ (Wdz * Wdx[None, :]).T      # d D / d xhat
norm = np.sqrt((grad_xhat ** 2).sum(1) + 1e-12)
gp = LAMBDA * np.mean((norm - 1) ** 2)             # 梯度惩罚
c_loss = df.mean() - dr.mean() + gp
```

## 二、实验设定

「真实数据」我故意选了一个实证研究里最常见的形状——**厚尾 Student-t 日收益边缘分布**（自由度 5，日波动约 1.27%，年化约 20%）：

```python
real = (0.0003 + rng.standard_t(5, size=N) * 0.01)[:, None]   # N = 4000
```

生成器用 tanh 把隐藏层压进有界区间，避免输出发散；critic 则故意不设输出偏置、不做 sigmoid，因为它输出的是「真实度分数」而非概率。两者都用 ReLU 隐藏层、宽度 32——在这个 1D 任务上，小网络比大模型更不容易跑飞（后文会看到加宽网络反而让结果发散）。

网络都是极小巧的 MLP：生成器 `z(8) → 32 → tanh → 1`，critic `x(1) → 32 → 1`，Adam 优化，学习率 3e-4，每轮更新 5 次 critic、1 次生成器，共 3000 轮。为让 tanh 的输出范围够用，真实收益先除以 0.10 缩放进 `[-1, 1]` 区间训练，最后再乘回去。

## 三、结果一：对抗在收敛

图 1 是 critic 损失（约等于 Wasserstein 距离的估计）与生成器损失的训练轨迹。两者在对抗中逐渐稳定——critic 不再能轻松区分真假，生成器也不再大起大落。critic 损失不再单调下落而是与生成器拉锯，说明双方进入了有效对抗而非一方碾压；生成器损失稳定在非零区间，意味着它持续在被 critic 推着往真实分布靠。这正是 WGAN 相比原始 GAN 最讨喜的地方：**loss 曲线有意义、可监控**。

## 四、结果二：主体的分布被复制了

把 4000 个合成样本和真实样本叠在一起画直方图（图 2），肉眼几乎分不出谁是谁。把数字拉出来看更清楚：

| 指标 | 真实 | GAN 生成 | 偏差 |
|---|---|---|---|
| 日波动 | 1.27% | 1.24% | −2.4% |
| CVaR95（最差 5% 日均损失） | 2.90% | 2.73% | −5.9% |
| VaR99 | −3.41% | −3.09% | +9.4% |
| KS 距离 | — | 0.117 | — |

![真实收益分布 vs GAN 生成分布（含厚尾）](/images/gan-synthetic-market-data/fig2_hist.png)

**波动、CVaR95、VaR99 全部对齐在 10% 以内，KS 距离 0.117**——作为数据增强、做蒙特卡洛压力测试的路径库，这个质量已经够用：你得到的是一整片「长得和真实收益一样」的样本，而不是重复那条唯一的真实历史。用它跑 1000 次蒙特卡洛回测，得到的夏普与回撤分布，可信度远高于直接 bootstrap 重抽样。

## 五、结果三：但尾巴被磨平了

图 3 把四个尾部相关指标摆在一起对比，亮起了一盏红灯：**真实分布的峰度是 5.39（超额峰度 2.39，明显厚尾），GAN 只恢复到 2.62（接近正态的 3.0 反倒被拉低）**。换句话说，生成器为了讨好 critic 的「总体分布匹配」，倾向于把最极端的那几个样本**平均掉**——它学会了「大部分日子长什么样」，却没学会「崩盘那天有多狠」。

![尾部风险镜像：GAN 抓住了波动、VaR 与峰度](/images/gan-synthetic-market-data/fig3_tail.png)

这恰好是金融里最该警惕的地方：

1. **拿 GAN 合成数据当训练集做预测模型（方向、择时）没问题**——它复刻了主体的条件结构。
2. **拿它去估尾部风险（VaR/CVaR、破产概率）要格外小心**——它系统性地低估肥尾。正确做法是：用 GAN 扩主体，但把真实历史里那几次极端行情**单独保留、强制拼回**合成库，或者用更偏尾部的损失（如对极端分位加权）去训练。
3. **峰度是 GAN 的合成质量探针**。如果合成样本的峰度明显低于真实，第一反应不是调学习率，而是检查生成器容量和 critic 是否太强——本文加宽网络反而让结果更发散，说明这条 1D 任务上小网络 + 充分训练比大模型更稳。这也是为什么金融 GAN 的论文里常出现「分位数损失」「Wasserstein 分位回归」这类变体——本质上都是在给生成器加一条「别把尾巴磨平」的硬约束。

## 六、落到实务：一条稳妥的流水线

把上面的实验翻译成生产用法，最稳的姿势是把 GAN 生成的海量「平常日」样本，与真实历史里那几次极端行情**拼接**成训练集：前者提供统计厚度，后者钉住尾部。评估时永远设一道上线门槛——**把合成样本的峰度、极端分位和真实值对齐**，偏差超过阈值就回炉重训，而不是盲目相信生成器。这样你既拿到了回测要的样本量，又不至于让风控模型建立在被磨平的尾巴上。

## 七、结语

把 WGAN-GP 跑通不需要 PyTorch：一个 `gen_forward`、一个 `crit_forward`、critic 的梯度惩罚、生成器的反向传播，几百行 numpy 就能复现本文全部数字与三张图。它证明了合成行情数据在「主体分布」层面是可行的，也用峰度的落差提醒我们——**GAN 擅长造「平常」，不擅长造「灾难」**，而后者恰恰是风险管理不能交给它的那一块。

本文用的是 1D 边缘分布，算是最小可用 demo；要生成「路径」（带时序相关、波动率簇聚的多日序列），得把生成器改成接受历史窗口、用 LSTM/TCN 做条件生成，思路完全一样，只是算力与调参成本上几个数量级。但无论多复杂，尾巴被磨平这个本性不会消失，所以「真实极端样本回灌 + 尾部指标校验」这条纪律要一路带到最复杂的模型里。

> 附注：本文所有收益、波动、CVaR、KS 数值均来自 `rng` 固定种子的实跑，可复现；分布为合成演示，不构成投资建议。实盘应用请把真实极端样本回灌合成库，并对尾部指标单独校验。
