## 一、结论先行

波动率不是观测值，而是从收益里反推出来的隐变量。GARCH 给一条点估计路径，滚动已实现波动给一条平滑线，但它们都不会告诉你"这段波动率估计有多不确定"。贝叶斯框架把整条 log 方差路径当作随机量，输出的是分布而不是点。

本文用经典的随机波动率（SV）模型跑一个真值已知的实验：

- 模型：`log(y_t²) = h_t + log(ε_t²)`，其中隐状态 `h_t = mu + phi·(h_{t-1} − mu) + σ·η_t`，ε、η 独立标准正态。真值设 mu=log(1e-4)=−9.2103、phi=0.97、σ=0.15，生成 1500 天。
- log(ε²) 没有解析密度，用 **7 分量正态混合**近似（EM 在 40 万条 log(χ²₁) 样本上拟合，混合均值 −1.2747 对上理论 −1.2704）。
- Gibbs 采样 7000 次，烧入 2000，每 5 次留一个，共 **1000 个后验样本**；状态用**前向滤波后向采样（FFBS）**整段抽取。

核心结果：

1. 三个参数全部被后验覆盖：mu 均值 **−9.2444**（95% CI [−9.5848, −8.8928]，偏差 −0.37%）、phi **0.9716**（[0.9546, 0.9860]，+0.16%）、σ **0.1569**（[0.1165, 0.2092]，+4.57%）。真值都落在区间内。
2. 平滑后的 log 方差路径与真值相关 **0.8485**、RMSE **0.3438**；95% 可信带对真值路径的实测覆盖率 **95.07%**——名义 95%，实测几乎分毫不差。
3. 对照组 21 日滚动已实现波动与真值相关只有 **0.6919**、RMSE **0.5335**。贝叶斯路径估计在相关和 RMSE 上都明显胜出。
4. 99% VaR 突破：后验波动率给出 **18 次（1.20%）**，真值波动率 22 次（1.47%），滚动 29 次（1.93%）；名义 1% 下后验最接近。
5. 两个真实调试坑值得单独讲：**FFBS 后向递推写错**时平滑状态直接跑到 +19、与真值相关仅 0.23（修后 0.87）；**公开混合表的最左分量只覆盖到约 −11.3**，扛不住本种子里 log(χ²₁) 噪声最左到 −21.45 的极端值，导致 phi、σ 被拉到 0.886 和 0.624（真值 0.97/0.15），换成 EM 自拟合的含胖尾分量混合才归位。

## 二、为什么要把波动率当隐变量

"波动率"这个词其实指三样不同的东西：真实的数据生成过程里那个条件标准差、你从过去数据算出来的估计、以及未来某天的预测值。传统方法把三者混在一起：用过去 20 天收益的标准差当今天的波动率，再拿它去算 VaR。这在波动平稳时够用，但波动聚集（volatility clustering）一来就露馅——危机期间滚动窗口反应迟钝，事后才追上去。

SV 模型承认波动率看不见，把它写成一条 AR(1) 隐路径：

```
h_t = mu + phi*(h_{t-1} - mu) + sigma*eta_t,   eta_t ~ N(0,1)
y_t = exp(h_t/2) * eps_t,                      eps_t ~ N(0,1)
```

phi 衡量波动持续性（0.97 意味着半衰期约 22 天），sigma 是波动本身的波动。收益的厚尾不需要额外假设——h_t 随机游走本身就会在边际上造出厚尾。

关键困难在观测方程：两边取平方再取对数得 `log(y_t²) = h_t + log(ε_t²)`，噪声项 `log(ε_t²) = log(χ²₁)` 既不对称也没有解析密度。这就是混合正态登场的理由。

## 三、7 分量混合：把 log(χ²₁) 拆成正态之和

Kim、Shephard、Chib 的经典做法是：找一组权重 qⱼ、均值 mⱼ、方差 vⱼ，使得 `Σ qⱼ·N(mⱼ, vⱼ)` 逼近 log(χ²₁) 的分布。一旦有了这个表示，观测方程就变成条件线性的——给定分量标签 s_t：

```
log(y_t²) = h_t + m_{s_t} + N(0, v_{s_t})
```

状态是高斯 AR(1)，观测噪声是高斯，整套 FFBS 就能直接套用。

本文没有照抄文献里的参数表，而是用 EM 在 40 万条 log(χ²₁) 样本上自己拟合 7 分量混合。拟合结果的混合均值 **−1.2747**，和理论值 ψ(1/2)+log2 = **−1.2704** 只差 0.0043；混合方差 4.9599（理论 π²/2≈4.9348）。这步自检很重要——后面会看到，混合表本身选错会把整个采样带偏。

## 四、Gibbs 三步与 FFBS

每个 Gibbs 迭代做三件事：

1. **抽分量标签** s_t：给定当前 h_t，后验是分类分布，概率正比于 `qⱼ·N(log(y_t²) | h_t + mⱼ, vⱼ)`。
2. **抽整条状态路径** h_{1:T}：给定 s 和参数，用 FFBS 一次性抽整段，而不是逐点 Metropolis——后者在 phi 接近 1 时混合极慢。
3. **抽参数** mu、phi、σ：把状态方程写成 `h_t = c + phi·h_{t−1} + 误差`（c=mu(1−phi)），对 (c, phi) 用共轭正态、对 σ² 用逆伽马。

FFBS 分两步。前向跑卡尔曼滤波，存下每时刻的滤波均值 mf_t 与方差 Pf_t；后向从 t=T 往回抽，用到联合正态的条件分布：

```
Ppred = phi²*Pf_t + sig2
cov   = phi*Pf_t
Var(h_t|h_{t+1}) = Pf_t - cov²/Ppred
Mean(h_t|h_{t+1}) = mf_t + cov/Ppred * (h_{t+1} - mu - phi*(mf_t - mu))
```

这个公式看着朴素，却是整篇最容易写错的地方（见第七节）。

## 五、参数与路径结果

1500 天数据，7000 次迭代、烧入 2000、稀释 5，留 1000 个样本：

|---|---|---|---|---|
| mu | −9.2103 | −9.2444 | [−9.5848, −8.8928] | −0.37% |
| phi | 0.9700 | 0.9716 | [0.9546, 0.9860] | +0.16% |
| σ | 0.1500 | 0.1569 | [0.1165, 0.2092] | +4.57% |

三个真值全部落在各自的 95% 区间里。sigma 的相对偏差最大（+4.57%）但绝对量只有 0.0069，且区间较宽 [0.116, 0.209]——这符合直觉：波动的波动本来就难估，1500 天数据给不出更紧的区间。

## 六、VaR 与链诊断

用后验均值波动率算 99% VaR（阈值 `exp(h_t/2)·z_0.01`），1500 天里突破 **18 次（1.20%）**；用真值波动率突破 22 次（1.47%）；滚动波动 29 次（1.93%）。名义 1% 下后验和真值都接近，滚动偏高——平滑滞后让它在高波动期低估阈值、低波动期又高估，突破次数被放大。

链的混合情况：phi 链 lag-1/5/10/20 的自相关分别是 **0.431 / 0.305 / 0.239 / 0.074**。lag-20 已经接近 0，说明 5 步稀释后样本基本独立，1000 个留样够用。图4 的联合后验散点也显示 phi 和 sigma 没有明显强相关，不存在参数间的"锯齿形"难采样结构。

## 七、两个真实调试坑（比结果更值得看）

**坑一：FFBS 后向递推写错，状态跑到 +19。** 初版后向步写成 `mean = V·(mf/Pf + phi·(h_{t+1}−mu)/sig2)`，看起来像Precision形式的标准条件均值，但对应的转移核不是 `h_{t+1}=mu+phi(h_t−mu)+η`。用真参数测试时，平滑状态最大值冲到 +32、均值 +19.9，与真值相关仅 0.23。改成正确的联合正态条件式（第四节那三行）后，同样测试相关立刻升到 **0.87**、RMSE 降到 0.33。**教训**：FFBS 后向公式不要凭记忆写，用一个已知真值的小样本先做单元验证——固定真参数跑一遍 FFBS，看能否还原状态。

**坑二：混合表扛不住极端左尾。** 换成文献里常见的 10 分量表后，最左分量均值 −9.95、标准差 0.39，最深只到约 −11.3；但本种子里 log(χ²₁) 噪声最左达到 **−21.45**（理论 0.1% 分位是 −13.36，1500 天出现极端值并不奇怪）。混合密度在这些点几乎为零，强迫状态去解释极端观测，结果 phi 被压到 **0.886**、σ 被抬到 **0.624**（真值 0.97/0.15），状态相关只有 0.38。改用 EM 在 log(χ²₁) 样本上自拟合的 7 分量（最左分量均值 −7.28、标准差 3.42，能覆盖到约 −21）后，三个参数才全部回到区间内。**教训**：混合近似要看尾部覆盖而不只是均值和方差；样本里最极端几个 log(y²) 必须落在混合分布的支撑范围内。

这两个坑都不是"方法不行"，而是实现细节写错。恰好说明贝叶斯 MCMC 的工程门槛：公式要推导、代码要单元验证、近似要查尾部。

## 八、完整代码骨架

```python
import numpy as np

# 1) EM 拟合 7 分量混合近似 log(chi^2_1)
def em_mixture(data, K=7, iters=300):
    q = np.ones(K)/K
    m = np.quantile(data, np.linspace(0.05, 0.95, K))
    v = np.full(K, 2.0)
    for _ in range(iters):
        logp = np.log(q)[None,:] - 0.5*np.log(2*np.pi*v)[None,:] \
               - 0.5*(data[:,None]-m[None,:])**2/v[None,:]
        w = np.exp(logp - logp.max(axis=1, keepdims=True))
        w /= w.sum(axis=1, keepdims=True)
        Nk = w.sum(axis=0)
        q = Nk/len(data)
        m = (w*data[:,None]).sum(axis=0)/Nk
        v = (w*(data[:,None]-m[None,:])**2).sum(axis=0)/Nk
    return q, m, v

Q, M, V = em_mixture(np.log(rng.standard_normal(400_000)**2))

# 2) FFBS: 给定标签与参数, 整段抽状态
def ffbs(ystar, s, mu, phi, sig2):
    n = len(ystar)
    ytil = ystar - M[s]
    a = np.empty(n); P = np.empty(n); mf = np.empty(n); Pf = np.empty(n)
    a[0], P[0] = mu, sig2/(1-phi**2)
    for t in range(n):
        F = P[t] + V[s[t]]; K = P[t]/F
        mf[t] = a[t] + K*(ytil[t]-a[t]); Pf[t] = P[t]*(1-K)
        if t < n-1:
            a[t+1] = mu + phi*(mf[t]-mu)
            P[t+1] = phi**2*Pf[t] + sig2
    hs = np.empty(n)
    hs[-1] = mf[-1] + np.sqrt(Pf[-1])*rng.standard_normal()
    for t in range(n-2, -1, -1):       # 后向: 正确的联合正态条件
        Ppred = phi**2*Pf[t] + sig2
        cov = phi*Pf[t]
        Vt = Pf[t] - cov**2/Ppred
        mn = mf[t] + cov/Ppred*(hs[t+1] - mu - phi*(mf[t]-mu))
        hs[t] = mn + np.sqrt(Vt)*rng.standard_normal()
    return hs

# 3) Gibbs 主循环: 抽标签 -> FFBS 抽状态 -> 共轭抽参数(mu, phi, sigma)
```

## 九、和其他波动率模型的关系

把 SV 放到模型谱系里看更清楚位置。GARCH(1,1) 把当前波动写成过去波动和过去冲击的确定性函数，参数少、滤波快，但条件方差没有独立的随机扰动；随机波动率多了一层 η_t，同样的波动聚集能靠状态自身的漂移生成，代价是似然不再有闭式解、必须做 MCMC 或粒子滤波。Heston 等连续时间随机波动率模型走的是另一条路——用特征函数求期权价格；本文的离散 SV 更适合直接对收益序列做推断和路径平滑。

选择标准其实很实际：如果你只要一条波动率点估计去做当日风控，EWMA 或 GARCH 足够；如果你要回答"这段高波动是真状态切换还是估计噪声"，或者要把波动率误差传递进 VaR、期权定价、组合风险预算，那后验分布就不可替代。贝叶斯方法在这里的价值不是"更准的点"，而是把不确定性显式地交到你手上。

## 十、边界与适用

这套方法适合需要**波动率不确定性**的场景：风险预算的可信区间、期权定价里把波动路径当随机输入的蒙特卡洛、以及检验"你的策略是不是只在点波动率假设下才赚钱"。它不适合高频数据（微观结构噪声会污染 log(y²)），也不适合收益里有大量零值的品种（log(0) 需要人为下限，会引入偏差）。

另一个现实约束是计算量：7000 次 Gibbs、每次 T=1500 的前向滤波是 Python 循环，本机跑约 26 秒。日子再长（比如 10 年日频 2500 天）就该考虑 Numba 或 JAX 加速。但和"给一条有误差棒的波动率路径"这个回报比，这点成本值。
