Black-Scholes 有个著名的"原罪"：它假设波动率是常数。可只要打开任意一个期权链，把隐含波动率对行权价画出来，你看到的从来不是一条水平线——而是微笑，是偏斜，是股票市场里那道著名的"崩盘恐惧"：虚值看跌的波动率系统性高于虚值看涨。

**Heston 模型**给出的解法优雅而克制：不让波动率拍脑袋地随时间变，而是给它写一个有金融含义的随机过程——它会自己波动、会向长期水平回复、还会和标的价格相关。更妙的是，这个模型有解析的特征函数，我们不必解偏微分方程、也不必依赖定价库，一次一维数值积分就能把整条波动曲面算出来。

本文用 `s=100, r=5%, v0=0.04, κ=2, θ=0.04, σ=0.5, ρ=−0.7` 这组参数，从零实现 Heston 定价，并做三重验证、复现微笑与期限结构。

## 一、五个参数，各自管什么

Heston 在风险中性测度下把标的与方差写成一对耦合的扩散：

$$dS_t=(r-q)S_t\,dt+\sqrt{v_t}S_t\,dW_t^1,\qquad dv_t=\kappa(\theta-v_t)\,dt+\sigma\sqrt{v_t}\,dW_t^2,\quad \mathrm{corr}(dW^1,dW^2)=\rho$$

五个参数每一个都有清晰的交易含义：

- **$v_0$**：今天的瞬时方差，决定近月期权贵不贵；
- **$\theta$**：长期方差水平，是整条波动曲线的"引力中心"（本例 $\sqrt{\theta}=20\%$）；
- **$\kappa$**：均值回复速度，$\kappa=2$ 意味着偏离以约半年为量级被拉回；
- **$\sigma$**：波动率的波动率（vol of vol），它决定微笑的凸性有多深；
- **$\rho$**：价格与方差的相关系数，**它单独决定偏斜的方向**——股票市场长期为负，因为跌得越狠、恐慌越强。

方差过程 $dv=\kappa(\theta-v)dt+\sigma\sqrt{v}dW$ 就是 CIR 过程：因为扩散项带 $\sqrt{v}$，只要 $v$ 趋近 0，随机扰动就自动熄火，所以方差天然不会变成负数。这是 Heston 比"直接让波动率服从正态分布"的局部波动率模型更讨人喜欢的地方。

## 二、特征函数：把价格问题变成积分问题

对对数价格 $X_T=\ln S_T$，Heston 的特征函数 $\phi(u)=E[e^{iuX_T}]$ 有闭式解：

$$\phi(u)=\exp\Big(iu(\ln S_0+(r-q)T)+A(u,T)+B(u,T)v_0\Big)$$

其中令 $\beta=\rho\sigma iu-\kappa$，$d=-\sqrt{\beta^2+\sigma^2(u^2+iu)}$（**分支必须取 $\mathrm{Re}(d)\le 0$**，否则 $e^{dT}$ 会指数爆炸），$g=(\beta-d)/(\beta+d)$：

$$B=\frac{d-\beta}{\sigma^2}\cdot\frac{1-e^{dT}}{1-ge^{dT}},\qquad A=\frac{\kappa\theta}{\sigma^2}\Big[(d-\beta)T-2\ln\frac{1-ge^{dT}}{1-g}\Big]$$

完整实现不到 20 行，且同时支持复数 $u$——后面换测度时会用到：

```python
import numpy as np

S0, r, q = 100.0, 0.05, 0.0
KAPPA, THETA, SIGMA, RHO, V0 = 2.0, 0.04, 0.5, -0.7, 0.04

def heston_cf(u, T, s=S0, v0=V0, kappa=KAPPA, theta=THETA,
              sigma=SIGMA, rho=RHO):
    u = np.asarray(u, dtype=complex)
    beta = rho * sigma * 1j * u - kappa
    d = -np.sqrt(beta**2 + sigma**2 * (u**2 + 1j*u))   # Re(d)<=0 分支
    g = (beta - d) / (beta + d)
    edT = np.exp(d * T)
    A = 1j*u*(np.log(s) + (r-q)*T)
    A += (kappa*theta/sigma**2)*((d-beta)*T - 2*np.log((1-g*edT)/(1-g)))
    B = (d-beta)/sigma**2 * (1-edT)/(1-g*edT)
    return np.exp(A + B*v0)
```

为什么特征函数能算出来？核心是 Heston 属于** affine 仿射模型**：对数价格条件特征函数对状态变量 $v_t$ 是指数仿射的，即 $\exp(A(\tau)+B(\tau)v_t)$。把这个形式代回 Feynman-Kac 方程，偏微分方程就塌缩成关于 $A$、$B$ 的常微分方程（Riccati 方程），后者有闭式解。这正是我们能用十几行代码替代 PDE 有限差分的根本原因——不是运气，是模型结构带来的红利。

有了特征函数，看跌看涨期权价格用 Gil-Pelaez 反演一步到位。风险中性测度下的概率 $\Pi_2=P(S_T>K)$ 直接由 $\phi$ 得到；而股票测度下的 $\Pi_1$ 只需一个漂亮的换测度技巧：$\phi_1(u)=\phi(u-i)/\phi(-i)$，其中分母 $\phi(-i)=E[S_T]/S_0=e^{(r-q)T}$。这个换测度不是数学戏法：把计价单位从无风险债券换成股票本身，$\Pi_1$ 就是"以股票为货币时行权的概率"，因此期权定价天然拆成"股票测度下的收益"减去"风险中性测度下的行权成本"两项。

```python
from scipy.integrate import quad

def heston_call(K, T, **p):
    lnK = np.log(K)
    phi2 = lambda u: heston_cf(u, T, **p)
    denom = phi2(-1j)                       # = exp((r-q)T)
    phi1 = lambda u: phi2(u - 1j) / denom

    def P(phi):
        # Re[e^{-iu lnK} phi(u)/(iu)] = Im[e^{-iu lnK} phi(u)]/u
        f = lambda u: (np.exp(-1j*u*lnK)*phi(u)).imag/u
        val, _ = quad(f, 1e-8, 300, limit=400, epsabs=1e-11)
        return 0.5 + val/np.pi

    return S0*np.exp(-q*T)*P(phi1) - K*np.exp(-r*T)*P(phi2)
```

注意我们巧妙避开了复数除法：$Z/(iu)$ 的实部正好等于 $Z$ 的虚部除以 $u$，数值上稳定得多。

## 三、三重验证：这个实现真的对吗

自己写的定价公式最容易"看起来对、其实错"。我用三种独立方法交叉验证：

**第一重——退化检验。** 把 $\sigma$ 压到 $10^{-4}$，方差几乎确定在 $\theta$，Heston 必须退回 Black-Scholes（波动率取 $\sqrt{\theta}$）：

| 行权价 | Heston (σ→0) | Black-Scholes | 误差 |
|---|---|---|---|
| 90 | 16.699631 | 16.699448 | +1.8e−4 |
| 100 | 10.450639 | 10.450584 | +5.6e−5 |
| 110 | 6.039960 | 6.040088 | −1.3e−4 |

三档都在 $2\times10^{-4}$ 以内，特征函数的分支和符号没有搞反。

**第二重——Monte Carlo。** 用全截断欧拉格式模拟 30 万条路径、252 步：ATM 看涨解析价 **10.1546**，模拟均值 **10.1863**，标准误 0.0201，$z=1.58$——落在两个标准差内，统计上无法拒绝。

**第三重——平稳分布。** CIR 方差的平稳分布是 Gamma，形状参数 $2\kappa\theta/\sigma^2=0.64$、尺度 $\sigma^2/(2\kappa)=0.0625$、均值 0.04；模拟 4000 条 4 年期路径的终端方差均值 0.0405，与理论 0.0400 吻合。

![Heston 方差路径与平稳分布](/images/heston-stochastic-volatility/heston-variance-paths.png)

顺带暴露一个常被忽略的细节：本例 $2\kappa\theta=0.16<\sigma^2=0.25$，**Feller 条件不满足**，方差确实可以触到 0。所以路径模拟必须用 `max(v,0)` 的全截断格式，否则 $\sqrt{v}$ 遇到负数会直接产生 NaN。

## 四、偏斜的方向，由一个 ρ 决定

把 Heston 价格反解成隐含波动率，就能看出参数如何塑造曲面。固定 $T=1$，只改 $\rho$：

| 行权价 K | 80 | 90 | 100 | 110 | 120 |
|---|---|---|---|---|---|
| ρ = −0.7 | 24.05% | 21.59% | 19.21% | 17.02% | 15.27% |
| ρ = +0.7 | 14.66% | 15.67% | 17.75% | 19.99% | 22.02% |

**ρ = −0.7 时，K=80 的隐含波动比 K=120 高 8.78 个点**——一条向右下方倾斜的偏斜，正是股票期权市场的常态：大跌时价格与波动率同向共振，虚值看跌因此昂贵。把 ρ 翻成 +0.7，曲线整个翻过来，变成虚值看涨更贵，这是商品市场常见的形态。而 ρ=0 时曲线近似对称的 U 形，只剩 $\sigma$ 撑起的微笑凸性。

![Heston 隐含波动率微笑与偏斜](/images/heston-stochastic-volatility/heston-vol-smile.png)

这就是 Heston 相对局部波动率模型最大的表达力：**偏斜的方向和微笑的凸性被两个参数干净地解耦**——$\rho$ 控偏斜，$\sigma$ 控凸性。校准时你可以先盯 25-delta 风险反转定 $\rho$，再用蝶式价差定 $\sigma$，思路非常清楚。

## 五、期限结构：均值回复留下的指纹

把行权价固定在 ATM，让期限从 1 个月拉长到 5 年，就能看到 $\kappa$ 的作用。

平静起点 $v_0=0.04=\theta$ 时曲线几乎平躺（19.77% → 20.28%）；但把今天的波动拉到压力状态 $v_0=0.09$（30%），短期 ATM 隐含波动飙到 **29.15%**，5 年期却只剩 **21.38%**——将近 8 个点的下行斜率。**因为市场知道高波动终将被 $\kappa$ 拉回长期水平**，远月不愿为恐慌买单。这种"短期贵、长期便宜"的期限结构，是均值回复在价格上留下的最直接证据；纯 BS 模型无论怎么调参数都造不出它。

## 六、从曲面到交易：这些形状怎么用

读懂了形状，下一步是把它变成交易语言。偏斜的陡峭程度（常用 25-delta 风险反转，即虚值看跌波动率减虚值看涨波动率）本质上衡量的就是 $\rho$ 与 $\sigma$ 的组合：股票市场偏斜长期为负，意味着"下跌保护"永远不便宜，卖保护收取的是实实在在的风险溢价，但尾部一旦兑现也是灾难性的。 微笑的凸性（蝶式价差）则由 $\sigma$ 主导：$\sigma$ 越大，市场认为未来波动率本身越不确定，虚值期权相对平值就越贵。

期限结构则告诉我们恐慌的"保质期"。当 $v_0$ 远高于 $\theta$ 时，近月隐含波动被短期恐慌顶起，远月却锚定长期水平，于是出现陡峭的向下倾斜——这时卖出近月波动、买入远月波动（日历价差）本质上是在赌"均值回复会如期发生"。反过来，若整条曲线被平行抬高且 $\rho$ 突然变负，市场大概率正在定价一场尚未发生的系统性风险。把 Heston 的五个参数每天重新校准一遍，你得到的不是五个数字，而是一张结构化的市场情绪地图。

对做 Beta 或套利的策略，这套语言还有一个实际用途：**用隐含波动曲面反推市场对未来的联合预期**。既然 $\rho$ 描述的是"跌与怕"的耦合，一个持续走低的 $\rho$ 就是恐慌弹性在增强的信号；把它作为风险开关叠加到动量或多因子组合上，往往比单看 VIX 绝对值更灵敏，因为它剥离了波动水平本身、只留下"方向不对称性"这一维信息。

## 七、落到量化实战

几点真金白银的经验：**第一，定价慢不是问题，校准才是。** 单个价格只需一次一维积分，但每次目标函数要算几十个期权，氢式优化器（如 `scipy.optimize.differential_evolution` 或 Levenberg-Marquardt）跑全曲面校准仍要几分钟；实盘常用 FFT 批量定价来加速。**第二，小心"小 Heston 陷阱"。** 用特征函数反演时，行权价处到底用 $u$ 还是 $u-i/2$，不同文献约定不同；一个可靠的自检就是本文的退化检验——$\sigma\to0$ 时必须精确回到 BS。**第三，参数会退化。** 若期权链只有近月，$\kappa$ 和 $\theta$ 几乎不可辨认，拟合出的"长期波动率"只是外推幻觉。

对量化研究员而言，Heston 的价值不止是定价公式，更是提供了一套思考波动的语言：今天的恐慌（$v_0$）、恐慌能持续多久（$\kappa$）、恐慌的长期基准（$\theta$）、恐慌自身的暴躁程度（$\sigma$）、以及跌与怕的耦合强度（$\rho$）。把这五个量分开看，波动率交易才从"猜方向"变成"管风险敞口"。
