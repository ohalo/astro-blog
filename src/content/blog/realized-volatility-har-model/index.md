打开任意一张波动率图，你都会看到同样的现象：平静的日子连着平静，暴涨暴跌扎堆出现。金融学管这叫**波动率聚集**；更麻烦的是，这种记忆衰减得非常慢——今天的高波动，往往一周后还有影子，一个月后仍未散尽。

直接拿 GARCH(1,1) 去拟合日收益当然可以，但它把日内 information 全扔了。既然今天我们已经有 5 分钟甚至 1 分钟 K 线，为什么不直接从日内数据里算出**已实现波动率**（Realized Volatility），再拿它做预测？Corsi 在 2009 年给出的 **HAR-RV** 就是这个思路下最优雅的答案：你不需分数阶差分、不需复杂的长记忆建模，只要一个普通最小二乘回归，把日、周、月三个时间尺度的平均波动塞进去，就能复现长记忆的大部分效果。

## 一、异质市场假说：三个尺度，一个回归

HAR 的出发点叫**异质市场假说**：市场里同时存在着不同交易频率的参与者——日内做市商关心昨天发生了什么，波段交易者看一周，机构配置盘看一个月。不同尺度的信息叠加起来，才形成了我们观察到的波动率长记忆。

写成模型就是：

$$\log RV_t = \beta_0+\beta_d\log RV_{t-1}+\beta_w\frac{1}{5}\sum_{i=1}^{5}\log RV_{t-i}+\beta_m\frac{1}{22}\sum_{i=1}^{22}\log RV_{t-i}+\beta_r\,L_{t-1}+\varepsilon_t$$

其中 $RV_t=\sqrt{\sum_{j=1}^{M}r_{t,j}^2}$ 是把一天 $M$ 根 5 分钟收益平方加总再开方得到的已实现波动率，$L_{t-1}$ 是昨日收益的标准化杠杆项（负收益对应正贡献，刻画"跌得更凶、波动更大"的不对称性）。

这个式子看起来平平无奇，但有一个深刻含义：**三个指数衰减核的和，可以极好地逼近一个缓慢衰减的双曲核**。换句话说，长记忆不必真的用长记忆模型——把一个"短记忆 + 中记忆 + 长记忆"的线性组合叠起来就够了。这正是 HAR 在工程上大获成功的原因：它的参数可以用 OLS 秒级估计，预测性能却常常逼分数积分模型。

## 二、造一份"真相已知"的数据

为了不让结论沦为"拟合了个寂寞"，我先人为设定真值：$\beta_d=0.35,\ \beta_w=0.40,\ \beta_m=0.20,\ \beta_r=-0.06$，噪声标准差 0.18，生成 2400 个交易日的对数已实现波动率，再据此模拟每日 48 根 5 分钟收益并回算 RV：

```python
import numpy as np
from scipy import stats

N, M = 2400, 48
B_D, B_W, B_M, B_R = 0.35, 0.40, 0.20, -0.06
C0, SIG_E = -0.22, 0.18          # 使长期平均日波动率约 1.2%
rng = np.random.default_rng(20261119)

logrv = np.full(N, np.log(0.012))
ret, rv, lev = np.zeros(N), np.zeros(N), np.zeros(N)
for t in range(30, N):
    d = logrv[t-1]
    w = logrv[t-5:t].mean()       # 过去 5 日均值
    m = logrv[t-22:t].mean()      # 过去 22 日均值
    l = min(lev[t-1], 0.0)
    logrv[t] = C0 + B_D*d + B_W*w + B_M*m + B_R*l + SIG_E*rng.standard_normal()
    ticks = (np.exp(logrv[t])/np.sqrt(M)) * rng.standard_normal(M)
    ret[t] = ticks.sum()
    rv[t] = np.sqrt(np.sum(ticks**2))          # 已实现波动率
    lev[t] = np.clip(ret[t]/max(rv[t], 1e-8), -4.0, 0.0)
```

为什么要用日内数据算 RV，而不是直接用收盘价到收盘价的收益平方？因为后者只用了每天一个观测点，把当天先冲高再跳水的剧烈来回全部抹平了。5 分钟采样则把这段时间里的每一次往返都计入平方和：同样收平的一天，来回震荡的日子算出的 RV 会远高于风平浪静的日子。对风控和期权定价来说，前者承担的日内路径风险其实更大，忽略它就会系统性低估真实波动。已有研究与实践普遍表明，采样频率适中时的已实现波动率，比日度收益平方是更有效、更充分的风险度量。

这里有个容易被忽视的工程细节：杠杆项**必须标准化并有界**。如果直接把上一日收益乘一个大系数，高波动日的巨额亏损会反过来把下一日波动推得更高，形成正反馈，logRV 几步就发散成 `inf`。用 `ret/rv` 把它压成"-4 到 0"的无量纲量，既保留了"跌得越多、未来波动越大"的信息，又保证系统稳定。

## 三、纯 numpy 估计：系数 recovered 得怎么样

不引入任何回归库，用一个二十行的 OLS 即可。前 1600 天训练，后 770 天测试：

```python
rows, ys = [], []
for t in range(30, N):
    rows.append([1.0, logrv[t-1], logrv[t-5:t].mean(),
                 logrv[t-22:t].mean(), lev[t-1]])
    ys.append(logrv[t])
X, Y = np.array(rows), np.array(ys)

def ols(X, y):
    xtxi = np.linalg.inv(X.T @ X)
    beta = xtxi @ (X.T @ y)
    resid = y - X @ beta
    sigma2 = resid @ resid / (len(y) - X.shape[1])
    se = np.sqrt(np.diag(xtxi) * sigma2)
    return beta, se, beta/se

b, se, tstat = ols(X[:1600], Y[:1600])
```

估计结果如下：

| 参数 | 真值 | 估计值 | t 统计量 |
|---|---|---|---|
| $\beta_d$ (日) | 0.35 | 0.449 | +15.8 |
| $\beta_w$ (周) | 0.40 | 0.342 | +7.9 |
| $\beta_m$ (月) | 0.20 | 0.153 | +4.5 |
| $\beta_r$ (杠杆) | −0.06 | −0.059 | −7.8 |

四个系数全部在统计上高度显著，杠杆项几乎精确命中真值。三个波动系数的和估计为 **0.944**（真值 0.95）——这个数很关键：它小于 1，意味着波动冲击最终会衰减回均值，系统是平稳的。如果估计出接近甚至大于 1，你看到的"长记忆"其实是非平稳的趋势，预测将完全失灵。**每次拟合 HAR，第一件该做的事就是检查 $\beta_d+\beta_w+\beta_m$。**

## 四、样本外：真正的考试

在没见过数据的 770 天上，用 $R^2=1-\frac{\sum(\hat y-y)^2}{\sum(\bar y-y)^2}$ 对比三个模型：

| 模型 | 样本外 $R^2$ |
|---|---|
| HAR-RV | **0.385** |
| AR(1)（只看昨天） | 0.252 |
| 随机游走（今天=昨天） | 0.147 |

HAR 把样本外解释力从 AR(1) 的 25% 抬到 38.5%，相对提升超过五成。但请注意：这个 $R^2$ 是在 **log RV** 上算的——它衡量的是"波动水平"的预测精度，不是收益方向，更不是交易胜率。

## 五、一个诚实的警告：方向命中只有 41.2%

如果把"明天波动比今天升还是降"当作二分类任务，HAR 的命中率只有 **41.2%**——比抛硬币还差。

原因并不神秘：因为系数和小于 1，HAR 本质上是个均值回复模型，今天波动特别高时它预测明天回落，今天特别低时它预测明天回升。而 log RV 的日度变化包含了大量噪声，如果拿逐日差分去打分，这种"反向预测"自然常常踩错。**这说明 HAR 擅长的是预测波动的中枢水平，而不是择时波动的每日拐点。** 用它做仓位缩放（预期波动高就减仓）是合理的；用它做"明天波动率会涨"的短线押注，则是在拿噪声当信号。

## 六、从波动预测到风控：条件 VaR 回测

HAR 最实在的用途，是给风险模型提供**条件波动率**：把预测出的 $\widehat{RV}_t$ 代进 $VaR_{99}=z_{0.01}\cdot\widehat{RV}_t$（正态分布下 $z_{0.01}=-2.326$），就得到每天动态变化的风险限额。

回测结果：770 个测试日里突破 4 次，违约率 **0.52%**，低于 1% 的目标；Kupiec POF 检验 $LR=2.179$，$p=0.140$，统计上不能拒绝模型正确。**但这里必须泼一盆冷水**：同期用训练期固定波动率算的无条件 VaR 只突破 1 次（0.13%），覆盖反而更保守——因为无条件波动取了算术平均，被少数极高波动日抬高。也就是说，HAR 在点预测上大获全胜，但在这段样本里**并没有把尾部风控做得更好**。条件模型真正的价值要在波动状态切换剧烈的时期才会凸显，样本越平静，它和固定波动率的差异就越难体现。

## 七、落到实盘的几点经验

**第一，对 log RV 建模，不要直接对 RV 建模。** 波动率严格为正且右偏，取对数后分布更接近正态，OLS 的线性假设才站得住；预测值指数还原后天然为正，不会算出负波动这种荒唐结果。

**第二，RV 的估计精度随采样频率提升而改善，但高频噪声会反噬。** 5 分钟是常见折中，1 分钟数据在流动性差的股票上会被买卖价差噪声污染，导致 RV 系统性高估——这时该上已实现核估计或子采样平均，而不是盲目提高频率。

**第三，杠杆项的符号别搞反。** 本文设定 $\beta_r<0$ 且 $L=\min(r/RV,0)\le0$，因此负收益贡献为正、推高波动；如果交换定义，系数符号会跟着翻，务必用自己的数据 sanity check 一遍。

**第四，HAR 是基座，不是终点。** 在它之上加一支已经实现半方差、加跳变分量、加波动率曲面隐含信息，都是自然延展。但每一次加特征，都要问同一个问题：样本外 $R^2$ 是否真的提高，而不只是训练拟合更好看。

一个常见的落地方式是拿 HAR 的预测波动做**波动率目标化仓位**：目标风险除以预测波动得到杠杆倍数，预测波动翻倍则仓位减半。这里要格外注意平滑——如果每天直接按预测值调仓，41% 的方向命中率意味着大量无谓换手，交易成本会吃掉波动择时带来的全部好处。实务中通常给预测波动加一个 20 天移动平均，或对仓位变化设置上下限，用一点点滞后换取显著更低的换手率。这也再次印证本文的核心结论：HAR 提供的是波动中枢的估计，把它当低频风险刻度盘用，远比当高频信号源用更靠谱。

对量化研究员来说，HAR-RV 最值得学习的不是那三个回归系数，而是一种建模哲学：**复杂的长记忆行为，未必需要复杂的模型；把正确的经济直觉翻译成正确的特征，普通最小二乘也能走很远。**
