在量化交易里，"赚了就加仓、亏了就扛"是散户亏钱的两大主因。它们看似贪婪与恐惧的两极，其实犯了同一个错误：**把仓位当成一个凭感觉调节的旋钮，而不是一个有数学最优解的随机变量**。凯利公式（Kelly Criterion）就是这个问题的精确答案——它告诉你，在长期重复博弈中，到底该押多少。

更反直觉的是，凯利告诉你"押太多会让你变穷"。这不是危言耸听，而是复利的数学铁律。本文从最简单的赌局出发，一路推到连续收益的杠杆选择，并用大规模蒙特卡洛把"全凯利/半凯利/过赌"的真实命运摆给你看。

## 从赌局推导：为什么是对数效用

设一个赌局：胜率 $p$，赢了净赚 $b$ 倍本金（赔率 $b:1$），输了亏掉全部下注。投入财富比例 $f$，赌 $n$ 局后的财富是：

$$
W_n = W_0 \prod_{i=1}^{n}(1 + f \cdot b)^{X_i}(1-f)^{1-X_i}
$$

其中 $X_i \in \{0,1\}$ 是第 $i$ 局胜负。直接最大化期望财富 $E[W_n]$ 会得出"全押"的荒唐结论，因为少数极端走运的路径会把均值拉到天上。正确的目标是最大化**长期几何增长率**，也就是对财富取对数后再求期望：

$$
g(f) = p\log(1+bf) + (1-p)\log(1-f)
$$

对 $f$ 求导令其为零，就得到大名鼎鼎的凯利公式：

$$
f^* = \frac{bp - q}{b} = p - \frac{q}{b}, \quad q = 1-p
$$

本文的赌局 $p=0.55$、$b=1$、$q=0.45$，于是 $f^*=0.55-0.45=0.10$——每局押当前财富的 10%。

![二元赌局的几何增长率曲线](/images/kelly-criterion-leverage/01_binary_growth.png)

上图是 $g(f)$ 曲线。在 $f^*=0.10$ 处达到峰值 $g^*=0.5008\%$/局；押一半（$f=0.05$）时 $g=0.3753\%$，保留了 74.9% 的增长率；而押双倍（$f=0.20$）时 $g$ 已经跌到 $-0.0138\%$——**增长率为负，长期必然亏钱**。押到 0.5 更惨，每局几何增长 $-8.89\%$，财富指数级蒸发。曲线右侧那片阴影区，就是"贪心过头反受其害"的数学领地。

## 蒙特卡洛：均值是骗人的，中位数才是你的命运

理论曲线很清楚，但实际财富路径的离散度大到什么程度？我用 20 万条路径、每条 500 局做蒙特卡洛，看四种下注策略的最终财富分布。

![不同凯利比例的蒙特卡洛财富路径](/images/kelly-criterion-leverage/02_monte_carlo.png)

结果极具戏剧性，值得逐条读：

| 策略 | 中位财富 | 均值财富 | 跌破半仓概率 |
|------|----------|----------|--------------|
| 半凯利 0.05 | 6.53 倍 | 12.08 倍 | 1.1% |
| 全凯利 0.10 | 12.23 倍 | 145.53 倍 | 8.2% |
| 双倍凯利 0.20 | 0.93 倍 | 14548.66 倍 | 44.6% |
| 过赌 0.50 | ≈0 | 0.36 倍 | 100% |

全凯利的中位财富（12.23 倍）确实是最高的，符合它最大化几何增长率的定义。但请注意它的均值高达 145.53 倍——**均值和中位数差了一个数量级**，这说明财富分布是极度右偏的：绝大多数路径落在中位数附近，极少数走运路径把均值拉上天。如果你看回测的"平均收益"，看到的就是这个被肥尾污染的幻象。

双倍凯利是最佳的教具：它的均值财富高达 14548 倍，看起来比全凯利强一百倍；可它的**中位数只有 0.93 倍——500 局下来不赚反亏**，且有 44.6% 的路径跌破半仓。一张好看的收益曲线（均值）和真实体验（中位数）能背道而驰到这种程度，这正是过度杠杆最危险的伪装。过赌 0.5 则毫无悬念：中位财富归零、100% 腰斩。

![连续收益下的增长率与杠杆](/images/kelly-criterion-leverage/03_continuous.png)

## 连续收益：从赌局到真实市场

真实市场不是二元的。对连续收益，设超额收益均值 $\mu$、波动 $\sigma$、投入比例 $f$，几何增长率近似为 $g(f)=f\mu - \frac{1}{2}f^2\sigma^2$（多空两边都适用）。求导得到连续版凯利：

$$
f^* = \frac{\mu}{\sigma^2}
$$

本文设 $\mu=6\%$、$\sigma=16\%$，则 $f^*=0.06/0.16^2=2.34$——**凯利建议用 2.34 倍杠杆**！全凯利的超额几何增长率是 $\mu^2/(2\sigma^2)=7.031\%$，半凯利（$f=1.17$）是 5.273%，依然精确保留 75%。

2.34 倍杠杆这个数字本身就敲响警钟：单个资产的凯利仓位往往高得离谱，因为它假设你对 $\mu$ 的估计是精确的。真实市场里 $\mu$ 的信噪比极低，这正是下一节的主题。

## 最致命的陷阱：对 mu 的敏感性

凯利公式在实际应用中最大的杀手，不是公式本身，而是输入 $\mu$ 的估计误差。看一个触目惊心的例子：真实 $\mu=6\%$，但你把 $\mu$ 高估成了 $12\%$（这在牛市里太常见了）。于是你按 $\hat\mu/\sigma^2=0.12/0.0256=4.69$ 倍下注。把这 4.69 倍代回**真实的**增长率公式：

$$
g(4.69) = 4.69 \times 0.06 - \tfrac{1}{2}\times 4.69^2 \times 0.16^2 = 0.281 - 0.281 = 0
$$

增长率**精确归零**——你自以为在最优杠杆上，实际上在原地踏步。若高估得更狠，增长率直接转负，长期必然亏损。

![参数估计误差下的稳健性对比](/images/kelly-criterion-leverage/04_robustness.png)

上图把"乐观倍数"$\hat\mu/\mu$ 从 0.5 扫到 2.5，对比全凯利与半凯利的**真实**增长率。全凯利（红线）在估计准确时最高，但在乐观倍数约 2.0 处增长率归零、之后转负——一个漂亮的倒 U 形，峰顶极其尖锐。半凯利（绿线）峰值只有全凯利的 75%，却宽阔平坦得多：即便把 $\mu$ 高估一倍（$\hat\mu/\mu=2$），全凯利增长率只剩 0.035%，半凯利仍有 7.03%，毫发无伤。

这就是业界几乎一致推荐**分数凯利**（fractional Kelly，通常半凯利）的根本原因：用四分之一的增长率上限，换取对参数误差的巨大容错空间。在一场你无法确定赔率的赌局里，活下来比最大化重要。

## 为什么均值财富会骗人：遍历性问题

蒙特卡洛里那个"均值 145 倍、中位 12 倍"的落差，背后是一个深刻的统计陷阱，称为**非遍历性**（non-ergodicity）。时间序列的增长率（你实际经历的）和大量平行样本的期望收益（回测报表展示的），在乘性过程中不是同一个东西。

想象 100 个人各自重复 500 局赌局。他们的**平均**财富会被极少数走运者拉到 145 倍——但任何一个具体的人，大概率拿到的是 12 倍左右的中位结果，甚至更低。更有甚者，如果过程中存在吸收壁（爆仓、追加保证金、被强平），一旦财富归零就再也无法翻身，此时时间平均增长率是 $-\infty$，而横截面的期望收益依然可以是正无穷。遍历性在这里彻底失效了。

这解释了为什么"期望收益为正"的系统仍可能让参与者破产：期望是对集合的平均，而你只能活在自己那一条路径上。凯利准则之所以选择最大化对数效用，正是因为它优化的是**时间平均的几何增长率**——也就是你真正会经历的那个量。从这个角度看，凯利不只是仓位公式，更是一种对"个体命运不等于群体平均"的清醒认知。

## 与其他风险管理框架的对话

凯利并非孤立存在，它和风险平价、波动率目标化等框架有内在联系。当收益与波动满足 $f^*\propto \mu/\sigma^2$ 时，凯利仓位天然对高波动资产减配——这与波动率目标化（按 $1/\sigma$ 缩放）方向一致，只是凯利还额外考虑了预期收益 $\mu$。

最大回撤约束则可以看作凯利的现实补丁：凯利控制的是长期增长率，对短期路径的剧烈回撤不设防（全凯利腰斩概率仍有 8.2%）。实务中的做法，是先算凯利仓位，再用历史或蒙特卡洛估计其回撤分布，若超出承受范围就整体缩放到分数凯利。这个过程本质上是在"增长率"和"生存概率"之间找一个你能睡得着觉的平衡点。

需要警惕的是把凯利和动量、马丁格尔等策略混为一谈。马丁格尔（输了加倍下注）是凯利的反面——它在有限赌局里几乎必赚，却把破产风险藏在了尾部；凯利恰恰是拒绝这种"捡钢镚压路机"式的策略，始终把破产概率压到零。

## 完整 Python 实现

```python
import numpy as np

# ---- 二元赌局 ----
p, b = 0.55, 1.0
q = 1 - p
f_star = (b*p - q) / b              # 0.10

def g_binary(f):
    return p*np.log(1 + b*f) + q*np.log(1 - f)

print(f"f*={f_star:.2f}, g*={g_binary(f_star)*100:.4f}%/局")
print(f"半凯利保留 {g_binary(f_star/2)/g_binary(f_star)*100:.1f}% 增长率")
# g*=0.5008%, 半凯利 g=0.3753% (74.9%), 双倍凯利 g=-0.0138%

# ---- 蒙特卡洛：用二项分布一次采样 ----
rng = np.random.default_rng(42)
T, N = 500, 200_000
W = rng.binomial(T, p, N)           # 每局胜负 -> 胜局数
for f in [0.05, 0.10, 0.20, 0.50]:
    logw = W*np.log(1+b*f) + (T-W)*np.log(1-f)
    wealth = np.exp(logw)
    print(f"f={f}: 中位={np.exp(np.median(logw)):.2f}x, "
          f"均值={wealth.mean():.2f}x, 腰斩率={(wealth<0.5).mean()*100:.1f}%")

# ---- 连续收益 & 高估 mu 的代价 ----
mu, sigma = 0.06, 0.16
f_cont = mu / sigma**2              # 2.34
def g_cont(f, mu_true):
    return f*mu_true - 0.5*f**2*sigma**2
f_hat = 0.12 / sigma**2             # 把 mu 高估到 12%
print(f"连续 f*={f_cont:.2f}, 高估后下注={f_hat:.2f}, "
      f"实际增长={g_cont(f_hat, mu)*100:.3f}%")  # 0.000%
```

## 结语：凯利是一种纪律，不是一个数字

凯利公式给我们的最大启示，不是"该押 10% 还是 20%"，而是三个思维转变。第一，**复利下要最大化的是几何增长率而非期望收益**，这让我们对肥尾路径保持警惕。第二，**存在一个过赌的临界点**，越过它，更多的风险不是更多的收益，而是必然的毁灭。第三，**参数误差不对称地惩罚激进仓位**——保守一点（半凯利）损失的增长率有限，激进一点（双倍凯利）却可能万劫不复。

实盘中还要叠加更多现实约束：凯利假设赌局独立、赔率已知、可以无限细分下注，而市场有冲击成本、流动性限制、相关性聚集和厚尾。因此 practitioners 几乎无一例外地用分数凯利，再叠加单票上限、行业约束和波动率目标化。把这些约束看成对凯利"理论最优"的必要妥协，而非对它的否定——毕竟，一个能让你长期留在牌桌上的次优仓位，远胜过一个理论上完美、却会在下一次黑天鹅里让你出局的最优仓位。
