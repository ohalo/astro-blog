均值-方差是经济学家开的处方：假设你有一个效用函数、把二阶矩当风险、解一个二次规划。前景理论（Kahneman-Tversky，1992）是心理学家做的描述：真实人类参考点依赖、亏损比等量收益疼 2.25 倍、还会把小概率放大、中大概率压缩。这两套语言在文献里已经吵了三十年。本文不问谁对谁错，问一个更动手的问题：**如果老老实实按 TK92 原版参数做组合优化，最优组合长什么样？** 答案会让两边都不舒服：CPT 最优是一杯 95% 的彩票。而把这个结果拆开的过程，恰好能把 CPT 的每个组件单独送上解剖台。

结论先放这：

**① 概率加权是彩票偏好的唯一引擎。** 同一个零均值正偏资产，线性概率下 CPT 价值 −0.0196（拒绝），TK 加权后 +0.0163（接受）——价值函数没变，只换了概率这把尺。机制：3% 的中奖月份拿走了 16.0% 的决策权重（5.3 倍放大），97% 的失血月份只分到 89%。

**② TK 标准参数（λ=2.25）下，CPT 最优 = 95% 彩票 + 5% 股票。** 单资产 CPT 价值：彩票 +0.0163 ≫ 债券 −0.0013 > 股票 −0.0069 > 黄金 −0.0137。原因：彩票与危机因子独立（没有亏损尾部）、亏损是每月 −0.6% 的小失血、中奖是加权后的大惊喜；而任何含危机敞口的资产，亏损侧的凸性都会被 λ 放大。

**③ 最优配置对 λ 是阶跃响应，不是渐变。** λ≤2.25 全在彩票，λ≥3.5 突然变成杠铃（λ=3.5：股票 15%/债券 40%/彩票 45%）。CPT 的排序不看风险大小，只看亏损落在哪。

**④ 概率加权越接近线性（γ→1），CPT 最优越像均值-方差**——γ=0.85 时最优变成债券主导的 30/65/5，彩票仓位归零。彩票偏好完全是概率加权的产物，不是价值函数的。

**⑤ 评估期决定一切（短视损失厌恶的机械解释）。** 月度评估：95% 彩票；半年：80% 股票；一年以上：100% 股票。聚合把中奖概率摊平，尾部超额权重消失，均值重新说话。

**⑥ 但别急着上线：经验 CPT 权重跨 5 条独立路径，彩票仓位在 0-100% 间摇摆。** 加上 30% 权重上限后最优变成 25/30/15/30 杠铃，回测 CAGR 5.04%/MDD −6.55%——可用，但那是约束的功劳，不是 CPT 的。

## CPT 机制：两把尺子

TK92 把决策价值写成两把尺子的组合。**价值函数**（对盈亏，参考点取 0）：

```python
def v(x, alpha=0.88, lam=2.25):
    # 收益域凹（x^0.88），亏损域更陡（-lam*(-x)^0.88）
    return np.where(x >= 0, np.abs(x) ** alpha, -lam * np.abs(x) ** alpha)
```

**概率加权函数**（逆 S 形）：收益域 γ=0.61、亏损域 γ=0.69，

```python
def w(p, gamma):
    return p ** gamma / (p ** gamma + (1 - p) ** gamma) ** (1 / gamma)
```

组合价值 = 把结果排序后，用累计概率的加权差分 π_i = w(F_i) − w(F_{i−1}) 加权求和。这把尺子的全部魔法在**域的边界**上：若一个资产 97% 的结果是亏损、3% 是盈利，那 3% 的盈利域拿到的总权重不是 3%，而是 w⁺(1) − w⁺(0.97) = **16.0%**——5.3 倍放大；而 97% 的亏损域只分到 w⁻(0.97) = 89%。记住这 16% 和 5.3 倍，后面所有的奇怪现象都从这来。

## 合成市场：四个分工明确的资产

用 20 万个月的参数化市场（约 11% 的月份落在 2-6 个月的危机块里，危机中市场因子均值 −1.0%、波动 8.5%），四个资产各管一条通道：

| 资产 | 月均收益 | 月波动 | 危机角色 |
|---|---|---|---|
| 股票 | +0.97% | 5.26% | 危机重灾区（因子载荷 1.0） |
| 债券 | +0.26% | 1.90% | 避险（载荷 −0.25→−0.50） |
| 黄金 | +0.21% | 4.31% | 强避险但高波动（−0.45→−0.90） |
| 彩票 | **−0.04%** | 3.67% | **与危机因子完全独立** |

彩票的构造是核心：3% 的月份 +18%±8%（中奖），97% 的月份 −0.6%±1.2%（失血）。均值 −0.04%/月，年化约 −0.4%——**一个期望收益为零、方差不小的正偏资产**，均值-方差对它毫无兴趣，最大夏普通常给它 0-3% 的权重。股票-债券相关 −0.79、股票-黄金 −0.63、债券-黄金 +0.65，彩票与一切的相关约等于 0。

## 发现一：同一张彩票，两把尺子两种命运

先做最干净的对照实验：单独看彩票资产，线性概率 vs TK 加权。**线性概率下 CPT 价值 −0.0196**（拒绝——2.25 倍的损失厌恶把 97% 的失血放大成主导项）；**TK 加权后 +0.0163**（接受）。价值函数一模一样，只换了概率这把尺， verdict 从"扔"变成"买"。这就是 CPT 世界里的 skewness preference：彩票不需要有正期望，只需要**尾部被放大**。

## 发现二：95% 彩票的解剖

在 20 万个月大样本上做长仓约束的单纯形网格搜索（共同随机数保证目标函数光滑），λ=2.25 的 CPT 最优是 **股票 5% / 彩票 95%**（CPT 价值 +0.0166）。单资产 CPT 价值排序解释了原因：彩票 +0.0163 ≫ 债券 −0.0013 > 股票 −0.0069 > 黄金 −0.0137——**连"避险资产"黄金都是 CPT 价值最低的**，因为它 4.31% 的日常波动在 α=0.88 的凹价值函数下天天产生负价值，危机里的那点正收益杯水车薪。

为什么分散化救不了场？因为亏损域的价值函数对 x 是凹的：E[v(−X)] ≤ v(−E[X])，**分散化让亏损更"平均"从而更接近 v(亏损均值)**——这本来该改善 CPT 价值。但任何与股票/债券/黄金的混合都会把彩票的 16% 加权中奖域摊薄（收益域同样凹，混搭稀释中奖），同时引入危机因子的亏损尾部。两害相权，优化器选择抱着彩票不放。MV 最大夏普在同一市场的答案是 27.8% 股票 + 68.7% 债券 + 3.5% 黄金——债券主导，靠的是 −0.79 的股债相关。两个"最优"指向完全相反的方向，而且都情有可原。

## 发现三：λ 的阶跃与 γ 的归零

把 λ 从 1.0 扫到 5.0，最优配置不是渐变而是**阶跃**：λ=1.0 和 2.25 都是 95-100% 彩票（λ=1 时股票 +0.0328 与彩票 +0.0344 几乎打平，只差 5%）；λ=3.5 突然变成 15/40/0/45 杠铃；λ=5.0 是 20/45/5/30。机制：λ 放大的是亏损域，股票的亏损是危机里 −5% 的重伤、彩票的亏损是每月 −0.6% 的擦伤——λ 越过某个阈值后，"抱着亏损最轻的资产"让位给"用低波资产摊薄亏损"，而亏损域的凹性此时开始奖励分散。CPT 的偏好**不按风险大小排序，按亏损的位置排序**，所以对 λ 的响应天然不单调。

γ 扫描给出更锋利的结论：γ=0.40（极端加权）→ 100% 彩票；γ=0.61（TK 标准）→ 95% 彩票；γ=0.85（接近线性）→ **30/65/5/0，彩票归零，最优长得和 MV 的债券组合一样**。彩票偏好不是来自"人类喜欢惊喜"这种笼统说法，**精确地来自 γ 对尾部的放大**。

## 发现四：评估期——短视的机械解释

Benartzi-Thaler 的经典论断是"短视的损失厌恶"：评估越频繁，越觉得股票可怕。CPT 把这个论断变成了可计算的机械过程。把收益按 h 个月聚合后再评估，最优配置单调旋转：**h=1 个月：95% 彩票 → h=3：20/25/5/50 → h=6：80% 股票 + 20% 黄金 → h=12/24：100% 股票**。道理直白：聚合把 3% 的中奖概率摊成"每个半年窗口都有中奖"（h=6 时窗口中奖概率约 17%），尾部超额权重消失；同时危机亏损被平均成少数几个大窗口，股票的高均值重新主导。**彩票是短视者的资产，股票是耐心者的资产**——同一套参数，只改评估期。

## 发现五：你估计不出它

就算全盘接受 CPT，还有最后一关：**经验 CPT 的排序噪声**。在 5 条独立的 360 个月路径上跑同样的网格优化，彩票权重分别是 85%、90%、0%、40%、100%——同一市场、同一参数，换个样本连"买不买彩票"的答案都会翻面。原因是 CPT 价值函数对排序和尾部加权极其敏感，360 个样本的尾部就那么十几个点。这也是为什么正文的优化全部放在 20 万大样本上（平滑目标），而把经验版本的结果只用于展示噪声。

## 回测：感觉良好的组合，终值难看

在一条独立的 480 个月路径上（期初 = 1，对数轴）：

- **MV 最大夏普**：CAGR 6.28%、波动 3.08%、夏普 2.00、MDD −2.47%
- **CPT 最优（95% 彩票）**：CAGR 0.01%、波动 12.60%、夏普 0.06、MDD **−46.16%**，64% 的月份在亏损
- **CPT 受限（权重≤30%，25/30/15/30）**：CAGR 5.04%、波动 4.85%、夏普 1.04、MDD −6.55%
- **60/40 股债**：CAGR 11.09%、波动 9.02%、MDD −17.37%

CPT 最优组合的体验很分裂：它确实**没有单月重伤**（最坏月份 −4.16%，MV 是 −2.08% 但 60/40 是 −7.81%），可它用 64% 的月份慢性失血换来的"心理舒适"，代价是四十年 CAGR 归零和 −46% 的回撤。而加上最朴素的 30% 权重上限，CPT 最优立刻变成一支像样的杠铃（25% 股票/30% 债券/15% 黄金/30% 彩票），回测全面可用——**但那是约束的功劳：上限强行恢复了分散化，而 CPT 在受限空间里已经说不出什么了**。

## 诚实结论

CPT 作为**描述模型**是行为金融最硬的成果之一：它用两把尺子同时解释了彩票偏好、保险需求、处置效应和股权溢价之谜。但作为**处方引擎**，TK 原版参数直接做组合优化会得到 95% 彩票这种荒诞解，根子有三：概率加权把 3% 的尾部放大成 16% 的权重，与风险度量完全脱钩；目标函数对 λ、γ、评估期、样本全部敏感，最优解在参数空间里阶跃跳变；亏损域凹性与收益域凹性的拉扯，让"分散化"时好时坏。实践界的解法从来不是"更精确地解 CPT"，而是给 CPT 上约束（权重上限、组合先验收缩、参数不确定性平均），或者干脆只用它做**校验**——问"我的 MV 组合在一个 CPT 投资者眼里会是什么体验"，而不是"CPT 说该买什么"。前者是今天所有机构风险报告的潜台词，后者是这篇合成市场用 −46% 的回投反对的。
