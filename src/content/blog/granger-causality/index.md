"这两个变量高度相关，是不是一个导致了另一个？"——这是量化研究里最容易踩坑的问题。相关只能说明它们**一起动**，却说不清谁**先动**、谁的信息能**预测**谁。格兰杰因果检验（Granger causality test）给出的正是一个更锋利、也更实用的定义：

> 如果利用 $X$ 的过去值，能比只用 $Y$ 自己的过去值更准确地预测 $Y$ 的未来，那么我们就说 $X$ **格兰杰引起** $Y$。

注意，它叫"格兰杰因果"，但严格说是"**预测因果**"——它衡量的是信息上的领先-滞后结构，而不是哲学意义上的真正因果。但恰恰是这一定义，让它在金融里极其好用：判断哪个因子领先、哪条曲线是"因"、新闻情绪有没有真的预测了收益。

这一定义妙在**可证伪**：它把一个模糊的"谁先动"问题，变成了一个能构建零假设、算出 $p$ 值的统计检验。比起"我觉得 A 导致了 B"，它给你的是一条可被数据推翻的证据，而不是一句感觉。

结论先放这：

**① 方向性检验是真的能分开的。** 在一个 $X$ 单向驱动 $Y$ 的合成系统里，$X\to Y$ 的 Granger F 统计量高达 **202.9**（$p\approx 1\times10^{-43}$，几乎不可能偶然），而反向 $Y\to X$ 只有 **0.31**（$p=0.58$，完全不显著）。用 statsmodels 现成函数交叉验证，数字逐位吻合。

**② 预测力能直接换成精度。** 把 $X$ 的滞后项加进 $Y$ 的一步预测模型后，样本外 MSE 从 1.092 降到 1.008，**下降了 7.7%**。这不是"统计显著但没用"，是实打实的预测增益。

**③ 相关≠预测因果，有反例为证。** 两个序列共享同一个同步冲击、相关系数达到 **0.33**，看起来"有关"，但双向 Granger 检验的 $p$ 值分别是 0.995 和 0.366——**谁也预测不了谁**。相关来自同一时刻的冲击，而非领先-滞后结构。

## 一、检验在测什么：受限模型 vs 无受限模型

格兰杰检验的本质，是一次**嵌套模型的 F 检验**。以一阶系统为例，我们关心 $X$ 的滞后是否对 $Y$ 有额外解释力：

**无受限模型**（允许 $X$ 提供信息）：

$$Y_t = c + a_1 Y_{t-1} + b_1 X_{t-1} + \varepsilon_t$$

**受限模型**（剥夺 $X$ 的信息）：

$$Y_t = c + a_1 Y_{t-1} + u_t$$

如果 $b_1$ 显著不为零，说明 $X_{t-1}$ 带走了 $Y_t$ 里 $Y_{t-1}$ 解释不了的那部分方差——也就是 $X$ 真的"格兰杰引起"了 $Y$。F 统计量比较的是两个模型的残差平方和（SSR）：

$$F = \frac{(SSR_r - SSR_u)/k}{SSR_u/(T - p - m)}$$

其中 $k$ 是被砍掉的参数个数（这里就是 $X$ 的滞后项数），$T$ 是样本量。F 越大、$p$ 越小，越有把握说"加 $X$ 不是白加的"。检验的零假设是 $b_1=0$，即 $X$ 不格兰杰引起 $Y$。

这里有个常被忽略的要点：**Granger 因果一定是对"方向"和"滞后阶数"同时成立的结论**。"$X$ 在滞后 1 阶下不引起 $Y$"和"$X$ 在任何阶数下都不引起 $Y$"是两句话；滞后阶数选错了，结论可能完全翻面。

## 二、从零实现：先造一个单向因果系统

下面的代码不依赖任何时间序列黑盒，纯粹用 numpy 把上面那套逻辑跑通。我们先造数据：让 $X$ 自己的过去决定自己，而 $Y$ 的过去**加上** $X$ 的过去才决定 $Y$——于是 $X$ 单向驱动 $Y$。

```python
import numpy as np

rng = np.random.default_rng(20261026)
N = 2000
e = rng.normal(0, 1, N)          # Y 的扰动
u = rng.normal(0, 1, N)          # X 的扰动
x = np.zeros(N); y = np.zeros(N)
for t in range(1, N):
    x[t] = 0.5 * x[t-1] + u[t]            # X 只靠自己
    y[t] = 0.5 * y[t-1] + 0.3 * x[t-1] + e[t]  # Y 靠自己 + 滞后 X
x, y = x[200:], y[200:]            # 丢弃烧入期
```

手写 Granger F 检验，就照着上一节的公式来：

```python
from numpy.linalg import lstsq

def granger_ftest(y, x, p=1):
    T = len(y)
    Y = y[p:T]
    Xr = np.column_stack([np.ones(T-p)] +
                         [y[p-k:T-k] for k in range(1, p+1)])      # 受限
    Xu = np.column_stack([Xr] +
                         [x[p-k:T-k] for k in range(1, p+1)])      # 无受限
    br, rr = lstsq(Xr, Y, rcond=None)
    bu, ru = lstsq(Xu, Y, rcond=None)
    ssr_r = rr @ rr; ssr_u = ru @ ru
    k = Xu.shape[1] - Xr.shape[1]
    df1, df2 = k, T - p - Xu.shape[1]
    F = ((ssr_r - ssr_u) / df1) / (ssr_u / df2)
    from scipy.stats import f as fdist
    return F, 1 - fdist.cdf(F, df1, df2)

F_xy, p_xy = granger_ftest(y, x, 1)   # X -> Y ?
F_yx, p_yx = granger_ftest(x, y, 1)   # Y -> X ?
```

跑出来 $X\to Y$ 的 F=202.9、$p\approx 0$，反向 $Y\to X$ 的 F=0.31、$p=0.58$。为了确认手写没算错，再用 statsmodels 自带的 `grangercausalitytests` 对拍，F 和 p 逐位一致——检验逻辑是对的。

## 三、方向性一眼看清

把两个方向的 F 统计量并排，结论就钉死了：

![两个方向的 Granger F 检验](/images/granger-causality/fig3_granger.png)

$X\to Y$ 的柱子冲到 200 多、标注 $p\approx 0$；$Y\to X$ 的柱子趴在 0.3、标注 $p=0.58$。**一个强烈显著、一个完全不显著**，方向分得干干净净。这就是格兰杰检验最舒服的地方：它把"谁领先"这种模糊直觉，变成了一个可拒绝的零假设。

那么"显著"到底值多少钱？我们做个样本外实验：用前 70%（1260 个样本）建模，后 30% 做一步预测。模型 A 只用 $Y$ 的滞后（受限），模型 B 加上 $X$ 的滞后（无受限），都用真实实现的滞后值做条件一步预测：

```python
tr = int(len(x) * 0.7)
xtr, ytr = x[:tr], y[:tr]
xte, yte = x[tr:], y[tr:]
br, _ = lstsq(np.column_stack([np.ones(tr-1), ytr[:-1]]), ytr[1:], rcond=None)
bu, _ = lstsq(np.column_stack([np.ones(tr-1), ytr[:-1], xtr[:-1]]), ytr[1:], rcond=None)
mse_r = np.mean((yte[1:] - (br[0] + br[1]*yte[:-1]))**2)
mse_u = np.mean((yte[1:] - (bu[0] + bu[1]*yte[:-1] + bu[2]*xte[:-1]))**2)
mse_red = (mse_r - mse_u) / mse_r * 100   # = 7.7%
```

![样本外一步预测对比](/images/granger-causality/fig4_oos.png)

图 4 里绿线（带 $X$）整体贴着实际值更紧。MSE 从 1.092 降到 1.008，**下降 7.7%**。对一个只有单滞后、单因子的极简模型来说，这是个不算小、而且"显著"能兑现成"更准"的结果。

## 四、反面教材：相关，但谁也预测不了谁

最容易让人误判的，是"看着相关就以为是因果"。下面的反例里，两条序列 $X$ 和 $Y$ 都各有自己的 AR(1) 过程，但**额外共享同一个同步冲击** $W_t$：

```python
w = rng.normal(0, 1, 900); e = rng.normal(0, 1, 900); u = rng.normal(0, 1, 900)
sx = np.zeros(900); sy = np.zeros(900)
for t in range(1, 900):
    sx[t] = 0.5*sx[t-1] + 0.7*w[t] + e[t]
    sy[t] = 0.5*sy[t-1] + 0.7*w[t] + u[t]
```

它们在同一时刻被同一个 $W_t$ 推一下，于是**同期相关**达到 0.33；但 $X$ 的滞后项里**没有任何**关于 $Y$ 未来、且 $Y$ 自己解释不了的信息——因为领先 $X$ 一步的，对 $Y$ 毫无增量。Granger 检验的结果：$X\to Y$ 的 $p=0.995$，$Y\to X$ 的 $p=0.366$，**两个方向都不显著**。

![共享同步冲击造成的相关](/images/granger-causality/fig5_spurious.png)

图 5 两条线黏在一起，视觉上"高度相关"，但检验冷冷地告诉你：谁也预测不了谁。这个例子点破了格兰杰因果的核心边界——**它抓的是领先-滞后结构，不是同期联动**。同期相关再高，只要没有"领先"，检验就不会买账。

## 五、用之前必须知道的边界

写到这里，检验的脾气也该讲清楚，否则容易用错：

- **它是预测因果，不是真因果。** 检验通过只说明"$X$ 的过去帮着预测 $Y$"，不证明 $X$ 是 $Y$ 的经济学原因。中间可能隔着第三个变量，也可能只是数据里的伪结构。
- **先平稳、先查协整。** 对非平稳序列（尤其带单位根的随机游走）直接跑 Granger，容易出现"伪因果"——两个独立随机游走偶尔相关系数很高，检验会乱拒零假设。正确做法是先差分/先做协整预检，再谈因果。
- **滞后阶数是人为选择。** 用 AIC/BIC 或经济含义定阶，别拿一个阶数就下全称结论；金融里常配合 VAR 阶数选择一起做。
- **显著性要看实际幅度。** 大样本下极小的效应也能显著，记得回到 MSE、方向、经济含义去判断"有没有用"，别被 $p$ 值牵着走。

## 六、实战落地：这把尺子到底量什么

回到开头那个问题——格兰杰检验在真实研究里最常被用来干三件事：

- **判资产间的领先-滞后。** 比如股指期货与现货、ETF 与成分股、不同期限国债之间，谁的价格先动。检验显著的那个方向，往往对应套利或对冲时要先盯的盘面。
- **判因子与情绪的预测力。** 把"昨天的北向资金""昨天的波动率""昨天的情绪分数"依次作为 $X$ 去检验是否格兰杰引起收益，能把"听起来有道理"的因子先筛一道。本文反向 $Y\to X$ 的 $p=0.58$ 就是个反面模板：看起来相关，检验说不预测。
- **判策略信号是否真领先。** 自研信号如果连在历史数据上都通不过"用信号滞后能否预测收益"的检验，就别指望它未来管用。

但务必记住那个数字提醒：$X\to Y$ 的 F=202.9 之所以大，是因为合成系统里 $X$ 的滞后系数（0.3）相对噪声足够强、样本也足；真实高频数据里 F 同样能冲到几百，可经济幅度可能微乎其微。所以**永远用 MSE、方向与经济含义给显著性兜底**——就像本文那 7.7% 的样本外降幅，才是"有用"的硬证据，而不是 $p$ 值本身。

一句话总结：格兰杰因果检验是量化里把"看着像"变成"能检验"的那道关。它不能替你断定因果，但能干净利落地告诉你——**在预测的意义上，谁的信息真的领先**。
