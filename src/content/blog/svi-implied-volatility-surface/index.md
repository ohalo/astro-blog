## 一、结论先行

期权交易台每天面对的原始数据是一堆分散的行权价与报价，而定价、对冲、风险指标都需要一条连续曲面。最直觉的做法——对每个期限把隐含波动率做样条插值——在数学上是有危险的：期权价格对行权价的二阶导数必须非负（否则存在蝶式套利），而噪声报价之间的样条完全可能插出负密度。

SVI（stochastic volatility inspired）把总方差写成对数行权价 k 的五个参数函数，用**参数化代替插值**，让平滑性和无套利性变成可检查的性质。本文用真值已知的模拟报价做完整实验，四条结论：

1. **五个参数能从噪声里把真曲面捞回来。** 0.25 年期 41 个报价点，校准后隐含波动率相对真曲面 RMSE 为 0.103 个波动率点，而报价自身的噪声是 0.226 点；1 年期 61 个点，0.066 点对 0.234 点。误差被压掉了 55% 和 72%。
2. **无套利检验拉开差距。** 蝶式密度函数 g(k) 在 SVI 曲面上最小值 0.337（短端）/0.352（长端），全程为正；同样数据做三次样条插值，最小值 -4.94/-13.68，30.0%/43.5% 的网格点违反 g(k)≥0——这是真金白银的套利信号，不是数值瑕疵。
3. **平滑带来的定价改善很实在。** 在五个代表性行权价上，用拟合曲面反算的看涨期权价格相对真值最大误差 0.0174 元（短端）/0.0256 元（长端），直接用含噪报价分别是 0.0278 元/0.0853 元，长端改善 70%。
4. **参数可辨识但有强弱之分。** 60 次独立噪声下，b 的标准差只有 0.00189、m 为 0.00233；对形状最敏感的是 rho（0.0113）与 sigma（0.00729），它们正是需要更多报价点或更强约束的两个参数。

## 二、SVI 参数化与蝶式条件

记远期 F、对数行权价 k = ln(K/F)，总方差 w(k) = σ_imp²(k)·T。SVI 的形式是：

$$w(k)=a+b\left[\rho(k-m)+\sqrt{(k-m)^2+\sigma^2}\right]$$

五个参数各管一件事：a 控制整体方差水平，b 控制微笑的斜率尺度，rho 控制左右翼的不对称（负 rho 是股票市场的典型形态：看跌翼更翘），m 是微笑最低点的位置，sigma 让顶点变圆滑、同时决定翼部的渐近斜率。当 σ→0 时曲面收敛到两段直线拼接的 V 形。

静态无套利的充分必要条件由 Gatheral 给出：对所有 k 有 g(k) ≥ 0，其中

$$g(k)=\left(1-\frac{k\,w'}{2w}\right)^2-\frac{(w')^2}{4}\left(\frac{1}{w}+\frac14\right)+\frac{w''}{2}$$

SVI 的一阶、二阶导数是闭式的：

```python
def svi_w(k, a, b, rho, m, sigma):
    kk = k - m
    return a + b * (rho * kk + np.sqrt(kk**2 + sigma**2))

def svi_d1(k, a, b, rho, m, sigma):
    kk = k - m
    return b * (rho + kk / np.sqrt(kk**2 + sigma**2))

def svi_d2(k, a, b, rho, m, sigma):
    kk = k - m
    return b * sigma**2 / (kk**2 + sigma**2)**1.5
```

这段解析导数很重要：它让 g(k) 的检查不必做数值差分，避免把离散误差误判成套利机会。

还有一个容易被忽略的细节：拟合目标应该是总方差 w，而不是隐含波动率 σ_imp。原因是 Black-Scholes 的 Vega 随 k 变化很大，同样的 0.25 个波动率点误差在不同行权价处对应完全不同的价格误差；在总方差空间里加权最小二乘，等价于近似按 Vega 给报价定价误差加权。本文的残差除以 2·sqrt(wT)·噪声标准差，正是把波动率噪声翻译回总方差尺度后再归一化。如果反过来直接对 σ_imp 做无权重回归，虚值端的报价会被过度信任，拟合出的翼部倾斜往往偏离真实曲面。

## 三、构造带噪声的期权链

实验设定：S=100、无风险利率 2%，两条期限分别用一组已知 SVI 参数生成真总方差，再按 0.25 个波动率点的高斯噪声扰动隐含波动率，反推回总方差。注意噪声要加在**波动率**上而不是总方差上——现实里做市商报的是波动率，且不同 k 处的方差敏感度不同：

```python
TRUE = {0.25: (0.018, 0.11, -0.38, 0.03, 0.09),
        1.00: (0.055, 0.19, -0.48, 0.09, 0.16)}
wtrue = svi_w(kgrid, *ptrue)
iv_true = np.sqrt(wtrue / T)
eps = rng.normal(0, 0.0025, size=kgrid.size)
w_obs = wtrue + 2 * np.sqrt(wtrue * T) * eps   # d(sqrt(w/T)) = dw/(2 sqrt(wT))
```

短端取 41 个报价点（k ∈ [-0.45, 0.45]），长端 61 个（k ∈ [-0.70, 0.70]）。拟合用 `scipy.optimize.least_squares`，残差按报价噪声的标准差归一化，并给五个参数加上有经济含义的边界（b>0、sigma>0、|rho|<1）。这里的经验是：**参数边界不是形式主义**，没有 b>0 的约束，优化器偶尔会跑到向上翘的反常微笑上。

## 四、校准结果

短端真值 a=0.0180、b=0.1100、rho=-0.38、m=0.0300、sigma=0.0900，拟合为 0.01847、0.11000、-0.39680、0.02544、0.08687；长端真值 0.0550、0.1900、-0.48、0.0900、0.1600，拟合为 0.04947、0.19664、-0.45796、0.09299、0.18466。五个参数都落在真值附近，但 rho 和 sigma 的偏差明显更大——这与后面 60 次重复的稳定性排序一致。

从"报价→曲面"的角度看，真正该关心的是隐含波动率误差：短端 RMSE 0.103 个波动率点、最大误差 0.198 点；长端 RMSE 0.066、最大 0.124。相较之下含噪报价自身的 RMSE 是 0.226/0.234 点。也就是说，SVI 不是把噪声记住了，而是把噪声平均掉了。

定价层面，用 Black-Scholes 把曲面转成价格，在五个代表性行权价（正中、两侧、两翼）上比对：短端拟合曲面的最大价格误差 0.0174 元、含噪报价 0.0278 元；长端 0.0256 元对 0.0853 元。若交易账簿里有几十万手期权，这个数量级的价格差足以影响当日损益归因。

## 五、无套利检验：SVI 与样条的正面对决

把每个报价点当作精确值做三次样条插值，看起来最"贴合市场"，但它没有理由满足 g(k)≥0。在 400 个 k 网格点上：

- 短端：SVI 的 g(k) 最小 0.337，样条最小 -4.938，30.0% 的点为负；
- 长端：SVI 最小 0.352，样条最小 -13.682，43.5% 的点为负。

负的 g(k) 意味着可以用蝶式组合锁定价差。实盘里你未必能真的套利（报价价差、交易成本、可执行性都会吃掉利润），但一个会制造套利信号的曲面拿去做对冲比率，风险一定会以别的形式冒出来。SVI 的优势不是"拟合得更紧"，而是**把拟合限制在有经济意义的函数类里**。

![图3：蝶式密度 g(k) 检查，红色阴影是样条的套利区域](/images/svi-implied-volatility-surface/fig3_butterfly.png)

需要说清楚的是：拟合出的 SVI 满足 g(k)≥0，不等于真实市场一定无套利；它只保证我们的曲面不会**主动制造**套利。同样，SVI 也不保证跨期限无套利（日历价差）与到期日之间的静态一致性，实务中还要对 a、b 等参数随 T 的路径加约束（如 SSVI/Heston 型参数化）。

## 六、噪声稳健性

短端真曲面上重复 60 次独立噪声校准，参数标准差依次为 a=0.00085、b=0.00189、rho=0.01130、m=0.00233、sigma=0.00729；隐含波动率 RMSE 中位数 0.0748 点、90 分位 0.1222 点、最差 0.1912 点。rho 的不稳定性反映了微笑倾斜与翼部曲率在有限 k 范围内天然相关：两个参数可以互相补偿而几乎不改变拟合误差。这也是为什么实务中经常固定 rho 或用跨期限联合校准来锁定它。一种可操作的做法是分两阶段拟合：第一阶段五个参数全放开，第二阶段把 rho 固定到全天的联合估计值，只对剩下四个参数重新最小化；这样得到的曲面在逐日滚动时不会因参数漂移而抖动，对冲比率的稳定性通常明显改善。代价是对突然变化的偏斜反应变慢，需要用参数监控指标来触发重新估计。

## 七、局限与落地建议

第一，本文用的是单一到期日的横截面，没有处理不同到期日之间的平滑性；第二，报价噪声被建模成同方差，真实期权链的深度流动性差异会让虚值端噪声更大，此时应在最小二乘里按买卖价差加权；第三，SVI 的翼部按 |k| 线性增长，总方差无界，超出报价区间做远翼外推要极度小心——加一层 Wing 约束或只在数据区间内使用。

落地时我建议按顺序做四件事：先把报价统一到远期和同一计息基准；再用 SVI 拟合并检查 g(k)；然后把样条版本作为对照跑一遍套利检测，让交易员直观看到差别；最后把参数随时间的变化画出来监控，rho 和 sigma 的跳变往往先于市场事件出现。具体来说，rho 快速变负意味着看跌翼突然变贵，通常对应避险需求抬升；sigma 收缩说明微笑顶点变尖，近月事件驱动的成分在加重；m 的系统性平移则反映偏斜中枢的迁移。把这些参数当作状态变量而不是静态拟合产物，SVI 就不只是一张曲面，还能成为市场情绪的低维传感器。当然，参数的时间序列本身也有噪声，监控时应对照本文第六节给出的标准差量级设阈值，避免把正常采样波动误读成信号。
