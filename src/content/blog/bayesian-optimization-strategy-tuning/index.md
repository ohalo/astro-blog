## 一、结论先行

量化策略调参有个尴尬的现实：每跑一次回测都要遍历几千天数据，参数一多，网格搜索的格子数指数爆炸；但用随机搜索又总觉得"没搜到位"。贝叶斯优化把回测当成黑箱函数，用高斯过程（GP）建一个代理模型，再用采集函数决定下一个该试哪组参数。

本文不是教程式的"BO 一定更好"，而是用真值已知的合成市场把三种方法放在同样的 36 次评估预算下对拍，四条结论：

1. **同样 36 次评估，BO 找到最好的参数，而且更稳。** 6 个随机种子下，BO 平均最好训练 Sharpe 1.7843，标准差 0.0095；6×6 网格 1.7768；随机搜索 1.7308±0.0351。稠密网格（25×17 个格子）的天花板是 1.8116，BO 达到它的 98.5%。
2. **样本外才有意义，BO 依旧领先。** 在另一条独立的 8000 天路径上，BO 选出的参数平均 Sharpe 1.8903±0.0351，网格 1.8729，随机 1.8406±0.0729。随机搜索有一个种子样本外跑到 1.980，但它的离散度是 BO 的两倍——"偶尔更好"不等于"方法更好"。
3. **达到 90% 天花板所需评估次数差距明显。** BO 中位数 6.5 次、随机 8 次、网格 20 次。真正的收益在节省回测次数，而不是最后那 0.01 的 Sharpe。
4. **GP 超参数的边界能决定成败。** 长度尺度上界设成 exp(1)=2.72 时，GP 学到几乎线性的曲面，EI 退化成乱试：BO 平均 1.7119，反而输给随机搜索的 1.7308。把长度尺度限制在 0.8 以下，BO 才回到 1.7843。这是一个真实的踩坑记录，不是理论上的边角情况。

## 二、实验设计：一个知道答案的黑箱

要公平比较调参方法，必须知道"正确答案"，否则只是比谁运气好。本文构造一个两参数均值回复策略：

- 一条 OU 对数价格路径 x（φ=0.98、日波动 0.008），它本身有已知的真实均值回复窗口 60 天；
- 下一步收益里埋入由**真实 60 天信号**驱动的可预测成分：r(t+1) = -0.0008·z60(t) + ε(t)，ε 独立同分布；
- 策略参数只有两个：滚动窗口 lookback（10~250 天）与入场阈值 entry（0.3~2.5），用 z 分数反向持仓，单笔换手成本 3bp。

于是"最优参数"在真值附近（lookback 应接近 60，阈值要平衡信号强度与换手），但三种调参方法都只看到 Sharpe 这个标量输出，不知道内部结构。训练和测试是两条不同随机种子的 8000 天路径，用来检验过拟合。

回测函数用前缀和把滚动均值/标准差降成 O(N)，这是让 400 多次评估几秒内跑完的关键：

```python
def rolling_mstd(x, w):
    c1 = np.concatenate([[0.0], np.cumsum(x)])
    c2 = np.concatenate([[0.0], np.cumsum(x*x)])
    m = (c1[w:] - c1[:-w]) / w
    s = np.sqrt(np.maximum((c2[w:] - c2[:-w]) / w - m*m, 1e-14))
    return m, s

def sharpe(path, lookback, entry, cost=3e-4):
    x, r = path
    lb = int(round(lookback))
    m, s = rolling_mstd(x, lb)
    z = (x[lb-1:] - m) / s
    pos = np.zeros_like(z)
    pos[z > entry] = -1.0
    pos[z < -entry] = 1.0
    pnl = pos[:-1]*r[lb:] - cost*np.abs(np.diff(np.concatenate([[0.0], pos[:-1]])))
    return np.sqrt(252)*pnl.mean()/pnl.std()
```

## 三、GP 代理与期望改进

把两个参数归一化到 [0,1]²，lookback 用对数刻度（10~250 天），阈值用线性刻度。GP 用 RBF 核加白噪声，三个超参数（两个长度尺度、观测噪声）通过对数边缘似然的最大化估计：

$$C_{ij}=\sigma_f^2\exp\left(-\frac12\sum_d\frac{(u_i^{(d)}-u_j^{(d)})^2}{\ell_d^2}\right)+\sigma_n^2\delta_{ij}$$

采集函数用期望改进 EI：

$$\mathrm{EI}(u)=\mathbb E[\max(f(u)-f_{\mathrm{best}},0)]=(\mu-f_{\mathrm{best}})\Phi(z)+\sigma\varphi(z),\quad z=\frac{\mu-f_{\mathrm{best}}}{\sigma}$$

实现上注意两点：一是 Cholesky 分解后缓存，每次迭代只解一次三角方程；二是候选点用固定种子生成 2048 个，让三种方法的随机性只来自初始点，不从候选池再引入一层噪声。

采集函数的选择也有讲究。EI 在高斯假设下有闭式解、数值稳定，是默认选项；改进概率 PI 更保守，倾向在已经不错的点附近继续压榨；UCB 则通过调大置信上界的系数显式控制探索强度。如果目标评估非常昂贵且噪声大，UCB 往往比 EI 更早找到可行参数；如果每次评估便宜且想要最后一次收敛到精确最优，PI 的后期表现更稳。本文全程用 EI，没有在六个种子上调采集函数——否则"BO 赢了"就可能只是又一层过拟合。

```python
def ei(gp, Xs, yb):
    mu, sd = gp_pred(gp, Xs)
    z = (mu - yb - 1e-6) / sd
    return (mu-yb-1e-6)*norm.cdf(z) + sd*norm.pdf(z)

for k in range(6, 36):
    gp = gp_fit(X, y)                                  # 重新拟合代理
    u = CAND[np.argmax(ei(gp, CAND, y.max()))]         # 采集函数选点
    y = np.append(y, f(u)); X = np.vstack([X, u])      # 跑一次真实回测
```

每轮都要重新拟合 GP，这是 BO 的主要计算开销；但相对于一次回测遍历 8000 天，几十次 37×37 矩阵的 Cholesky 分解几乎可以忽略。

## 四、结果：赢在哪里，输在哪里

稠密网格（25 个 lookback × 17 个阈值）给出的天花板是训练 Sharpe 1.8116，最优 lookback 57.4 天、阈值 0.7125，非常接近埋进去的真值 60 天——说明实验设计本身是有效的。

6×6 网格（36 次评估）最好 1.7768，落在 lookback 60.3 天、阈值 0.74；随机搜索 6 个种子平均 1.7308±0.0351；BO 平均 1.7843±0.0095。注意 BO 的标准差只有随机搜索的 27%，这才是工程上最值钱的性质：交付给别人的调参结果不该靠运气。

样本外的结果更有意思。BO 选出的参数在独立路径上平均 1.8903±0.0351，网格 1.8729，随机 1.8406±0.0729。随机搜索最好的一次样本外达到 1.980，高于任何 BO 种子；但同一个方法另一次只有 1.753。把单次结果当方法优劣的证据，是调参评估里最常见的错误。

## 五、翻车现场：长度尺度上界

第一版实验里，GP 超参数的对数长度尺度上界设成 1（即长度尺度最大 2.72，覆盖了整个归一化定义域）。结果 6 个种子下 BO 平均最好训练 Sharpe 只有 1.7119，样本外 1.7997，**双双输给随机搜索**。诊断时发现某个种子的拟合长度尺度恰好顶在上界 2.71828——GP 认为目标几乎是线性的，于是 EI 的"探索"项主导，选点接近随机。

把两个长度尺度的上界收到 exp(-0.22)≈0.8（即 GP 至少要能分辨定义域内五分之一的局部变化），BO 立刻回到 1.7843。教训很直接：**BO 不是免调参的**。当函数曲面只有一个中等宽度的峰时，允许 GP 变得太平滑，就等于主动放弃代理模型的优势。实务中更稳妥的做法是给长度尺度设一个与目标峰宽同量级的先验区间，或者直接用 Matérn 5/2 核对 RBF 的结果。

## 六、边界与建议

这套方法的前提是目标函数"可评估但昂贵"。如果你的回测只要 0.1 秒，直接暴力网格更省心；如果参数超过十维、每次评估要几分钟，BO 的收益会更大，但 GP 本身也会开始吃力（此时可考虑 TPE 或随机森林代理）。

另一个必须说清的限制是噪声：本文的 Sharpe 是固定路径上的确定性函数，真实调参里每次回测还叠加数据噪声与随机初始化。此时应在 GP 里显式建模同一点的重复观测方差，并使用噪声稳健的 EI（如取多次观测均值）。否则 BO 会把回测噪声当成真实结构，收敛到一条只在训练路径上好看的参数——图 3 里那些"训练很高、样本外很低"的点就是这个问题的最小版本。

最后，调参只应满足一个有限预算下的搜索目标，不能替代样本外的策略验证。本文所有样本外数字都来自独立生成的 8000 天路径，而不是同一条数据切最后 20%——后者在策略研究中太容易被无意中"看"过而失去独立性。

还有一个实务问题值得单独说：搜索空间怎么定义。lookback 用对数刻度而不是线性刻度，是因为参数从 10 天翻倍到 20 天的影响，远大于从 190 天到 200 天的影响；在线性刻度上，GP 会把大部分长度尺度浪费在高 lookback 区间，等效样本数反而变少。同样的道理适用于阈值、手续费、止损比例这类跨数量级的参数。搜错空间比搜错算法更常见：如果真最优在区间边界上（比如本文把上界设成 250 天时，旧设定的最优就死死顶在边界），无论 BO 还是网格都找不到更好的点，第一反应应该是扩展边界而不是换算法。
