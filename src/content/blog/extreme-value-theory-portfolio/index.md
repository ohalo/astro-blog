风控里最贵的错误，往往不是算错数字，而是用错了分布族。

如果你用正态分布去算 99.9% 的 VaR，你得到的是一个漂亮、稳定、可复现的数字——然后它在真正的危机里系统性低估风险。原因很简单：正态分布是薄尾的，它的密度以指数速度衰减，而真实市场的亏损以幂律速度衰减。尾部差的这一点，在日常 99% 分位看不出来，到了 99.9% 就是致命的。

本文要讲的极值理论（Extreme Value Theory，EVT）就是专门为解决这件事而生的一套数学工具。它不试图拟合整条分布，而是**只关心尾巴**，并且有严格的极限定理撑腰。我们会看到，在一个已知真值的厚尾数据集上，正态模型把 99.9% VaR 低估了 40%，而 EVT 把误差压到了 0.4% 以内。

## 一、两种建模尾部的方式：块最大值与超阈

EVT 有两条主流路径。

第一条叫**块最大值法**（Block Maxima）。把数据切成若干块（比如每年一块），取每块的最大值，这些最大值服从广义极值分布（GEV）。Fisher-Tippett-Gnedenko 定理保证了这一点。但它的代价是浪费数据——5000 天里你只留下几十个年度最大值，尾部信息大量丢失。

第二条叫**超阈值法**（Peaks Over Threshold，POT）。设定一个阈值 u，把所有超过 u 的样本单独拿出来。Pickands-Balkema-de Haan 定理告诉我们：当阈值足够高时，超阈损失（减去 u 之后）的条件分布会收敛到**广义帕累托分布**（Generalized Pareto Distribution，GPD）。这条路径用到了所有尾部样本，是近年风控实践的主流选择，本文聚焦它。

GPD 的累积分布函数只有一个形状参数 xi 和一个尺度参数 sigma：

```
G(x) = 1 - (1 + xi * x / sigma)^(-1/xi)      xi != 0
G(x) = 1 - exp(-x / sigma)                    xi = 0
```

xi 是整篇文章的灵魂。它决定尾巴的厚度：xi 越大，尾部越厚；xi ≥ 0.5 时方差发散，xi ≥ 1 时连期望都不存在。对我们做风控的人来说，xi 就是"极端亏损有多极端"的那个旋钮。

## 二、从 GPD 到 VaR：尾部外推的公式

设总样本数 n，超过阈值的样本数 Nu，则 ζ = Nu/n 是超过阈值的经验概率。对任意高分位 p（比如 0.999），只要 p > F(u)，POT 给出的 VaR 估计是：

```
VaR(p) = u + (sigma / xi) * [ ((1 - p) / ζ)^(-xi) - 1 ]
ES(p)  = (VaR(p) + sigma - xi * u) / (1 - xi)          (要求 xi < 1)
```

这两个公式就是 POT 的全部魔法所在。注意 `(1-p)/ζ` 这一项：它把"我们要估计的尾部概率"和"样本里实际观测到的尾部概率"做比值，再用 xi 做幂次外推。当 p 很极端（1-p 远小于 ζ）时，历史模拟法根本没几个样本可用，而 GPD 借这个幂律关系把曲线平滑地延伸了出去。

这里有个容易写错的地方：指数是**负的** xi。我在第一次实现时就写反了符号，结果 VaR 算出来是负数——一个明显的 sanity check 就能抓住它。写数值代码时，务必用一个已知分布验证公式的方向。

## 三、实验设计：在已知真值的数据上验身

空谈定理没意义，我们要在真值已知的数据上检验方法。数据生成过程如下：

- 从自由度 df=4 的学生 t 分布抽 5000 个随机数，标准化到日波动 1.2%，取负号当作"每日亏损"。
- 学生 t(df) 的理论尾部形状参数恰好是 xi = 1/df = 0.25，这是我们的真值参考。
- 另外抽 50 万个样本当作"真实分布"，用来计算 99% / 99.5% / 99.9% 的真 VaR 与 ES。

阈值取亏损的 95% 分位数，得到 u = 1.7923%，超阈样本 Nu = 250 个（ζ = 0.05）。对这 250 个超阈损失（减去 u）做 GPD 的极大似然估计。

结果是：xi 估到 0.2070，sigma 估到 0.7238%，修正尺度 sigma - xi·u = 0.3529%。xi 的估计 0.2070 比理论值 0.25 偏低约 17%——这是有限样本的常态，250 个尾部点估形状参数本就很吃紧，后面我们会专门讨论这个不确定性。KS 拟合优度检验 D = 0.0419、p = 0.7563，说明 GPD 与超阈样本没有显著偏离，拟合是可信的。

![GPD 对超阈损失的拟合诊断](/images/extreme-value-theory-portfolio/evt-gpd-fit.png)

左图是 QQ 图，经验分位数贴着理论线走；右图把超阈损失的经验密度和拟合出的 GPD 密度叠在一起，形状吻合得不错。

## 四、VaR 对决：正态输得有多惨

现在到了关键环节。我们把四种方法放在同一张表里：真值（50 万样本）、正态假设、历史模拟、GPD。单位都是亏损百分比。

| 分位 | 方法 | VaR | ES |
|------|------|-----|-----|
| 99% | 真值 | 3.177% | 4.460% |
| 99% | 正态 | 2.779% | 3.186% |
| 99% | 历史 | 3.295% | 4.437% |
| 99% | GPD | 3.175% | 4.448% |
| 99.5% | 真值 | 3.934% | 5.413% |
| 99.5% | 正态 | 3.078% | 3.458% |
| 99.5% | 历史 | 3.900% | 5.279% |
| 99.5% | GPD | 3.927% | 5.397% |
| 99.9% | 真值 | 6.181% | 8.206% |
| 99.9% | 正态 | 3.696% | 4.028% |
| 99.9% | 历史 | 5.528% | 8.382% |
| 99.9% | GPD | 6.154% | 8.205% |

结论一目了然。正态模型在 99.9% 分位只给出 3.696% 的 VaR，而真值是 6.181%——**低估了 40%**。ES 更离谱，真值 8.206%，正态只给 4.028%，几乎腰斩。这就是为什么 2008 年那么多用正态 VaR 的机构被打了个措手不及：模型不是在小数点上出错，而是在结构上就错了。

历史模拟法在 99% 和 99.5% 表现不错（5000 个样本里分别有 50 个和 25 个点可用），但到了 99.9% 只剩下 5 个点，估计开始发飘，VaR 低估 11%。ES 反而高估——因为少数几个极端点被平均进去了，波动很大。

GPD 全程稳定：99.9% 的 VaR 误差只有 -0.4%，ES 更精确到 8.205% 对 8.206%，几乎分毫不差。在 99.5% 分位，GPD 的 VaR 偏差只有 -0.2%，而正态是 -21.7%。

三张子图从左到右是 99%、99.5%、99.9%。看最后一张：正态那根橙色柱子明显矮一大截，而 GPD 的绿色柱子和真值的深蓝柱子几乎等高。

## 五、阈值的选取：稳定性诊断不能省

POT 方法最容易被质疑的一点就是：阈值 u 到底怎么选？选高了样本太少，选低了偏离渐近理论。实践中没有唯一的正确答案，但有标准的诊断工具。

第一张是**参数稳定性图**：把阈值从 88% 分位一路扫到 99% 分位，每个阈值重新估一次 xi 和修正尺度 sigma*。如果 GPD 假设成立，xi 应该在一个水平带附近波动，修正尺度也应该基本稳定。我们的数据里 xi 在 0.17 到 0.30 之间起伏，中位数附近集中在 0.21 左右，与理论值 0.25 在同一量级——偏低但方向正确。

第二张是 **Hill 估计**：直接取最大的 k 个次序统计量，用 `xi_H = mean(log(top k)) - log(k-th largest)` 估计形状参数。Hill 对 k 很敏感，但它在一段中间区域应该给出平台。

![尾部指数的阈值与阶数稳定性](/images/extreme-value-theory-portfolio/evt-threshold-stability.png)

左图 GPD 的 xi 随阈值扫描，红色虚线是理论值 0.25；右图 Hill 估计随 k 的变化。两个诊断共同支持"这是厚尾、xi 在 0.2 上下"的判断。

我的经验是：不要迷信单一阈值点估计，务必看稳定性图。如果 xi 随阈值剧烈漂移，说明数据可能不是单一幂律尾部，或者样本量根本不够——这时候报告一个带区间的结论，比报一个虚假精确的数字诚实得多。

## 六、可运行代码

下面这段是本次实验的核心。用 scipy 的 `genpareto.fit(..., floc=0)` 做 MLE，注意 location 固定在 0（因为我们对"超阈部分"建模）。

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(2024)
n = 5000
raw = rng.standard_t(4.0, size=n)      # 自由度 4 的厚尾
raw /= raw.std(ddof=1)
losses = -(raw * 0.012)                  # 每日亏损，波动 1.2%

# 1) 阈值与超阈样本
u = np.quantile(losses, 0.95)
exc = losses[losses > u] - u
zeta = len(exc) / n                      # = 0.05

# 2) GPD 极大似然估计
xi, _, sigma = stats.genpareto.fit(exc, floc=0)
print(f"xi={xi:.4f}, sigma={sigma:.4%}")  # 0.2070, 0.7238%

# 3) 尾部外推：VaR 与 ES
def pot_est(p):
    var = u + (sigma / xi) * (((1 - p) / zeta) ** (-xi) - 1)
    es = (var + sigma - xi * u) / (1 - xi)
    return var, es

print("VaR99.9%, ES99.9% =", pot_est(0.999))  # (0.06154, 0.08205)

# 4) 拟合优度检验
D, pval = stats.kstest(exc, lambda x: stats.genpareto.cdf(x, xi, 0, sigma))
print(f"KS D={D:.4f}, p={pval:.4f}")          # p=0.7563
```

## 七、EVT 的边界与诚实提醒

EVT 很强，但不是万能的，有几个前提必须讲清楚。

第一，**独立性假设**。经典 POT 理论假设超阈事件相互独立。金融收益率有波动聚集，极端亏损往往扎堆出现。实践中的标准做法是做 declustering——把连续几天内的超阈点合并成一个"簇"事件，只用簇最大值拟合。本文为聚焦原理用了简化处理，真实风控中这一步不能省。

第二，**xi 的估计不确定性**。我们的 xi 估到 0.2070，理论是 0.25，差了 17%。尾部形状参数天生素材有限，250 个超阈点就算不错了。所以报告 VaR 时最好给出置信区间，或者用不同的阈值/方法（GPD、Hill、矩估计）交叉验证，而不是只报一个数。

第三，**ES 要求 xi < 1**。如果 xi ≥ 1，期望都不存在，ES 公式失效。真遇上这种极端厚尾（一些高频或加密货币数据），要退回更稳健的风险度量。

第四，**历史不会简单重演**。EVT 外推的是"同一分布下更极端分位"的行为，它假设未来还服从今天这条幂律。结构性断裂（监管变化、新交易机制）会让这个假设失效。任何尾部模型都要配合压力测试和专家判断。

## 小结

极值理论把"给极端亏损定价"这件事从拍脑袋变成了一门有定理支撑的技术。我们看到：正态分布因为薄尾假设，在 99.9% 分位把 VaR 低估了 40%、ES 腰斩；历史模拟在尾部样本太少时开始发飘；而 POT + GPD 借幂律外推，把 VaR 误差压到 0.4%、ES 误差压到 0.01% 以内。

但请记住那个 0.2070 对 0.25 的差距——EVT 给了你一把锋利的尺子，这把尺子本身也有刻度误差。真正专业的做法，是连同阈值稳定性图、多种估计方法的交叉验证、以及不确定性区间一起呈现，而不是拿一个精确到小数点后三位的数字去假装确定。

**关键数值一览**：阈值 u=1.7923%（95% 分位），超阈样本 250 个；xi=0.2070（理论 0.25），sigma=0.7238%，KS p=0.7563；99.9% VaR 真值 6.181% / 正态 3.696%（-40%）/ 历史 5.528% / GPD 6.154%（-0.4%）；99.9% ES 真值 8.206% / GPD 8.205%。
