上一篇用 KDE 做 regime 概率映射，前提是"你已经有了 regime 标签"。标签哪来的？大多数人是拍阈值：波动率 > 25% 算恐慌。这篇去掉这个前提——**让模型自己数出市场有几个态、每个态长什么样**。工具是高斯混合模型（GMM）+ EM 算法：假设每天的特征向量（日收益、波动代理）都是从 $K$ 个高斯之一抽出来的，抽到哪个的概率由权重 $\pi_k$ 决定。模型的职责是反推 $(\pi_k, \mu_k, \Sigma_k)$。

GMM 与 k-means 的区别就一个字：**软**。k-means 把每个点硬性判给最近的簇，且默认簇是球形；GMM 给每个点发一张"成分清单"——这个交易日 73% 属于常态、26% 属于恐慌、1% 属于平静——并且每个分量自带椭球形协方差，能贴合"恐慌态又长又瘦"的真实形状。

结论先行（全部现场计算）：

**① 软标签 + 椭圆形状值 34 个百分点。** 3000 天三态合成市场，GMM 对真 regime 的恢复准确率 **96.4%**，k-means 硬聚类只有 **62.0%**——恐慌态的特征云沿波动轴拖得老长，球形簇切不动它。

**② EM 的招牌保证是真的。** 三组病态初始（初始 σ = 0.05 近塌缩 / 0.5 / 3.0 过胖），对数似然 120 迭代**逐次只增不减**，一次违反都没有。

**③ 该分几个态，BIC 替你做主。** K=1..6 扫描：BIC 依次 13963.9 / 11161.8 / **10358.2** / 10384.0 / 10399.8 / 10435.4，最低点在 **K=3**——与真值一致。

**④ regime 不是好看，是有钱的。** 1200 天 Markov 时序上软标签与真 regime 一致率 97.4%；恐慌态次日波动均值 2.28%（n=51），平静态 0.64%（n=796）；"恐慌态概率 > 0.5 就空仓"使 Sharpe 从 −0.33 升到 **0.33**，最大回撤从 −24.4% 收窄到 **−18.4%**。

**⑤ 恶疾实拍：分量塌缩。** 让一个分量贴着最密点、σ=0.001 出生，无正则化时它的 σ 一路滑向 1e-9、对数似然持续上冲；σ 下限 0.05 可兜住。

## 一、EM 在做什么：猜测—认领—重估

GMM 的对数似然是 $\sum_t \log \sum_k \pi_k \mathcal N(x_t \mid \mu_k, \Sigma_k)$——log 里套 sum，直接最大化没有闭式解。EM 曲线的思路是交替两件事：

- **E 步（认领）**：给定当前参数，算每个点属于每个分量的责任度 $\gamma_{tk} = \dfrac{\pi_k \mathcal N(x_t;\mu_k,\Sigma_k)}{\sum_j \pi_j \mathcal N(x_t;\mu_j,\Sigma_j)}$；
- **M 步（重估）**：把 $\gamma$ 当"软权重"，加权重算 $\pi_k = \bar\gamma_k$、$\mu_k = \sum_t \gamma_{tk} x_t / \sum_t \gamma_{tk}$、$\sigma_k^2 = \sum_t \gamma_{tk}(x_t-\mu_k)^2 / \sum_t \gamma_{tk}$。

循环直到 $\gamma$ 不再变化。理论保证：**每轮 E→M，对数似然单调不减**（Jensen 不等式的直接推论）。下面是逐维对角协方差的完整 numpy 实现（数值稳定全靠 log-sum-exp）：

```python
import numpy as np
import itertools

def logsumexp(a, axis):
    m = np.max(a, axis=axis, keepdims=True)
    return (np.squeeze(m, axis) + np.log(np.exp(a - m).sum(axis))).ravel()

def em(X, K, seed, sd_floor=1e-6, iters=300):
    r = np.random.default_rng(seed)
    mu = X[r.choice(len(X), K, replace=False)].copy()
    sd = np.full((K, X.shape[1]), X.std(0)*0.8); w = np.full(K, 1/K)
    lls = []
    for it in range(iters):
        sd = np.maximum(sd, sd_floor)                      # 防塌缩下限
        # E 步：逐维高斯 log-density，求和后过 logsumexp
        z = -0.5*((X[:, None, :] - mu[None])/sd[None])**2 \
            - np.log(sd[None]) - 0.5*np.log(2*np.pi)
        lz = z.sum(2) + np.log(w)[None]
        lse = logsumexp(lz, axis=1); ll = lse.sum(); lls.append(ll)
        g = np.exp(lz - lse[:, None])                      # 责任度 γ
        # M 步：按 γ 加权重估
        Nk = g.sum(0) + 1e-12; w = Nk/len(X)
        mu = (g[:, :, None]*X[:, None, :]).sum(0)/Nk[:, None]
        sd = np.sqrt((g[:, :, None]*(X[:, None, :] - mu[None])**2)
                     .sum(0)/Nk[:, None])
    return w, mu, sd, g, np.array(lls)
```

## 二、合成考场：真值已知，看谁能把三态捞出来

## 四、K 是超参数：让 BIC 在 K=1..6 里竞标

分 2 个态还是 5 个态？对数似然永远偏爱更大的 K（多一个分量总能挤多一点拟合），所以要 penalize。BIC $= -2\overline{\mathrm{LL}} \cdot n + p \ln n$，参数量 $p = 7K - 1$（权重 K−1、均值 2K、方差 2K）。每个 K 用多组初始各跑 250 轮取最优：

![BIC 模型选择](/images/gaussian-mixture-regime-classification/fig3_bic_selection.png)

BIC 曲线：K=1 的 13963.9 一路跌到 K=3 的 **10358.2** 后反弹（10384.0 / 10399.8 / 10435.4）——**谷底恰好是真值 K=3**。从 K=3 跨到 K=4，拟合只多赚约 12.6 nats 对数似然（−2·LL 从 10211.9 降到 10186.6），复杂度罚单却要多付 7·ln 1500 ≈ 51，净 BIC 反超 25.8，模型复杂度自动封顶。注意 BIC 挑 K 的前提是每个 K 都跑够多初始、取各自最优 LL，否则随机初始化的坏收敛会污染竞标结果。

## 六、成名恶疾：分量塌缩（一个分量吃掉一个点）

GMM 的对数似然有个著名的无底洞：若某分量 $\mu_k$ 恰落在一个样本点上、$\sigma_k \to 0$，该点对似然的贡献 $\to +\infty$。我们故意把一个分量按在最密点、σ=0.001 出生：

![分量塌缩与正则化](/images/gaussian-mixture-regime-classification/fig5_degenerate.png)

左图：无下限版（红）的对数似然还在以每迭代约 +8 的斜率爬坡（120 轮后 −11038，仍未收敛），右图坐实了病因——其最小 σ 已滑到 1e-9 的机器地板。绿线是加了 **σ 下限 0.05** 的正规版，120 轮稳定在 −10262。**体检指标就一条：监控全体分量最小 σ 是否一路归零**；药也便宜：`sd = np.maximum(sd, sd_floor)` 一行，或给 $\pi_k$ 设最小权重。EM 对初始值敏感（可能落在局部最优），实战标配是多组随机初始 + 取似然最高者——本文所有 fit 都是 6–9 组初始里选冠军。

## 七、使用手册（踩坑清单）

1. **特征选 (收益, 波动代理) 这类"形状可分"的量**，别只丢收益——三态在收益轴上重叠，纯收益几乎分不开；
2. **对角协方差是安全默认**，点少时全协方差容易过拟合；要建模相关就加正则；
3. **σ 下限必须设**，没有下限的 EM 迟早遇到塌缩（本篇实拍了它一路奔向 +∞ 的样子）；
4. **K 用 BIC 选**，且每个 K 多初始化；
5. **标签要配置换对齐**，"分量 2"没有身份，身份是你按波动中心排出来的；
6. 事后标签（本篇）之外在线更新要防 look-ahead：用截至当天的数据滚动重估，或上 HMM（给 regime 装上转移矩阵的"未来会怎样"）。
