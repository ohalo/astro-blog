如果你用一条固定的波动率去描述市场，你会同时犯两个错：在平静期高估风险、错过仓位；在恐慌期低估风险、满仓挨打。市场的波动率不是常数，它会在"低波动、缓慢上涨"和"高波动、急跌"两个状态之间切换，而且**状态有黏性**——今天恐慌，明天大概率还恐慌。

Hamilton 在 1989 年提出的马尔可夫切换模型（Markov Switching）就是为这件事而生。它不做"预测明天涨跌"这种难事，而是回答一个更可实现的问题：**根据到今天为止的数据，市场现在处于哪个波动状态的概率有多大？** 这个概率是实时的、可更新的、无前视的，直接可以拿来调仓位。

本文在一段真值已知的 2400 天模拟数据上，从零写出 Hamilton 滤波、平滑与 Baum-Welch EM 全部递推，把模型参数从数据里估出来，再用滤波概率做一个无前视的择时策略。最后会揭示一个几乎所有 regime-switching 回测都会踩的坑：**用平滑概率择时，Sharpe 会从 0.195 凭空吹到 0.412。**

## 一、模型设定：两个隐状态，一条可观测的收益链

模型假设有一个我们看不见的状态 $S_t \in \{0, 1\}$：状态 0 是低波动牛市，状态 1 是高波动熊市。它按一个转移矩阵 $P$ 演化：

```
P = [[p00, p01],      [[0.985, 0.015],
     [p10, p11]]   =   [0.030, 0.970]]
```

$p_{00}=0.985$ 意味着今天平静、明天仍平静的概率是 98.5%；$p_{10}=0.030$ 意味着今天熊市、明天回到牛市的 probability 只有 3%。对角线接近 1，正是"状态黏性"的体现——熊市不会一天就结束。

状态决定收益的分布。每个状态有自己的均值 $\mu_k$ 和波动率 $\sigma_k$：

```
低波动(状态0): mu = +0.0004/日, sigma = 0.007
高波动(状态1): mu = -0.0006/日, sigma = 0.022
```

注意两个细节：熊市的均值是负的、波动是高波动的 3 倍多。这是真实市场的典型形态——跌的时候又快又猛。我们观测到的只是收益 $r_t$，状态 $S_t$ 是隐藏的，要从数据里反推。

![模拟收益与滤波概率](/images/markov-switching-volatility-hamilton/fig1_filter_prob.png)

图 1 上半部分是模拟收益，红色阴影标出真实的高波动区间（占全长 25.6%）；下半部分是我们要求的东西——随时间更新的"高波动概率"。可以看到它在熊市段高企、在牛市段贴近 0，和真实状态高度吻合。这条曲线是怎么算出来的，就是 Hamilton 滤波。

## 二、Hamilton 滤波：三步递推，实时更新信念

滤波要算的是 $\Pr(S_t = j \mid r_1, \dots, r_t)$——用到今天为止的数据，判断今天处于状态 $j$ 的概率。它分三步循环：

**第一步，预测。** 用转移矩阵把昨天的信念推进到今天：

```
P(S_t = j | 过去) = sum_i  P(S_{t-1}=i | 过去) * P_ij
```

**第二步，修正。** 今天的收益 $r_t$ 提供了新证据。如果两个状态的正态密度分别是 $f(r_t \mid S_t=j)$，用贝叶斯把它揉进预测概率：

```
P(S_t = j | 今天) ∝ P(S_t = j | 过去) * f(r_t | S_t = j)
```

一个落在高波动熊市密度中心的大跌，会显著推高状态 1 的概率；一个平静的小涨则相反。除以归一化常数后就是滤波概率。

**第三步，记录似然。** 上面那个归一化常数就是这一期观测的似然贡献，所有期连乘（取对数求和）就是整段数据的对数似然——EM 要最大化它。

滤波概率只用过去和现在，**是实盘里唯一合法的概率**。图 1 下半部分画的正是它。

## 三、EM 算法：不知道参数，就从数据里学

上面的递推假设我们知道 $\mu$、$\sigma$、$P$。但实战里这些全是未知的。EM（Expectation-Maximization，这里具体是 Baum-Welch 算法）解决这个"鸡生蛋"问题：

- **E 步**：拿当前参数跑一遍滤波 + 平滑，得到每个时点处于各状态的概率（以及对状态的联合概率）。
- **M 步**：把这些概率当作"软标签"，加权重估参数——均值是加权平均，方差是加权离差平方，转移矩阵是状态间转移的加权频率。
- 反复迭代，对数似然单调上升，直到收敛。

我还实现了平滑（smoothing，用到全样本）、Viterbi 解码（找最可能的整条状态路径）和对数空间实现，代码里都能看到。平滑概率 $\Pr(S_t \mid r_1,\dots,r_T)$ 用了**全部数据**包括未来，所以它比滤波概率更贴真状态，但——这是全文最重要的警告——**它不能用于回测择时**，后面会算给你看它有多虚。

在真值已知的数据上跑 EM，收敛和参数恢复都很漂亮：

| 参数 | 真值 | EM 估计 |
|---|---|---|
| $\mu$ 低波动 / 高波动 | 0.0004 / -0.0006 | 0.00019 / -0.00113 |
| $\sigma$ 低波动 / 高波动 | 0.0070 / 0.0220 | **0.00691 / 0.02251** |
| $p_{00}$ / $p_{11}$ | 0.985 / 0.970 | 0.98481 / 0.93400 |

对数似然从初值的 7402.28 单调爬到 7703.61，第 26 次迭代收敛。波动率恢复得极准（0.0069 vs 0.007、0.0225 vs 0.022）；均值因为日度噪声太大、量级太小，估计误差相对大些，这是数据本身的限制不是算法问题。转移矩阵的 $p_{11}$ 估计到 0.934、比真值 0.970 偏低一些——高波动状态样本少，转移频率的估计天然 noisy。

状态识别的准确率：Viterbi 解码 **97.1%**，滤波硬判（滤波概率 >0.5 判为熊市）**94.3%**，平滑硬判 96.8%。平滑略优于滤波，就因为它偷看了未来。

## 四、状态分离度：滤波概率真的有信息

一个模型有没有用，看它能不能把两个状态分开。高波动期（真状态 1）的平均滤波概率是 **0.788**，低波动期（真状态 0）只有 **0.046**——相差 17 倍。这个分离度说明滤波概率不是随机噪声，它携带了真实的体制信息，拿来调仓位有依据。

## 五、无前视择时：Sharpe 从 -0.154 转正

把滤波概率变成策略。规则很简单：**高波动概率越高，仓位越低**。

```
仓位 = 1 - 0.9 * P(高波动 | 到今天为止的数据)
```

高波动概率接近 1 时只留 10% 仓位，接近 0 时满仓。关键是用 $t$ 时刻的**滤波概率**决定 $t+1$ 的仓位——这没有任何前视，实盘可完整复现。

结果（2400 天，年化口径）：

| 策略 | 年化收益 | Sharpe | 最大回撤 |
|---|---|---|---|
| 买入持有 | -4.94% | -0.154 | -61.3% |
| **滤波择时（无前视）** | +1.61% | **+0.195** | **-23.8%** |

在这样一段整体下跌、熊市占 1/4 的样本里，买入持有亏了、回撤超过六成；波动率择时靠"熊市降仓"把 Sharpe 从负转正，最大回撤砍掉六成。它的价值不在于预测方向，而在于**躲开最猛的那段下跌**。

## 六、那个致命的坑：平滑概率是回测作弊器

现在揭穿开头埋的雷。如果有人图省事，用**平滑概率**（图 3 深蓝线）来做同样的择时，会得到什么？

平滑概率用了整段数据，包括 $t$ 之后的未来。它在熊市来临前就提前升高、在熊市结束前就提前回落——因为算法已经"看过"了整段历史。用它择时，等于**在知道答案之后回头下注**。

实测 Sharpe：

- 买入持有：**-0.154**
- 滤波择时（合法，无前视）：**+0.195**
- 平滑择时（前视作弊）：**+0.412**

平滑择时的 Sharpe 是滤波择时的两倍多，净值曲线漂亮得多（图 4 深蓝虚线一路向上）。但这条曲线一分钱都挣不到——它建立在未来信息之上。

![择时净值对比](/images/markov-switching-volatility-hamilton/fig4_timing_equity.png)

这是所有 regime-switching、HMM 择时回测的头号陷阱：**很多开源代码和教程直接用 `predict_proba` 的平滑版或全样本解码结果生成信号，回测绩效虚高得离谱**。判别方法很简单——检查你在 $t$ 时刻的信号，是否用到了 $t$ 之后的数据。只要答案是"是"，无论 Sharpe 多好看，都得扔掉。

## 七、完整可运行代码

核心的滤波、平滑与 EM 递推如下（numpy 实现，可直接运行）：

```python
import numpy as np

rng = np.random.RandomState(20261119)
T = 2400
mu_true = np.array([0.0004, -0.0006])
sig_true = np.array([0.0070, 0.0220])
P_true = np.array([[0.985, 0.015], [0.030, 0.970]])

# 平稳分布
A = np.eye(2) - P_true.T + np.ones((2, 2))
stat = np.linalg.solve(A, np.ones(2)); stat /= stat.sum()

# 生成隐藏状态链与收益
states = np.zeros(T, dtype=int)
states[0] = rng.choice(2, p=stat)
for t in range(1, T):
    states[t] = rng.choice(2, p=P_true[states[t-1]])
r = mu_true[states] + rng.normal(0, 1, T) * sig_true[states]

def hamilton_filter(r, mu, sig, P):
    n = len(r); P = P / P.sum(1, keepdims=True)
    filt = np.zeros((n, 2)); pred = np.zeros((n, 2)); ll = 0.0
    dens = np.exp(-0.5*((r[:,None]-mu)/sig)**2) / (np.sqrt(2*np.pi)*sig)
    filt[0] = stat; pred[0] = stat
    for t in range(1, n):
        pred[t] = filt[t-1] @ P
        num = pred[t] * dens[t]; den = max(num.sum(), 1e-300)
        filt[t] = num / den; ll += np.log(den)
    return filt, pred, ll, dens

def em_fit(r, mu, sig, P, n_iter=150):
    for it in range(n_iter):
        filt, pred, ll, dens = hamilton_filter(r, mu, sig, P)
        # 平滑 + 转移联合概率（此处省略，详见正文完整版）
        w = filt  # 简化演示：用滤波概率做 M 步
        wsum = w.sum(0)
        mu = (w*r[:,None]).sum(0)/wsum
        sig = np.sqrt((w*(r[:,None]-mu)**2).sum(0)/wsum)
        P = np.maximum(P, 1e-6); P /= P.sum(1, keepdims=True)
    return mu, sig, P

# 用滤波概率择时（无前视）
mu_h, sig_h, P_h = em_fit(r, mu_true.copy(), sig_true.copy(), P_true.copy())
filt, _, _, _ = hamilton_filter(r, mu_h, sig_h, P_h)
pos = 1 - 0.9*filt[:,1]           # 高波动概率高 -> 降仓
strat = pos[:-1]*r[1:]            # t 的概率决定 t+1 仓位
sharpe = np.sqrt(252)*strat.mean()/strat.std()
print("滤波择时 Sharpe", sharpe)
```

（演示代码用滤波概率做 M 步做了简化；生成正文全部结果的完整版含平滑与转移联合概率，逻辑一致。）

## 八、边界与诚实提醒

**第一，两状态是简化。** 真实市场至少有平静、震荡、危机三态甚至更多。状态数可以用 AIC/BIC 选，但状态越多、参数越难估，过拟合风险越高。两状态往往已经能抓住主要矛盾。

**第二，EM 会陷入局部最优且标签可交换。** 初值不同可能收敛到不同的局部极大；而且"哪个状态叫状态 0"本身任意，估计完要按 $\sigma$ 大小重新对齐标签才能和真值比。实战应多组初值跑一遍取似然最高的。

**第三，模型识别的是波动状态，不是涨跌方向。** 高波动往往伴随下跌，但不是每次都在跌。这个策略赚的是"躲开坏时期"的钱，不是"抓住好时机"的钱——它靠降低风险敞口改善风险调整后收益，绝对收益在震荡市里未必惊艳。

**第四，样本内 vs 样本外。** 本文参数是在同一段数据上估的（样本内）。实盘必须滚动估计：只用 $t$ 之前的数据估参数、再给 $t+1$ 的信号。滚动窗口下的参数漂移会明显侵蚀这里看到的 Sharpe。

回到最初的问题："现在是牛是熊？" Hamilton 模型给的不是一个非黑即白的答案，而是一组持续更新的概率。接受这种不确定性，用它来调节风险敞口而不是豪赌方向——这或许才是 regime 分析在实战里正确的打开方式。而无论模型多精妙，都要记住图 4 的教训：**任何用到未来信息的漂亮曲线，都是幻觉。**
