蒙特卡洛是量化工作的默认工具：路径依赖期权没有闭式解，上 MC；复杂组合没有解析分布，上 MC；风控要尾部分位数，还是上 MC。但朴素 MC 的误差按 **N^(-1/2)** 下降——想把误差压掉一个数量级，样本量要乘 100。方差缩减技术换的就是这个账：用你对问题的**结构知识**（哪些随机数其实在决定结果、哪个量有闭式解、稀有事件长什么样）去换样本效率。本文用两个实验把这门手艺拆开：主实验是**算术亚式期权定价**（回报取决于整条路径的平均，没有闭式解），第二实验是**稀有事件尾概率估计**（p≈1e-4，朴素 MC 直接瘫痪）。五个估计量全部 numpy 从零实现，同一参考价、同一预算下横评。

结论先放这：

**① 控制变量是王者，前提是你找得到高相关孪生。** 算术亚式和几何亚式的回报相关系数 ρ=0.9991，用有闭式解的几何亚式做控制变量，方差缩减 546×，几乎贴住理论极限 1/(1−ρ²)=578×。同预算下 4096 条路径的 RMSE 从 0.205 压到 0.0089。

**② RQMC 是中小样本利器，但别迷信渐近速率。** Sobol 低差异序列在 N=4096 时拿到 132× 方差缩减，可 12 维 + 回报带 max() 尖点，实测收敛斜率只有 −0.62，够不到 N^(-1) 那条线。

**③ 分层抽样要分对方向。** 在终端布朗值 W_T 上用 Brownian bridge 条件抽样，VR 3.9×，逼近理论极限 1/(1−R²)=4.3×——16 层就基本饱和，加层数没用。

**④ 对偶变量在这里几乎白干（2.0×）。** 它的效力靠 payoff(Z) 与 payoff(−Z) 的负相关，而亚式回报是 12 个维度的平均，配对相关性被稀释到所剩无几。

**⑤ 重要性采样是稀有事件的唯一解，但 θ 标定是生死线。** p≈1e-4 的事件，朴素 MC 在 N≤65536 时多数重复估计为 0；指数倾斜后同预算 VR 209×。但 θ 扫描显示：θ=1.0 时 VR 249×，过度倾斜到 θ=1.4 只剩 77×——似然比的二阶矩会爆炸。

## 实验设置：一个没有闭式解的目标

算术亚式看涨期权：到期收益 = max(A − K, 0)，其中 A 是存续期内 12 个月末价格的**算术平均**。标的服从 GBM，S₀=K=100，r=5%，σ=30%，T=1 年。算术平均没有闭式解（几何平均才有），MC 估计 E[payoff] 后折价。几何亚式的 Kemna-Vorst 闭式解先算出来：**价格 8.0247**（未折价期望 8.4361）——它马上会成为我们的控制变量。

用 N=2²³ 的控制变量估计量把参考价钉在 **8.4744**（RMSE 量级 1e-3），后面所有方法都对着它算误差。

```python
import numpy as np
from scipy.stats import norm

S0, K, r, sigma, T = 100.0, 100.0, 0.05, 0.30, 1.0
N_STEPS, DT = 12, 1 / 12
MU = r - 0.5 * sigma ** 2
DISC = np.exp(-r * T)

# 几何亚式闭式解（Kemna-Vorst）：监控点等距，n=12
mG = np.log(S0) + MU * T * (N_STEPS + 1) / (2 * N_STEPS)
sG2 = sigma ** 2 * T * (N_STEPS + 1) * (2 * N_STEPS + 1) / (6 * N_STEPS ** 2)
sG = np.sqrt(sG2)
d1 = (mG - np.log(K) + sG2) / sG
GEO_PRICE = DISC * (np.exp(mG + sG2 / 2) * norm.cdf(d1) - K * norm.cdf(d1 - sG))
GEO_PAYOFF = GEO_PRICE / DISC          # 未折价期望：控制变量必须同口径！

def arith_payoff(Z):                    # Z: (N, 12) 标准正态
    logS = np.log(S0) + np.cumsum(MU * DT + sigma * np.sqrt(DT) * Z, axis=1)
    return np.maximum(np.exp(logS).mean(axis=1) - K, 0.0)
```

## 对偶变量：免费的午餐，但今天菜单不对

对偶变量（antithetic variates）是最古老的技巧：每条路径 Z 配一条镜像路径 −Z，取平均。如果 payoff 关于 Z 单调，两者强负相关，配对方差大降。但亚式回报是 12 个维度的平均：镜像掉头尾、留下中间，payoff(Z) 与 payoff(−Z) 的配对相关系数被 12 维平均稀释得所剩无几。实测 **VR=2.0×**——RMSE 从 0.205 降到 0.146（N=4096），聊胜于无。教训：对偶变量的效力随「被平均的维度数」衰减，路径平均类回报（亚式、篮子、亚式互换）天然不吃这套。

## 控制变量：找一条同向的命

控制变量的逻辑：想估 X（无闭式解），找一条 Y（有闭式解）且与 X 高相关，用样本里 Y 的误差去修正 X 的误差。估计量 X̄ − β·(Ȳ − E[Y])，最优系数 β* = Cov(X,Y)/Var(Y)，方差缩减倍数的理论上限是 **1/(1−ρ²)**。

算术亚式和几何亚式是天作之合：同样 12 个监控点、同样的路径、回报只差在「平均」的方式。实测 ρ=**0.9991**，β*=1.049——理论上限 578×，实测 **546×**，48 次重复的 RMSE 从 0.205 压到 0.0089，连参考价 8.4744 都被它自己独立复现出来（误差 <0.003）。这就是控制变量的魅力：**结构找得准，两个数量级的效率白送**。

这里插一个我自己踩过的坑，值得所有做 MC 的人记住：控制变量的修正项必须**同口径**。我第一版把未折价的样本均值 Ȳ 直接去减**折过价的**闭式解 E[Y]=8.0247，参考价被系统性拉低 0.414——于是出现诡异现象：控制变量自己收敛得好好的，其他所有方法的 RMSE 却在 0.41 处集体搁浅。诊断方法很简单：**如果只有用了闭式解的方法在 decay，先怀疑参考价，不要怀疑其他估计量**。

## 分层抽样：分对方向比多加几层重要

分层抽样把样本空间切成 k 层，每层内部分别抽样再按层概率加权。切在哪？答案是**方差的主方向**。对亚式回报，终端布朗值 W_T 解释了 76.5% 的方差（R²=0.765），它就是主方向。实现上用 Brownian bridge：每层抽一个 U，定死 W_T = Φ⁻¹(U)·√T，层内其余 11 个增量自由抽样，最后减掉样本均值、加上目标终值——注意必须减**样本均值**再平移，直接钉死最后一维会得到错误的路径条件分布（我第一版就偏了 0.85）。

16 层实测 **VR=3.9×**，理论极限 1/(1−R²)=4.3×，基本吃饱。RMSE 从 0.205 到 0.106。分层的效率上限被「层内残余方差」锁死，加层数只能逼近不能突破——它适合做控制变量之外的补充，不适合当主力。

## Sobol RQMC：低维的魔法在 12 维打折

拟蒙特卡洛用确定性低差异序列（Sobol）代替伪随机数：点集在单位立方里铺得更均匀，Koksma-Hlawka 误差上界里的差异度 D_N 从 O(N^(-1/2)) 降到接近 O(N^(-1)·log^d N)。下图一目了然：同样 256 个点，Sobol 序列的每个小方格都被拜访，伪随机还在随机挖坑。

![Sobol 序列 vs 伪随机点](/images/monte-carlo-variance-reduction/qmc_vs_random.png)

实测 **VR=132×**（N=4096，48 次重复），是仅次于控制变量的亚军。但诚实的部分在斜率：log-log 拟合只有 **−0.62**，够不到 N^(-1)。原因有两个：维度到了 12（log^d 惩罚开始显形），以及 max() 尖点破坏了光滑性。RQMC 的正确定位是**中小样本的效率工具**，不是渐近神器。另外必须用加扰 Sobol（scramble）——无扰的确定性点集没法估计误差，而加扰后每个 scramble 都是无偏估计，误差棒随 scramble 数下降。

## 稀有事件：朴素 MC 的至暗时刻与重要性采样

现在换第二实验：估计 P(A > 207.0)，即算术平均突破 99.99 分位的事件，p≈**9.99e-4** 不对——**9.99e-5**（419 万条试跑只有约 42 次命中）。朴素 MC 在这里的窘境是结构性的：N=16384 时期望命中 1.6 次，多数重复估计直接是 0，误差棒比真值还大；N 加到 65536 依然多数重复为 0。

重要性采样的思路：**别在原地等稀有事件，把分布搬过去**。对每个维度的正态增量加常数 θ（指数倾斜），事件在新测度下变得常见，再用似然比 LR = exp(−θ·ΣY + nθ²/2) 把期望搬回来。θ 的选择是全文最讲究的地方，直接扫描：

| θ | 倾斜后事件概率 | VR（N=16384） |
|---|---|---|
| 0.3 | 0.3% | 61× |
| 0.6 | 3.5% | 82× |
| **1.0** | **29.2%** | **249×** |
| 1.4 | 76.9% | 77× |

**θ 扫描（选最优后全网格复核 VR=209×，估计均值 1.013e-4 vs 真值 9.99e-5，无偏性成立）**

规律很清晰：倾斜太轻，事件依然稀有，VR 上不去；倾斜太重（θ=1.4），事件概率冲到 77%，似然比的二阶矩 E_q[LR²]=exp(nθ²) 爆炸，方差反而恶化。最优点在「事件概率 20-30%」的区间——够常见到能采样，又不至于让似然比失控。这也解释了一个反直觉：**让事件在倾斜测度下「恰好典型」（概率 50%）并不是最优**，因为 A 的方差只有 76.5% 由 ΣZ 解释，剩下 23.5% 是路径形状噪声，倾斜只搬得动前者。

**组合拳才是实战答案**：RQMC 或分层打底（百倍量级），叠加控制变量（又一个量级），估计量方差可以掉到 1e-6 以下——这是风险指标（ES、CVaR、凸性风险）和复杂期权定价能跑进实时门槛的原因。但要诚实地说三件事：**第一，所有方法的效力都来自结构知识**——不知道几何亚式的闭式解就没有控制变量，不知道方差主方向就分不对层，这些知识比代码贵；**第二，维度是共同的天花板**——12 维就让 RQMC 的斜率从 −1 掉到 −0.6，高维问题请直接上 QMC+CV 或者干脆换方法；**第三，稀有事件的 IS 不是即插即用**——θ 标定错误能把 209× 变成 77×，生产环境里请把 θ 扫描写进例行程序。
