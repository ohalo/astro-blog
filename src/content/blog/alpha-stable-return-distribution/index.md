## 一、结论先行

收益分布建模里有个绕不开的事实：日收益的样本峰度远大于 3，而且样本量越大峰度越大——这不是数据脏，而是总体的四阶矩根本不存在。高斯分布把尾部强行锁成指数衰减，结果就是风险被系统性低估。

Alpha 稳定分布（stable distribution）提供了另一条路：用四个参数同时描述尖峰、肥尾和偏斜，并且天然带有可加稳定性——独立同分布稳定变量之和仍是稳定分布，只是尺度放大。代价也很直接：除了高斯（α=2）、柯西（α=1,β=0）和列维（α=1/2,β=1）三个特例，它没有可用的解析密度函数，最大似然没法写。

本文在真值已知的 8000 天合成收益上（α=1.70, β=−0.35, scale=0.010, loc=0.0003）把这套方法完整跑一遍：

1. 用**经验特征函数（ECF）**拟合四个参数，得到 α=**1.7266**、β=**−0.3992**、scale=**0.010071**、loc=0.002142，最大特征函数误差仅 **0.00251**——四个参数全部落在真值附近。
2. 高斯最大似然给出的标准差是 **2.2760%**，是稳定分布尺度参数 1.0071% 的 2.26 倍：高斯把少数极端值摊进了方差，中心反而被压平。
3. 尾部风险差距在小概率区急剧放大：真值 VaR99=**5.8657%**，ECF 拟合 **5.4774%**（偏差 6.6%），高斯 **5.2579%**；到 99.5% 分位真值 **8.4851%**，高斯只有 **5.8257%**。
4. 期望损失（ES）的差距更刺眼：ES99 真值 **13.2185%**、ECF **12.2262%**、高斯 **6.0292%（低估 54.4%）**；ES99.5 真值 20.2548%、高斯 6.5452%——**低估 67.7%**。用高斯算 ES，等于把尾部最危险的那部分直接抹掉。
5. 两个常见工具在稳定分布上会翻车：**Hill 估计**在 k=20~640 全区间给出 α∈[2.08, 2.30]，全部越过 α≤2 的理论上限；**样本峰度**随样本量从 11.0 涨到 15.6、34.8、308.9，永不收敛——它们测的不是同一个东西。
6. 好消息是可加稳定性成立：把收益按 1/5/20/50 天加总（用重叠窗口保持样本量），ECF 估出的 α 仍在 **1.6419~1.9489** 之间，形状基本不变，只有尺度按 m^(1/α) 放大。

## 二、为什么密度函数这条路走不通

稳定分布由特征函数定义。记 θ=(α,β,γ,δ)，α∈(0,2] 控制尾部厚度，β∈[−1,1] 控制偏斜，γ>0 是尺度，δ 是位置。除了三个特例，密度 f(x;θ) 只能通过数值傅里叶反演计算，而且没有闭式表达式。

后果是连锁的：最大似然目标函数 ℓ(θ)=Σlog f(xᵢ;θ) 里每个 f 都要做一次数值积分，几千个观测乘上优化器的几百次迭代，计算量直接失控；更糟的是数值密度在尾部精度差，似然面崎岖，优化器经常收敛到局部解。

特征函数则一直有解析式。对 α≠1，scipy 用的 S0 参数化下标准化特征函数为：

```
phi_std(u) = exp( -|u|^alpha * (1 - i*beta*sign(u)*Phi_Z0(u)) )
Phi_Z0(u)  = -tan(pi*alpha/2) * (|u|^(1-alpha) - 1)
```

加上位置和尺度后 φ(t) = exp(i·δ·t) · φ_std(γ·t)。密度是它的反演，但我们根本不需要反演——直接让经验特征函数去贴解析特征函数即可。

## 三、经验特征函数（ECF）估计

样本的经验特征函数是两个充分统计量的组合：

```
ecf(t) = (1/N) * sum_j exp(i*t*x_j)
       = mean(cos(t*x)) + i*mean(sin(t*x))
```

它是 φ(t) 的无偏估计，且由大数定律一致收敛。拟合思路是选一组格点 t₁..tₖ，最小化实部与虚部残差的平方和：

```
target(t) = log(ecf(t))
resid(theta) = [ Re(log_cf(theta) - target), Im(log_cf(theta) - target) ]
theta_hat = argmin ||resid(theta)||^2
```

三个工程细节决定成败：

- **格点范围**。γ 未知，先用中位数绝对偏差估个初值 γ₀=median|x−median(x)|/0.6745，再把格点取在 t∈[0.08, 1.6]/γ₀。太靠近 t=0 时各参数几乎不可辨识，太远时 ECF 因样本量有限噪声爆炸。
- **用 log 而不是直接比 φ**。直接最小化 |φ̂−φ| 在尾部（|φ|很小）几乎没有梯度，取对数后相位信息也被纳入目标。
- **参数边界**。α 限制在 [1.05, 1.99]（本文场景已知是无限方差但有限均值），β 在 [−0.999, 0.999]，避免 α→2 时退化为高斯、β→±1 时完全偏斜导致数值奇异。

本次运行结果：α=1.7266（真值 1.70，误差 +1.6%）、β=−0.3992（真值 −0.35）、scale=0.010071（真值 0.010，误差 +0.7%）、loc=0.002142（真值 0.0003）。位置参数偏差相对最大，这是稳定分布的已知弱辨识问题——位置只在靠近原点处影响相位，而那里恰恰是格点最稀疏的区域；对尾部风险几乎没影响。

## 四、尖峰与肥尾：高斯错在哪

图1 左半用对数纵轴画尾部。真实数据在 |x|>2% 的区域明显高于高斯，稳定分布拟合曲线紧贴直方图和真值；右半放大中心区域，稳定分布在 0 附近形成更尖的峰——这就是金融收益最典型的"尖峰肥尾"：极端值更多，同时中间更集中。高斯用单一方差同时描述两者，必然两头不讨好。

高斯最大似然估出的标准差是 2.2760%，是稳定分布尺度 1.0071% 的 2.26 倍。原因是高斯把那些偶发的 8%、10% 单日跌幅全摊进方差，中心区域的拟合反而变平。数值上看，把 α<2 的数据硬当高斯，得到的"波动率"本身就是一个被极端值污染的量，拿它去做 2σ、3σ 风控阈值会双重出错。

## 五、尾部风险：VaR 与 ES 的灾难性低估

把四个分布（真值、ECF 拟合、高斯、历史模拟）的损失分位数摆在一起，差异一目了然：

| 指标 | 真值 | ECF 拟合 | 高斯 | 高斯误差 |
|---|---|---|---|---|
| VaR99 | 5.8657% | 5.4774% | 5.2579% | −10.4% |
| VaR99.5 | 8.4851% | 7.9168% | 5.8257% | −31.3% |
| ES99 | 13.2185% | 12.2262% | 6.0292% | −54.4% |
| ES99.5 | 20.2548% | 18.6589% | 6.5452% | −67.7% |

历史模拟的 VaR99 是 5.7974%，跟真值只差 1.2%——在 8000 个样本、1% 分位（约 80 个尾部点）这个量级上，直接取经验分位数居然够用。但历史模拟给不出比样本最差那天更极端的损失，而稳定分布可以外推到 99.9% 甚至更高分位，这正是参数化模型的价值。

ES 的差距比 VaR 大得多，原因很直观：VaR 只关心分位点那一个值，ES 要平均分位点之外所有损失。高斯分布的尾部按 exp(−x²) 衰减，超过 3σ 后几乎归零；稳定分布是幂律衰减 x^(−α)，尾部还有可观的概率质量。分位点处两者差 10%，但把整条尾巴平均下来就差了一半以上。任何以 ES 为主要风险指标的系统（比如监管资本、期权尾部对冲）用高斯都会严重欠配资本。

样本外回测也支持这个结论：前 6000 天拟合（训练 α=1.7132），后 2000 天统计 99% VaR 突破次数。稳定分布突破 14 次，高斯突破 19 次，理论期望 20 次——两者在 1% 水平下 Kupiec 检验都通过（p=1.0），单看 VaR 区分度不够；但高斯的 VaR 阈值 4.6969% 明显低于稳定的 5.7519%，配合 ES 的系统性低估，实际尾部保护不足是确定的。

## 六、两个陷阱：Hill 估计与样本峰度

**Hill 估计器**是厚尾分析的标准工具：取最大的 k 个损失，用 α̂ = 1 / mean(log(Xᵢ / X_{k+1})) 估尾指数。它在 Pareto 型分布上表现不错，但在稳定分布上会翻车。本文在 k=20/40/80/160/320/640 六个档位上得到 α̂ = 2.079 / 2.297 / 2.099 / 2.125 / 2.245 / 2.101——全部超过 2.0，而稳定分布要求 α≤2。这不是随机误差，是系统性高估：稳定分布的尾巴不是纯 Pareto，带有缓慢变化的修正项，Hill 估计把它误判成更薄的尾巴。用 Hill 的结果去配 VaR，会低估风险。

**样本峰度**更不能当诊断量。同一段数据在 n=100/400/1600/4000/8000 时样本峰度分别是 11.0 / 15.6 / 34.8 / 31.2 / 308.9，没有收敛迹象。原因是 α=1.7<2 时总体四阶矩无限，样本峰度按 n^(2/α−1) 量级发散。看到峰度随样本量暴涨不要以为是数据变脏，恰恰说明总体矩不存在，该换稳定分布框架了。

## 七、可加稳定性：形状不变，尺度缩放

稳定分布最漂亮的性质是可加稳定性：若 X₁..Xₘ 独立同分布于 S(α,β,γ,δ)，则它们的和服从 S(α,β,m^(1/α)·γ, m·δ)（α≠1）。对风险管理的意义是——日频模型和月频模型可以用同一套 α、β，只改尺度。

本文用重叠窗口把 8000 天收益按 m=1/5/20/50 天加总，再对每档重新做 ECF 拟合，得到 α = 1.7266 / 1.6419 / 1.7254 / 1.9489。除 m=50 因有效样本量下降偏高外，α 围绕真值 1.70 波动，没有系统性漂移。这跟高斯框架下"不同频率波动率尺度不同、还要重新估计"的做法形成对比：稳定分布把形状参数沉淀下来，跨频率复用。

## 八、完整代码实现

```python
import numpy as np
from scipy.stats import levy_stable, norm
from scipy.optimize import least_squares

# 1. 生成真值已知的合成收益 (S0 参数化)
alpha, beta, gamma, delta = 1.70, -0.35, 0.010, 0.0003
r = levy_stable.rvs(alpha, beta, loc=delta, scale=gamma,
                    size=8000, random_state=20261121)

# 2. 经验特征函数
def ecf(x, ts):
    return np.mean(np.exp(1j * np.outer(ts, x)), axis=1)

# 3. scipy S0 参数化的对数特征函数 (alpha != 1)
def log_cf(ts, a, b, g, d):
    u = g * ts
    Phi = -np.tan(np.pi*a/2) * (np.abs(u)**(1-a) - 1)
    log_std = -(np.abs(u)**a) * (1 - 1j*b*np.sign(u)*Phi)
    return 1j*d*ts + log_std

# 4. ECF 拟合
g0 = np.median(np.abs(r - np.median(r))) / 0.6745
ts = np.linspace(0.08, 1.6, 30) / g0
target = np.log(ecf(r, ts))

def resid(p):
    e = log_cf(ts, *p) - target
    return np.concatenate([e.real, e.imag])

sol = least_squares(resid, [1.7, 0.0, g0, r.mean()],
                    bounds=([1.05,-.999,g0*.2,r.mean()-.02],
                            [1.99, .999,g0*3, r.mean()+.02]))
a_hat, b_hat, g_hat, d_hat = sol.x

# 5. 尾部风险: VaR 与 ES
def var_es(a, b, loc, sc, level):
    q = levy_stable.ppf(level, a, b, loc=loc, scale=sc)   # 下尾分位
    s = levy_stable.rvs(a, b, loc=loc, scale=sc, size=1_000_000)
    return -q, -s[s <= q].mean()

var99, es99 = var_es(a_hat, b_hat, d_hat, g_hat, 0.01)

# 6. 高斯对照 (会系统性低估)
mu, sd = r.mean(), r.std(ddof=1)
g_var99 = -(mu + norm.ppf(0.01)*sd)
g_es99 = -mu + sd*norm.pdf(norm.ppf(0.01))/0.01
```

## 九、什么时候该用稳定分布

稳定分布不是万能替代品。α<2 意味着方差无限，很多依赖方差的框架（马科维茨、CAPM 的 β、Sharpe 比率的标准误）在它面前要么失效要么需要重新解释。它的适用场景很明确：

- **尾部风险以 ES 为主**、需要外推到样本之外分位的系统（风险预算、极端情形资本计提）；
- **收益频率混合**的场景，需要一套形状参数跨日/周/月复用；
- 作为**高斯之外的对照组**，检验自己的风控结论是不是只在正态假设下成立。

反过来，如果你只需要刻画中心区域的波动、且样本量不大，高斯或 Student-t 更稳健——稳定分布四个参数在低样本下辨识度差，位置参数尤其如此。工具没有高低，关键是认清它在测什么。
