## 一、结论先行

做因子研究时我们天天跑这样一条回归：

```
r_i = α + λ · x_i + ε_i
```

想估的是 λ——每单位因子暴露值多少风险溢价。这条式子的命门在于它默认 `x_i` 与 `ε_i` 不相关。可现实中这条假设几乎从不成立：高暴露的股票往往同时被更优秀的经理选中、更容易被流动性冲击裹挟、交易成本结构也系统性不同。这些漏掉的变量既抬高收益又抬高暴露，`x` 就成了内生变量。OLS 会把"遗漏变量的贡献"错误地记到 λ 头上，而且这个偏差不会随样本增大消失——它收敛到一个错误的常数，样本越多只是让标准误越小、错得越自信。

本文用一个真值完全已知的蒙特卡洛实验，把"偏差有多大、2SLS 怎么修、修不好会怎样、怎么检验"四件事一次讲清。所有数字都由随附脚本实际跑出，不是教科书抄来的。

## 二、数据生成过程：把内生性埋进去

我们构造这样一个世界。有个看不见的混淆变量 η（可以想成"经理能力"或"隐形流动性冲击"），它通过两条路径同时起作用：

```
z ~ N(0,1)                     外生工具（如指数调仓强加的暴露）
η ~ N(0,1)                     遗漏的混淆变量
u ~ N(0,1)                     暴露的其它扰动
x = π·z + δ·η + u             因子暴露（δ≠0 即内生）
ε = σ·e                        收益残差
r = α + λ·x + γ·η + ε         真实收益生成式
```

关键在 `δ` 和 `γ` 同时非零：η 既影响 x 又直接影响 r，但研究者回归时看不到 η。此时 OLS 的极限是

```
plim λ_OLS = λ + γ·δ / Var(x) = λ + γ·δ / (π² + δ² + 1)
```

取真值 λ=0.05、γ=0.04、δ=0.6、π=0.8、n=3000、重复 3000 次。理论偏差 = 0.04×0.6/(0.64+0.36+1) = 0.012，OLS 应该收敛到 0.062。

![图1：OLS 与 2SLS 的 λ 估计抽样分布，真值 0.05](/images/instrumental-variable-factor/fig1_distributions.png)

实测结果：OLS 均值 **0.06200**，标准误 0.00079，偏差 **+0.012**——与理论 plim 0.0620 三位有效数字吻合；2SLS 均值 **0.04998**，标准误 0.00145，偏差 **−0.00002**，几乎无偏。这就是核心结论：OLS 高估溢价约 24%，而且它的标准误比 2SLS 还小，教科书式的"更精确的错误"。

要理解这个偏差的来源，不妨把 x 拆成两块：由外生工具 z 驱动的"干净"部分，以及由 η 和 u 驱动的"脏"部分。因为 γ≠0，脏部分与收益直接相关，OLS 无法区分"暴露上升带来收益"和"η 上升同时抬高暴露与收益"，于是把后者的贡献整个记到 λ 头上。关键在于这不是有限样本的偶然噪声，而是总体的系统性偏误——大数定律只会让样本均值越来越贴近那个错误的 0.062，标准误却一路缩小到 0.00079，制造出一种"精度很高、方向错了"的假象。这正是内生性比普通噪声危险得多的原因：增加数据量不但治不好它，反而会让你对错误结论更加确信。做因子研究时动辄上万只股票、十几年面板，sample size 从来不是内生性的解药。

## 三、2SLS 怎么把偏差消掉

工具变量 z 满足两个条件：与暴露相关（`Cov(z,x)=π≠0`，相关性），但不通过 η 影响收益（排除限制，`Cov(z,η)=0`）。二阶段最小二乘的第一步把 x 投影到 z 上得到 `x̂ = z(z'z)⁻¹z'x`，第二步用 x̂ 替换 x 做回归。直观上，x̂ 只保留了由外生工具驱动的那部分暴露波动——而这部分按构造与 η 无关，于是遗漏变量偏差被剥离。

在单工具单内生变量情形，2SLS 估计量有极简形式 `λ̂ = Cov(z,r)/Cov(z,x)`。代入生成式，`Cov(z,r) = λ·π`，`Cov(z,x) = π`，立刻得到 `λ̂ = λ`——无偏性一目了然。numpy 实现如下（含异方差无关的标准误与后续检验统计量）：

```python
import numpy as np

def twosls(y, X, Z):
    # X: [1, x] 含截距与内生变量; Z: [1, z] 含截距与外生工具
    ZtZi = np.linalg.inv(Z.T @ Z)
    XtPz = X.T @ Z @ ZtZi          # X' P_z
    A = XtPz @ (Z.T @ X)          # X' P_z X
    Ai = np.linalg.inv(A)
    beta = Ai @ (XtPz @ (Z.T @ y))  # 2SLS 估计
    r = y - X @ beta
    V = (r @ r / (len(y) - Z.shape[1])) * Ai  # 方差估计
    return beta, V, r

# Anderson-Rubin 检验 H0: lambda=lambda0，对弱工具稳健
def ar_stat(y, x, z, lambda0):
    r0 = y - lambda0 * x
    Z = np.column_stack([np.ones(len(y)), z])
    q = Z.T @ r0
    num = q @ np.linalg.inv(Z.T @ Z) @ q - (r0.sum()**2) / len(y)
    den = r0 @ r0 - q @ np.linalg.inv(Z.T @ Z) @ q
    return (num) / (den / (len(y) - 2))  # ~ F(1, n-2)
```

## 四、弱工具：2SLS 也会失灵

2SLS 的一致性依赖"工具够强"。第一阶段系数 π 太小（工具对暴露几乎没解释力）时，x̂ 里绝大部分是噪声，2SLS 反而会把 OLS 的偏差重新引回来。

![图2：左—工具强度随 π 的变化；右—Wald 与 Anderson-Rubin 置信区间覆盖率](/images/instrumental-variable-factor/fig2_weak_instruments.png)

我们扫描 π 从 0.03 到 0.8，同时记录第一阶段 F 统计量（经验法则 F<10 视为弱工具）：

- π=0.03 时 **F=3.0**，典型弱工具。此时 2SLS 偏差 **+0.02185**，相当于真值的 44%——OLS 偏差是 +0.012，弱工具下的 2SLS 居然错得比 OLS 还狠。这正是"弱工具让 2SLS 向 OLS 偏"的经典现象。
- 标准误中位数从强工具时的 **0.00146** 膨胀到 **0.0438**，30 倍。更诡异的是 Wald 95% 置信区间的覆盖率反而是 **99.0%**——因为它太宽了，宽到几乎任何值都落在区间里。这不是好事：区间宽到无法排除任何经济上相关的溢价，等于没有信息。
- Anderson-Rubin 区间在这些点覆盖率 **95.0%**，始终贴合名义值。AR 检验不依赖 λ̂ 的正态近似，而是直接检验"在 λ=λ0 下残差是否与工具正交"，因此对弱工具稳健。实操建议：第一阶段 F<10 时报告 AR 置信区间，别只看 Wald 的 t 值。
- π≥0.4（F>350）后，两种区间覆盖率都收敛到 95%，2SLS 偏差压到 0.0001 以内。

## 五、两个必备的诊断检验

2SLS 用起来有两个前提需要检验：内生性是否真的存在（决定要不要上 IV），以及工具是否真的外生（排除限制无法用数据完全证明，但过度识别时可以部分检验）。

**Hausman 检验**比较 OLS 与 2SLS：若两者系统性不同，说明 OLS 确有内生偏差。统计量 `H = (λ_OLS − λ_2SLS)² / (V_2SLS − V_OLS)` 在 H0 下服从 χ²(1)。

![图3：Hausman 检验在原假设与备择假设下的拒绝率](/images/instrumental-variable-factor/fig3_hausman.png)

实测：暴露外生（δ=0）时拒绝率 **5.1%**，贴近 5% 名义水平；暴露内生（δ=0.6）时 **100%** 检出。检验既有正确的尺寸又有足够的功效。

**Sargan 过度识别检验**用于有多个工具时。若工具都外生，2SLS 残差应与所有工具正交；统计量 `J = n·(r'Z(Z'Z)⁻¹Z'r)/(r'r)` 服从 χ²(工具数−内生变量数)。

![图4：Sargan 过度识别检验对有效/无效工具的区分度](/images/instrumental-variable-factor/fig4_overid.png)

用两个工具 z1、z2：都有效时拒绝率 **4.7%**（平均 J=0.98，接近自由度 1 的期望）；把 z2 改成与遗漏变量 η 相关（坏工具）后，拒绝率 **100%**，平均 J 飙到 **186.0**。过度识别检验抓坏工具非常灵敏。

但要清醒：Sargan 检验在恰好识别（工具数等于内生变量数）时根本用不了，此时没有多余矩条件可供检验。而且它检验的是"所有工具都外生"这个联合原假设——只要有一个工具有效、一个无效，检验就会拒绝，但它不会告诉你是哪一个。实务中更可靠的做法是逐个论证工具的外生性来源：指数调仓、监管阈值、制度变化这类"外生冲击型"工具比"macro 变量"更容易讲通故事。工具变量的质量从来不是统计检验能完全担保的，它最终是一个经济识别问题。

## 六、给量化研究者的实操清单

第一，别默认暴露外生。只要 x 是通过某种"选择"形成的——选股、调仓、基金经理主动配置——就先问一句它与遗漏的收益驱动因素是否相关。第二，报告第一阶段 F，F<10 就别只信 Wald 的 t 检验，改报 Anderson-Rubin 区间。第三，能找到多个工具时就跑 Sargan，但记住它只能"证伪"不能"证实"工具有效性——排除限制始终是经济论证，不是统计检验。第四，2SLS 的标准误比 OLS 大（本例强工具下 0.00145 对 0.00079），这是消除偏差的代价：如果 δ 很小、内生性不成立，强行上 IV 只会白白损失精度，Hausman 检验就是帮你判断这笔交易划不划算的。

工具变量不是魔法，它把"不可识别的因果问题"转化为"可检验的统计假设"。本文所有数值可用 `python3` 复现，四张图均由脚本真实计算生成。理解 x 为什么内生，比会调 `twosls()` 这个函数重要得多——毕竟函数不会告诉你 z 到底是不是真的外生。最后提醒一句：本文的"因子暴露内生性"是为了讲清识别逻辑而人为构造的世界，真实数据里 η 往往无法观测、工具也难称完美外生；2SLS 给出的永远是建立在一组假设之上的估计，而不是因果关系的最终判决。把假设写清楚、把诊断检验跑全，比报出一个漂亮的 λ 更有价值。
