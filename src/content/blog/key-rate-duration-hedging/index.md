## 一、结论先行

"组合久期已经对冲到零了，利率风险应该没了。"这句话在固定收益交易台上是常见的错觉。原因很简单：久期是把整条收益率曲线**压成一个数**之后的剩余风险，而真实的曲线会陡峭、平缓、扭曲，短端和长端从来不是同步移动的。

本文用一个真值完全可知的合成实验把这件事钉死：

1. 组合总 PV01 仅 **0.3794 元/bp**，看起来风险很小；但用一只 10 年期附息债把久期中性化之后，陡峭化场景下损益从 **-19.85 元**变成 **+2.72 元**，扭曲场景从 **+9.85 元**翻成 **-3.64 元**——对冲反而制造了新方向的风险。
2. 改成匹配八个关键期限节点的 KRD 对冲后，五个场景的损益残差最大只有 **0.50 元**，平行上移 100bp 的残差是 **0.003 元**。
3. 600 天曲线因子模拟里，未对冲日度损益标准差 **3.018 元**，久期对冲只降到 **1.477 元**（降 51%），KRD 降到 **0.108 元**（降 96.4%）；95% 分位的绝对损益从 5.649 降到 2.791 再降到 0.209。

## 二、关键利率久期到底在量什么

普通修正久期回答的是："曲线**平行**移动 1bp，价格变多少？"关键利率久期（Key Rate Duration，也叫部分久期）回答的是一个更细的问题："**只在 τ 这个期限节点上**移动 1bp，价格变多少？"

做法是把零收益率曲线写成节点 `z_1, ..., z_K` 之间的分段线性插值，然后逐个节点做 ±0.5bp 的扰动，用中心差分算出该节点的 PV01：

`PV01_i = [P(z_i - 0.5bp) - P(z_i + 0.5bp)] / (1bp)`

因为曲线是分段线性的，所有节点各 bump 1bp 的效果相加，正好等于平行移动 1bp。所以**总 PV01 等于各节点 PV01 之和**——这就是久期对冲能"看起来正确"的数学基础，也是它丢失信息的起点：和相同，分布可以完全不同。

本文用 Nelson-Siegel 形式生成一条平缓上行的零曲线（1 年 2.88%、10 年 3.44%、30 年 3.92%），在 1/2/3/5/7/10/20/30 年八个期限上取节点。组合由四只债券构成：3 年 2.5% 附息债 200 面值、7 年 3.2% 附息债 150、15 年 3.6% 附息债 120、30 年零息债 100，初始市值 **488.37 元**。对冲工具是这八个节点上各一只 4% 附息债（面值 100）。

为什么选八个节点而不是密网格？因为节点既是风险刻度的分辨率，也是方程组的维度。太少则形状风险漏网，太多则每个节点的 PV01 估计都被报价噪声支配，解出来的对冲持仓会在相邻节点之间来回抵消。八个期限覆盖了短端、 belly 和长端，是银行账簿里常见的粗细度。还要注意 PV01 和修正久期的口径差别：修正久期是归一化的百分比敏感度，PV01 是每 1bp 的真实货币损益——交易台真正关心的是后者，因为它直接对应账户盈亏，且可以做加总。

## 三、久期中性为什么会在非平行移动里翻车

先看各节点的 PV01 分布：3 年 0.0598、7 年 0.0912、10 年 0.0681、30 年 0.0926 元/bp，加起来才是 0.3794。用一只 10 年期债券对冲，只能把**10 年节点**的 PV01 打平；其余七个节点一点没动。在平行移动里这无关紧要——因为各节点冲击同号同幅，总 PV01 才是主导项；一旦曲线变形，每个 node 各走各的，漏掉的部分就是纯裸露风险。

![图2：组合、久期对冲与 KRD 对冲在各节点的 PV01 分布](/images/key-rate-duration-hedging/fig2_pv01_profile.png)

更糟的是符号翻转。扭曲场景设定短端 +100bp、长端 -80bp：未对冲组合因为久期偏长而**盈利 9.85 元**，10 年期空头对冲却在这类场景下变成净损失来源，组合最终**亏 3.64 元**。5 年附近的驼峰冲击也是同理：未对冲亏 8.02 元，久期对冲亏 4.90 元，只改善了一点。12 年/25 年方向的驼峰更夸张，未对冲亏 2.53 元，久期对冲反而巨亏 **12.45 元**——因为组合的长端敞口和 10 年期空头在这个形状上是同向叠加的。

连平行场景也不是完美闭环：+100bp 下未对冲亏 35.40 元，久期对冲后留下 **+6.63 元**残差。这不是节点没对冲好，而是组合与单只 10 年期债券的**凸性不同**——再次说明"久期中性"只匹配了一阶导数。

把价格对收益率做二阶泰勒展开，损益近似为 `ΔP ≈ -PV01·Δy + 0.5·C·(Δy)²`。久期对冲只消掉第一项，第二项由组合和工具各自的凸性 `C` 之差决定。本例组合里有一只 15 年附息债和一只 30 年零息债，长尾现金流的凸性明显大于 10 年期工具，于是利率不管上还是下，残差都偏向同一侧——这就是 +6.63 元的来源。它不会随节点数增加而自动消失，只能通过匹配凸性、买入凸性或用含权工具来单独管理。

## 四、KRD 对冲：把八个节点当八个方程

KRD 对冲的思路是直接解一个线性方程组。设 `A[i,j]` 是第 j 只对冲债在第 i 个节点的 PV01，`p` 是组合在各节点的 PV01 向量，求对冲数量 `h` 使得 `A·h + p = 0`。八个节点、八只债，`A` 可逆，解出来的持仓（面值）为：1 年 +0.054、2 年 +0.056、3 年 -1.922、5 年 +0.063、7 年 -1.424、10 年 -0.640、20 年 -0.236、30 年 -0.818。注意里面有正有负，现实中执行要考虑做空可行性与抵押品。

![图3：五种曲线场景下的完整重定价损益](/images/key-rate-duration-hedging/fig3_scenario_pnl.png)

结果是干净的：平行 +100bp 残差 0.003 元，陡峭化 -0.076 元，扭曲 -0.052 元，4 年驼峰 -0.002 元，12 年/25 年驼峰 -0.50 元。除了最后一个跨节点形状，其余都在一毛钱以内。这里必须说清楚：**节点上完全对冲，不等于整条曲线完全对冲**。

## 五、节点之间的风险不会被节点对冲吃掉

为了不把结论吹过头，历史模拟里我在 4 年、12 年、25 年三个**没有对冲节点**的位置加入宽度 1.5 年的局部高斯冲击（标准差 8bp），同时节点上跑水平/斜率/曲率三因子模型。600 天的结果：

- 未对冲：日度损益标准差 **3.018 元**，95% 绝对分位 5.649，最大 10.868；
- 久期对冲：**1.477 元**，95% 分位 2.791，最大 4.761——降幅可观，但曲线一变形就露馅；
- KRD 对冲：**0.108 元**，95% 分位 0.209，最大 0.352——比久期对冲再降 92.7%，但不是零。

![图4：600 天曲线冲击下的累计损益与分布](/images/key-rate-duration-hedging/fig4_backtest.png)

剩下的 0.108 来自两处：节点间形状的局部冲击（对冲债的现金流分布与这些位置并不完全匹配）和凸性差异。如果曲线真实运动能被八个节点的分段线性插值完全描述，KRD 残差还会更小；现实里不能，所以别把"节点中性"当成"无风险"。

## 六、完整可运行代码

```python
import numpy as np

nodes = np.array([1., 2., 3., 5., 7., 10., 20., 30.])
tgrid = np.arange(0.25, 30.01, 0.05)
lam = 2.5
def ns(tau):
    u = tau / lam
    f = (1 - np.exp(-u)) / u
    return 0.040 - 0.015*f + 0.005*(f - np.exp(-u))
z0 = ns(tgrid)                       # 密集曲线，便于加节点间冲击

def curve(node_bp, off_bp):
    s = np.interp(tgrid, nodes, node_bp) / 1e4
    for k, a in zip([4., 12., 25.], off_bp):
        s += a/1e4 * np.exp(-0.5*((tgrid-k)/1.5)**2)
    return z0 + s

def price(cfs, times, zc):           # 现金流折现
    return np.sum(cfs * np.exp(-np.interp(times, tgrid, zc) * times))

def pv01(cfs, times, zc):            # 逐节点中心差分
    out = []
    for i in range(len(nodes)):
        inc = np.interp(tgrid, nodes, (np.arange(len(nodes)) == i).astype(float)) * 5e-5
        out.append((price(cfs, times, zc-inc) - price(cfs, times, zc+inc)) / 1e-4 * 1e-4)
    return np.array(out)

def bond(m, c, face=100.):
    t = np.arange(1, int(m)+1, dtype=float)
    cf = np.full(len(t), c/100*face); cf[-1] += face
    return t, cf

port = [bond(3, 2.5, 200), bond(7, 3.2, 150), bond(15, 3.6, 120), (np.array([30.]), np.array([100.]))]
hedge = [bond(m, 4.0) for m in nodes]
c0 = curve(np.zeros(8), np.zeros(3))
p_vec = sum(pv01(cf, t, c0) for t, cf in port)
A = np.column_stack([pv01(cf, t, c0) for t, cf in hedge])
h_krd = -np.linalg.solve(A, p_vec)          # 关键利率久期对冲
h_dur = np.zeros(8); i10 = 6
h_dur[i10] = -p_vec.sum() / A[i10, i10]      # 单只 10 年债的久期对冲

def pnl(node_bp, off_bp, h):
    zc = curve(node_bp, off_bp)
    d = sum(price(cf, t, zc) - price(cf, t, c0) for t, cf in port)
    d += sum(h[j]*(price(cf, t, zc) - price(cf, t, c0)) for j, (t, cf) in enumerate(hedge))
    return d

print("陡峭化：", pnl(np.array([-40,-30,-20,0,30,60,100,120.]), np.zeros(3), h_dur),
      pnl(np.array([-40,-30,-20,0,30,60,100,120.]), np.zeros(3), h_krd))
```

## 七、什么时候该用，什么时候别用

KRD 不是万能的。节点选得太少，节点间的形状风险照样漏；选得太多，对冲方程对报价噪声敏感，持仓会剧烈跳动。实务里更稳的做法是先对曲线冲击做主成分分析，用水平、斜率、曲率三个因子对应的组合来匹配风险，再用 KRD 做细调。另外，对冲工具的现金流分布最好和被对冲组合相近——用国债期货对冲企业债组合，还要叠加信用利差与交割期权的基础风险，那已经不是本文模型能覆盖的部分。

最后一个容易被忽略的点是**凸性**：本文所有场景都是先对节点扰动、再完整重定价，所以非线性效应都被算进损益里。如果只看 PV01 线性近似，平行 +100bp 下你会以为残差是零，实际是 +6.63 元。线性近似适合做日常风险报告，真要算钱，必须重定价。

落到执行层面，一套可用的检查清单是：第一，先明确你要守的是哪些场景——平行、陡峭、扭曲还是特定驼峰，场景清单决定了节点选在哪里；第二，用历史曲线冲击做主成分分析，看前几个因子能解释多少方差，若两因子已解释九成以上，就没必要硬凑八个方程；第三，检查对冲矩阵的 cond 值，条件数过大说明节点或工具高度共线，此时宁可加正则化约束也不要硬解；第四，给每个节点设 PV01 容忍带而不是追求精确为零，因为报价与曲线拟合本身就有误差；第五，定期用完整重定价复核线性风险报告，把凸性残差单独列账。

## 八、小结

久期是一个数，曲线是一整个函数。把一个数对冲到零，只保证了平行移动那一维的安全。本文实验里，KRD 把日度损益波动从 3.018 压到 0.108，代价是更分散、有正有负的对冲持仓与对节点间残余风险的持续监控。下次有人说"我们已经 duration neutral 了"，值得追问一句：八个节点呢？
