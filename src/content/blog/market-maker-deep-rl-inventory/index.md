做市是量化里最古老的生意：同时挂买单和卖单，赚中间那点价差。听起来是无风险捡钱，真正做过的人都知道，做市商的生死线不是价差，是**库存**——单子被一头打穿，货压在手里，价差收入不够填持仓亏损。Avellaneda-Stolz 给了这个问题一个漂亮的闭式解，但它假设做市商是价格接受者、库存影响线性、市场没有跳变。本文换个姿势：把做市商写成一个 POMDP，用 numpy 从零实现一个 DQN，让它在合成市场里自己学报价，然后诚实地回答三个问题：RL 学到了什么？比闭式解强吗？强多少？

结论先放这：

**① 三家的日均收益几乎一样，差距全在风险形态。** 60 个样本外交易日：对称做市日均 5.733 元、DQN 5.543 元、AS 闭式 5.512 元——统计上分不开。但对称做市的 PnL 标准差 8.80、最大库存 27.0 股、盈利日只有 83%；DQN 把这三个数字变成 2.22、11.3 股、97%。Sharpe 从 0.65 抬到 2.50：RL 没有赚更多，但赚得稳了一个数量级。
**② DQN 追平闭式解，但没有稳定跑赢。** 对比 AS 闭式，DQN 日均只多 0.031 元，60 天里只赢了 48 天。RL 在这个任务上的定位是风险管理员，不是收益增强器。
**③ 学到的策略和教科书反着来。** 低波时挂宽价差（半价差 3 tick）+ 偏移甩货；高波时反而挂窄（1.5-2.5 tick）拼周转；库存撞到 +30 股极限时，价差骤收到 1.5 tick 坚决清仓。AS 闭式在高波下是挂更宽的——这个分歧值得细品。

## 一、把做市写成 POMDP

做市商每一步只知道自己挂了什么价、成交了多少、手里压了多少货，不知道基本面下一秒去哪——这就是一个部分可观察马尔可夫决策过程（POMDP）。五元组：

- **状态**（5 维）：当前库存 q（归一化到 ±30 股）、剩余时间 τ=(T−t)/T、波动 regime 指示（低波 1.5 tick/步、高波 4.5 tick/步）、订单流不平衡（买卖单的 EWMA）、上一步收益；
- **动作**（12 个）：半价差 ∈ {1.5, 2.0, 2.5, 3.0} tick × 库存偏移 ∈ {0, 0.10, 0.25} tick/股。偏移让报价整体平移：shift = −skew·q·tick，库存为正时报价下移，吸引买单来收货；
- **奖励**：每步 mark-to-market（现金变动 + 库存市值变动），收盘时每股罚 1 tick，逼它清仓；
- **转移**：合成市场（下一节）；
- **回合**：一个 390 步的模拟交易日。

注意「部分可观察」这四个字的含金量：做市商永远不知道当前处在哪个波动 regime、不知道基本面 v 在哪、不知道下一笔打过来的是噪声单还是知情单——只能从订单流的不平衡、上一步的收益这些边角料里猜。这就是 AS 闭式解不需要面对、而 RL 必须面对的世界：公式假设全知，agent 承认无知。

为什么用 POMDP 而不是套 AS 公式？因为 AS 假设做市商是价格接受者、库存影响线性、没有跳变——而真实市场里你的报价会改变成交概率（价差越宽成交越少），库存越大越急着甩。这些反馈闭环，都得靠 agent 自己试出来。

## 二、合成市场：价差收入、逆向选择、库存硬闸

市场里只有三类参与者。基本面 v 从 100 出发，每步按当前 regime 的波动走正态（低波 1.5 tick、高波 4.5 tick，regime 以 0.5% 概率切换），另有 0.2% 概率出现 ±12 tick 跳变。成交强度随报价宽度指数衰减：λ = 0.65·exp(−0.5·max(0.05, hs ∓ skew·q))——挂 1.5 tick 半价差，每步每侧成交概率约 0.31；挂 3 tick 只剩 0.15。

- **噪声交易者**：泊松到达打穿买价/卖价，做市商被动成交（记账口径：主动买单打穿 ask，做市商卖出；主动卖单打穿 bid，做市商买入）；
- **知情交易者**：当基本面突破你报价 2.5 tick 以上，有 20% 概率来打你——这是逆向选择，做市亏损的主要来源；
- **库存硬闸**：|q| 超过 30 股强制按 mid∓2 tick 平仓，模拟真实风控线。

一天下来，价差收入是明牌，持仓盈亏是暗牌。三种策略的真正比分，就在盈亏分解表里。

## 三、从零实现 DQN

网络小到可以手写：5→32→12 两层 ReLU，目标网络每 5 回合同步一次，8000 容量的经验回放池，batch 64，学习率 2e-4，梯度裁剪 ±1，ε 从 1.0 按每回合 ×0.99 衰减到 0.05，训练 350 个模拟交易日。奖励整体除以 5 缩放，不然数值范围会炸开。

```python
import numpy as np

class DQN:
    def __init__(self, n_feat, n_act, hidden=32, lr=2e-4, seed=7):
        rng = np.random.default_rng(seed)
        self.W1 = rng.normal(0, 1/np.sqrt(n_feat), (n_feat, hidden))
        self.b1 = np.zeros(hidden)
        self.W2 = rng.normal(0, 1/np.sqrt(hidden), (hidden, n_act))
        self.b2 = np.zeros(n_act)
        self.lr = lr
        self._sync_target()

    def _sync_target(self):
        self.tW1, self.tb1 = self.W1.copy(), self.b1.copy()
        self.tW2, self.tb2 = self.W2.copy(), self.b2.copy()

    def qvals(self, x, target=False):
        W1, b1, W2, b2 = ((self.tW1, self.tb1, self.tW2, self.tb2)
                          if target else (self.W1, self.b1, self.W2, self.b2))
        h = np.maximum(0.0, x @ W1 + b1)
        return h @ W2 + b2

    def update(self, x, a, r, x2, done):
        x, x2 = np.atleast_2d(x), np.atleast_2d(x2)
        a, r, done = np.atleast_1d(a), np.atleast_1d(r), np.atleast_1d(done)
        y = r + 0.99 * self.qvals(x2, target=True).max(axis=1) * (1 - done)
        q_now = self.qvals(x).copy()
        B = x.shape[0]
        q_now[np.arange(B), a] = y
        h = np.maximum(0.0, x @ self.W1 + self.b1)
        dq = (self.qvals(x) - q_now) / B
        gW2, gb2 = h.T @ dq, dq.sum(0)
        dh = (dq @ self.W2.T) * (h > 0)
        gW1, gb1 = x.T @ dh, dh.sum(0)
        for g in (gW1, gW2):
            np.clip(g, -1.0, 1.0, out=g)
        self.W1 -= self.lr * gW1; self.b1 -= self.lr * gb1
        self.W2 -= self.lr * gW2; self.b2 -= self.lr * gb2

# 训练主循环（每个回合 = 一个 390 步的模拟交易日）
net, buf = DQN(5, 12), []
for ep in range(350):
    # ... 跑完一天，把 (x, a, r, x2, done) 逐条压入 buf（上限 8000，先进先出）
    for _ in range(20):        # 每回合末抽 20 个 batch 更新
        idx = np.random.default_rng(ep).integers(0, len(buf), 64)
        batch = [np.array([buf[i][k] for i in idx]) for k in range(5)]
        net.update(*batch)
    if ep % 5 == 0:
        net._sync_target()     # 目标网络软同步
```

图 1 是训练曲线：灰色是含 ε 探索的训练日收益（方差大得没法看），红色是贪心策略的评估收益——从第 0 回合的 6.31 出发，在 5.0-7.3 之间震荡，全程咬住 AS 闭式（蓝色，固定 6.449）。样本内评估看不出谁更好，真正的比分要看样本外。

训练本身最大的难题是**信用分配**：第 100 步挂宽价差少赚的那几毛钱，可能要等到 290 步后的收盘库存惩罚里才体现。390 步的延迟回报对 DQN 向来不友好，回放池打乱时间相关性、目标网络稳住 bootstrap 目标，这两件套是长回合里不炸的最低配置；梯度裁剪 ±1 则是为了按住 Q 值的爆炸式更新。换个 seed 重训，学到的策略形态会有细节差异，但「库存大就偏移、撞墙就收价差」的定性结论稳定复现。

## 四、样本外：60 个独立交易日

训练集一天都没用过的 60 个新路径，三家同场竞技：

| 策略 | 日均 PnL | std | Sharpe | 价差收入 | 持仓盈亏 | 成交笔数 | 最大\|库存\| | 盈利日 |
|---|---|---|---|---|---|---|---|---|
| 对称做市 | 5.733 | 8.803 | 0.65 | 6.996 | −1.047 | 202.4 | 27.0 | 83% |
| AS 闭式 | 5.512 | 2.274 | 2.42 | 6.570 | −0.989 | 191.3 | 11.8 | 97% |
| DQN | 5.543 | 2.221 | 2.50 | 6.231 | −0.639 | 146.7 | 11.3 | 97% |

读表要点：价差收入三家都在 6.2-7.0 之间，**差距全在持仓盈亏那一列**。对称做市「来者不拒」，成交最多（202 笔、403 股）但库存最大、持仓亏 1.047 元/天，亏损的方差拖垮整条 PnL 曲线。DQN 成交最少（147 笔）却库存最小、持仓亏得最少（0.639）——它学会了挑单。

盈利日 97% vs 83% 的差距更直观：对称做市的亏损日，几乎都是「被知情单连续打穿同侧 + 库存撞墙强平」的连环事故——单边行情里它的报价不躲不闪，买单卖单轮流挨打。DQN 在这些日子里靠偏移报价提前躲开一侧，把事故降级为擦伤。

## 五、显微镜下的策略：RL 学到了什么

把训练好的 DQN 调到贪心模式，固定时间和其他状态，只扫描库存 q 从 −30 到 +30，看它每一步怎么报价（图 3）：

- **低波 regime**：半价差 2.5-3.0 tick，比对称做市的 2.0 更宽；库存为正时偏移 0.25 tick/股——报价整体下移，让买单来收货；
- **高波 regime**：半价差反而降到 1.5-2.5 tick，偏移只留 0.1；
- **库存撞墙时**（q=+30）：半价差骤收到 1.5 tick，不惜薄利也要把货甩出去。

高波挂窄、低波挂宽——这和 AS 闭式（g·σ²·τ 项让高波挂更宽）正好相反。原因在成本结构：本模型里价差按 tick 计、波动也按 tick 计，高波时挂宽等于给知情单送钱（2.5 tick 门槛内就打你），且持仓盈亏的方差随 σ² 爆炸。DQN 的实际选择是「薄利快周转」：用窄价差换双向流量，把库存钉在 0 附近，持仓亏损最小（−0.639）。这不是公式推出来的，是 350 天试错试出来的。

## 六、诚实结论

把话说全：**在这个环境里，RL 没有创造收益，它重新分配了风险。** 日均 PnL 和 AS 闭式统计上无法区分（差 0.031 元、胜率 48%），Sharpe 2.50 vs 2.42 的优势也只是一倍标准差内的噪声。真正的增量是库存减半（11.3 vs 27.0 股）、盈利日 +14 个百分点——对真实做市台，这些比年化多 2% 重要得多。

还没解决的事：排队优先级（你的单排在多深，本文假设打穿即成交）、多品种库存相关性（股指期货一篮子做市时库存会互相传染）、撤单成本，以及最要命的——风控怎么审计一个神经网络的报价决策。RL 做市在真实市场的落地难点从来不是 PnL，是可解释性与运维。本文的合成市场把知情者建模成「突破报价就出手」的规则流，真实世界里对手是别的 RL 模型时，这个 POMDP 的对手盘假设也得推翻重来——那时均衡策略长什么样，就是另一个课题了。
