违约不是价格从 10 元跌到 9 元，是一个 0 到 1 的跳变：一家公司活着，然后突然不还钱了。信用风险管理的核心输出是违约概率（PD），而行业主流做法仍是「年度体检」——每年看一次财务报表，打一个分，用一年。问题在于：违约强度是随时变的，一家公司的杠杆、已实现波动、盈利能力每个月都在动，去年的快照今年可能已经过期，而静态评分对此完全失明。

生存分析把「活多久」当主角。Cox 比例风险模型是其中的工作母机：它不假设基线风险长什么样，只假设协变量对风险的影响是乘性比例的，并且天然处理删失（有些公司到观察期末还没违约，我们只知道它「至少活了这么久」）。本文用 numpy 从零实现整条流水线——部分似然、Newton-Raphson、Breslow 基线、Schoenfeld 检验——在一片 6000 家合成高收益债 universe 上跑一遍，看看它到底能做什么、不能做什么。

结论先放这：

**① 系数恢复干净，符号和显著性全对。** 真实 β = (1.5, 1.2, −2.0)（杠杆、波动、ROA），Cox 估计 β̂ = (1.293, 1.137, −2.469)，z 统计量 4.2 / 3.5 / −3.4 全部显著。杠杆每上升 10 个百分点，月违约强度乘以 1.14；ROA 每下降 1pp，强度乘以 1.02×……听着小，60 个月复利下来就是 3.6 倍的风险比。
**② PD 期限结构是模型真正的输出。** 高杠杆（80%）公司的 12 个月边际 PD 从评分初月的 4.45% 走到末年的 5.95%——即使协变量完全不动，PD 也随基线上行；低杠杆（20%）同期只有 2.07%→2.78%。
**③ 静态分组会把期初的协量极端值当成永久状态。** 按月初风险分分三组，模型曲线（固定 lp）高估高风险组违约（S(60) 82.1% vs 经验 KM 84.4%）、低估低风险组（88.4% vs 85.2%）——协变量会均值回复，组内差异被磨平。高风险组月初静态 PD12 3.38%，实际 12 个月违约率只有 2.81%。
**④ 但别神话 Cox：排名上它和 logit 打平。** 12 个月前瞻违约排名（测试公司、同一评估集），Cox 逐月重评 0.558，面板 logit 0.552，静态 logit 0.551——同样的数据同样的目标，能榨的排名信息差不多。Cox 的真优势在别处：系数用全部事件时间信息估计（12 个月窗口的静态 logit 把 ROA 系数估成 +0.89，真值是 −2.0），PD 有期限结构，比例风险假设可检验。

## 一、合成市场：违约即跳变，协量逐月漂移

造一片什么样的 universe？高收益债的气质：5 年累计违约率两位数。6000 家公司，观察 60 个月，每家每月有三个协变量：杠杆（债务/资产）、30 日已实现波动、ROA。三者各自走 AR(1)——杠杆 φ=0.95、波动和 ROA φ=0.90，围绕均值 0.40 / 0.25 / 0.02 回复。违约强度写死成非齐次 Poisson：

```
λ(t, x) = λ0(t) · exp(1.5·lev + 1.2·vol − 2.0·roa)，   λ0(t) = 0.0008·exp(0.01·t)
```

逐月掷骰子：p = 1 − exp(−λ)，中了就违约离场，没中就带着漂移后的协变量进入下个月。期末还活着的 5095 家是右删失样本。最终 905 家违约（15.08%）。违约公司的违约月均协量是 lev=0.420、vol=0.275、roa=0.014，存活公司期末均 lev=0.398、vol=0.259、roa=0.019——方向全对，但注意差别没有天差地别：违约是概率事件，协变量只提供乘性倾斜，这就是为什么预测上限本来就不高。

上图是三家违约公司和一家存活公司的路径。违约公司的共同画像是杠杆缓步爬坡、波动抬头；但「爬坡」和「违约」之间隔了几个月到几年——这正是时变协量模型要捕捉的东西。

## 二、Cox 部分似然：numpy 从零 Newton-Raphson

Cox 模型的写法：λ(t, x) = λ0(t)·exp(βᵀx)。基线 λ0(t) 完全 unspecified，参数只有 β。偏似然（partial likelihood）的构造很物理：在每一个违约事件发生的时点，问「为什么是这家而不是风险集里其他家」——

```
L(β) = Π_{事件i} exp(βᵀx_i) / Σ_{j ∈ 风险集(t_i)} exp(βᵀx_j)
```

风险集 = 退出时间 ≥ 事件时点的所有公司。时变协量的正确用法是**事件月快照**：事件公司和风险集成员都取「事件发生那个月」的协变量值——用年初值就是前视偏差，用期末值就是后视偏差，这个细节错了整个模型都错。对数似然的梯度和 Hessian 有闭式（加权均值和加权协方差），Newton-Raphson 十几步收敛：

```python
def nll_grad_hess(beta, Xev, ev_times, risk_cache, Xt):
    """Xev: 事件月协量快照 (n_events, 3)；risk_cache[t]: 风险集成员索引"""
    denom = np.array([np.exp(Xt[risk_cache[te], te, :] @ beta).sum()
                      for te in ev_times])
    ll = (Xev @ beta - np.log(denom)).sum()
    grad = np.zeros(3); hess = np.zeros((3, 3))
    for k, te in enumerate(ev_times):
        xm = Xt[risk_cache[te], te, :]              # 风险集的事件月快照
        w = np.exp(xm @ beta); sw = w.sum()
        xbar = (w[:, None] * xm).sum(0) / sw        # 加权均值
        grad += Xev[k] - xbar
        xc = xm - xbar
        hess += (w[:, None, None] * xc[:, :, None] * xc[:, None, :]).sum(0) / sw
    return -ll, -grad, hess          # f=-ll, ∇f=-∇ll, ∇²f=hess（正定）

beta = np.zeros(3)
for it in range(100):                # Newton-Raphson + 步长减半保险
    f, g, h = nll_grad_hess(beta, ...)
    step = np.linalg.solve(h, g)
    s = 1.0
    while nll_grad_hess(beta - s * step, ...)[0] > f: s *= 0.5
    beta = beta - s * step
```

训练集取 4200 家（测试集 1800 家留做样本外）。估计结果：

| 协变量 | 真实 β | Cox β̂ | 标准误 | z | 风险比 exp(β̂) |
|---|---|---|---|---|---|
| 杠杆 | 1.5 | 1.293 | 0.305 | 4.2 | 3.64 |
| 波动 | 1.2 | 1.137 | 0.321 | 3.5 | 3.12 |
| ROA | −2.0 | −2.469 | 0.724 | −3.4 | 0.085 |

杠杆每上升 10 个百分点（0.40→0.50），月违约强度乘以 exp(1.293×0.1) ≈ 1.14；ROA 每下降 1pp 乘以 exp(2.469×0.01) ≈ 1.03——单月看着温和，60 个月累积就是数倍差距。三个系数方向、量级、显著性全部合理，估计器本身没有问题。

## 三、基线风险和 PD 期限结构

β 只告诉你「谁比谁危险」，绝对水平在基线 λ0(t) 里。Breslow 估计量按月离散：λ̂0(t) = 当月违约数 / 风险集成员的 exp(βᵀx) 之和。

![基线违约强度：真实 vs Breslow 估计](/images/survival-analysis-highfreq-default/baseline_hazard.png)

λ̂0(0)=0.0011 vs 真值 0.0008、λ̂0(59)=0.00176 vs 0.00144——水平被高估了两成左右，因为 β̂ 有衰减（杠杆 1.293 < 1.5），基线要替系数「补课」；但上行的形状基本复现。拿到 Λ0 和 β 之后，任何协量画像的生存曲线和 PD 都是闭式：

```
S(t|x) = exp(−Λ0(t)·exp(βᵀx))，   PD_h(x) = 1 − S(t+h|x)/S(t|x)
```

![12 个月边际违约概率 PD 期限结构](/images/survival-analysis-highfreq-default/pd_term_structure.png)

PD 期限结构是静态评分给不了的东西。高杠杆公司 12 个月 PD 从 4.45% 爬到 5.95%——协变量一动不动，PD 也随基线上行；低杠杆同期 2.07%→2.78%。对风险限额、对信用利差定价、对监管资本，「PD 不是常数而是期限的曲线」这件事本身就是信息。参考画像（lev 40%/vol 25%/ROA 2%）的 5 年累计违约率真值 14.33%，与合成宇宙的整体违约率 15.08% 互相印证。

## 四、生存曲线 vs KM：静态分组的隐性偏差

按月初线性预测值 lp = βᵀx(0) 分三组，模型曲线（固定组均 lp）和经验 Kaplan-Meier 对照：

![生存曲线：模型 vs 经验（按风险三分位）](/images/survival-analysis-highfreq-default/survival_curves.png)

低风险组模型 S(60)=88.4% vs KM 85.2%，高风险组 82.1% vs 84.4%——模型把两端的差距拉得比现实更开。原因不难想：分组用的是**期初** lp，而协变量会均值回复，期初踩在极端值上的公司随后往均值掉，真实风险比静态 lp 暗示的更温和。这不是 Cox 的错，是「分组固定」的代价；Cox 的正确用法是逐月用最新协量重算 lp。同一个偏差在 PD 上也能看到：高风险组月初静态 PD12 3.38%，实际 12 个月违约率 2.81%，高估两成。

## 五、和静态模型正面对比：排名打平，优势在别处

把评估统一成「12 个月前瞻违约排名，逐月重评」：每个月 m，用 m 月及以前的协量给每家公司打分，同月内比较「12 个月内违约」与「活过窗口」的公司，pooled C-index。三个模型在同一测试集上：

![模型对比与系数恢复](/images/survival-analysis-highfreq-default/model_comparison.png)

Cox 逐月重评 0.558、面板 logit（同样的面板数据、同样的 12 个月目标）0.552、静态 logit（m=0 训练、系数冻结、每月套最新特征）0.551——**打平**。如果只做年度体检（仅 m=0 快照，测试集约 90 个事件），C-index 0.49±0.05，与随机不可区分。诚实的结论分两层：

**排名上 Cox 没有魔法。** 同样的数据、同样的目标，logit 也能学到近似的线性排序。差别在估计质量：Cox 用全部 905 个违约的**时间信息**（谁在第 3 个月违约、谁在第 57 个月），而 12 个月窗口的静态 logit 每个公司只贡献一个 0/1 标签——训练集里 ROA 系数被估成 +0.89（真值 −2.0），符号都是噪声，只是杠杆项足够强把排名兜住了。面板 logit 把 ROA 拉回 −1.13，和 Cox 的 −2.47 量级相符（前瞻窗口的衰减系数本来就该打折）。
**Cox 的真优势是可解释的产出。** PD 期限结构、基线风险、比例风险假设检验——这些 logit 给不了。Schoenfeld 残差对时间回归，杠杆斜率 +0.00003、波动斜率 +0.00007， proportional hazards 在本文数据生成机制下成立（本来就是这样造的）；真实世界里若 β 随 regime 漂移，这个检验会第一时间报警，而静态模型连报警的接口都没有。

## 六、局限清单

比例风险假设是假设不是礼物：危机期杠杆系数往往跳升，Schoenfeld 能抓到但修要上时变系数模型。基线风险估计会吸收系数衰减（本文 λ̂0 水平高估两成）。时变协量的实现处处是坑：事件月快照用错月份就是前视偏差，删失和竞争风险（被并购退市）本文直接忽略。样本外衰减、协变量操纵（季末突击降杠杆）都足以让回测里的 0.558 打折。把这些算进去，生存分析的价值不是「预测违约」，而是把「谁在变危险、危险多少、什么时候危险」变成一条可以逐月跟踪、带置信区间的曲线。
