## 一、结论先行

传统压力测试是正向的：挑一个历史情景（2008、2020、2015 股灾），把组合收益代进去，看亏多少。它有个隐性问题——**你只能测你想到过的情景**。而真正让基金爆仓的，往往是没人设想过的因子组合。

反向压力测试（Reverse Stress Testing, RST）把逻辑倒过来：先设定一个"不可接受的损失"（比如单日亏 5%），再问**什么样的市场冲击会导致这个损失，其中哪一个最可能发生**。答案是"在所有达成该损失的情景里，离当前市场分布最近的那个"——用马氏距离衡量远近，问题就变成一个带线性等式约束的二次规划，而且有闭式解。

本文在一个 3 因子组合（日波动 1.535%）上把这套方法跑完，五个结论都做了数值对拍：

1. **闭式解与数值解一致**：目标损失 5%（相当于 3.2569 个组合标准差）时，反推情景是股票因子 **-3.25 个标准差**、利率 **+0.25sd**、信用 **-0.08sd**，最小马氏距离平方 **10.607**，与 SLSQP 数值优化的最大差异只有 **7.5e-9**。
2. **它确实是"最该担心"的情景**：50 万次高斯抽样中，271 次真正触发了 5% 损失；这些样本里最小的马氏距离平方是 **10.73**，是理论值 10.61 的 **1.012 倍**——抽样永远只能从边界外侧命中，闭式解正好压在下确界上。
3. **肥尾让"极端情景"没那么极端**：同样马氏距离下，高斯假设的尾概率是 **1.405%**，而 t(3) 分布下高达 **16.36%**，是 11.6 倍；t(5) 也有 7.4 倍。用高斯做 RST，会把灾难的可达性系统性压低一个数量级。
4. **凸性缺口会误导风控**：组合做空 gamma（Γ_股票=-3）时，线性模型在反推情景上报损失 5.00%，真实损失却是 **5.51%**，低估 **10.2%**；把凸性纳入约束后，达成同样 5% 损失所需的马氏距离从 3.257 降到 **2.978（降 8.57%）**——线性模型把一个"更近、更容易发生"的危险情景漏掉了。
5. **相关性误设只带来有限漂移**：股票—信用相关系数从 0 拉到 ±0.7，反推情景向量的相对漂移也只从 0 增到 4.4%，主方向由因子暴露 β 决定，相关性是二阶修正。

## 二、问题 formulation：把"最可能的坏情景"写成优化

设组合日收益由 k 个正交风险因子驱动：

```
r_p = βᵀ z,    z ~ N(0, Σ)
```

其中 β 是因子暴露向量，Σ 是因子协方差。给定目标损失 L（正数，表示要亏掉 L），我们想找 z 满足两件事：

```
βᵀ z = -L                  （恰好亏这么多）
min  zᵀ Σ⁻¹ z              （在所有满足条件的 z 里，离分布中心最近）
```

第二项 `zᵀΣ⁻¹z` 就是**马氏距离平方**。它不是欧氏距离——它按协方差把各因子标准化，两个高波动因子的联合变动不会被误判成"很远的异常"。最小化它等价于最大化该情景在高斯分布下的密度，所以这个优化找到的就是**给定损失下最可能发生的市场状态**。

用拉格朗日乘子法可以直接解。目标函数 `zᵀΣ⁻¹z` 加约束 `λ(βᵀz + L)`，对 z 求导得 `2Σ⁻¹z + λβ = 0`，即 `z = -λΣβ/2`。代回约束 `βᵀz = -L` 解出 λ，最终：

```
z* = Σ β · (-L) / (βᵀ Σ β)
d* = sqrt(z*ᵀ Σ⁻¹ z*) = L / sqrt(βᵀ Σ β) = L / σ_p
```

最后这个等式很漂亮：**最小马氏距离恰好等于目标损失除以组合波动率**。亏损目标每提高一个组合标准差，情景就往尾部推一个标准差。这就是图2 里那条严格直线的来历。

本文设定：β = (0.85, −0.60, 0.40) 对应股票/利率/信用三个因子，因子日波动分别 1.8%/0.2%/0.1%，于是组合日波动 `σ_p = sqrt(βᵀΣβ) = 1.5352%`。目标损失 5% 对应 **3.2569 个组合标准差**。代入闭式解：

```
z* = (-0.0584, +0.000509, -0.0000849)
```

换成标准差单位（除以各因子波动）就是股票 **−3.2458sd**、利率 **+0.2546sd**、信用 **−0.0849sd**——亏损几乎全由股票因子贡献，利率和信用只是被动跟随，这与 β 的量级排序一致（股票暴露 0.85 最大）。

![图2：目标损失与最小马氏距离的线性关系，闭式解与数值优化完全重合](/images/reverse-stress-testing/fig2_md_curve.png)

## 三、闭式解验证：数值优化与蒙特卡洛双重对拍

闭式解对不对，用两条独立路径检验。

**路径一：SLSQP 数值优化。** 直接从零向量出发，最小化 `zᵀΣ⁻¹z`，约束 `βᵀz + 0.05 = 0`。结果 `z = (-0.0584242, 0.00050914, -8.4865e-5)`，与闭式解的最大绝对差 **7.5e-9**，目标函数值 10.6071534644 对 10.6071534643——吻合到小数点后 9 位。

**路径二：暴力蒙特卡洛。** 抽 50 万个高斯因子向量，筛选出真正亏到 5% 的样本（271 个），看它们的马氏距离最小能到多少。理论上闭式解是下确界，任何抽样命中都只能在边界外。实测最小马氏距离平方 **10.732**，是理论值 10.607 的 **1.0118 倍**——完全符合预期（抽样点几乎不可能精确落在约束超平面上）。同时，抽样触发损失的经验概率 **0.0542%** 对高斯理论值 `Φ(-3.2569) = 0.0563%`，也吻合。

两条路径把闭式解钉死了。这很重要：RST 的全部后续结论都建立在这个"边界点"上，如果它算错，后面全错。

## 四、肥尾的当头一棒：同样的情景，概率差一个数量级

到这里都是教科书内容。但真实市场不是高斯。RST 最危险的用法，就是把"马氏距离 3.26"直接翻译成"大约 3.3 个 sigma 事件，几乎不会发生"。

在多元 t 分布下，马氏距离的分布在解析上是清楚的：若 `z ~ t_ν(0, Σ)`，则 `zᵀΣ⁻¹z / k ~ F(k, ν)`（k 为因子数）。本文 k=3，把 `d*² = 10.607` 代入：

| 分布 | 超过该情景的概率 | 相对高斯 |
|------|------|------|
| 高斯 | 1.405% | 1.0× |
| t(30) | 2.641% | 1.9× |
| t(10) | 5.613% | 4.0× |
| t(5) | 10.38% | 7.4× |
| t(3) | 16.36% | **11.6×** |

![图3：同一马氏距离在不同分布假设下的情景概率，对数坐标](/images/reverse-stress-testing/fig3_fattail_probability.png)

一个在高斯世界里"千分之一概率"的灾难，在 t(3) 世界里是**六分之一的概率**。这不是学术细节：如果风控用高斯 RST 得出"这个情景要 3.3 sigma，几十年一遇，不必对冲"，而真实收益是厚尾的，那么实际上它每年都可能撞上几次。**肥尾不是让情景更远，而是让同样的情景更近。**

作为对照，本文还做了 5000 天的 t(4) 肥尾历史回放：最差单日亏 17.96%，有 22 天超过 5% 目标，最差 20 天的平均马氏距离平方是 **29.64**，是 RST 情景 10.61 的 **2.79 倍**——历史极端日的因子组合比闭式解"离谱"得多，因为它们同时叠加了多个因子的同向冲击。RST 的价值恰恰在此：它找到的是**最省力的亏钱方式**，历史回放则是一堆"用力过猛"的样本。

## 五、凸性缺口：线性模型看不见的"近在咫尺"的风险

第二个更隐蔽的问题来自非线性。组合若含期权，收益不再是因子的线性函数。构造一个做空股票 gamma 的组合：

```
r_p = βᵀ z + 0.5 · zᵀ Γ z,    Γ[0,0] = -3
```

负的 Γ[0,0] 表示股票跌得越深，亏损加速（卖出了看跌期权或做了空 gamma 结构）。在线性反推情景 `z*` 上，线性项给出 −5.00%，但凸性项 `0.5·zᵀΓz = −0.00512`，把真实损失推到 **5.51%**——线性模型低估 **10.2%**。

更关键的是**反向问题也变了**。在真实非线性模型上重新反推"亏 5% 的最可能情景"，得到的马氏距离是 **2.978**，比线性答案 3.257 **低了 8.57%**。原因直观：有了做空 gamma 的凸性放大，不需要那么极端的股票冲击就能亏到 5%（股票因子只需 −2.97sd 而非 −3.25sd）。线性 RST 因为看不见凸性，**把真正更危险、更容易发生的情景系统性推远了**。

![图4：线性模型与真实非线性模型在反推情景上的损失对比](/images/reverse-stress-testing/fig4_convexity_gap.png)

这是本文最想强调的工程教训：**RST 的"最可能情景"结论，严重依赖 PnL 模型的线性假设**。组合里有期权、可转债、带凸性的信用结构时，必须把二阶项（甚至全定价函数）放进约束，否则会把脆弱点算成安全点。

## 六、相关性误设与实操建议

最后测了一下相关性误设的敏感度：把股票—信用相关系数从 0 扫到 ±0.7，反推情景向量相对基准的相对漂移从 0 增到 **4.4%**（ρ=−0.7）和 **4.1%**（ρ=+0.7）。主方向由暴露 β 锁死，相关性只是二阶修正。这算是个好消息：即便协方差矩阵估得粗糙，RST 给出的"哪个因子是元凶"的一阶结论仍然稳。

实操上给三条建议：

1. **别把 RST 当预测**：它回答的是"亏 5% 需要什么条件"，不是"明天会亏 5%"。它的输出是条件情景，不是概率预报。
2. **概率解释必须匹配分布假设**：报"3.3 sigma"之前先确认收益是否厚尾；用 t 分布重算可达概率，往往比高斯高一个数量级。
3. **非线性组合必须上全定价**：把期权 Greek 的二阶项纳入 PnL 约束，否则线性 RST 会低估损失、推远危险情景，双向误导。

## 七、完整代码

```python
import numpy as np
from scipy import optimize, stats

rng = np.random.default_rng(20261121)
beta = np.array([0.85, -0.60, 0.40])        # 股票/利率/信用 暴露
fac_vol = np.array([0.018, 0.002, 0.001])   # 因子日波动
Sigma = np.diag(fac_vol ** 2)
Sinv = np.linalg.inv(Sigma)
L = 0.05                                     # 目标损失 5%

# --- 闭式解 ---
denom = beta @ Sigma @ beta                  # = sigma_p^2
z_star = Sigma @ beta * (-L) / denom
md2 = z_star @ Sinv @ z_star                 # = (L/sigma_p)^2
print("z* (sd):", z_star / fac_vol, " md:", np.sqrt(md2))

# --- 数值优化验证 ---
obj = lambda z: z @ Sinv @ z
cons = ({"type": "eq", "fun": lambda z: beta @ z + L},)
res = optimize.minimize(obj, np.zeros(3), constraints=cons, method="SLSQP")
print("numeric diff:", np.max(np.abs(res.x - z_star)))

# --- 肥尾概率：zᵀΣ⁻¹z/k ~ F(k, nu) ---
p_gauss = stats.chi2.sf(md2, df=3)
p_t3 = stats.f.sf(md2/3, 3, 3)
print("tail gauss/t3:", p_gauss, p_t3)        # 1.41% / 16.36%

# --- 凸性：做空 gamma ---
Gamma = np.zeros((3, 3)); Gamma[0, 0] = -3.0
pnl_nl = lambda z: beta @ z + 0.5 * z @ Gamma @ z
res_nl = optimize.minimize(obj, z_star,
    constraints=({"type": "eq", "fun": lambda z: pnl_nl(z) + L},), method="SLSQP")
print("nonlinear md:", np.sqrt(res_nl.x @ Sinv @ res_nl.x))  # 2.978
```

## 八、小结

反向压力测试把风险管理从"被动列举情景"变成"主动求解脆弱点"。高斯线性模型下的闭式解 `z* = Σβ(−L)/(βᵀΣβ)` 优雅且可验证（数值、蒙特卡洛双重对拍），但它的两个软肋——**忽略肥尾导致低估灾难可达性**、**忽略凸性导致推远危险情景**——在含期权的真实组合里会让结论反向。用 t 分布重算概率、用全定价 PnL 做约束，是把 RST 从教科书搬进实盘的必要两步。
