期权定价课上，Black-Scholes 那个偏微分方程（PDE）总让人望而生畏：

$$\frac{\partial V}{\partial t}+\frac{1}{2}\sigma^2 S^2\frac{\partial^2 V}{\partial S^2}+rS\frac{\partial V}{\partial S}-rV=0$$

学生背下边界条件、解出闭式公式，很少有人停下来问：**这个二阶 PDE 和「模拟一堆股价路径、算平均收益、再折现」到底有什么关系？** Feynman-Kac 定理给出的答案 sharp 得惊人——它们本来就是同一个东西的两种写法。前者是确定性的局部描述，后者是随机的全局期望；PDE 的解在任意一点 $(S,t)$ 的值，恰好等于从该点出发的风险中性路径的折现收益期望。

这个视角不只是美学。当你定价一个路径依赖的奇异期权——比如收益取决于股价有没有碰过某条障碍线——PDF 那一套在高维状态空间里寸步难行，而蒙特卡洛只要多写几行路径判断就能照算不误。本文用纯 numpy/scipy 把这套等价性彻底跑一遍，所有数字都是脚本实跑所得。

## 一、Feynman-Kac：从 PDE 到路径期望

对满足 $dS=rS\,dt+\sigma S\,dW$（风险中性测度 $\mathbb{Q}$）的标的，任意期末收益 $h(S_T)$ 的期权价格是

$$V(S,t)=\mathbb{E}^{\mathbb{Q}}_t\!\left[e^{-r(T-t)}\,h(S_T)\right]$$

Feynman-Kac 定理保证这个函数 $V$ 正好解上面那个 Black-Scholes PDE 及相应终值条件。其中风险的漂移被悄悄换成了无风险利率 $r$——这个「换测度」的动作是整件事的灵魂，我们在第四节会用数字展示用错漂移的代价。

在 GBM 下路径可以精确采样：因为 $\ln S_T=\ln S_0+(r-\tfrac12\sigma^2)T+\sigma\sqrt{T}Z$，$Z\sim N(0,1)$。所以一次定价估计就是

$$\hat V=e^{-rT}\cdot\frac{1}{N}\sum_{i=1}^N \max(S_0 e^{(r-\sigma^2/2)T+\sigma\sqrt{T}Z_i}-K,\,0)$$

为了压低抽样噪声，我们用对偶变量（antithetic variates）：每抽一个 $Z$，配对用 $-Z$，让正负冲击互相抵消。设定 $S_0=K=100$、$r=5\%$、$\sigma=20\%$、$T=1$，闭式 Black-Scholes 价格是 **10.4506**。

## 二、收敛：路径越多，期望越准

先看蒙特卡洛 estimate 如何随路径数收敛。理论告诉我们标准误按 $1/\sqrt{N}$ 衰减，实测完全吻合：

| 路径数 N | MC 估计 | 标准误 | 95% 置信区间 |
|---|---|---|---|
| 100 | 10.281 | 1.353 | [7.63, 12.93] |
| 500 | 10.055 | 0.616 | [8.85, 11.26] |
| 2,000 | 10.232 | 0.321 | [9.60, 10.86] |
| 10,000 | 10.475 | 0.147 | [10.19, 10.76] |
| 50,000 | 10.428 | 0.065 | [10.30, 10.56] |
| 200,000 | 10.437 | 0.033 | [10.37, 10.50] |

用固定种子、20 万条对偶路径再估一次得到 **10.4685 ± 0.0647**（±为 1.96 倍标准误），闭式解 10.4506 稳稳落在区间内。注意小样本时的估计可以偏得很离谱（500 条时 10.06），但置信区间诚实地覆盖了真值——这正是蒙特卡洛该有的样子：不是每次都准，而是误差可量化。

![蒙特卡洛定价随路径数收敛](/images/feynman-kac-option-pricing/02_mc_convergence.png)

关键洞见：**这里的期望是对「收益函数」取期望，不对「股价」取期望**。很多人误以为 $V=e^{-rT}\mathbb{E}[S_T]-K$，把折现期望和 max 的顺序搞反。收益的凸性（期权是凸函数）正是期权价值的来源， Jensen 不等式告诉我们 $\mathbb{E}[\max(S_T-K,0)]\ge\max(\mathbb{E}[S_T]-K,0)$。

## 三、同一价格，第三条路：有限差分解 PDE

既然 Feynman-Kac 说 PDE 和期望等价，我们直接把 PDE 数值解出来，看是否殊途同归。为避免 $S$ 网格在非线性系数 $\frac12\sigma^2S^2$ 上出乱子，做对数变换 $x=\ln(S/K)$、$\tau=T-t$，方程变成常系数：

$$\frac{\partial u}{\partial\tau}=\frac12\sigma^2\frac{\partial^2 u}{\partial x^2}+\Big(r-\frac12\sigma^2\Big)\frac{\partial u}{\partial x}-ru,\qquad u(x,\tau)=V/K$$

用 Crank-Nicolson 格式（时间二阶、无条件稳定），把每个时间步化为一个三对角线性系统，用 `scipy.linalg.solve_banded` 求解。1200 个价格格点、1200 个时间步，解出的 $V(S_0,0)=$ **10.4507**，与闭式 10.4506 误差仅 **0.0014%**。

![Crank-Nicolson PDE 与解析解对比](/images/feynman-kac-option-pricing/03_pde_vs_analytic.png)

三条完全独立的路径——解析公式、路径平均、PDE 数值解——给出同一个数，这就是 Feynman-Kac 最直观的验证。你完全可以只用其中一种；理解它们等价的价值在于：当某一方法失效时（高维、路径依赖、非马尔可夫），你知道另一种还站着。

## 四、换错测度的代价：漂移必须是 r，不是 μ

Feynman-Kac 里的期望是**风险中性期望**，漂移必须取无风险率 $r$。如果把真实（物理）漂移 $\mu=12\%$ 代进去，会发生什么？同样 20 万条路径，价格从 10.45 飙到 **15.56**，虚高 **48.9%**。

原因很清楚：更高的漂移把整条 $S_T$ 分布右移，看涨收益被系统性抬高。市场不会为这种「一厢情愿的乐观」买单——期权价格必须是在能复制它的自融资组合成本下定出来的，而这个复制论证天然落在风险中性测度上。风险溢价已经通过 $r$（而非 $\mu$）的体现被正确计入，再塞进 $\mu$ 就是重复计价、把投资者本该获得的股票风险补偿也当成期权收益算进去了。

这也是为什么实务里做衍生品定价，第一件事是把漂移写成 $r-q$（$q$ 为股息率），而做方向性预测时才用 $\mu$。两个数字服务于两个问题，混用是最经典的入门错误之一。

## 五、路径依赖上场：障碍期权

前面三个方法打平手，是因为欧式期权的状态空间只有二维 $(S,t)$。现在加入路径信息：一个**向下敲出看涨期权**，若期间 $S$ 触及障碍 $H=80$ 就作废，否则到期按 $\max(S_T-K,0)$ 支付。

PDE 要做这件事，得增加一个「已触及障碍」的状态变量或把边界条件钉在 $H$ 上；换成美式或带记忆的合约更是维度灾难。而 Feynman-Kac 这边只需在每条路径上多一句判断。我们用布朗桥（Brownian bridge）修正离散监控偏差：即使一条路径在两个监控时点都高于 $H$，也按桥过程公式 $p=\exp(-2\ln(S_{ prev}/H)\ln(S/H)/(\sigma^2\Delta t))$ 补算区间内穿越的概率。

结果：15 万条路径、252 步的蒙特卡洛给出 **10.3824 ± 0.0748**，触障率 22.2%；用 Reiner-Rubinstein 的 in-out parity 闭式解是 **10.3513**（同时用吸收边界 PDE 独立验证得 10.3513，三者吻合）。敲出特征让价格从 10.45 降到 10.35——因为约 22% 的路径中途作废，期权变便宜了。

![折现收益分布与漂移选择](/images/feynman-kac-option-pricing/04_payoff_drift.png)

注意这里蒙特卡洛的标准误（0.075）比欧式情形大了一截：障碍判断引入了路径层面的方差。想要更精细的价格，要么加大路径数，要么做重要性采样/分层——这就是 Feynman-Kac 视角下的「工程问题」，而不再是「数学问题」。

## 六、让路径期望更省样本：方差缩减与实际边界

蒙特卡洛的软肋是收敛慢——想把标准误砍一半，路径数要翻四倍。实务里有两个几乎零成本的技巧。一是前面用的**对偶变量**：由于 $\max(S_T-K,0)$ 是 $S_T$ 的凸函数，配对 $Z$ 与 $-Z$ 让两个收益的平均值被 Jensen 不等式「夹」在中间，方差天然小于独立抽样。二是**控制变量**：用同一个随机数同时算出解析可定价的欧式看涨和障碍期权，两者高度正相关，于是用已知解析价的欧式结果去校正障碍估计，把共享的随机噪声减掉。这两招不改变期望的无偏性，只压缩方差，是 Feynman-Kac 框架下最划算的工程优化。

但要诚实指出这条路的边界。Feynman-Kac 把期权写成「一条路径末期收益的折现期望」，这个形式天然适合**欧式**合约—— payoff 只依赖终点。一旦进入**美式期权**的提前执行，问题变成最优停止：期望里多了「何时执行」这个需要沿路径动态决定的策略，定价从求期望升级为求解 $\sup_\tau\mathbb{E}[e^{-r\tau}g(S_\tau)]$，Feynman-Kac 的简单形式不再直接适用，得回到变分不等式或最小二乘蒙特卡洛（Longstaff-Schwartz）。障碍、亚式、回望这类**弱路径依赖**合约仍在射程内，因为 payoff 可以写成整条路径的函数、不需要额外做最优决策。理解这条分界线，才知道什么时候该放心用路径模拟、什么时候要换成别的武器。

## 七、把三种方法放进工具箱

回顾一下各自的甜区：

- **解析闭式**：欧式、永续等少数几种简单收益，快且精确，但覆盖不了花样合约。
- **PDE / 有限差分**：低维、状态马尔可夫、需要全场数值（比如要整个 $\Delta(S,t)$ 曲面）时很顺手；维度一高（多资产、路径依赖）就爆炸。
- **蒙特卡洛（Feynman-Kac 路径期望）**：维度几乎不是障碍，收益函数多复杂都能写进 payoff；代价是统计误差按 $1/\sqrt N$ 收敛，且必须老老实实待在风险中性测度里。

它们共享同一个内核——**期权价格是折现后的风险中性收益期望**。Feynman-Kac 定理的价值，就是把「解 PDE」和「算期望」这两件看似无关的事焊死成一个事实，让你在任何一个具体合约前都能挑最省力的那把刀。

## 八、完整代码骨架

```python
import numpy as np
from scipy.stats import norm

S0, K, r, sigma, T = 100.0, 100.0, 0.05, 0.20, 1.0

# 闭式 Black-Scholes
def bs_call(S, K, r, sigma, T):
    d1 = (np.log(S/K) + (r + 0.5*sigma**2)*T) / (sigma*np.sqrt(T))
    d2 = d1 - sigma*np.sqrt(T)
    return S*norm.cdf(d1) - K*np.exp(-r*T)*norm.cdf(d2)

# Feynman-Kac 路径期望（对偶变量）
def mc_call(n_paths, seed):
    rs = np.random.default_rng(seed)
    Z = rs.standard_normal(n_paths//2)
    Z = np.concatenate([Z, -Z])                      # 对偶
    ST = S0*np.exp((r - 0.5*sigma**2)*T + sigma*np.sqrt(T)*Z)
    payoff = np.maximum(ST - K, 0.0)
    vals = np.exp(-r*T)*payoff
    return vals.mean(), vals.std(ddof=1)/np.sqrt(len(vals))

print(bs_call(S0,K,r,sigma,T))        # 10.4506
print(mc_call(200000, seed=777))      # (10.4685, 0.0330)
```

把 `ST` 换成逐日迭代的 GBM 路径、给 payoff 加上障碍判断，就是敲出期权的定价器——整个框架一行不用推倒。这正是 Feynman-Kac 留给实践者最实用的遗产：**把求导数的苦活，变成掷骰子的体力活**。
