打开任意一天的国债收益率表，你会看到从 3 个月到 30 年十几个期限，每个期限一个收益率。这些点不是杂乱的——它们几乎总能用一条平滑曲线串起来，而且这条曲线的形状变化，长期被业界总结成三个词：**整体抬高或压低、变陡或变平、中间鼓包或凹陷**。

Nelson-Siegel（1987）把这三句话变成了三个数学因子，从此一条曲线只需要四个参数（三个系数加一个衰减速度 λ）就能描述。它至今仍是各国央行和养老金做曲线拟合、利率风险管理的默认起点——不是因为最精确，而是因为**参数少、形状有金融含义、还能稳定地外推到没有数据的远端**。

本文从载荷函数推导开始，讲清每个因子的形状，然后在已知真值的数据上现场反解，用主成分分析验证"三个因子够不够"，最后做一个把三次多项式彻底打爆的外推测试。

## 一、三个因子，各自的形状长什么样

Nelson-Siegel 把期限 τ 的即期收益率写成三个载荷的线性组合：

```
y(τ) = β0 · L(τ) + β1 · S(τ) + β2 · C(τ)

L(τ) = 1
S(τ) = (1 - exp(-τ/λ)) / (τ/λ)
C(τ) = S(τ) - exp(-τ/λ)
```

三个载荷各管一件事：

- **L(τ) ≡ 1（水平因子）**：对所有期限一视同仁。β0 是它的系数，等于曲线的长期极限水平——τ→∞ 时 S、C 都趋于 0，只剩 β0。所以 β0 就是"长端锚"。
- **S(τ)（斜率因子）**：从 τ=0 时的 1 单调衰减到 0，是一支快衰减的指数。β1 控制短端相对长端的高低：β1 为正、曲线短端高（倒挂），β1 为负、短端低（正常陡峭）。
- **C(τ)（曲率因子）**：从 0 出发、先升后降、最后回到 0，是中间那个"鼓包"。β2 为正时中段凸起，形成蝶式。关键在于 λ——它决定鼓包出现在哪个期限，这是整条曲线唯一的非线性参数。

![Nelson-Siegel 三个因子的载荷形状](/images/nelson-siegel-yield-curve/ns-loadings.png)

上面这张图用 λ=2.2 年画出三个载荷。可以看到 S 从 1 快速滑落，C 在 λ 附近达到峰值约 0.29，然后慢慢回落到 0。这意味着：**λ 就是曲率因子发生作用的时间尺度**。真实数据里 λ 通常落在 1.5 到 3 年之间，因为中短端的鼓包最常见。如果强行让 λ 过大，C 的峰会被推到十几年远端、几乎摊平，模型就退化成只有水平与斜率两因子；λ 过小则鼓包挤在一年内，中段失去解释力。所以实务里给 λ 设一个有经济含义的优化区间（本文用 0.25 到 30 年），本质是防止优化器跑到这两个没有意义的极端。

基础 Nelson-Siegel 只有一个鼓包。当市场在同一条曲线上出现两个明显的驼峰（短端和中长端各一个），Svensson（1994）加了一个带独立 λ2 的第二曲率项 C2(τ)，把参数扩到六个，拟合弹性大增。代价正是第三节要讲的：自由度越多，参数识别越不稳，曲率信号越难从噪声里稳定估出。这也解释了为什么很多机构宁可用固定 λ 的基础版——在曲线拟合这件事上，**约束力往往比拟合精度更值钱**。

## 二、现场反解：三个系数加一个 λ，能不能还原真值

说得再漂亮，不如在已知答案的数据上验证。我设定一组真值：β0=3.50%、β1=−2.00%、β2=1.80%、λ=2.2，在 11 个典型期限（0.25 到 30 年）上算出收益率，再叠加标准差 4bp 的高斯噪声模拟真实报价误差。然后用 scipy 的最小二乘从这些带噪点反解四个参数。

核心代码不过十几行：

```python
import numpy as np
from scipy.optimize import least_squares

def loadings(tau, lam):
    x = tau / lam
    S = (1 - np.exp(-x)) / x
    C = S - np.exp(-x)
    return np.ones_like(tau), S, C

def ns_yield(tau, b0, b1, b2, lam):
    L, S, C = loadings(tau, lam)
    return b0 + b1*S + b2*C

def resid(p):
    return ns_yield(taus, *p) - y_obs

sol = least_squares(
    resid, x0=[0.03, -0.01, 0.01, 2.0],
    bounds=([-0.1, -0.2, -0.2, 0.25], [0.2, 0.2, 0.2, 30.0]),
)
beta0, beta1, beta2, lam_hat = sol.x
```

结果：β0 恢复到 3.5421%（真值 3.50%），β1 恢复到 −2.0436%（真值 −2.00%），λ_hat=1.9973（真值 2.2）。拟合残差的 RMSE 是 **3.35bp**，比噪声真值本身的 3.76bp 还小——这是最小二乘在"吸收"噪声，说明四个参数几乎没有浪费，全用在了曲线形状上。

![NS 拟合：11 个期限点还原整条曲线](/images/nelson-siegel-yield-curve/ns-curve-fit.png)

有个细节值得提醒：β2 恢复得最差（1.4477% 对真值 1.80%），λ 也偏低。这不是 bug，而是 Nelson-Siegel 的一个著名毛病——**β2 和 λ 高度相关、识别度弱**。曲率因子只在中段有明显贡献，中段数据一有噪声，鼓包的高度和位置就能互相补偿。实务里若要看稳，要么固定 λ、要么用带惩罚项的正则化，这也是 Svensson 扩展和复合 Nelson-Siegel 试图改善的地方。

## 三、三个因子够不够：拿 600 条曲线做 PCA

"三个因子"是经验之谈还是真有道理？我用蒙特卡洛生成 600 条收益率曲线：让 β0、β1、β2 分别服从均值 3.50%/−2.00%/1.80%、标准差 2.0%/1.0%/0.4% 的正态分布（模拟历史上水平波动最大、斜率次之、曲率最小的经验规律），再叠加极小的独立噪声。然后对这些曲线做奇异值分解。

```python
X = panel - panel.mean(axis=0)
U, s, Vt = np.linalg.svd(X, full_matrices=False)
var_exp = s**2 / np.sum(s**2)   # 各主成分解释的方差占比
```

结果很干脆：第一主成分解释 **97.815%** 的方差，第二主成分 **2.150%**，累计前两个已达 **99.965%**，第三个曲率因子只剩 **0.028%**——几乎可以忽略。

![收益率曲线面板的前三个主成分](/images/nelson-siegel-yield-curve/ns-pca-factors.png)

这个数字有两层含义。好的一面：在现实的参数波动结构下，**两个因子就能解释几乎全部曲线变动**，这解释了为什么对冲基金常用"久期中性 + 曲线中性"两维风险框架就够了。需要留意的一面：曲率的信息量极小，意味着任何以曲线陡峭度、蝶式为标的的策略，信号都淹没在水平与斜率的巨响里——你要交易的那个 β2，恰恰是最难从噪声里稳定估出的那个。

## 四、外推测试：三次多项式在 30 年端彻底崩掉

曲线拟合真正的考验不在拟合区间内，而在区间外。养老金和保险公司常常需要 20 年、30 年甚至更长端的收益率，可这些期限要么没有流动性报价、要么数据质量差。实务做法是用短端数据拟合、再外推长端。这里最能看出模型好坏。

我做一个极端的实验：**只用 10 年以内的 7 个点拟合**，然后预测 15、20、30 年的收益率，并和同样只用短端数据拟合的三次多项式对比。真值就是前面那组 NS 参数生成的曲线（15/20/30 年分别约 3.469%/3.478%/3.485%，因为长端已经逼近 β0=3.50% 的极限）。

```python
short = taus <= 10
sol_s = least_squares(lambda p: ns_yield(taus[short], *p) - y_obs[short],
                      x0=[0.03, -0.01, 0.01, 2.0],
                      bounds=([-0.1, -0.2, -0.2, 0.25], [0.2, 0.2, 0.2, 30.0]))
pred_ns = ns_yield(taus[~short], *sol_s.x)
coef = np.polyfit(taus[short], y_obs[short], 3)
pred_poly = np.polyval(coef, taus[~short])
```

差距是灾难性的：NS 的外推 RMSE 只有 **9.72bp**，而三次多项式是 **2719.90bp**。多项式在 30 年端给出荒唐的 **49.9%** 收益率——因为多项式在区间外会失控地发散，这是它的数学本性，与数据质量无关。NS 之所以稳，是因为它的载荷函数在 τ→∞ 时天然收敛到常数 β0，结构上就带着"长端趋于水平"的经济学约束。

这就是结构化模型的价值：它不是在数据点上硬性插值，而是把你对收益率曲线形状的理解（长端有极限、中段有鼓包）编码进了函数形式里。

## 五、把曲率变成可交易的量：蝶式

三个因子里，β2 对应经典的**蝶式套利**。以 2 年、5 年、10 年三个期限构造 2s5s10s 蝶式：

```
butterfly = 2 × y(5) - y(2) - y(10)
```

代入 NS 载荷，蝶式对 β2 的敏感度是 `2·C(5) − C(2) − C(10)`。用 λ=2.2 算出 C(2)=0.2539、C(5)=0.2916、C(10)=0.2070，于是敏感度为 `2×0.2916 − 0.2539 − 0.2070 = 0.1223`——β2 每上升 1 个百分点，蝶式走阔约 12.2bp。当前 β2=1.80% 时，蝶式读数约 39.04bp。这让 β2 不再是个抽象的拟合系数，而是一个可以直接映射成头寸比例的量：做多蝶式，本质上就是押注中段相对两端凸起（β2 上升）。

当然，回到第三节的结论——β2 的信息量在曲线变动里只占 0.028%，用它做交易信号时必须清醒：你面临的估计误差，很可能比你想捕捉的收益还大。

## 小结

Nelson-Siegel 用三个有金融含义的因子，把一条曲线压缩成四个参数。我们看到它在带噪数据上能稳定反解真值（残差 3.35bp），PCA 揭示两个因子就解释了 99.965% 的曲线变动，而它的结构化函数形式让长端外推（9.72bp）把三次多项式（2719.90bp）甩开两个数量级。它的短板也很清楚：β2 与 λ 识别度弱，曲率信号天然微弱。理解这两面，才算真正会用这个业界最常用的曲线工具。

**关键数值一览**：水平 β0 真值 3.50% → 拟合 3.5421%；残差 RMSE 3.35bp（噪声真值 3.76bp）；PCA 前两成分累计 99.965%、第三成分仅 0.028%；长端外推 NS 9.72bp vs 三次多项式 2719.90bp；2s5s10s 蝶式对 β2 敏感度 0.1223。
