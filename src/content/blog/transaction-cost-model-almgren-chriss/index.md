你手里有一笔 100 万股的卖单，市场价 50 美元，名义本金 5000 万美元。你要在一天内卖完。

卖得太快，你的卖单会把价格砸下去，自己吃掉的冲击成本高得吓人；卖得太慢，价格在你慢慢出货的这段时间里随机游走，可能朝不利方向走很远，你暴露在风险里的时间太长。这是一个典型的两难：**冲击成本（快了贵）与时间风险（慢了险）之间的权衡**。

Almgren 和 Chriss 在 1999 年和 2001 年的两篇论文里，第一次把这个模糊的直觉精确定量成了一个可解的数学优化问题，并给出了漂亮的闭式解。这个解至今仍是机构算法交易台的基石——VWAP、TWAP、POV 这些执行算法，背后都能看到它的影子。本文从成本泛函一步步推到双曲正弦解，再用数值对拍验证，最后把效率前沿画出来。

## 一、把两难写成数学：成本泛函

先设定符号。要在时间窗口 [0, T] 内卖掉 X 股，用 x(t) 表示 t 时刻还没卖掉的持仓（x(0)=X，x(T)=0），交易速率就是 v(t) = -x'(t)。

Almgren-Chriss 把价格冲击拆成两部分：

- **永久冲击**（permanent impact）：你的交易永久性地移动了中间价，模型为 g(v) = γ·v。它对所有成交股数都生效，总成本是 γ·X²/2——注意，这个量与你怎么分配节奏**完全无关**，是一笔逃不掉的过路费。
- **临时冲击**（temporary impact）：你下单瞬间吃掉的价差，模型为 h(v) = η·v。它只跟当下的交易速率有关，总成本是 η·∫v(t)²dt。卖得越快，这一项按速率平方爆炸式增长。

价格本身还叠加一个无漂移的布朗运动，波动率 σ（单位是美元/股/√日）。持仓 x(t) 暴露在这个波动里，带来的成本方差是 σ²·∫x(t)²dt。

于是期望成本和方差分别是：

```
E[cost] = γ·X²/2 + η·∫₀ᵀ v(t)² dt
Var[cost] = σ²·∫₀ᵀ x(t)² dt
```

决策者用风险厌恶系数 λ 把两者合成一个目标函数：`U = E[cost] + λ·Var[cost]`。λ=0 表示你完全不在乎风险，只求省冲击成本；λ 越大，你越愿意多花成本换低风险。

这个目标函数的关键结构是：它只含 x 和 x' 的二次函数，所以是一个标准的变分优化问题——Euler-Lagrange 方程能给出闭式解。

## 二、闭式解：双曲正弦节奏

对目标泛函用变分法求解，得到持仓路径：

```
x(t) = X · sinh(κ(T - t)) / sinh(κT)
κ = sqrt(λ · σ² / η)
```

这个 κ 是全篇的核心参数，可以理解为"紧迫度"。κ 越大，双曲正弦曲线越陡，意味着策略越急于在早期把货出掉；κ→0 时，双曲正弦退化为线性，x(t)→X(1-t/T)，也就是匀速的 TWAP。

我们用的参数是：股价 50 美元，卖出 100 万股，窗口 1 日，日波动 σ=0.5 美元/股（约 1%），临时冲击系数 η=2.5×10⁻⁷，永久冲击系数 γ=1×10⁻⁷。κ 与 λ 的换算关系是 λ = κ²·η/σ²，比如 κ=3 对应 λ=9×10⁻⁶，κ=10 对应 λ=1×10⁻⁴。

上图画出了不同 κ 的节奏。灰色虚线是 TWAP（匀速），最陡的红色曲线是 κ=10——它在第一个时段就卖掉 18% 的仓位，而 TWAP 每段只卖 2%。

## 三、解析解对拍离散二次规划

闭式解是在连续时间下推出来的，实盘执行是离散的（比如每 30 分钟下一单）。为了验证这套推导并能落地，我把窗口切成 50 段，用持仓 y_k 作为决策变量（y₀=X，y_N=0），把目标写成离散二次型：

```
min  Σ (η/τ)·(y_k - y_{k+1})²  +  λ·σ²·τ·Σ y_k²      其中 τ = T/N
```

一阶条件给出一个三对角线性方程组，直接求解即可。把它和解析解 `x(kτ) = X·sinh(κ(T-kτ))/sinh(κT)` 逐点对比：

| κ | 解析解 vs 离散 QP 最大绝对偏差 | 占 X 比例 |
|---|-------------------------------|-----------|
| 1 | 1.77 股 | 0.00018% |
| 3 | 51.23 股 | 0.00512% |
| 5 | 152.76 股 | 0.01528% |
| 10 | 610.90 股 | 0.06109% |

偏差随 κ 增大而上升——因为 κ 越大节奏越陡，50 段的离散网格相对越粗。但即便 κ=10，偏差也只占仓位的万分之六，完全在工程可接受范围内。这给了我们信心：连续闭式解可以放心地离散化落地。

## 四、效率前沿：成本与风险的取舍

现在看核心结果。名义本金 5000 万美元，1 个基点（bp）= 名义本金的 0.01% = 5000 美元。永久冲击成本 γ·X²/2 = 5 万美元 = 10bp，如前所述与路径无关。

不同 κ 的期望成本和成本标准差如下：

| κ | 期望成本 | 永久 / 临时 | 成本标准差 | 首段成交占比 |
|---|---------|------------|-----------|-------------|
| 0 (TWAP) | 60.00bp | 10 / 50 | 57.74bp | 2.00% |
| 1 | 60.93bp | 10 / 50.93 | 54.27bp | 2.61% |
| 2 | 69.47bp | 10 / 59.47 | 47.04bp | 4.07% |
| 3 | 87.61bp | 10 / 77.61 | 40.31bp | 5.85% |
| 5 | 135.12bp | 10 / 125.12 | 31.61bp | 9.52% |
| 10 | 260.00bp | 10 / 250.00 | 22.36bp | 18.13% |
| 20 | 510.00bp | 10 / 500.00 | 15.81bp | 32.97% |

规律很清楚。TWAP 的期望成本最低（60bp），但风险最大（57.7bp）——因为它把持仓暴露摊满了整个窗口。随着 κ 上升，临时冲击成本按速率平方飞涨（κ=20 时高达 500bp），但成本标准差一路降到 15.8bp。这就是效率前沿：**没有免费的午餐，想降低执行风险，就得实打实地多付冲击成本**。

## 五、风险来自哪里：持仓敞口面积

有人会问：为什么慢慢卖风险就大？答案藏在方差公式 `Var = σ²·∫x(t)²dt` 里——风险正比于持仓平方对时间的积分。

TWAP 的持仓从 X 线性降到 0，∫x²dt = X²T/3；而 κ=10 的激进策略早早把仓位清空，∫x²dt 小得多。这个积分可以理解为"你带着敞口在市场里待了多久、多重"，敞口面积越大，布朗运动把你推向不利方向的累计机会就越多。

![持仓敞口面积决定价格风险](/images/transaction-cost-model-almgren-chriss/ac-exposure.png)

图中绿色阴影是 κ=3 策略的敞口面积，明显小于 TWAP 的整个三角形区域。这个面积就是风险的来源。

## 六、可运行代码

下面是生成最优节奏和成本的核心代码，纯 numpy 实现闭式解 + 三对角离散对拍。

```python
import numpy as np

S0, X, T = 50.0, 1_000_000.0, 1.0
sig, eta, gam = 0.5, 2.5e-7, 1.0e-7
NOTIONAL = S0 * X

def schedule(t, k):
    """闭式最优持仓 x(t)。"""
    if k < 1e-9:
        return X * (1 - t / T)           # kappa->0 退化为 TWAP
    return X * np.sinh(k * (T - t)) / np.sinh(k * T)

def moments(k):
    """解析计算 int x^2 dt 与 int v^2 dt。"""
    if k < 1e-9:
        return X**2 * T / 3, X**2 / T
    s2, den = np.sinh(2*k*T), np.sinh(k*T)**2
    ix = X**2 / den * (s2/(4*k) - T/2)
    iv = X**2 * k**2 / den * (s2/(4*k) + T/2)
    return ix, iv

def costs(k):
    ix, iv = moments(k)
    e_perm = 0.5 * gam * X**2            # 10bp，路径无关
    e_temp = eta * iv
    std = np.sqrt(sig**2 * ix)
    return e_perm, e_temp, std

for k in [0, 3, 10]:
    ep, et, sd = costs(k)
    print(f"kappa={k}: 期望 {(ep+et)/NOTIONAL*1e4:.1f}bp, "
          f"标准差 {sd/NOTIONAL*1e4:.1f}bp")
# kappa=0: 期望 60.0bp, 标准差 57.7bp
# kappa=3: 期望 87.6bp, 标准差 40.3bp
# kappa=10: 期望 260.0bp, 标准差 22.4bp
```

## 七、模型的边界与实务提醒

Almgren-Chriss 是一个优雅的起点，但真实执行比模型复杂，用的时候要清楚它的假设边界。

第一，**线性冲击假设**。模型假设临时冲击 η·v 随速率线性增长，但大量实证表明冲击与参与率更接近平方根关系（square-root law）。线性假设在小单子（占 ADV 比例很低）时够用，大单子会低估冲击的非线性。

第二，**常数波动率**。模型用固定的 σ，现实中波动率随时间变化且有聚集。实务中会用 GARCH 预测或日内波动曲线替代常数 σ，把模型升级成时变版本。

第三，**没有涨跌停和流动性约束**。模型允许任意交易速率，实际有涨跌停、最小报价单位、流动性深度限制。κ=20 那种"首段卖 33%"的节奏，在真实盘口里可能根本吃不下。

第四，**基准选择**。Almgren-Chriss 用的是"执行成本 + 风险"框架，隐含基准是决策时刻的中间价（implementation shortfall 视角）。如果你的考核基准是 VWAP，目标函数要相应调整。

第五，**strategic vs tactical**。闭式解给出的是事前的战略节奏（strategic schedule）。实盘中要根据盘口深度、成交进度动态修正（tactical adjustment），在战略节奏上加一个反馈控制项。

## 小结

Almgren-Chriss 把"快卖还是慢卖"这个交易台上每天都在做的决策，变成了一个有闭式解的二次规划。我们看到：永久冲击 10bp 是与节奏无关的过路费；临时冲击随速率平方增长；价格风险正比于持仓敞口面积。三者合成的效率前沿上，TWAP 成本最低但风险最大（60bp / 57.7bp），κ=3 是折中（87.6bp / 40.3bp），κ=10 则几乎把风险砍半但成本翻四倍（260bp / 22.4bp）。

选择哪个点，没有标准答案——它取决于你的风险厌恶、考核基准和对市场冲击的判断。但有了这把尺子，你至少知道自己站在前沿的哪个位置，以及为了再降一点风险要付出多少代价。这就是定量执行相对拍脑袋的核心价值：它让权衡变得可见、可算、可讨论。

**关键数值一览**：名义本金 5000 万美元，永久冲击 10bp（路径无关）；TWAP 期望 60bp / 标准差 57.7bp；κ=3 期望 87.6bp / 标准差 40.3bp；κ=10 期望 260bp / 标准差 22.4bp；解析解与 50 期离散 QP 最大偏差 0.0002%~0.06%。
