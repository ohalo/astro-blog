## 一、结论先行

"我预测这 20 只股票未来一个月的超额收益，现在怎么建仓？"这是主动投资最朴素的问题，也是最容易做错的地方。两种常见错误：一是**按信号强弱平均下注**，把预测噪声当成真金白银；二是**忽略每只股票各自的风险**，给一只高波动股票和低波动股票同样的仓位。

Treynor-Black（1973）模型给出了这个问题的解析解，核心三条：

1. **主动权重正比于"预测 alpha ÷ 残差方差"**：`w_i ∝ α_i / σ²_εi`。信号越准、残差风险越小的股票，权重越高。在 alpha 相同的理想对照里，最低残差股票拿到的权重是最高残差股票的 **5.76 倍**。
2. **整体夏普按勾股定理增长**：`Sharpe² = Sharpe_m² + IR_A²`。被动市场的夏普和主动组合的信息比率，是两个互相正交的风险来源——这个漂亮的结论可以直接算出来，本文用数值验证到小数点后四位完全一致。
3. **预测质量决定一切**：完美预测下主动 IR 上界是 0.4183（本例），但预测噪声一旦放大到和残差风险同量级，正确加权的 TB 组合实现 IR 只有 0.0606；此时**忽略残差风险的naive方案直接掉到 -0.0013**，集中押注前 5 名也只有 0.0343。加权方式对不对，在噪声环境下是盈亏之分。

## 二、模型：把主动收益写成市场加残差

先把单只股票的收益拆开。设市场组合的月超额收益为 `r_m`，股票 i 的超额收益满足单因子模型：

`r_i = β_i · r_m + α_i + ε_i`

其中 `α_i` 是这只股票相对市场的超额收益（我们要预测的 alpha），`ε_i` 是特异收益，方差 `σ²_εi` 就是残差风险。分析师给出的是带噪声的预测 `α̂_i = α_i + 误差`——注意真实 `α_i` 我们只有在回测评估时才知道，建仓时手上只有 `α̂_i`。

主动组合就是把这些股票按权重 `w_i` 组合起来（允许做空，所以权重可正可负）。它的两个关键量：

- 组合 alpha：`α_A = Σ w_i · α_i`（评估时用真 alpha，不是预测值，这是避免"噪声幻觉"的关键）
- 组合残差风险：`σ²_εA = Σ w_i² · σ²_εi`（假设残差互不相关）

于是主动组合的信息比率 `IR_A = α_A / σ_εA`——它衡量的是"每承担一单位残差风险，能换来多少 alpha"。

## 三、最优权重为什么是 alpha 除以残差方差

我们要选 `w_i` 让 `IR_A` 最大。这是个带约束的优化问题：在组合残差风险固定为某个值时，最大化组合 alpha。用拉格朗日乘子法，一阶条件给出：

`w_i ∝ α̂_i / σ²_εi`

**分母上的残差方差是整个模型的灵魂**。直觉是：同样 1% 的预测 alpha，来自一只残差风险 5% 的股票，比来自残差风险 12% 的股票"更可信"——前者信号噪声比更高，值得下更重的注。

本文实验 3 专门验证这一点：给 20 只股票**完全相同的 alpha**，只让残差风险从 5% 匀速升到 12%。TB 权重从 0.1174 单调降到 0.0204，最低残差股票的权重是最高残差股票的 **5.76 倍**。这个纯粹的"风险调整"效应，是naive等权方案完全做不到的。

## 四、整体夏普的勾股定理

TB 模型最漂亮的结论是怎么把主动组合和被动市场拼起来。设主动仓位比例为 `w`（`w=0` 全被动，`w=1` 全主动），投资者实际持有的组合收益是市场的 `(1−w)` 份加上主动组合的 `w` 份。经过推导，最优主动仓位是：

`w* = (α_A / σ²_εA) ÷ (μ_m / σ²_m)`

把它代回组合夏普，会得到一个惊人的恒等式：

`Sharpe² = Sharpe_m² + IR_A²`

市场的夏普和主动的信息比率，像直角三角形的两条直角边——主动能力越强，整体夏普按勾股定理往上走。本文实验 4 让 `IR_A` 从 0 扫到理论上限 0.4183，理论公式 `sqrt(0.15² + IR²)` 和数值求解最优仓位的结果**在所有点上完全一致**（如 IR=0.2836 时两者都是 0.3208）。图4 里蓝线和红点严丝合缝地重叠。

## 五、预测质量是生命线

理论很美，但主动投资的现实是：alpha 预测往往很不准。本文实验 1 把预测噪声从残差风险的 0.1 倍逐步放大到 3.0 倍，每个噪声水平重复 500 次，结果非常说明问题：

- **噪声 0.1 倍**（预测很准）：预测 IC 高达 0.546，实现 IR_A 达到 0.284，组合夏普从市场的 0.15 抬升到 0.3005——翻了一倍。此时最优主动仓位 `w*≈2.06`，但受"不加杠杆"约束封顶到 1。
- **噪声 1.0 倍**（噪声与残差同量级）：IC 掉到 0.049，IR_A 塌到 0.046，组合夏普只剩 0.1713。
- **噪声 3.0 倍**（几乎纯噪声）：IC 跌到 0.012，IR_A 只剩 0.045，组合夏普 0.1705，和市场相比所剩无几。

注意一个反直觉的细节：预测再差，TB 组合的夏普也没有跌破市场——因为当信号无价值时，`w*` 自动变小，组合退化成接近全被动。这正是贝叶斯收缩的稳健性：**它不会在噪声里强行下注**。

## 六、加权方式在噪声环境下的生死差

实验 2 把三种加权方案放在同一批带噪预测上重复 1000 次，用真实 alpha 评估实现 IR：

| 加权方案 | 平均实现 IR | 说明 |
|---|---|---|
| TB（除以残差方差） | **0.0606** | 正确方案，噪声中仍为正 |
| 只看信号强弱等权 | −0.0013 | 忽略残差风险，噪声中归零 |
| 集中押注前 5 名 | 0.0343 | 过度集中，丢掉分散化收益 |
| 完美预测上界 | 0.4183 | 真 alpha 已知时的理论天花板 |

三种方案都远低于完美预测上界——因为噪声就是噪声，再好的加权也变不出信息。但**正确加权（TB）在噪声中守住了正的 IR，而naive方案直接归零甚至转负**。这个差距在实盘里就是"勉强覆盖成本"和"稳定亏损"的区别。

## 七、贝叶斯视角：TB 其实就是一种收缩

标题里说"用贝叶斯把 Alpha 预测融进被动指数"，这一节把这件事讲透。把每只股票的收益看成两层结构：第一层是观察到的预测 `α̂_i`，它是真 alpha `α_i` 的带噪观测，`α̂_i = α_i + 误差`，误差方差与残差风险 `σ²_εi` 成正比；第二层是我们对真 alpha 的先验——在没有更多信息时，认为它均值为零、有一个先分散布。

在这个层次模型下做贝叶斯推断，真 alpha 的后验均值不是直接用观测 `α̂_i`，而是往先验均值（零）方向收缩，收缩的强度取决于"信号有多强、噪声有多大"。信号强、噪声小，就少收缩、接近原预测；信号弱、噪声大，就多收缩、接近零。数学上可以证明，当先验取无信息形式时，这个后验均值经过归一化，恰好正比于 `α̂_i / σ²_εi`——也就是 TB 权重。

这个视角解释了两件事。第一，为什么 TB 模型在噪声大时自动减小主动仓位：预测整体不可靠，后验均值整体被拉向零，主动组合的 alpha 估计趋近于零，`w*` 自然跟着变小，组合退回被动。这不是人为加的风控规则，而是贝叶斯推断的必然结果。第二，为什么它比"设一个固定仓位上限"更优雅：固定上限是拍脑袋的硬约束，而收缩是根据当下预测质量连续调整的软约束——数据说信号可信，就多配；数据说不可信，就少配。

理解了这一点，就能明白 TB 模型的适用边界：它依赖于"预测误差方差 ∝ 残差风险"这个假设。如果你的预测误差其实和残差风险无关（比如某个模型对高波动股票的预测反而更准），那 `α̂_i / σ²_εi` 就不是正确的贝叶斯权重，需要改用与真实误差结构匹配的收缩系数。

## 八、完整代码

```python
import numpy as np

# 参数：20 只股票，市场月超额收益 0.6%、月波动 4%
N, mu_m, sigma_m = 20, 0.006, 0.04
alpha_true = np.array([0.012, 0.010, 0.009, 0.008, 0.007,
                       0.006, 0.005, 0.004, 0.003, 0.002,
                       0.001, 0.0005, -0.0005, -0.001, -0.002,
                       -0.003, -0.004, -0.005, -0.006, -0.008])
sigma_e = np.linspace(0.05, 0.12, N)   # 残差风险 5%~12%

rng = np.random.default_rng(20261120)
error_scale = 1.0                       # 预测噪声 = error_scale × 残差风险
alpha_hat = alpha_true + rng.normal(0, error_scale * sigma_e, size=N)

# 核心：TB 最优主动权重 ∝ alpha_hat / sigma_e^2
b = alpha_hat / sigma_e**2
w = b / np.sum(b)                       # 归一化（允许做空，权重可负）

# 用真实 alpha 评估实现信息比率（关键：不能用预测值自欺欺人）
alpha_A = np.sum(w * alpha_true)
sigma_eA = np.sqrt(np.sum(w**2 * sigma_e**2))
IR_A = alpha_A / sigma_eA

# 最优主动仓位与整体夏普
w_star = (alpha_A / sigma_eA**2) / (mu_m / sigma_m**2)
w_use = min(max(w_star, 0.0), 1.0)      # 不加杠杆：封顶 100%
sharpe = (mu_m + w_use * alpha_A) / np.sqrt(sigma_m**2 + (w_use * sigma_eA)**2)
sharpe_theory = np.sqrt((mu_m / sigma_m)**2 + max(IR_A, 0)**2)

print(f"实现 IR_A = {IR_A:.4f}")
print(f"最优主动仓位 w* = {w_star:.3f}，实际使用 {w_use:.3f}")
print(f"组合夏普 = {sharpe:.4f}，理论 = {sharpe_theory:.4f}")
```

## 九、局限与实践提醒

第一，**`w_i ∝ α_i/σ²_εi` 里的 `σ²_εi` 必须是预测误差的方差，而不是股票的历史波动率**。很多人把两者混为一谈，结果给高波动股票错误地降权。这里的残差风险指的是"alpha 预测有多不可靠"，需要用预测误差的历史统计去估。

第二，**TB 假设残差互不相关**。现实中同行业股票的残差高度相关，直接套公式会低估组合的真实残差风险。实务中要先对残差做因子剥离，或用估计的残差协方差矩阵替代对角假设。

第三，**alpha 预测的 IC 才是真正的胜负手**。本文所有加权技巧加起来，也只是把噪声环境下的 IR 从 0 守到 0.06；而一个真正 high-IC 的预测能把 IR 抬到 0.28 以上。把 80% 的精力花在提升预测质量上，比在权重公式上精雕细琢更划算——这是 TB 模型给主动投资者最实在的提醒。
