"市场进入高波动状态了"——这句话谁说了算？拍脑袋不算数，需要一个检测器。变点检测（changepoint detection）有两个流派：**在线派**逐日累计证据、越阈报警，代表是 Page 1954 年的 CUSUM；**离线派**拿到全序列后做一次最优分割，代表是带 L1 惩罚的动态规划（PELT 一族）。本文在同一个合成市场上把两派放上解剖台：5 个真变点、50 次重复的功效曲线、120 次重复的检出延迟，以及一个谁都躲不掉的暗坑——**均值漂移会被平方收益出卖，长得跟波动跳跃一模一样**。

结论先行（全部来自本文现场计算，seed=20261027）：

**① 在线 CUSUM 对"持续升高的长波段"很灵，对中等跳跃可以整体失明。** 主序列（T=1200、5 真变点）上 CUSUM 用重尾置换校准阈值 $h = 137.9$、松弛量 $k = 3.42$，7 次告警只命中 2/5：day 820 的下跌变点提前 35 天"预警"（其实是前一个高波段的累积告警落在容差内），day 560 晚 34 天；而 day 150 那个 2.5× 的向上跳跃——逐日净增量 $4.00 - 0.64 - 3.42 = -0.06$，统计量**永远爬不到阈值**。

**② PELT  offline 定位近乎靶心，但惩罚 β 是唯一的生死钮且两全不存在。** β=27 时断出 [149, 560, 819, 1019]：命中的 4 个变点里 3 个偏移 ≤1 天、0 虚警；漏掉的是 0.6× 的温和降（σ 2.0→1.2）。扫描 46 档 β：零虚警带 [23, 50] 内最多命中 4/5，能全命中的带 [5, 11] 必带虚警——**"零误报"与"抓全 5 个"没有任何一个 β 能同时做到**。

**③ 功效是有价格的。** 每档 50 次 MC（T=400、变点在 200 天）：CUSUM 在跳幅 ×1.6 越过 80% 功效线（96%），PELT（β=22）要 ×1.8（84%）。但 CUSUM 的高功效是买来的——跳跃发生前它的实测虚警率 **0.284 次/天**，约 12 天就来一次狼来了。

**④ 在线检出的延迟代价约一周。** 对 ×2.4 的跳跃做 120 次 MC，CUSUM 首次告警延迟中位 **2 天**、均值 3.5 天、P90 **7.1 天**；PELT 因为是离线全量优化，断点偏移中位 1 天内。

**⑤ 冷水：σ 全程恒定时，均值漂移照样触发两个检测器。** σ≡1.0、均值从 0 阶跃到 0.9%（无波动变化）：CUSUM 告警 14 次，PELT β=27 断 3 刀（464/622/647）。均值线性漂到 1.6%：CUSUM 告警 40 次，越漂越密。两者都是"对方差负责"的检测器——**先去均值，再谈波动 regime**。

## 一、考场：合成波动率阶梯市场

1200 个交易日，日收益 $r_t \sim \mathcal{N}(0, \sigma_t^2)$，σ 分 6 段：

$$\sigma = [0.80,\ 2.00,\ 1.20,\ 2.60,\ 0.90,\ 1.80]\%$$

真变点在 day 150 / 380 / 560 / 820 / 1000，相邻跳幅依次 **2.5×↑、0.6×↓、2.17×↑、0.35×↓、2.0×↑**——大跳小跳、升跳降跳都齐了。两个检测器都只看平方收益 $x_t = r_t^2$（均值为零时它是方差信息的全部载体）。

![合成阶梯市场与 CUSUM 轨迹](/images/change-point-detection-volatility-jump/fig1_cusum_path.png)

上图第三行就是 CUSUM 的双侧统计量轨迹。它的递推只有一行：

$$S_t^+ = \max\!\big(0,\ S_{t-1}^+ + (x_t - m_0 - k)\big), \qquad S_t^- = \max\!\big(0,\ S_{t-1}^- - (x_t - m_0 - k)\big)$$

任何一侧越过阈值 $h$ 即告警并双双清零复位（标准 PP 图语义）。$m_0$ 是"正常状态"下 $r^2$ 的参照水平（本文用首段估计 0.64），$k$ 是松弛量——设计用来忽略小噪声、只对"足够大"的漂移累计。

## 二、CUSUM：三个旋钮，两个坑

三个旋钮 $m_0, k, h$ 里，$h$ 不能拍脑袋：$r^2 = \sigma^2\chi_1^2$ 是重尾右偏分布（单侧 $\chi_1^2$ 的 95 分位是均值的约 5.4 倍，偶发一个大 $r^2$ 顶好几天），拿正态近似定阈会荒腔走板。本文用**置换校准**：把序列打乱 60 次（保留单点边缘分布、毁掉全部时序结构），每次跑同一个 CUSUM 记峰值，取 95 分位——$h = 137.9$。

这条校准路径直接决定了主序列的命运：$k = 0.5\,\widehat{\mathrm{std}}(r^2) = 3.42$（std 被 5 个跳跃段的全样本抬到 6.85）。day 150 处 σ 从 0.8 跳到 2.0，高波段 $x_t$ 均值约 4.00，逐日净增量 $4.00 - 0.64 - 3.42 = -0.06 < 0$：$S^+$ 永远累不起来，**这个 2.5× 的大跳跃在实盘式在线设置下直接失明**。而 day 560 之后 σ=2.6 的长波段净增量 +2.7/天，约 51 天即可越阈一次，于是告警成串——主序列 7 次告警里 5 次都堆在长波段内部与末尾，day 820 变点反而"提前 35 天被预警"。同一个算法、同样的功效扫描设定下（k、m₀ 用自己的 400 天样本重算），×2.5 档检出率却是 100%——**参数口径是跟着样本走的，文章里的每个"灵"与"不灵"都换不过参数**。

## 三、PELT：一次动态规划，买断全序列最优分割

离线派不问"今天有没有跳"，而是问"整条序列分成几段、断在哪，总成本 + β×段数最小"：

$$F(T) = \min_{\text{分割}} \sum_{\text{段}} \mathrm{cost}(\text{段}) + \beta \times (\text{段数} - 1)$$

成本取 $\log r^2$ 的分段常数高斯负对数似然，前缀和让任意段成本 O(1) 查询，DP 递推 $F[t] = \min_s F[s] + c(s,t) + \beta$ 精确求解（每段至少 10 天防逐点退化）。β 越小越敢断——它就是唯一定生死的旋钮：

![PELT 惩罚 β 扫描](/images/change-point-detection-volatility-jump/fig2_pelt_beta.png)

扫 β∈[5, 50]：β 一大检出数单调下降（过分割区→欠分割区），存在一个**零虚警带 β∈[23, 50]**，其中以 β=27 检 [149, 560, 819, 1019] 表现最好——对得上 4 个真变点（149↔150 偏移 1 天、560 精确、819↔820 偏移 1 天），0 误报；漏掉的是 day 380 的 σ 2.0→1.2（0.6× 温和降，信号最弱）。想要全 5 个？β 必须压进 [5, 11]，那个带里段数膨胀、虚警必现。**"宁可错杀"和"一个不漏"在 β 轴上是两段不相交的区间**，这不是调参水平问题，是 L1 惩罚的固有取舍。

## 四、功效与延迟：在线买灵敏度，付出虚警与滞后

把"一次真跳跃能不能抓到"做成 MC：T=400、变点在 200 天、基准 σ=0.8%、跳幅从 ×1.2 扫到 ×3.0，每档 50 次重复；CUSUM 阈值用跳跃前段位置校准，PELT 固定 β=22。

![跳跃幅度 × 检出功效](/images/change-point-detection-volatility-jump/fig3_power.png)

两条曲线都是 S 形右移：**CUSUM 在 ×1.6 过 80% 线（96%），PELT 要到 ×1.8（84%）**。在线派赢在"更早、更敢"，账单在段前虚警：跳跃发生前 CUSUM 实测告警 **0.284 次/天**（≈12 天一次狼来了）；PELT 没有"实时虚警"这个概念，但它的保守把 ×1.2~×1.4 的小跳跃几乎全部漏掉（6%/18%）——离线派不是不犯错，是把错犯在"装作无事发生"。

延迟侧：主序列 CUSUM 的命中偏移 +34/−35 天被大 k 拖累，参考价值有限；干净的测量是 ×2.4 跳跃的 120 次 MC：

![逐变点偏移与在线延迟分布](/images/change-point-detection-volatility-jump/fig4_lag.png)

120 次全部检出，CUSUM 首告延迟（变点后天数）中位 **2 天**、均值 3.5 天、P90 **7.1 天**。换句话说：**在线检测的信息损失 ≈ 一周行情**。同期 PELT 断点偏移 1/−/0/1/19 天（day 1000 那个跳到 1019，边界附近成本曲面平，DP 把刀挪了 19 天）——离线定位比在线告警准一个数量级，这是它存在的理由。

## 五、冷水：均值漂移在 r² 眼里就是波动

最阴的坑：两个检测器都吃 $r^2$，而 $r^2$ 不区分"波动变大"和"均值走偏"。构造 σ≡1.0 全程恒定的两段（T=900）：(a) 均值在 day 450 从 0 阶跃到 0.9%/天——一个纯趋势；(b) 均值从 0 线性漂到 1.6%/天。阈值用无漂移前段置换校准（h=7.98）。

![均值漂移的虚警实拍](/images/change-point-detection-volatility-jump/fig5_false_alarm.png)

结果：阶跃均值序列 CUSUM 告警 **14 次**（day 143 一次纯属噪声，其余 13 次全在均值漂移之后）、PELT β=27 断 **3 刀** [464, 622, 647]——第一刀离均值阶跃点 450 只差 14 天，因为趋势确实改变了 $\log r^2$ 的分布，它"瞎猫撞上死耗子"，后两刀是纯过分割。线性漂移序列告警密度随斜率走高：首告在 day 360（漂移累计 ≈0.64% 时），最后 250 天里告了 30+ 次，PELT 也在 [590, 638] 断了两刀。**如果你的收益里混着未剥离的 α 或趋势，波动率 regime 检测器会把趋势读成恐慌**——上线之前，先去均值（或至少减掉策略基准）。

## 六、可运行核心代码

CUSUM（复位型双侧递推）与 PELT（精确 DP）核心，numpy 即可跑：

```python
import numpy as np

def cusum_reset(x2, k, h, m0):
    """双侧 CUSUM：S± 越阈 h 告警并复位。返回统计量轨迹与告警时刻。"""
    n = len(x2); sp = np.zeros(n); sn = np.zeros(n); al = []
    splus = sminus = 0.0
    for t in range(n):
        splus = max(0.0, splus + (x2[t] - m0) - k)
        sminus = max(0.0, sminus - (x2[t] - m0) - k)
        if splus > h or sminus > h:
            al.append(t); splus = sminus = 0.0
        sp[t], sn[t] = splus, sminus
    return sp, sn, al

def pelt_l1(x2, beta, lmin=10):
    """PELT 式精确最优分割：log r² 分段高斯成本 + β×段数，前缀和 O(1) 段成本。"""
    v = np.log(x2 + 1e-12); n = len(v)
    c1 = np.concatenate([[0.0], np.cumsum(v)])
    c2 = np.concatenate([[0.0], np.cumsum(v * v)])
    F = np.full(n + 1, np.inf); F[0] = -beta
    bk = np.zeros(n + 1, dtype=int)
    for t in range(1, n + 1):
        s = np.arange(0, t - lmin + 1)
        if len(s) == 0: bk[t] = 0; continue
        m = t - s; s1 = c1[t] - c1[s]; s2 = c2[t] - c2[s]
        mu = s1 / m
        var = np.maximum(s2 / m - mu * mu, 1e-8)
        cost = np.where(m >= lmin, m * (np.log(var) + 1) + beta, np.inf)
        costs = F[s] + cost
        j = int(costs.argmin()); F[t] = costs[j]; bk[t] = int(s[j])
    cps = []; t = n
    while t > 0:
        s = bk[t]
        if s > 0: cps.append(s)
        t = s
    return sorted(cps)
```

CUSUM 与 PELT 不是竞品，是流水线：**离线 PELT 标 regime、校准阈值与标注历史，在线 CUSUM（先 z 分数化、k 对着待检跳幅调）盯实时切换**，均值漂移坑用去均值绕开。检测器不会告诉你市场"为什么"变了，它只告诉你"数字上"变了——把这句话印在风控部的墙上，能省很多钱。
