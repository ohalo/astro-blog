做因子研究的人迟早会撞上同一个取舍：**没有一种模型能通吃所有因子形态**。线性回归干净可解释，但遇到 `tanh`、`sin`、二次项这类非线性信号就只剩线性近似的残差；决策树能抓阈值和曲率，却对全局趋势和边缘外的外推很笨；Ridge 把所有特征一锅炖，噪声因子混进来就悄悄过拟合。把鸡蛋放在一个篮子里，盲点就是你的回撤。很多人图省事，直接把几个模型的预测取个平均就当「集成」用——但这既浪费了模型间的互补信息，也保留了噪声模型带来的拖累。

**集成学习里的 Stacking（堆叠）**给出一条干净的路：不纠结「哪个基学习器最好」，而是训练一个**元学习器（meta-learner）**，把若干个归纳偏置各异的基学习器的预测再组合成最终信号。它比盲目平均聪明的地方在于，权重是「学」出来的——谁的样本外解释力高、谁和别人冗余，元模型自己会用系数表态。本文在 300 只股票 × 120 期（共 36000 条横截面观测）的合成面板上，用纯 numpy 从零实现四种基学习器 + 一个线性元学习器，并严格防止信息泄漏地做样本外评估。结果很说明问题：**样本外 Rank-IC 从最佳单模型的 0.096 提升到 0.134（相对 +40%），毛多空 Sharpe 从 2.61 提升到 3.55**，而元学习器的权重还顺手暴露了它更信任哪类专家。

## 一、数据：故意埋了非线性与噪声

为了让「单一模型有盲点」这件事可被量化，我构造了一个诚实的合成面板：5 个因子里前 3 个携带**非线性**真实信号，后 2 个是纯噪声；真实前向收益由三项非线性信号叠加，再叠一层**逐期波动率体制（异方差）**——安静期与动荡期交替，使多空收益的跨期波动贴近真实：

```python
import numpy as np
rng = np.random.default_rng(20261028)
N_STOCK, N_PER = 300, 120
n = N_STOCK * N_PER
period = np.repeat(np.arange(N_PER), N_STOCK)
F = rng.normal(0, 1, size=(n, 5))              # 5 个因子
signal = (0.9 * np.tanh(0.9 * F[:, 0])         # 非线性①
          + 0.7 * np.sin(F[:, 1])               # 非线性②
          + 0.5 * (F[:, 2] ** 2 - 1.0))         # 非线性③（二次）
v_t = rng.lognormal(0, 0.6, size=N_PER)         # 逐期波动体制
v = v_t[period]
y = signal + rng.normal(0, 1, size=n) * 8.0 * v  # 含噪声的前向收益
```

三类基学习器会被这个设定各自卡住：线性模型只能线性近似 `tanh`/`sin`，漏掉曲率；而 `f2²` 这一项，线性模型若没显式造出二次特征也抓不到。

## 二、四个基学习器：归纳偏置各异的「专家」

Stacking 的前提是基学习器**多样**——如果四个模型本质一样，堆叠只是浪费算力。我故意让它们各有所长（全部纯 numpy，无第三方库）：

```python
def linreg(X, y):
    Xd = np.hstack([np.ones((X.shape[0], 1)), X])
    beta, *_ = np.linalg.lstsq(Xd, y, rcond=None)
    return beta
def ridge(X, y, alpha=2.0):
    Xd = np.hstack([np.ones((X.shape[0], 1)), X])
    A = Xd.T @ Xd + alpha * np.eye(Xd.shape[1])
    return np.linalg.solve(A, Xd.T @ y)
def stump(X, y):
    """单变量决策树桩：在最优特征的均值处二分"""
    best = None
    for j in range(X.shape[1]):
        thr = np.median(X[:, j]); left = y[X[:, j] <= thr]; right = y[X[:, j] > thr]
        if len(left) == 0 or len(right) == 0: continue
        err = ((left-left.mean())**2).sum() + ((right-right.mean())**2).sum()
        if best is None or err < best[0]:
            best = (err, j, thr, left.mean(), right.mean())
    return best[1:]

# 四位专家：不同特征子集 / 不同归纳偏置
bases = {
    "M1_线性(f0,f1)": lambda X, y: linreg(X[:, [0, 1]], y),
    "M2_二次(f2)":    lambda X, y: linreg(np.c_[X[:, 2], X[:, 2]**2], y),  # 显式吃 f2²
    "M3_树桩(f0)":    lambda X, y: stump(X[:, [0]], y),
    "M4_Ridge(全)":   lambda X, y: ridge(X, y, alpha=2.0),
}
```

注意 M2 把 `f2` 的二次型**显式**加进特征，专门吃掉真实信号里的 `(f2²−1)` 项；M3 的决策树桩则用阈值去逼近 `tanh(0.9·f0)` 的台阶形状。四种偏置互补，这正是堆叠能增值的土壤。

## 三、泄漏安全的 Stacking：必须用 Out-of-Fold 预测

Stacking 最容易被做错的一步，是用**基学习器在自己训练集上的预测**去训练元学习器——这会把训练集的过拟合原封不动喂给元模型，样本外瞬间崩盘。正确做法是 **5 折交叉验证**生成**样本外（out-of-fold, OOF）预测**，元学习器只在 OOF 预测上训练；最后基模型用全部训练集重训，再去预测测试集。

![Stacking 相对单模型的样本外 Rank-IC 与多空 Sharpe](/images/ensemble-stacking-factors/fig1_oos_ic_sharpe.png)

```python
fold = rng.integers(0, 5, size=Xtr.shape[0])
oof = {name: np.zeros(n_tr) for name in bases}
for f in range(5):
    in_f, out_f = fold != f, fold == f
    for name, train in bases.items():
        b = train(Xtr[in_f], ytr[in_f])
        oof[name][out_f] = pred_funcs[name](b, Xtr[out_f])
# 元学习器：对 OOF 预测做线性回归
Xmeta = np.vstack([oof[name] for name in bases]).T
beta_meta, *_ = np.linalg.lstsq(np.hstack([np.ones((n_tr,1)), Xmeta]), ytr, rcond=None)
```

## 四、样本外结果：堆叠确实更强

在最后 20% 期（测试集）上，我同时算了**样本外 Rank-IC**（每期 Spearman 均值，因子研究的标准指标）和**五分位多空毛 Sharpe**（前/后 20% 多空，未扣交易成本）。结果如下：

| 模型 | 样本外 Rank-IC | 毛多空 Sharpe |
|------|---------------|--------------|
| M1 线性(f0,f1) | 0.096 | 1.25 |
| M2 二次(f2) | 0.088 | 2.61 |
| M3 树桩(f0) | 0.056 | 1.73 |
| M4 Ridge(全) | 0.087 | 1.53 |
| **集成 Stacking** | **0.134** | **3.55** |

两个指标一致指向同一个结论：**Stacking 的样本外 Rank-IC 0.134 比最佳单模型（M1 的 0.096）高出约 40%，毛 Sharpe 3.55 也比最佳单模型（M2 的 2.61）高出约 36%**。差距不是噪声——它来自「把多个互补专家的视角融合」带来的**方差缩减**与**信号互补**。堆叠预测与真实收益的 Spearman 相关系数达到 **0.097**，散点随预测单调抬升：

## 五、元学习器说了实话：它更信任谁

元学习器就是一层线性回归，它的系数直接告诉我们「最终信号里，每个专家占多大权重」：

![元学习器给各基学习器的线性权重](/images/ensemble-stacking-factors/fig3_meta_weights.png)

权重分别是 **M1 = +1.27、M2 = +0.97、M3 = +0.27、M4 = −0.48**。三个信号值得出的结论很有意思：

1. **M1、M2 被重仓**：线性专家（吃 `tanh`/`sin` 的线性投影）和二次专家（吃 `f2²`）各自贡献了最干净的信号分量，元模型自然给最高权重。
2. **M3 树桩只拿零头（+0.27）**：树桩只在 `f0` 上做阈值，信息量和 M1 大量重叠，所以被「挤」成了配角而非主角。
3. **M4（Ridge 全特征）被赋负权 −0.48**：这是最值得玩味的一点。把所有特征一锅炖的「通才」不仅没被信任，反而被元模型**反向对冲**——因为它把 `f3`、`f4` 两个噪声因子也吃了进去，引入了 M1/M2 没有的额外噪声，元模型学会用负权重来抵消这部分冗余。换句话说，Stacking 没有盲目迷信「特征越多越好」，而是用权重把通才的噪声部分中和掉了。

## 六、为什么是 Stacking，而不是简单平均

很多人会问：把四个模型的预测取个平均不就行了？区别在于**加权是学出来的，不是拍脑袋**。`M1+M2` 的简单等权会忽略 M3 的边际信息，也会保留 M4 的噪声；而元学习器在 OOF 预测上做的线性回归，自动按「谁的样本外解释力高、谁和别人冗余」来分配权重。本文里 M4 得到负权，就是这种自动去冗余的直接证据——这是等权做不到的。

## 七、边界与注意事项

- **多样性是前提**：基学习器必须真正异构。四个都是同构的线性模型，堆叠几乎不会增值，只是徒增复杂度与过拟合面。一个实用的监控手段是算基模型预测间的相关系数——若两两相关都高于 0.95，说明它们本质在重复同一件事，堆叠的空间非常有限；理想状态是相关性中等（0.3–0.7），既共享一部分真信号、又各自携带独特视角。
- **泄漏是头号杀手**：元学习器只能在 OOF 预测上训练。任何用训练集内预测喂元模型的做法，都会让样本外惨案在回测里看起来很美。交叉验证的折数也不宜太少，折太少意味着每折的训练集和验证集重叠度高，OOF 预测仍会沾染过拟合气息，建议 5 折起步。
- **垃圾进垃圾出**：Stacking 提升的是「在给定基模型基础上的信号提纯」，它救不了四个基模型都没捕获的真实 Alpha；基模型弱，堆叠天花板也低。换言之，先把手里的基模型做对、做干净，再谈堆叠，顺序不能反。
- **成本与可解释性**：多模型并行训练、推理成本更高；虽然元权重可解释，但整体仍是「黑箱信号」，实盘前仍需做 ICIR、换手、分层回测等稳健性检验。尤其要警惕元权重在样本内「过度讨好」某一个过拟合基模型——可用滚动窗口观察权重是否稳定，若权重剧烈漂移，往往是某个基模型在样本内偶然拟合、样本外会塌方的前兆。

## 八、结论

因子堆叠 Stacking 不是玄学，而是一种**把异构专家的互补视角，用一层线性回归安全地融合**的工程方法。在本文的合成面板上，它把样本外 Rank-IC 从 0.096 推到 0.134、毛 Sharpe 从 2.61 推到 3.55，同时用权重自动「重仓真专家、负权对冲噪声通才」。所有代码纯 numpy 可运行——你把 `F`、`y` 换成自己的因子矩阵和真实前瞻收益，跑一遍同样的 OOF 流程，就能拿到属于你自己的堆叠信号与元权重。真正落地时，记得把「泄漏安全」和「基模型多样性」这两条红线焊死。
