## 一、结论先行

高斯世界里的波动率是一个常数：今天和明天只差一个 $\sqrt{t}$。市场不是这样——对数收益的直方图总有更胖的左尾，期权微笑也从不对称。Variance Gamma（VG）不往价格上直接加跳，而是把**时钟**换成随机的：用一条单调递增的 Gamma 过程 $G_t$ 替掉日历时间，让布朗运动在这条被随机拉伸/压缩的时间轴上行走。一个参数 $\nu$ 控制时间抖动的剧烈程度，跳跃形状就自己长出来了。

我在固定种子 `20261126` 的合成实验里得到几个能直接拿去对拍的数字：

- 4000 条年度对数收益的样本偏度 **-0.864**、超额峰度 **1.458**，而同均值同方差的正态分布按定义只能是 **0 / 0**；
- 用四个累积量做矩匹配，$\hat\theta=-0.2214$（真值 -0.22）几乎无偏，但 $\hat\nu=0.273$ 对真值 0.35 偏低 **22%**——高阶矩只估出"有跳"，估不准"跳多密"，这是诚实的负面结果；
- $S_0=100,\ r=4\%,\ T=0.25$，VG 傅里叶价与 20 万条 Gamma 时间变换路径的 MC 价，在 $K=80$ 与 $K=120$ 上分别只差 **-0.45 / +0.39 个标准误**；看涨看跌平价残差精确为 **0**；
- 把 at-the-money 反解出的 **19.32%** 隐含波动当一条平线（总波动其实是 22.21%），$K=90$ 看涨价被低估 **0.6384**，$K=110$ 被高估 **0.4963**，虚值看跌一侧的错价可达 3 位有效数字；
- 定价积分的截断更阴险：$T=1$ 时上限 $U=200$ 的误差只有 $2\times10^{-8}$，$T=0.02$ 时同样 $U$ 偏 **0.111**，推到 $U=3200$ 还有 **0.0038** 的震荡残差。短期限不是模型坏了，是特征函数衰减太慢。

## 二、模型：把时间换成 Gamma 时钟

令 $G_t\sim\mathrm{Gamma}(t/\nu,\ \nu)$，均值 $t$、方差 $\nu t$；$\nu\to0$ 时它退化成确定性时间。定义

$$
X_t=\theta G_t+\sigma W_{G_t},
$$

$W$ 是标准布朗运动。给定 $G_t=g$ 时 $X_t\mid g\sim\mathcal N(\theta g,\ \sigma^2 g)$，把 $g$ 积掉得到特征函数

$$
\phi_X(u)=\mathbb E[e^{iuX_t}]=\Bigl(1-i\theta\nu u+\tfrac12\sigma^2\nu u^2\Bigr)^{-t/\nu}.
$$

它足够光滑，又允许任意阶累积量，定价时不必写无穷多个跳项。对 $t=1$，前四阶累积量为

$$
\kappa_1=\theta t,\quad \kappa_2=(\sigma^2+\theta^2\nu)t,
$$
$$
\text{skew}=\frac{3\theta\sigma^2\nu+2\theta^3\nu^2}{(\sigma^2+\theta^2\nu)^{3/2}\sqrt t},\quad
\text{ex.kurt}=\frac{6\sigma^4\nu+12\theta^2\sigma^2\nu^2+6\theta^4\nu^3}{(\sigma^2+\theta^2\nu)^2t}.
$$

注意**总方差不是 $\sigma^2t$**，而是 $(\sigma^2+\theta^2\nu)t$：漂移项在随机时钟上也在抖动。本文真值 $\theta=-0.22,\ \sigma=0.18,\ \nu=0.35$ 对应总波动 22.21%、偏度 -0.921、超额峰度 2.10；4000 条样本给出 -0.864 / 1.458，抽样误差已经不小，这正是 $\nu$ 估不准的根源。

```python
import numpy as np
from scipy.optimize import least_squares

def cumulants(theta, sigma, nu, t=1.0):
    k2 = (sigma**2 + theta**2 * nu) * t
    k3 = (3*theta*sigma**2*nu + 2*theta**3*nu**2) * t
    k4 = (6*sigma**4*nu + 12*theta**2*sigma**2*nu**2 + 6*theta**4*nu**3) * t
    return theta*t, k2, k3/k2**1.5, k4/k2**2

def simulate_vg(n, t, theta, sigma, nu, rng):
    g = rng.gamma(shape=t/nu, scale=nu, size=n)   # random clock
    return theta*g + sigma*np.sqrt(g)*rng.standard_normal(n)
```

## 三、从报价反推参数：四个矩就够，但别高估精度

矩匹配的目标函数用样本均值、方差、偏度、超额峰度四个数，方差和峰度按目标量级归一化，否则优化器只会盯着最大的那个。结果 $\hat\theta=-0.2214$、$\hat\sigma=0.1849$、$\hat\nu=0.2733$：均值几乎完美，拟合出来的偏度 -0.754 对样本 -0.864 偏低，峰度 1.640 对 1.458 偏高。也就是说，四条矩只能同时满足"大致形状"，$\nu$ 与 $|\theta|$ 之间存在现实的识别弱性。

真要上生产，正确做法是用特征函数做经验 CF 拟合，或直接对数值反演的密度做极大似然；矩匹配的用途是**给优化器一个好的起点**。图一里的拟合密度来自对 $\phi_X$ 做数值反演 $f(x)=\frac1\pi\int_0^\infty\Re(e^{-iux}\phi_X(u))du$，与样本直方图和正态对照放在一起，左尾的差异肉眼可见。

## 三之一、与 Heston、局部波动率的分工

既然都在解释微笑，为什么不直接用 Heston 或 Dupire 局部波动率？差别在**波动的来源**。Heston 让方差均值回复，擅长刻画波动聚集与期限结构；VG 的随机时钟是纯跳跃的无限活动过程，一秒内可以有无穷多次微小跳跃，但没有独立的均值回复机制。若标的在危机中呈现持续数周的高波动平台，Heston 的路径分布更接近现实；若主要是收益分布的偏斜与峰度需要一次性解释，VG 的三参数更省事。

Dupire 局部波动率能把欧式期权价格逐点拟合得极好，但它假设瞬时波动是现货与时间的确定性函数，路径层面的动态对冲表现常常与隐含波动率的演化矛盾。VG 反过来：它只承诺一组与欧式价格一致的边缘分布，微笑由 $\theta,\sigma,\nu$ 三个数共同决定，不能精确贴合任意一条市场曲线。交易台上更常见的做法是拿 VG 做**跨执行价的相对价值与风险因子**，再用 SVI 之类的参数化做逐点报价校准；把两者混为一谈，会既丢掉 VG 的紧凑性，又丢掉 SVI 的拟合度。

VG 还有一个实用的数学优势：累积量有闭式解、特征函数只有幂函数，标定和定价都不需要解 PDE 或跑大路径模拟。本文 13 个执行价的傅里叶定价全部在秒级完成，这在小规模研究里比理论优雅更值钱。代价是 $\theta$ 与 $\nu$ 在有限样本下纠缠——这也是矩匹配把 $\nu$ 低估 22% 却几乎不影响 $\theta$ 的原因。

## 四、定价： martingale 修正别漏掉符号

风险中性下 $\log S_T=\log S_0+(r-q+\omega)T+X_T$，其中

$$
\omega=\frac1\nu\ln\!\bigl(1-\theta\nu-\tfrac12\sigma^2\nu\bigr)<0
$$

（因为 $\mathbb E[e^{X_T}]=(1-\theta\nu-\sigma^2\nu/2)^{-T/\nu}$）。很多人把 $\omega$ 写成负的对数，结果是所有看涨价一起虚高。$\theta\nu+\sigma^2\nu/2<1$ 是必须检查的存在条件。

用 Gil-Pelaez 反演两个概率：

$$
P_2=\frac12+\frac1\pi\int_0^\infty\frac{\Im(e^{-iu\ln K}\phi_Y(u))}{u}\,du,\qquad
P_1=\frac12+\frac1\pi\int_0^\infty\frac{\Im(e^{-iu\ln K}\tilde\phi(u))}{u}\,du,
$$

其中 $\tilde\phi(u)=e^{iu m+\omega T}\phi_X(u-i)$ 是股票测度下的特征函数，$m=\ln S_0+(r-q+\omega)T$。看涨价 $C=S_0e^{-qT}P_1-Ke^{-rT}P_2$。把 $1/(iu)$ 写成 $-i/u$ 之后积分里只剩虚部，数值上比直接处理复数除法稳得多。

```python
from scipy.integrate import quad

def cf_x(u, t, theta, sigma, nu):
    u = np.asarray(u, dtype=complex)
    return (1 - 1j*theta*nu*u + 0.5*sigma**2*nu*u**2)**(-t/nu)

def price_vg(K, T, theta, sigma, nu, umax=1500.0):
    om = np.log(1 - theta*nu - 0.5*sigma**2*nu)/nu
    m  = np.log(S0) + (R-Q+om)*T
    phi     = lambda u: np.exp(1j*u*m)*cf_x(u, T, theta, sigma, nu)
    phi_s   = lambda u: np.exp(1j*u*m + om*T)*cf_x(u-1j, T, theta, sigma, nu)
    def prob(ph):
        f = lambda u: np.imag(np.exp(-1j*u*np.log(K))*ph(u))/u
        v, _ = quad(f, 1e-8, umax, limit=600, epsabs=2e-10)
        return 0.5 + v/np.pi
    return S0*np.exp(-Q*T)*prob(phi_s) - K*np.exp(-R*T)*prob(phi)
```

数值积分从 $10^{-8}$ 起而不是 0，是为了避开 $1/u$ 的奇点；上限 1500 对应 $T=0.25$ 的精度已足够，短期限必须另行检查。每算完一个价格，顺手检查 $0\le P_1,P_2\le1$ 并且 $P_1\ge P_2$ 在合理范围内：这两个概率跑出区间通常意味着特征函数的复数分支或漂移修正写错，比看价格本身更容易定位。若要做整条微笑的高频报价，把 Gil-Pelaez 换成带阻尼因子的 Carr-Madan FFT 会快得多；但阻尼参数会引入新的截断偏差，两种实现至少要在几个执行价上互相验证过才能上线。

一组便宜的自检：深度实值 $K=20,\ T=1$ 的看涨价 **80.78424**，理论上界 $S_0-Ke^{-rT}=$ **80.78421**，差 $3\times10^{-5}$；$K=90/100/110$ 三个执行价的看涨看跌平价残差都是 **0**。平价过了不代表定价对——上一节那种漂移符号错误同样满足平价，必须靠深度实值极限单独抓。

## 五、平线波动率错在哪里

把 $K=100$ 的 VG 价格反解成 Black-Scholes 波动率，得到 19.32%，比总波动 22.21% 低 2.89 个百分点。用这条平线给整条曲线报价：

- $K=90$：VG 价 **12.0510**，平线价 11.4125，低估 **0.6384**；
- $K=110$：VG 价 **0.5467**，平线价 1.0430，高估 **0.4963**；
- $K=70$ 看涨差 **0.1003**，$K=80$ 差 **0.3416**，都是同方向的系统性偏低。

隐含波动率从 $K=70$ 的 **35.28%** 单调降到 $K=110$ 的 **15.44%**，右端再翘回 19.06%。这是左偏和峰度共同作用的标准形状：平线波动率在 ATM 校准得再漂亮，只要拿它给虚值看跌定价，就会系统性少收风险溢价。

## 六、蒙特卡洛对拍：同新息、同修正

MC 直接用 Gamma 增量：$g\sim\Gamma(T/\nu,\nu)$，$X=\theta g+\sigma\sqrt g Z$，再用同一个 $\omega$ 做漂移修正。$K=80$ 与 $K=120$ 上 20 万路径的价格分别是 **21.1508** 与 **0.07846**，傅里叶参考价 **21.1600** 与 **0.07762**，z 分数 **-0.45** 与 **+0.39**；两条路径的 2 倍标准误带都稳稳包住参考价。

![MC 向傅里叶价格收敛](/images/variance-gamma-time-change/fig3_mc_convergence.png)

要特别小心：如果 MC 里的 $g$ 与 $Z$ 用了不相关的随机数，或者把 $\omega$ 写成 $-\ln(\cdot)/\nu$，价格会安静地偏几个百分点，而收敛曲线看起来依然很漂亮。**收敛不等于无偏**。

## 七、短期限：特征函数衰减慢，积分别乱截

$\phi_X(u)\sim u^{-2T/\nu}$，指数里带着 $T$。$T=1,\ \nu=0.35$ 时衰减幂约 5.7，$U=200$ 就够；$T=0.02$ 时幂只有 0.114，$U=200$ 的 $K=90$ 看涨价还偏 **0.111**，$U=3200$ 仍残留 **0.0038** 的震荡。$T=0.25$ 的中间情形在 $U=200$ 时误差 $4.6\times10^{-4}$，到 $U=1600$ 压到 $1.8\times10^{-5}$。

![傅里叶积分截断误差](/images/variance-gamma-time-change/fig4_truncation.png)

实盘里短期限期权通常还有离散股息、美式特征和买卖价差，模型误差本来就不小；但**积分截断误差是自己制造的**，完全可以靠自适应求积、阻尼变换（Carr-Madan 的 $\alpha$ 阻尼）或者提高上限消掉。上线前固定一组短期限报价，把 $U$ 翻倍看价格变不变，比任何单元测试都直接。

## 八、边界与实盘提醒

VG 是纯跳跃的无限活动模型，没有独立的扩散项；真实市场的日内高频波动往往还需要一层连续扩散（即 VG 加布朗，或更一般的 Lévy 过程）。它的参数在时间上也不稳定：$\theta$ 吸收偏度、$\nu$ 吸收峰度，危机期两者会同时漂移，用一年数据拟合出的静态参数给一周期权定价很危险。本文的正向 MC 是同分布精确模拟，不是欧拉离散；换成近似格式会额外引入偏差，那部分不能算到模型头上。
