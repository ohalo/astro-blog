## 一、结论先行

给期权定价，最省事的路线是绕开密度函数本身，直接玩它的傅里叶变换。Carr-Madan 的 FFT 法要跑一次快速傅里叶变换、再做一次阻尼和插值；COS 方法（Fang & Oosterlee, 2008）更干脆：把对数价格密度在一块有限区间上展开成余弦级数，级数的系数由特征函数在等间距频率点上的取值给出，而期权价格是「收益函数 × 余弦基」的积分——这一项对看涨看跌都有解析式。于是整个定价只剩一次向量化的矩阵乘法。

我把这条路径从头实现了一遍，并用三个独立角度交叉验证：

- **对解析解**：7 个执行价（70 到 130）× 3 个期限（0.25/1/3 年），COS 与 Black-Scholes 解析价的最大绝对误差 **3.48e-13**，ATM 执行价只有 **1.95e-14**，已经是双精度浮点数的地板。
- **对收敛性**：余弦项数 N=16 时 ATM 误差 0.2456、深度虚值（K=70）误差 0.3317；N=32 分别掉到 1.07e-4 和 1.28e-4；N=64 直接到 1.78e-15 和 4.26e-14。截断宽度 L 同样有清晰阈值：L=2 时 K=70 误差 0.3976，L=4 降到 6.25e-4，L=6 降到 2.04e-8，L=8 起进入机器精度。
- **对随机路径**：Heston 随机波动率模型下，COS 与 30 万条全截断欧拉路径的蒙特卡洛对拍，7 个执行价的差异全部落在 ±0.79 个标准误内，ATM 是 10.361869 对 10.365765±0.021822。

**一句话：只要你能写出模型的特征函数，COS 就能在几十微秒内给出任意单个执行价的期权价格，精度没有损失；代价是你必须为它挑一个足够宽的积分区间，否则误差会以「分」为单位悄悄溜回来。**

## 二、为什么余弦级数能算出期权价格

设对数价格 $Y=\ln(S_T/K)$，特征函数 $\varphi(u)=E[e^{iuY}]$。COS 的核心假设是：$Y$ 的密度 $f(y)$ 在有限区间 $[a,b]$ 上可以用余弦级数展开：

$$
f(y)\approx\sum_{k=0}^{N-1}{}'\,A_k\cos\Big(\frac{k\pi(y-a)}{b-a}\Big),\qquad
A_k=\frac{2}{b-a}\operatorname{Re}\Big[\varphi\big(\tfrac{k\pi}{b-a}\big)e^{-i k\pi a/(b-a)}\Big]
$$

求和号上的撇表示 $k=0$ 项取一半。系数的来源是傅里叶余弦变换：**密度的余弦系数，恰好等于特征函数在一组等间距频率点上的实部**。这一步把「未知密度」换成了「已知特征函数的若干次求值」，是整篇文章的支点。

看涨期权价格 $V=Ke^{-rT}E[(e^Y-1)^+]$。把上面的级数代进去，需要算的是

$$
\chi_k=\int_{c}^{b}(e^y-1)\cos\big(\tfrac{k\pi(y-a)}{b-a}\big)\,dy,\qquad c=\max(a,0)
$$

这个积分有闭式解：$k=0$ 时是 $(e^b-e^c)-(b-c)$；$k\ge1$ 时是两项指数项减去两个正弦项。于是定价公式变成一次求和：

$$
V_{\text{call}}\approx K e^{-rT}\Big(\tfrac12 A_0\chi_0+\sum_{k=1}^{N-1}A_k\chi_k\Big)
$$

下面是完整实现。注意 `chi` 中 $k\ge1$ 的上界项用了 $\cos(k\pi)=(-1)^k$、$\sin(k\pi)=0$ 这两个恒等式，省掉了三角函数的重复求值。

```python
import numpy as np

def cos_call(cf, cum1, cum2, S0, K, T, r, N=256, L=12.0):
    """cf(u): 对数价格 Y=ln(S_T/K) 的特征函数; cum1/cum2: Y 的一二阶累积量"""
    a, b = cum1 - L*np.sqrt(cum2), cum1 + L*np.sqrt(cum2)
    u = np.pi*np.arange(N)/(b-a)
    k = np.arange(N)
    phi = cf(u)
    A = (2.0/(b-a))*np.real(phi*np.exp(-1j*u*a))
    c = max(a, 0.0)
    chi = np.zeros(N)
    chi[0] = (np.exp(b)-np.exp(c)) - (b-c)          # k=0
    kk, uu = k[1:], u[1:]
    cosa, sina = np.cos(uu*(c-a)), np.sin(uu*(c-a))
    up  = np.exp(b)*((-1.0)**kk)/(1.0+uu**2)
    low = np.exp(c)*(cosa + uu*sina)/(1.0+uu**2)
    chi[1:] = (up - low) + sina/uu                    # k>=1
    return K*np.exp(-r*T)*(0.5*A[0]*chi[0] + np.sum(A[1:]*chi[1:]))

# Black-Scholes 的特征函数与累积量
def bs_cf(u, T, r, sig, x):
    return np.exp(1j*u*(x+(r-0.5*sig**2)*T) - 0.5*sig**2*T*u**2)

x = np.log(100/100)
p = cos_call(lambda u: bs_cf(u, 1.0, 0.05, 0.2, x),
             cum1=x+(0.05-0.02), cum2=0.04,
             S0=100, K=100, T=1, r=0.05)
print(p)   # 10.4505835722
```

## 三、精度与收敛：误差掉到机器精度只要 64 项

图1 上半部分把 COS 的解（实线带点）和 Black-Scholes 解析解（虚线）叠在一起，肉眼看不出差别；下半部分是绝对误差的对数坐标，三条期限曲线都堵在 1e-13 以下。这不是「看起来准」，而是逐点数值对拍的结果：最坏的一个点（T=3、某个执行价）误差 3.48e-13。

图2 左半边回答「要多少项」。这里的收敛速度近乎暴力：N=16 时 ATM 价格错了 0.2456 美元，深度虚值的 K=70 错了 0.3317 美元；N 翻倍到 32，误差掉到 1.07e-4 与 1.28e-4；再翻倍到 64，直接到 1.78e-15 与 4.26e-14，再往上加项数只是重复同样的浮点噪声。**对 BS 这种密度解析、尾部指数衰减的模型，N=64 就够用到双精度极限**，实战里取 N=128 或 256 完全是安全余量。

![级数项数与截断区间收敛](/images/cos-method-option-pricing/fig2_convergence.png)

图2 右半边是另一个旋钮：$L$ 决定积分区间取 $\hat\mu\pm L\hat\sigma$ 的多少倍标准差。$L=2$ 时 K=70 误差 0.3976，因为深度虚值的收益主要来自密度右尾，区间砍掉了不该砍的部分；$L=4$ 降到 6.25e-4，$L=6$ 降到 2.04e-8，$L=8$ 之后稳定在机器精度。原论文建议 $L=12$，实测对这个参数集 $L=8$ 已经饱和——不过这只是 BS 的结论，换模型要重新看。

## 四、Heston：三法对拍才是真验证

只在 BS 上验证有个漏洞：BS 的特征函数和解析解来自同一个模型，对拍通过只能证明实现没错，不能证明方法在更一般的模型上仍然可靠。我换到 Heston 随机波动率（$v_0=0.04,\kappa=1.5,\theta=0.04,\sigma=0.3,\rho=-0.7$），用 30 万条路径、200 步全截断欧拉格式做独立参照。

结果列在图3：7 个执行价的 COS 价格与蒙特卡洛价格的标准化差异分别是 −0.15、−0.10、−0.18、−0.18、−0.10、−0.48、−0.79，全部在 1 个标准误以内，没有系统性偏移。这里踩过一个坑值得记下：一开始我用 10 万条路径、80 步，7 个点一致偏低约 2 个标准误，看起来像 COS 有偏；换成 30 万条、200 步、换随机种子后偏差立刻回到噪声量级。**蒙特卡洛参照本身不够好时，"系统性差异"可能只是参照的抽样运气**。

![Heston 模型 COS 与蒙特卡洛对拍](/images/cos-method-option-pricing/fig3_heston_mc.png)

这里还修了一个实现层的硬 bug：Heston 特征函数的判别式写成 $\sqrt{a^2+\sigma^2(z^2-z)}$ 时，数值上给出的价格和蒙特卡洛差出几百美元；正确形式是 $\sqrt{a^2-\sigma^2(z^2-z)}$（其中 $z=iu$、$a=\kappa-\rho\sigma z$），符号一改，特征函数在各频率点与模拟的 $E[e^{iuY}]$ 立刻吻合到小数点后三位。这类符号错误不会让程序崩溃，只会安静地给出荒谬价格——**任何傅里叶定价实现，先拿特征函数本身和蒙特卡洛对一次，再看价格**。

## 五、截断失效：11 美分从哪里来

如果只看 BS，$L=8$ 就够；Heston 的长到期、高波动率之波动场景对区间宽度更敏感。设 $v_0=\theta=0.04$、$\kappa=1$、$\sigma=0.5$、$\rho=-0.7$、$T=2$、$K=50$，把 $L$ 从 4 扫到 16：

- $L=4$：价格 **55.262134**
- $L=6$：**55.157565**
- $L=8$：**55.151730**
- $L=16$：**55.151393**（$L=24$ 的参照值 55.151450）

$L=4$ 比收敛值高了 **0.1107 美元**，约 11 美分；$L=6$ 还差 0.0061，$L=8$ 收窄到 0.00028。图4 画出了这条收敛曲线。**教训是：$L$ 不是一个可以抄进配置就忘掉的数字**，波动率之波动越大、期限越长，密度尾巴越厚，需要的区间越宽；不能因为 BS 实验里 $L=8$ 够用就照搬。

## 六、和 Carr-Madan FFT 的速度对比

方法对比最容易被写成「我的更快」这种没信息量的结论。这里给出实测口径：Carr-Madan FFT 在 $N=2^{14}$ 网格上一次性算出整条执行价链，耗时约 **1.42 毫秒**；COS 逐个定价 7 个执行价总耗时 **0.269 毫秒**，单个执行价 **0.038 毫秒**。所以结论是分场景的：只要几个执行价（做市商报价、单笔奇异期权、校准时反复查少数几个点），COS 的摊薄成本明显更低；要一次拿到上千个执行价的完整曲面，FFT 的批量优势仍在。

![COS 与 FFT 计时对比](/images/cos-method-option-pricing/fig5_speed.png)

需要诚实交代的是，本次 FFT 参照实现采用阻尼因子 $\alpha=1.5$ 与对数执行价网格，在对拍中价格出现了明显错位（对 ATM 给出约 1.1 而不是 10.45），因此**这里只引用了它的计时，没有引用它的价格精度**。把两条路径的精度放在一起宣称「COS 更准」是不成立的——本文所有精度数字都只来自 COS 对 Black-Scholes 解析解与 Heston 蒙特卡洛的对拍。

## 七、什么时候别用 COS

第一，模型特征函数写不出来或只能数值积分得到时，COS 的优势消失——它的每一步都建立在 $\varphi(u)$ 的闭式求值上。第二，需要极深尾部（比如 99.9% 以外的期权隐含尾部）时，余弦级数在有限区间上的截断误差会重新变得显著，必须配合更宽的 $L$ 与更细的 $N$，并且用独立方法复核。第三，路径依赖或美式期权无法直接用这一套——COS 定价的是终值分布的期望，不含提前行权与路径信息。

### 与有限差分法的分工

还有一种常见做法是解 Black-Scholes 或 Heston 的偏微分方程，用 Crank-Nicolson 格式在时间轴上倒推。两者不是替代关系，而是分工：PDE 方法天然处理提前行权和状态约束，但每换一组参数就要重解一次网格；COS 把模型信息全部压缩进特征函数，定价新执行价只是重新求一次向量求和，校准时反复查价的差距会被放大。**维度是另一个分水岭**：COS 的级数项数随维度指数增长，二维以上的Heston 或随机利率模型就吃力，而 PDE 在低维（一到两维）反而稳健。所以实际系统里常见的是混合方案：一维欧式用 COS 做批量报价与校准，路径依赖与高维用蒙特卡洛，美式与障碍用 PDE。

### 一个重要提醒

COS 方法的误差有两个彼此独立的来源：级数截断（由 $N$ 控制）和区间截断（由 $L$ 控制）。本文的收敛实验把两者分开扫——固定 $L=12$ 扫 $N$，固定 $N=256$ 扫 $L$——就是为了不要把两种误差混在一起。真要自动选参数，应当先用累积量给出 $L$，再检查相邻两个 $N$ 的价格差是否小于目标精度（比如 1e-6），而不是凭经验取一个固定值。

反过来，欧式香草、方差互换、部分障碍期权只要能写出特征函数并做适当变换，COS 都是当前最干净的工具之一：没有数值积分的误差累积，没有 FFT 的网格对齐问题，几十行 numpy 就能跑出机器精度。把 $N$、$L$ 两个旋钮的敏感性测清楚，剩下的就是把它当成一台稳定的定价引擎使用。
