## 一、结论先行

"谁欠得最多谁最危险"是风险管理里最常见的偷懒。但同业网络的风险不是加法，是**乘法沿路径传播**：A 的损失让 B 的权益缩水，B 的缩水又让 C 的债权减值。谁在最关键的中介位置，光看对违约方的直接敞口根本看不出来。

我构造了一个 14 家机构、43 条有向同业债权的网络：核心节点 0~3 彼此高度互持，节点 4~13 是外围，边是"债权人 → 借款人"（箭头指向欠钱的人）。合计权益 167。给节点 0 的外部资产打一记 **80%** 的冲击后：

- 按"每个债权人只承担借款人**本轮新增**的损失"传播，总权益损失 **25.39**，占合计权益的 **15.2%**，14 家全部被波及；被冲击的节点 0 自己从 80% 被环路反馈抬到 **84.25%**；
- 只看直接债权人的**一步线性近似**给 **18.09**，低估 **7.30（28.7%）**；
- 如果把每轮的困境程度 $h$ 整个重新代入迭代（最常见的实现错误），总损失冲到 **167**——全网络 $h$ 都被顶到 1，是正确口径的 **6.58 倍**；
- 去掉所有有向环后，同一冲击的级联损失是 **21.29**，也就是说**环本身额外放大了 4.10（19.2%）**。相对敞口矩阵的谱半径只有 **0.492**，离 1 不远不近，正好是"有放大但不爆炸"的区间；
- 排名更值得警惕：直接敞口与 DebtRank 的 **Spearman 只有 0.655**（p=0.011）。节点 7 对节点 0 的直接敞口排第 2，却挤不进 DebtRank 前四；节点 4 直接敞口只排第 5，DebtRank 却排第 3。按直接敞口配资本，会把钱花错地方。

## 二、模型：权益是吸收冲击的缓冲垫

对机构 $i$，记权益 $E_i$、对 $j$ 的同业债权 $A_{ij}$。若 $j$ 损失了其权益的 $h_j\in[0,1]$，且债权按同比例减值，则 $i$ 的权益损失为 $A_{ij}h_j$，相对自身的损失比例是 $A_{ij}h_j/E_i$。于是传播算子是

$$
\Lambda_{ij}=\frac{A_{ij}}{E_i},\qquad
\Delta h_i^{(t+1)}=\sum_j \Lambda_{ij}\,\Delta h_j^{(t)},\qquad
h_i^{(t+1)}=\min\Bigl(1,\ h_i^{(t)}+\Delta h_i^{(t+1)}\Bigr).
$$

**关键是 $\Delta h$ 而不是 $h$**：每一份损失只能被计入一次债权减值。如果用 $h$ 代替 $\Delta h$，同一笔早期损失会在后续每一轮被重复记账——这正是 6.58 倍虚增的来源。它不是理论分歧，是实现 bug，而且不会报错。

```python
import numpy as np

def propagate(A, equity, seed, shock, max_iter=200):
    Lam = A / equity[:, None]
    h = np.zeros(len(equity))
    h[seed] = shock
    delta = h.copy()                       # only NEW losses propagate
    for _ in range(max_iter):
        inc = Lam @ delta
        new = np.clip(inc, 0.0, 1.0 - h)
        if new.max() < 1e-12:
            break
        h += new
        delta = new
    return h

# the common wrong version: re-apply the full distress every round
def propagate_naive(A, equity, seed, shock):
    Lam = A / equity[:, None]
    h = np.zeros(len(equity))
    h[seed] = shock
    for _ in range(500):
        new = np.minimum(1.0, h + Lam @ h)
        if np.max(new - h) < 1e-12:
            return new
        h = new
    return h
```

两条路径在本文网络上的差别是 **25.39 对 167**。前者是"损失会计"，后者只是"困境程度的不动点"，把后者当总损失读，就会凭空造出一场全系统崩盘。

## 二之一、先看拓扑：钱都压在谁身上

这张网络总同业债权 **69.44**，相对合计权益 167 的杠杆不算极端；43 条边分布在 14 个节点上，平均出度约 3.1。但方向极不均衡：节点 2 有 **11 条债权指向它**，是全网络被借钱最多的机构，节点 0 只有 6 条；节点 12 没有债权人，节点 8 只有 1 条。这就解释了为什么"入度"和"风险"不能直接画等号：节点 2 的债权人虽多，单笔规模小，它在级联中的损失比例并不靠前；节点 0 的债权人少但单笔大，一记 80% 冲击足以让全网 14 家全部受损。**拓扑决定传播路径，权重决定传播强度，两者缺一不可。**

再补一个容易被忽略的事实：相对敞口矩阵 $\Lambda=A_{ij}/E_i$ 的谱半径 **0.492**，是由权益而不是债权总额归一化的。同一张债权网络，如果各家权益普遍缩水一半，谱半径就会翻倍，级联从"可控"直接跨到"爆炸"区间。所以系统性风险不是网络的固有属性，是**网络与资本充足率共同决定**的状态量。

## 三、一步近似为什么系统性偏低

风险报告里常见的简化是：违约方损失 $L$，直接债权人各承担 $A_{ij}/E_i\cdot L$，到此为止。本文节点 0 的冲击是 $0.8\times E_0=9.6$，加上直接债权人合计约 8.49，一步口径总共 **18.09**。但完整级联是 25.39，**少了 7.30**。漏掉的是二阶及以后：节点 3、4、10 拿到第一棒之后，再把损失传给它们的债权人（包括绕回节点 0）。

这不是一个可以忽略的尾部项。换个角度看，$\Lambda$ 的谱半径 0.492 意味着"一笔冲击经过一轮自我复制后还剩约 49%"，几何级数 $\sum_k\Lambda^k=(I-\Lambda)^{-1}$ 的上界远大于 $I+\Lambda$。一步近似恰好只取了级数的前两项。

冲击大小扫描还暴露出**分段线性**结构：初始冲击从 0.02 加到 1.00，总损失的边际斜率在 0.92 附近从 **31.74** 掉到 **15.12**，到 0.94 几乎归零——因为部分机构的 $h$ 撞到 1 的上限，再大的冲击也无法从它们身上榨出更多损失。任何用单一线性系数外推"冲击翻倍损失翻倍"的模型，在这个拐点之后都会高估。

## 四、排名：为什么直接敞口会挑错人

把 14 家机构按"对节点 0 的债权 $A_{i0}$"和"DebtRank（级联后自身损失比例 $h_i$）"各排一次，Spearman 只有 0.655：

| 机构 | 直接敞口排名 | DebtRank 排名 | 含义 |
|---|---|---|---|
| 3 | 1 | 2 | 两种口径都认为重要 |
| 7 | 2 | 不在前四 | 大额敞口，但下游链条短 |
| 1 | 3 | 不在前四 | 同上 |
| 4 | 5 | 3 | 敞口不算大，但处在传染病传播的中枢 |
| 10 | 4 | 4 | 两种口径都认为重要 |

换句话说，**直接敞口度量的是"我暴露给谁"，DebtRank 度量的是"谁暴露给我、我再传给谁"**。前者是风险来源，后者是风险放大器。监管资本若只按前者计提，节点 4 这类"中等敞口、高中心性"的机构会被系统性低估。

## 五、环路：真实放大与虚假放大的区别

把原网络的边按索引方向截断，只保留 $i>j$ 的边，得到一张无有向环的 DAG，其余权重不变。同一冲击下：

- 原图（含环）总损失 **25.39**；
- DAG 总损失 **21.29**；
- 环路额外放大 **19.2%**，其中节点 0 自身从 80% 被反馈抬到 84.25%。

这部分是**真实**的放大：损失绕了一圈回到起点。但第四节里 6.58 倍的虚增是**虚假**的：它不是环的物理效应，而是把 $h$ 当 $\Delta h$ 重复记账。即使在没有环的图上，错误版本也会虚增 7.73 倍（DAG 中 164.6 对 21.29）——所以"迭代次数越多数字越大"绝不能当成系统性风险证据。区分两者的简单办法：**写出增量形式，并检查一次冲击在账上是否只被记一次**。

## 六、稳健性：排名比金额稳，但前四名并不稳

把每条边权乘上 $\exp(\mathcal N(0,0.15^2))$ 的随机扰动，重复 300 次。与基准 DebtRank 的 Spearman 中位数 **0.978**、最低 **0.921**，看起来非常稳；但"前四名集合完全一致"的频率只有 **35.7%**。这说明**整体排序稳健、头部名单脆弱**：名次靠后的机构调换影响不大，前四名里换掉一个就会改变监管名单。任何基于 Top-N 的风控决策都要报名单稳定率，不能只报相关系数。

## 六之一、真要用在实盘，还缺什么

把这套方法搬到真实账户，第一件事是把 $A_{ij}/E_i$ 换成**分层损失给定**：同业债权有优先级、抵押品和净额结算协议，违约时回收率不会是 0，不同合同的雪崩阈值也不同。第二件事是数据的时效性：资产负债表是季频快照，而冲击传播按天发生，用三个月前的敞口估今天的传染，误差往往比模型误差大一个数量级。第三件事是**反向校验**：把历史上几次真实的同业违约塞进网络，看模型给出的受损机构排序和事后财报是否一致；对不上的节点要单独查有没有隐藏的担保链或集团内部转移。

还有一个操作层面的坑：DebtRank 输出的是相对权益损失 $h$，不是可交易的期望损失。要把 $\sum_i E_i h_i$ 变成组合的信用损失估计，还得叠加违约概率（PD）、违约损失率（LGD）和敞口（EAD），而这三者在压力期本身就高度相关。本文 25.39 这个数字只能当**冲击传播的相对尺度**读，不能直接当 P&L 预测。

## 七、边界

模型假设债权减值比例等于借款人权益损失比例，等价于回收率为 0 且不存在债务重组；现实中回收率、交叉违约条款和政府救助会把传播系数大幅压低。本文也没有用真实资产负债数据，43 条边是合成网络，结论是**方法层面的**，不是对某个银行体系的判断。要落地，至少要把 $A_{ij}/E_i$ 换成按优先级分层的损失给定（loss given default）矩阵，并对数据缺失做敏感性分析。
