"当前市场处于恐慌状态"—— regime 交易的每句操作指令都长这样。问题是"状态"看不见：你手里只有日收益序列，状态是藏在后面的隐变量。隐马尔可夫模型（HMM）给这件事一个完整的概率框架：状态按 Markov 链转移，观测从状态发射，你从观测反推状态。听起来优雅，实盘的坑全在细节里。本文不用任何现成 HMM 库，手写 log 空间的 forward / backward / Viterbi / Baum-Welch，在已知真值的合成市场上把整条流水线放上手术台——**已知答案才能判卷**，这是合成数据存在的唯一理由。

结论先行（全部来自本文现场计算，seed=20261027）：

**① EM 学波动率很准，学方向很瞎。** 120 迭代 Baum-Welch，对数似然 −1980.16 → −1950.54，逐迭代单调不减（EM 的下界保证，实测 120/120 步无违反）；按 σ 排序对拍：σ̂ = [0.616, 1.112, 2.337] 对真值 [0.60, 1.10, 2.40]，MAPE 依次 2.6% / 1.1% / 2.6%，转移矩阵 Â 平均绝对误差 0.0159。可期望收益 μ̂ 里恐慌态是 **+0.274%，真值 −0.35%——反号**。不是 bug：恐慌一共 66 天，样本均值 +0.174%、标准误 0.307%、t=0.57，纯噪声。

**② 三个数全对靠的是 σ 的信号强度，不是模型"懂"市场。** 恐慌日 |r| 均值 1.966%，非恐慌日 0.665%——波动差 3 倍，σ̂ 当然学得到；日收益期望差只有 0.45%/天，跟每日 1%~2% 的噪声比，统计上不显著。**HMM 在你的数据上能恢复什么，由信噪比决定，不由你的模型方程决定。**

**③ Viterbi 与 posterior 打平？打的是不同比赛。** 与真标签一致率：Viterbi 联合路径 88.1%，posterior 逐日边缘 89.2%（逐点最优天然占优，0.1 个百分点在 MC 误差内）；两者互相一致率 92.1%——分歧的 8% 集中在 regime 切换边界。要"一条可以执行的平滑路径"用 Viterbi，要"今天该给恐慌多少概率"用 posterior。

**④ 恐慌不是当场宣布的，是事后追认的。** 8 次持续恐慌（进入后至少待 2 天）的 Viterbi 检出滞后：中位 **1 天**、62.5% 在 1 天内跟上——但均值被拉到 15.6 天、P90 **60 天**：有 **2 次要 60 天窗口外才追认**（那两次恐慌本身只持续两三天，路径优化直接判定"不值得切换"）。

**⑤ 维度是最贵的旋钮。** 只允许 K=2 时，模型把平静和常态揉成一团、恐慌被常态稀释：高态 σ̂ = 1.455%，比恐慌真值 2.40% **低估 39.4%**；恐慌日给高态的平均后验 0.895、平静日 0.045——分类仍锋利，但尺度错了，54.5% 的恐慌日 |r| 超出高态 σ̂。10 个随机初始的 K=3 重拟合 σ̂ 散布 std 全为 0：EM 从哪个角落出发都掉进同一个局部最优。**稳定是稳定，正确是正确，两回事。**

## 一、考场：3-state Markov 驱动的 1500 天

状态机三档：平静（μ=+0.10%，σ=0.60%）、常态（+0.05%，1.10%）、恐慌（−0.35%，2.40%）。转移矩阵给足粘性——平静自持 0.970、常态 0.945、恐慌 0.830，期望停留 1/(1−A_kk) = 33.3 / 18.2 / 5.9 天。初始分布 [0.45, 0.45, 0.10]。模拟 1500 个交易日，日收益 $r_t \sim \mathcal{N}(\mu_{z_t}, \sigma_{z_t}^2)$，实得状态计数 [781, 653, 66]——恐慌是稀有事件，后面所有麻烦都从这 66 天里长出来。

![合成市场全貌与 20 日滚动波动](/images/hidden-markov-market-regime/fig1_market_truth.png)

上图第二行的紫色 20 日滚动波动是给模型准备的"肉眼证据"：三段 σ 各自成带，但边界模糊——这正是 HMM 该发挥作用的地方。拟合初始化就取材于它：把滚动波动按 1/3、2/3 分位（实测切点 0.660% / 0.986%）分成三位，各段样本矩当 μ̂₀、σ̂₀，转移矩阵 A₀ = 0.9·I + 0.05 给足对角粘性。

## 二、Baum-Welch：单调爬升的期望最大化

EM 的逻辑是一句循环废话的数学化：**猜状态归属 → 按归属重估参数 → 再猜**。E 步用 forward/backward 算出每个时刻每个状态的归属概率 γ 和相邻时刻的状态对归属 ξ，M 步用它们做加权样本矩更新 μ̂、σ̂、Â。保证是每步对数似然不减——因为 EM 每步都在抬高似然的变分下界。

![EM 收敛与参数恢复对拍](/images/hidden-markov-market-regime/fig2_em_convergence.png)

左图是实测收敛曲线：−1980.16 起步，约 15 个迭代吃掉 90% 的增益（+27.1），之后长尾逼近 −1950.54，全程无一迭代倒退。右图是按 σ 排序对拍的参数恢复：σ 三根柱子几乎贴在真值上，Â 的 MAE 0.0159——恢复最好的是平静态行 [0.976, 0.024, 0.000]（781 天样本喂出来的），最差的是恐慌态行 [0.074, 0.072, 0.854]（自持 0.830 被高估到 0.854，66 天样本撑不起 9 个自由参数）。

必须用 log 空间写：forward 递推是概率连乘，1500 步朴素乘法在迭代几百次后下溢到 0，EM 第一步就会崩成 NaN。log-sum-exp 的写法里有个具体坑：backward 按行归约时 `mx = m.max(1, keepdims=True)` 的 keepdims 不能省——每行要减的是**自己**的最大值，先 squeeze 再广播就把不同行的尺度混掉了，似然静默算错，日志里连一条 −inf 都不会留下。

## 三、冷水一：σ̂ 全对，μ̂ 反号

恐慌态的拟合期望收益是 **+0.274%**，真值 **−0.35%**。先怀疑 bug，再查数据：那 66 个恐慌日的收益样本均值 **+0.174%**，标准误 0.307%，t 值 0.57——真值 −0.35% 离样本均值足 1.7 个标准误，MCMC 噪声完全够把符号翻过去。EM 没有错，它诚实地报告了"这 66 天的样本均值"。恐慌日的判别信息根本不在均值里：|r| 均值 1.966% 对比非恐慌日 0.665%，**波动差 3 倍、均值差零头都不到**。

实践含义直白：用 HMM 做 regime 识别时，把 σ̂ 当信号、把 μ̂ 当噪声。想靠"恐慌态 μ̂ 为负"做择时对冲，等于拿 t=0.57 的结果下注。

## 四、Viterbi 还是 posterior：两种"最优"不是一回事

拿拟合参数回头解码状态，有两种准则。**posterior**（平滑概率）逐日取 $\arg\max_k P(z_t=k \mid r_{1:T})$，每个时刻单独最优；**Viterbi** 用动态规划找**联合**概率最大的整条路径 $\arg\max_{z_{1:T}} P(z_{1:T} \mid r_{1:T})$，逐日 max 换成递推 max，多存一张 ψ 回溯表。

![两种解码与真标签对照](/images/hidden-markov-market-regime/fig3_viterbi_vs_posterior.png)

判卷：与真标签一致率 posterior 89.2%、Viterbi 88.1%——逐点最优比联合最优高 1.1 个百分点，但两者互相一致率 92.1%，说明大面上的判断是一致的，分歧集中在状态切换的边界日：posterior 敢在孤立日"闪断"一下，Viterbi 的路径粘性把它抹平（看图 3 第三行对照第二行，零星的异色点几乎都贴着状态边界）。实盘选择没有悬念：**执行择时指令要 Viterbi**——今天恐慌、明天平静、后天又恐慌的路径会把你折腾死，切换成本照付、信号却没抓到；posterior 概率更适合当仓位函数的输入而不是开关。

## 五、冷水二：恐慌是事后追认的

Viterbi 的粘性是双刃剑。取真值序列中"进入恐慌且至少连待 2 天"的 8 次 onset，看 Viterbi 路径多久才跟上：滞后 [1, 1, 60, 0, 1, 2, 0, 60] 天——中位 1 天、62.5% 在 1 天内，看着很漂亮；均值 15.6 天、P90 60 天，因为**有 2 次恐慌（时长太短）在 60 天窗口内始终没被路径采纳**，图 4 左图右上角的注释框就是为此而加——直方图 0~10 天的 bins 里根本看不见这两个失败样本。

![恐慌检出滞后与停留时长](/images/hidden-markov-market-regime/fig4_lag_dwell.png)

短恐慌逃过 Viterbi 不是bug，是目标函数使然：为两三天异常收益切换状态，联合似然上不如"留在常态、把它们当肥尾噪声"。这暴露了 HMM 的哲学：**它是历史学家，不是哨兵**。右图是对模型假设本身的检查——三档停留时长的经验分布与 A 隐含的几何分布几乎重合（实测均值 32.5 / 20.4 / 5.5 天vs 理论 33.3 / 18.2 / 5.9）。真值本来就是 A 生成的，吻合是应该的；真正的使用场景里，市场停留分布是厚尾的（危机一待几个月），几何假设在尾部会系统性高估"随时会切换"的先验——这是 regime 模型比看起来更脆的深层原因。

## 六、维度代价与"稳定的错误"

没人规定 K 由数据免费告诉你。只许 K=2 重拟合：低态 σ̂=0.648%（平静+常态的混音），高态 σ̂=1.455%，而恐慌真 σ=2.40%——**被常态稀释，低估 39.4%**。危险的是它看起来仍很好用：恐慌日给高态的平均后验 0.895，平静日只有 0.045，"分类"几乎完美。但尺度是假的：54.5% 的恐慌日 |r| 超出高态 σ̂，模型在高态内部被自己的尾部反复打脸，用它出的 σ̂ 做波动率目标仓位会系统性欠配。

![K=2 欠规格与 10 种子散布](/images/hidden-markov-market-regime/fig5_limits.png)

右图是另一盆冷水：换 10 个随机初始（重抽 400 天分三档取样本矩）重跑 K=3，σ̂ 按档排序后的散布 std = [0.0, 0.0, 0.0]，中位数 [0.616, 1.112, 2.337]——十个起点全掉进同一个局部最优。在 T=1500、σ 分离度 3 倍的任务上这是福气（似然地形够尖锐）；但"跑十次都一样"永远只证明地形尖锐，不证明找到了真值。K 的选择没有任何算法能替你负责——BIC 也好、似然拐弯处（elbow）也好，都是人替模型背的锅。

## 七、可运行核心代码

log 空间 forward / Viterbi / Baum-Welch 骨架，纯 numpy：

```python
import numpy as np

def forward(le):                    # le: (T,K) 对数发射概率
    T, K = le.shape
    la = np.empty((T, K))
    la[0] = np.log(pi) + le[0]
    for t in range(1, T):
        m = la[t - 1][:, None] + logA
        mx = m.max(0)
        la[t] = mx + np.log(np.exp(m - mx).sum(0)) + le[t]
    m = la[-1]; mx = m.max()        # log-lik = logsumexp(la[-1])
    return la, mx + np.log(np.exp(m - mx).sum())

def viterbi(le):
    T, K = le.shape
    d = np.full((T, K), -np.inf); psi = np.zeros((T, K), int)
    d[0] = np.log(pi) + le[0]
    for t in range(1, T):
        m = d[t - 1][:, None] + logA
        d[t] = m.max(0) + le[t]; psi[t] = m.argmax(0)
    path = np.zeros(T, int); path[-1] = d[-1].argmax()
    for t in range(T - 2, -1, -1):
        path[t] = psi[t + 1][path[t + 1]]
    return path

# Baum-Welch 单步（E 步 γ/ξ + M 步重估），需与 forward/backward 配合
la, ll = forward(le); lb = backward(le)
g = la + lb; g = np.exp(g - g.max(1, keepdims=True)); g /= g.sum(1, keepdims=True)
xi_sum = np.zeros((K, K))
for t in range(T - 1):
    m = la[t][:, None] + logA + le[t + 1][None, :] + lb[t + 1][None, :]
    xi_sum += np.exp(m - ll)
pi = g[0]
A = xi_sum / xi_sum.sum(1, keepdims=True)
mu = (g * r[:, None]).sum(0) / g.sum(0)
sig = np.sqrt((g * (r[:, None] - mu[None, :]) ** 2).sum(0) / g.sum(0))
```

backward 函数与 forward 同构（把 max/sum 的方向沿时间反向走一遍，注意上文的 keepdims 坑），Baum-Welch 就是把这个单步循环 120 次、每轮用最新的 Â/π̂ 重算 logA 与 pi。HMM 值得用，但要用对姿势：**σ̂ 是资产，μ̂ 是装饰；Viterbi 给你历史，posterior 给你今天；K 是人定的，检验它的方式只有一个——换种子、换窗口、换 K，看你的策略亏不亏钱**。模型猜情境，你负责验谎。
