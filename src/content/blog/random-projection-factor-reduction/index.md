## 问题：因子越来越多，样本却没有变多

一个普通的 A 股多因子工作台，动量、价值、质量、波动率、换手、资金流……随手堆到 50 个因子很正常。因子越多，截面回归的自变量越多，系数估计的方差越大——样本还是每天 400 只股票那点数据，自由度却翻倍地吃。PCA 是最常用的解法，但它有个隐藏假设：**方差大的方向就是有用的方向**。在噪声因子堆里，这个假设经常不成立。

还有两条更数学化的路：

1. **Johnson–Lindenstrauss（JL）引理**：随机高维投影可以在 distances 上保持几乎不变，把 50 维压到几十维；
2. **压缩感知（CS）**：如果信号本身是稀疏的（只依赖少数因子），那么远少于维度数的样本就足以精确重建。

这两条路的教科书陈述都很漂亮，但落到量化场景里有两个必须回答的实证问题：**实际需要的维度/样本量到底比理论界小多少？降维之后选股能力掉了多少？** 本文用一套严格仿真（数据生成过程可控，因此有 ground truth 可以对表）逐条实测。

## 数据生成过程：让答案已知

仿真设定如下。400 只股票（N=400），6 个不可观测的潜在因子 $F$，50 维可观测因子矩阵由潜在因子线性混合加噪声生成：

$$X_{obs} = F W_{true} + \varepsilon,\qquad \varepsilon \sim N(0, 0.6^2)$$

也就是说，50 个"因子"里大部分是 6 个真实驱动源的混合与噪声——这正是现实因子库的病态结构：看着多，信息量少。

```python
import numpy as np

N, K, M = 400, 50, 6          # 股票数、可观测因子数、潜在因子数
rng = np.random.default_rng(0)
F = rng.standard_normal((250, M))                     # 潜在因子时序
W_true = rng.standard_normal((M, K))                  # 混合矩阵
X_obs = F @ W_true + rng.normal(0, 0.6, (N, K))       # 可观测 50 维因子
```

所有图都从这份数据现场计算，种子固定，可复现。

## JL 引理：理论界保守到荒唐，实践收敛得很早

JL 引理的标准形式：要把 N 个点的成对距离保持在 $(1\pm\varepsilon)$ 带内，投影维度 $d$ 满足

$$d \;\ge\; \frac{8\ln N}{\varepsilon^2 - \varepsilon^3/3}$$

代入 N=400、ε=0.2，得到 **d\* = 1284**——比原始维度 50 大了 25 倍还多。这个界的最坏情况保证是无条件成立的，但它给了我们一个绝佳的实证靶子：**真实数据远远不需要这么多维度**。

![JL 投影的成对距离畸变](/images/random-projection-factor-reduction/jl-distortion.png)

实测结果（每只股票的因子向量先 L2 归一化，距离定义为 $1-\cos$）：

- **d=16** 时，全部 79,800 个配对中，距离比的中位数已经是 **1.0002**——typical pair 几乎零畸变；P95 为 1.447、P5 为 0.616，尾部仍有离群对；
- 距离比落在 ±20% 带内的配对占比随 d 单调抬升：d=16 时 63.1%，d=25 时 68.9%，到 **d=100 才首次越过 95%**；
- 最坏配对（max/min 距离比）收敛得更慢，这正是 JL 界"悲观"的来源——它要为最倒霉的那一对负责。

结论第一条：**JL 的理论界是保最坏情况的，不要拿它做工程预算**。按"95% 配对入带"这种分布上的标准，d≈100 足够；如果下游模型对 typical 距离敏感（比如基于距离的聚类），d=16~25 就已经在失真范围外了。

## 压缩感知：真正的开关是稀疏性

JL 只管"保距离"，不管"能不能从数据里学出信号"。学习的样本复杂度由另一条理论管：若信号真实依赖 $k$ 个因子（k-稀疏），则样本量 $m \gtrsim 2k\ln(K/k)$ 就能用 L1 优化精确重建。代入 k=5、K=50，得 **m 的下界 = 23.0**。

我们构造一个只依赖 5 个因子的信号 $y = X\theta + \mathrm{noise}$（θ 在 50 维中只有 5 个非零），然后扫描"用于拟合的股票样本数 m"，看对**留出股票**的预测误差：

![压缩感知相变：Lasso 的样本复杂度骤变](/images/random-projection-factor-reduction/cs-phase-transition.png)

| 拟合样本 m | Lasso 留出误差 | OLS 留出误差 | Lasso 支撑度命中 |
|---|---|---|---|
| 16 | 0.318 | 0.855 | — |
| 25 | **0.170** | 0.711 | 84% |
| 50 | 0.131 | **3.949**（爆炸） | 92% |
| 80 | 0.123 | 0.165 | 100% |
| 400（全部） | 0.112 | 0.132 | 100% |

（噪声地板 = 0.112，即不可约减的误差下限）

三个读数：

1. **Lasso 在 m=25 附近发生相变**，与理论下界 23.0 对表几乎是贴着的。m=25 时误差 0.170，离噪声地板 0.112 只差 0.06；
2. **OLS 在同一点还远未恢复**（m=25 误差 0.711），更糟糕的是 m=K=50 处设计阵接近方阵、条件数崩塌，留出误差爆炸到 **3.949**——样本数和自变量数打平正是过拟合最凶的位置。OLS 要到 m=80（1.6 倍维度）才真正稳定下来；
3. 支撑度命中率（Top-5 系数是否命中真实 5 因子）在 m=25 已达 84%，m=50 达 92%，m=80 起满命中。

结论第二条：**"因子多"本身不是病，"信号稠密"才是**。如果真实收益信号只压在少数因子上（Lasso 在全 50 维上拟合显示系数非零个数为 37/50，说明混合噪声下稠密部分主要是伪信号），Lasso 只需 25~50 只股票的拟合样本就能把真因子找出来——降维省下来的不是计算，是**样本**。

## 稀疏暴露恢复：全维 Lasso 直接把真因子点名

把 Lasso 直接跑在全 50 维上（不加任何投影），看它能否点名真实因子列。真实信号依赖的第 13、15、29、31、46 列（真实权重 −0.548、0.672、−2.849、0.149、1.069）：

![Lasso 稀疏暴露恢复](/images/random-projection-factor-reduction/sparse-recovery.png)

**Top-5 命中 4/5**——最强权重（−2.849）那列毫无悬念地位居榜首，漏掉的是权重最接近零的 0.149 那列，属于统计上本就该牺牲的边际信号。作为对照，同样数据上全维 Ridge 的 50 个系数没有一个是零：稠密解永远告诉你"每个因子都有一点用"，这正是过拟合的话术。

Lasso 坐标下降的核心循环（不依赖 sklearn 的极简实现，可直接跑）：

```python
def lasso_cd(X, y, lam, n_iter=300):
    p = X.shape[1]
    beta = np.zeros(p)
    r = y - X @ beta
    norms = (X ** 2).sum(axis=0)
    for _ in range(n_iter):
        for j in range(p):
            rho = X[:, j] @ r + norms[j] * beta[j]
            beta[j] = np.sign(rho) * max(abs(rho) - lam, 0) / norms[j]
            r = y - X @ beta
    return beta
```

## 邻域结构保持：d=15 时近邻还剩一半

一个具体的下游场景：用因子距离找"相似股票"做配对或聚类。d=15 的 JL 投影之后（种子独立）：

![邻域结构保持](/images/random-projection-factor-reduction/neighborhood.png)

- 原始 50 维成对距离 vs. 投影后距离的散点沿对角线分布，相关系数 **r = 0.839**；
- 但**近邻榜单的保持率只有 52.4%**——每个股票的前 10 个近邻里，投影后还有约 5 个留在前 10。

散点图"看起来"贴着对角线，榜单却换掉了一半。这是距离数据最容易被误读的地方：**分布上的贴合不等于序结构的保持**。如果你的策略对"谁和谁近"敏感（配对对冲、KNN 信号），要么加大 d 到 25+，要么像下一节一样，把投影只当正则化而不是当特征。

## 组合回测：d=15 的 JL 投影打了全 50 因子几乎平手

最后是终极问题：这些数学性质换算成选股能力值多少？

仿真改成端到端：真实漂移 $\mu_i = x_i\theta$（θ 仍只有 5/50 非零），日收益 = 漂移 + 市场共性冲击 + 个股噪声，500 个交易日，每 10 日调仓，每次用过去 120 日实现收益重新拟合打分，持有一个组合（Top-40 等权），38 个调仓期拼接净值，全程无前视。四种打分方式：

- **全 50 因子 Ridge**（不降维基线）
- **JL 投影 d=15 + Ridge**（JL 当正则化用）
- **全维 Lasso**（稀疏路线）
- **前视 oracle**（直接用真 μ 打分，天花板）

![JL 投影与全 50 因子的选股回测对比](/images/random-projection-factor-reduction/portfolio.png)

| 打分方式 | 年化 Sharpe | 10 日 IC |
|---|---|---|
| 全 50 因子 Ridge | 2.79 | 0.177 |
| JL 投影 d=15 Ridge | **2.69** | 0.176 |
| 全维 Lasso | **2.85** | 0.177 |
| 前视 oracle | 3.07 | 0.187 |

关键读数：

- **d=15 只保留 30% 的维度，Sharpe 保留了全因子版本的 96%**（2.69/2.79），且 JL Top-40 组合 captures 真 Top-40 的 **68.5%**——损失集中在榜单头部的微调上；
- **全维 Lasso（2.85）反超 Ridge（2.79）**，逼近 oracle 与 Ridge 之间空档的三分之二。在 DGP 真稀疏的设定下这是必然结果：Lasso 找到了真因子，Ridge 把 45 个噪声因子的方差也吃了进去；
- oracle 3.07 与最好实际策略 2.85 之间的差距，就是"不知道哪 5 个因子是真的"这件事的价格。

## 工程守则（本文实证版）

1. **别按 JL 理论界做预算**。d\*=1284 是为最坏配对负责的界；按 95% 配对入带的分布标准，本例 d≈100，按 typical 距离标准 d=16~25 即可。
2. **降维前先测稀疏性**。把 Lasso 跑在全维上，看非零系数有几个、Top 权重能否复现（本文设定下 Top-5 命中 4/5）。稀疏明确 → Lasso 路线优于任何投影；稀疏不明确 → JL 投影当 Ridge 的正则化用，d=15 起步做敏感性扫描。
3. **警惕 m≈K 的 OLS**。拟合样本数接近自变量数时（本文 m=50=K），OLS 留出误差爆炸到 3.95，比只用 16 个样本还差得多。宁可用稀疏方法，不要在这条线上硬拟合。
4. **距离图好看 ≠ 近邻榜好看**。d=15 时距离比相关 0.839，Top-10 近邻却只剩一半。凡是下游依赖 KNN 榜单的策略，验收指标必须是榜单保持率而不是散点贴合度。

## 诚实边界

这是仿真，不是实盘。DGP 人为保证了"存在 5 个真因子"，真实市场中稀疏性可能模糊得多（本文全维 Lasso 拟合出 37 个非零系数已经提示了这种模糊）；真实因子间存在生存者偏差、发布滞后与拥挤效应，都是仿真没有的。仿真能回答的是"数学保证在实践中打折到什么程度"，不能回答"这些保证在真实 A 股上还成立吗"。前者是本文的目标，后者需要你把同一套代码接到真实因子库上重跑——代码骨架都给出过，种子和口径自己定。
