做行业轮动的人几乎都听过一句话：**半导体涨了，科技往往跟上；券商一动，银行常常在后面。** 这类"谁先动"的经验如果只停留在盘感层面，就没法系统化。能否把整个市场的领先滞后关系画成一张有向图，让数据自己告诉我们哪些行业是"发令枪"、哪些是"跟随者"？这就要把**两两 Granger 因果检验**升级成一张**因子因果网络**。

难点不在单个检验，而在规模。8 个行业两两互检，要跑 8×7=56 次回归；每次都在 5% 显著性下判断，纯靠运气也会冒出大约 2.8 条假边。所以多重检验校正不是可选项，而是这套方法的生死线。本文用一份**已知真值网络**的合成数据，把整个流程从数据生成、检验、FDR 校正到样本外回测完整走一遍，并诚实地展示它在哪里成功、在哪里力不从心。

之所以坚持用合成数据而不是真实行情，是因为真实市场里我们永远不知道"正确的网络"长什么样，也就无从判断一套方法究竟是抓到了信号还是过拟合了噪声。只有在答案已知的阅卷环境里，精确率、召回率这些指标才有意义。等流程在合成数据上验证无误，再搬到真实行业指数上跑，心里才有底。这种"先造答案再验方法"的思路，是量化研究里被严重低估的基本功。

## 一、从单个检验到一张网络

Granger 因果的定义很朴素：如果在预测 $Y_t$ 时加入 $X$ 的过去值能显著降低残差，就说 $X$ Granger 导致 $Y$。这里的"导致"是预测意义上的，不是哲学意义上的因果。

单个检验用带约束与不带约束两组回归的残差平方和构造 F 统计量。设滞后阶数为 $p$：

$$
F=\frac{(RSS_r-RSS_u)/p}{RSS_u/(n-2p-1)}
$$

其中 $RSS_r$ 是只用 $Y$ 自身滞后的受限模型残差，$RSS_u$ 是加入 $X$ 滞后后的非受限模型残差。$F$ 越大、$p$ 值越小，说明 $X$ 的过去对预测 $Y$ 贡献越大。

把这套检验对每一对有序行业 $(j,i)$ 都跑一遍，就得到一个 $8\times8$ 的 F 矩阵：第 $i$ 行第 $j$ 列代表"$j$ 领先 $i$"的强度。矩阵里显著的位置连成有向边，一张网络就出来了。

## 二、多重检验：56 次回归里的幽灵

真正凶险的是多重检验。单个检验的 5% 显著性意味着"原假设为真时仍有 5% 概率误判显著"。跑 56 次，哪怕所有行业彼此独立，期望也会有 56×0.05≈2.8 条假边混进来。若不加校正，你画出的网络会稠密得毫无信息量。

本文用 **Benjamini-Hochberg 的 FDR（错误发现率）校正**，控制在 $q=0.05$：把 56 个 $p$ 值从小到大排序，找到满足 $p_{(k)}\le q\cdot k/m$ 的最大 $k$，把前 $k$ 个全部判为显著。相比 Bonferroni 把族错误率死压在 5%，FDR 允许少量假阳性，换取更高的检出率——这正适合"宁可多抓几条再筛"的因子挖掘场景。

核心估计器不过几十行：

```python
import numpy as np
from scipy import stats

def granger_f(x_i, x_j, p=2):
    """检验 x_j 是否 Granger 导致 x_i, 返回 (F, pvalue)"""
    n = len(x_i)
    Yi = np.column_stack([x_i[p-k-1:n-k-1] for k in range(p)])
    y  = x_i[p:]
    Xr = np.column_stack([np.ones(n-p), Yi])       # 受限: 只有 y 自身滞后
    Xj = np.column_stack([x_j[p-k-1:n-k-1] for k in range(p)])
    Xu = np.column_stack([Xr, Xj])                  # 非受限: 加入 x_j 滞后
    br = np.linalg.lstsq(Xr, y, rcond=None)[0]
    bu = np.linalg.lstsq(Xu, y, rcond=None)[0]
    rss_r = np.sum((y - Xr @ br) ** 2)
    rss_u = np.sum((y - Xu @ bu) ** 2)
    F = ((rss_r - rss_u) / p) / (rss_u / (n - 2*p - 1))
    return F, 1 - stats.f.cdf(F, p, n - 2*p - 1)

def bh_fdr(pvals, q=0.05):
    """Benjamini-Hochberg FDR 校正, 返回布尔显著矩阵"""
    p = pvals.flatten(); m = len(p)
    order = np.argsort(p)
    passed = p[order] <= q * (np.arange(1, m+1) / m)
    k = np.where(passed)[0]
    sig = np.zeros(m, dtype=bool)
    if len(k): sig[order[:k.max()+1]] = True
    return sig.reshape(pvals.shape)
```

## 三、已知真值：让方法接受阅卷

要评价一套网络重建方法，得先有一张标准答案。我用 8 个行业（半导体、科技、新能源、券商、银行、地产、消费、医药）生成一个 VAR(1) 过程，在系数矩阵里**人为埋入 7 条领先边**：半导体→科技、新能源→科技、科技→消费、券商→银行、银行→地产、地产→银行（一条反馈环）、消费→医药。这个拓扑有现实经济逻辑：上游零部件先于整机，券商先于银行反映牛市预期，消费景气再传导到医药。

我把系数矩阵缩放到谱半径 0.10——也就是让可预测成分远小于特质噪声。这一步很关键：如果信号造得太强，检验会轻易拿到完美结果，回测 Sharpe 会飙到离谱，那是自欺欺人。真实市场的领先关系本就微弱。数据共 1400 天，**前 900 天用来估网络，后 500 天留作样本外回测**，绝不偷看。

谱半径在这里扮演"信号总音量"的角色。VAR(1) 系统 $X_t=AX_{t-1}+\varepsilon_t$ 是否稳定、冲击会不会发散，完全由 $A$ 的最大特征值模长决定：小于 1 系统平稳，大于 1 就爆炸。我先把原始矩阵算出的谱半径 0.2775 归一化，再统一缩放到 0.10，相当于把每条边的强度一起等比缩小。这样既能保留网络的相对拓扑结构，又能把整体可预测性压到接近真实日频收益的水平——单期方向准确率勉强超过抛硬币，靠微弱优势在长样本里累积出统计显著性。

## 四、网络重建：精确但会漏

FDR 在 $q=0.05$ 下检出了 5 条边，对照答案逐条核验：

![真值网络与 Granger-FDR 估计网络对比](/images/granger-causality-factor-network/granger-network.png)

- **精确率 100%**：检出的 5 条边（科技→消费、新能源→科技、券商→银行、银行→地产、消费→医药）全部是真边，零假阳性。FDR 守住了底线。
- **召回率 71.4%**：7 条真边漏了 2 条——半导体→科技（$F=4.487$，$p=0.0115$）和地产→银行。这两条恰好是最弱的边，被 FDR 的门槛挡在外面。
- **反向边被正确拒绝**：科技→半导体 $F=0.267$、$p=0.765$，科技→地产 $F=0.729$、$p=0.483$。网络没有把方向搞反，这点比"抓到多少边"更重要。

F 统计量的原始分布见下图，星号是 FDR 显著位置，圆圈是真值边。可以看到强边（科技→消费 $F=19.1$、消费→医药 $F=22.3$）远远甩开噪声，而弱边就淹没在临界线附近。

![Granger F 统计量矩阵热力图](/images/granger-causality-factor-network/granger-f-matrix.png)

阈值扫描揭示了精确率与召回率的经典权衡。$p$ 阈值放宽到 0.0122 时，F1 从 0.833 升到 0.933——多找回一条弱边，但因为强边依旧显著、没有引入假阳性。再放宽，假边就会开始涌入，F1 掉头向下。

## 五、网络中心性与样本外轮动

网络建好，就能算每个行业的**领先出度**（它指向多少个下游行业）和**被领先入度**（多少个行业指向它）。半导体、科技、券商是典型的"发令枪"，医药则几乎纯跟随（入度 1、出度 0）。这个结构性信息本身就是一种 alpha 线索。

我用一个朴素策略验证网络是否真的有用：对每条检出的边 $j\to i$，当行业 $j$ 上一期上涨时做多 $i$、下跌时做空 $i$，等权汇总。**所有信号只在训练期估出的边上生成，在 500 天样本外测试**。结果为 Sharpe 4.52，等权基准 -0.047，最大回撤 -7.4%。

![样本外领先滞后轮动策略净值](/images/granger-causality-factor-network/granger-rotation.png)

必须泼一盆冷水：这个 Sharpe 高得不合常理。原因有三——数据是合成 VAR、信号被人为埋得相对干净、策略完全没算交易成本与冲击。它有意义的结论只是**方向性的**：用 Granger 网络筛出的边确实携带可预测的领先信息，样本外仍然有效；但 4.52 这个数字千万别当成实盘预期。

## 六、局限与改进

这套方法有三个绕不开的坑。第一，**Granger 检验只抓线性预测关系**，非线性的领先滞后（比如情绪到收益的传导）会漏掉，这时该换传递熵。第二，**伪因果**：两个行业被同一个宏观因子共同驱动时，会互为 Granger 因，网络里出现假边；加入条件变量或偏因果检验能缓解。第三，**不平稳性**：相关系数在牛熊之间漂移，值得用滚动窗口重估网络，观察拓扑随市场状态的演化。

把散乱的两两检验拼成网络，最大价值不在于某个 F 值，而在于**结构视角**：谁处在传导链条的上游、谁是关键枢纽、哪条边在崩盘时最先断裂。单看一个 p 值你永远看不到这些。
