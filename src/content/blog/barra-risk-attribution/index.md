你有没有过这种经历——辛辛苦苦选了 300 只股票，觉得足够分散了，结果某个月一涨全涨、一跌全跌，账户波动比想象中大得多？问题往往不在选股的数量，而在于这 300 只股票可能**集体押注了同一个风格因子**。你以为自己在做精细选股，其实是在对一个因子下重注，只是自己没看见。

这正是风险归因（risk attribution）要解决的事。它把组合的收益和波动，从"300 个个股的混沌"重新投影到"几个可解释的维度"上。本文用纯 numpy 从零搭一个简化版 Barra 多因子模型，全程数字可复现、三张图均为真实计算产出，不靠任何占位符。

风险归因之所以在机构里是刚需，是因为它把"业绩归因"从主观叙述变成可审计的数字。基金经理说"我赚的是动量的钱"，这句话在没有归因之前只是一句描述；有了 CTR 分解，它变成"动量贡献 +1.17、占主动收益的 93%"——既能被独立检验，也能在风险预算会议上被质疑。当收益和风险的来源都被钉到少数几个因子上，组合才真正"可解释、可管控"，而不是停留在"我选了一篮子好股票"的直觉里。

## 一、多因子收益模型：把收益拆成"因子"和"自己的事"

Barra 模型的核心假设极其朴素：任何一只股票的收益，都可以分成两部分——**所有股票共同承担的风格因子收益**，和**它自己特有的、与因子无关的那部分**。

$$ r_{it} = \mathbf{b}_i^\top \mathbf{f}_t + u_{it} $$

其中 $\mathbf{b}_i$ 是个股 $i$ 的 $K$ 维因子暴露（loading，也有人叫因子载荷），$\mathbf{f}_t$ 是第 $t$ 期 $K$ 个风格因子的收益，$\mathbf{u}_{it}$ 是个股特异收益（specified / idiosyncratic），按假设与因子正交。

把全市场写成矩阵形式更清楚：

$$ \mathbf{R}_t = \mathbf{B}\,\mathbf{f}_t + \mathbf{u}_t $$

$\mathbf{B}$ 是 $N\times K$ 的暴露矩阵。这套模型真正的价值在于：一旦你有了 $\mathbf{B}$ 和因子的协方差 $\boldsymbol{\Sigma}_f$，组合的一切——收益、风险、甚至压力的传导路径——都能被归因到少数几个**能说人话的维度**上（"这个月亏钱是因为动量因子回撤"比"第 87 只股票跌了"有用一万倍）。

## 二、构造一个"看似分散"的动量组合

我们用 numpy 造一个干净的实验宇宙，避免真实数据里的估计噪声干扰结论。设定 300 只股票、6 个风格因子（市场、规模、价值、动量、波动率、质量）、120 个月：

```python
import numpy as np
rng = np.random.default_rng(20261029)
n_stocks, n_periods, K = 300, 120, 6
# 因子的月均收益与月波动
fm = np.array([0.008, 0.003, 0.004, 0.006, -0.001, 0.002])
fv = np.array([0.040, 0.020, 0.020, 0.025, 0.015, 0.015])
# 因子协方差（含轻度相关，让故事更真实）
Sf = np.diag(fv**2)
Sf[0,3] = Sf[3,0] = 0.4*fv[0]*fv[3]      # 市场-动量正相关
Sf[2,5] = Sf[5,2] = 0.2*fv[2]*fv[5]      # 价值-质量正相关
L = np.linalg.cholesky(Sf)
f = fm[None,:] + rng.standard_normal((n_periods,K)) @ L.T   # T×K 因子收益
B = rng.standard_normal((n_stocks,K))                       # N×K 暴露
spec_vol = rng.uniform(0.03, 0.08, n_stocks)                # 个股特异波动
U = rng.standard_normal((n_periods,n_stocks)) * spec_vol    # 特异收益
r_stock = f @ B.T + U                                       # T×N 个股收益
```

接下来构建一个经典的市场中性动量组合：做多动量暴露最高的前 30% 股票、做空最低的后 30%，中间 40% 不动。权重和为 0（多空各 50%），所以它天然对"市场整体涨跌"免疫，看起来非常"分散"：

```python
w_b = np.full(n_stocks, 1/n_stocks)                 # 等权基准
mom_z = (B[:,3] - B[:,3].mean()) / B[:,3].std()     # 动量暴露 z 分数
rank = np.argsort(mom_z)
top, bot = rank[-90:], rank[:90]                    # 前/后 30%
w_p = np.zeros(n_stocks)
w_p[top] = 0.5/len(top); w_p[bot] = -0.5/len(bot)   # 多空各 50%
aw = w_p - w_b                                      # 主动权重（相对基准）
```

## 三、收益归因：主动收益到底从哪来

组合的主动收益（相对等权基准）在第 $t$ 期为：

$$ R^{act}_t = \sum_i a_i\, r_{it} = \mathbf{a}^\top\mathbf{B}\,\mathbf{f}_t + \sum_i a_i u_{it} $$

其中 $\mathbf{a}=\mathbf{w}_p-\mathbf{w}_b$ 是主动权重。关键一步：把 $\mathbf{a}^\top\mathbf{B}$ 先乘出来，得到 $K$ 维的**主动因子暴露** $\mathbf{B}^{act}$。之后每个因子的累计贡献就是它的暴露乘以该因子的累计收益：

$$ C_k = B^{act}_k \sum_t f_{tk}, \qquad C^{spec} = \sum_t \sum_i a_i u_{it} $$

两者之和**严格等于**总主动收益——这是一个线性恒等式，不靠任何近似或拟合，所以归因绝不会"对不上账"。

实验里这个动量组合的累计主动收益是 **+1.2614**。拆开看（图 2）：

- 动量因子：**+1.1746**（占总主动收益的 **93%**）
- 价值因子：+0.0826
- 特异收益：+0.0606
- 市场因子：−0.0673（多空组合带了轻微负市场暴露，拖了后腿）
- 规模、波动率、质量：几乎为零

结论刺眼：你以为在做"300 只股票的精细选股"，实际上 **93% 的盈亏是动量这一个因子在替你下注**。其余两个勉强为正的项目（价值、特异）加起来还不到 7%。

## 四、风险归因：让你睡不着的夜晚是谁造成的

收益归因回答"赚的钱从哪来"，风险归因回答"波动是谁制造的"。主动风险（跟踪误差）的方差满足：

$$ \sigma^2_{TE} = \mathbf{B}^{act\top}\boldsymbol{\Sigma}_f\mathbf{B}^{act} + \sum_i a_i^2\sigma^2_{u,i} $$

第一项是因子风险，第二项是个股特异风险。要把总风险拆回每个因子，用 **Euler 分解**（齐次函数的分量贡献定理）：

$$ CTR_k = \frac{B^{act}_k\,(\boldsymbol{\Sigma}_f\mathbf{B}^{act})_k}{\sigma_{TE}}, \qquad CTR^{spec} = \frac{\sum_i a_i^2\sigma^2_{u,i}}{\sigma_{TE}} $$

CTR（Component Contribution to Risk，成分风险贡献）之和**恰好等于** $\sigma_{TE}$——这是 Euler 分解的数学必然，不是拟合出来的。

本例月度跟踪误差 $\sigma_{TE} =$ **2.95%**。成分风险贡献（图 3）显示：

- 动量因子：**+0.0288**（占跟踪误差的 **97.5%**）
- 特异风险：+0.0010（3.3%）
- 其余因子：趋近于 0

注意市场因子的 CTR 是 **−0.0006（负的）**。这绝不是算错：因为市场与动量正相关（+0.4），而我们的动量多空组合带了轻微负的市场暴露，于是市场因子的波动反而和动量"对冲"掉了一部分，对总风险的贡献为负。Euler 分解里出现的负号，正是组合内部风险结构的真实写照——它告诉你哪两个维度在互相抵消。

## 五、暴露地图：组合到底"偏向"哪里

把图 1 的主动因子暴露 $\mathbf{B}^{act}$ 画出来，结论一目了然：动量暴露高得离谱（约 +1.18，因为多空前 30% 减后 30%），价值暴露小幅为正（+0.05），市场暴露为负（−0.04），其余因子在零附近。

![图1 组合的主动因子暴露](/images/barra-risk-attribution/fig1_exposure.png)

这**不是"中性"，而是"只对动量有意见"**。一个常见误区是把"权重分散"当成"风险分散"——权重分散只保证你没把鸡蛋放一个篮子，但所有篮子可能都绑在同一辆车上。暴露地图就是把"车"显形出来的工具。读懂这张图，你就能在组合建好的一瞬间判断：它到底是分散投资，还是披着分散外衣的单因子下注；前者能扛住因子轮动，后者一旦它赖以生存的因子回撤，就会整篮子的钱一起缩水。

## 六、知道了又怎样：归因之后的三个动作

1. **约束因子暴露。** 如果你的目标是真正分散，就该对 $\mathbf{B}^{act}$ 里的动量分量设上限（比如 $|\mathbf{B}^{act}_{动量}|\le 0.3$），强制把风险摊到其他维度。Barra 优化器里这叫"因子中性约束"，本质就是给归因结果上的一道保险。
2. **区分"靠运气"和"靠能力"。** 如果某段时间的 alpha 几乎全来自一个顺风因子，那不是你厉害，是风大。归因能把"因子 beta 收益"和"真正的选股 alpha（特异收益）"分开——本例特异收益仅 +0.06，说明真实选股贡献微乎其微，绝大部分是动量 beta 的馈赠。
3. **监控漂移。** 组合建好时暴露可能是中性的，但调仓几次后可能悄悄偏向某个因子。把归因做成日报，能在风险失控前预警，而不是等回撤发生了才翻旧账。

## 七、诚实的局限

- 本例用的是**已知真值**的合成宇宙。实盘中 $\mathbf{B}$（暴露）和 $\boldsymbol{\Sigma}_f$（因子协方差）都要靠估计，估计误差会直接污染归因结论，尤其在小样本、高换手时。
- Barra 的暴露 $\mathbf{B}$ 通常用个股特征（市值、估值、动量等）对因子收益回归得到，存在"用收益解释收益"的循环，归因精度受回归窗口选择影响。
- CTR 是**边际**贡献，加总等于总风险，但单个 CTR 不能直接拿来做"减掉这个因子就降这么多风险"的因果推断——因为因子间有相关（如本例市场-动量 +0.4），减一个会改另一个的贡献符号和大小。
