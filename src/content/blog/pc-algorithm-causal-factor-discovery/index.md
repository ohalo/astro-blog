## 问题：相关榜选出来的因子，为什么会选出「关系户」

因子工厂的日常是这样的：算一遍所有因子对未来收益的边际相关，取 top-3 进模型。听起来很数据驱动，直到你会发现选进来的不是「对收益有因果贡献」的因子，而是「跟收益有牵连」的因子——这两件事在因果图上的距离，可以只有一个碰撞器（collider）那么远。

我们造了一个六因子的模拟世界来把这件事钉死：市值 S、动量 Mo 是外生因子（各自的独立冲击驱动）；价值 V、波动 Vo 则各有一半血统由 S 派生（V=0.62·S+噪声，Vo=0.50·S+噪声）；换手 To 由 S 和 Mo 共同驱动；而未来收益 Y **只被 Mo、V、Vo 直接驱动**。真值长这样：

![真值 DAG：Y 的父集只有 Mo、V、Vo](/images/pc-algorithm-causal-factor-discovery/true-dag.png)

按边际相关性，换手率 To 与收益 Y 的相关达到 0.272——比真父集成员 Vo（0.245）和 S（0.238）都高。但 To 对 Y 没有任何直接的因果贡献：它的相关全部来自「被 Mo 驱动」这条旁路（To←Mo→Y）。它就是那个挤进前三的关系户。

## 碰撞器：相关矩阵系统性看不见的东西

先看本文最扎眼的一个数。n=6000 时：

- corr(S, Mo) = **-0.001**，p=0.93 —— 干净得可以直接写进「因子正交性检验通过」；
- corr(S, Mo | To) = **-0.383**，p<1e-12 —— 一旦 conditioning 在 To 上，S 和 Mo 立刻强相关。

这就是碰撞器：两个独立的原因（S、Mo）共同驱动一个结果（To）。不看 To 时两者互不相干；一旦把 To 放进回归（或按 To 筛样本），S 和 Mo 就被「连线」了——给定 To 的一个实现，S 高就暗示 Mo 低，就像两位嫌疑人各自独立地解释了同一个案发时间。

![边际相关矩阵 vs 给定碰撞器 To 的偏相关矩阵](/images/pc-algorithm-causal-factor-discovery/corr-vs-partial.png)

对因子选择的直接伤害是双向的：你不仅会把碰撞器（或碰撞器的后代）当成有用因子选进来，还会在它进入模型后**扭曲其他因子的系数**——S 和 Mo 在含 To 的回归里会互相抢解释力，系数和显著性都变得不可解释。这就是很多「加入一个新因子，老因子系数全变」现象的因果图解释。

## PC 算法：只问「给定这些，那两个还相关吗」

PC 算法（Peter–Clark，以发明者命名）的哲学是：不最大化任何拟合、不猜任何方向，只做一种提问——**给定条件集 S，X 和 Y 是否条件独立（X⊥Y|S）**。答案全在偏相关里：从 6×6 相关矩阵取出 {i, j}∪S 的子矩阵求逆，偏相关 = -P[0,1]/√(P[0,0]·P[1,1])；再用 Fisher-z 变换 z = ½·ln((1+r)/(1-r))·√(n-|S|-3) 换成 p 值。流程三步：

1. **骨架**：从全连接图出发，对每条边 (i,j) 依次尝试一切大小 0、1、2……的条件子集，任何一个做出「独立」判决就删边，并把该子集记为 sepset(i,j)；
2. **v-结构**：对每个未连接对 (i,j) 的走廊 i–k–j，若 k **不在** sepset(i,j) 里，判定 i→k←j——碰撞器是因果方向在数据里唯一「自证」的签名；
3. **Meek 规则**：三条定向传播规则迭代到不动点（例如 a→b 且 b–c 且 a、c 不相邻，则 b→c，否则制造新碰撞器或成环，与已定方向矛盾）。

输出的图叫 CPDAG：无环、且与真图蕴含**同一族条件独立关系**的那个图——有些边能被数据定向，有些不能，后者以无向线段的形态公开留白。

以下是可直接运行的骨架核心（numpy + scipy，无其他依赖）：

```python
import numpy as np
from scipy.stats import norm
from itertools import combinations

def fisher_p(r, n, k):                      # 偏相关的 Fisher-z 双侧 p 值
    r = np.clip(r, -0.999999, 0.999999)
    z = 0.5 * np.log((1 + r)/(1 - r)) * np.sqrt(n - k - 3)
    return 2 * (1 - norm.cdf(abs(z)))

def pcorr(C, i, j, S):                      # 经精度矩阵求偏相关
    if not S: return C[i, j]
    idx = [i, j] + list(S)
    P = np.linalg.inv(C[np.ix_(idx, idx)])
    return -P[0, 1] / np.sqrt(P[0, 0] * P[1, 1])

def pc_skeleton(C, n, alpha=0.01, maxdep=4):
    N = C.shape[0]
    adj = {i: set(range(N)) - {i} for i in range(N)}
    sep = {}                                 # sepset 记录，v-结构要用
    for depth in range(maxdep + 1):
        for i in range(N):
            for j in sorted(adj[i]):
                if j < i or j not in adj[i]: continue
                nb = sorted(adj[i] - {j})
                if len(nb) < depth: continue
                for S in combinations(nb, depth):
                    if fisher_p(pcorr(C, i, j, S), n, depth) >= alpha:
                        adj[i].discard(j); adj[j].discard(i)
                        sep[frozenset((i, j))] = set(S)
                        break                # 找到一个独立证据就够
    return adj, sep                          # adj 即无向骨架
```

## 还原成绩单：47 次检验，5 条边定对，2 条边留白

n=6000、α=0.01 下跑完整流程（v-结构 + Meek R1–R3）：47 次条件独立检验，骨架找回 7/7 条真边、零假边；v-结构在 To 处抓到 S→To←Mo，在 Y 处抓到 Mo→Y←V、Mo→Y←Vo、V→Y←Vo，加上 Meek 传播后 **5 条可定向边全部正确**。而 S–V 和 S–Vo 保持无向——这**不是算法的失败，是数据的极限**：把真图里 S→V 翻转成 S←V，整个条件独立关系族一模一样（Markov 等价）。观测数据永远无法告诉你 S 和 V 谁驱动谁；想知道，得靠实验、时间顺序先验（比如「市值在月初定、价值由上月数据算」这类构造信息）或者干预。

![PC 算法输出的 CPDAG：5 条边定向正确，S–V、S–Vo 诚实留白](/images/pc-algorithm-causal-factor-discovery/cpdag-recovered.png)

关键 sepset 证据链：To⊥Y|{S, Mo}（换手对收益没有旁路—— conditioning 掉 S 和 Mo 后 To 是死变量）、S⊥Y|{V, Vo}、V⊥Vo|{S}、Mo⊥S|∅。最后一条是碰撞器故事的骨架版：S 和 Mo 从头到尾没有直接连边，它们的全部「交情」都要经过 To。

## 命门一：α 无关紧要时别折腾 α；命门二：n 才是亲爹

有人信奉「α 调到 0.001 才严谨」。α 扫描显示：n=6000 时 α 从 0.001 到 0.1，召回率全部 7/7、假边全部 0——**效应量足够大时，α 是安慰剂参数**。真正的问题是样本量。看两个数字：弱旁路 S→Vo→Y 产生的偏相关 r(S,Y|V) 只有 **0.071**。n=6000 时 z=0.071×√5993≈5.5，稳稳存活；n=300 时 z≈1.2，p=0.22，Fisher-z 直接把它判成噪声——S⊥Y|{V} 的错误独立判决一旦做出，v-结构就会把 Y→Vo 反向定出来。整个 n 扫描：n=500 时 12 个种子里 **0 个**完整还原 CPDAG（平均每种 1.83 条错误定向弧），n=1000 过半（58%），n=4000 才到 92%，n=10000 全对。

![α 扫描与 n 扫描：PC 的两个命门](/images/pc-algorithm-causal-factor-discovery/alpha-scan.png)

对小样本横截面做因果发现，等于让算法用放大镜找一粒米：判决噪声比信号还大。要么攒够 n，要么用 bootstrap 重复跑、只保留高频出现的边（稳定版 PC 的核心思想），别贪快。

## 下游大考：换掉排序依据，样本外成绩就变了

最后把「发现能力」折算成钱。对 12 个独立种子各生成 n_train=n_test=6000 的面板，比较四种因子选择策略的样本外 MSE：

| 策略 | 因子集 | OOS MSE（12 种子均值） |
|---|---|---|
| 边际第一名 | {Mo} | 0.914 |
| **朴素 top-3（边际相关）** | **{V, Mo, To}** | **0.832** |
| **CPDAG 父集** | **{Mo, V, Vo}** | **0.801** |
| 全部 5 因子 | {S, Mo, V, Vo, To} | 0.801 |

朴素 top-3 在 **12 个种子里全部**把关系户 To 选进前三、**全部**把真父集成员 Vo 踢出局，样本外 MSE 比因果父集贵 **3.8%**。而「全都要」组证明 S、To 确实不携带增量信息——它们只能把 5 个参数摊薄成和 3 参数模型一样的成绩，还额外背上共线性方差。因果父集用一半的因子数贴住全知基准：这就是因果发现对因子选择的真正兑现方式——**不是预测更准，是更小的模型、可解释的系数、和不花哨的稳定性**。

## 诚实边界

1. **可定向的只是 Markov 等价类**。2/7 的边（S–V、S–Vo）PC 永远定不了向，需要构造信息（谁先被计算出来）或干预实验补刀；宣称 PC「学出因果图」的文案都该按 CPDAG 打折。
2. **无隐变量假设在因子动物园里是奢侈品**。若存在没观测到的共同驱动（机构资金流同时打高换手、波动和短期收益），PC 会画出错误的直接边。隐变量版本（FCI）把边分成四类，代价是更多留白。
3. **线性相关性、因果线性性、无误设**：本文的检验是线性高斯的，非线性条件独立（波动聚集、阈值效应）Fisher-z 一概看不见——kernel CI 检验能救，但计算量是平方级起跳。
4. **3.8% 的 OOS 提升值得泼冷水**：真值是我们自己造的，效应量（0.18–0.30）是刻意放在朴素方法「看得见但不该选」的位置；真实因子的信噪比更低，小样本还原率会跌破本文的 n 扫描下限。PC 是探路的罗盘，不是提款机——把它当「哪些因子关系值得做 A/B 实验」的候选生成器，才是它在流水线里的正确工位。
