## 一、结论先行

拿到一块 N 只股票、T 个时期的收益面板，想用因子模型压风险，第一个问题就是：**里面到底有几个真实的共同因子？** 数多了把噪声当信号，协方差矩阵过拟合；数少了漏掉真实的共同波动，风险估计系统性偏低。Bai-Ng (2002) 的信息准则是这个问题的教科书答案，但它的推导里藏着一个隐含假设——因子是强的，每个因子的特征值都远远高出噪声 bulk。本文用真值已知的合成面板把这件事钉死，结论有四条：

1. **强因子下四种判据全对，没有任何悬念。** N=100、T=250、r=3 的标准设定里，IC_p1、PC_p1、IC_p3 和 Ahn-Horenstein 特征值比 ER 全部 150 次重复都精确命中 r=3。教科书没问题。
2. **弱因子下 IC_p1 系统性漏掉最弱的那一个，且漏掉的位置被理论精确预言。** 把第三个因子的载荷缩放 c 倍，IC_p1 的正确率在 c=0.30 还有 99.3%，c=0.25 剩 95.3%，c=0.20 崩到 22.0%——理论临界点 c\*=0.2482 分毫不差地卡在这中间。这个临界点是解析的：当第三因子贡献的方差比 ln(1+c²) 小于惩罚项时，准则必然选 k=2。
3. **反向场景暴露了 ER 的荒谬。** 纯噪声面板（真值 r=0）下，三个 Bai-Ng 准则都老实给出 r=0，而 ER 平均报出 3.03 个因子、150 次重复 100% 高估——特征值比的 argmax 机制在平坦的噪声谱上就是随机指一个位置。
4. **最危险的盲区不在风险端，在收益端。** 漏掉一个 c=0.20 的弱因子，最小方差组合的真实波动只上升 1.43%，看起来无伤大雅；可如果这个低方差因子承载着最强的收益预测力，漏掉它让组合每期 Sharpe 从 0.63 掉到 0.37。**二阶矩判据按方差大小定去留，而量化里最值钱的因子往往方差最小。**

## 二、近似因子模型与四种判据

近似因子模型假设收益面板可以写成少数共同因子加特异噪声：

$$X_{it}=\sum_{r=1}^{k}\lambda_{ir}f_{tr}+e_{it},\qquad i=1,\dots,N,\ t=1,\dots,T$$

Bai-Ng 的思路是把「取前 k 个主成分之后的残差方差」与「模型复杂度惩罚」加在一起求最小：

$$V(k)=\frac{1}{NT}\sum_{j=k+1}^{\min(N,T)}d_j^2,\qquad IC_1(k)=\ln V(k)+k\cdot\frac{N+T}{NT}\ln\frac{NT}{N+T}$$

其中 $d_j$ 是面板奇异值。惩罚系数 $g_1=\frac{N+T}{NT}\ln\frac{NT}{N+T}$ 在 N=100、T=250 时等于 0.0598。PC_p1 用 $V(k)+k\,\hat\sigma^2 g_1$ 的形式，IC_p3 换成轻惩罚 $g_3=\ln\min(N,T)/\min(N,T)=0.0220$。特征值比 ER 则完全不走惩罚路线，直接取相邻特征值比值的 argmax。四种判据、一段 numpy，从 SVD 出发几行就能实现：

```python
import numpy as np

def bai_ng_criteria(X, kmax=8):
    """X: T x N 收益面板，返回四种判据各自选出的因子个数"""
    T, N = X.shape
    d2 = np.linalg.svd(X, compute_uv=False) ** 2      # 降序特征值
    NT = N * T
    g1 = (N + T) / NT * np.log(NT / (N + T))          # IC_p1 惩罚
    g3 = np.log(min(N, T)) / min(N, T)                # IC_p3 惩罚（轻）
    V = np.array([d2[k:].sum() / NT for k in range(kmax + 1)])
    ks = np.arange(kmax + 1)
    ic1 = np.log(V) + ks * g1
    ic3 = np.log(V) + ks * g3
    pc1 = V + ks * V[kmax] * g1
    er = np.argmax(d2[:kmax] / d2[1:kmax + 1]) + 1    # 特征值比
    return int(np.argmin(ic1)), int(np.argmin(pc1)), int(np.argmin(ic3)), int(er)
```

数据生成同样几行：三个独立标准正态因子、N×3 的标准正态载荷、单位方差噪声，唯一的手脚是把载荷第三列乘上缩放系数 c——c 越小，第三个因子越「弱」：

```python
def gen_panel(c, N=100, T=250, seed=20261120):
    rg = np.random.default_rng(seed)
    F = rg.standard_normal((T, 3))          # 三个真因子
    L = rg.standard_normal((N, 3))          # 载荷
    L[:, 2] *= c                            # 第三个因子乘上 c，变"弱"
    return F @ L.T + rg.standard_normal((T, N))
```

c=1.0 时第三个因子与另外两个一样强；c=0.15 时它贡献的截面方差只有 c²≈2%，特征值已经沉到噪声 bulk 的边缘（图 1 右）。这个参数就是全文的实验旋钮。

## 三、强因子下四种判据全对

c=1.0 的单次实验里，四种判据一致给出 r=3：前三个特征值（按 d²/T 归一）在 70–110 之间，噪声 bulk 的 Marchenko-Pastur 上界只有 2.66，信号与噪声隔着接近两个数量级的鸿沟，任何合理的判据都不会看走眼。150 次重复的蒙特卡洛里，IC_p1、PC_p1、IC_p3、ER 的正确率全部是 100%。

![图2：三种场景下的判据曲线——强因子、弱因子、纯噪声](/images/bai-ng-factor-number-selection/fig2_criteria_curves.png)

图 2 左 panel 是这一节的全部内容：IC_p1 曲线在 k=3 处取得明显的最小值，惩罚项在强因子面前不值一提。**这一节的真正作用是给后文定锚**——同样的代码、同样的样本量，唯一变化的只有第三个因子的强度，如果后面判据开始犯错，原因就只能归到弱因子上，而不是实现错误。

## 四、弱因子的临界点：理论与蒙特卡洛对上了

IC_p1 在 k=2 与 k=3 之间的比较可以解析展开。取前 2 个主成分时残差方差 $V(2)\approx 1+c^2$（噪声加第三因子贡献），取前 3 个时 $V(3)\approx 1$。IC_p1 选 3 当且仅当：

$$\ln(1+c^2) > g_1 \iff c > \sqrt{e^{g_1}-1}$$

代入 g₁=0.0598 得临界点 c\*=0.2482。这是个非常清晰的预言：载荷缩放低于 0.2482 的因子，在 IC_p1 眼里与噪声无异——不是判据「偶尔失误」，而是**必然漏掉**。

150 次重复的扫描精确验证了这个临界点（图 3）：c=0.30 时 IC_p1 正确率 99.3%，c=0.25 时 95.3%（跨在临界点上方），c=0.20 时 22.0%（跌落），c≤0.15 时 0%。理论线 c\*=0.2482 恰好画在成功率断崖的正中间。

![图3：弱因子强度扫描——四种判据选中 r=3 的频率与理论临界线](/images/bai-ng-factor-number-selection/fig3_weak_factor_scan.png)

更有信息量的是四条曲线的**相对位置**。PC_p1 和轻惩罚的 IC_p3 明显更耐受：c=0.20 时两者分别还有 66.7% 和 88.7% 的正确率，临界点被推到 c≈0.15–0.20。这不是免费的午餐——图 2 右 panel 显示轻惩罚在噪声更肥的场景会付出代价（下节用纯噪声检验这一点）。ER 则是另一个极端：c≤0.30 时正确率恒为 0%，它要等特征值比拉开到 c≈0.5 才稳定命中（c=0.50 时 99.3%）。**四种判据在弱因子区间没有一个是全对的，差别只在漏的方向和程度。**

## 五、纯噪声的反向检验：ER 凭空造出 3 个因子

选因子个数是个双向错误的问题：漏掉真因子（低估）与把噪声当因子（高估）都要付出代价。前面只看了低估端，这一节补上高估端：r_true=0 的纯噪声面板，四种判据会报什么？

结果一边倒：IC_p1、PC_p1、IC_p3 的平均报数为 0.000，150 次重复零次高估——Bai-Ng 惩罚项在纯噪声下把所有候选因子全部压死，这个设计确实把「宁缺毋滥」做得很扎实。ER 的表现则完全失控：平均报出 3.03 个因子，100% 的重复都高估。原因很机械——纯噪声的特征值谱是平缓下降的曲线，相邻比值接近常数，argmax 就在这个平坦曲线的某个随机位置取最大值，均值恰好落在 3 附近纯属这个样本量下的巧合，换个 N、T 就会漂移。

**这解释了为什么 ER 在实务里「看起来保守」其实不可靠**：它在弱因子上过度保守（c=0.25 时正确率 0%），在纯噪声上又凭空造因子。一个在两个方向都出错的判据，比一个只在弱因子上低估的判据危险得多——后者至少错误方向一致、可以用经济常识兜底。

## 六、经济代价与真正的盲区：方差小不等于不重要

漏掉弱因子到底多疼？用前 k 个主成分重构因子协方差矩阵（主块加对角特异修正），求最小方差组合，再用真实协方差评估它的波动。图 4 给出三条曲线：k=2 的组合波动始终高于 k=3，超出的幅度随 c 增大——c=0.20 时 +1.43%，c=0.30 时 +3.34%，c=0.50 时 +8.96%，c=1.00 时 +33.57%。注意这幅图的读法：IC_p1 只在 c<0.25 区间犯错，而那个区间里 k=2 的额外波动只有 1.4% 左右。**惩罚项漏掉的因子，恰好是风险贡献已经小到接近噪声的因子——从纯风险管理的角度看，Bai-Ng 的「误判」代价出奇地小，这其实是个安慰性的结论。**

![图4：漏掉因子的经济代价——k=2 组合的真实波动始终更高](/images/bai-ng-factor-number-selection/fig4_economic_cost.png)

但风险端的小代价掩盖了收益端的大问题。把实验改成这样：三个因子里，f₁、f₂ 是白噪声加 AR(1) 系数 0.35 的弱可预测因子，f₃ 方差被 c 压得很低、AR(1) 系数却是 0.70 的强可预测因子——一个典型的「低波动高 alpha」因子。用 k 个因子建模、构造预期收益、再用真实矩评估组合的每期 Sharpe：

![图5：alpha 盲区——被漏掉的因子承载着最大的可预测收益](/images/bai-ng-factor-number-selection/fig5_alpha_blind_spot.png)

c=0.20（IC_p1 的误判区间）时，保留真值 k=3 的 Sharpe 是 0.626，按 IC_p1 截到 k=2 只剩 0.374，差距 0.25；c=0.30 时差距拉大到 0.51——f₃ 的稳态方差（c²/0.51≈0.18）已远低于 f₁、f₂ 的 1.14，任何基于方差的判据都把它排到最后，但它承载的预测信号（φ=0.70 对 0.35）是前两个因子之和还要多。c=1.0 处曲线反而回落，那是因为 f₃ 的稳态方差升到 1.96、已不再是弱因子，此时 k=2 漏掉的是三者中最强的因子，损失同样可观（0.76 对 0.32）。

这就是全文最想留下的警告：**Bai-Ng 这类判据度量的是因子对二阶矩（协方差）的解释力，而组合管理的收益端依赖的是因子对条件均值（alpha）的预测力。这两个「重要性」在弱因子区域完全可以反向。** 用方差解释率去裁剪因子库，等于用风险管理的标准去裁剪收益引擎。

## 七、实操建议

把前面的结果收拢成四条可执行的规则：

1. **主判据用 IC_p1/PC_p1，但把临界区标出来。** 算出你的 N、T 对应的 g₁，再对候选因子按特征值排序，凡是排在 $\sqrt{e^{g_1}-1}$ 临界强度附近的因子，都要意识到判据在这里的答案是「抛硬币」。
2. **多判据交叉，分歧即信号。** IC_p1 给 2、IC_p3 给 3 时（c≈0.20 的典型场景），说明面板里有一个边界强度的因子——此时值得单独检验它的经济含义，而不是机械听从任何一个。
3. **不要用 ER。** 本文它在弱因子端全错、纯噪声端 100% 高估，唯一比它更糟的做法是只凭碎石图肉眼找肘部。
4. **alpha 因子单独走一条通道。** 方差贡献低于判据阈值的因子，如果承载预测信号（高 IC、低波动），不要用因子个数选择去裁剪它——把它放进收益预测模型，让组合优化去决定它的仓位。风险模型追求的是协方差的完整，收益模型追求的是信号的存活，两个模型对「弱」的定义本该不同。

本文全部数值来自 N=100、T=250、150 次重复的蒙特卡洛，代码即第二节的两段函数加上扫描循环，可整段复制运行。判据本身只有十几行，难的不是实现，而是记住它看不见什么。
