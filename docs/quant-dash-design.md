## 1. 先回答灵魂拷问：这个页面凭什么存在

一个页面的合法性来自它能回答用户每天真实会问的问题。你的问题清单（从你的原话反推）：

| # | 每天真实的问题 | 现在能回答吗 | 对应模块 |
|---|---|---|---|
| Q1 | 今天大盘怎么样？我的自选里哪只在异动？ | ❌ 完全没有 | 顶部行情带 + 左侧自选列表 |
| Q2 | 茅台现在什么价位？离 52 周高点多远？放量没有？ | ⚠️ 只有一根裸K线 | 价格头部 + 右侧量化卡 |
| Q3 | 它的趋势怎么看？日K看不出就看周K月K | ❌ 只有日K | **周期系统：日/周/月/年**（周月年由日线聚合，真实可算） |
| Q4 | 今天盘中怎么走的？（分时/五日） | ❌ 缺 | 分时/五日（需分钟数据源，见 §8 决策） |
| Q5 | 它贵不贵？PE/PB 历史分位 | ❌ 缺 | 估值卡（baostock 有 PE 日线，M0 补入库后可真实） |
| Q6 | 波动率、动量这些我文章里写的指标，此刻在它身上是多少？ | ❌ 缺 | **量化衍生卡**（数据湖可算，M0 就能真实） |
| Q7 | 我的策略/模拟盘今天跑赢基准没？ | ⏳ M3 才有 | 底部策略状态条（原型中灰色"待点亮"） |
| Q8 | 我看的这份数据是几点更新的，可信吗？ | ❌ 从没显示 | 数据新鲜度卡（publishedAt，已有真实数据） |

**设计目标一句话**：打开 `/dash`，30 秒内得到「市场概况 + 自选异动 + 选中股的价格/趋势/量感/估值/量化画像」，
并且随时知道数据新鲜度。它不是 K线展示页，是**每天收盘后 10 分钟的复盘工作台**——这是它区别于东财
App 的立足点：东财给你行情，这里给你**行情 + 你自己数据湖算出来的量化指标**（Q6 是杀手锏，
也是把你 580 篇研究脚本资产变现的入口）。

## 2. 设计原则（为什么之前那版丑）

旧版三宗罪：① 图表悬在空白文档里，没有信息架构；② 无视觉层级，价格与说明文字一样大；
③ 没有任何"结论性"内容，等于把数据库表吐在屏幕上。新版原则：

1. **密度分级**：主数字（价格）28px/600，标签 12px/muted，卡内键值对紧凑双列。信息密度对标行情终端，
   不留大面积空白。
2. **结论前置**：每个卡片回答一个问题，标题就是问题（"波动率画像"而不是"数据展示"）。
3. **跟随博客主题**：全部颜色走 Pure 主题变量（`hsl(--card/--border/--muted-foreground)`），
   深色模式自动适配，视觉上是博客的亲生儿子。
4. **数字用等宽**：`ui-monospace` + `tabular-nums`，对齐不跳动。
5. **红涨绿跌**（A股习惯），`--qk-up:#e64545 / --qk-down:#1aa16a` 独立 token，未来可一键换绿涨红跌。
6. **示意内容必须打徽章**：所有未接真实数据源的模块右上角挂 `示意` 小徽章，绝不假装真实。

## 4. 模块明细（每个模块：回答什么 + 数据来源）

| 模块 | 回答的问题 | 内容 | 数据来源 | 真实性 |
|---|---|---|---|---|
| ①行情带 | Q1 大盘如何 | 四大指数价+涨跌幅、涨/跌家数、数据新鲜度 | `qplat ingest-index`（baostock 日线含指数，**需新入库**） | 原型示意→M0真实 |
| ②自选列表 | Q1 谁在异动 | codes.txt 成员、现价、涨跌幅、60日sparkline | 日线数据湖 + `/api/stock` 批量实时 | 茅台真实 |
| ③主图 | Q3 趋势 | 六周期切换 + MA 多选 + 成交量副图 + 区间快捷键 | **周/月/年 = 日线本地聚合，即刻真实**；分时/五日见 §8 | 日周月年真实 |
| ④价格档案 | Q2 价位全景 | 今开昨收高低量额换手、PE/PB/市值 | 日线(真实) + baostock `query_history_k_data_plus` 的 peTTM/pbMRQ(**需扩字段**) | 半真实 |
| ④52周位置 | Q2 | 高/低/现价三点位置条 | 数据湖250日 high/low | ✅真实 |
| ④量能 | Q2 放量没有 | 量比(今日量/5日均量)、20日均量 | 数据湖 volume | ✅真实 |
| ④波动率画像 | **Q6 杀手锏** | 20日年化波动率、20日动量、距250日高回撤 | 数据湖 close 计算 | ✅真实 |
| ④估值 | Q5 贵不贵 | PE-TTM/PB + 历史分位 | baostock peTTM 日序列(需入库后算分位) | 原型示意 |
| ⑤底部条 | Q7 | 因子/回测/模拟盘入口，未上线灰显+预计里程碑 | — | 导航占位 |

**注意 M0 立刻能全部变真实的部分**：日/周/月/年K线、52周位置、量能、波动率画像——全部只依赖已在湖里的日线。

## 6. 视觉规范（Design Tokens）

```css
:root {                       /* 亮色: 全部对齐 Pure(shadcn式) 主题变量 */
  --qk-bg-card: hsl(var(--card));        --qk-border: hsl(var(--border));
  --qk-text: hsl(var(--foreground));     --qk-muted: hsl(var(--muted-foreground));
  --qk-up: #e64545;  --qk-down: #1aa16a; --qk-flat: #9ca3af;
  --qk-ma: #f59e0b; --qk-ma2:#3b82f6; --qk-ma3:#a855f7; --qk-ma4:#0ea5e9;
}
.dark { --qk-up:#f16a6a; --qk-down:#3fba85; }  /* 深色下提高亮度保对比 */
```

字体层级：现价 28/600 等宽｜涨跌 14/600｜股票名 15/600｜卡片标题 13/600 muted｜键值标签 12/muted、值 13/等宽。
卡片：`border-radius:12px; border:1px solid var(--qk-border); background:var(--qk-bg-card); padding:12px 14px`，
阴影只在 hover。 segmented 周期按钮：28px 高胶囊组，激活态 `background:hsl(var(--muted))`。
涨跌色只用于数字，不染大面积背景（防廉价感）。空态/骨架屏：灰色 shimmer，不出现文字堆。

## 8. 待你拍板的三个决策

1. **分时/五日要不要进 M0？** 日线体系里它俩需要分钟数据源。我的建议：M0 用现有 Vercel
   `/api/stock` 函数加分钟代理即时实现（盘中实时、零发布压力），分时图样式简单化（线+量，不画 tick 盘口）。
   或者砍到 M1 之后。
2. **配色惯例**：红涨绿跌（默认建议，A股习惯）还是绿涨红跌（国际习惯）？做成 token 可切换，但要定默认。
3. **自选列表数据**：`platform/codes.txt` 即自选的唯一来源（改了要跑一次 daily），还是希望以后页面
   上自己管理自选（那是 M4 用户系统的事，阶段零建议先用文件）？
